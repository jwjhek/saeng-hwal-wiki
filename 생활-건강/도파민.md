# 도파민

> **분류:** 생활·건강 · [[생활위키 목차]]

**도파민**(dopamine)은 뇌·몸에서 쓰이는 **신경전달물질**이다. 
운동·동기·보상·학습 등에 관여한다고 알려져 있어, 뉴스·SNS에서 **「도파민 중독」** 같은 말이 자주 나온다.

이 글은 **생물학 개념**만 정리한다. **진단·치료·보충제 복용 권유가 아니다.**

확인일: 2026-08-11

관련: [[노르에피네프린]] · [[세로토닌]] · [[코르티솔]] · [[정신건강]] · [[우울장애]] · [[아카시지아]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 정체 | 뇌 신경세포·일부 신경 밖에서도 쓰는 **화학 메신저** |
| 흔한 연상 | **기쁨·보상·동기** — 실제로는 **여러 회로**가 나뉨 |
| 만들기 | 아미노산 **티로신** → (중간 단계) → **도파민** → [[노르에피네프린]] |
| 인기 말 | 「도파민 디톡스」「중독」 — **과장·단순화**가 많음 (§8) |

```text
티로신
 ↓
L-도파 (레보도파)
 ↓
★ 도파민
 ↓
노르에피네프린 → 에피네프린(아드레날린)
```

---

## 2. 뇌에서 하는 일 (경로마다 다름)

도파민은 **한 가지 역할**이 아니다. **어디서 나오느냐**에 따라 기능이 갈린다.

| 경로 (대략) | 주로 연관되는 것 |
|-------------|------------------|
| **흑질-선조체** | **운동 조절** — 여기가 많이 줄면 **파킨슨병** 논의 |
| **중뇌피질-변연계** | **보상·동기·습관** — 중독·습관 연구에서 자주 언급 |
| **중뇌피질-전전두피질** | **주의·계획·동기** — [[정신건강]]·[[ADHD]] 논의와 겹침 |
| **시상하부 등** | 호르몬·자율신경과 **연결** (호르몬 분비 조절 등) |

「도파민 = 행복 호르몬」처럼 **한 줄로 말하기 어렵다.** 
[[세로토닌]]·[[노르에피네프린]]·GABA 등과 **함께** 작동한다.

---

## 3. 일상에서 느끼는 것과의 관계

| 현상 | 도파민과의 관계 (단순화) |
|------|--------------------------|
| 좋아하는 일·성취 | 보상 회로 **활성**과 연관 **연구** 많음 |
| 습관·반복 | **습관 형성**에 관여한다는 모델 |
| 집중·시작하기 어려움 | 동기·주의 회로와 **겹칠 수** 있음 — 원인은 항상 도파민만이 아님 |
| 「무기력」 | 우울·수면·질환·약·스트레스 등 **원인이 다양** — [[우울장애]] |

**혈액 검사 한 번으로 「도파민 부족」을 확정**하는 일은 일반 진료에서 흔하지 않다. 
증상 해석은 **의료** 영역이다.

---

## 4. 너무 적을 때·많을 때 (개념)

| 방향 | 대표적 맥락 (의학은 개인마다 다름) |
|------|-----------------------------------|
| **운동 쪽 부족** | 파킨슨병 — 떨림·경직·느린 동작 등 → **레보도파** 등 처방 |
| **정신건강 쪽** | 우울·무기력·동기 저하 **일부** 모델에서 관여 — **단일 원인 아님** |
| **과다·민감 가설** | 정신분열 등에서 **도파민 가설**이 오래 논의됨 — **단순하지 않음** |
| **약물** | 항정신병약이 **도파민 수용체**를 막으면 **부작용**([[아카시지아]] 등) 가능 |

「부족하면 보충제」가 **성립하지 않는** 경우가 대부분이다. 뇌 안 농도는 **혈액과 다르고**, 함부로 올리면 **위험**하다.

---

## 5. 약·치료와의 연결 (방향만)

| 종류 | 도파민과의 관계 (개념) |
|------|------------------------|
| **레보도파** | 파킨슨에서 **도파민 전구체** 보충 |
| **도파민 작용제** | 수용체를 **직접 자극**하는 약 (적응증·부작용은 처방 전제) |
| **항정신병약** | 주로 **도파민 D2 수용체 길항** — 정신증상 조절과 **부작용** trade-off |
| **[[ADHD]] 흥분제** | 도파민·[[노르에피네프린]] **재흡수 억제** 등 — **처방·감시** 필요 |
| **일부 항우울제** | 간접적으로 **단일 신경전달물질만** 건드리지 않음 |

**임의 복용·타인 약 사용 금지.** 용량·중단은 반드시 **의사** 지시.

---

## 6. 생활·습관 (보조 수준)

도파민을 「올린다」기보다 **뇌·몸 전체**를 돌보는 쪽이 현실적이다.

| 방향 | 내용 |
|------|------|
| **수면** | 불규칙한 수면은 기분·집중을 깨뜨림 |
| **운동** | 규칙적 활동은 기분·인지에 **도움 되는 경우** 많음 (기전은 복합) |
| **작은 목표** | 과도한 자극(숏폼·도박·과음)만 반복하지 않기 |
| **사회·의미** | 관계·일·취미는 「호르몬 한 방」으로 대체되지 않음 |

[[보충제]]·L-도파·Mucuna 등을 **우울·집중용으로 임의 복용**하는 것은 **위험**할 수 있다.

## 7. 다른 신경전달물질과

| 물질 | 한 줄 |
|------|--------|
| [[노르에피네프린]] | 도파민에서 **합성** — 각성·주의·스트레스 |
| [[세로토닌]] | 기분·불안 — **SSRI** 등 |
| GABA | 억제·진정 |
| 글루타메이트 | 흥분성 |

우울·불안·[[ADHD]]는 **한 물질만** 고장난 그림이 아니다.

---

## 8. 흔한 오해

| 오해 | 현실 |
|------|------|
| 도파민 = 쾌락만 | **동기·습관·운동** 등 역할이 나뉨 |
| SNS가 「도파민을 털어 준다」 | 비유일 뿐, **진단명·치료법 아님** |
| 도파민 디톡스로 중독 치료 | **근거 약함** — 중독은 **전문 치료** |
| 티로신·보충제로 뇌 도파민 올림 | 장 흡수·혈뇌장벽·개인차 — **만능 아님** |
| 우울 = 도파민만 부족 | **여러 기전** — 약도 SSRI·SNRI·기타로 나뉨 — [[세로토닌]] |

---

## 9. 정리

1. 도파민은 **운동·동기·보상·습관** 등에 관여하는 신경전달물질이다.  
2. **경로마다 역할이 다르다** — 한 문장으로 정의하기 어렵다.  
3. 파킨슨·정신과 약·[[ADHD]] 치료와 **연결**되지만, **자가 진단·보충제 대체는 금지**다.  
4. 「도파민 중독」 같은 말은 **대화용 비유**로 이해하고, 증상이 있으면 [[정신건강]]·진료를 본다.
