# 페라미플루

> **분류:** 생활·건강 · [[생활위키 목차]]

**페라미플루**는 인플루엔자(독감)에 쓰는 **주사 항바이러스제**의 상품 이름이다. 성분 이름은 **페라미비르**(peramivir). 먹는 [[타미플루]](오셀타미비르)와 **같은 계열**(뉴라미니다제 억제제)이지만, **정맥으로 병원에서 넣는 약**이다. 병의 자리는 [[A형 독감]]을 본다.

**전문의약품**이다. 집에서 사는 주사가 아니고, 이 글에 **용량·넣는 시간·횟수**를 적지 않는다. **독감 예방접종과 다른 약**이다.

숨이 심하게 차거나 의식이 흐리면 **주사를 기다리며 있지 말고 119**. 안내는 질병관리청 **1339**.

## 1. 개요

| 항목 | 설명 |
|------|------|
| **성분** | 페라미비르(수화물). 페라미플루는 **한 회사 상품명**. 같은 성분 다른 이름(프리믹스·제네릭)이 있음 |
| **하는 일** | 바이러스가 세포에서 **퍼져 나가는 단계**를 막음. A형·B형 독감 **치료** 허가가 흔함 |
| **하지 않는 일** | 코 감기 치료, 세균 항생, [[A형 독감]] **백신 대체**, 집에서 자가 주사 |
| **어떻게** | **정맥 점적**(링거처럼). 의료기관에서 의료진이 투여 |
| **구입** | **처방·원내**. 급여·비급여·본인부담은 **기준·병원·절기**가 바뀜 |

```text
독감 의심 → 병의원·응급실 (진찰·검사)
 ↓
삼키기 어렵거나 의사가 주사가 맞다고 보면
 ↓
페라미비르 점적 (페라미플루 또는 다른 상품명)
 ↓
아이·청소년은 관찰 — [[타미플루]] §5와 같은 식약처 안내
```

「한 대 맞으면 독감이 바로 낫는다」「타미플루보다 무조건 세다」로 단정하지 말 것. **쓸지 말지는 의사**.

## 2. 타미플루와 비교 (대략)

구매·시술 권유가 아니다.

| | [[타미플루]] (오셀타미비르) | **페라미플루** (페라미비르) |
|--|------------------------------|------------------------------|
| 형태 | **먹는** 캡슐·현탁 | **주사**(점적) |
| 어디서 | 처방 후 약국·복용 | **의료기관**에서 투여 |
| 계열 | 뉴라미니다제 억제제 | 같음 |
| 흔한 이야기 | 외래에서 처방이 많음 | 구토·의식·입원이거나 **먹는 약이 어려울 때** 이야기가 나옴 |
| 백신 | 아님 | 아님 |

흡입 약(자나미비르)·다른 먹는 약(발록사비르)도 있다. 표는 [[타미플루]] §2.

같은 계열이라도 **제형·콩팥 조절·나이 하한**이 상품마다 다르다. 검색 mg를 가져오지 말 것.

## 3. 언제 이야기가 나오나

허가 문구에는 **증상 초기에 투여를 시작한다**는 식이 흔하다. 「몇 시간까지 유효」는 **그 제품 설명서·의사**다. 이 글이 시계를 대신하지 않는다.

| 상황 | 방향 |
|------|------|
| **치료** | 인플루엔자 A 또는 B (허가 범위는 제품·연령이 다름) |
| **예방 주사** | 이 약은 **치료제**. 매년 맞는 독감 백신과 다름 → [[A형 독감]] §5 |
| **유행주의보 급여** | 항바이러스 **먹는 약** 급여 안내와 **주사 급여 기준이 다를 수** 있음. 심평원·병원 원무가 우선 |
| **가격** | 비급여면 병원마다 금액이 크게 갈린다는 이야기가 많음. **숫자로 고정하지 않음** → [[나만의닥터]]는 독감 주사 가격의 공식 창구가 아님 |

콩팥 기능이 떨어지면 **용량을 조절**하는 안내가 있다. 숫자만 보고 요구하지 말 것.

---

## 4. 이상 반응 · 아이 관찰

식약처는 독감 치료제 전반에 대해, 주로 소아·청소년에서 **경련·섬망·이상행동** 보고가 있고 인과는 미확정이지만, 보호자는 **적어도 이틀간 혼자 두지 말고** 보라는 안내를 낸 바 있다. 상세는 [[타미플루]] §5.

주사 쪽이므로 **넣는 자리 통증·발진·알레르기**도 본다. 숨참·온몸 두드러기·혈압이 떨어지면 투여 중인 **의료진·119**.

설사 등 장 증상, 드물게 혈액·피부 중증 반응 보고가 허가에 있는 제품이 있다. **설명서·의사**.

이상 반응이 있으면 임의로 「한 대 더」를 요구하지 말고 투여한 기관에 알린다.

## 5. 하지 말 것

| 하지 말 것 | 이유 |
|------------|------|
| 집에서 바이알을 꽂기 | 점적·희석·프리믹스는 **의료 행위** |
| 「타미플루 대신 무조건 주사」 요구 | 적응·급여·위험이 **사람마다** 다름 |
| 검색한 **mg·분**대로 맞혀 달라고 우기기 | 나이·체중·콩팥·제형(바이알 vs 프리믹스)이 다름 |
| 예방접종 대신 이 주사 | 축이 다름 |
| 감기·코로나만으로 단정 | 검사·진찰. [[A형 독감]] |

실비는 급여·비급여·특약에 따름 → [[실손보험]].

## 면책

> **강한 면책**
> - **처방·투여법·급여·비급여 가격을 대체하지 않는다.**
> - 용량·점적 시간·연령 하한·콩팥 조절은 **제품 허가사항·의사**가 우선이다. 상품명마다 다를 수 있다.
> - 이상행동·피부·호흡 문제는 약일 수도 독감 합병증일 수도 있다. **의료진**.
> - 항바이러스 주사 급여는 **심평원 기준·절기**가 바뀐다.
> - 호흡 곤란·의식 변화·소아 경련은 **119**.
