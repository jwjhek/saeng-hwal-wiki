# 역류성 위염

> **분류:** 생활·건강 · [[생활위키 목차]]

**역류성 위염**은 **위산이 식도(입과 위를 잇는 관)** 로 **역류**하면서 식도 점막에 **염증**이 생긴 상태를 말하는 경우가 많다. 
넓게는 **위식도역류질환**(GERD) — 속쓰림·신물 역류 등 **증상**이 있는 질환 — 안에서 **내시경·병리**로 확인되는 **식도염** 쪽에 가깝다.

이 글은 **개념·생활 관리**만 정리한다. **약·용량·검사는 담당 의사**가 정한다.

확인일: 2026-08-13

관련: [[장상피화생]] · [[다이어트]] · [[요리]] · [[불면증]] · [[나만의닥터]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 위 내용물(위산 등)이 **식도로 올라와** 식도 점막을 **자극·염증** |
| **흔한 느낌** | **속쓰림**(가슴뼈 뒤 타는 느낌), **신물·쓴맛 역류**, 더부룩함 |
| **진단** | 증상 + (필요 시) **위·식도 내시경** · 산도 검사 등 |
| **[[장상피화생]]과** | **다른 부위·다른 병리** — 위 점막 변화 vs **식도** 염증. **같이** 있을 수 있음 |

```text
하부 식도 괄약근 약화·복압 ↑·위산 과다 등
 ↓
위 내용물이 식도로 역류
 ↓
속쓰림·역류 (증상) / 식도염 (내시경 소견)
 ↓
생활습관 + (필요 시) 약물 · 추적
```

**가끔 속쓰림**과 **만성 역류성 식도염**은 다를 수 있다 — **자주·심하면** 진료.

---

## 2. 원인·위험 요인

| 요인 | 설명 |
|------|------|
| **과체중·복부 비만** | 복압↑ — 생활습관 교정 중 **근거가 비교적 분명한** 항목 |
| **과식·야식** | 위가 차면 역류 쉬움 |
| **식후 바로 눕기** | 중력 도움 없음 — **취침 2~3시간 전** 식사 줄이기 권고되는 경우 많음 |
| **기름진·자극적 음식** | 개인마다 다름 — **본인에게 맞는** 회피 |
| **카페인·탄산·술·담배** | 괄약근·위산에 영향 — **금연·절주** 권고 |
| **임신** | 호르몬·복압 — 산후 호전되는 경우 많음 |
| **특정 약** | 진통제·일부 혈압약 등 — **복용 중이면** 의사·약사에 **역류 악화** 여부 문의 |
| **헬리코박터·만성 위염** | 위 쪽 질환과 **겹칠 수 있음** → [[장상피화생]] |

---

## 3. 증상

### 3.1 흔한 증상

| 증상 | 설명 |
|------|------|
| **속쓰림** | 가슴뼈 **뒤** 타는 느낌 — 식후·누울 때 심해지기 쉬움 |
| **역류** | 신맛·쓴맛이 **목·입**으로 올라옴 |
| **더부룩함·명치 불편** | 위·식도 경계 쪽 |
| **삼킴 불편** | 오래되면 식도 협착 등 **합병증** 의심 — **진료** |

### 3.2 덜 흔하지만 연관되는 증상

| 증상 | 설명 |
|------|------|
| **만성 기침·천명** | 야간 기침 — 역류성 **호흡기** 증상으로 갈 수 있음 |
| **쉰 목소리·인후 이물감** | 아침에 심한 경우 |
| **흉통** | **심장질환과 구분 필요** — 처음·심한 흉통은 **응급** |

---

## 4. 진단

| 방법 | 설명 |
|------|------|
| **진료·문진** | 증상 빈도·야간·체중·약 복용 |
| **위·식도 내시경** | **식도염**·미란·바렛 식도 등 확인 — [[장상피화생]]은 **위** 조직검사 |
| **24시간 산도 검사** 등 | 약에 안 낫거나 수술 전 **역류 정량** — 전문 진료 |

**내시경 소견**에 「역류성 식도염」「LA grade」 등이 적힐 수 있다 — **등급·치료**는 의사 설명을 따른다.

---

## 5. 생활습관 (기본)

가이드라인마다 표현은 다르지만, **자주 나오는 것**:

| 권장 | 설명 |
|------|------|
| **체중 감량** | 과체중이면 — [[다이어트]]와 연결 (급격 굶기 X) |
| **취침 전 식사 줄이기** | 눕기 **2~3시간 전**까지 식사 마무리 권고되는 경우 많음 |
| **상체 올려 자기** | 야간 증상 — **머리 쪽** 침대 높이기(베개만으론 부족할 수 있음) |
| **왼쪽으로 눕기** | 일부에서 역류 감소 보고 — 개인차 |
| **과식·야식 줄이기** | [[배달 앱]] **자극적·기름진** 야식 반복은 피하기 쉬움 |
| **금연·절주** | |
| **꽉 끼는 옷·허리 조이기** 줄이기 | 복압↑ |
| **천천히 씹기** | 과식·공기 삼킴 줄이기 |

**모든 음식을 일괄 금지**하기보다, **내가 먹으면 악화되는 것**을 메모해 줄이는 **개인화**가 권고되는 편이다.

## 6. 식단 — 자주 거론되는 것

| 줄이거나 피하기 쉬운 것 | 이유(개요) |
|-------------------------|------------|
| **기름진·튀긴·인스턴트** | 위 비우기 지연·복압 |
| **매운·자극적** | 개인 민감 |
| **카페인**(커피·홍차·에너지음료) | 괄약근·위산 |
| **탄산·사이다** | 복부 팽만 |
| **술** | |
| **초콜릿·민트**(박하) | 일부 가이드에서 회피 권고 |
| **과산성 과일·주스**(오렌지 등) | 산 자극 — **민감한 사람만** |
| 늦은 [[라면 스프 보쌈]]·짠 국물 | 과식·나트륨·눕기와 겹치기 쉬움 |

[[방울토마토]]·토마토 소스 등 **산 있는 채소**는 **역류 민감**한 사람만 조절 — 전원 금지는 아님.

---

## 7. 약물 (개념만)

| 종류 | 역할 (개요) |
|------|-------------|
| **제산제** | 위산 **일시 중화** — 가벼운 증상·응급 완화 |
| **H2 차단제** | 위산 분비 **억제**(중등도) |
| **양성자 펌프 억제제(PPI)** | 위산 분비 **강하게 억제** — 식도염 치유에 흔히 씀 |
| **P-CAB 등** | 최근 위산 억제제 계열 — **처방·기간**은 의사 |

- **OTC·인터넷 장기 복용**은 **부작용·골밀도·장내균** 등 이슈 — **의사와 기간** 정하기  
- [[항히스타민]] **1세대**는 졸음·구강건조, **2세대**는 위와 **다른 약** — 혼동 주의  

증상이 **수 주 이상** 지속·삼키기 어려움·체중 감소·흑변·토혈 등 **경고 신호**는 **바로 진료**.

## 8. [[장상피화생]]·[[다이어트]]와

| | 역류성 위염 | [[장상피화생]] |
|--|-------------|----------------|
| **주요 부위** | **식도** | **위** 점막 |
| **내시경** | 식도염·미란 등 | 위 조직 **병리** |
| **생활** | 식후 자세·체중·자극 음식 | 저염·제균·위암 **추적** |
| **겹침** | 만성 위염·비만 환자에서 **둘 다** 있을 수 있음 |

[[다이어트]]로 **체중을 줄이면** 역류 증상 완화에 도움이 되는 경우가 있다 — **극단 단식**은 역류·위통을 **악화**시킬 수 있음.

---

## 9. 수술·추적

| 상황 | 설명 |
|------|------|
| **약·생활습관으로 호전** | 유지 요법·필요 시만 복용 등 **개인별** |
| **약에 안 낫거나 합병증** | 식도 협착·바렛 식도 등 — **전문 병원** |
| **장기 약 부담** | 수술(예: 위바닥 주름술 등) 논의 — **소화기 외과** |

---

## 10. 응급에 가까운 신호

- **처음 오는·심한 흉통** — 심장질환 배제  
- **토혈·검은 변·피 섞인 토**  
- **삼키기 곤란·체중 급감**  
- **구토로 탈수**  

---

## 11. 진료 때 물어볼 것

- 내시경 **식도염 등급**·치료 기간  
- **PPI** 등 복용 **기간·부작용**  
- **헬리코박터**·[[장상피화생]] 동반 여부  
- 복용 중 **진통제·혈압약** 조정 가능 여부  
- **야식·체중** 목표  

예약: [[나만의닥터]] — 내시경은 **대면·검진 센터** 경로가 일반적.

---

## 면책

> **강한 면책**
> - **진단·처방·약물 선택을 대체하지 않는다.** 흉통은 **심장·식도** 감별이 필요할 수 있다.
> - 음식 회피 목록은 **사람마다** 다르다. 인터넷 「이것만 먹으면 완치」는 **과장**인 경우가 많다.
> - 임신·소아·노약자는 **전문 진료** 우선.
