# 결핵

> **분류:** 생활·건강 · [[생활위키 목차]]

**결핵**은 **결핵균**(Mycobacterium tuberculosis 등)이 주로 **폐**에서 증식하며 염증을 만드는 감염병이다. 뼈·림프절·뇌막 등 **폐 밖**에도 생긴다.

전염성 있는 폐결핵 환자가 **기침·말**을 할 때 공기 중으로 나온 균을 **숨쉴 때** 들이마시면 감염될 수 있다. **식기·옷·침구를 같이 쓴다고 옮는 병은 아니다.**

**2주 이상 기침·가래**가 가면 감기약만 반복하지 말고 **보건소나 병의원에서 결핵 검사**를 본다. 대량 객혈·심한 숨참은 **119**.

이 글은 **개념·전염 구분·검진 시점**만 정리한다. 약 조합·기간·격리 해제는 **호흡기내과·보건소**가 정한다.

확인일: 2026-08-14  
참고: [질병관리청 결핵ZERO](https://tbzero.kdca.go.kr) · 국가결핵관리지침(연도 개정) · 보건소 안내

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 결핵균 감염 후 **발병**한 상태. 감염만 되고 잠자는 경우([[#2. 잠복결핵과 활동성]])도 많음 |
| **전염** | **공기**. 전염성 폐결핵의 기침·대화. 잠복결핵은 **전염 없음** |
| **흔한 증상** | 2주 이상 **기침·가래**, 미열, 밤에 식은땀, 피로, 식욕·[[다이어트]]와 무관한 **체중 감소**, 흉통, **객혈** |
| **초기** | 증상이 **거의 없을 수** 있음 |
| **치료** | 여러 약을 **수개월** 함께. 중간에 끊으면 **내성·재발** |
| **국내** | 환자 수는 줄어 왔지만, OECD 안에서는 **발생이 높은 편**으로 자주 언급됨 |

```text
전염성 환자의 기침 → 공기 중 균
 ↓
숨쉴 때 폐로 들어옴 (감염)
 ↓
대부분은 잠복 / 일부는 발병(활동성 결핵)
 ↓
검진 · (활동성이면) 다제 치료 · 접촉자 검사
```

「만성 기침 = 결핵」「BCG 맞았으니 안 걸린다」로 단정하지 말 것.

---

## 2. 잠복결핵과 활동성

감염되었다고 **모두 병이 되는 것은 아니다.**

| | **잠복결핵감염** | **활동성 결핵** |
|--|------------------|-----------------|
| 증상 | 없음 | 기침·열·체중 감소 등 (없을 수도) |
| 전염 | **없음** | 폐·기도가 열려 균이 나오면 **있음** |
| 영상·가래 | 활동 병변이 없음 | 엑스레이·가래에서 병변·균이 나올 수 있음 |
| 치료 | **권고**(발병 예방). 수개월 | **끝까지**. 흔히 **6개월 전후**(약제·병형에 따라 다름) |
| 신고 | 해당 없음에 가깝 | 의료기관 **법적 신고** (감염병·결핵예방법) |

잠복이 나중에 발병하기 쉬운 때: **면역 저하**(당뇨, 스테로이드·일부 면역약, HIV, 투석, 영양 불량, 고령 등). 숫자는 개인마다 다르다.

---

## 3. 어떻게 전염되나

| 되는 편 | 안 되는 편 |
|---------|------------|
| 좁은 실내에서 **오래** 같이 숨쉬기 | 식기·컵·옷·악수만 |
| 전염성 환자의 **기침**이 닫힌 공간에 맴돎 | 잠복결핵인 사람과 같이 지내기 |
| 치료 전·균이 많이 나오는 시기 | 의사가 **전염력 없음**으로 본 뒤 (가래·치료 반응) |

폐 밖 결핵(림프절 등)은 **공기 전염이 약한** 경우가 많다. 구분은 **진료**.

마스크·환기·기침 예절(휴지·소매로 입 가리기)은 호흡기 감염 **공통** 예방이다.

---

## 4. 증상 · 검사 받을 때

하나라도 **2주 이상** 가면 검사를 고려한다. 결핵만의 증상은 아니다.

| 증상 | 설명 |
|------|------|
| **기침·가래** | 감기약에 안 나음 |
| **객혈** | 가래에 피. 양이 많으면 **응급** |
| **열·식은땀** | 오후 미열, 잘 때 땀 |
| **체중·기력** | 의도하지 않은 감소·피로 ([[위고비]]·절식과 혼동하지 말 것) |
| **가슴** | 통증, 숨참 |

**바로 보는 때**

- 결핵 환자와 **같이 산 가족·동거인** (증상 없어도)  
- 역학조사 대상이라는 연락을 받은 경우  
- 65세 이상에서 국가·지자체가 안내하는 **정기 검진**  
- 집단시설·의료 종사자 등 **지침상 검진 대상** (해마다 바뀜 → 보건소)

대량 객혈, 숨이 안 참, 고열·탈수는 **119·응급실**.

---

## 5. 병원에서 흔히 하는 것

| 검사          | 설명                                                  |
| ----------- | --------------------------------------------------- |
| **가슴 엑스레이** | 병변 유무. 잠복만이면 정상인 집이 많음                              |
| **가래**      | 도말·배양·핵산증폭. **확진·전염력**에 중요                          |
| **잠복 검사**   | 피부반응(투베르쿨린) 또는 피검사(인터페론). BCG·다른 균과 **해석이 다름** — 의사 |
| **약제 감수성**  | 어떤 약이 듣는가. 내성이면 처방이 **완전히 달라짐**                     |

치료(감수성 폐결핵의 **전형**, 처방이 아님):

- 여러 항결핵제를 **같이** 시작 (한 가지만 쓰면 내성이 생기기 쉬움)  
- 흔히 **약 6개월**. 공동이 있거나 2개월 뒤 배양이 양성이면 **늘리기도**  
- 복용 시작 후 **대략 2주**가 지나면 전염력이 크게 떨어진다는 설명이 흔함. **출근·등교 시점은 보건소·의사가 가래 결과로** 정함  
- 약 부작용: 간, 시력(일부 약), 소변·눈물 색 변화 등 — **임의 중단하지 말고** 알린다  

**다제내성**(이소니아지드+리팜핀 등에 안 들음)은 기간·약이 다르고 **전문 기관**이 맡는다. 이 글이 조합을 적지 않는다.

잠복 치료는 지침에서 **리팜핀이 들어간 단기 요법**을 우선 권고하는 추세다. 간 독성·상호작용은 의사와.

---

## 6. BCG · 「이미 면역」

한국에서 어릴 때 **BCG**를 맞는 집이 많다.  
아이 **중증 결핵**(수막염 등)을 줄이는 쪽으로 설명되며, **성인 폐결핵을 완전히 막지 못한다.**

흉터·접종 기록만으로 잠복 검사 결과를 해석하지 않는다.

## 7. 국가 관리 · 비용

| 항목 | 설명 |
|------|------|
| **보건소** | 의심 증상·접촉자 **엑스레이·가래·잠복 검사**를 안내·지원하는 경우가 많음 |
| **치료비** | 활동성·잠복 모두 **국가가 민간 의료 치료비를 지원**하는 사업이 있음. 비급여·전액 본인부담은 빠질 수 있음 — **그해 지침·병원** |
| [[실손보험]] | 국가 지원과 **겹침·청구**는 약관. 이 글이 보장 확인이 아님 |
| **신고·역학** | 활동성 환자는 의료기관이 신고. 가족 검진이 따라옴 |
| **약 순응** | 보건소가 복용을 돕는 프로그램이 있음. **혼자 끊지 말 것** |

안내 허브: [결핵ZERO](https://tbzero.kdca.go.kr). 예약 앱([[나만의닥터]])으로 **2주 기침을 미루지 말 것.** 보건소가 더 맞는 입구인 집이 많다.

이 글은 **법률 자문이 아니다.** 신고·취업·출국 제한은 법령·고시가 우선이다.

## 8. 일상에서

| 하면 도움 되기 쉬운 것               | 피하기 쉬운 것                 |
| --------------------------- | ------------------------ |
| 2주 기침 → **검사**              | 「결핵은 옛날 병」               |
| 기침 예절·실내 환기                 | 전염성 기간에 **마스크 없이** 밀집    |
| 약은 **같은 시각**에, 빠지면 의사 규칙    | 부작용이 무서워 **임의 중단** (내성)  |
| 접촉자면 안내받은 **잠복 검사**         | 식기를 소독하느라 검사를 미룸         |
| 당뇨·면역약은 주치의에게 **결핵 병력**을 알림 | 체중 감소를 [[다이어트]] 성공으로만 보기 |
|                             |                          |

영양이 나쁘면 발병 위험이 올라간다는 설명이 있다. 극단 절식은 결핵과 무관해도 해롭다.

## 9. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 결핵균에 의한 감염병. 폐가 흔하고 **공기로** 옮을 수 있음 |
| 잠복 | 균은 있으나 병·전염 없음. 나중에 발병 가능 |
| 의심 | **2주 이상 기침** · 접촉자 · 원인 없는 체중 감소 |
| 치료 | 여러 약 **수개월**. 끊으면 내성 |
| 창구 | **보건소** · 호흡기내과 · [결핵ZERO](https://tbzero.kdca.go.kr) |

## 면책

> **강한 면책**
> - **진단·약 처방·격리 해제·취업 가능 여부를 대체하지 않는다.**
> - 기침은 **감기·천식·역류·암** 등과 겹친다. 구분은 **의료**.
> - 항결핵제는 **간·시력·상호작용**이 있다. 임의 시작·중단·남 약 금지.
> - 지원 범위·검진 대상·치료 기간은 **연도·지침**이 바뀐다. 질병관리청·보건소가 우선.
> - 대량 객혈·호흡 곤란은 **119**.
