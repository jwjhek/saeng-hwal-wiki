# A형 독감

> **분류:** 생활·건강 · [[생활위키 목차]]

**A형 독감**은 일상에서 **인플루엔자 A형 바이러스** 감염을 가리키는 말이다. 고열·근육통과 기침이 **갑자기** 오는 급성 호흡기 병이다. 코 감기와 같은 병이 아니다.

숨이 **심하게** 차거나, 입술·손톱이 푸르거나, 의식이 흐리거나, 아이가 경련을 하면 **119**. 질병 안내는 질병관리청 콜센터 **1339**.

이 글은 **개념·감기와 구분·진료 시점**만 정리한다. 검사·약·등교·출근 가능 시점은 **병의원**이 정한다.

확인일: 2026-08-14  
참고: [질병관리청 인플루엔자](https://kdca.go.kr/kdca/3495/subview.do) · [예방접종도우미](https://nip.kdca.go.kr)

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 인플루엔자 바이러스. 사람에서 흔한 계절 유행은 **A형**(H1N1, H3N2 등)과 **B형** |
| **검사에서 「A형」** | 신속항원·PCR 등에서 **A가 나옴**. B형·감기바이러스·코로나19와 구분은 **검사·의사** |
| **잠복** | 대개 **1~4일**(평균 2일 전후, 질병관리청) |
| **전염** | **비말**(기침·재채기·가까운 대화). 증상 **하루 전**부터 발병 후 **5~7일** 전후. 소아·면역 저하는 **더 길 수** 있음 |
| **증상** | **38~40도** 고열, 마른기침, 목아픔, 두통, **온몸 근육통**, 심한 피로. 콧물·눈 통증·아이에서 구토·설사가 겹치기도 함 |
| **치료** | 휴식·수분 등 대증. 항바이러스([[타미플루]]·[[페라미플루]] 등)는 **처방**. 항생제는 바이러스 독감 자체가 대상이 아님 |

```text
비말로 바이러스 흡입
 ↓
1~4일 잠복
 ↓
갑자기 고열·근육통·기침
 ↓
대부분 수일~1~2주 호전 / 일부는 폐렴 등 합병증
```

「독감 주사 맞아서 독감에 걸렸다」는 말로 접종을 단정하지 말 것. 불활성화 백신은 **살아있는 계절 독감 바이러스를 넣지 않는** 종류가 흔하다. 이상 반응은 **접종 기관·의사**.

## 2. A형 · B형 · 감기 · 다른 병

| | **A형 독감** | **B형** | **감기**(여러 바이러스) |
|--|--------------|---------|-------------------------|
| 시작 | **갑자기** 고열·전신통 | 비슷 | 서서히, 열이 없거나 낮음 |
| 유행 | 사람·동물 숙주. **대유행** 이야기가 나올 수 있음 | 주로 사람 | 연중 |
| 백신 | 계절 백신에 A 주가 **들어감** | 절기 백신 조성에 따름 | 없음(원인 바이러스가 많음) |

신속키트에서 A만 나와도 **중증도는 사람마다** 다르다. B형이라고 가볍다고 단정하지 말 것.

| 겹치는 말 | 구분 |
|-----------|------|
| **코로나19** | 증상만으로 가르기 어렵다. 필요하면 **각각 검사** |
| **2주 이상 기침**만 남음 | 독감 후유 기침일 수도, [[결핵]]·천식·[[역류성 위염]]일 수도. **늘어지면 진료** |
| **가금류 조류인플루엔자** 뉴스 | 철새·농장 **방역** 이야기. 겨울 유행 **H1·H3 계절 독감**과 **같은 사건이 아님**. 사람 감염은 드물고 대응은 당국 |

의사환자(ILI) 감시 정의 예: **38도 이상 발열** + 기침 또는 인후통. 유행주의보 숫자는 **절기마다** 바뀐다.

## 3. 전염 · 쉴 때

| 되는 편 | 줄이는 편 |
|---------|-----------|
| 닫힌 실내에서 기침이 가까운 얼굴로 | **손 씻기**, 씻지 않은 손으로 눈·코·입 안 만지기 |
| 증상 있을 때 출근·등교·밀집 장소 | **기침 예절**(소매·티슈), 가능하면 **집에서 휴식** |
| 같은 컵을 바로 쓰는 것보다는 **비말·손**이 중심 | 마스크는 유행기·증상 있을 때 주변 배려로 쓰이는 경우가 많음 |

전염 기간은 개인·나이·면역이 다르다. **며칠이면 된다**고 직장에 단정하지 말고, 고열·숨참이 있으면 쉬는 쪽을 본다.

## 4. 언제 병의원 · 언제 119

| 창구 | 예 |
|------|-----|
| **병의원·보건소** | 고열과 근육통이 갑자기, 고위험(고령, 임산부, 만성 폐·심장·당뇨, 면역 저하, 어린 아이), 증상이 낫지 않음 |
| **검사** | 신속항원 또는 유전자 검사. 음성인데 중증이면 **재검·다른 원인** |
| **119** | 숨이 심하게 참, 가슴 통증([[협심증]] 가능), 입술이 푸름, 깨우기 힘듦, 소아 경련·처짐, 물을 못 마심 |

고위험군은 **유행주의보 기간**에 의심 증상만으로 항바이러스 급여가 안내된 절기가 있다. **그해 공지·의사**가 우선이다. 남 약·인터넷 구매는 금지에 가깝다 → [[타미플루]].

아이 독감 의심 때 **아스피린 계열을 임의로 주지 않는다**(라이증후군 논의). 해열제는 **의사·약사**.

감기약·종합감기약에 [[항히스타민]]이 이미 들어 있는지 **중복**을 본다.

## 5. 예방접종

매년 **그 절기 백신**을 맞는다. 바이러스가 조금씩 바뀌기 때문이다.

| 항목 | 메모 |
|------|------|
| **국가 지원** | 어린이(생후 6개월~연령 상한), **임신부**, **65세 이상** 등이 무료인 절기가 많음. **출생 연도·기간은 그해 사업** |
| **어디서** | 위탁 병의원·보건소. [예방접종도우미](https://nip.kdca.go.kr) · 보건소. 가격 비교 앱은 [[나만의닥터]] |
| **3가·4가** | 조성은 WHO·국내 위원회가 절기마다 정함. 2025-2026 국가사업은 **3가**로 안내된 바 있음 |
| **금기·주의** | 이전 접종 중증 알레르기, 계란 **아나필락시스** 등. **세포배양 백신** 논의는 의사. 음식 글 [[계란]]과 **별개** |
| **코로나 백신** | 같은 날 다른 부위에 맞는 안내가 나온 적 있음. **그날 의료진** |

접종해도 **안 걸리라는 보장은 없다.** 중증·입원을 줄이려는 쪽에 가깝다.

확인일(2026-08)은 2025-2026 절기 접종이 끝난 뒤·다음 절기 직전이다. **9월 전후 새 공지**를 본다.

## 6. 집에서 (진료 전제)

의사가 집에서 쉬라고 한 경우의 **방향**만.

| 함 | 하지 말 것 |
|----|------------|
| 휴식, 수분, 처방·안내된 해열 | 항생제 임의, 남 [[타미플루]], 음주 |
| 창문을 가끔 열기 | 숨이 찬데 참기 |
| 가족은 손 씻기·식기 구분 | 「독감 = 결핵」처럼 공기 결핵과 같은 격리를 혼자 설계하기. 결핵 의심은 [[결핵]] |

폐렴·심근염·뇌염은 **드물지만** 있다. 흉통·숨참·심한 두통·목 뻣뻣함은 재진료·119.

실비는 약제·입원 특약에 따라 다르다 → [[실손보험]] · [[보험 기초]].

## 면책

> **강한 면책**
> - **진단·처방·등교·출근·격리 해제를 대체하지 않는다.**
> - 고열·기침은 **감기·코로나19·폐렴·결핵** 등과 겹친다. 구분은 **의료**.
> - 항바이러스·해열제·백신 종류·급여는 **절기·연령·기저질환**마다 다르다. 질병관리청·의사·약사가 우선.
> - 국가예방접종 대상·기간·3가/4가는 **매년 바뀐다.** 이 글의 절기 예는 참고일 뿐이다.
> - 호흡 곤란·의식 변화·소아 경련은 **119**. 일반 안내는 **1339**.
