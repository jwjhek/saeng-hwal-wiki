# 뇌졸중

> **분류:** 생활·건강 · [[생활위키 목차]]

**뇌졸중**은 뇌에 피를 보내는 **혈관이 막히거나 터져** 그 부위 뇌가 손상되고, **갑자기** 마비·말·시야·균형·두통 같은 신경 증상이 생기는 병이다.  
예전에 **중풍**이라고 부르던 말과 겹친다. 흔히 적는 **뇌졸증**은 같은 뜻을 가리키는 **틀린 표기**에 가깝다.

한쪽 얼굴·팔·말이 **갑자기** 이상하면 **119**. 가족이 올 때까지, 외래·비대면 진료까지 **기다리지 않는다.**

이 글은 **개념·응급 징후·예방 방향**만 정리한다. 진단·약·시술·재활 처방은 **응급실·신경과·신경외과**가 한다.

확인일: 2026-08-14  
참고: [질병관리청 국가건강정보포털](https://health.kdca.go.kr) · 심뇌혈관 9대 생활수칙 · 대한뇌졸중학회 홍보(이웃손발시선)

관련: [[다이어트]] · [[오메가3]] · [[우울장애]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 뇌혈관이 **막힘(뇌경색)** 또는 **터짐(뇌출혈)** → 그 뇌 영역 기능 저하 |
| **특징** | 증상이 **갑자기**. 「어제부터 조금씩」보다 **지금 당장**이 전형 |
| **왜 급하나** | 뇌세포는 혈류가 끊기면 **수 분~수 시간** 안에 되돌리기 어려운 손상이 올 수 있음 |
| **진단** | 증상 + 진찰 + **CT·MRI** 등. 집에서 이름 붙이지 않음 |
| **재발** | 한 번 있으면 **다시 올 수 있음**. 위험 요인·약 유지는 의사와 |

```text
혈관 막힘 또는 파열
 ↓
그 부위 뇌에 혈류·압박 문제
 ↓
갑자기 마비·말·시야·균형·두통 등
 ↓
119 → 급성기 치료가 가능한 병원
```

「손발이 저리다 = 뇌졸중」「피곤해서 발음이 흐리다」로 **혼자 결론 내지 말 것.** 반대로 **조금 나아졌다고 집에 있지 말 것.**

---

## 2. 종류

현장에서 치료·약이 **반대 방향**일 수 있다. 출혈인지 경색인지는 **영상**으로 가른다.

| 종류 | 무슨 일 | 자주 이야기되는 원인 |
|------|---------|----------------------|
| **뇌경색** (허혈) | 혈관이 **피떡(혈전)** 등으로 막힘. 국내 뇌졸중의 **다수** | 동맥경화, 목·머리 큰 혈관, **심방세동** 등 심장에서 혈전이 떠내려옴, 작은 혈관(열공) |
| **뇌내출혈** | 뇌 **안**에서 혈관이 터져 피가 고임 | **오래된 고혈압**이 흔함. 혈관 기형 등 |
| **거미막밑출혈** (지주막하출혈) | 뇌를 감싼 막 아래에 피. **동맥류(꽈리)** 파열이 전형 | 갑자기 **평생 처음인 극심한 두통**·구토 |

**일과성 허혈 발작(TIA):** 증상이 수 분~수 시간 만에 **완전히 좋아진** 것처럼 보여도, 곧이어 본 뇌졸중이 올 수 있는 **경고**다. 나아졌다고 안심하지 말고 **바로 진료.**

---

## 3. 갑자기 이런 증상

하나라도 **갑자기** 있으면 119. 질병관리청이 알리는 조기 증상 축:

| 증상 | 예 |
|------|-----|
| **한쪽 힘** | 얼굴·팔·다리가 빠지거나 저리고 무딤. 특히 **한쪽** |
| **말** | 발음이 어눌, 말이 안 나옴, **상대 말을 못 알아들음** |
| **눈** | 한쪽이 안 보임, 시야 반이 빔, **물체가 두 개** |
| **균형** | 어지러움, 중심을 못 잡음, 한쪽으로 쏠림 |
| **두통** | 지금까지 없던 **심한 두통** |

대한뇌졸중학회 등에서 쓰는 기억법 **이웃손발시선** (캠페인 문구는 시점마다 조금 다를 수 있음):

| 글자 | 확인 |
|------|------|
| **이·웃** | 「이~」 하며 **웃을 때** 입꼬리가 한쪽만 |
| **손** | 두 팔을 앞으로 들었을 때 **한쪽이 떨어짐** |
| **발** | **발음**이 어눌하거나 말이 안 됨 |
| **시선** | 눈이 **한쪽으로 쏠림** |

미국 FAST(얼굴·팔·말·시간)와 같은 취지다. **자가 진단 점수가 아니라, 하나라도 있으면 시간을 쓰지 말라는 뜻.**

---

## 4. 그때 할 일 · 하지 말 일

질병관리청 대응 요령과 같은 방향이다.

| 한다 | 하지 않는다 |
|------|----------------|
| **바로 119** | 증상이 지나갈 거라 생각하기 |
| 급성기 치료가 되는 병원으로 **구급차** | 환자 **본인이 운전** |
| 증상 **시작 시각**을 기억·전달 (마지막 정상 시각) | 가족·지인이 올 때까지 대기 |
| 의식이 흐리면 **옆으로 눕히고** 기도 확인 (구조 지침) | 야간·주말이라 **내일 외래** |
| | 물·밥·약을 **억지로** (삼킴이 안 되면 사레) |
| | 출혈인지 모르는 채 **아스피린·한약**을 임의로 |
| | [[나만의닥터]] 같은 **비대면**으로 시간 보내기 |

정맥 혈전용해는 증상 후 **약 4.5시간** 안에 도착해야 논의되는 경우가 많다. 큰 혈관 막힘은 **혈전 제거술**이 더 늦은 시간까지 가능한 집도 있다. **시계를 세며 집에서 계산하지 말고** 일단 간다.

인증 병원 목록 예: [대한뇌졸중학회 뇌졸중센터](https://www.stroke.or.kr/hospital/) — 구급대가 가까운 가능 병원을 아는 경우가 많다.

---

## 5. 병원에서 흔히 하는 것

인터넷 순서표가 처방이 아니다.

| 단계 | 설명 |
|------|------|
| **CT** | 빠르다. **출혈을 가리는** 데 특히 씀. 경색은 초기에 안 보일 수 있음 |
| **MRI** | 이른·작은 경색을 더 잘 보기도. 시간·금기(금속 등)가 있음 |
| **혈관·심장** | CT/MR 혈관, 초음파, 심전도·심장초음파. **심방세동**을 찾기도 |
| **뇌경색 급성** | 조건이 되면 **혈전용해제(정맥)**, 큰 혈관이면 **혈전 제거술**. 이후 항혈소판·항응고 등은 **원인·출혈 여부**에 따라 의사 |
| **뇌출혈 급성** | 혈압·뇌압 조절. 일부는 수술. 동맥류는 **재출혈 전** 시술·수술이 논의됨 |
| **병실** | 가능하면 **뇌졸중 집중 치료**. 삼킴·폐렴·혈당·체온도 봄 |
| **재활** | 급성기 안정 후 **이른 재활**이 권장되는 편. 시점은 전문의 |

아스피린 등은 **경색**에서 쓰이기도 하지만, **출혈이면 해가 된다.** 집에서 먼저 먹지 않는다.

## 6. 위험 요인

바꿀 수 없는 것: **나이**, 이전 뇌졸중·TIA, 일부 가족력.  
바꿀 수 있는 것(문헌에서 자주 거론):

| 요인 | 메모 |
|------|------|
| **고혈압** | 경색·출혈 **모두**에서 가장 흔히 꼽힘 |
| **당뇨·이상지질혈증** | 동맥경화 |
| **흡연** | 본인·간접. 전자담배도 「안전」 근거가 부족하다는 안내가 있음 |
| **심방세동·심장** | 혈전이 뇌로. 항응고는 **처방** |
| **비만·허리둘레** | [[다이어트]] |
| **과음** | |
| **운동 부족** | 오래 앉아 있기 |
| **짜게 먹기** | |

「[[오메가3]]만 먹으면 예방」은 **과장**인 경우가 많다. 응급·처방약을 **보충제로 대체하지 않음.**

---

## 7. 예방 방향 (생활수칙)

질병관리청·관련 학회 **심뇌혈관 9대 생활수칙**의 뼈대다. **개인 목표 혈압·약 종류는 의사.**

1. 담배를 피우지 않는다.  
2. 술은 가급적 마시지 않는다.  
3. 짜지 않게, 통곡·채소·콩·생선을 포함해 **규칙적으로**.  
4. 매일 **30분 이상** 움직이고, 앉아 있는 시간을 줄인다. ([[다이어트]] 운동은 질환 있으면 처방 우선)  
5. 체중·허리둘레를 적정 범위로.  
6. 스트레스를 관리한다. ([[우울장애]]·수면과 겹치면 진료)  
7. **혈압·혈당·콜레스테롤** 숫자를 안다.  
8. 고혈압·당뇨·지질 이상은 **임의 중단하지 않고** 치료한다.  
9. 뇌졸중·심근경색 **응급 증상**을 알고, 그때 **119**.

이미 뇌졸중이 있으면 **이차 예방**(재발 방지 약·시술)이 급성기만큼 중요하다.

## 9. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 뇌혈관이 **막히거나 터져** 뇌가 손상되는 응급 병 |
| 표기 | **뇌졸중**. 뇌졸증은 흔히 쓰는 오자 |
| 핵심 증상 | 갑자기 **한쪽 힘·말·눈·균형·심한 두통** |
| 행동 | **119**. 직접 운전·대기·임의 아스피린 금지 |
| 예방 | 혈압·담배·당뇨·지질·체중 + 이미 있으면 **재발 방지 약** |

## 면책

> **강한 면책**
> - **진단·약·시술·재활 처방을 대체하지 않는다.**
> - 증상은 **편두통·저혈당·술·발작·목 디스크** 등과 겹칠 수 있다. 구분은 **의료**.
> - 의심되면 **119·응급실**. 이 글을 읽으며 시간을 쓰지 않는다.
> - 혈전용해·항혈소판·항응고·혈압 목표는 **영상·원인·금기**에 따라 다르다. 임의 복용·중단 금지.
> - 숫자(시간 창·사망률)는 **가이드·연도**가 바뀐다. 공신 자료·담당 의사가 우선.
