# 삐약

> **분류:** 생활·건강 · [[생활위키 목차]]

**삐약**은 국내 **GLP-1 계열 비만 치료 주사**(예: [[위고비]], [[마운자로]]) 사용자를 위한 **투약·체중 기록** 모바일 앱이다. 
주사 일정, 체중·식욕, **체내 약물 농도 추정 그래프**, 병원·약국 정보, 커뮤니티를 한곳에 모은다.

공식 사이트: [https://www.vvdhealth.com](https://www.vvdhealth.com)  
iOS·Android 앱 스토어에서 **삐약** 검색

확인일: 2026-08-11

---

## 1. 개요

| 항목       | 설명                                                   |
| -------- | ---------------------------------------------------- |
| 대상       | [[위고비]]·[[마운자로]] 등 **처방** 비만 주사를 쓰는 사람의 **자가 기록·정보** |
| 하는 일     | 주사·체중·부작용 기록, 농도 **추정** 그래프, 병원·약국, 후기·커뮤니티          |
| 하지 않는 일  | **진단·처방·용량 결정** (의료 행위 아님)                           |
| [[다이어트]] | 약은 **진료 전제**. 앱은 생활·투약 **일지**에 가깝다                   |

```text
[진료] 처방·용량·주기 ← 의사
 ↓
[삐약] 맞은 날·용량·체중·체감 기록
 ↓
[참고] 농도 추정 그래프·통계 (의료 결정 대체 아님)
```

---

## 2. 주요 기능

| 기능 | 내용 |
|------|------|
| **주사 기록** | 약 종류([[위고비]]·[[마운자로]] 등), 용량, 맞은 날·시간, 다음 주사 **알림** |
| **체중·식욕** | 체중 그래프, 식욕 억제 체감, 운동·식단 메모 |
| **부작용** | 구역·변비 등 **자가 기록** (진단 아님) |
| **약물 농도** | 반감기 모델 기반 **추정** 그래프 (§4) |
| **병원·약국** | 지역별 처방·조제 정보 (재고·가격은 변동). 가격·예약은 [[나만의닥터]] 등 별도 |
| **커뮤니티·후기** | 용량별 경험담, Q&A (개인 후기 ≠ 의학적 권고) |
| **콘텐츠** | 비만 치료 뉴스·관리 정보 (앱·블로그·영상 등) |

앱 메뉴·유료 기능·광고 여부는 **버전마다** 다르다. 설치 후 최신 **앱 안내**를 본다.

---

## 3. [[위고비]]·[[마운자로]] 주사 맞기 기록

주 1회(또는 처방) **피하 주사**를 맞을 때마다 앱에 남기는 흐름이 핵심이다.

| 기록 항목 | 쓰임 |
|-----------|------|
| 약 이름·단계 | 위고비·마운자로 등 **처방과 동일하게** 입력 |
| 용량(mg) | 펜 다이얼·처방 용량 |
| 투여일 | 간격·다음 알림 계산 |
| 주사 부위 | 교대 부위 메모 (개인 관리) |
| 체중·식욕 | 감량 속도·부작용과 **함께** 보면 패턴 파악에 도움 |

### 진료와 앱의 역할

| 구분 | 담당 |
|------|------|
| 용량 올리기·유지·중단 | **의사** (설명서·처방) |
| 맞은 사실·체감 정리 | **삐약** 등 기록 앱 |
| 용량을 앱 수치만 보고 바꾸기 | **하지 않음** |

[[다이어트]]의 단백질·근력·수면은 약과 **병행**하는 경우가 많다. 앱은 그 생활을 **적어 두는 도구**일 뿐이다.

---

## 4. 약물 농도 관리 (추정 그래프)

삐약이 내세우는 기능 중 하나가 **체내 약물 농도 추정 그래프**다.

### 무엇을 보여 주나

| 항목 | 설명 |
|------|------|
| 입력 | 기록한 **약 종류·용량·맞은 날·간격** |
| 계산 | 성분 **반감기** 등을 쓴 **수학적 모델** |
| 출력 | 시간에 따른 **추정 농도** 곡선, 다음 주사 전후 구간 |

GLP-1 주사는 한 번 맞으면 며칠에 걸쳐 흡수·감소한다. 그래서 “맞은 직후만 세고 끝”이 아니라 **누적·감소**를 그림으로 보여 준다.  
위고비(세마글루타이드)·마운자로(티르제파타이드)처럼 **약마다** 모델·반감기 가정이 다를 수 있다.

### 어떻게 쓰면 되나

| 적합 | 부적합 |
|------|--------|
| “이번 주 식욕이 약해진 느낌”과 **그래프 구간**을 **대조**해 본다 | 그래프 숫자만 보고 **용량을 스스로** 올리거나 줄인다 |
| 다음 주사 **전후** 체감 패턴을 **일지**로 남긴다 | 혈액검사·의료기기 결과처럼 **정확한 농도**로 믿는다 |
| 진료 때 **기록·그래프 캡처**를 보여 주며 상담 | 앱이 **효과 없음**을 진단했다고 받아들인다 |

앱·제작사도 **참고용 추정치**이며 개인차가 있다고 안내한다. **실제 혈중 농도·치료 결정**은 검사와 **의료진** 영역이다.

## 5. 위고비 나눠맞기 기능 (과거 · 현재)

### 나눠맞기란 (배경만)

일부 사용자 사이에서 **고용량 펜**을 여러 번에 나눠 쓰는 비공식 방식이 논의된 적이 있다.  
제조사 **허가·설명서 용법**은 보통 **펜당 정해진 1회 분량**을 주 1회 맞는 형태이며, 나눠맞기는 **공식 권장이 아니다**. 용량 오차·오염·효과 불균일 등 **위험**이 거론된다. 자세한 의학 논의는 [[위고비]]·진료를 본다.

### 삐약 앱에서의 변화

| 시기 | 앱 |
|------|-----|
| **과거** | 위고비 **나눠맞기 계산** 기능을 제공한 적이 있다. 처방 용량·나눌 횟수·다이얼 등을 넣어 **참고용** 숫자를 보여 주는 식이었다. |
| **현재 (2026-08 기준)** | **나눠맞기 기능은 지원하지 않는다.** 주사 기록·농도 추정 등 **허가 용법에 맞는 투약 기록** 중심으로 쓰면 된다. |

옛 블로그·스토어 설명·위키 글에는 나눠맞기 문구가 **남아 있을 수** 있다. **설치된 앱 메뉴**와 **업데이트 안내**를 기준으로 본다.

나눠맞기를 검색해 찾은 정보만으로 **투약 방식을 바꾸지 않는다.** 비용·용량 문제는 **병원·약국**에서 공식 경로로 상담한다.

## 6. 다른 기록과 비교

| | 삐약 | 일반 메모·달력 | [[갤럭시 워치 사용법]] 등 |
|--|------|----------------|---------------------------|
| GLP-1 특화 | **주사·농도·병원** 메뉴 | 직접 서식 짜야 함 | 체중·활동 위주 |
| 커뮤니티 | **후기·Q&A** | 없음 | 없음 |
| 농도 그래프 | **반감기 추정** | 없음 | 없음 |
| 개인정보 | 계정·커뮤니티 **서버** 가능 | 기기 로컬 | 삼성·Google 연동 |

손으로 적는 것만으로 충분하면 메모 앱도 된다. **위고비·마운자로를 오래** 쓰며 패턴을 보고 싶을 때 삐약을 쓰는 경우가 많다.

## 7. 사용 시 주의

| 주제 | 내용 |
|------|------|
| **처방** | 앱은 **의사 대체 아님**. 용량·약 변경은 진료 |
| **농도 그래프** | **추정치**·참고. 검사 결과 아님 |
| **커뮤니티** | 후기·댓글은 **개인 경험**. 따라 맞기·약 바꾸기 금지 |
| **병원·약국 정보** | 재고·가격·온누리 등은 **변동**. 방문 전 확인 |
| **나눠맞기** | 앱 **미지원**(현재). 비권장 용법 정보에 의존하지 않음 |
| **데이터** | 건강 기록은 **민감 정보**. 계정·공유 설정을 본다 |

---

## 면책

> **강한 면책**  
> 삐약은 **진단·처방·치료**를 하지 않는 **기록·정보 앱**이다.  
> 약물 농도 그래프·통계·커뮤니티 내용은 **참고용**이며, 개인마다 다르다.  
> [[위고비]]·[[마운자로]]는 **전문의 처방** 약이다. 용량·투여·중단은 **설명서와 의료진**만 따른다.  
> 이 글은 앱 **기능 설명**이며, 앱 사용·치료를 권유하지 않는다.  
> 기능·지원 여부(나눠맞기 등)는 **앱 버전**마다 바뀔 수 있다.
