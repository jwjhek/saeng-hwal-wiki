# 코르티솔

> **분류:** 생활·건강 · [[생활위키 목차]]

**코르티솔**(cortisol)은 **부신 피질**에서 나오는 **호르몬**이다. 
혈당·대사·면역·혈압·**스트레스 대응**에 관여하며, **아침에 높고 밤에 낮아지는** 하루 리듬이 있다.

SNS·기능의학에서 **「코르티솔 검사」** 가 자주 언급되지만, **한 번의 수치**만으로 피로·불면 원인을 단정하기는 어렵다. 
이 글은 **생물학 개념**만 정리한다. **진단·치료 권유가 아니다.**

확인일: 2026-08-13

관련: [[노르에피네프린]] · [[도파민]] · [[불면증]] · [[다이어트]] · [[포스파티딜세린]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **정체** | **부신**이 만드는 **스테로이드 호르몬** (글루코코르티코이드) |
| **조절** | 뇌하수체의 **ACTH** → 부신 자극 → 코르티솔 분비 (**HPA 축**) |
| **흔한 별칭** | **스트레스 호르몬** — 급·만성 스트레스에 **올라갈 수** 있음 |
| **리듬** | 보통 **이른 아침 최고** → 낮·저녁 **하강** → 밤 **최저** |

```text
[뇌] 시상하부 → 뇌하수체(ACTH)
 ↓
[부신 피질] ★ 코르티솔
 ↓
혈당·대사·면역·혈압 · 스트레스 적응
```

---

## 2. 몸에서 하는 일

| 기능 (개요) | 일상과 연결 |
|-------------|-------------|
| **혈당 올리기** | 공복·스트레스 시 에너지 **동원** |
| **대사** | 단백질·지방·당 대사 조절 |
| **항염·면역 억제** | **스테로이드** 약과 같은 계열 — 염증·알레르기에 쓰이는 이유 |
| **혈압·수분** | 저혈압·탈수 대응에 관여 |
| **각성·기상** | **아침 리듬** — 기상·활동 시작과 겹침 |

**필요한 양**이 있어 **너무 적거나 많으면** 질병이 된다 — §6.

---

## 3. [[노르에피네프린]]·[[도파민]]과

| | 코르티솔 | [[노르에피네프린]]·에피네프린 |
|--|----------|---------------------------|
| **나오는 곳** | **부신 피질** | **부신 수질**·교감신경·뇌 |
| **속도** | 분비 **느리게** 올라가 **오래** 유지되는 편 | **급한** 각성·심박 |
| **합성** | **별도 경로** (콜레스테롤 등) | [[도파민]] → 노르에피네프린 → 에피네프린 |
| **스트레스** | **HPA 축** — 만성 스트레스·수면 부족과 연구 많음 | **교감신경** fight-or-flight |

「스트레스 호르몬 = 아드레날린만」이 아니라 **코르티솔**도 핵심 축이다.

---

## 4. 하루 리듬 (일주기)

| 시간대 | 대략 |
|--------|------|
| **새벽~오전** | 가장 **높음** — 기상·활동 |
| **오후** | 점차 **감소** |
| **밤·취침** | **낮음** — 수면·회복 |

**야간 근무·불규칙 수면·시차**는 이 곡선을 **흐트러뜨릴** 수 있다 → [[불면증]] · [[갤럭시 워치 사용법]] (수면·스트레스 지수는 **참고용**).

검사 해석 시 **몇 시에 채혈했는지**가 중요하다 — §7.

## 5. 무엇이 수치를 올리거나 내리나 (생리·생활)

| 올릴 수 있음 | 내릴 수 있음 |
|--------------|--------------|
| **급·만성 스트레스**·불안 | **에디슨병** 등 **부신 기능 저하** |
| **수면 부족** (하루만이어도) | 장기 **스테로이드** 복용 후 급격 중단 |
| **감염·발열·통증** | 뇌하수체·부신 질환 |
| **격한 운동**·채혈 직전 긴장 | (질환) |
| **비만** | |
| **카페인·니코틴**(검사 직전) | |
| **경구 피임약**·일부 약 | |

**검사 당일** 컨디션이 결과에 **크게** 실릴 수 있다 — **한 번**으로 확정하지 않는 경우 많음.

---

## 6. 너무 많을 때·적을 때 (질환 개념)

| 방향 | 대표 질환 (개념) | 흔한 이야기 (전부 해당 아님) |
|------|------------------|------------------------------|
| **과다** | **쿠싱증후군** — 부신·뇌하수체·약물 등 | 얼굴 둥글어짐·복부 비만·스트레·쉬운 멍·고혈압·고혈당 |
| **부족** | **에디슨병**(부신기능저하증) | 극심한 피로·저혈압·체중 감소·피부 어두워짐 |

**스테로이드**(프레드니솔론·덱사메타손 등) **장기 복용**도 쿠싱 **비슷한** 소견을 만들 수 있다 — **감량은 의사** 지시.

일반인의 **「피곤하니 코르티솔 부족」** 은 **에디슨병**과 **같지 않다** — §8.

---

## 7. 검사 (개념)

| 방법 | 무엇을 보나 |
|------|-------------|
| **혈액 코르티솔** | **한 시점** 농도 — 보통 **오전 7~9시** 채혈 |
| **24시간 소변** | 하루 **총 배출량** — 과다 여부 등 |
| **타액 코르티솔** | **여러 시점** — **리듬 곡선** (기상·저녁 등) |
| **추가** | ACTH·**덱사메타솬 억제검사**·ACTH 자극검사 등 — **질환 감별** |

| 주의 | 설명 |
|------|------|
| **단일 혈액 1회** | 스트레스·수면부족·운동으로 **일시 상승** 가능 — **쿠싱 선별**에만 쓰는 경우 많음 |
| **참고치** | 검사실·**채혈 시각**마다 다름 |
| **웨어러블** | 손목 **스트레스 지수** ≠ 혈액 코르티솔 **직접 측정** |

이상 수치면 **재검·부하검사** — 인터넷 키트만으로 **자가 진단**하지 않는다.

---

## 8. 「부신 피로」·코르티솔 다이어트

| 말 | 현실 |
|----|------|
| **부신 피로**(adrenal fatigue) | **주류 의학**에서 공식 질환명으로 **인정되지 않는** 경우가 많음 — 피로 원인은 **수면·우울·갑상선·빈혈** 등 **다양** |
| **코르티솔만 맞추면 살 빠짐** | [[다이어트]]는 **칼로리·근육·수면·질환**이 먼저 — 코르티솔 **단독 해법 아님** |
| **아침 코르티솔 낮으면 탈진 단계** | **타액 곡선** 마케팅가 **과장**인 경우 많음 — **내분비과** 감별 필요 |
| [[포스파티딜세린]] | 일부 연구에서 **운동 후 코르티솔** 관심 — **만능 항스트레스제 아님** |

피로·불면이 **수주 이상**이면 코르티솔 키트보다 **진료**가 우선.

---

## 9. 생활과의 연결

| 요인 | 참고 |
|------|------|
| **수면** | 부족하면 리듬·수치 **교란** — [[불면증]] |
| **만성 스트레스** | HPA 축 **과활성** 논의 — [[정신건강]]·상담·운동 등 **복합** |
| **[[다이어트]]** | 비만은 코르티솔·대사와 **양방향** — **체중 감량**이 도움 되는 경우 |
| **카페인·야식** | 불면·[[역류성 위염]]과 겹치면 **수면·스트레스** 악순환 |
| **운동** | 적당한 운동은 스트레스 완화 — **과훈련·공복 과운동**은 일시 코르티솔↑ |

「코르티솔 낮추는 음식」 **특정 목록**은 **개인·근거** 편차가 크다 — **균형 식사·수면**이 먼저.

---

## 10. 약·호르몬제 (방향만)

| 종류 | 코르티솔과 |
|------|------------|
| **경구·주사 스테로이드** | 체내 코르티솔 **작용을 대체·억제** — **갑자기 끊으면 위험** |
| **흡입 스테로이드**(천식 등) | 전신 영향은 **용량·기간**에 따라 적음~있음 |
| **경구 피임약** | 검사 수치 **영향** 가능 |

약 **증량·감량·중단**은 **처방 의사**만.

---

## 11. 흔한 오해

| 오해 | 현실 |
|------|------|
| 스트레스 = 코르티솔만 | **노르에피네프린**·심박·염증 등 **여러 축** |
| 아침 피로 = 코르티솔 부족 | **수면 질**·우울·갑상선·빈혈 등 **감별** |
| 검사 1번으로 쿠싱 확정 | **부하검사·영상** 등 **추가** 필요 |
| 워치 스트레스 80 = 위험 | **상대 지표** — 증상·진료와 **별개** |
| 코르티솔 검사 = [[보충제]] 처방 근거 | **질환 치료**와 **건강식품**은 **다름** |
