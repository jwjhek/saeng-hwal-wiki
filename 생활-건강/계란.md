# 계란

> **분류:** 생활·건강 · [[생활위키 목차]]

**계란**은 완숙·반숙·스크램블·프라이 등 조리가 쉽고, 감량·고단백 식단의 기본 재료로 자주 쓰인다.  
[[다이어트 추천 음식]]에서 **단백질 기둥**에 가깝다.

> **면책**  
> 영양·식단 **처방·치료 권유가 아니다.**  
> 콜레스테롤·알레르기·생란 섭취·임산부 등은 가이드·개인 상담이 우선.  
> “계란 노른이 무조건 해롭다/무조건 좋다” 극단은 피한다.

확인일: 2026-08-07

관련: [[다이어트 추천 음식]] · [[다이어트]] · [[스트링 치즈]] · [[병아리콩]] · [[방울토마토]] · [[오이]]

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 무엇 | 닭란이 일반적. 메추리알 등은 별도 |
| 다이어트에서 | **단백질**·포만·저렴·조리 간단 |
| 노른·흰자 | 영양이 나뉨. “흰자만”은 선택이지 만능 아님 |
| 주의 | 기름·마요·치즈를 잔뜩, 생란·보관, 알레르기 |

---

## 2. [[다이어트]]와

| | 감각 |
|--|------|
| 장점 감각 | 아침·도시락·운동일 단백질. 근력([[다이어트]] §4)과 자주 묶임 |
| 조합 | [[방울토마토]]·[[오이]] · [[스트링 치즈]] · 샐러드에 [[병아리콩]] |
| 함정 | 매일 마요 계란 샌드만, 기름 프라이 3장+밥 대접, 원푸드 계란 |
| 방법 | 고단백·칼로리 적자와 친화. 콜레스테롤 이슈면 **의사 지침** |

[[위고비]]·[[마운자로]] 사용 중 메스꺼움이 있으면 기름진 프라이보다 **삶란**이 편한 집이 있다. 개인차·처방 아님.

---

## 3. 고르는 법 · 먹는 법

| 조리 | 감각 |
|------|------|
| 삶란(완숙·반숙) | 기름 최소. 휴대 |
| 스크램블·프라이 | **팬 오일·버터 양**이 칼로리 |
| 찜·수란 | 담백 |
| 가공 | 액란·훈제·마요 샐러드 — 라벨 |

| 구매·안전 | 감각 |
|-----------|------|
| 깨진 달걀·이상한 냄새 | 폐기 |
| 냉장·유통기한 | 지킴 |
| 생란·반숙 | 면역·임신·노약자는 가이드 확인 |
| 알레르기 | 즉시 중단·진료 |

노른의 식이 콜레스테롤 이야기는 **시대·개인 위험도**에 따라 상담 내용이 다르다. 인터넷 금지령만 따르지 말 것.

## 4. 주의

- 계란 알레르기
