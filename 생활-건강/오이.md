# 오이

> **분류:** 생활·건강 · [[생활위키 목차]]

**오이**는 수분 많은 채소로, 생채·무침·간식에 흔하다. 
감량에서는 **부피·씹는 감·저칼로리**으로 [[다이어트 추천 음식]]에 자주 넣는다.

확인일: 2026-08-07

관련: [[다이어트 추천 음식]] · [[다이어트]] · [[방울토마토]] · [[병아리콩]] · [[계란]] · [[스트링 치즈]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 박과 채소. 다다기·취청 등 품종 |
| 다이어트에서 | 부피↑ · 간식 · 수분 · 칼로리 밀도 낮은 편 |
| 한계 | 단백질은 적음 → [[계란]]·[[스트링 치즈]]·[[병아리콩]]과 짝 |
| 주의 | 마요·크림·짜장·치즈 딥 과다, 절임 나트륨 |

---

## 2. [[다이어트]] 추천 음식

| | |
| ----- | ------------------------------------ |
| 장점 | 야식·출출함 완충, 접시 채우기, 배달 대신 아삭한 식감 |
| 조합 | [[방울토마토]] · 병아리콩 샐러드 · 스트링 치즈 · 계란 옆 |
| 함정 | 오이 무침에 당·참기름 과다, “오이 다이어트”만 하기 |
| 방법 | 거의 모든 패턴에 무난. 원푸드 오이는 비추 |

---

## 3. 고르는 법 · 먹는 법

| | 설명 |
|--|------|
| 고르기 | 단단·윤기. 끝 말랑하면 빨리 소비 |
| 생 | 씻어 썰기 · 스틱 간식 |
| 무침 | 식초·마늘·고춧가루 — **설탕·오일 양** |
| 샐러드 | 오이 + 방울토마토 + 병아리콩 |
| 피클 | 나트륨·당 라벨 |

껍질·씨 제거는 취향·소화. 영양 “독소” 이야기보다 **세척·보관**이 실용적이다.

---

## 4. 주의

- 드물게 알레르기·구강 가려움(꽃가루 관련 등) 
- 냉한 느낌·소화 민감은 개인차 
- 절임·피클의 나트륨 
- 원푸드·주스 클렌즈로만 감량 → [[다이어트]] §3.6

## 6. 정리

오이는 **부피·간식용으로 쓰기 쉬운 채소**다. 
단백질 짝만 잊지 않으면 [[다이어트 추천 음식]]으로 잘 맞는다.
