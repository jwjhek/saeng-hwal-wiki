# 다이어트

> **분류:** 생활·건강 · [[생활위키 목차]]

체중·체지방을 줄이거나 유지하려는 **생활 습관 접근**을 정리한다.  
처방 주사·약([[위고비]], [[마운자로]])은 **의사 진료 전제**이며, 이 글이 약을 권하지 않는다.

확인일: 2026-08-07

관련: [[다이어트 추천 음식]] · [[위고비]] · [[마운자로]] · [[크레아틴]] · [[종합비타민]] · [[오메가3]] · [[갤럭시 워치 사용법]] · [[배달 앱]]

---

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 물리 | 장기적으로 **쓰는 에너지 > 먹는 에너지**면 체중이 줄어드는 쪽이 기본 틀 |
| 현실 | 수면·스트레스·근육량·약·질환이 식욕·대사에 영향 |
| 목표 | “빨리”보다 **유지 가능한 속도·근육 보존** |
| 방법 | 저탄·IF·원푸드 등 → [[#3. 다이어트 방법 모음]]. **이름보다 유지·안전** |
| 음식 | 반복하기 쉬운 재료 → [[다이어트 추천 음식]] ([[계란]]·[[병아리콩]] 등) |
| 운동 | 걷기·근력 등이 뼈대 → [[#4. 운동]]. “유산소만”보다 **근육 보존** |
| 약 | [[위고비]]·[[마운자로]] 등은 **비만·질환 치료 맥락의 전문 영역** |

광고의 “독소 배출·특정 음식만”보다, **식사·움직임·수면**이 먼저인 경우가 많다.

## 2. 기본 축 (생활)

### 2.1 식사

| 방향        | 감각                                    |
| --------- | ------------------------------------- |
| 단백질       | 포만·근육 유지에 자주 강조. 양은 개인·질환에 따라 다름      |
| 채소·식이섬유   | 부피·포만, 가공 초고칼로리와 균형                   |
| 초가공·당음료   | 칼로리가 쌓이기 쉬움 → 줄이면 체감이 큰 집이 많음         |
| 극단 원푸드·장기간 단식 | 요요·영양 결핍·근육 손실·폭식 위험. **유행만 따르지 말 것** → [[#3. 다이어트 방법 모음]] |
| 기록        | 앱·메모로 “뭘 먹었는지”만 봐도 패턴이 보임             |
| 추천 재료 예 | [[다이어트 추천 음식]] — [[계란]] · [[병아리콩]] · [[스트링 치즈]] · [[방울토마토]] · [[오이]] |

칼로리·매크로를 숫자로 짤지는 선택이다. 질환·신장·간 문제가 있으면 **수치 다이어트 전 상담**.  
특정 식품만으로 끝내려 하지 말고, **단백질 + 채소 부피 + 유지 가능한 양**을 본다.

### 2.2 움직임

감량의 “소모”만 보면 유산소에 쏠리기 쉽지만, **근육·대사·유지**까지 보면 저항 운동이 같이 거론된다.  
종류·추천 감각·주의는 [[#4. 운동]]에 모았다.

| 방향 | 감각 |
|------|------|
| 일상 활동(NEAT) | 걷기·계단·서기 — 지속하기 쉬움 |
| 유산소 | 심폐·칼로리 소모. 과하면 회복·식욕이 흔들릴 수 있음 |
| 근력(저항) | 체중만 줄이면 근육도 빠지기 쉬움 |
| 과한 HIIT만 | 부상·번아웃. 기초 체력·수면과 세트 |
| [[크레아틴]] 등 | 수행 보조 논의는 별도. **지방 연소 마법이 아님** |

### 2.3 수면·스트레스

잠이 줄면 식욕·충동·회복이 흔들리기 쉽다.  
야식·배달([[배달 앱]]) 패턴과 같이 보면 원인 분리가 쉽다.

### 2.4 측정

| 도구 | 감각 |
|------|------|
| 체중계 | 하루 변동 큼 → **주 평균·같은 조건** |
| 허리·옷 | 체중보다 체감에 유용할 때 |
| 워치 체성분 | [[갤럭시 워치 사용법]] — **의료 인바디 대체 아님**, 추세용 |
| BMI | 키·체중 지수일 뿐. 근육형·노인 등은 해석 주의 |

## 3. 다이어트 방법 모음

이름은 많고, **결국 먹는 양·구성·지속성**에서 갈리는 경우가 많다.  
아래는 **유행 이름 정리·감각 비교**이지, 어떤 방법을 하라는 처방이 아니다.  
당뇨·신장·담석·섭식장애·임신·약 복용 중이면 **의사·영양 상담 없이** 극단 제한을 시작하지 않는다.

### 3.1 한눈에 비교

| 이름 | 핵심 아이디어 | 잘 맞는 감각 | 주의 |
|------|---------------|--------------|------|
| 칼로리 적자 | 섭취 < 소모 | 숫자로 관리하고 싶을 때 | 과소 섭취·근육 손실·기록 왜곡 |
| 고단백 | 단백질 비중↑ | 포만·근력 병행 | 신장 질환 시 상담 |
| 저지방 | 지방 줄이기 | 기름진 외식 줄이기 | “무지방=건강”은 아님(당·가공) |
| 저탄고지(케토) | 탄수↓ 지방↑ | 탄수 갈망·혈당 이슈 논의 | 적응기·콜레스테롤·지속성·질환자 |
| 저탄수화물 | 밥·면·당 줄이기 | 케토보다 느슨한 제한 | “탄수=독” 과장은 피함 |
| 간헐적 단식 | 먹는 시간창 제한 | 야식·간식 끊기 | 저혈당·폭식·섭식장애 위험 |
| 원푸드 | 한 가지만 먹기 | 단기 “리셋” 유혹 | 영양 결핍·요요·추천하기 어려움 |
| 디톡스·주스 | 액체·클렌즈 | SNS 유행 | 증거 약함·근육·당분 주의 |
| 채식·비건 감량 | 동물성↓ | 윤리·환경과 겹칠 때 | 단백질·B12·철 설계 |
| 지중해식 | 채소·통곡·올리브·생선 | 장기 건강 패턴으로 자주 언급 | “감량 속도”보다 습관 |
| DASH 등 | 염분·가공↓ | 혈압·심혈관 맥락 | 감량 전용 브랜드가 아님 |
| 배달·외식 다이어트 | 빈도·메뉴 조절 | [[배달 앱]] 생활권 | “집밥만” 강박은 지속성↓ |
| 약·주사 | GLP-1 등 | [[위고비]]·[[마운자로]] | **처방·진료만** |

공통으로: **유지할 수 있는지**, **단백질·근력·수면이 빠지지 않는지**를 본다.

### 3.2 칼로리 적자 · 매크로

| | 감각 |
|--|------|
| 원리 | 장기적으로 에너지 적자면 체중이 줄어드는 쪽이 기본 틀 |
| 하는 법 | 앱·눈대중·접시 규칙(채소 반·단백질·전분) 등 |
| 장점 | 음식 종류를 크게 막지 않아도 됨 |
| 함정 | TDEE 추정이 흔들림, 주말 폭식, 과한 적자 → 기운·탈모·생리·폭식 |

“하루 800kcal” 같은 **극단 저칼로리**는 의료 감독 없이 흉내 내지 않는다.

### 3.3 고단백 · 저지방

| 방법 | 감각 |
|------|------|
| 고단백 | 포만·근육 보존 논의가 많음. 운동([[크레아틴]] 맥락의 수행)과 자주 묶임 |
| 저지방 | 1990년대 유행. 지방만 줄이고 당·가공을 늘리면 의미가 흐려짐 |
| 실전 | “단백질 챙기고, 튀김·크림·당음료를 줄이기” 정도로 합치는 집이 많음 |

### 3.4 저탄고지(케토) · 저탄수화물

| | 감각 |
|--|------|
| 저탄수화물 | 밥·면·빵·설탕·단 음료를 줄임. 정도는 사람마다 |
| 저탄고지(LCHF)·케토 | 탄수를 아주 낮추고 지방을 올리는 쪽. **케톤** 이야기를 자주 함 |
| 사람들이 기대하는 것 | 식욕↓, 초기 체중↓(수분·글리코겐 포함) |
| 흔한 부작용·이슈 | 두통·변비·입냄새·적응기, 지질 수치, 운동 수행, **장기 지속** |
| 누구에게 특히 주의 | 당뇨약·인슐린, 신장·췌장·담낭, 임신, 섭식장애 병력 → **상담** |

“탄수만 끊으면 무조건 건강”은 과장이다. **가공육·버터만** 먹는 케토와, 채소·단백질 있는 저탄은 다르다.

### 3.5 간헐적 단식 (IF)

| 패턴(예) | 감각 |
|----------|------|
| 16:8 | 하루 중 8시간만 식사 |
| 18:6 · OMAD | 창이 더 짧음. 난이도·위험↑ |
| 5:2 등 | 주중 일부 날을 아주 적게 |

| | 감각 |
|--|------|
| 잘 되는 경우 | 야식·무의식 간식이 끊기며 **자연 적자** |
| 안 맞는 경우 | 아침 필수·저혈당·격한 운동·약 복용 시간·섭식장애 |
| 함정 | 창 안에서 **고칼로리 폭식**, 수분·전해질 무시, “단식=해독” 과장 |

물·차·블랙커피만 허용하는지는 정의마다 다르다. **약물·질환**이 있으면 의사와 시간창을 맞춘다.

### 3.6 원푸드 · 디톡스 · 주스 · 단기 챌린지

| 이름 | 감각 | 왜 위험한 편인가 |
|------|------|------------------|
| 원푸드(사과·고구마·닭가슴만 등) | 단순해서 초반 감량 체감 | 영양 편중, 근육↓, 끝난 뒤 **요요·폭식** |
| 디톡스·클렌즈 | “독소 배출” 마케팅 | 간이 이미 해독. **증거 약한 유행**이 많음 |
| 주스·스무디만 | 씹기↓·당분↑ 가능 | 포만·치아·칼로리 밀도 |
| 1주 5kg · 워터 단식 | SNS 챌린지 | 탈수·전해질·심혈관·담석 등 **의료 영역** |

단기 체중 하락의 **지방만**이 아닌 경우가 많다. 목표를 “이벤트 체중”에 두면 유지가 어렵다.

### 3.7 채식·비건으로 감량

동물성 식품을 줄이면 칼로리가 자연히 내려가는 집이 있다.  
다만 **가공 비건 과자·튀김**만 먹으면 감량과 무관하고, 장기면 **단백질·B12·철·칼슘** 설계([[종합비타민]] 논의와 겹칠 수 있음)가 필요하다.

### 3.8 지중해식 · DASH · “건강한 식단” 형

| 이름 | 감각 |
|------|------|
| 지중해식 | 채소·과일·통곡·콩·올리브유·생선·적당 유제품·가공↓ |
| DASH | 혈압·심혈관 맥락에서 자주 언급. 염분·가공↓ |
| 공통 | “유행 이름”보다 **패턴·지속**에 가깝다. 감량 속도는 적자·활동에 달림 |

급격한 제한보다 **외식·배달·당음료 습관을 바꾸는 뼈대**로 쓰기 좋다.

### 3.9 배달·외식 · 현실형

| 방향 | 감각 |
|------|------|
| 빈도 | 매일 → 주 N회로 |
| 메뉴 | 튀김·크림·당 음료 조합 줄이기 |
| 분량 | 1인분 나누기·국물 남기기 |
| 기록 | 시킨 날만 메모해도 패턴이 보임 |

완벽한 집밥이 아니라 **평균이 내려가면** 된다. 관련: [[배달 앱]] · [[배민]] · [[쿠팡이츠]].

### 3.10 약·주사와 방법의 관계

[[위고비]]·[[마운자로]]는 **식욕·포만을 바꾸는 치료** 논의이지, 원푸드·디톡스를 대체하는 SNS 팁이 아니다.  
투여 중에도 **단백질·근력·구역에 맞는 식사**가 자주 거론된다. 선택은 **진료실**.

### 3.11 고를 때 질문

1. **12주 뒤에도** 같은 규칙을 지킬 수 있는가  
2. 단백질·채소·수면·걷기·근력([[#4. 운동]])이 빠지지 않는가  
3. 질환·약·생리·기분·폭식 이력이 있는가 → 있으면 **전문 상담**  
4. “독소·혈자리·특정 음식만” 과장에 기대지 않는가

## 4. 운동

식사 적자만으로도 체중은 줄 수 있지만, **근육 손실·요요·컨디션**을 보면 움직임이 빠지기 어렵다.  
아래는 **일반 성인 감각의 정리**이지, 개인 재활·선수 처방·PT 대체가 아니다.  
심장·관절·디스크·수술 직후·어지럼·흉통이 있으면 **운동 시작 전 진료**.

### 4.1 왜 넣나

| 역할 | 감각 |
|------|------|
| 에너지 소모 | 유산소·일상 활동이 적자에 도움 |
| 근육 보존 | 감량 중 저항 운동 + 단백질이 자주 묶임 |
| 식욕·기분·수면 | 사람마다 다르지만, 규칙적 움직임이 도움이 되는 집이 많음 |
| 약([[위고비]]·[[마운자로]])과 | 투여 중에도 **근력·단백질** 논의가 많음 |
| 한계 | 운동만으로 “폭식 상쇄”는 어렵고, 부상 나면 장기적으로 손해 |

### 4.2 종류 한눈에

| 종류 | 하는 일 | 다이어트에서 |
|------|---------|--------------|
| 일상 활동(NEAT) | 걷기·계단·가사·출퇴근 | 매일 쌓이기 쉬움. **먼저 올리기 좋음** |
| 유산소(중강도) | 빠른 걷기·자전거·수영 등 | 심폐·소모. 대화 가능한 강도부터 |
| 근력(저항) | 맨몸·덤벨·머신·밴드 | 근육·기초대사·체형 유지에 중요 |
| HIIT·인터벌 | 짧고 센 구간 반복 | 시간 대비 자극. **기초 후에**, 주 횟수 제한 |
| 유연성·가동성 | 스트레칭·폼롤러·요가 일부 | 부상 예방·회복. 감량의 본체는 아님 |
| 스포츠 | 배드민턴·축구·등산 등 | 재미로 지속. 충돌·무릎 주의 |

“뱃살만 태우는 운동”은 없다. **전신 적자 + 근력**이 현실에 가깝다.

### 4.3 추천으로 자주 거론되는 운동

**개인 상태에 맞게 고르고, 통증·호흡곤란이면 멈춘다.** “이 목록을 전부 하라”가 아니다.

#### 일상 · 걷기

| 운동 | 감각 | 시작 감각 |
|------|------|-----------|
| 평지 걷기 | 진입 장벽 낮음 | 하루 합쳐 20~40분부터 |
| 빠른 걷기(파워워크) | 중강도 유산소의 기본 | 숨이 살짝 차되 대화 가능 |
| 경사·인클라인 걷기 | 무릎 충격 적게 부하↑ | 트레드밀 경사·언덕 |
| 계단 | NEAT·하체 | 한 칸씩, 난간. 무릎 아프면 줄임 |
| 제자리 걷기·마칭 | 날씨·공간 제한 | TV·통화와 묶기 |

만보(10000보)는 **목표 예시**일 뿐. 지금보다 **조금 더**가 먼저다.

#### 유산소 (걷기 외)

| 운동 | 감각 | 주의 |
|------|------|------|
| 실내·실외 자전거 | 무릎 부담이 걷기보다 나은 집도 | 안장·자세 |
| 수영·아쿠아 | 체중 부하↓, 전신 | 수영장 접근성 |
| 일립티컬·로잉머신 | 실내 전신 | 자세·허리 |
| 가벼운 조깅 | 심폐 | 과체중·무릎이면 **걷기·자전거 먼저** |

주 **150분 내외의 중강도** 이야기가 건강 가이드에서 자주 나오지만, 감량 초보는 **주 3회×20~30분**부터도 충분하다.

#### 근력 — 집(맨몸·밴드)

주 **2~3회**, 전신 또는 상·하체 나눔. 세트 사이 호흡·통증 확인.

| 부위 | 예시 | 감각 |
|------|------|------|
| 하체 | 스쿼트(의자 앉았다 일어나기), 런지(짧게), 힙 브리지 | 무릎이 발끝 방향, 통증 없이 |
| 엉덩이·후면 | 힙 브리지, 밴드 사이드 스텝 | 앉아 있는 생활 보완 |
| 미는 동작 | 벽·무릎·일반 푸시업 | 손목·어깨 아프면 벽부터 |
| 당기는 동작 | 밴드 로우, 문손잡이 로우(안전 확인) | 둥근 어깨 보완 |
| 코어 | 플랭크(짧은 시간), 데드버그, 사이드 플랭크 | 허리가 꺾이지 않게 |
| 전신 | 버피·점프 스쿼트 | **초보·관절에 부담** → 급할 필요 없음 |

횟수 감각: 동작당 **8~15회 × 2~3세트**, 마지막 2회가 살짝 힘든 정도.  
정확한 자세가 불안하면 **영상 1개만** 정하거나, 센터·PT 1~2회가 이득인 집이 있다.

#### 근력 — 헬스장(머신·프리)

| 구분 | 예시 | 감각 |
|------|------|------|
| 하체 | 레그프레스, 레그컬·익스텐션, 케이블 킥백 | 머신으로 자세 배우 쉽 |
| 등 | 랫풀다운, 시티드 로우 | 당기기 균형 |
| 가슴·어깨 | 체스트 프레스, 숄더 프레스(가벼운 무게) | 과도한 아치·반동 금지 |
| 힌지 | 루마니안 데드리프트(가벼운 바·덤벨) | **허리 디스크·통증 시 지도 필수** |
| 코어 | 케이블 우드찹, 머신 크런치 | 매일 수백 개 복근보다 질 |

초보 루틴 감각(예시, 처방 아님):

1. 레그프레스 또는 스쿼트 계열  
2. 랫풀다운 또는 로우  
3. 체스트 프레스  
4. 힙 브리지 또는 루마니안(가능 시)  
5. 플랭크 또는 데드버그  

무게는 **통제되는 범위**에서. 매주 조금씩 올리기(점진 부하).

#### HIIT · 서킷 (선택)

| | 감각 |
|--|------|
| 예 | 자전거 인터벌, 짧은 케틀벨·맨몸 서킷 |
| 언제 | 걷기·근력 **기본이 생긴 뒤**, 주 1~2회 |
| 피하기 | 수면 부족, 식욕 폭발, 무릎·허리 통증, 초보의 매일 HIIT |

#### 유연성 · 회복

| | 감각 |
|--|------|
| 스트레칭·요가·필라테스 | 가동성·호흡·스트레스. **감량 본체 대체 아님** |
| 걷기 쿨다운 | 운동 후 5분 천천히 |
| 휴식일 | 근육통·수면. 매일 고강도는 필수가 아님 |

관련 통증·시술 맥락은 [[체외충격파 치료]] 등과 **별개**. 운동 중 날카로운 통증은 중단.

### 4.4 주간 조합 예시 (참고)

| 수준 | 예시 한 주 | 메모 |
|------|------------|------|
| 입문 | 걷기 5일×20~30분 + 맨몸 근력 2일 | 배달·야식 조절과 같이 |
| 기본 | 빠른 걷기/자전거 3~4일 + 전신 근력 2~3일 | 수면 우선 |
| 여유 | 위 + 가벼운 인터벌 1일 또는 등산·구기 1일 | 칼로리·회복 균형 |

같은 날: **근력 → 짧은 유산소** 또는 요일 분리. 공복 고강도는 어지럼·저혈당 주의(특히 IF·당뇨약).

### 4.5 과장 · 함정

| 비교적 | 과장·함정 |
|--------|-----------|
| 걷기+주 2회 근력 | “이 동작만 하면 뱃살 분해” |
| 점진적으로 | 첫날부터 매일 HIIT·레그데이 몰아치기 |
| 통증 없는 가동 범위 | 통증 참으며 고중량 |
| 단백질·수면과 세트 | 운동 후 보상 폭식·야식 |
| [[크레아틴]]은 수행 보조 | “먹으면 지방이 빠짐” |

워치 칼로리([[갤럭시 워치 사용법]])는 **과대 추정**되는 경우가 많다. 그 숫자만큼 더 먹지 않기.

### 4.6 식사·약과 같이 볼 때

| 상황 | 감각 |
|------|------|
| 감량 중 | 단백질 + 근력 → 근육 보존 논의 |
| 저탄·케토 | 초기 고강도 수행이 떨어질 수 있음 → 적응·상담 |
| IF | 훈련 시간을 식사창·약 복용과 맞춤 |
| [[위고비]]·[[마운자로]] | 구역·피로 시 강도↓. **근손실 우려**로 근력 유지가 자주 거론 |
| 보충제 | [[크레아틴]] 등은 선택. 운동·식사 대체 아님 |

## 5. 흔한 과장과 위험

| 비교적 | 과장·위험 |
|--------|-----------|
| 적당 적자 + 단백질 + 걷기·근력 | “독소·혈자리”만으로 지방 제거 · “이 동작만 뱃살” |
| 배달·외식 빈도 조절 | 설사·이뇨제로 체중계만 속이기 |
| 습관 유지 12주+ | 1주 5kg·원푸드·워터 단식 챌린지 |
| 의사와 약·시술 | SNS 무허가 주사·해외 직구 무처방 |
| 저탄·IF를 **도구**로 | “○○만 하면 대사 리셋” 만능론 |

보충제([[종합비타민]], [[오메가3]])는 **결핍·식사 보조**이지 다이어트의 본체가 아니다.

## 6. 약이 거론될 때 ([[위고비]] · [[마운자로]])

식욕·혈당 경로에 작용하는 **전문의약품**이 비만·당뇨 치료에 쓰인다.  
대표적으로 알려지고, 국내·해외 허가·급여·적응이 **약마다·시점마다** 다르다.

| | 감각 |
|--|------|
| 역할 | 생활습관 **보조·치료**의 일부. “주사만 맞고 폭식”은 결과가 나쁘기 쉬움 |
| 필수 | **의사 진료·처방·추적**. 자가 구매·나눠 쓰기 금지 |
| 이 위키 | 개념·주의는 [[위고비]] · [[마운자로]] |
| 생활과의 연결 | 약 복용(투여) 중에도 **단백질·근력·부작용(구역 등)에 맞는 식사** 상담 |

적응증(비만 정도·동반질환), 금기, 보험은 **병의원**에서만 판단한다.

## 7. 멈추거나 도움을 청할 때

- 체중·음식에 대한 공포, 폭식·구토, 생리·탈모·실신  
- 심장·신장·담낭·췌장 질환 병력  
- 임신·수유·청소년  
- 운동 중 흉통·실신·날카로운 관절 통증 → 중단 후 진료  
- 약·주사 부작용이 심함 → 처방의와 연락  

정신건강([[우울장애]] 등)과 먹이 행동이 겹치면 **정신건강·영양 전문**을 같이 본다.

- [ ] 원푸드·워터 단식·불법약 배제  
- [ ] [[다이어트 추천 음식]]: 단백질([[계란]] 등) + 부피([[오이]]·[[방울토마토]] 등)를 넣을 수 있는가  
- [ ] [[#4. 운동]]: 걷기(또는 유산소) + **주 2회 이상 근력** 감각을 넣었는가  
- [ ] 단백질·수면과 운동이 **같이** 가는가  
- [ ] 측정은 같은 조건·추세  
- [ ] 약 관심 시 [[위고비]]·[[마운자로]] 읽고 **진료** (자가 투여 금지)

## 9. 정리

다이어트 **방법 이름**은 많고, 공통 뼈대는 **지속 가능한 식사·운동·수면**이다.  
재료 예시는 [[다이어트 추천 음식]]([[계란]]·[[병아리콩]]·[[스트링 치즈]]·[[방울토마토]]·[[오이]] 등)을 보면 된다.  
저탄·IF·칼로리 등은 **도구**일 뿐이고, 원푸드·디톡스 챌린지는 위험 쪽이다.  
운동은 **걷기·일상 활동 + 근력**이 추천 감각의 중심이고, HIIT는 기초 다음이다.  
[[위고비]]·[[마운자로]]는 그 위에 올릴 수 있는 **전문 치료 옵션**이지, 면책 없이 SNS로 따라 할 대상이 아니다.

## 면책

> **강한 면책**  
> - **진단·처방·식이요법 처방·약 복용 권유가 아니다.**  
> - 급격한 절식·불법 다이어트약·검증 안 된 주사는 위험하다.  
> - 섭식장애·임산부·청소년·만성질환은 **전문 상담** 없이 스스로 극단 제한하지 않는다.  
> - 워치·체성분 수치는 참고용 ([[갤럭시 워치 사용법]]).  
> - 운동 예시는 일반 감각이다. **부상·질환 시 운동 처방 대체가 아니다.**
