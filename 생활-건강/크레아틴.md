# 크레아틴

> **분류:** 생활·건강 · [[생활위키 목차]]

운동·회복 쪽에서 자주 거론되는 보충제 **크레아틴(Creatine)** 을 개념·근거 감각·사용 시 주의만 정리한다.  
제품 광고·인플루언서 용량을 그대로 따르지 말고, **라벨·의사·약사**를 우선한다.

> **면책**  
> 의료·영양 **진단·처방·섭취 권유가 아니다**.  
> 질병·임신·수유·청소년·신장·약 복용 중이면 사용 전 전문가와 상담한다.  
> 효과·안전성 연구는 사람·용량·제품마다 다르고, 과장 광고가 많다.

확인일: 2026-08-07

관련: [[포스파티딜세린]] · [[종합비타민]] · [[오메가3]]

---

## 1. 한눈에

| 항목 | 내용 |
|------|------|
| 정체 | 근육·뇌에 있는 **에너지 완충** 관련 화합물 |
| 흔한 목적 | 근력·고강도 반복, 일부 인지·회복 연구 |
| 근거 밀도 | 스포츠 보충제 중 **연구가 매우 많음** |
| 흔한 형태 | 모노하이드레이트 분말 |

“만병통치”가 아니다. **고강도 운동 수행** 쪽 합의가 상대적으로 뚜렷하다.

---

## 2. 무엇인가

간·신장·췌장에서 일부 합성되고, 붉은 고기·생선에도 있다.  
근육에서는 **포스포크레아틴**으로, 짧은 고강도 운동 때 ATP를 다시 만드는 데 쓰인다.

```text
고강도 짧은 수축 (스프린트, 무거운 중량)
        ↓
ATP 소모 → 포스포크레아틴이 완충
        ↓
저장량이 충분하면 반복·파워에 유리할 수 있음
```

보충제로 먹는 이유는 음식으로만 채우기 번거롭고, 채식·저육식에서는 저장량이 낮은 경우가 많아서다.

---

## 3. 형태

| 형태 | 메모 |
|------|------|
| **모노하이드레이트** | 가장 많이 연구·가성비. 기본 선택 |
| HCl, 완충형, 액상 등 | 마케팅이 앞서는 경우 많음. 필수 아님 |
| 크레아틴 + 대량 자극제 부스터 | 다른 성분 효과를 크레아틴 탓으로 오해하기 쉬움 |

---

## 4. 용량·타이밍 (감각)

문헌·가이드에서 자주 보는 패턴(개인차 큼):

| 방식 | 내용 |
|------|------|
| 유지 | 하루 **약 3–5 g** 모노하이드레이트 |
| 로딩(선택) | 짧게 고용량 후 유지 — **필수는 아님**. 안 해도 수주 내 저장량 상승 가능 |
| 타이밍 | “운동 직후만”보다 **매일 꾸준히**가 더 중요하다는 견해가 많음 |
| 물 | 평소보다 수분 섭취를 의식하는 사람이 많음 |

체중·신장 기능·의사 지시에 따라 달라질 수 있다. **이 문서가 용량을 처방하지 않는다.**

---

## 5. 기대할 수 있는 것 / 과장

| 비교적 자주 언급                 | 과장·오해                                          |
| ------------------------- | ---------------------------------------------- |
| 고강도·반복 수행, 일부에서 제지방·회복 보조 | 스테로이드·급격한 “약”                                  |
| 일부 인지·채식 관련 연구 관심         | 모든 질병 예방·치료                                    |
|                           | “간·신장 무조건 망가짐” (건강인·적정 용량 근거와 동떨어진 공포 마케팅도 많음) |
|                           |                                                |

**신장 질환·의사 주의 대상**이면 임의로 보충하지 않는 쪽에 가깝다.  
체중 증가(수분)가 초기에 있을 수 있다. 경기 체급 선수는 감안.

---

## 6. 고를 때

1. **주성분 함량** (크레아틴 g, 모노하이드레이트인지)  
2. 첨가 자극제·과당·과대 블렌드  
3. 인증·제3자 테스트(오염·함량) — 스포츠는 도핑 리스트도  
4. 유통기한·보관(습한 곳의 분말 뭉침)  

의약품이 아닌 **건강기능식품·보충제** 규제는 국가·표시마다 다르다.

---

## 7. 생활에서 더 큰 것

1. 수면  
2. 단백질·총 열량·수분  
3. 훈련 프로그램·점진 부하  
4. 질환·약·검진  

갤럭시 워치 등 활동·수면 기록은 **참고용** ([[갤럭시 폰과 워치 사용법]]).

---

## 8. 실전 체크

- [ ] 모노하이드레이트, 불필요 블렌드 최소화  
- [ ] 하루 용량·수분  
- [ ] 카페인·다른 보충제와 섞인 “올인원” 라벨 확인  
- [ ] 이상 증상·기존 질환 → 중단·상담  

---

## 9. 정리

크레아틴은 고강도 수행 보조로 **연구·실사용이 많은** 보충제다.  
모노하이드레이트·꾸준함이 기본 감각이고, 질환자는 상담한다.
