# 크레아틴

> **분류:** 생활·건강 · [[생활위키 목차]]

운동·회복 쪽에서 자주 거론되는 보충제 **크레아틴(Creatine)** 을 개념·근거·사용 시 주의만 정리한다. 
제품 광고·인플루언서 용량을 그대로 따르지 말고, **라벨·의사·약사**를 우선한다.

확인일: 2026-08-13

관련: [[포스파티딜세린]] · [[우울장애]] · [[ADHD]] · [[보충제]] · [[종합비타민]] · [[오메가3]]

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 정체 | 근육·뇌에 있는 **에너지 완충** 관련 화합물 |
| 흔한 목적 | 근력·고강도 반복, 일부 인지·회복 연구 |
| 근거 밀도 | 스포츠 보충제 중 **연구가 매우 많음** |
| 흔한 형태 | 모노하이드레이트 분말 |

“만병통치”가 아니다. **고강도 운동 수행** 쪽 합의가 상대적으로 뚜렷하다.

---

## 2. 무엇인가

간·신장·췌장에서 일부 합성되고, 붉은 고기·생선에도 있다. 
근육에서는 **포스포크레아틴**으로, 짧은 고강도 운동 때 ATP를 다시 만드는 데 쓰인다.

```text
고강도 짧은 수축 (스프린트, 무거운 중량)
 ↓
ATP 소모 → 포스포크레아틴이 완충
 ↓
저장량이 충분하면 반복·파워에 유리할 수 있음
```

보충제로 먹는 이유는 음식으로만 채우기 번거롭고, 채식·저육식에서는 저장량이 낮은 경우가 많아서다.

---

## 3. 형태

| 형태 | 메모 |
|------|------|
| **모노하이드레이트** | 가장 많이 연구·가성비. 기본 선택 |
| HCl, 완충형, 액상 등 | 마케팅이 앞서는 경우 많음. 필수 아님 |
| 크레아틴 + 대량 자극제 부스터 | 다른 성분 효과를 크레아틴 탓으로 오해하기 쉬움 |

---

## 4. 용량·타이밍 

문헌·가이드에서 자주 보는 패턴(개인차 큼):

| 방식 | 내용 |
|------|------|
| 유지 | 하루 **약 3–5 g** 모노하이드레이트 |
| 로딩(선택) | 짧게 고용량 후 유지 — **필수는 아님**. 안 해도 수주 내 저장량 상승 가능 |
| 타이밍 | “운동 직후만”보다 **매일 꾸준히**가 더 중요하다는 견해가 많음 |
| 물 | 평소보다 수분 섭취를 의식하는 사람이 많음 |

체중·신장 기능·의사 지시에 따라 달라질 수 있다. **이 문서가 용량을 처방하지 않는다.**

---

## 5. 기대할 수 있는 것 / 과장

| 비교적 자주 언급 | 과장·오해 |
| ------------------------- | ---------------------------------------------- |
| 고강도·반복 수행, 일부에서 제지방·회복 보조 | 스테로이드·급격한 “약” |
| 일부 인지·채식 관련 연구 관심 | 모든 질병 예방·치료 |
| | “간·신장 무조건 망가짐” (건강인·적정 용량 근거와 동떨어진 공포 마케팅도 많음) |
| | |

**신장 질환·의사 주의 대상**이면 임의로 보충하지 않는 쪽에 가깝다. 
체중 증가(수분)가 초기에 있을 수 있다. 경기 체급 선수는 감안.

---

## 6. 우울·인지·ADHD (연구만)

운동 외에 **뇌 에너지·인지** 연구가 늘고 있다. **치료 대체·자가 처방 근거는 아니다** — [[우울장애]]·[[ADHD]]는 **진료·처방**이 먼저.

### 6.1 [[우울장애]]

| 출처 (방향) | 요약 |
|-------------|------|
| **체계적 문헌고찰·메타분석** (예: *British Journal of Nutrition*, 2025) | 무작위 대조시험 **11건·약 1,100명** — 우울 점수 **소~중간 감소** 가능. **GRADE: 매우 낮음**, 연구 간 편차 큼 |
| **정신질환 RCT 요약** (예: *Canadian Journal of Psychiatry*, 2025) | 주로 **주요우울장애 보조** — SSRI·CBT에 **덧붙였을 때** 도움 **가능성**. 표본 **작음** |
| **임상적 의미** | 평균 효과가 **「뚜렷하게 나았다」** 수준인지는 **논쟁** — **1차·단독 치료 아님** |

```text
항우울제·심리치료 (1차)
 ↓
연구 단계: 크레아틴 보조 요법?
 ↓
의사 없이 임의 복용 X — 양극성 장애 등에서는 조증 위험 논의
```

| 주의 | 설명 |
|------|------|
| **양극성** | 일부 시험·사례에서 **조증·경조증** 보고 — **양극성 스펙트럼**이면 **임의 복용 금지** |
| **보조** | **처방 항우울제·CBT를 대체하지 않음** |

### 6.2 집중·[[ADHD]]·인지

| 출처 (방향) | 요약 |
|-------------|------|
| **소아·청소년 ADHD RCT** (예: *J Psychiatr Res*, 2022) | ADHD 진단 아동·청소년 대상 **무작위 시험 1건** 수준 — **추가 대규모 시험 부족** |
| **성인 인지 메타분석** (예: *Frontiers in Nutrition*, 2024) | RCT **16건·492명**(건강+질환 혼합) — **기억**·**처리 속도**에 **작은** 개선 보고. **실행기능·전체 인지**는 **유의하지 않았던** 분석 |
| **규제·리뷰** | EU **EFSA** 등 — 「크레아틴 → 인지 개선」 **인과 확립 안 됨** 평가도 있음 |
| **ADHD 약** | **흥분제·비흥분제**가 **1차** — 크레아틴으로 **대체 불가** |

| 오해 | 현실 |
|------|------|
| 「집중력 보충제」 | 피로·수면 부족 연구와 **ADHD 치료**를 **혼동**하기 쉬움 |
| 「도파민 올려서 ADHD」 | [[도파민]] 글 참고 — **자가 처방 위험** |

**정리:** 우울·인지 쪽 **논문은 있다**. 효과는 **작고 불균일**하며, **증거 등급은 낮은 편**이다.

---

## 7. 고를 때

1. **주성분 함량** (크레아틴 g, 모노하이드레이트인지) 
2. 첨가 자극제·과당·과대 블렌드 
3. 인증·제3자 테스트(오염·함량) — 스포츠는 도핑 리스트도 
4. 유통기한·보관(습한 곳의 분말 뭉침) 

의약품이 아닌 **건강기능식품·보충제** 규제는 국가·표시마다 다르다.

---

## 8. 생활에서 더 큰 것

1. 수면 
2. 단백질·총 열량·수분 
3. 훈련 프로그램·점진 부하 
4. 질환·약·검진 

갤럭시 워치 등 활동·수면 기록은 **참고용** ([[갤럭시 워치 사용법]]).

---

## 9. 실전 체크

- [ ] 모노하이드레이트, 불필요 블렌드 최소화 
- [ ] 하루 용량·수분 
- [ ] 카페인·다른 보충제와 섞인 “올인원” 라벨 확인 
- [ ] 이상 증상·기존 질환 → 중단·상담 

- [ ] [[우울장애]]·[[ADHD]] 때문에 **인지용**으로 먹기 전 — **진료·처방** 우선, 양극성 병력 있으면 **의사**와 상담

---

## 10. 정리

크레아틴은 고강도 수행 보조로 **연구·실사용이 많은** 보충제다. 
우울·인지 쪽 **보조 연구도 늘지만** 치료 대체가 아니다. 모노하이드레이트·꾸준함이 기본이고, 질환자는 상담한다.

---

## 면책

> **면책** 
> 의료·영양 **진단·처방·섭취 권유가 아니다**. 
> 질병·임신·수유·청소년·신장·약 복용·**양극성 장애 병력** 중이면 사용 전 전문가와 상담한다. 
> 효과·안전성 연구는 사람·용량·제품마다 다르고, 과장 광고가 많다.
