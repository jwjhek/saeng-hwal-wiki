# 아카시지아

> **분류:** 생활·건강 · [[생활위키 목차]]

**아카시지아**(akathisia)는 **안에서부터 들끓는 불안·초조**와 **가만히 있지 못함**이 함께 나타나는 **운동 관련 부작용**·증상군이다. 
의자에 앉아 있어도 다리를 꼬거나 흔들고, 일어서서 걸어 다니고 싶은 **충동**이 강해지는 경우가 많다.

대개 **약물**(특히 **항정신병약·일부 항우울제·진토제**)과 연관된다. 
“성격이 급하다” “불안장애가 심해졌다”와 **같은 말이 아닐 수** 있어, **처방 의사·정신건강의학과**에 바로 말하는 것이 중요하다.

이 글은 **개념·원인·구분·대처 방향**만 정리한다. 약 조절·중단은 **의료진 지시** 없이 하지 않는다.  
관련: [[정신건강]] · [[우울장애]] · [[강박장애]] · [[틱장애]] · 위기면 **1577-0199**.

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 핵심 | **내면의 초조·불편** + **움직여야 한다는 충동** (가만히 있기 어려움) |
| 느낌 | “안에서 들끓는다”, “몸이 가만히 못 있다”, “피부 아래가 간지럽다” 등 **주관적 고통** |
| 겉으로 | 다리 흔들기, 자리 바꾸기, **왔다 갔다 걷기**, 무릎 꿇었다 일어서기 |
| 시점 | 약 **시작·증량 직후** 며칠~몇 주에 자주. **만성**으로 남는 경우도 있음 |
| 위험 | 방치하면 **수면·일상 붕괴**, 증상 악화로 오인되거나 **극단적 생각**까지 이어질 수 있음 — **조기 보고** |

```text
약물(또는 금단 등)
 ↓
내면 초조·불편 (주관)
 ↓
다리·몸을 움직이고 싶은 충동
 ↓
걷기·자세 바꾸기로 잠시 완화 → 다시 반복
```

---

## 2. 흔한 원인 (약물)

| 계열 | 예 (이름 나열이 처방 권유가 아님) |
|------|----------------------------------|
| **항정신병약** | 1·2세대 모두에서 보고. **용량·증량 속도**와 관련 |
| **항우울제** | SSRI·SNRI 등 **일부**에서 드물게 |
| **진토제** | 메토클로프라미드(프리미품 등) **단기 복용**에도 나올 수 있음 |
| **기타** | 일부 기분 안정제·항구역제 등 — **개인차** |
| **금단** | 약을 **갑자기 끊을 때** 비슷한 초조가 나타날 수 있음 |

[[우울장애]]·정신증 치료를 **새로 시작·바꾼 뒤** 몸이 가만히 못 있게 되면, “약이 안 맞는다”만이 아니라 **아카시지아 가능성**을 의사에게 말한다.

---

## 3. 증상 (당사자·주변)

| 구분 | 내용 |
|------|------|
| **주관** | 초조, 불안, 짜증, “몸을 움직이지 않으면 견딜 수 없다” |
| **운동** | 앉아서 다리 흔들기, 손가락 두드리기, **방 안을 맴돌기**, 의자에서 일어났다 앉기 반복 |
| **말** | “못 앉아 있겠다”, “불안해” — **정신 증상 악화**와 헷갈리기 쉬움 |
| **시간** | 낮·저녁에 두드러지는 경우 많음 (사람마다 다름) |

**틱**은 짧고 반복적인 패턴이 튀어나오는 느낌이 강하고, **아카시지아**는 **가만히 있지 못하는 전신적 초조**가 중심인 경우가 많다. 감별은 **의료**.

---

## 4. 무엇과 구분하나

| | 아카시지아 | 비슷해 보이는 것 |
|--|-----------|------------------|
| 초점 | **움직여야 한다**는 충동·초조 | |
| 불안장애 | 겉 움직임보다 **걱정·긴장**이 중심인 경우 많음 | 약 시작 시기·운동 증상을 함께 봄 |
| [[강박장애]] | **사고·확인 행동** 순환 | 몸만 안 가만히인 것과 다를 수 있음 |
| [[틱장애]] | **짧은 반복** 운동·음성 | 어릴 때 시작·틱 전 충동 등 |
| 초조 다리 증후군(RLS) | 주로 **다리** 불편·밤에 악화·움직이면 완화 | 아카시지아는 **전신·낮**에도 두드러질 수 있음 |
| 정신증 악화 | 환각·망상 등 **내용**이 핵심 | 아카시지아만으로 “병이 심해졌다”고 **용량을 올리면** 악화할 수 있음 |
| 초조·초조성 우울 | 기분·에너지 저하와 겹침 | 병력·약물 시점으로 구분 |

인터넷으로 **자가 진단하지 않는다.** “그냥 참자”는 **위험**할 수 있다.

---

## 5. 왜 위험한가

- **고통**이 커서 수면·식사·출근·수업이 깨진다.  
- 의사·가족이 **불안 악화·조현병 악화**로 오해해 **약을 더 올리면** 악화하는 경우가 있다.  
- 극심할 때 **자해·자살 생각**이 생길 수 있다고 보고된다 — **즉시 연락**.  
- **만성 아카시지아**는 약을 줄여도 **오래 남는** 경우가 있어, 초기에 알리는 것이 중요하다.

---

## 6. 대처 (방향만)

| 할 일 | 설명 |
|------|------|
| **처방 의사·정신건강의학과에 바로 연락** | 시작·증량 **시점**, 증상을 **구체적으로** (가만히 못 앉음, 걸어야 함 등) |
| **약을 임의로 끊지 않기** | 금단·원병 악화 위험 — **감량·교체·보조약**은 의료가 결정 |
| **용량 조절·약 변경** | 같은 계열 내 감량, 다른 약으로 **전환** |
| **보조 치료** | 베타차단제(프로프라놀롤 등)·벤조디아제핀류·항콜린제 등이 **선택**되는 경우 — **처방만** |
| **기록** | 약 이름·용량·시작일·증상 시간대를 메모해 진료에 가져가기 |

응급실은 **극심한 초조·자해 위험**이 있을 때. 평소 증상이면 **외래·전화 상담**을 우선한다.

---

## 7. 예방·리스크 (참고)

| 요인 | 메모 |
|------|------|
| **빠른 증량** | 천천히 올리는 편이 리스크를 줄인다는 설명이 많음 |
| **고용량** | 가능한 **최소 유효 용량** |
| **과거 아카시지아** | 같은 계열 재처방 시 주의 |
| **다약제 병용** | 여러 정신과 약·진토제 동시 — 의사·약사에게 **전체 목록** 알리기 |

환자가 “이상하다”고 말하면 **경청**하는 것이 치료의 일부다.

---

## 8. 주변·가족

| 하지 말 것 | 대신 |
|------------|------|
| “예민한 거야”, “의지가 약해” | **약 부작용**일 수 있음을 인정 |
| 약을 **몰래 끊게** 하기 | 의사와 **감량·교체** |
| [[우울장애]]·조현병을 **탓**만 하기 | **증상 시점·약**을 함께 설명 |

---

## 9. 실전 체크

- [ ] **새 약·증량 후** 가만히 앉기·눕기가 **견디기 어려운가**  
- [ ] 다리 흔들기·**걸어 다니기** 충동이 **내면 불편**과 함께 오는가  
- [ ] [[우울장애]]·불안 악화와 **시점**이 겹치는가 — 의사에게 **둘 다** 말할 것  
- [ ] 처방 의사·정신건강의학과 **연락처**를 알아 두었는가  
- [ ] 약을 **임의 중단**하지 않기로 했는가  
- [ ] 극심하거나 자해 생각이 있으면 **1577-0199**·응급실  

---

## 10. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | **내면 초조 + 가만히 못 있는** 운동 증상. 흔히 **약물 부작용** |
| 흔한 약 | 항정신병약, 일부 항우울제, **메토클로프라미드** 등 진토제 |
| 오해 | 불안 악화·병 악화와 **구분** 필요 — 잘못 증량하면 더 나빠질 수 있음 |
| 핵심 | **조기에 처방 의사에게 보고**, 임의로 약 끊지 않기 |

---

## 면책

> **강한 면책**  
> - **진단·치료·약 처방·중단 권유가 아니다.** 약 변경은 **반드시 처방 의사**와 한다.  
> - 아카시지아는 **개인·약물·용량**마다 다르다. 인터넷 정보로 자가 판단하지 않는다.  
> - 극심한 초조·자해·자살 생각이 있으면 **즉시** 응급·위기 상담·가까운 응급실.  
> - 국내 위기 상담 예: **정신건강위기상담전화 1577-0199** (지역·안내는 바뀔 수 있음).
