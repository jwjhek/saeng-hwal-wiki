# 나만의닥터

> **분류:** 생활·건강 · [[생활위키 목차]]

**나만의닥터**(My Doctor)는 **비대면 진료**·**병원 예약**·**약국 찾기**·**의료비·약값 비교**를 묶은 국내 **의료 플랫폼** 앱이다. 
같은 처방·시술이라도 병원마다 **비급여 가격** 차이가 큰 항목에서 **지역별 최저가**를 찾고 예약하는 데 쓰는 경우가 많다.

공식: [https://my-doctor.io](https://my-doctor.io)  
가격 비교: [https://my-doctor.io/medical-cost](https://my-doctor.io/medical-cost)  
iOS·Android 앱 스토어에서 **나만의닥터** 검색

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 환자용 **모바일·웹** 의료 서비스 (운영: 메라키플레이스 등) |
| 핵심 | **비대면 진료** + **최저가 병원** 검색·예약 + **의료비 비교** |
| 대상 | 재진·가벼운 증상, 예방접종, 비급여 시술·검사, 일부 **처방약** 진료·비교 |
| [[삐약]]과 | 삐약은 **맞은 뒤 기록**. 나만의닥터는 **어디서 맞·받을지·얼마인지** 찾기 |

```text
[비용·병원] 나만의닥터 — 가격 비교 · 예약 · 비대면 진료
 ↓
[처방·투약] 병원·약국 (대면·비대면 규정 따름)
 ↓
[일지] [[삐약]] 등 — 주사·체중·농도 추정 기록
```

---

## 2. 주요 기능

| 기능 | 내용 |
|------|------|
| **비대면 진료** | 영상·전화 등으로 의사 진료 (증상·재진·일부 처방 등, 규정·병원 정책 따름) |
| **병원 예약** | 대면·비대면 진료·시술·접종 **예약** |
| **약국 찾기** | 처방 후 **인근 약국** 지도·안내 |
| **의료비 가격 비교** | 비급여·시술·백신·일부 약 **병원별 가격** (§3) |
| **최저가 진료** | [[위고비]]·[[마운자로]]·탈모약·여드름약·백신 등 **항목별** 저가 병원 연결 |
| **건강 콘텐츠** | 증상·질환 안내 (진단 대체 아님) |

메뉴·진료 과목·수수료는 **앱 버전**마다 다르다. 이용 전 **앱 안내**를 본다.

---

## 3. 진료비·약값 **최저가** 비교

나만의닥터의 차별점 중 하나가 **전국 의료기관 가격을 한곳에서 비교**하는 것이다.

### 무엇을 비교하나

| 구분 | 예시 |
|------|------|
| **비급여 진료비** | 치과(임플란트·크라운), 라식·라섹, MRI·MRA, 초음파, 내시경, 상급병실 |
| **예방접종** | 독감, 가다실 9가, 대상포진(싱그릭스 등), 폐렴구균, 소아 백신 |
| **주사·수액** | 감기 수액, 영양 주사 등 병원 **시술비** |
| **처방·진료 패키지** | 탈모약, 여드름약, 일부 **성형·피부·비뇨** 처방 진료비 |
| **비만 치료 주사** | [[위고비]]·[[마운자로]] 등 **진료·처방·약제** 관련 **병원별 안내 가격** |

앱·웹의 **「의료비 가격 비교」** 메뉴에서 **지역·항목**을 고르면 병원별 금액을 나란히 볼 수 있다.

### 데이터 출처·갱신

| 항목 | 설명 |
|------|------|
| **출처** | **건강보험심사평가원(심평원)** 비급여 진료비 정보 등 공개 데이터를 활용한다고 안내 |
| **갱신** | 공개일·병원 제출 시점에 따라 **몇 달 차이** 날 수 있음 |
| **「최저가」** | 비교 목록에서 **가장 낮게 표시된 병원**을 가리키는 경우가 많음. **실결제액 보장**은 아님 |

### 비교할 때 체크

| 확인 | 이유 |
|------|------|
| **진료비 + 약값 + 주사료** | 「최저」가 **진료만**이고 약·재료가 따로일 수 있음 |
| **용량·단계** | 위고비·마운자로는 **mg·단계**마다 가격이 다름 |
| **비대면 vs 대면** | 진료 방식·처방 가능 **약**이 다를 수 있음 (비만 주사 등) |
| **부가 비용** | 검사·상담·재진·배송(약) 등 |
| **예약 시점** | 병원이 **가격 변경**·품절·예약 마감했을 수 있음 |

**방문·예약 전** 앱 표시와 **병원·약국에 최종 확인**하는 편이 안전하다.

### 심평원과의 관계

심평원 **비급여정보공개** 사이트에서도 병원별 가격을 볼 수 있다. 나만의닥터는 그 데이터를 **앱 안에서 필터·예약**까지 이어 주는 **플랫폼**에 가깝다. 공식 원본이 궁금하면 [심평원 비급여정보](https://www.hira.or.kr)도 함께 본다.

## 4. [[위고비]]·[[마운자로]] 등 — 진료·약값 찾기

비만 치료 주사는 **전액 비급여**인 경우가 많아 **병원·약국마다 차이**가 크다. 나만의닥터는 이 항목을 **가격 비교·예약** 카테고리로 내세운다.

| 항목 | 앱에서 하는 일 (일반적) |
|------|-------------------------|
| **가격 비교** | 지역별 **진료·약제** 안내 가격 나열 |
| **최저가 병원** | 비교 후 **예약**·진료 연결 |
| **약국** | 처방 후 **조제**할 약국 찾기 |

### 진료와 앱의 역할

| 구분 | 담당 |
|------|------|
| 처방 가능 여부·용량·적응 | **의사** ([[위고비]]·[[마운자로]] 진료) |
| 어디가 상대적으로 저렴한지 **참고** | 나만의닥터 등 **가격 비교** |
| 맞은 뒤 기록·농도 추정 | [[삐약]] 등 |

**최저가만** 보고 병원을 고르기보다, **진료 품질·재진·응급 대응·설명**도 같이 본다. [[다이어트]] 생활 습관은 약과 **병행**하는 것이 전제인 경우가 많다.

### 비대면·처방 제한

비만 주사·일부 약은 **비대면 처방이 제한**되거나 정책이 바뀐 적이 있다. **당시 법·가이드·병원 정책**을 따른다. 앱에 떠 있다고 **모든 방식으로 처방**된다는 뜻은 아니다.

## 5. 다른 서비스와 비교

| | 나만의닥터 | [[삐약]] | 심평원 비급여 사이트 |
|--|------------|----------|----------------------|
| 목적 | 예약·진료·**최저가 찾기** | **투약·체중 일지** | 공공 **가격 정보** |
| 진료 | **연결** | 없음 | 없음 |
| 위고비·마운자로 | **가격·예약** | **기록·농도 추정** | 병원별 비급여 표 |
| 커뮤니티 | 제한적·콘텐츠 | **후기 중심** | 없음 |

[[실손보험]]은 **낸 뒤** 영수증으로 청구하는 층이고, 나만의닥터는 **낼 가격을 미리 비교**하는 층에 가깝다. 비급여 비만 주사는 **실손 보장 범위 밖**인 경우가 많다 ([[보험 기초]]·[[실손보험]]).

## 6. 이용 시 주의

| 주제 | 내용 |
|------|------|
| **진단** | 앱·비대면은 **응급 대체 아님**. 심한 증상은 119·응급실 |
| **가격** | 표시는 **참고·평균·제출가**일 수 있음. **최종 영수증**이 기준 |
| **광고·순위** | 제휴·프로모션 병원이 **눈에 띄게** 노출될 수 있음. 비교 표 전체를 본다 |
| **개인정보** | 진료·결제·위치 **민감**. 계정·권한 설정 확인 |
| **불법 처방** | SNS **대리처방**·해외 직구와 병행하지 않음 |
| **면책** | 플랫폼은 **의료기관이 아님**. 진료 책임은 **의사·병원** |

---

## 면책

> **강한 면책**  
> 나만의닥터는 **의료기관·약국이 아닌** 중개·정보·예약 플랫폼이다.  
> **최저가·가격 비교**는 정보 참고용이며, 실제 청구액·보험 적용·처방 여부를 **보장하지 않는다**.  
> [[위고비]]·[[마운자로]] 등은 **전문의 처방** 약이다. 가격만 보고 **자가 투여·용량 변경**하지 않는다.  
> 비급여·비대면 규정은 **법령·심평원·병원** 기준이 우선이다.  
> 메뉴·가격·제휴 병원은 **수시로 변경**된다.
