# ADHD

> **분류:** 생활·건강 · [[생활위키 목차]]

**ADHD**(주의력결핍 과잉행동 장애, attention-deficit/hyperactivity disorder)는 **주의력·충동·과잉행동**이 **어린 시기부터** 나타나 **여러 환경**에서 **기능을 깨는** 신경발달 장애다.

「산만한 성격」「게으름」과 **같은 말이 아니다.** 이 글은 **개념·일상과 구분·도움 방향**만 정리한다. 진단·치료는 **소아청소년과·정신건강의학과**에 맡긴다.

확인일: 2026-08-13

관련: [[정신건강]] · [[틱장애]] · [[도파민]] · [[노르에피네프린]] · 위기면 **1577-0199**

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| **핵심** | **부주의**·**과잉행동·충동**이 **지속**되고, 학교·직장·관계·안전 등에 **실질적 지장** |
| **시작** | 증상이 **어릴 때**(보통 **12세 전**)부터 있었던 패턴 — **성인에 처음 진단**되는 경우도 많음 |
| **유형 (개념)** | **부주의형** · **과잉·충동형** · **혼합형** — 사람마다 **조합·강도**가 다름 |
| **흔한 동반** | [[불면증]]·불안·[[우울장애]]·[[틱장애]]·[[강박장애]]·학습 문제 등 — **함께** 평가 |

```text
어린 시기부터의 주의·충동·과잉행동 패턴
 ↓
여러 상황(집·학교·직장)에서 기능 저하
 ↓
다른 질환·수면·스트레스와 구분 (의료)
 ↓
필요 시 약·심리·생활·편의 조정
```

---

## 2. 세 가지 축 (증상 예)

의사는 **기간·빈도·환경·기능**을 함께 본다. 아래는 **참고용**이며 체크리스트로 **자가 진단하지 않는다.**

### 2.1 부주의 (inattention)

| 예 | 설명 |
|----|------|
| **시작·마무리** | 과제·일을 **시작하기 어렵고** 끝까지 **못 가는** 경우 |
| **세부 놓침** | 실수·깜빡함이 **반복**되어 성적·업무에 영향 |
| **듣기·지시** | 말을 **안 듣는 것처럼** 보이거나 지시를 **따르기 어려움** |
| **정리·시간** | 물건·일정 **관리 실패**, 마감·약속 **자주 늦음** |
| **쉽게 산만** | **관심 있는 일**에도 외부 자극·생각에 **끊기는** 느낌 |

### 2.2 과잉행동·충동 (hyperactivity / impulsivity)

| 예 | 설명 |
|----|------|
| **가만히 있기** | 앉아 있기 **불편**, 손·발 **움직임** |
| **끼어들기** | 대화·게임에 **끼어들거나** 차례 **기다리기 어려움** |
| **충동** | 생각보다 **먼저 말·행동** — 후회하는 패턴 |
| **안절부절** | 안에서 **에너지가 넘치는** 느낌 (성인은 **내적 초조**로 보이기도) |

**성인**은 뛰어다니기보다 **안절부절·충동 구매·운전·관계** 문제가 두드러지는 경우가 많다.

---

## 3. 일상적 산만함과의 차이

| 비교적 일상 | 도움이 필요할 수 있는 쪽 |
|-------------|--------------------------|
| 가끔 집중 안 됨 | **여러 해** 비슷한 패턴, **여러 환경**에서 반복 |
| 관심 없는 과목·일만 힘듦 | **좋아하는 일**에도 시작·유지가 **어려움** |
| 피곤·스트레스 한때 | [[불면증]]·우울 등 **다른 원인** 배제 후에도 **지속** |
| 「게으름」이라 불림 | **노력해도** 체계·시간 관리가 **막히는** 느낌 |
| SNS에서 ADHD 테스트 | **인터넷 검사**로 확정 **불가** — 임상 면담·병력 |

「요즘 다 ADHD」처럼 **가볍게 붙이는 말**은 진짜로 고통받는 사람의 **도움을 가리기** 쉽다.

## 4. 무엇과 헷갈리나

| | ADHD | 비슷해 보이는 것 |
|--|------|------------------|
| **집중** | **오래·여러 곳**에서 패턴 | 일시 피로·[[불면증]]·카페인 과다 |
| **충동** | **반복**되는 충동 조절 어려움 | 청소년기·일시적 스트레스 |
| **과잉행동** | **발달 수준** 대비 과함 | 활발한 성격만으로는 **기능 저하** 설명이 안 될 때 의심 |
| **틱** | **동반** 가능 | [[틱장애]]는 **갑작스러운** 운동·음성 틱이 중심 — **감별은 의료** |
| **강박** | **동반** 가능 | [[강박장애]]는 **사고·확인 행동 순환**이 중심 |
| **우울·불안** | **동반·가림** | 집중 저하만 ADHD로 단정 **금지** — [[우울장애]] |
| **MBTI** | **진단 아님** | [[MBTI]] P형·E형과 **1:1 대응 안 됨** |

갑상선·빈혈·수면 무호흡·약물·알코올 등 **몸 질환**이 집중을 깨뜨리는 경우도 있다 → **검사는 의료**.

---

## 5. 왜 생기나 (알려진 것만)

| 요인 | 설명 |
|------|------|
| **유전·뇌 발달** | 가족력이 있는 경우 **많음** — **뇌 주의·실행 기능 회로** 차이 모델 |
| **신경전달물질** | [[도파민]]·[[노르에피네프린]] **주의·동기** 회로와 **연구** — **단일 원인 아님** |
| **환경** | **스트레스·가정·학대**가 **만든다**기보다, **악화·가림** 요인으로 논의 |
| **스크린·설탕** | 「스마트폰 때문에 ADHD」 — **인과**로 단정하기 **어렵음**. 증상 **악화** 요인일 수는 있음 |

「의지 부족·부모 탓」으로 돌리면 **치료·적응만** 어려워진다.

---

## 6. 진단 (방향만)

의사·임상심리가 **병력·증상·기능·동반 질환**을 묻고, 필요 시 **학교·직장** 정보나 **검사**를 쓴다.

| 확인할 것 | 이유 |
|-----------|------|
| **어린 시기** 증상 | ADHD는 **발달 초**부터의 패턴 |
| **여러 환경** | 집만·회사만이 아니라 **넓게** 지장 |
| **기능 저하** | 성적·업무·관계·안전 |
| **동반** | [[틱장애]]·불안·우울·학습장애 등 |
| **다른 원인 배제** | 수면·갑상선·약물·우울 등 |

**성인**은 어릴 때 **기록이 없거나** 「그냥 덜렁대는 아이」로 넘어간 경우가 많아 **면담**이 길어질 수 있다.

---

## 7. 치료·관리 (방향만)

| 방향 | 설명 |
|------|------|
| **약물** | **흥분제**(메틸페니데이트·암페타민 계열)가 **1차**로 쓰이는 경우 많음 — **도파민·노르에피네프린** 신호 조절. **비흥분제**(아토목세틴·관찰신·클로니딘 등)도 있음 |
| **역설적 반응** | 흥분제인데 **진정·집중**되는 것처럼 보이는 이유는 **뇌 보상·주의 회로** 조절 때문 — **남의 약** 복용 **금지** |
| **심리·행동** | **CBT**, 시간 관리·실행 기능 훈련, **부모·교사** 교육 (아동) |
| **생활** | [[불면증]] 치료, 규칙적 수면·운동 — **보조**이지 단독 치료 대체 아님 |
| **학교·직장** | **시험 시간 연장·자리·업무 분할** 등 **합리적 편의** — 규정·진단서에 따름 |

약 **용량·종류·휴약**은 **처방 의사**만. 심박·식욕·수면·기분 변화는 **정기 추적**.

### 7.1 보충제 ([[크레아틴]]·[[포스파티딜세린]] 등)

| 주장 | 현실 |
|------|------|
| 「뇌 영양제로 ADHD」 | **1차 치료 아님** — 흥분제·비흥분제·CBT가 **표준** |
| **[[포스파티딜세린]]** | 소아 **부주의**에 **작은** 효과 **일부** 보고 — **증거 낮음**, PS+[[오메가3]] 제품 혼재 — [[포스파티딜세린]] §3.2 |
| **[[크레아틴]]** | 소아 ADHD **RCT 1건** 수준, 성인 ADHD **대규모 시험 부족** — [[크레아틴]] §6.2 |
| **집중력 마케팅** | [[불면증]]·[[우울장애]]·수면 부족과 **감별** — 보충제만으로 **약 대체 금지** |

의사·약사 없이 **흥분제를 끊고** 보충제만 쓰지 않는다.

---

## 8. 학교·직장·대인관계

| 상황 | 참고 |
|------|------|
| **수업·회의** | 끊기기 쉬움 — **노트·타이머·자리** 등 개인 맞춤 |
| **마감** | 시작이 어려워 **막바지 몰아치기** 패턴 — 구조·알림이 도움 될 수 있음 |
| **비난** | 「공부 안 해」「태도 문제」만으로 설명되기 쉬움 — **평가** 후 지원 |
| **주변** | ADHD를 **변명·밈**으로 쓰지 않기 — 당사자 **수치·낙인** |

법적 **장애인 등록·편의**는 국가·기관 규정·개인 선택에 따른다.

## 9. 흔한 오해

| 오해 | 현실 |
|------|------|
| **ADHD = 똑똑한 아이만** | 지능과 **무관** — IQ 높아도 **실행 기능**은 어려울 수 있음 |
| **여자는 잘 안 걸림** | **부주의형**은 **늦게**·**놓치기** 쉬움 — 성별 편향 주의 |
| **성인 ADHD는 사후 꾸밈** | 어릴 때 **미진단**·증상 **변형**이 흔함 — **의료 평가** 필요 |
| **흥분제 = 약물 남용** | **처방·감시** 하에 **치료** — 타인 약·과다 복용은 **위험** |
| **[[도파민]]만 올리면 됨** | [[보충제]]·L-도파 등 **대체 불가** — [[도파민]] 글 참고 |
| **보충제 = ADHD 치료** | [[크레아틴]]·[[포스파티딜세린]] **연구만** — §7.1, **1차 치료 아님** |
| **MBTI P = ADHD** | [[MBTI]]는 **성격 프레임** — 진단 **아님** |
| **숏폼 보다 ADHD** | 집중력 저하는 **여러 원인** — 자가 라벨 **주의** |

## 10. 실전 체크 (당사자·보호자)

- [ ] 어릴 때부터 **비슷한** 주의·충동·과잉행동이 **여러 환경**에서 반복되는가  
- [ ] 학업·직장·관계·안전에 **실질적 지장**이 있는가  
- [ ] [[불면증]]·우울·불안·[[틱장애]]가 **같이** 있으면 **함께** 말할 것  
- [ ] 인터넷 테스트·SNS **자가 진단** 대신 **소아청소년과·정신건강의학과** 경로를 알아 두었는가  
- [ ] 약은 **본인 처방**만 — 타인 흥분제 **복용 금지**  
- [ ] 위기(자해·극단적 생각) 시 **1577-0199**·응급실

## 11. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | **주의·충동·과잉행동**이 어릴 때부터 **지속**되고 **기능을 깨는** 신경발달 장애 |
| 유형 | 부주의·과잉·충동·혼합 — **성인**은 표현이 다를 수 있음 |
| 겹침 | [[틱장애]]·[[강박장애]]·불안·[[우울장애]] **동반** 흔함 |
| 치료 | **약물·심리·생활·편의** 조합 — **의료 판단** |
| 핵심 | 게으름·성격 **아님** — 자가 진단·낙인 없이 **전문 평가** |

## 면책

> **강한 면책**
> - **진단·치료·약 처방 권유가 아니다.**
> - ADHD는 **개인차가 크다.** 인터넷 검사·체크리스트로 **자가 진단하지 않는다.
> - 흥분제·비흥분제는 **처방·감시**가 필요하다. **타인 약**·과다 복용 **금지**.
> - 증상이 길어지거나 동반 불안·우울·틱이 있으면 **소아청소년과·정신건강의학과**를 우선한다.
> - 위기(자해·자살 생각 등)면 즉시 응급·위기 전화·가까운 응급실.
> - 국내 위기 상담 예: **정신건강위기상담전화 1577-0199** (지역·안내는 바뀔 수 있음).
