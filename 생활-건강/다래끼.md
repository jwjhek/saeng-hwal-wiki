# 다래끼

> **분류:** 생활·건강 · [[생활위키 목차]]

**다래끼**는 눈꺼풀 분비샘(기름샘·땀샘 등)에 **염증·감염**이 생겨 붓고 아픈 덩어리가 나는 흔한 눈 질환이다. 
영어권에서는 **hordeolum**(맥립종) 등으로 부르기도 한다. 
**콩다래끼**(chalazion, 산립종)는 이름이 비슷하지만 **원인·경과·치료**가 다르다.

이 글은 **개념·집에서 할 수 있는 관리·진료 시점**만 정리하며, 진단·처방은 하지 않는다.

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 눈꺼풀 **분비샘** 주변의 급성 염증. 대개 **포도상구균** 감염이 겹침 |
| 흔한 증상 | 눈꺼풀 **붓기·발적·압통**, 이물감, 눈물·끈적임, 가려움 |
| 경과 | 가벼우면 **수일~1~2주**에 호전되는 경우가 많음. 재발도 흔함 |
| 전염 | 눈을 비비거나 손·도구로 옮기면 **같은 사람·주변에 반복**될 수 있음 |
| 헷갈리기 쉬운 것 | **콩다래끼** — 막힌 기름이 쌓인 **만성 결절**. 통증이 적은 편 |

“눈이 붓었다”만으로 다래끼라고 단정하지 않는다. **알레르기·결막염·다른 안검 질환**과 겹칠 수 있다.

---

## 2. 종류

눈꺼풀에는 **짜이스샘**, **몰샘**, **마이봄샘** 등 분비샘이 있다. 어디에 생기느냐에 따라 이름이 갈린다.

| 종류 | 위치·특징 | 흔한 양상 |
|------|-----------|-----------|
| **겉다래끼** | 눈꺼풀 **바깥** 표면 쪽 (짜이스·몰샘 등) | 속눈썹 줄기 쪽 **빨간 덩어리**, 통증·부기 |
| **속다래끼** | 눈꺼풀 **안쪽** 막 쪽 (마이봄샘 급성 감염) | 눈을 뒤집으면 **빨간 부위·농점**이 보일 수 있음 |
| **콩다래끼** (산립종) | 마이봄샘 **만성** 막힘·육아종 | **통증 적은 단단한 알갱이**. 시간이 길어질 수 있음 |

```text
분비샘 막힘·기름 축적
 ↓
(세균 감염이 겹치면) 겉·속다래끼 — 급성, 아픔·붓기
 ↓
(감염 없이 만성화) 콩다래끼 — 단단한 결절, 통증 적음
```

---

## 3. 원인·위험 요인

원인은 하나로만 설명되지 않는다. **막힘 + 세균 + 습관**이 겹치는 경우가 많다.

| 요인 | 설명 |
|------|------|
| 세균 | **포도상구균** 등. 피부·손에 흔한 균이 눈꺼풀로 옮겨짐 |
| 분비샘 막힘 | 마이봄샘 기름이 잘 안 빠지면 염증·콩다래끼로 이어지기 쉬움 |
| 눈 비비기·손 위생 | 같은 손으로 얼굴·렌즈·화장을 만지면 **재발·양쪽** 가능 |
| 렌즈·화장품 | 오래 착용, 세척 부실, 밤에 안 지우기 |
| 피로·스트레스·면역 저하 | “갑자기 잘 걸린다”는 경험과 겹치기도 |
| 피부 질환 | 안면 습진·아토피·이전 다래끼 병력 |

---

## 4. 어떻게 보이나

```text
전조(눈꺼풀 당김·이물감·살짝 붓기)
 ↓
붉고 아픈 덩어리 (겉·속다래끼)
 ↓
고름이 차거나 피부·결막 쪽으로 배출 → 통증 감소·호전
 (또는 안과 치료 후 호전)
```

| 단계 | 일상에서 |
|------|----------|
| 초기 | 눈꺼풀 한쪽이 **욱신**거리고, 눌렀을 때 아픔 |
| 진행 | **빨갛게 부음**, 눈을 감을 때 걸리는 느낌, 눈물 |
| 호전 | 덩어리가 **작아지거나** 고름이 빠지며 나아짐 |
| 만성·재발 | 같은 자리·양쪽이 반복 → **습관·안검염** 점검 |

콩다래끼는 **통증이 적고** 오래 가는 **단단한 혹**처럼 느껴지는 경우가 많다.

---

## 5. 콩다래끼와 구분

| | 겉·속다래끼 | 콩다래끼 |
|--|-------------|----------|
| 성격 | **급성** 화농성 염증 | **만성** 육아종·막힘 |
| 통증 | 흔함 | 대체로 적음 |
| 붉기·부기 | 뚜렷한 편 | 덜하거나 없음 |
| 기간 | 보통 **수일~2주** 안에 호전 | **수주~수개월** 지속 가능 |
| 집 관리 | 찜질·위생. 필요 시 **항생제 안약** 등 | 온찜질·경과 관찰. 크면 **시술** 논의 |

콩다래끼에 **상처·감염**이 겹치면 속다래끼처럼 아파질 수 있다. **스스로 종류를 확정하지 말 것.**

---

## 6. 집에서 할 수 있는 것

진료를 대체하지 않는다. **초기·경증**에서 많이 쓰는 방법이다.

### 6.1 찜질 — 온찜질과 냉찜질

| 상황 | 방향 |
|------|------|
| **막 붓고 빨갛고 아플 때** (급성 초기) | **냉찜질**로 통증·부기 진정 (짧게, 피부 보호) |
| **덩어리가 단단해지고** 배출이 필요할 때 | **온찜질** — 하루 **3~4회**, **10~15분** (너무 뜨겁지 않게) |
| **콩다래끼** | **온찜질**이 더 자주 권장되는 편 (막힌 기름 배출) |

온찜질 예: 깨끗한 수건을 미지근하게 적시거나, 전용 온찜질팩·라벤더백 등을 **눈꺼풀 위**에 올린다. 
**직접 눈에 뜨거운 물**을 붓지 않는다.

### 6.2 눈꺼풀 위생

- 온찜질 후 **깨끗한 면봉·거즈**로 속눈썹 **가장자리**를 부드럽게 닦기 
- 시중 **눈꺼풀 세정액**·의사가 권한 **안연고**가 있으면 설명대로 
- **렌즈·화장은** 증상 있는 동안 쉬는 편이 낫다 (의사·약사와 확인)

### 6.3 하지 말 것

| 금지 | 이유 |
|------|------|
| **손·면봉으로 짜기** | 2차 감염·흉터·안와 감염 위험 |
| **강한 화장품·향료** 눈꺼풀에 바르기 | 자극·악화 |
| **남의 안약·스테로이드 연고** 임의 사용 | 부작용·오진 |
| **오래된 렌즈·솔루션** 계속 사용 | 재발 |

---

## 7. 진료·치료에서 나오는 말

| 방향 | 설명 |
|------|------|
| 진단 | 병력·육안 진찰. 필요 시 눈꺼풀 뒤집기·세균 검사 등 |
| 보존 | **온찜질**, 눈꺼풀 세정, 렌즈·화장 중단 |
| 약 | **항생제 안약·안연고** (경구 항생제는 중증·확산 시 등) |
| 배농 | 농이 차도 스스로 안 빠지면 **절개 배농** |
| 콩다래끼 | 작고 무증상이면 관찴. 크거나 불편하면 **절개·긁어내기**, **스테로이드 국소 주사** 등 |
| 만성·반복 | **안검염·마이봄샘 기능 이상** 치료, 생활 습관 교정 |

안과·응급에서 “그냥 두면 된다”고 해도, **통증·시야·확산**이 있으면 기다리지 않는다.

---

## 8. 예방·습관

| 해보기 쉬운 것 | 메모 |
|----------------|------|
| 손 씻기 후 눈·렌즈 만지기 | 다래끼 **재발** 예방에 자주 거론 |
| 화장 **밤에 제거**, 눈 쪽 공유 도구 금지 | 마스카라·아이라이너 브러시 위생 |
| 렌즈 **착용 시간·세척** 지키기 | 불편하면 착용 중단 후 안과 |
| 눈 비비지 않기 | 알레르기·건조와도 연결 |
| 피로·수면·전반 건강 관리 | 면역·스트레스 축과 겹치기도 |

한 번 나았다고 **습관을 그대로** 두면 같은 부위에 다시 생기기 쉽다.

---

## 9. 멈추고 진료를 서두를 때

- **시야가 흐려지거나** 눈을 뜨기 어려울 정도로 붓기 
- **눈 주변 전체**가 붓고, **열·심한 통증** 
- **48~72시간** 이상 악화되거나, 집 관리 후에도 **호전 없음** 
- **콩다래끼**가 커지거나 시야를 가림 
- **소아·임산부·당뇨·면역저하** — 자가 약·짜기 금지, **빨리 진료** 
- 붉은 줄이 얼굴 쪽으로 퍼지는 느낌, **안와·얼굴 감염** 의심 (응급)

눈은 감염이 **주변 조직**으로 번지면 위험해질 수 있다. “집에서 짜면 빨리 낫는다”는 설은 **피한다.**

---

## 10. 실전 체크

- [ ] 겉·속다래끼와 **콩다래끼**를 구분하려 **안과**를 보는가 
- [ ] 급성 통증에는 **냉찜질**, 배출 단계에는 **온찜질**을 쓰는가 
- [ ] **손으로 짜지 않는가** 
- [ ] 렌즈·화장·눈 비비기를 **잠시 끊는가** 
- [ ] 남의 안약·강한 연고를 **쓰지 않는가** 
- [ ] 시야 이상·전체 부기·열이 있으면 **기다리지 않는가** 

---

## 11. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 눈꺼풀 분비샘의 급성 염증·감염 (겉·속다래끼) |
| 구분 | **콩다래끼**는 막힌 기름의 만성 결절 — 치료·경과가 다름 |
| 집 관리 | 위생, 단계에 맞는 **찜질**, 짜지 않기 |
| 진료 | 악화·시야 문제·반복 시 **안과** |
| 예방 | 손·렌즈·화장 위생, 눈 비비기 줄이기 |

---

## 면책

> **강한 면책**  
> - **진단·치료·약 처방·시술 권유가 아니다.**  
> - 눈꺼풀 붓기는 **다래끼·콩다래끼·알레르기·결막염·안검염·감염** 등과 겹칠 수 있다. **안과 진료**가 우선이다.  
> - 안약·안연고·항생제·스테로이드 주사는 **의사 지시**만. 임의 사용·장기 사용 금지.  
> - 다래끼를 **손으로 짜면** 2차 감염·흉터·안와 감염 위험이 있다.  
> - 시야 변화·심한 부기·열·확산 의심 시 **응급·안과**를 늦추지 않는다.
