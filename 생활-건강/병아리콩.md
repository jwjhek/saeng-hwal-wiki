# 병아리콩

> **분류:** 생활·건강 · [[생활위키 목차]]

**병아리콩(chickpea, garbanzo)** 은 콩류로, hummus·샐러드·카레·스낵에 자주 쓰인다. 
감량 식단에서는 **단백질·식이섬유·포만** 때문에 [[다이어트 추천 음식]]에 자주 올라온다.

확인일: 2026-08-07

관련: [[다이어트 추천 음식]] · [[요리]] · [[다이어트]] · [[계란]] · [[방울토마토]] · [[오이]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 둥글고 베이지색인 콩. 건조·통조림·삶은 제품 |
| 다이어트에서 | 부피·섬유·식물성 단백질 → 포만에 도움되는 집이 많음 |
| 탄수 | 콩이라 **탄수화물도 있음**. 초저탄·케토와는 양 조절 |
| 주의 | 통조림 **나트륨**, 과식 시 가스·더부룩함, 튀김·당 코팅 스낵 |

---

## 2. [[다이어트]]와

| | 설명 |
|--|------|
| 장점 | 고기만으로 단백질을 채우기 어려울 때, 샐러드·밥 반찬에 섞기 쉬움 |
| 조합 | [[방울토마토]]·[[오이]]·간단 드레싱 · 또는 [[계란]]과 한 접시 |
| 함정 | 기름에 잔뜩 볶기, hummus를 빵·칩과 무한, “건강하니까” 대접시 |
| 방법 | 저탄이면 양↓ · 채식 감량이면 활용↑ → [[다이어트]] §3 |

원푸드로 병아리콩만 먹는 식은 [[다이어트]]에서 말하는 극단과 같다. 비추천.

---

## 3. 고르는 법 · 먹는 법

| 형태 | 설명 |
|------|------|
| 건조콩 | 불림·삶기. 염분 조절 쉬움. 시간 필요 |
| 통조림 | 편의. **물로 헹구면** 염분·거품 성분 일부↓ |
| 삶은 냉장 | 바로 샐러드 |
| hummus | 재료·오일·첨가 확인. 한 스푼 단위 |

| 활용 | 예 |
|------|-----|
| 샐러드 | 콩 + 토마토 + 오이 |
| 따뜻한 요리 | 카레·조림·수프 (오일·크림 양) |
| 간식 | 오븐에 바삭 (시판 튀김·가당은 라벨) |

---

## 4. 주의

- 갑작스러운 다량 → 가스·복통 
- 통조림 염분 · 혈압·신장 이슈 시 라벨 
- 알레르기(콩·레시틴 등 제품) 
- 칼로리는 “다이어트 식품”이라도 **양**이 좌우 

---

## 5. 실전 체크

- [ ] 통조림이면 염분·헹굼을 봤는가 
- [ ] 한 끼에 채소([[오이]]·[[방울토마토]])와 같이 가는가 
- [ ] 저탄을 엄격히 하면 양을 조절하는가 
- [ ] 허브: [[다이어트 추천 음식]] · 틀: [[다이어트]] 

---

## 6. 정리

병아리콩은 **포만·식물성 단백질용으로 쓰기 좋은 콩**이다. 
마법이 아니라 [[다이어트 추천 음식]]의 한 칸이다.
