# 불면증

> **분류:** 생활·건강 · [[생활위키 목차]]

**불면증**(insomnia)은 **잠들기 어렵거나**, **자주 깨거나**, **너무 일찍 깨서** 낮에 피로·집중 저하·기분 문제가 이어지는 **수면 장애**다. 
가끔 밤을 새우는 것과 **만성 불면**은 다르다.

이 글은 **개념·원인·대처 방향**만 정리한다. **진단·치료·수면제 권유가 아니다.**  
관련: [[정신건강]] · [[우울장애]] · 위기면 **1577-0199** · **109**

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 핵심 | **수면의 양·질**이 기대에 못 미치고, **낮 기능**에 영향 |
| 흔한 형태 | 잠들기 어려움 · 밤중 각성 · 새벽 일찍 깸 · **피곤한데 잠이 얕음** |
| 기간 | 며칠~몇 주(**단기**) vs **수개월 이상 반복**(**만성**) |
| 겹치는 것 | [[우울장애]]·불안·스트레스·[[노르에피네프린]] 과각성·다른 **수면 질환** |

```text
밤: 잠들기/유지 어려움
 ↓
낮: 피로·집중↓·짜증·운전 위험
 ↓
밤: 「오늘은 꼭 자야 해」 불안 → 악화 (악순환)
```

---

## 2. 종류 (느낌 기준)

의료 분류는 세부 진단명이 있으나, 일상에서는 아래처럼 나눠 말한다.

| 형태 | 설명 |
|------|------|
| **입면 불면** | 누워도 **30분~1시간 넘게** 잠들지 못함 |
| **유지 불면** | 자주 깸, 다시 잠들기 어려움 |
| **조기 각성** | 목표보다 **몇 시간 일찍** 깨고 재취침 실패 |
| **비질적 수면** | 시간은 있는데 **개운하지 않음** |

한 사람에게 **여러 형태가 겹칠** 수 있다.

---

## 3. 가끔 vs 도움이 필요할 때

| 가끔 있는 밤 | 불면증으로 볼 여지 (의료 판단) |
|--------------|-------------------------------|
| 시험·여행·스트레스 **며칠** | **주 3회 이상** 수준으로 **수주~수개월** |
| 낮에 **대체로 견딤** | 낮 **졸림·실수·기분**이 일상을 깨뜨림 |
| 원인 사라지면 회복 | 침대에 **오래 누워도** 잠이 안 옴 |
| | **수면제 없이는** 견디기 어렵다고 느낌 |

**「몇 시간 자야 한다」** 숫자만 맞추는 것보다 **낮 기능**이 더 중요한 기준인 경우가 많다. 
정확한 기준·검사는 **의사·수면 전문** 영역이다.

---

## 4. 흔한 원인

| 분류 | 예 |
|------|-----|
| **심리** | 스트레스·걱정·[[우울장애]]·불안·트라우마 |
| **생활** | 불규칙한 취침·낮잠·카페인·알코올·늦은 식사·운동 |
| **환경** | 빛·소음·더위·스마트폰·침실이 **일·TV 공간**과 겹침 |
| **질환** | **수면무호흡**(코골이·숨 멈춤), 하지불안증후군, 통증·갑상선·위산 역류 등 |
| **약·물질** | 스테로이드·일부 항우울제·흥분제·[[항히스타민]](각성형)·카페인·술 |
| **교대·시차** | 근무·비행으로 **생체 리듬** 깨짐 |

**한 가지 원인만**인 경우는 드물다. 불면이 **오래가면** 우울·불안과 **서로 키우는** 경우도 많다.

---

## 5. 다른 수면 문제와

| 질환·현상 | 불면과 구분 포인트 |
|-----------|-------------------|
| **수면무호흡** | 큰 코골·숨 멈춤 목격·아침 두통·낮 극심한 졸림 → **수면다원검사** 논의 |
| **하지불안** | 잠들기 전 **다리 불편·움직여야 함** |
| **일주기 리듬 장애** | **극심한 올빼미형**·교대근무 — 취침 위생만으로 안 될 수 있음 |
| **과다수면** | 낮에도 잠 — 불면과 **다른 평가** |
| **[[아카시지아]]** | 약 시작 후 **가만히 못 있음** — 불면과 혼동 가능, **의사 보고** |

워치·앱 수면 점수는 **참고**일 뿐 **진단 도구가 아니다** ([[갤럭시 워치 사용법]] 면책과 같음).

---

## 6. 대처 방향 (개요)

### 6.1 1순위: 인지행동치료 for 불면 (CBT-I)

만성 불면에서 **근거가 가장 탄탄한 비약물 치료**로 알려진 접근이다.

| 요소 (개념) | 내용 |
|-------------|------|
| **자극 조절** | 침대는 **잠·성**만 — 깨어 있으면 일어나기 |
| **수면 제한** | 실제 잠 시간에 맞춰 **침대에 있는 시간** 조절 (전문가 지도) |
| **인지** | 「8시간 못 자면 망한다」 같은 **불안 생각** 다루기 |
| **이완·교육** | 호흡·근이완, 수면에 대한 오해 바로잡기 |

병원·수면 클리닉·앱·온라인 프로그램으로 제공된다. **혼자 무리한 수면 제한**은 역효과일 수 있다.

### 6.2 수면 위생 (보조)

CBT-I **대체가 아니라** 함께 쓰는 **기본 습관**이다.

| 할 것 | 피할 것 |
|-------|---------|
| **같은 시간**에 일어나기 (주말도 비슷하게) | 낮 **긴 낮잠** (필요하면 20분 전후) |
| 아침 **햇빛**·가벼운 활동 | 오후 늦은 **카페인** |
| 침실 **어둡고 시원하게** | 잠들기 전 **스마트폰·격한 뉴스** |
| 잠 안 오면 **20분 뒤 다른 방**에서 책 등 | 침대에서 **시계만 보기** |
| [[다이어트]]처럼 **규칙적 운동** (너무 늦은 고강도는 주의) | 잠들기 위해 **술** — 초반엔 졸리게 하다 **새벽 각성** |

### 6.3 약물 (방향만)

| 참고 | |
|------|--|
| **단기** | 급한 상황에 **의사가** 수면제를 쓸 수 있음 — **장기 의존 주의** |
| **만성** | CBT-I와 **병행** 논의. 약만으로 **근본 습관**이 안 바뀌는 경우 많음 |
| **멜라토닌** | 시차·리듬 문제에 **도움 될 수** 있음 — 만능 아님, 용량·시간은 전문가 |
| **OTC 수면제** | 졸음·다음날 후유증·약물 상호작용 — **임의 장기 복용 비권장** |

**타인 수면제·처방전 공유 금지.** [[우울장애]] 약과 **겹치면** 부작용·각성이 달라질 수 있다.

## 7. 진료·검사 (언제 보나)

| 신호 | |
|------|--|
| **1개월 이상** 주당 여러 번, 낮 기능 저하 | 내과·정신건강의학과·수면 클리닉 |
| **코골·숨 멈춤**·비만·목둘레 큼 | 수면무호흡 **스크리닝** |
| 다리 불편·움직임 | 하지불안 등 |
| 우울·불안·자살 생각 동반 | [[우울장애]]·[[정신건강]] — **우선 상담** |
| 수면제 **증량·다약제**에 의존 | **의사와 감량·대체** 계획 |

검사 예: 수면 일기, 설문, 필요 시 **수면다원검사**(병원 1박).

## 8. 흔한 오해

| 오해 | 현실 |
|------|------|
| 8시간 못 자면 불면 | **개인·나이**마다 필요 수면 다름 — **낮 기능**이 핵심 |
| 침대에 누워 있으면 결국 잠듦 | 누워만 있으면 **침대=각성** 조건화 |
| 술 한 잔이 수면제 | **수면 질 저하**·새벽 각성 |
| 수면제를 매일 먹어야 정상 | **단기 보조**인 경우 많음 — CBT-I·원인 치료 병행 |
| 피곤하면 낮잠 | 만성 불면에 **긴 낮잠**은 밤을 깨뜨릴 수 있음 |
| 워치 점수 100점이 목표 | **착용 오차** 큼 — 증상과 다를 수 있음 |

## 9. 실전 체크리스트

- [ ] **1~2주 수면 일기** (취침·각성·낮 졸림·카페인·술)  
- [ ] 침실 **어둡고**, 침대는 **잠용**인가  
- [ ] 오후 **카페인·운동·스크린** 줄였는가  
- [ ] 코골·다리 불편·우울·불안 **겹침** — 진료 필요?  
- [ ] 수면제 **임의 증량·중단** 하지 않았는가  

---

## 10. 정리

1. 불면증은 **잠의 문제 + 낮 기능 저하**다.  
2. **스트레스·우울·생활·다른 수면 질환**을 함께 본다.  
3. 만성 불면은 **CBT-I**가 1순위 비약물 치료로 알려져 있다.  
4. 수면 위생·운동·[[다이어트]]의 수면 관리는 **보조**다.  
5. 오래가거나 코골·정신건강 동반 시 **진료**를 미루지 않는다.
