# 협심증

> **분류:** 생활·건강 · [[생활위키 목차]]

**협심증**은 심장 근육에 피를 보내는 **관상동맥**이 좁아지거나 일시적으로 오그라들어, 심장이 필요한 산소보다 **공급이 부족**할 때 가슴이 **조이고 뻐근한** 불편이 생기는 병이다. 이름 그대로 가슴이 좁아진 듯한 느낌에서 왔다.

**처음이거나, 쉬어도 안 낫거나, 식은땀·숨참·왼쪽 팔·턱으로 퍼지면 119.** 속쓰림([[역류성 위염]])·어깨([[극상근증후군]])로 넘겨 시계를 보지 않는다. 심근경색과 집에서 **30분을 재며 구분하지 말 것.**

이 글은 **개념·응급 징후·예방 방향**만 정리한다. 진단·약·스텐트·수술은 **응급실·순환기내과**가 한다.

확인일: 2026-08-14  
참고: [질병관리청 국가건강정보포털 — 협심증](https://health.kdca.go.kr) · 심뇌혈관 9대 생활수칙

관련: [[뇌졸중]] · [[역류성 위염]] · [[다이어트]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 심근 **허혈**(피·산소 부족)로 생기는 가슴 불편. 대개 **관상동맥 죽상경화** |
| **흔한 느낌** | 앞가슴·명치 쪽이 **조임·짓누름·무거움·쥐어짬**. 팔·어깨·목·턱·등으로 **퍼지기도** |
| **전형** | 계단·언덕·추운 날·흥분·과식 때 시작 → **수분** 안에 정점 → 쉬면(또는 처방 니트로글리세린) **수 분**에 잦아듦 |
| **진단** | 증상 + 심전도·효소·심장 CT·부하 검사·필요 시 **관상동맥 조영술**. 집에서 이름 붙이지 않음 |
| **왜 급하나** | 불안정해지면 **심근경색**(근육이 죽음)·심정지·심부전으로 갈 수 있음 |

```text
관상동맥 좁아짐 · 혈전 · 연축(오그라듦)
 ↓
심근에 산소 공급 < 필요량
 ↓
가슴 조임 · (진행 시) 심근경색
 ↓
휴식·약 · 또는 119 → 재개통(스텐트 등)
```

「체해서 그렇다」「가스가 찼다」로 **처음 심한 흉통**을 넘기지 말 것. 여성·노인·당뇨는 **호흡곤란·명치·소화불량**만 두드러지기도 한다.

---

## 2. 종류

| 종류 | 대략 | 주의 |
|------|------|------|
| **안정형** | 쉴 때는 괜찮고, **힘쓸 때**만. 비슷한 강도로 반복 | 방치하면 불안정·경색으로 갈 **수** 있음. 반드시 그 순서는 아님 |
| **불안정형** | 더 자주·더 길게, **쉬고 있어도**. 새로 생겼거나 갑자기 나빠짐 | **급성 관상동맥증후군** 축. 심근경색 직전으로 봄. **119** |
| **변이형** (연축) | 경화는 덜해도 혈관이 **갑자기 수축**. 밤·새벽·음주 다음 날·추위 | 돌연 심장사·경색도 가능. 진단·약은 의사 |

좁아진 정도가 심하지 않은 자리의 경화반이 **터지며 혈전**이 생기면, 안정형이 없던 사람에도 불안정·경색이 **갑자기** 올 수 있다.

**심근경색:** 혈관이 막혀 심근이 **괴사**. 효소(트로포닌 등)가 오르고, 쉬어도 통증이 **오래** 가며 식은땀이 흔하다. 구분은 **병원 검사**. 집에서 「협심증이니까 참자」고 두지 않는다.

---

## 3. 어떻게 느끼나

질병관리청이 정리한 경향이다. 사람마다 다르다.

| 축 | 설명 |
|----|------|
| **위치** | 가슴뼈 아래 앞가슴, 명치. 어깨·팔·목·등·턱·윗배에도 |
| **성질** | 조임, 압박, 무거움, 쥐어짬, 모호한 불편, 때로 타는 느낌 |
| **유발** | 운동, 감정 스트레스, 추위, 과식 |
| **완화** | 휴식. **처방받은** 니트로글리세린 설하·스프레이 (용법은 의사) |
| **비전형** | 숨참, 구역, 식은땀, 극심한 불안, 윗배 불편 — 특히 여성·노인·당뇨 |

**협심증일 가능성이 상대적으로 낮은 편**(그래도 심하면 진료): 바늘로 찌르듯 **날카로움**, 숨쉴 때·자세에 따라 **확 바뀜**, 위치가 자꾸 옮겨 다님.

[[역류성 위염]] 속쓰림, [[극상근증후군]] 어깨 통증과 **겹쳐 보일 수** 있다. 왼쪽 어깨 + 흉통 + 식은땀은 **심장부터**.

---

## 4. 119가 맞는 때

질병관리청: 협심증이 의심되면 **즉시 119**. 올 때까지 **편한 자세**. 처방받은 니트로글리세린이 있으면 **혀 밑**(삼키지 않음). 안 낫거나 처음·심하면 **분을 세지 말고** 간다.

| 한다 | 하지 않는다 |
|------|----------------|
| **119** · 급성기 가능 병원 | 본인 **운전** |
| 하던 일 멈추고 휴식 | 「체한 것」으로 소화제만 |
| 증상 **시작 시각**을 전달 | 가족이 올 때까지 대기 |
| 처방 **니트로글리세린**만, 안내 횟수 | 남의 심장약·임의 아스피린 여러 알 |
| 의식 없으면 119 + **가슴압박**(일반인 CPR 교육) | 야간이라 **내일 외래** · [[나만의닥터]] 비대면으로 시간 |

응급의료 포털 예: [E-Gen 응급실 찾기](https://www.e-gen.or.kr) — 구급대가 가능 병원을 아는 경우가 많다.

---

## 5. 병원에서 흔히 하는 것

인터넷 순서표가 처방이 아니다.

| 검사·치료 | 설명 |
|-----------|------|
| **심전도** | 급성 흉통의 기본. 안정형은 **절반 이상이 정상**일 수 있음 |
| **혈액** | 심근 효소(경색 감별), 당·지질·신장 등 |
| **심장 초음파** | 벽 운동, 대동맥 박리·판막 등 **다른 응급** 감별 |
| **심장 CT** | 관상동맥 좁아짐을 보는 비수술 검사로 자주 거론 |
| **부하 검사** | 운동·약물로 허혈을 드러냄. 불안정·의심 경색이면 **급성기에 억지로 하지 않음** |
| **조영술** | 손목·사타구니 동맥으로 관을 넣어 혈관을 **직접** 봄. 연축 유발 검사는 변이형 |
| **약** | 스타틴(지질), 항혈소판, 베타차단제·칼슘차단제·질산염 등 **증상·예방**. 종류·기간은 의사 |
| **스텐트·풍선** | 좁아진 곳을 넓힘 (PCI) |
| **우회술** | 다른 혈관으로 **돌아가게** 이음. 여러 혈관·당뇨·주간지 등에서 논의 |

스텐트 후 **두 가지 항혈소판**을 일정 기간 쓰는 집이 많다. **임의로 끊으면** 스텐트 혈전 위험이 있다. 치과·수술 전에도 **순환기내과와**.

---

## 6. 비슷한 이야기 (혼자 가르지 말 것)

| 비슷한 이야기 | 메모 |
|---------------|------|
| **심근경색** | 근육 괴사. 응급 재개통 |
| **불안정 협심증** | 효소는 안 올라도 **경색과 같은 급**으로 봄 |
| [[역류성 위염]] | 식후·누우면 속쓰림. **처음 심한 흉통은 심장 배제** |
| [[극상근증후군]] | 팔 들 때 어깨. 흉통·식은땀이면 심장 |
| **대동맥 박리** | 찢어지는 극통, 등. 응급 |
| **폐색전·기흉** | 숨참·한쪽 가슴 |
| **공황·근육통** | 있을 수 있으나 **배제 후** |

---

## 7. 위험 요인·예방

바꿀 수 없는 것: **나이**(문헌 예: 남성 45세·여성 55세 이상부터 위험이 올라간다고 자주 적음), **이른 관상동맥 질환 가족력**.  
바꿀 수 있는 것: **고혈압·당뇨·이상지질혈증·흡연·비만**.

예방 뼈대는 [[뇌졸중]]과 같은 **심뇌혈관 9대 생활수칙**이다. 금연, 절주·금주, 짜지 않게, 움직임, 체중([[다이어트]]), 혈압·혈당·콜레스테롤 숫자 알기, 약 임의 중단 금지, 응급 증상 알고 **119**.

[[오메가3]]·건강기능식품은 **스타틴·항혈소판을 대체하지 않는다.**

이미 협심증·스텐트가 있으면 증상이 없어도 **외래 추적**. 빈도·강도가 늘면 알린다.

운동은 심장 환자는 **낮은 강도부터**, 흉통·실신이 있으면 중단 후 진료 ([[다이어트]] 운동 절과 같음).

## 8. 니트로글리세린 (개념만)

| 항목 | 설명 |
|------|------|
| **무엇** | 혈관을 넓혀 급성 조임을 줄이는 **질산염**. 설하정·스프레이 |
| **누가** | **처방받은 사람**만. 남 약 금지 |
| **쓰임** | 흉통 때 혀 밑(삼키지 않음). 예방으로 쓰기 전 안내는 의사 |
| **주의** | 일부 발기부전약 등과 **같이 쓰면 혈압이 위험하게** 떨어질 수 있음 — 약 목록을 의사·약사에게 |
| **한계** | 넣어도 안 낫면 **경색·다른 응급**일 수 있음 → 119 |

용량·몇 분 간격·몇 회는 **설명서·처방의**가 우선. 이 글이 용법을 정하지 않는다.

## 9. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 관상동맥 혈류 부족으로 가슴이 **조이는** 허혈 |
| 안정형 | 힘쓸 때, 쉬면 수분 내 잦아듦 — **진료는 필요** |
| 불안정·경색 | 휴식 시·악화·식은땀·안 낫음 → **119** |
| 함정 | 속쓰림·어깨·체함으로 오인. 여성·당뇨는 비전형 |
| 예방 | 담배·혈압·당·지질·체중 + 약은 **끊지 않고** |

---

## 면책

> **강한 면책**
> - **진단·약·스텐트·수술 처방을 대체하지 않는다.**
> - 흉통은 **협심증·경색·박리·폐·식도·근골격** 등과 겹친다. 구분은 **의료**.
> - 의심되면 **119·응급실**. 이 글을 읽으며 시간을 쓰지 않는다.
> - 니트로글리세린·아스피린·항혈소판·스타틴은 **의사 지시**만. 임의 시작·중단 금지.
> - 혈압·LDL 목표 숫자는 **지침·연도·개인**이 다르다. 담당 의사가 우선.
