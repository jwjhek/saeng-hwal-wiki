# 요리

> **분류:** 생활·건강 · [[생활위키 목차]]

**집에서 음식을 만드는** 실무를 모은 허브다. 
**무엇을 먹을지·칼로리**는 [[다이어트]] · [[다이어트 추천 음식]], **밖에서 시키기**는 [[배달 앱]] — 여기서는 **조리·도구·장보기·안전**을 다룬다.

확인일: 2026-08-13

관련: [[다이어트 추천 음식]] · [[계란]] · [[병아리콩]] · [[오이]] · [[방울토마토]] · [[스트링 치즈]] · [[최저가와 쿠폰]] · [[배달 앱]]

---

## 1. 개요

| 글 | 역할 |
|----|------|
| **이 글([[요리]])** | 삶기·볶기·도구·장보기·집밥 루틴 |
| [[다이어트 추천 음식]] | 감량·유지에 **자주 넣는 재료** stub 모음 |
| [[다이어트]] | 칼로리·운동·약 — 식단 **전체 틀** |
| [[배달 앱]] | 주문·쿠폰 — 집밥 **대안** |

```text
장보기([[최저가와 쿠폰]]·마트)
 ↓
재료 손질 · (선택) 미리 삶기·데치기
 ↓
가열·양념 · 한 끼·도시락
 ↓
설거지·보관 — 다음 끼니
```

**배달만** vs **집밥만**이 아니라, **바쁜 날은 배달·간단 집밥·미리 해둔 것**을 섞는 경우가 많다.

## 3. 기본 조리 (손맛)

처방이 아니다. **불 세기·시간**은 냄비·재료·취향에 맞게 조절.

| 방법 | 하는 일 | 자주 쓰는 재료 예 |
|------|---------|-------------------|
| **삶기** | 물·육수에 익힘 | [[계란]](완숙·반숙), 면, 채소 |
| **데치기** | 끓는 물에 잠깐 → 찬물 | 브로콜리, 시금치, [[오이]] 무침 전 |
| **찌기** | 수증기·뚜껑 닫고 익힘 | 계란찜, 감자, 만두 |
| **볶기** | 팬+기름(적게) | [[계란]] 스크램블, [[병아리콩]]·채소 |
| **굽기** | 오븐·**에어프라이어** | [[방울토마토]] 로스트, 닭·생선(두께·내부온도 확인) |
| **무치기** | 익힌·생 채소+양념 | [[오이]]·토마토 샐러드, [[병아리콩]] |

**칼로리의 본체**는 재료보다 **기름·소스·튀김**인 경우가 많다 — [[다이어트 추천 음식]] §2와 같다.

## 4. 재료별 — 조리 한 줄

상세·영양·다이어트는 각 stub. 여기는 **집에서 바로 쓰기**용.

| 재료 | 조리 예 | stub |
|------|---------|------|
| [[계란]] | 삶란·스크램블·프라이(기름 적게) | [[계란]] §3 |
| [[병아리콩]] | 샐러드·수프·볶음 (통조림은 헹굼) | [[병아리콩]] |
| [[오이]] | 생채·무침·계란과 곁들임 | [[오이]] |
| [[방울토마토]] | 생식·로스트·샐러드 | [[방울토마토]] |
| [[스트링 치즈]] | **가열 없이** 간식·도시락 | [[스트링 치즈]] |

### 4.1 한 끼 조합 예 (15~20분)

| 끼니 | 예시 |
|------|------|
| 아침 | [[계란]] 2개 삶기 + [[방울토마토]] |
| 점심 도시락 | [[병아리콩]] 샐러드 + [[오이]] + 밥·현미 |
| 출출할 때 | [[스트링 치즈]] + 오이 — 가열 없이 |
| 저녁 간단 | 계란 스크램블 + 데친 채소 + 밥 |

양념은 **간장·식초·참기름 소량**부터. 마요·튀김 반죽은 칼로리가 크게 오른다.

### 4.2 집밥 숏컷 (유행·간편)

| 요리 | 설명 |
|------|------|
| [[라면 스프 보쌈]] | **라면 스프**(특히 **안성탕면**)로 돼지고기 삶기 — **냄비**·**전자레인지** |

SNS에서 돌아가는 레시피는 **시간·나트륨·익힘**을 본인 환경에 맞게 조절한다.

## 5. 도구·주방 최소

| 도구 | 용도 |
|------|------|
| **냄비** | 삶기·찌기·라면·수프 |
| **프라이팬** | 계란·볶음 (불 조절·기름 양) |
| **칼·도마** | 손질 — **젖은 채로** 미끄럼 주의 |
| **전자레인지** | 데우기·감자·계란찜 · **짧은 수육**([[라면 스프 보쌈]] §5) — 용기·구멍 확인 |
| **에어프라이어** | 굽기·튀김 대체 — **기름은 줄여도 칼로리는 남음** |
| **밀폐용기** | 남은 반찬·도시락 — 냉장 **유통기한** |

처음부터 장비를 많이 살 필요는 없다. **냄비+팬+칼**로 대부분 시작 가능.

## 6. 장보기

| 체크 | 설명 |
|------|------|
| **리스트** | [[다이어트 추천 음식]] 표를 보고 **단백질·채소**를 같이 적기 |
| **가격** | [[최저가와 쿠폰]] · [[최저가 비교 사이트]] — **g당·개당** 단가 |
| **유통기한** | 계란·치즈·콩 통조림·채소 |
| **냉동·통조림** | 편하지만 **나트륨·당** 라벨 확인 |
| **과구매** | 상한 없이 사두면 버림 → [[다이어트]] 목표와도 어긋남 |

마트 **할인 시간대**·앱 **장보기 쿠폰**은 [[최저가와 쿠폰]] §3에서 표로 모을 수 있다.

## 8. 배달과 집밥

| | 집밥 | [[배달 앱]] |
|--|------|-------------|
| **시간** | 장보기·조리·설거지 | 주문·대기만 |
| **비용** | 재료값 — **남은 반찬** 재사용 | 배달비·최소주문·팁 |
| **양·기름·소금** | 본인이 조절 | 가게·메뉴 의존 |
| **현실** | 주 2~3끼만 집밥도 충분한 경우 많음 | 쿠폰·[[생일 혜택]] 쓰는 날 |

「집밥이 무조건 싸다」만은 아니다 — **시간값·재료 폐기**를 넣어 본다. 반대로 배달이 **매일**이면 [[다이어트]]·지갑 모두 점검.

## 9. 실전 체크

- [ ] [[다이어트 추천 음식]] 재료가 **장보기 리스트**에 있는가  
- [ ] 한 끼에 **단백질 + 채소**가 같이 가는가  
- [ ] 기름·소스·튀김을 의식하는가  
- [ ] 바쁜 날 **미리 삶은 계란·콩**을 쓸 수 있는가  
- [ ] 배달은 **쿠폰·총액** 확인 후 — [[배달 앱]]

## 면책

> **면책**
> - **영양·질환 식단·치료 처방이 아니다.** 알레르기·임신·당뇨 등은 **의료·영양 상담** 우선.
> - 조리 시간·불 세기는 **기기·재료**마다 다르다. 생식·미익힘 위험에 주의.
> - 가격·쿠폰은 [[최저가와 쿠폰]] 확인일 기준.
