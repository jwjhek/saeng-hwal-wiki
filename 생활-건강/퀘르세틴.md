# 퀘르세틴

> **분류:** 생활·건강 · [[생활위키 목차]]

식물성 **플라보노이드**인 **퀘르세틴(Quercetin)** 을 개념·알레르기·히스타민 관련 주장·주의만 정리한다. 
약국·온라인 보충제로 팔리지만, **항히스타민제(의약품)와 같은 역할이 아니다.**

확인일: 2026-08-07

관련: [[항히스타민]] · [[종합비타민]] · [[오메가3]]

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 정체 | 양파·사과·차 등에 있는 **플라보노이드** |
| 흔한 목적(주장) | 항산화, 알레르기·히스타민·염증 “완화” 마케팅 |
| 형태 | 건기식·보충제 캡슐/정. 음식으로도 섭취 |
| [[항히스타민]]과 | **다름**. 퀘르세틴은 보통 보충제 축, 항히스타민은 의약품 축 |

“천연이라 무조건 안전·치료”는 과장이다.

---

## 2. 무엇인가

퀘르세틴은 식물 색소·방어 물질 계열의 화합물이다. 
식품으로도 들어오지만, 보충제는 **농축 용량**이라 음식과 동일하게 보기 어렵다. 
흡수율이 낮다는 이야기가 많아, 제품에 **흡수 강화 제형**(예: 특정 복합·지용성 제형) 마케팅이 붙는 경우가 있다. 
제형 우열을 이 문서가 단정하지 않는다 → 라벨·약사.

---

## 3. 알레르기·히스타민 이야기 (주장 vs 현실)

마케팅·일부 연구에서 나오는 말:

| 주제 | |
| ------------------- | ---------------------------------- |
| 비만세포(마스트세포)·히스타민 유리 | 실험·기초 연구에서 **관심**. 사람마다·용량마다 결과 편차 |
| 계절 알레르기·가려움 | “먹으면 항히스타민 대체”는 **과한 기대** |
| 항산화·염증 | 광범위 주장. **질병 치료 증명**으로 단정하기 어려움 |

심한 알레르기·호흡 곤란·아나필락시스는 **응급 체계·처방약**이 우선이다. 
퀘르세틴으로 에피네프린·처방 [[항히스타민]]·스테로이드를 끊지 않는다.

---

## 4. [[항히스타민]]과 어떻게 다른가

| | 퀘르세틴 | 항히스타민 |
|--|----------|-------------|
| 성격 | 주로 **보충제·건기식** | 주로 **의약품**(일반/전문) |
| 작용 | 히스타민 **유리·염증 경로**에 대한 연구·주장 | 히스타민 **수용체(H1 등)를 막아** 증상 완화 |
| 급성 증상 | 즉효 치료제로 보지 말 것 | 콧물·두드러기 등에 **허가된 용법**이 있음 |
| 고를 때 | 라벨·상호작용 | 용법·졸음·약사 상담 |

같이 쓰는 사람이 있어도, **병용은 약사·의사에게 확인**한다. 
이 위키가 병용을 권하지 않는다.

---

## 5. 주의·상호작용 (중요)

| 이슈 | 설명 |
|------|------|
| **약 대사** | 일부 간 효소·수송체에 영향을 줄 수 있다는 논의 → 처방약과 **겹치면 상담** |
| 항응고·항혈소판 | 출혈 경향 이야기 → 수술 전·해당 약 복용 시 주의 |
| 일부 항생제 등 | 흡수·간격 이슈가 언급됨 → 약사 |
| 갑상선약 | 동시 복용 시 흡수 방해 가능성 → **시간 간격** 상담 |
| 임신·수유 | 자료 제한 → 임의 고용량 비권장에 가깝다 |
| 부작용 | 소화 불편·두통 등. 개인차 |

브로멜라인(파인애플 효소) 등과 섞인 제품은 **알레르기 원료**도 확인한다.

---

## 6. 고를 때

1. **퀘르세틴 mg** (총량·1회) 
2. 다른 블렌드(브로멜라인, 비타민 C 등)와 중복([[종합비타민]] 등) 
3. 의약품인지 건기식인지 — 치료 문구 과장은 의 
4. 복용 약 목록을 들고 약국·병원 확인 
5. “항히스타민 대체·알레르기 완치” 광고 → 거르기 

계정·질환·실제 복용 일지는 공개 위키가 아니라 `private/`에만 둔다.

## 8. 정리

퀘르세틴은 식품에도 있는 **플라보노이드 보충제**다. 
알레르기·히스타민 관련 **연구와 마케팅이 혼재**하며, [[항히스타민]] 의약품을 대체하지 않는다. 
약 상호작용 가능성이 있으니 **라벨·상담**이 우선이다.

---

## 면책

> **면책** 
> 의료·영양 **진단·처방·섭취 권유가 아니다**. 
> 알레르기·천식·아나필락시스 치료제를 **대체하지 않는다**. 
> 복용 약·임신·수유·신장·출혈 경향이 있으면 사용 전 전문가와 상담한다. 
> 이 문서가 용량·브랜드를 정하지 않는다.
