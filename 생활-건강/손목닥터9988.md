# 손목닥터9988

> **분류:** 생활·건강 · [[생활위키 목차]]

**손목닥터9988**은 서울시 **스마트 건강관리** 앱이다. 이름 뜻은 **99세까지 88(팔팔)** 하게. 걷기·설문·챌린지 등으로 **포인트**를 모아 **서울페이**로 바꿔 쓴다. 예전 시범 이름은 **온서울 건강온**. 시 자료에 **손목닥터9988+** 로 적힌 적도 있다.

공식 누리집: [https://onhealth.seoul.go.kr](https://onhealth.seoul.go.kr)  
앱: 스토어 **손목닥터9988**  
상담: **1811-9988** · 다산콜 **02-120**  
확인일: 2026-08-21

관련: [[서울사랑상품권]] · [[갤럭시 워치 사용법]] · [[다이어트]] · [[제로페이]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 서울시 시민 건강 앱. 걸음·식단·마음건강 기록 + **포인트** |
| **대상** | **서울 시민**(거주). **서울 소재** 직장·대학도 안내됨. **연령은 앱·누리집이 최종**(보도·연혁은 **19세 이상**이 많음) |
| **모집** | 2024년 3월부터 **상시**로 안내. 예산·점검은 공지 |
| **기기** | **폰만**으로도 참여 가능(2024~). 워치·밴드는 선택이지만 기록이 편한 집이 많음 |
| **무엇이 아님** | 병원 진단, 의료기기, 전국 공용 앱, [[경기지역화폐]] |

```text
앱 설치 · 본인 인증 · 서울 자격(필요 시 증빙)
 ↓
삼성 헬스 / 애플 건강 연동 (권한)
 ↓
걷기·미션 → 다음날 포인트
 ↓
일정 금액 이상 → 서울페이플러스로 전환 → 가맹점
```

포인트 숫자·한도·전환 단위는 **앱 공지**가 우선이다. 2025년 12월부터 **걷기 일일 적립이 줄고 주 단위 보너스가 붙는** 개편이 보도됐다.

## 2. 시작하기

| 단계 | 내용 |
|------|------|
| 1 | 스토어에서 **손목닥터9988** 설치. 안드로이드·iOS **최소 버전**이 올라간 공지가 있음 |
| 2 | 본인 인증 가입. 건강 정보·위치·걸음 권한 |
| 3 | **서울 시민**이면 주민 인증. **서울 직장·대학·자영업**이면 재직·학생증 등 **증빙 업로드**가 필요할 수 있음 |
| 4 | 갤럭시: **삼성 헬스** 연동. 아이폰: **애플 건강**. 워치는 헬스 앱을 거쳐 걸음이 넘어가는 구조가 흔함 |
| 5 | 설문·목표(최대 몇 개)를 고르면 **초기 포인트**가 붙는 안내가 있었음 |

승인 뒤 **다음날부터** 본격 적립이라는 설명이 많다. 걸음이 안 맞으면 설정 → **데이터 연동**에서 권한을 다시 켠다. 아이폰·애플워치는 **연동 방식이 바뀐** 공지(2025-07)가 있다.

워치가 없어도 된다. [[갤럭시 워치 사용법]]·갤럭시 핏을 쓰면 폰을 안 들고 걸어도 잡히기 쉽다. 기기 할인(예: 핏3 선착순)은 **회차 이벤트**다. 지금 매대가 아닐 수 있다.

## 3. 포인트

**1포인트 = 1원**으로 안내된다. **적립일부터 1년** 안 쓰면 소멸한다는 안내가 있다. 걷기만 있는 게 아니다. 건강카드·식단·챌린지·체력인증·대사증후군·금연·치매예방 등 **프로그램별 적립**이 앱에 따로 있다.

### 3.1 걷기 (자주 나오는 뼈대)

목표 걸음은 **하루 8,000보**, **70세 이상은 5,000보**로 안내된 적이 많다.

| 시기 | 보도에 나온 방향 (앱이 최종) |
|------|------------------------------|
| 개편 전 | 목표 달성 시 **매일 200포인트** |
| **2025-12-01~** | 일일 걷기가 **100포인트**로 줄고, **주말 1일 포함 주 5회** 성공 시 **500포인트** 추가 등 |

연간 **최대 적립**(신규 기준)도 예전에 **10만**으로 안내되다가 **줄어든** 보도가 있다. 「매일 200P」만 적힌 블로그는 만료일 수 있다.

걸음 연동 오류 시 **보상 기준** 공지가 따로 난 적 있다(2026-03).

### 3.2 서울페이로 바꾸기

포인트는 자동으로 돈이 되지 않는다. **전환 신청**이 필요하다.

| 항목 | 자주 나온 안내 |
|------|----------------|
| **앱** | 손목닥터에서 전환 → **서울페이플러스**([[서울사랑상품권]] 글의 그 앱) |
| **최소** | **5,000포인트** 이상부터라는 안내가 많음 |
| **시간** | **다음날** 반영. **주말**에는 막히거나 늦는다는 이용 안내가 있음 |
| **쓰기** | 서울페이 가맹. 병원·약국·편의점(**주류·담배 제외**) 등이 반복됨. **따릉이 쿠폰**도 안내된 적 있음 |
| **선물** | 정책수당성 잔액은 [[서울사랑상품권]] **선물 불가** 축으로 안내됨 |

전환이 **일시 중단**된 공지(2025-07)도 있었다. 쓰기 직전에 앱을 본다.

보험료 할인·티머니 마일 연동은 **제휴 회차**다. 가입 권유가 아니다. [[보험 기초]]와 별개로 **약관·고지**를 본다.

## 4. 앱에서 하는 일 (건강)

| 축 | 메모 |
|----|------|
| **걷기·운동** | 걸음, PT·러닝 등 콘텐츠. 워치 운동 모드가 있으면 추가 미션이 열릴 수 있음 |
| **식단** | 기록·저당 프로그램(「덜 달달」 등)은 **모집 회차** |
| **마음건강** | 명상·스트레스. [[정신건강]] 진료를 대체하지 않음 |
| **대사증후군** | 보건소 검사·챌린지와 연동된 적립 안내가 있음 |
| **서울체력9988** | 체력인증센터 측정·등급. **별도 메뉴**로 안내 |
| **커뮤니티** | 인증·챌린지. 2026-07 운영정책 제정 공지 |

같은 9988 이름인 **혈당캐치9988** 등은 **다른 사업**일 수 있다. 혼동하지 말 것.

워치 심박·수면·체성분은 **의료 진단이 아니다** → [[갤럭시 워치 사용법]].

## 5. 자주 막히는 점

| 상황 | 볼 것 |
|------|--------|
| 가입이 안 됨 | 서울 주소·증빙. 연령. OS 버전 |
| 걸음이 0 | 헬스 앱 권한, 워치-폰 동기화, 앱을 **하루에 한 번** 켜기 |
| 포인트가 안 붙음 | **익일** 정산. 목표 보·나이 구간(5천/8천). 개편 후 **주 5회** 조건 |
| 전환 버튼이 없음 | 5천 미만, 서울페이 미가입, 일시 중단 공지 |
| 타 지역 앱과 혼동 | **경기도** 만보기 사업과 **별개**. 손목닥터는 **서울시** |
| 가짜 앱 | 공식 스토어·[onhealth.seoul.go.kr](https://onhealth.seoul.go.kr)만 |

건강취약계층(산후, 보건소 대사증후군, 중장년 1인 가구, 고립 청년 등)은 **보건소·주민센터 별도 모집**이 있었던 안내가 있다.
