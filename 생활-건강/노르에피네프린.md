# 노르에피네프린

> **분류:** 생활·건강 · [[생활위키 목차]]

**노르에피네프린**(norepinephrine, **노르아드레날린**과 같은 물질)은 **각성·주의·스트레스 반응·혈압** 등에 관여하는 **신경전달물질**이자 **호르몬**이다.

[[도파민]]에서 만들어지고, 필요하면 **에피네프린(아드레날린)** 으로 이어진다. 
이 글은 **생물학 개념**만 정리한다. **진단·치료 권유가 아니다.**

확인일: 2026-08-11

관련: [[도파민]] · [[코르티솔]] · [[정신건강]] · [[우울장애]]

---

## 1. 개요

| 항목    | 설명                                              |
| ----- | ----------------------------------------------- |
| 다른 이름 | **노르아드레날린**(noradrenaline) — 같은 물질              |
| 역할    | **각성**, **주의 집중**, **스트레스·위협 대응**, **혈압·심박** 조절 |
| 어디서   | **뇌**(청반핵 등), **교감신경** 끝, **부신 수질**(에피네프린과 함께)  |
| 합성    | [[도파민]] → **노르에피네프린** → (일부) **에피네프린**          |

```text
[뇌] 청반핵 → 각성·주의·각성도
[몸] 교감신경 → 심박↑·혈관 수축·에너지 동원
[부신] 스트레스 시 → 에피네프린과 함께 분비
```

---

## 2. 뇌에서 하는 일

| 기능 (단순화) | 설명 |
|---------------|------|
| **각성** | 졸림·무기력과 반대 방향의 **「깨어 있음」** |
| **주의** | 중요한 자극에 **집중**, 잡음 걸러내기 |
| **스트레스 반응** | 위협·압박 시 **몸과 마음을 경계** 상태로 |
| **기분** | [[우울장애]]·불안 모델에서 **[[세로토닌]]·도파민과 함께** 논의 |

**청반핵-전뇌 경로**가 대표적으로 언급된다. 
「노르에피네프린만」으로 우울·불안을 설명하기는 **어렵다.**

---

## 3. 몸(말초)에서 하는 일

교감신경이 활성화되면 노르에피네프린(및 에피네프린)이 혈관·심장 등에 작용한다.

| 효과 (대략) | 체감 예 |
|-------------|---------|
| 심박·박출 증가 | 긴장 시 **심장 두근거림** |
| 혈관 수축 | **혈압 상승** |
| 간당원 분해 | 에너지 **동원** |
| 동공 확대·땀 | **fight-or-flight**(싸우거나 도망) 반응 |

만성 스트레스에서 이 축이 **오래 켜져 있으면** 수면·소화·기분에 **악영향**이 날 수 있다 — 개인차가 크다.

---

## 4. 도파민·에피네프린과의 관계

| 물질           | 관계                                          |
| ------------ | ------------------------------------------- |
| [[도파민]]      | **직전 단계** — 도파민이 부족하면 노르에피네프린도 줄 수 있음       |
| **에피네프린**    | 노르에피네프린에서 **한 단계 더** — 부신에서 **급한 스트레스**에 많이 |
| **[[세로토닌]]** | 기분·불안 — **다른 축**이지만 약·질환에서 **함께** 다루는 경우 많음 |

```text
티로신 → L-도파 → 도파민 → ★ 노르에피네프린 → 에피네프린
```

---

## 5. 너무 적을 때·많을 때 (개념)

| 방향 | 맥락 (단순화, 개인마다 다름) |
|------|------------------------------|
| **부족 (뇌)** | 무기력·집중 저하 **일부** 우울 모델 — **단일 원인 아님** |
| **부족 (혈압)** | **저혈압**·실신 경향 — **교감신경**·부신 기능 등 **다른 질환** 검사 |
| **과다 (급성)** | 극심한 불안·공황·심박 — **불안장애**·자극제·카페인 등 |
| **과다 (만성)** | 스트레스·불면·혈압 문제와 **겹칠 수** 있음 |

일반 건강검진에서 「노르에피네프린 수치」만으로 정신건강을 **판정하지 않는다.**

---

## 6. 약·치료와의 연결 (방향만)

| 종류 | 노르에피네프린과의 관계 (개념) |
|------|-------------------------------|
| **SNRI** | 세로토닌·**노르에피네프린** 재흡수 억제 — 일부 **항우울제** |
| **일부 삼환계 항우울제** | 노르에피네프린(·도파민)에도 영향 |
| **[[ADHD]] 흥분제** | 도파민·노르에피네프린 **재흡수 억제** — **처방 전제** |
| **베타차단제** | 노르에피네프린·에피네프린의 **말초 작용** 일부 차단 — 심박·떨림 |
| **클로니딘 등** | 교감신경 **억제** — [[ADHD]]·혈압 등 (적응증별) |
| **승압제(노르에피네프린 제제)** | **저혈압·쇼크** 등 **병원**에서 정맥 주사 — **자가 사용 아님** |

약 선택·용량·중단은 **정신건강의학과·내과** 등 **처방 의사**만 한다.

---

## 7. 카페인·스트레스·생활

| 요인 | 참고 |
|------|------|
| **카페인** | 각성·심박 — **민감한 사람**은 불안·불면 악화 |
| **수면 부족** | 각성 축이 **과보상**되다 느껴질 수 있음 |
| **만성 스트레스** | 교감신경 **항상 켜짐** 느낌 — HPA 축·[[코르티솔]]과 **겹쳐** 이야기됨 — 휴식·운동·상담 등 **복합 대응** |
| **티로신 보충제** | 합성 **전구체** 마케팅 — **우울·집중 치료 대체 아님** |

[[보충제]]로 노르에피네프린을 「올린다」는 식의 **자가 처방**은 권하지 않는다.

---

## 8. 흔한 오해

| 오해 | 현실 |
|------|------|
| 스트레스 호르몬 = 에피네프린만 | **노르에피네프린**도 핵심 |
| 우울 = 노르에피네프린만 부족 | **도파민·[[세로토닌]]·기타** 포함 — 약도 다양 |
| 베타차단제가 뇌 노르에피네프린을 막는다 | 주로 **말초** — 뇌 관통 여부는 **약마다** 다름 |
| 각성제·에너지 드링크로 공부 | 단기 각성 ≠ **장기 인지 향상** — 부작용·의존 주의 |

---

## 9. 정리

1. 노르에피네프린은 **각성·주의·스트레스·혈압**에 관여한다.  
2. **뇌**와 **몸(교감신경)** 에서 역할이 **겹치지 않게** 나뉜다.  
3. [[도파민]]에서 만들어지고, **에피네프린**으로 이어질 수 있다.  
4. SNRI·흥분제·베타차단제 등과 **연결**되지만, **자가 약물 조절은 금지**다.
