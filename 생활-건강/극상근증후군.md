# 극상근증후군

> **분류:** 생활·건강 · [[생활위키 목차]]

**극상근증후군**은 어깨를 돌리고 안정시키는 **회전근개** 중 **극상근** 힘줄이 좁은 공간에서 **반복해서 눌리거나 마찰**되며 통증·염증·건병증이 생기는 양상을 가리키는 말이다.  
병원·보험 기록에서는 **충돌증후군**, **극상근 건염·건병증**, **회전근개 질환** 등으로 적히는 경우가 많다. **같은 이름 = 같은 병**은 아니다.

이 글은 **개념·일상에서 조심할 점·진료 시점**만 정리한다. 진단·운동 처방·주사·수술은 **정형외과·재활의학과**에 맡긴다.

확인일: 2026-08-14

관련: [[체외충격파 치료]] · [[다이어트]] · [[나만의닥터]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 극상근 힘줄·그 위 **점액낭**이 어깨뼈 지붕(견봉)과 위팔뼈 사이에서 **끼이거나 과사용**되어 아픈 상태 |
| **흔한 느낌** | 어깨 **앞·옆**이 아프고, 팔 중간까지 내려가는 듯한 통증. **머리 위 동작**·밤에 누우면 더함 |
| **누가 많나** | 중년 이후 **퇴행**, 머리 위 일을 많이 하는 직업·운동. 젊은 층에도 **과사용·외상**으로 옴 |
| **진단** | 증상 + 진찰. 필요 시 **엑스레이·초음파·MRI** |
| **중요** | 통증 세기만으로 **염증인지 파열인지** 단정하지 못함 |

```text
머리 위 반복 사용 · 힘줄 퇴행 · 견봉 아래 공간 좁아짐
 ↓
극상근 힘줄·점액낭 마찰·미세 손상
 ↓
통증 · (진행 시) 건병증 · 부분/전층 파열 가능
 ↓
휴식·재활·약물·주사 등 보존 치료
 (부족·파열·기능 저하 시 수술 논의)
```

「어깨가 아프다 = 극상근증후군」「오십견」으로 **혼자 이름 붙이지 말 것.**

---

## 2. 어디에 있나

회전근개는 **네 개** 근육의 힘줄이 위팔뼈 머리를 감싸 관절을 잡아 주는 구조다.

| 근육 | 대략 하는 일 |
|------|----------------|
| **극상근** | 팔을 **옆으로 들기 시작**할 때, 위팔뼈 머리가 빠지지 않게 유지. **가장 자주** 문제 |
| **극하근·소원근** | 팔을 **바깥으로** 돌리기 |
| **어깨밑근**(견갑하근) | 팔을 **안으로** 돌리기 |

극상근 힘줄은 **견봉**(어깨 꼭대기 뼈)과 위팔뼈 사이 **좁은 터널**을 지난다. 팔을 들 때마다 이 공간이 더 좁아질 수 있다.

```text
[견봉]  ← 어깨 지붕
   |   좁은 공간 (점액낭 · 극상근 힘줄)
[위팔뼈 머리]
```

## 3. 이름이 여러 개인 이유

현장에서 이름이 **겹쳐** 쓰인다. 차트에 적힌 말만 보고 인터넷 운동을 따라 하지 않는다.

| 자주 듣는 말 | 관계 |
|--------------|------|
| **극상근증후군** | 극상근 쪽을 강조한 **임상·통칭**. 공식 진단명만은 아님 |
| **충돌증후군** | 견봉 아래에서 힘줄이 **반복 압박**된다는 설명. 최근에는 **회전근개 건병증** 안에 넣는 문헌도 많음 |
| **극상근 건염·건병증** | 힘줄 **염증·변성**. 만성이면 단순 염증보다 **건의 질** 문제에 가깝다는 설명이 흔함 |
| **회전근개 파열** | 힘줄이 **부분** 또는 **전층**으로 끊김. 극상근 부착부가 흔함 |
| **석회성 건염** | 힘줄 안에 **석회**가 생김. 극상근에 많고, 흡수기에 **극심한 통증**이 올 수 있음 |
| **오십견**(유착관절낭염) | **모든 방향**으로 어깨가 굳는 병. 나이만으로 같게 보지 않음 |

영상에서 힘줄이 좀 상해도 **증상이 약할 수** 있고, 반대로 가벼운 점액낭염만으로도 **밤에 잠을 못 잘** 수 있다. **증상 ≠ 영상 심각도.**

---

## 4. 어떻게 느끼나

경향일 뿐, 사람마다 다르다.

| 양상 | 설명 |
|------|------|
| **위치** | 어깨 **앞·옆**. 위팔 **중간**(삼각근 부착 쪽)까지 내려가는 느낌. 보통 **손끝 저림까지는 덜함** — 손 저림·목 통증이면 **목 디스크** 등도 감별 |
| **아픈 동작** | 머리 감기, 옷 입기, 선반, 머리 뒤로 손 넣기, 옆으로 팔 들기 |
| **아픈 각도** | 팔을 옆으로 들 때 **중간 구간**에서 더 아픈 집이 있음 — **진찰**에서 봄 |
| **밤** | 아픈 쪽으로 **누워 자기** 힘듦. 밤에 더함 |
| **힘** | 통증 때문에 못 드는 것과, **힘줄이 끊겨** 못 드는 것은 다름. 구분은 **진료** |

외상 후 **갑자기 팔을 못 들면** 기다리지 말고 본다.

---

## 5. 왜 생기나

한 가지로 단정하지 않는다. **힘줄 자체 퇴행(내인)** 과 **뼈·자세로 인한 압박(외인)** 이 겹친다는 설명이 많다.

| 요인 | 설명 |
|------|------|
| **나이·퇴행** | 힘줄 질이 떨어지고 혈류가 약해진다는 설명. 중년 이후 흔함 |
| **과사용** | 페인트, 미용, 청소, 수영·배구·야구처럼 **머리 위** 반복 |
| **구조** | 견봉 모양, 견봉 밑 **골극**, 빗장뼈와 어깨 끝이 만나는 관절의 골극 등으로 공간이 좁아짐 |
| **자세·날개뼈** | 둥근 어깨, 날개뼈가 잘 안 돌아가면 공간이 더 좁아질 수 있음 |
| **외상** | 넘어지며 팔을 짚거나 갑자기 당김 |
| **석회** | 힘줄 안 석회 — 원인 단정은 어려움. 당뇨 등과 **같이** 이야기되기도 |

[[다이어트]] 근력 운동에서 **숄더 프레스·푸시업**을 무리하면 어깨가 아픈 집이 있다. **아픈 각도로 밀어 넣지 말 것.**

## 6. 비슷한 이야기

의사가 보는 영역이다.

| 비슷한 이야기 | 왜 다른가 |
|---------------|-----------|
| **오십견** | 남이 들어 줘도 **전 방향**이 굳음. 충돌은 특정 각도·동작이 더 아픈 편 |
| **목 신경** | 목 움직임에 따라 변하고, **손 저림·방사통**이 어깨만의 통증과 다를 수 있음 |
| **이두근 장두 건염** | 앞쪽 깊게, 팔꿈치를 구부리거나 손목을 돌릴 때 |
| **석회성 건염** | 갑자기 **밤새 못 잘 정도**로 아플 수 있음. 엑스레이에서 석회가 보이기도 |
| **관절염·불안정** | 나이·탈구 병력·마찰음 양상이 다름 |
| **왼쪽 어깨 + 흉통·식은땀** | **심장** 가능성을 배제해야 함. 어깨 스트레칭으로 넘기지 않음 |

---

## 7. 진료가 급한 때

- 외상 후 **팔을 전혀 못 듦**  
- **점점 힘이 빠짐**, 어깨 뒤가 꺼져 보임(위축)  
- 수 주~수개월 **보존해도** 일상(머리 감기·옷)이 안 됨  
- **열·붓기·원인 없는 체중 감소**와 같이 옴  
- 가슴 통증·호흡 곤란·식은땀과 **왼쪽 어깨**가 같이 옴 → **응급**

예약·병원 찾기는 [[나만의닥터]] — 어깨는 **대면 진찰·영상**이 일반적이다.

## 8. 병원에서 흔히 하는 것

나이, 직업, 파열 크기, 힘, 통증, 외상 여부를 보고 정한다. **인터넷 순서표가 처방이 아니다.**

### 보존 (많은 경우 먼저)

| 방향 | 설명 |
|------|------|
| **자극 줄이기** | 수개월 단위로 **머리 위 반복**을 줄임. 완전 고정만 오래 하면 **굳음**(오십견) 위험이 있어, **움직임은 유지**하는 쪽이 흔함 |
| **냉·온** | 급성 통증에 **냉찜질**(한 번에 짧게, 피부에 직접 얼음 X). 재활 전에 **온찜질**을 쓰는 집도 있음 — 병원 안내 |
| **약** | 소염진통제 등. **위장·심혈관** 부작용. 장기 OTC는 의사와 |
| **물리·운동** | 관절 가동 범위 유지, **회전근개·날개뼈 주변** 근력. **가동 범위**는 당김이 있게, **근력**은 **안 아픈 범위**에서 — 세부 동작은 **지도** |
| **주사** | 견봉 아래 **스테로이드** 등으로 염증·통증을 줄여 재활을 돕는 경우. **힘줄 안·짧은 간격 반복**은 힘줄 약화 보고가 있어 **횟수 제한**이 흔함 |
| **기타** | PRP·증식치료 등은 **선택·근거·비용**이 갈림. 의사와 |

파열이 **없거나 부분**이고 통증이 조절되면 보존으로 가는 집이 많다. **증상 없는 파열**도 영상에서 나오기도 한다.

### 수술을 이야기하는 때 (경향)

전층 파열, 젊은 층의 **외상성** 파열, 힘이 크게 떨어진 경우, **수개월 적극 보존에도** 일상·일이 안 되는 경우 등.  
관절경으로 힘줄을 봉합하고, 충돌을 줄이려 **견봉 일부를 다듬는** 술이 흔하다. 광범위 파열·퇴축이 심하면 봉합이 어렵고, 일부 노인에서는 **역행성 인공관절** 등이 논의된다. **적응은 의사.**

---

## 9. [[체외충격파 치료]]

석회가 있는 **석회성 어깨 건병증**에서는 체외충격파가 **선택지**로 자주 거론된다.  
석회가 없는 건병증은 근거가 **더 갈린다**(해당 글 NECA 요약).  
파열·감염·종양이 의심되면 충격파가 답이 아니다. **진단 후** 논의.

---

## 10. 일상에서

의료 대체가 아니다. **악화만 줄이는** 쪽.

| 하면 도움 되기 쉬운 것 | 피하기 쉬운 것 |
|------------------------|----------------|
| 아픈 쪽으로 **엎어 자지 않기** (베개·자세 조절) | 아픈데 **머리 위 반복** (선반·철봉·헤비 프레스) |
| 옷은 **아픈 팔 먼저** 넣고, 벗을 때는 **건강한 팔 먼저** | 「안 쓰면 낫는다」며 **몇 달 팔짱만** |
| 가방을 **반대 어깨**·크로스 | 통증 각도로 **유튜브 스트레칭**을 억지로 |
| 의사 받은 **가동·근력**만 꾸준히 | 스테로이드 주사를 **자주 맞으며** 바로 과격 운동 |

근력 운동은 [[다이어트]] §운동처럼 **손목·어깨가 아프면 강도를 낮추고**, 각도를 바꾼다.

## 11. 진료 때 물어볼 것

- 충돌·건병증·**파열 유무·크기**  
- 초음파 vs MRI가 **지금 필요한지**  
- 머리 위 일·운동을 **얼마나** 줄일지  
- 주사 **횟수·간격**, 충격파가 **석회와** 맞는지  
- 보존을 **몇 개월** 보고 수술을 다시 이야기할지  
- 실손·급여: [[보험 기초]] · [[실손보험]] (비급여 물리·충격파는 약관마다 다름)

## 12. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 극상근 힘줄이 좁은 어깨 지붕 아래에서 **과사용·퇴행·충돌**로 아픈 양상 |
| 핵심 증상 | 앞·옆 어깨 통증, 머리 위 동작, **야간통** |
| 함정 | 오십견·목·석회·파열·심장과 **겹쳐 보일 수** 있음 |
| 기본 | 자극 줄이기 + **굳지 않게** 움직이기 + 재활. 주사·충격파·수술은 **진단 후** |
| 원칙 | 증상만으로 경중을 판단하지 않음 |

## 면책

> **강한 면책**
> - **진단·운동 처방·약·주사·수술 권유가 아니다.**
> - 어깨 통증은 **충돌·파열·오십견·목·석회·관절염·심장** 등과 겹칠 수 있다. **정형외과·재활의학과·응급**이 우선이다.
> - 인터넷 자가 테스트·철봉·아픈 채로 참고 하는 스트레칭은 **파열을 키울** 수 있다.
> - 스테로이드 주사·소염제·충격파는 **적응·금기·횟수**가 있다. 임의 반복 금지.
> - 왼쪽 어깨 + 흉통·호흡 곤란·식은땀이면 **119·응급실**.
