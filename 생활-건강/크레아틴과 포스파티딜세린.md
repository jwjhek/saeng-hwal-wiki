# 크레아틴과 포스파티딜세린

> **분류:** 생활·건강 · [[생활위키 목차]]

운동·집중·회복 쪽에서 자주 거론되는 **보충제 두 가지**를 개념·근거 감각·사용 시 주의만 정리한다.  
제품 광고·인플루언서 용량을 그대로 따르지 말고, **라벨·의사·약사**를 우선한다.

> **면책**  
> 의료·영양 **진단·처방·섭취 권유가 아니다**.  
> 질병·임신·수유·청소년·신장·약 복용 중이면 사용 전 전문가와 상담한다.  
> 효과·안전성 연구는 사람·용량·제품마다 다르고, 과장 광고가 많다.

확인일: 2026-08-06

---

## 1. 한눈에

| | 크레아틴 (Creatine) | 포스파티딜세린 (PS) |
|--|---------------------|---------------------|
| 정체 | 근육·뇌에 있는 **에너지 완충** 관련 화합물 | 세포막(특히 뇌)의 **인지질** 성분 |
| 흔한 목적 | 근력·고강도 반복, 일부 인지·회복 연구 | 스트레스·코르티솔·인지·운동 후 회복 **주장** |
| 근거 밀도 | 스포츠 보충제 중 **연구가 매우 많음** | 연구 있으나 크레아틴보다 **편차·한계**가 큼 |
| 흔한 형태 | 모노하이드레이트 분말 | 대두·해바라기 유래 연질캡슐 등 |

둘 다 “만병통치”가 아니다.  
크레아틴은 **운동 수행** 쪽 합의가 상대적으로 뚜렷하고, PS는 **목적·근거를 더 까다롭게** 보는 편이 안전하다.

---

## 2. 크레아틴

### 2.1 무엇인가

간·신장·췌장에서 일부 합성되고, 붉은 고기·생선에도 있다.  
근육에서는 **포스포크레아틴**으로, 짧은 고강도 운동 때 ATP를 다시 만드는 데 쓰인다.

```text
고강도 짧은 수축 (스프린트, 무거운 중량)
        ↓
ATP 소모 → 포스포크레아틴이 완충
        ↓
저장량이 충분하면 반복·파워에 유리할 수 있음
```

보충제로 먹는 이유는 음식으로만 채우기 번거롭고, 채식·저육식에서는 저장량이 낮은 경우가 많아서다.

### 2.2 형태

| 형태 | 메모 |
|------|------|
| **모노하이드레이트** | 가장 많이 연구·가성비. 기본 선택 |
| HCl, 완충형, 액상 등 | 마케팅이 앞서는 경우 많음. 필수 아님 |
| 크레아틴 + 대량 자극제 부스터 | 다른 성분 효과를 크레아틴 탓으로 오해하기 쉬움 |

### 2.3 용량·타이밍 (감각)

문헌·가이드에서 자주 보는 패턴(개인차 큼):

| 방식 | 내용 |
|------|------|
| 유지 | 하루 **약 3–5 g** 모노하이드레이트 |
| 로딩(선택) | 짧게 고용량 후 유지 — **필수는 아님**. 안 해도 수주 내 저장량 상승 가능 |
| 타이밍 | “운동 직후만”보다 **매일 꾸준히**가 더 중요하다는 견해가 많음 |
| 물 | 평소보다 수분 섭취를 의식하는 사람이 많음 |

체중·신장 기능·의사 지시에 따라 달라질 수 있다.

### 2.4 기대할 수 있는 것 / 과장

| 비교적 자주 언급 | 과장·오해 |
|------------------|-----------|
| 고강도·반복 수행, 일부에서 제지방·회복 보조 | 스테로이드·급격한 “약” |
| 일부 인지·채식 관련 연구 관심 | 모든 질병 예방·치료 |
| | “간·신장 무조건 망가짐” (건강인·적정 용량 근거와 동떨어진 공포 마케팅도 많음) |

**신장 질환·의사 주의 대상**이면 임의로 보충하지 않는 쪽에 가깝다.  
체중 증가(수분)가 초기에 있을 수 있다. 경기 체급 선수는 감안.

### 2.5 실무 체크

- [ ] 모노하이드레이트, 불필요 블렌드 최소화  
- [ ] 하루 용량·수분  
- [ ] 카페인·다른 보충제와 섞인 “올인원” 라벨 확인  
- [ ] 이상 증상·기존 질환 → 중단·상담

## 3. 포스파티딜세린 (PS)

### 3.1 무엇인가

세포막의 **인지질**. 뇌 세포막에 상대적으로 많다.  
식품(내장육·콩 등)에도 있으나, 보충제는 **대두 또는 해바라기** 유래가 흔하다.  
콩 알레르기면 원료를 본다.

### 3.2 왜 팔리나 (주장 vs 현실)

마케팅·일부 연구에서 나오는 주제:

| 주제 | 감각적 정리 |
|------|-------------|
| 인지·기억·집중 | 연구 있음. **결과 불균일**, 대상·용량·기간 의존 |
| 운동·정신적 스트레스, 코르티솔 | 일부 운동 연구에서 관심. **만능 항스트레스제 아님** |
| 운동 후 회복·근육통 | 근거가 크레아틴·수면·영양만큼 탄탄하다고 보기 어려움 |

“뇌 영양제 = 무조건 똑똑해짐”은 과장이다.  
수면·운동·질환·약물이 인지에 미치는 영향이 훨씬 클 때가 많다.

### 3.3 용량·형태 (감각)

시판·연구에서 **수십–수백 mg/일**대가 자주 보인다.  
제품마다 PS 순수 함량·인지질 복합 비율이 다르니 **원소 표시(mg PS)**를 본다.  
“권장량”을 이 문서가 정하지 않는다 → 라벨·전문가.

### 3.4 주의

- 혈액응고·혈압·진정·항콜린 등 **약물**과 겹칠 여지 → 약사·의사  
- 임신·수유·소아: 근거·안전 자료 제한 → 임의 고용량 비권장  
- 대두 유래: 알레르기·GMO 표기 선호 여부  
- 효과 체감이 애매하면 **비싼 장기간 맹신**보다 생활습선을 먼저  

---

## 4. 같이 먹을 때

둘을 **세트로 먹어야 하는 궁합**은 아니다.

| 상황 | 감각 |
|------|------|
| 근력·고강도 훈련 | 크레아틴 쪽이 우선 검토되는 경우 많음 |
| 시험·업무 스트레스만 | PS만으로 해결하려 하기보다 수면·부하 조절 |
| 둘 다 관심 | 각각 목적·용량·부작용을 따로 기록. 한 통에 섞인 부스터는 성분 표 확인 |

카페인·알코올·수면 부족이 있으면 보충제 체감이 흐려진다.

---

## 5. 고를 때 라벨 보는 법

1. **주성분 함량** (크레아틴 g, PS mg)  
2. 첨가 자극제·과당·과대 블렌드  
3. 인증·제3자 테스트(오염·함량) — 스포츠는 도핑 리스트도  
4. 원료 (PS: soy vs sunflower)  
5. 유통기한·보관(습한 곳의 분말 뭉침)  

의약품이 아닌 **건강기능식품·보충제** 규제는 국가·표시마다 다르다.  
“질병 치료” 표기는 규제·허위 여부를 의심한다.

---

## 6. 생활에서 더 큰 것

보충제 전에 보통 우선순위가 높다.

1. 수면  
2. 단백질·총 열량·수분  
3. 훈련 프로그램·점진 부하  
4. 질환·약·검진  

갤럭시 워치 등 활동·수면 기록은 **참고용**이다 ([[갤럭시 폰과 워치 사용법]]). 의료 기기가 아니다.

---

## 7. 정리

| | 한 줄 |
|--|--------|
| 크레아틴 | 고강도 수행 보조로 **연구·실사용이 많은** 보충제. 모노·꾸준함. 질환자 상담 |
| PS | 뇌·막 인지질. 인지·스트레스 **연구·마케팅 혼재**. 기대치 낮고 라벨·상담 |
