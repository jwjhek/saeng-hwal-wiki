# 방울토마토

> **분류:** 생활·건강 · [[생활위키 목차]]

**방울토마토**는 작은 토마토로, 생으로 먹기 쉬워 간식·샐러드에 흔하다. 
감량에서는 **부피·수분·단맛 욕구**를 달래는 쪽으로 [[다이어트 추천 음식]]에 자주 넣는다.

확인일: 2026-08-07

관련: [[다이어트 추천 음식]] · [[다이어트]] · [[오이]] · [[병아리콩]] · [[계란]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 소형 토마토. 빨강·황·주황 등 |
| 다이어트에서 | 칼로리 밀도 낮은 편 · 씹는 간식 · 채소 부피 |
| 맛 | 단맛이 있어 과자 욕구와 바꿔 쓰기 쉬운 집이 많음 |
| 주의 | 크림·치즈·오일 파스타에 묻히면 성격이 바뀜 · 산·역류 민감 |

---

## 2. [[다이어트]]와

| | 설명 |
|--|------|
| 장점 | 출출할 때 과자 대신, 접시 색깔·부피 |
| 조합 | [[오이]] · [[병아리콩]] 샐러드 · [[계란]] 옆 · [[스트링 치즈]]와 한 접시 |
| 함정 | 설탕·오일 잔뜩 구이만, 케첩·가당 소스와 동일시 |
| 방법 | 대부분의 식사 패턴에 무난. 원푸드 토마토만은 비추 → [[다이어트]] |

---

## 3. 고르는 법 · 먹는 법

| | 설명 |
|--|------|
| 고르기 | 탱탱·꼭지 상태. 무르면 빨리 소비 |
| 보관 | 너무 찬 냉장고만 고집하면 풍미↓라는 말도 있음. 집 환경에 맞게 |
| 생 | 씻어서 그대로 · 반 갈라 소금 살짝(나트륨) |
| 조리 | 구이·로스트(오일 양) · 수프 |

샐러드: 방울토마토 + [[오이]] + [[병아리콩]] + 식초·허브 정도가 담백한 편.

---

## 4. 주의

- 산·토마토에 민감하면 속 쓰림 
- 알레르기(드묾) 
- “디톡스 주스”로만 살 빼기 → [[다이어트]] 디톡스 항

## 6. 정리

방울토마토는 **먹기 쉬운 부피·간식용 채소(과일)** 다. 
[[다이어트 추천 음식]]의 한 칸이지, 단독 해법이 아니다.
