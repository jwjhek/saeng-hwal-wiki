# 전기자전거

> **분류:** 생활·건강 · [[생활위키 목차]]

**전기자전거**(e-bike)는 페달에 **전동기 보조**를 더해 오르막·출퇴근·장거리를 덜 힘들게 하는 자전거다. 
한국에서는 **페달 보조(PAS)** 와 **스로틀(손잡이만으로 주행)** 에 따라 **법적 분류·면허·도로**가 완전히 달라진다.

이 글은 **종류·법규 요약·고를 때·안전·관리**를 정리한다. 구매·튜닝·사고 대응은 **최신 법령·판매처·보험사**를 본다.

확인일: 2026-08-11

참고: [찾기쉬운 생활법령정보 — 자전거](https://easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=1&cciNo=1&cnpClsNo=1&csmSeq=719) · [전동킥보드 등](https://easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=1&cciNo=1&cnpClsNo=1&csmSeq=1506)

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 사람이 페달을 밟고, 필요할 때 **모터가 힘을 보태는** 자전거(합법 PAS 기준) |
| 쓰는 이유 | 출퇴근·장보기·어린이 통학·오르막. **땀 덜 나는** 이동·가벼운 유산소 |
| 한국 핵심 | **PAS 합격 모델** = 자전거. **스로틀만** 또는 불법 개조 = **개인형 이동장치(PM)**·원동기 취급 가능 |
| 면허 | PAS 합법 전기자전거는 **자전거와 같이 면허 없음**. PM·스로틀은 **원동기 면허** 등 필요 |
| 보험 | **의무 가입은 아닌** 경우가 많으나, 사고 시 부담이 커서 **자전거·상해보험** 검토를 권하는 설명이 많음 → [[보험 기초]] |

“전기자전거”라는 이름만 같고, **합법 여부는 구조·인증·속도 제한**으로 갈린다.

---

## 2. PAS vs 스로틀 — 법이 갈리는 지점

|              | **PAS**(페달 보조)                             | **스로틀**(손잡이·페달 없이 전기만)                  |
| ------------ | ------------------------------------------ | --------------------------------------- |
| 작동           | **페달을 밟아야** 모터 보조 (손페달 포함)                 | 페달 없이 **전기만**으로도 출발·주행                  |
| 법적 분류 (합격 시) | **전기자전거 = 자전거**                            | **개인형 이동장치(PM)** 등으로 분류되는 경우가 많음        |
| 면허           | **불필요** (합법 PAS·안전요건 충족)                   | **16세 이상 원동기 면허** 등 **필요**              |
| 도로           | **자전거도로** 이용 가능 (안전요건 충족 시)                | **차도** 중심. 자전거도로 **불가**에 가깝게 안내되는 경우 많음 |
| 헬멧           | **자전거용 안전모** (착용 의무·단속 강화 논의·시행은 시점·대상 확인) | PM 규정·**안전모**·음주 단속 등 **이륜에 가까운** 규율    |

```text
구매 전 확인
 ↓
① 페달 없이만 가는가? → 스로틀·PM 취급 가능성 ↑
② 시속 25km 넘으면 모터가 꺼지는가?
③ 전체 중량 30kg 미만인가?
④ 안전요건·인증 표시(제조사·모델)가 있는가?
 ↓
하나라도 “아니오”·불명 → 자전거도로·무면허 기대 금지
```

해외 직구·중고·**속도 제한 해제(튜닝)** 는 한국 도로에서 **불법·과태료·사고 책임** 문제로 이어질 수 있다. “빨라서 좋다”만 보지 말 것.

## 3. 합법 PAS 전기자전거 요건 (요약)

「자전거 이용 활성화에 관한 법률」 등에서 말하는 **전기자전거** 축(법령 개정 시 문구 확인):

| 요건 | 설명 |
|------|------|
| 동력 | **페달 + 전동기** 동시. **전동기만으로는 안 움직임** |
| 속도 | **시속 25km 이상**이면 **전동기 작동 중지** (속도 제한 장치) |
| 중량 | 장치 포함 **전체 30kg 미만** |
| 안전요건 | **안전요건 적합** 모델만 자전거도로 등 이용. 부적합 시 **과태료** 등 |

판매 페이지의 “최고속도 25km”만 믿지 말고, **제조사·인증·명세**와 **실제 구조(스로틀 단독 주행 여부)** 를 본다.

---

## 4. 종류·용도

| 유형 | 특징 | 메모 |
|------|------|------|
| **시티·통근형** | 랙·물통·흙받이. U자 자물쇠 | 출퇴근·마트 |
| **접이식** | 대중교통 환승·좁은 집 | 무게·단단함·배터리 위치 |
| **MTB·하이브리드** | 험로·레저 | PAS 합법 범위·헬멧·보호장구 |
| **카고·적재** | 짐 많음 | **중량·길이**로 30kg·자전거 규격 벗어날 수 있음 — 스펙 확인 |
| **스로틀·PM형** | 페달 없이 주행 | **면허·차도·PM 규정** 적용. “자전거 대체”로 착각 금지 |

[[배달하기]]에서 자전거 배달을 할 때도 **본인 차량이 합법 PAS인지**·플랫폼 규정·[[보험 기초]]를 따로 본다.

## 5. 고를 때 보는 스펙

| 항목 | 설명 |
|------|------|
| **모터** | 허브·미드 드라이브. 오르막·효율·소음·정비 난이도가 다름 |
| **배터리 (Wh)** | 와트시가 클수록 **주행 거리** 여유. 무게·가격↑ |
| **주행 거리** | 체중·바람·오르막·보조 단계에 따라 **절반 이하**로 줄기도 |
| **보조 단계** | Eco / Tour / Turbo 등. **높을수록 빨리 소모** |
| **브레이크** | 디스크 브레이크가 무거운 차량·비에 유리한 편 |
| **타이어** | 펑크 방지·폭. 노면·눈비에 따라 교체 |
| **프레임 크기** | 안장·핸들 조절. 발끝 닿는지 **매장·시승** |
| **AS·부품** | 배터리·모터 **국내 AS**·소모품 가용성 |

| 함정 | |
|------|--|
| “주행 100km” 광고 | 최저 보조·평지 기준인 경우 많음 |
| 배터리 **호환·중고** | 화재·성능 저하·인증 없는 배터리 위험 |
| **불법 튜닝** 가능 광고 | 법·보험·사고 모두 불리 |

## 6. 배터리·충전·화재

리튬 배터리 화재 사고가 뉴스에 나오는 경우가 있다.

| 습관 | 설명 |
|------|------|
| **정품·제조사 충전기** | 다른 기기 충전기 임의 사용 금지 |
| **과충전·과열** | 무인 충전·가연물 근처·햇볕 아래 장기 방치 주의 |
| **충격·침수** | 넘어짐·빗길 후 **이상 발열·냄새**면 사용 중단 |
| **보관** | 겨울 장기 보관 시 제조사 **권장 충전률** (보통 40~60% 전후 안내가 많음) |
| **배터리 수명** | 충전 사이클·년수 후 **용량 감소**. 교체 비용을 **총소유비**에 포함 |

화재·손상 시 **판매처·제조사·소방** 안내를 따른다. 이 글은 전기 안전 매뉴얼 전체가 아니다.

---

## 7. 도로·안전

### 7.1 통행

- **자전거도로**가 있으면 우선 이용 (합법 PAS·자전거 기준)  
- **보행자와 보도** — 자전거 통행 금지 구역·시간은 지역·표지 확인  
- **신호·방향** — 자전거도 **교통법규** 적용. 역주행·무신호 위험  
- **이어폰·휴대폰** — 주의 산만·단속 대상이 될 수 있음  

### 7.2 보호장구

| 장비 | 메모 |
|------|------|
| **헬멧** | 자전거용 안전모. PM·스로틀은 규정이 더 엄격할 수 있음 |
| **전조등·후미등** | 야간·터널 **필수**에 가깝게 안내 |
| **벨·반사** | 보행자·차량 인지 |
| **장갑·장화** | 넘어짐·비 오는 날 |

### 7.3 도난·주차

- **U자 자물쇠** + 고정물에 **프레임** 체결  
- 공용 충전·지하철 역 — CCTV·통행 많은 곳  
- 일련번호·구매 영수증 **사진 보관**

## 8. 보험·사고

| | 설명 |
|--|------|
| **의무** | 시점·차종에 따라 다름. **없다고 가정하지 말 것** |
| **자전거보험·상해** | 대인·대물·본인 상해. [[보험 기초]]에서 **실손·상해** 축과 별도로 검토 |
| **배달** | [[배달하기]] — 플랫폼·개인 보험·산재는 **별도** |
| **사고 시** | 부상·112·보험사 연락. **음주 운전**은 PM·자전거도 처벌 대상이 될 수 있음 |

“보험 없이 싸게”는 사고 한 번에 **배상·치료비**가 커질 수 있다.

## 9. 관리·계절

| 항목 | 주기·메모 |
|------|-----------|
| **타이어 공기압** | 주 1회 눈으로. 펑크·연비(전비)에 영향 |
| **체인·변속** | 소음·걸림 있으면 정비 |
| **브레이크 패드** | 마모 시 교체 지연 금지 |
| **볼트·퀵릴리즈** | 진동으로 풀리지 않았는지 |
| **펌웨어** | 스마트 모델은 제조사 업데이트 |
| **겨울** | 배터리 **추위**에서 거리 급감. 실내 보관·충전 |
| **여름** | 고온 충전·직사광선 주의 |

정기 점검은 **브랜드 정비점**·자전거 숍. 불법 개조 이력이 있으면 AS 거절·화재 위험이 커질 수 있다.

## 10. 운동·[[다이어트]]

전기자전거도 **페달을 밟으면** 활동량이 쌓인다. 보조를 높이면 체감 운동은 줄고, 낮추면 **일반 자전거에 가깝다**.

|          | 일반 자전거             | PAS 전기자전거                             |
| -------- | ------------------ | ------------------------------------- |
| 칼로리      | 같은 속도면 더 많이 쓸 수 있음 | 보조↑면 **적게**                           |
| 지속       | 오르막·더움에 지치기 쉬움     | **출퇴근·장거리 유지**에 유리                    |
| [[다이어트]] | 유산소 옵션으로 자주 언급     | “안 타게 되는” 대신 **이동+가벼운 유산소**로 쓰는 집도 많음 |

[[갤럭시 워치 사용법]] 등으로 걸음·심박을 보더라도, **의료 기기**는 아니다.

## 11. 실전 체크 (구매·운행 전)

- [ ] **PAS 합법** 모델인가 (스로틀 단독·25km 제한·30kg·인증)  
- [ ] **면허·도로**를 종류에 맞게 이해했는가  
- [ ] **헬멧·등화**·자물쇠를 준비했는가  
- [ ] 배터리 **정품 충전기**·화재 주의를 알고 있는가  
- [ ] **튜닝·해제** 상품을 피했는가  
- [ ] 보험·[[배달하기]] 규정을 필요 시 확인했는가

## 12. 정리

| 항목 | 한 줄 |
|------|--------|
| 핵심 | **PAS 합법** = 자전거. **스로틀·불법 개조** = 면허·PM·차도 쪽 |
| 구매 | 모터·배터리 Wh·AS·**법적 스펙**을 같이 본다 |
| 안전 | 헬멧·등화·배터리 화재 주의·도난 방지 |
| 보험 | 의무 아니어도 **사고 대비** 검토 |
| 건강 | [[다이어트]]·통근 **이동량** 늘리는 도구로 쓰기 쉬움 |

## 면책

> **강한 면책**  
> - **법률·교통·보험 자문이 아니다.** 면허·도로·헬멧·과태료는 **시점·모델·지자체**에 따라 다르다. [찾기쉬운 생활법령정보](https://www.easylaw.go.kr) 등 **공식 자료**를 본다.  
> - **스로틀·속도 제한 해제·불법 개조**는 처벌·사고·보험 거절 위험이 있다.  
> - 배터리 화재·충전은 **제조사 안내**를 따른다.  
> - 이 글은 구매 권유·특정 브랜드 추천이 아니다.
