# 틱장애

> **분류:** 생활·건강 · [[생활위키 목차]]

**틱장애**는 **갑작스럽고 반복적인** 움직임(운동 틱)이나 소리(음성 틱)가 나는 신경발달·정신과 질환군이다. 
아이 때 시작해 **들쭉날쭉** 변하는 경우가 많고, 가벼우면 지나가고 심하면 학교·직장·대인관계에 지장을 준다.

이 글은 **개념·일상과 구분·도움 방향**만 정리한다. 진단·치료는 **소아청소년과·정신건강의학과**에 맡긴다.  
관련: [[정신건강]] · [[강박장애]] · [[우울장애]] · 위기면 **1577-0199**.

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 틱이란 | **짧고 반복**되는 운동(눈 깜빡임·어깨 들쭉 등) 또는 **음성**(헛기침·코 훌쩍·단음 등) |
| 특징 | **의지와 무관하게** 튀어나오는 느낌. 잠시 **억누를 수** 있으나 긴장·불편이 따름 |
| 전조 | 틱 전 **불쾌한 느낌·충동**(전조 감각)이 있는 경우가 많음 |
| 변화 | 스트레스·피로·흥분 때 **늘고**, 집중·이완 때 **줄어** 보이기도 함 |
| 연령 | **어릴 때** 시작하는 경우가 많음. 경과는 사람마다 다름 |

“버릇”이나 “장난”과 **같은 말이 아니다.** 당사자도 멈추고 싶은데 어렵다고 말하는 경우가 흔하다.

---

## 2. 운동 틱 · 음성 틱

| 종류 | 예 (사람마다 다름) |
|------|-------------------|
| **운동 틱** | 눈 깜빡임, 얼굴 찡그림, 어깨 으쓱, 목 비틀기, 손·발 움직임 |
| **음성 틱** | 헛기침, 코 훌쩍, 목 긁는 소리, 짧은 음절·단어 (내용은 개인차 큼) |
| **단순 vs 복잡** | 짧은 한 동작/소리 vs 여러 동작이 이어지거나 의미 있는 말·제스처 |

운동만 있거나, 음성만 있거나, **둘 다** 있을 수 있다.  
틱 **종류·빈도·부위**는 시간이 지나며 바뀌기도 한다.

---

## 3. 진단 이름 (방향만)

의사가 **기간·종류·나이·다른 질환 배제**로 나눈다. 이름은 참고용이다.

| 이름 (개념) | 대략적인 기준 (의료가 판단) |
|-------------|------------------------------|
| **일과성 틱 장애** | 틱이 **짧은 기간**(보통 수 주~수 개월 미만) |
| **만성 틱 장애** | **1년 이상** 지속, 운동 또는 음성 틱 |
| **뚜렛 증후군** | **여러 운동 틱 + 음성 틱**이 1년 이상, 보통 **18세 이전** 시작 |

“뚜렛”은 **욕설·비속어**만을 뜻하지 않는다. 음성 틱의 일부일 뿐이고, **없는 사람도 많다.**  
미디어·유튜브에 나오는 극단적 모습만으로 판단하지 않는다.

---

## 4. 무엇과 헷갈리나

| | 틱 | 비슷해 보이는 것 |
|--|-----|------------------|
| 시작 | **갑작스럽고** 같은 패턴 반복 | 습관은 천천히 고정되는 경우 많음 |
| 억제 | 잠시 참으면 **긴장·불편** | 습관은 참기가 상대적으로 쉬운 편 |
| 전조 | **틱 직전 충동**이 있는 경우 | |
| 의도 | **원치 않는** 느낌 강조 | 의도적 장난·모방과 다름 |

| 다른 축 | 구분 포인트 |
|---------|-------------|
| [[강박장애]] | **사고·확인 행동의 순환**이 중심. 틱과 **함께** 있는 경우도 많음 — 감별·치료는 의료 |
| ADHD | 산만·충동과 **동반** 빈번 |
| 간질·이상운동 | **발작 양상·의식·EEG** 등으로 구분 — 의료 |
| 자폐 스펙트럼의 자극 행동 | **편안함·자극** 목적이 큰 경우. 겹칠 수 있음 |

인터넷 영상·체크리스트로 **자가 진단하지 않는다.**

---

## 5. 왜 생기나 (알려진 것만)

- **유전·뇌 회로** 요인이 큰 편으로 알려짐 (가족력이 있는 경우 있음)  
- **스트레스·수면 부족·카페인·흥분**이 악화 요인으로 자주 언급됨  
- **감염 후 급격한 악화** 등 논의는 있으나, 모든 틱에 해당하지 않음 — **개별 진료**  

“부모 탓·의지 부족”으로 돌리면 **치료·적응만 어려워진다.**

---

## 6. 경과

```text
어릴 때 틱 시작
 ↓
몇 주~몇 달 지나가는 경우 (일과성) 많음
 ↓
1년 이상 지속 → 만성 틱 / 뚜렛 등 이름 (의료 판단)
 ↓
사춘기 전후 증상 변동 큼 — 나아지기도, 형태만 바뀌기도
```

- **가벼운 틱**은 성인이 되어 **거의 안 보이는** 경우도 있다.  
- **중등도 이상**은 오래 남을 수 있어 **생활 맞춤·치료**가 필요할 수 있다.  
- 틱이 **한동안 없다가** 다시 생겨도 흔한 패턴이다.

---

## 7. 학교·직장·대인관계

| 상황 | 참고 |
|------|------|
| 또래·동료 | “그만 해” “신경 쓰인다”는 **지적이 악화**시키는 경우 많음 |
| 수업·회의 | 틱을 **의식하게** 만들면 빈도가 올라갈 수 있음 |
| 설명 | 필요 시 **짧게** “의학적 증상이라 참기 어렵다”고 알리기 (본인·보호자 선택) |
| 배려 | 틱을 **놀림·밈·모방**하지 않기 |

법적 **합리적 편의**(시험 시간·자리 배치 등)는 학교·회사 규정·진단서에 따른다.

---

## 8. 도움·치료 (방향만)

| 방향 | 설명 |
|------|------|
| **평가** | 틱 종류·기간·ADHD·[[강박장애]]·불안 등 **동반** 확인 |
| **행동 치료** | **CBIT**(틱에 대한 행동 중재) 등이 가이드라인에서 자주 언급됨 |
| **약물** | 빈도·고통이 클 때 **의사 처방**으로 고려 — **자가 복용 금지** |
| **동반 질환** | ADHD·OCD·불안이 있으면 **함께** 다루는 경우 많음 |
| **생활** | 수면·스트레스 관리 — **보조**이지 단독 치료 대체 아님 |

아이는 **“참아”만** 강요하기보다, 전문가·학교와 **같은 이해**를 맞추는 편이 낫다.

---

## 9. 하지 말 것

- 틱을 **의도적·버릇없이** 비난하거나 모방·밈으로 소비  
- 유튜브·커뮤니티로 **뚜렛 단정**  
- 처방 없이 **신경 안정제·보충제**로 막기  
- [[강박장애]]·[[우울장애]] 증상을 틱만으로 설명하려 하기  

개인 진단·약 이름·병원 기록은 공개 위키가 아니라 `private/`에만 둔다.

---

## 10. 실전 체크 (당사자·보호자·주변)

- [ ] 움직임·소리가 **반복·갑작스럽고**, 참으면 **불편**한가  
- [ ] 학교·직장·수면·관계에 **지장**이 있는가  
- [ ] **소아청소년과·정신건강의학과** 진료 경로를 알아 두었는가  
- [ ] [[강박장애]]·ADHD·불안이 **같이** 있으면 함께 말할 것  
- [ ] 주변에 **놀림·모방**이 있으면 교사·상담·진료에 연결  
- [ ] 위기(자해·극단적 생각) 시 **1577-0199**·응급실  

---

## 11. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | **반복·갑작스러운** 운동·음성 틱. 의지와 무관한 느낌이 강함 |
| 흔한 오해 | 버릇·장난·뚜렛=욕설 **아님** |
| 경과 | 어릴 때 시작, **들쭉날쭉** — 많이 나아지기도, 치료가 필요하기도 |
| 겹침 | [[강박장애]]·ADHD·불안 **동반** 흔함 |
| 핵심 | 자가 진단·낙인 없이 **전문 평가·행동 치료·필요 시 약물** |

---

## 면책

> **강한 면책**  
> - **진단·치료·약 처방 권유가 아니다.**  
> - 틱·뚜렛은 **개인차가 매우 크다.** 인터넷 영상·체크리스트로 자가 진단하지 않는다.  
> - 증상이 길어지거나 생활 지장·동반 불안·강박이 있으면 **소아청소년과·정신건강의학과**를 우선한다.  
> - 위기(자해·자살 생각 등)면 즉시 응급·위기 전화·가까운 응급실.  
> - 국내 위기 상담 예: **정신건강위기상담전화 1577-0199** (지역·안내는 바뀔 수 있음).
