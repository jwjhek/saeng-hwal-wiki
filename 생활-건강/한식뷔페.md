# 한식뷔페

> **분류:** 생활·건강 · [[생활위키 목차]]

**한식뷔페**는 밥·국·반찬을 손님이 **셀프**로 담는 한식 매장이다. 1인 **정액**이고 리필이 되는 집이 많다. 직장·학교 **창구**는 [[구내식당]], 집밥은 [[요리]], 앱 주문은 [[배달 앱]]을 본다.

호텔·패밀리 레스토랑 뷔페([[생일 혜택]]의 라세느·빕스 등)와 **가격대·메뉴가 다른 축**이다. 삼겹 등 **고기 무한리필**과도 같지 않다.

확인일: 2026-08-14  
가격·무한 여부·영업시간은 **그날 매장**이 우선이다.

관련: [[구내식당]] · [[요리]] · [[다이어트]] · [[거지맵]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 가판에서 한식을 담는 **정액 셀프** 매장 |
| **값** | 점심이 싸고 저녁·주말이 비싼 집이 흔함 |
| **누구** | 대개 누구나. 예약·시간 제한은 집마다 |
| **결제** | 카드·페이·현금. [[제로페이]]·지역화폐는 **가맹이면** |
| **무엇이 아님** | [[구내식당]], 호텔 뷔페, 고기 무한리필, 영양 처방 |

```text
한 끼가 필요
 ├─ 집 → [[요리]]
 ├─ 앱 → [[배달 앱]]
 ├─ 회사·학교 창구 → [[구내식당]]
 └─ 동네 한식 정액·셀프 → 한식뷔페
```

만원 이하 제보 지도는 [[거지맵]]. 뷔페가 찍혀 있어도 **당일 정액**을 본다.

---

## 2. 고를 때

| 항목 | 설명 |
|------|------|
| **형식** | 밥·국·나물·조림·구이·전·김치 등을 가판에서 담음. **리필**이 기본인 집이 많음 |
| **시간** | **브레이크 타임**이 있는 집도 있음 |
| **잘 맞는 때** | 반찬을 여러 가지, 혼자여도 1인 정액 |
| **덜 맞는 때** | 빨리 한 접시만, 전·튀김만 쌓으면 배만 부르고 값은 같음 |

매장에서:

- 회전이 빠른지(찬이 식고 말라 있으면 위생·맛 둘 다 떨어짐)  
- 집게·국자가 **음식마다** 있는지, 맨손 손님이 많은지  
- 국·찌개 온장, 생선·육류 재가열 상태  
- 음료·후식이 가격에 포함인지  

아이·노인·알레르기는 **원재료 표시가 약한** 집이 있다. 못 먹는 것이 있으면 직원에게 묻거나 다른 끼니를 고른다.

## 3. 담는 순서 · 과식

정액이라 본전을 채우려다 전·튀김·볶음밥만 쌓이기 쉽다.

[[다이어트]]를 보면 **단백질(생선·달걀·육류 살코기) + 나물**을 먼저 담고, 밥·국·전은 한 바퀴만 가는 편이 평균이 낫다. 질환 식단은 이 글이 정하지 않는다 → [[역류성 위염]] 등은 **진료**.

매일 뷔페만 가면 단가가 [[배달 앱]]보다 낮아도 **열량·나트륨**이 쌓이기 쉽다. 평균만 보면 된다 → [[다이어트]] §3.9.

| | 집밥 [[요리]] | [[배달 앱]] | 한식뷔페 |
|--|---------------|-------------|----------|
| 시간 | 조리+설거지 | 대기 | 이동+줄 |
| 분량 | 내가 정함 | 1인분이 큼 | 내가 담음 → **과식 쉬움** |
| 값 | 재료비 | 음식+배달팁+쿠폰 | 정액 |
| 쿠폰 | 마트 [[최저가와 쿠폰]] | 앱 쿠폰 | 매장 타임 세일 정도 |

## 4. 위생

셀프 가판은 **집게를 같이 쓰는** 구조다. 직원이 담는 [[구내식당]]보다 교차가 생기기 쉽다.

| 습관 | 이유 |
|------|------|
| 집게 손잡이만, 입 댄 젓가락으로 가판을 집지 않기 | 교차 |
| 뜨거워야 할 것이 미지근하면 건너뛰기 | 보관 온도 |
| 생선·계란·전복 등 **냄새·색**이 이상하면 남기기 | 한 접시 아깝다는 이유로 먹지 말 것 |
| 먹고 나서 구토·고열·혈변이 심하면 **진료**. 여럿이면 보건소 | 이 글이 진단을 하지 않음 |

매장 위생 등급·점검 스티커는 **참고**일 뿐이다.

|------|------|
| 카드·삼성페이 등 | 되는 집 많음 |
| [[제로페이]] · [[경기지역화폐]] · [[온누리 상품권]] | **가맹 매장만** |

## 면책

> **면책**
> - **특정 매장·체인 가입 권유가 아니다.**
> - 가격·메뉴·영업시간·페이 가맹은 **그날 안내**가 우선이다.
> - 영양·질환 식단·식중독 진단이 아니다. 알레르기·임신·당뇨 등은 **의료**.
> - 위생 문제는 개인 습관만으로 끝나지 않는다. 심한 증상은 **병의원·보건소**.
