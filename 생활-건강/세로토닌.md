# 세로토닌

> **분류:** 생활·건강 · [[생활위키 목차]]

**세로토닌**(serotonin, **5-HT**)은 뇌·몸에서 쓰이는 **신경전달물질**이자, 혈소판·장 등에서도 역할이 있다. 
기분·불안·수면·식욕·구역·장 운동 등과 **연관**되어 **항우울제(SSRI)** 논의의 중심에 자주 나온다.

「행복 호르몬」「세로토닌만 올리면 우울이 낫다」는 **단순화**가 많다. 
이 글은 **생물학 개념**만 정리한다. **진단·치료·보충제 권유가 아니다.**

확인일: 2026-08-13

관련: [[도파민]] · [[노르에피네프린]] · [[우울장애]] · [[정신건강]] · [[불면증]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **정체** | **5-히드록시트립타민**(5-HT) — 신경세포·일부 장 세포·혈소판 등 |
| **만들기** | 아미노산 **트립토판** → (효소 단계) → **5-HTP** → **세로토닌** |
| **흔한 연상** | **기분·불안·수면** — 실제로는 **뇌·장·혈액**에서 **역할이 나뉨** |
| **인기 말** | 「세로토닌 부족 = 우울」 — **모델일 뿐** 전부를 설명하지 못함 |

```text
식품·단백질 속 트립토판
 ↓
(장·간·뇌 등) 5-HTP
 ↓
★ 세로토닌 (5-HT)
 ↓
신경 전달 · 장 운동 · 혈소판 응집 등
```

---

## 2. 어디서·무엇을 하나

| 위치 | 역할 (개요) |
|------|-------------|
| **뇌** | 기분·불안·**수면·각성 리듬**·식욕·통증 감각 등 — **여러 회로** |
| **장(소화관)** | 장 운동·분비 — 체내 세로토닌 **대부분**이 장 쪽에서 만들어진다는 설명이 흔함 |
| **혈소판** | 출혈 시 **응집** — **뇌 기분**과 **직접 같지 않음** |

「장이 제2의 뇌」·**장-뇌 축**은 연구 주제지만, **우울 = 장만 고치면 된다**는 식의 SNS 말은 **과장**인 경우가 많다.

---

## 3. [[도파민]]·[[노르에피네프린]]과

| | 세로토닌 | [[도파민]] | [[노르에피네프린]] |
|--|----------|------------|---------------------|
| **전구** | **트립토판** | **티로신** | 도파민에서 합성 |
| **흔한 연상** | 기분·불안·수면 | 동기·보상 | 각성·스트레스 |
| **우울 약** | **SSRI** 등 | 간접·다른 계열 | **SNRI** 등 |

```text
[기분·불안 축] 세로토닌 ↔ 도파민 ↔ 노르에피네프린
        (한 가지만 부족한다고 단정하기 어려움)
```

[[우울장애]]는 **한 물질 부족**만으로 설명되지 않는다 — 약도 **SSRI·SNRI·기타**로 나뉜다.

---

## 4. 일상·증상과 (단순화)

| 현상 | 세로토닌과의 관계 (개념) |
|------|--------------------------|
| **우울·불안** | 뇌 **세로토닌 신호** 모델이 **항우울제** 설명에 쓰임 — **유일 원인 아님** |
| **수면** | 각성·수면 전환과 **겹침** — [[불면증]] · 멜라토닌 등 **다른 축** |
| **식욕** | 포만·탄수화물 욕구 등과 **연구** — [[다이어트]]와 단순 연결 주의 |
| **메스꺼움** | SSRI 초기 **구역**·항구토제(5-HT3 길)와 연결 |
| **편두통 등** | 혈관·신경에서 **5-HT** 관여 — **트립탄** 계열 약 |

**혈액 세로토닌**으로 우울을 **일반 진료에서 확정**하는 경우는 **드묾** — 증상·평가·치료 반응이 중심.

---

## 5. 약물 (방향만)

| 종류 | 세로토닌과의 관계 (개념) |
|------|--------------------------|
| **SSRI** | 뇌에서 세로토닌 **재흡수 억제** → 시냅스 가용량 **변화** — **새로 대량 합성**이 아님 |
| **SNRI** | 세로토닌 + [[노르에피네프린]] 재흡수 억제 |
| **삼환계·기타 항우울제** | 여러 경로 |
| **트란스더말 등** | MAO 억제 등 — **식품·약물 상호작용** 주의 |
| **항구토·항편두통** | 5-HT **수용체** 작용 |
| **일부 항정신병약** | 5-HT·[[도파민]] **동시** 조절 |

| 주의 | 설명 |
|------|------|
| **세로토닌 증후군** | SSRI + **트립탄·MAO억제제·일부 진통제** 등 **겹치면** 위험 — **고열·경련·혼돈** 등 **응급** |
| **갑작스런 중단** | **재발·전기쇼크 유사 증상** — **의사 지시**로만 |
| **[[아카시지아]]** | SSRI·SNRI **부작용** 가능 — 가만히 못 있음 등 **즉시 의사** |

약 선택·용량·중단은 **정신건강의학과** 등 **처방 의사**만.

---

## 6. 음식·보충제·「올리기」

| 주장 | 현실 |
|------|------|
| **치킨·칠면조 = 트립토판 → 기분 좋아짐** | 식사로 **뇌 세로토닌**이 **직접·크게** 오르기 **어렵다** — **혈뇌장벽**·다른 아미노산 경쟁 |
| **5-HTP·트립토판 보충제** | 마케팅 많음 — **우울 치료 대체 아님** · SSRI와 **겹치면 위험** 가능 |
| **「세로토닌 다이어트」** | **근거 약함** — [[다이어트]]는 **칼로리·수면·운동**이 먼저 |
| **햇빛·운동** | 기분·수면에 **도움** — **세로토닌만** 올린다고 단정하긴 어려움 |

[[보충제]]로 세로토닌을 「맞춘다」는 **자가 처방**은 권하지 않는다.

---

## 7. 흔한 오해

| 오해 | 현실 |
|------|------|
| **행복 호르몬 = 세로토닌** | [[도파민]]·엔돌핀·[[코르티솔]] 등 **여러 축** |
| **우울 = 세로토닌만 부족** | **스트레스·수면·질환·유전·생활사** 등 **복합** |
| **SSRI = 세로토닌 약** | **재흡수 조절** — 효과까지 **수 주** 걸릴 수 있음 |
| **장 세로토닌 = 기분** | **장**과 **뇌**는 **연결**되지만 **같지 않음** |
| **검사 한 번으로 부족 확정** | 임상에서 **흔하지 않음** |

---

## 8. 정리

1. 세로토닌(5-HT)은 **기분·불안·수면·장·혈소판** 등 **여러 역할**을 한다.  
2. **트립토판**에서 만들어지며, [[도파민]]·[[노르에피네프린]]과 **함께** 우울·불안 논의에 나온다.  
3. **SSRI** 등은 **신호 조절** 약이지, 「행복 물질 주사」가 아니다.  
4. 보충제·음식만으로 **정신건강 치료를 대체**하지 않는다.
