# 다이어트 추천 음식

> **분류:** 생활·건강 · [[생활위키 목차]]

감량·유지할 때 **자주 식단에 넣는 음식**을 모은 허브다.  
방법·운동·약은 [[다이어트]], 개별 식품은 아래 링크.

> **면책**  
> - **개인 식단·칼로리·질환 식 처방이 아니다.**  
> - “이것만 먹으면 살 빠짐”이 아니다. **전체 양·지속성**이 먼저다.  
> - 알레르기·신장·통풍·콜레스테롤·혈압약 등은 **상담** 후.  
> - 영양 숫자는 대략 감각이며, 제품·조리법마다 다르다.

확인일: 2026-08-07

관련: [[다이어트]] · [[병아리콩]] · [[방울토마토]] · [[스트링 치즈]] · [[계란]] · [[오이]] · [[위고비]] · [[마운자로]]

---

## 1. 한눈에

| 방향 | 감각 |
|------|------|
| 고르는 기준 | 포만·단백질·부피(채소) 대비 칼로리가 과하지 않은지 |
| 이 위키에 있는 예 | [[병아리콩]] · [[방울토마토]] · [[스트링 치즈]] · [[계란]] · [[오이]] |
| 한계 | 튀김·크림·당 음료·배달 과다가 남으면 단일 “건강 식품”으로 상쇄 어려움 |
| 약과 | [[위고비]]·[[마운자로]] 투여 중에도 **단백질·소화 편한 쪽** 상담이 많음 |

```text
[[다이어트]] 생활 축
        ↓
단백질 · 채소 · 간식 대체
        ↓
개별 식품 메모 (이 분류의 글들)
```

---

## 2. 식품 표

| 식품 | 다이어트에서 | 한 줄 |
|------|--------------|--------|
| [[계란]] | 단백질·간편 | 삶·프라이(기름 적게)·스크램블 |
| [[병아리콩]] | 단백질·식이섬유·포만 | 샐러드·hummus·조림 (통조림 염분 주의) |
| [[스트링 치즈]] | 단백질 간식 | 당 과자 대신. **나트륨·칼로리**는 제품마다 |
| [[방울토마토]] | 부피·간식·샐러드 | 단맛 욕구를 과일·간식으로 대체하기 쉬움 |
| [[오이]] | 부피·수분·저칼로리 감각 | 간식·무침. 짜장·마요와 과다 조합은 별개 |

공통: **양념·기름·소스**가 칼로리의 본체일 때가 많다.

---

## 3. 조합 예시 (참고)

처방이 아니다. 취향·알레르기·칼로리에 맞게 조절.

| 상황 | 예시 |
|------|------|
| 아침·간단 | [[계란]] + [[방울토마토]] · 또는 계란 + [[오이]] |
| 점심 샐러드 | [[병아리콩]] + 방울토마토 + 오이 + 간단 드레싱 |
| 출출할 때 | [[스트링 치즈]] 1개 · 또는 오이·방울토마토 |
| 저녁 곁들임 | 단백질 메인 + 오이·토마토 샐러드 |
| 피하기 쉬운 함정 | 병아리콩 튀김만, 치즈+크래커 과다, 계란 마요 무제한 |

저탄을 고수하면 병아리콩 양을 줄이는 집이 있고, 고단백이면 계란·치즈 비중이 올라가기 쉽다 → [[다이어트]] §3.

---

## 4. 고를 때·살 때

| 체크 | 감각 |
|------|------|
| 가공 | 같은 이름이어도 가당·튀김·크림 소스면 성격이 바뀜 |
| 나트륨 | 치즈·통조림 콩·절임 오이 |
| 유통 | 계란 신선도, 토마토·오이 무름, 치즈 유통기한 |
| 대체 | 병아리콩 ↔ 다른 콩, 스트링 ↔ 일반 저지방 치즈 등 — 집착 불필요 |

보충제([[종합비타민]], [[오메가3]])는 **결핍 보조**이지 이 식품들의 대체가 아니다.

---

## 5. 실전 체크

- [ ] “추천 음식”만 늘리고 배달·당음료는 그대로인지 점검  
- [ ] 단백질([[계란]]·[[스트링 치즈]]·[[병아리콩]])과 부피([[오이]]·[[방울토마토]])가 한 끼에 같이 가는가  
- [ ] 알레르기·질환·약과 충돌 없는지  
- [ ] 전체 틀은 [[다이어트]] (운동·수면·방법)  

---

## 6. 정리

다이어트 추천 음식은 **마법 재료가 아니라 반복하기 쉬운 선택지**다.  
[[계란]]·[[병아리콩]]·[[스트링 치즈]]·[[방울토마토]]·[[오이]]는 그 예시이고, 뼈대는 여전히 [[다이어트]]다.
