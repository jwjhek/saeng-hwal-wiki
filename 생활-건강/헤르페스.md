# 헤르페스

> **분류:** 생활·건강 · [[생활위키 목차]]

일상에서 **헤르페스**라고 하면 대개 **단순포진**(herpes simplex) — 단순포진바이러스(HSV)가 피부·점막에 **옹기종기 물집**을 만드는 병 — 을 가리킨다.  
입술 쪽을 **구순포진**, 성기 쪽을 **성기단순포진**(음부포진)이라고 부른다.

**대상포진**은 이름이 비슷해도 **수두-대상포진바이러스(VZV)** 로, 단순포진과 **다른 병**이다. 띠 모양 통증·물집, 백신 논의는 순환기·피부과·[[나만의닥터]] 예방접종 항목과 별개다.

이 글은 **개념·전염 구분·진료 시점**만 정리한다. 약·임신·성관계 가능 시점은 **피부과·산부인과·비뇨의학과**가 정한다.

확인일: 2026-08-14  
참고: [질병관리청 국가건강정보포털](https://health.kdca.go.kr) · 정책브리핑(2024-02, 단순포진)

관련: [[한포진]] · [[아토피 피부염]] · [[다래끼]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | HSV가 피부·점막을 감염 → 물집. 이후 **신경절에 잠복**했다가 **같은 근처**에 재발 |
| **완치** | 바이러스를 **몸에서 없애는 약은 아직 없음**. 증식 억제·증상 단축 약은 있음 |
| **전염** | **접촉**(물집·침·점막·피부가 정상처럼 보여도 균이 나올 수 있음). 공기로 결핵처럼 퍼지는 병이 아님 |
| **경과** | 전구(따가움) → 붉은 바탕에 **작은 물집이 모임** → 헐고 딱지 → 대개 **1~2주** |
| **재발** | 사람마다 다름. 평균 연 1회 정도로 이야기되나 더 잦을 수 있음. 시간이 지나면 **덜해지는** 집이 많음 |

```text
접촉으로 HSV 감염
 ↓
신경절에 잠복 (증상 없이 지내는 집도 많음)
 ↓
피로·자외선·스트레스 등 → 같은 부위에 물집
 ↓
자연 호전 또는 항바이러스(처방)
```

「입술 물집 = 불결」「한 번이면 평생 매일 전염」은 **과장**인 경우가 많다. 반대로 **물집이 없다고 절대 안 옮는다**도 아니다.

---

## 2. 1형과 2형

| | **HSV-1** | **HSV-2** |
|--|-----------|-----------|
| 흔히 | **입·얼굴** 주위 | **성기·항문** 주위 |
| 옮는 길 | 침, 입 맞춤, 입술 물집 접촉 | 성기·항문 점막·피부 접촉 |
| 교차 | 구강-성기 접촉으로 **성기에 1형**, 드물게 **입에 2형**도 가능 | |

위치만으로 형을 단정하지 않는다. 구분이 필요하면 **검사**(물집에서 핵산 등).

헤르페스과 바이러스에는 이 밖에도 수두-대상포진, 엡스타인바, 거대세포 등이 있다. **입술 물집 글에서 대상포진 백신을 맞추지 말 것.**

---

## 3. 어떻게 보이나

질병관리청이 정리한 단계다.

| 단계 | 일상에서 |
|------|----------|
| **전구** | 같은 자리가 **가렵고 따갑고 화끈**. 재발 경험이 있으면 “또 오겠다”고 느끼기도 |
| **물집** | 작은 물집이 **모여** 생김. 입술 아래가 흔함 |
| **헐음·딱지** | 터져 헐고 딱지. 보통 **7~10일**에 떨어지며 호전 |
| **성기 초감염** | 열·두통·피로, 통증·가려움 후 많은 물집·궤양. **증상이 없는 감염**도 많다는 설명이 있음 |

같은 자리에 반복되나, 잦으면 **조금 옆으로** 옮기기도 한다.

**눈:** 눈이 아프고 빛에 민감·시야가 흐리면 **안과 응급**에 가깝다. 입술 물집을 손으로 눈에 옮기지 말 것. [[다래끼]]와 **다른 병**.

**손끝 물집**(헤르페스성 손끝염)은 [[한포진]](습진)과 헷갈린다. 한쪽 손가락이 **아프고 모여 나는 물집**이면 짜지 말고 피부과.

**아토피** 피부에 헤르페스가 퍼지면(포진상 습진) **고열·급격한 확산**이 있을 수 있어 **빨리 진료**. → [[아토피 피부염]]

**드물게** 뇌염·전신 감염(신생아·면역 저하). 고열·의식·심한 두통·목 뻣뻣함은 **119**.

---

## 4. 전염을 줄이는 방향

완치가 아니므로 **노출을 줄이는** 쪽이다. 이 글이 성관계 허가가 아니다.

| 상황 | 설명 |
|------|------|
| **물집이 있을 때** | 입맞춤·성기 접촉·면도기·수건·립밤을 **같이 쓰지 않음**. 물집 만진 손 → 눈·다른 사람 |
| **물집 직후** | 공신 안내에 **딱지가 떨어진 뒤 1~2일**까지 접촉을 피하라는 설명이 있음 |
| **물집이 없어도** | 피부·점막이 멀쩡해 보여도 **균이 나오는(무증상 배출)** 때가 있음 |
| **콘돔** | 성기 헤르페스 위험을 **줄이나 덮이지 않는 피부**는 남을 수 있음 |
| **상대** | 사실·진료를 나누는 편이 안전하다. **법률 자문은 이 글 밖** |

신생아: **분만 때** 성기 물집이 있으면 아기에게 옮을 수 있다. 임신 중 재발 관리는 **산부인과**. 인터넷 주수·제왕절개 결정은 **처방이 아님**.

---

## 5. 재발을 부추기는 요인

잠복 바이러스가 다시 피부로 내려올 때 자주 거론되는 것:

| 요인 | 메모 |
|------|------|
| 피로·스트레스 | [[우울장애]]·수면과 겹치기도. 원인 확정은 아님 |
| **자외선** | 입술 구순포진 |
| 열·감기 | |
| 생리 | |
| 피부 상처·레이저·미용 시술 | 시술 전 **병력을 알림** |
| 면역 저하 | 약·질환. 주치의에게 HSV 병력 |

재발을 **0으로 만드는 민간요법·디톡스**는 근거가 약한 경우가 많다.

## 6. 병원에서 흔히 하는 것

| 방향 | 설명 |
|------|------|
| **진단** | 병력(같은 자리·전구·1~2주 자연 경과)만으로 충분한 집이 많음. 애매하면 물집 **핵산·배양** |
| **안 써도 되는 집** | 상처를 깨끗·건조하게 두면 **1~2주**에 낫는다는 안내. 모든 재발에 약이 필수는 아님 |
| **먹는 항바이러스** | 아시클로버, 발라시클로버, 팜시클로버 등. **증식을 억제**. 용법·신기능은 의사 |
| **언제 먹나** | **전구가 올 때 빨리** 쓰면 물집을 줄이거나 막을 수 있다는 설명이 있음. 미리 처방을 받아 두는 집을 안내하기도 |
| **연고** | 이미 물집이 커진 뒤에는 **효과가 제한적**이라는 설명이 있음 |
| **자주 재발** | 매일 소량 억제(억제 요법)를 논의. **처방** |
| **임신** | 만삭에 재발을 줄이려 약을 이야기하는 지침이 있음 — **산부인과** |

약 이름을 나열한 것은 **검색용**이다. 용량·며칠은 이 글이 정하지 않는다.

[[항히스타민]]은 가려움 보조일 뿐, 바이러스를 죽이지 않는다.

---

## 7. 하지 말 것 · 진료를 서두를 것

| 하지 말 것 | 서두를 것 |
|------------|-----------|
| 물집을 **짜기** | 눈 통증·시야 이상 → **안과** |
| 입술 연고를 눈에 | 아토피 피부에 **급속 확산·열** |
| 스테로이드 연고를 **헤르페스로 알고** 바르기 | 손끝·성기 **첫 심한** 궤양 |
| 면역 저하인데 집에서만 | 임신·신생아 노출 의심 |
| 「수치」로 병원 미루기 | 고열·의식·목 뻣뻣 → **119** |

성기 궤양은 **매독·다른 성매개감염**과 겹칠 수 있다. 한 가지 이름만 붙이지 말 것.

---

## 8. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | HSV에 의한 **반복 물집**(단순포진). 대상포진과 다름 |
| 잠복 | 신경절에 남아 **완치약은 없음** |
| 전염 | 접촉. 물집 때 가장 높고, **없어도** 나올 수 있음 |
| 관리 | 청결·자극 줄이기. 약은 **전구에 빨리**, 의사는 피부과 등 |
| 함정 | [[한포진]]·[[다래끼]]·다른 궤양과 혼동 |

---

## 면책

> **강한 면책**
> - **진단·항바이러스 처방·성관계·분만 방법 권유가 아니다.**
> - 물집은 **습진·세균·진균·다른 성매개감염**과 겹친다. **피부과·해당 과**가 우선이다.
> - 임신·신생아·눈·면역 저하는 **전문 진료**를 미루지 않는다.
> - 이 글은 **법률(고지 의무 등) 자문이 아니다.**
> - 인터넷 「완치 주사·독소 배출」은 거리 둔다.
