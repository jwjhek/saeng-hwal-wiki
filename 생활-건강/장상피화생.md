# 장상피화생

> **분류:** 생활·건강 · [[생활위키 목차]]

**장상피화생**은 오래된 **만성 위염** 등으로 위 점막 세포가 **장(소장·대장) 쪽 상피와 비슷하게 바뀐** 상태다. 
**위암이 아니지만**, 위암으로 이어질 수 있는 **위험 요인·전구 단계**로 보는 경우가 많아 **내시경 추적**이 중요하다.

이 글은 **개념·일상 관리**만 정리한다. **진단·치료·검사 간격은 담당 의사**가 정한다.

확인일: 2026-08-13

관련: [[나만의닥터]] · [[다이어트]] · [[요리]] · [[역류성 위염]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 위 점막이 원래 역할 대신 **장 상피와 닮은 세포**로 **바뀐 것**(화생) |
| **왜 걱정되나** | **위암 위험이 올라갈 수 있는** 소견 — **모든 사람이 암이 되는 것은 아님** |
| **어떻게 알나** | **위내시경** + **조직검사(병리)** 로 확정 |
| **흔한 배경** | **만성 위염** · **위축성 위염**과 같이 보고되는 경우 많음 |

```text
만성 자극(헬리코박터·짠맛·흡연 등)
 ↓
만성 위염 → (진행 시) 위축성 위염
 ↓
장상피화생 (일부)
 ↓
의사 판단 하 추적 내시경 · 제균·생활습관
```

**「암 선고」가 아니다.** 다만 **방치하지 말고** 병원 안내를 따르는 편이 안전하다.

---

## 2. 원인·위험 요인

| 요인 | 설명 |
|------|------|
| **헬리코박터 파일로리** | 만성 위염의 **대표 원인** — 감염·제균 여부는 검사로 확인 |
| **오래된 만성 위염** | 염증이 반복되면 점막이 **위축·화생**으로 갈 수 있음 |
| **나이** | 고령일수록 소견이 많아지는 경향 |
| **흡연** | 위암·위염 진행과 함께 거론 |
| **짠·자극적 식습관** | 염분·훈제·절임·매운 자극 **과다**는 피하는 편이 권고됨 |
| **가족력** | 위암 가족력이 있으면 **추적 간격**을 더 촘촘히 잡을 수 있음 |

원인을 **한 가지**로만 단정하기 어렵고, **겹치는 경우**가 많다.

---

## 3. 진단 — 내시경·병리

| 단계 | 설명 |
|------|------|
| **위내시경** | 위 안을 직접 봄 — 위축·화생 **의심 소견**이 보일 수 있음 |
| **조직검사** | 의심 부위 **조직을 떼어** 현미경으로 확인 — **진단은 병리 결과** |
| **병리 보고서** | 「장상피화생」 외에 **완전형·불완전형** 등 **분류**가 적힐 수 있음 — **위험도 해석은 의사** |

내시경 사진만으로 **위험도를 혼자 판단하지 않는다.** 
종이 **병리 결과·진료 기록**을 보관해 두면 추적 때 편하다.

---

## 4. 위암과의 관계 (과장·무시 둘 다 피하기)

| 구분 | 설명 |
|------|------|
| **지금** | **위암이 아님** — 다만 **앞으로 위험이 높아질 수 있는** 상태로 보는 경우 많음 |
| **진행** | 소수에서 **이형성증** 등을 거쳐 위암으로 가는 경로가 설명됨 — **기간·확률은 사람마다** |
| **불안** | 인터넷 「무조건 암 된다」 글은 **과장**인 경우 많음 |
| **방치** | 「별거 아니니까 내시경 안 함」도 **위험** — **추적 계획**을 의사와 정함 |

**얼마나 자주 내시경을 할지**는 병리 **형태·위축 범위·가족력·제균 여부** 등을 보고 **개인별**로 정한다.

---

## 5. 관리 — 병원에서 하는 것

| 항목 | 설명 |
|------|------|
| **헬리코박터 검사** | 혈액·호기·조직 등 — **양성**이면 **제균 치료**를 권하는 경우 많음 |
| **제균 치료** | 항생제 등 **복합 요법** — 완치 후에도 **추적 내시경**은 보통 계속 |
| **추적 위내시경** | 국가 **위암 검진**(고위험 외 일반)은 **2년** 간격 안내가 흔함 — **장상피화생·위축**은 **더 짧게**(예: **1년**) 잡는 경우 많음 — **담당 의사** 기준 |
| **이형성증** | 병리에 **이형성증**이 있으면 **간격·치료**가 달라짐 — 반드시 **소화기 내과** 상담 |

검사·약은 **자가 구매·인터넷 처방**이 아니다.

---

## 6. 생활습관·식단

의사·가이드라인마다 표현은 다르지만, 공통으로 자주 나오는 것:

| 권장 | 피하거나 줄이기 |
|------|----------------|
| **금연** | 담배 |
| **절주** | 과음·매일 음주 |
| **저염** | 짠 국물·절임·라면 스프 **과다**·가공육 **과다** |
| **신선한 채소·과일** | 극단적 **원푸드·디톡스** |
| **규칙적인 식사** | 배달 **자극적·기름진** 음식만 반복 ([[배달 앱]]) |
| **적정 체중** | 급격한 **굶기**·[[다이어트]] 극단법 |

「이 음식만 먹으면 장상피화생이 낫는다」는 **특정 음식 처방**은 근거가 약한 경우가 많다. 
[[요리]]·[[다이어트 추천 음식]]은 **짠맛·가공식 줄이기** 정도로 연결하면 된다.

**위산 역류**가 심하면 취침 전 과식·눕기 등은 증상 악화에 도움이 안 될 수 있음 — [[역류성 위염]] · 증상 있으면 **진료**.

---

## 7. 증상

| | 설명 |
|--|------|
| **있을 수 있음** | 속쓰림·더부룩함·명치 불편 — **만성 위염**과 비슷 |
| **없을 수도** | 검진·내시경 **우연히** 발견되는 경우도 많음 |

증상이 없다고 **추적을 생략**하지 않는다.

---

## 8. 진료 때 물어볼 것

- 병리 **완전형·불완전형** 등 내 결과의 **위험도**  
- **헬리코박터** 검사·제균 필요 여부  
- **다음 위내시경** 시기(몇 년·몇 개월)  
- **위축성 위염** 동반 여부와 의미  
- 가족 **위암 병력** 말할 것  
- 복용 중인 **진통제·아스피린** 등 위에 자극되는 약  

예약·병원 찾기: [[나만의닥터]] (비대면은 **재진·증상**에 따라 제한 — 내시경은 **대면**).

---

## 9. 자주 하는 오해

| 오해 | 실제 |
|------|------|
| 「암이다」 | **아님** — **위험 인자**로 **관리** |
| 「제균하면 끝」 | 제균 후에도 **추적** 필요한 경우 많음 |
| 「6개월마다 무조건」 | **모든 사람 동일 아님** — 과잉·부족 모두 의사 판단 |
| 「한약·디톡스로 치료」 | **대체 치료 권유 아님** |
| 「증상 없으니 괜찮다」 | **조용히 진행**할 수 있어 **추적**이 핵심 |

---

## 면책

> **강한 면책**
> - **의학적 진단·치료·검사 간격을 대체하지 않는다.** 병리·내시경 결과는 **담당 의사**가 해석한다.
> - 위암 **발생률·개인 예후**는 연령·병리·동반 질환마다 다르다. 인터넷 사례만으로 **공포·방치**하지 말 것.
> - 응급: **토혈·검은 변·심한 복통·체중 급감** 등은 **즉시 진료**.
