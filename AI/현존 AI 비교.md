# 현존 AI 비교

> **분류:** AI · [[생활위키 목차]]

2026년 기준으로, 일상·업무에서 만나는 **대화형 AI·코딩 AI·검색형 AI**를 정리한다. 
모델 이름·요금·벤치마크는 수시로 바뀌므로, **역할과 장단점** 위주로 읽고 세부 버전은 각 서비스에서 확인한다.

확인일: 2026-08-06

---

## 1. 먼저 알아둘 것

### AI가 하는 일 (현실적으로)

- 글을 쓰고, 요약하고, 번역하고, 아이디어를 펼친다
- 코드를 읽고 고치고, 명령을 제안한다
- 이미지·음성·문서를 입력받아 설명한다 (멀티모달)
- 웹·파일·도구를 붙여 **에이전트**처럼 여러 단계를 수행하기도 한다

### AI가 못 하거나 위험한 일

- **항상 사실을 보장하지 않는다** (환각/할루시네이션)
- 최신·로컬·비공개 정보는 연결이 없으면 모른다
- 법률·의료·금융 결정은 전문가를 대체하지 않는다
- 입력한 내용이 학습·로그에 쓰일 수 있다 (기업·민감 정보는 정책 확인)

### 용어 짧게

| 용어 | 의미 |
|------|------|
| LLM | 대규모 언어 모델. ChatGPT 등에 들어가는 “두뇌” |
| 챗봇 / 어시스턴트 | 채팅 UI로 LLM을 쓰는 제품 |
| 멀티모달 | 텍스트뿐 아니라 이미지·음성·영상 등 |
| 컨텍스트 윈도우 | 한 번에 넣을 수 있는 맥락 길이 (길수록 긴 문서·코드에 유리) |
| 에이전트 | 도구를 쓰며 여러 단계 작업을 이어 가는 모드 |
| 오픈 웨이트 | 가중치를 공개해 직접 돌리거나 커스텀 가능한 계열 |
| API | 채팅창이 아니라 프로그램에서 모델을 호출 |
| RAG | 질의 때 문서 청크를 검색해 붙이는 방식. 상태를 남기지 않는 경우가 많음 |
| LLM Wiki | ingest 때 LLM이 **마크다운 위키**를 만들·갱신하고, 질의는 그 위키를 읽는 패턴 → [[LLM Wiki]] |

## 2. 큰 지도 — 무엇을 고를지

```text
일상 질문·만능 비서 ────── ChatGPT, Gemini, Claude, Grok, Meta AI
근거 있는 조사·인용 ────── Perplexity (+ 검색 특화)
코딩·저장소 수정 ──────── Cursor, Claude Code, Copilot, ChatGPT/Claude
문서·메일·시트 안 ──────── Microsoft Copilot, Gemini (Workspace)
싸게 / 직접 호스팅 ────── DeepSeek, Llama, Mistral, Qwen 등
```

**한 줄 요약**

| 목적 | 우선 후보 |
|------|-----------|
| 만능 기본값 | ChatGPT |
| 긴 글·신중한 추론·코딩 품질 | Claude |
| 구글 문서·Gmail·Drive | Gemini |
| 실시간 이슈·X(트위터) 맥락 | Grok |
| 출처 달린 조사 | Perplexity |
| Office 365 안에서 | Microsoft Copilot |
| 에디터에서 코드 수정 | [[Cursor 사용법\|Cursor]] (+ Claude/GPT 등) |
| 비용·자체 서버 | DeepSeek / Llama / Mistral |

만능 1등 제품은 없다. **작업 종류에 따라 바꿔 쓰는 것**이 정석이다.

## 3. 주요 제품 설명

### 3.1 ChatGPT (OpenAI)

- **무엇**: 가장 널리 쓰이는 대화형 AI. GPT 계열 모델.
- **강점**: 범용성, 생태계(앱·플러그인·음성·이미지), 자료·튜토리얼이 많음, 에이전트·도구 사용 폭이 넓음
- **약점**: 최고 성능 티어는 요금이 가파름, 긴 문서·코딩에서 Claude에 밀리는 평가가 자주 나옴, 정책·요금 변경이 잦음
- **이런 사람에게**: “하나만 쓴다면”, 이미지·음성·일상 업무를 한곳에서

사이트: [https://chatgpt.com](https://chatgpt.com)

### 3.2 Claude (Anthropic)

- **무엇**: 안전·신중한 응답을 강조하는 계열. Opus / Sonnet 등 등급.
- **강점**: 장문 작성·구조화, 코딩·리팩터, 지시 따르기, 에이전트형 개발 도구와의 궁합
- **약점**: 소비자용 부가기능·플러그인 생태계는 ChatGPT보다 좁은 편, 일부 주제는 거부가 더 엄격할 수 있음
- **이런 사람에게**: 글·문서·코드 품질이 중요, Cursor 등에서 모델로 자주 선택

사이트: [https://claude.ai](https://claude.ai)

### 3.3 Gemini (Google)

- **무엇**: Google DeepMind의 모델. 검색·Workspace와 연결이 핵심.
- **강점**: 긴 컨텍스트, 멀티모달, Gmail/Docs/Drive/Android와의 자연스러운 연동, 무료 체감이 괜찮은 편
- **약점**: “구글 밖” 워크플로만 쓰면 이점이 줄어듦, 제품명·플랜 bundling이 자주 바뀜
- **이런 사람에게**: 이미 구글 계정·문서로 일을 하는 사람

사이트: [https://gemini.google.com](https://gemini.google.com)

### 3.4 Grok (xAI)

- **무엇**: xAI의 어시스턴트. X(트위터)와의 실시간 연결이 차별점.
- **강점**: 실시간 여론·이슈, 말투가 덜 딱딱하다는 평, 코딩·범용도 경쟁권
- **약점**: 에코시스템·기업용 문서화는 선두권보다 얇을 수 있음, 최고 기능이 높은 요금 티어에 묶이기도 함, “덜 검열”은 양날의 검
- **이런 사람에게**: 뉴스·SNS 맥락이 업무에 중요, Cursor 등에서 선택지로 쓰는 경우

사이트: [https://grok.com](https://grok.com) / X 앱 연동

### 3.5 Microsoft Copilot

- **무엇**: Microsoft 365·Windows·Edge에 심어진 어시스턴트. 뒤에 OpenAI 계열 등이 붙는 경우가 많음.
- **강점**: Word/Excel/Outlook/Teams 안의 초안·요약, 기업 계정·권한 모델
- **약점**: 365를 안 쓰면 매력이 급감, “순수 채팅 품질”만 보면 ChatGPT/Claude 앱과 겹침
- **이런 사람에게**: 회사 PC가 이미 Microsoft 중심
- **전용 글**: [[Microsoft Copilot]] · 웹 Office·초안 팁 [[Microsoft Copilot과 무료 Office]]
- **코딩용과 구분**: [[GitHub Copilot 사용법]] (이름만 비슷한 별개 제품)

### 3.6 Perplexity

- **무엇**: **검색 + 인용**에 최적화된 답변 UI. 여러 모델을 백엔드로 쓰기도 함.
- **강점**: 출처 링크, 조사·팩트체크 습관에 맞음
- **약점**: 창작·긴 코딩 에이전트보다는 “찾아 정리”에 특화
- **이런 사람에게**: 보고서·리서치 초안, “이 말의 근거가 뭐지?”

사이트: [https://www.perplexity.ai](https://www.perplexity.ai)

### 3.7 Meta AI (Llama 계열)

- **무엇**: WhatsApp·Instagram·Messenger 등에 붙어 있는 무료 AI. 모델 가문으로는 Llama.
- **강점**: 이미 쓰는 메신저 안에서 무료로 접근, 오픈 웨이트 Llama는 자체 호스팅·연구용으로 중요
- **약점**: 복잡한 업무·코딩·긴 추론에서는 유료 프론티어에 밀리는 경우가 많음
- **이런 사람에게**: 가벼운 질문, 메신저에서 바로, 또는 오픈 모델 실험

### 3.8 DeepSeek / Qwen / Mistral 등 (비용·오픈·지역)

| 이름           | 한 줄                                      |
| ------------ | ---------------------------------------- |
| DeepSeek     | API·채팅에서 **가성비**로 자주 언급. 코딩에도 강하다는 평     |
| Qwen (알리바바)  | 중국권·다국어·오픈/상용 라인. 에이전트·코딩 경쟁             |
| Mistral      | 유럽 거점, 효율·오픈/상용 균형. 규제·주권 이슈에 민감한 조직이 관심 |
| Llama (Meta) | 대표적 오픈 웨이트. 연구·온프레미스·커스텀                 |

**장점**: 저렴, 통제 가능(자체 배포), 실험 자유 
**단점**: 최고 프론티어 UX·툴링·안정성은 빅테크 챗 제품에 못 미치는 경우, 운영·보안은 사용자 책임

### 3.9 코딩에 특화된 “껍데기” (모델이 아니라 제품)

모델과 **제품을 구분**해야 한다.

| 제품 | 역할 |
|------|------|
| [[Cursor 사용법\|Cursor]] | VS Code 기반 에디터. 여러 LLM을 골라 Agent/Chat/Inline으로 코드 수정 |
| [[GitHub Copilot 사용법]] | IDE 자동완성·채팅. GitHub 생태계 |
| Claude Code 등 | 터미널·에이전트형 코딩 워크플로 |
| Windsurf 등 | Cursor와 비슷한 AI IDE 경쟁 제품 |

같은 Claude라도 **claude.ai 채팅**과 **Cursor Agent**는 체감이 다르다. 
컨텍스트(열린 파일·저장소)·도구(터미널·diff)가 붙기 때문이다.

## 5. 장단점 모아보기

### ChatGPT

- 장점: 만능, 자료 많음, 멀티모달·음성, 통합 넓음 
- 단점: 최고티어 비쌈, 분야별 1위는 아닌 경우가 많음

### Claude

- 장점: 글·코드·긴 추론, 지시 준수, 개발 도구와 궁합 
- 단점: “만능 엔터테인먼트/플러그인” 면에서는 ChatGPT에 밀릴 수 있음

### Gemini

- 장점: Workspace, 긴 컨텍스트, 멀티모달, 가격 체감 
- 단점: 구글 밖에서는 차별점이 줄어듦

### Grok

- 장점: X 실시간, 톤, 코딩도 경쟁 
- 단점: 엔터프라이즈·문서화·일관된 “안전한 기본값”은 취향/정책 이슈

### Perplexity

- 장점: 인용·조사 습관 
- 단점: 창작·대규모 리팩터의 메인 엔진으로는 보통 부족

### Copilot (Microsoft)

- 장점: 이미 쓰는 Office 안의 생산성 
- 단점: 365 밖에서는 존재감 약함

### 오픈/저가 모델 (DeepSeek, Llama, Mistral, Qwen…)

- 장점: 비용, 통제, 실험 
- 단점: 직접 운영 부담, 최고 UX·에이전트 완성도는 제각각

### Cursor 같은 AI IDE

- 장점: diff 검수, 저장소 맥락, 터미널·다중 파일 
- 단점: 구독 비용, 모델 품질에 종속, “자동 수락” 시 사고 위험 
- 상세: [[Cursor 사용법]]

## 7. 잘 쓰는 공통 원칙

1. **역할을 나눠 쓴다** — 조사는 Perplexity, 초안은 Claude/ChatGPT, 코드는 Cursor
2. **출처가 필요하면 검색형**을 쓰거나, 일반 챗봇에게 URL·자료를 `@`/`첨부`한다
3. **출력을 그대로 믿지 않는다** — 숫자·법률·의료·인용은 재확인
4. **민감 정보를 넣지 않는다** — 비밀번호, 개인정보, 비공개 코드(정책 허용 범위만)
5. **모델을 바꿔 가며 A/B** — 같은 질문을 두 곳에 넣어 보면 약점이 보인다
6. **코딩은 diff를 읽는다** — [[Cursor 사용법]]의 수락/거절 습관

프롬프트 뼈대는 [[Cursor 사용법]] 7절과 같다: 목표 · 위치 · 제약 · 합격 기준 · 참고 자료.

## 8. 요금·플랜 (감만)

대략적 개인 요금대 (세전·프로모션·번들 제외, 자주 변동):

- 무료 티어: 대부분의 챗 제품에 존재 (한도·모델 제한)
- 월 ~$20대: Plus / Pro / Advanced 급이 흔함
- 상위·에이전트·고한도: 수십~수백 달러대 플랜도 존재
- API: 토큰당 과금. 많이 돌리면 채팅 구독과 별개로 비용 발생
- Cursor 등 IDE: **에디터 구독 + (경우에 따라) 모델 사용량**

정확한 가격은 각 결제 페이지를 본다.
