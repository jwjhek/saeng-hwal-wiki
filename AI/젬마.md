# 젬마

> **분류:** AI · [[생활위키 목차]]

**젬마**(Gemma)는 Google DeepMind가 공개하는 **오픈 웨이트** LLM 가문이다.  
연구·가중치의 뿌리는 **제미니(Gemini)** 쪽과 겹친다고 안내하지만, **제미니 챗 제품이 아니다.** 직접 받아 [[Ollama]] · Hugging Face 등으로 돌린다.

개발자 허브: [https://ai.google.dev/gemma](https://ai.google.dev/gemma)  
Gemma 4 소개: [https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/](https://blog.google/innovation-and-ai/technology/developers-tools/gemma-4/)  
Gemma 4 카드: [https://ai.google.dev/gemma/docs/core/model_card_4](https://ai.google.dev/gemma/docs/core/model_card_4)  
Ollama: [https://ollama.com/library/gemma4](https://ollama.com/library/gemma4)

확인일: 2026-08-27  
크기·컨텍스트·라이선스·태그 이름은 **모델 카드·Ollama 라이브러리**가 우선이다. 이 글의 숫자는 고정 견적이 아니다.

관련: [[현존 AI 비교]] · [[Ollama]] · [[파라미터 수]] · [[RAG]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 구글이 가중치를 공개한 **모델 패밀리**. 챗 구독 앱이 아님 |
| 제미니와 | **Gemini** = 검색·Workspace에 붙는 **제품**. 젬마 = **직접 호스팅**하는 가중치 |
| 잘 맞음 | 로컬·온프레미스, [[RAG]] 생성 모델, 실험·미세조정 |
| 덜 맞음 | “구글 계정만 있으면 되는 비서” — 그건 [[현존 AI 비교]]의 Gemini |
| 입출력 (4대) | 텍스트 생성. 크기에 따라 **이미지·오디오 입력** 안내 |

```text
쓸 곳 정하기
 ├─ 브라우저 챗·Gmail     → Gemini 제품
 └─ PC·서버에 모델 파일   → 젬마 + [[Ollama]] 등
```

오픈 웨이트라도 **라이선스·이용 정책**은 세대마다 다르다. 상업 이용 전에 그 버전 카드를 읽는다.

---

## 2. 제미니와 한 줄

| | **제미니 (Gemini)** | **젬마 (Gemma)** |
|--|---------------------|------------------|
| 정체 | 구글 **서비스** | **모델 파일** |
| 실행 | gemini.google.com, 앱, API | 이용자 기기·서버, 또는 호스티드 런타임 |
| 데이터 | 구글 계정·약관 | 로컬이면 요청이 기기에 머무는 쪽에 가깝다. `:cloud` 태그는 예외 → [[Ollama]] |
| 이름 | Gemini 2.5 등 **제품 버전** | Gemma 3, Gemma 4 등 **가중치 세대** |

둘 다 Google DeepMind 연구 라인이다. **채팅창의 제미니를 젬마라고 부르면** 팀에서 헷갈린다.

---

## 3. 세대 (요약)

| 세대 | 메모 |
|------|------|
| Gemma 1·2 | 초기 공개. 지금은 후속 카드를 보는 편이 낫다 |
| **Gemma 3** | 멀티모달(텍스트·이미지), 여러 크기(270M~27B대 안내). [카드](https://ai.google.dev/gemma/docs/core/model_card_3) |
| **Gemma 4** | 2026년 공개 안내. 더 큰 컨텍스트, MoE·밀집 혼재. 아래 §4 |

실무에서 새로 받으면 **4** 카드를 먼저 보고, 옛 튜토리얼의 `gemma2` 태그와 **섞지 않는다.**

---

## 4. Gemma 4 크기 (카드 안내)

확인일 기준 카드·라이브러리에 나오는 축이다. **E**는 effective(실사용에 가깝게 적는 크기). 임베딩까지 합치면 표기보다 파라미터가 더 있다는 설명이 있다.

| 이름 (예) | 구조 | 컨텍스트 안내 | 자주 쓰는 자리 |
|-----------|------|----------------|----------------|
| **E2B** | 작은 밀집. 실효 약 2B대 | 128K | 폰·엣지·아주 약한 PC |
| **E4B** | 실효 약 4B대 | 128K | 노트북·가벼운 로컬 |
| **12B** | 밀집. 멀티모달 통합 안내 | 256K | 중간 GPU |
| **26B A4B** | **MoE**. 전체 약 26B, 활성은 약 4B대 | 256K | 소비자 GPU. `26B` 읽는 법 → [[파라미터 수]] |
| **31B** | 밀집. 품질을 올릴 때 | 256K | VRAM이 되는 워크스테이션 |

같은 `26B`라도 **전부 켜는 밀집**과 **일부만 켜는 MoE**는 VRAM·속도가 다르다. Ollama 태그는 `gemma4`, `gemma4:e4b`, `gemma4:26b`, `gemma4:31b`처럼 **라이브러리가 수시로 바뀐다.**

입출력: 텍스트 생성. 이미지 입력은 여러 크기에 안내. **오디오 입력**은 E2B·E4B·12B 쪽에 있고 31B·26B MoE는 이미지 중심이라는 식의 표가 카드에 있다. 쓰려는 **정확한 태그 카드**를 연다.

양자화(`Q4` 등)를 하면 파일·메모리가 줄어든다. GB 숫자는 이 글에 고정하지 않는다.

---

## 5. 돌리는 곳

| 경로 | 메모 |
|------|------|
| [[Ollama]] | `ollama run` 후 라이브러리에서 `gemma4` 검색. **`:cloud`는 로컬이 아님** |
| Hugging Face · Kaggle | 원본 가중치·미세조정 출발점 |
| llama.cpp · vLLM · LM Studio 등 | 서버·벤치. 공식 4 소개에 런타임 목록이 있음 |
| [[DGX Spark]] | 큰 체급을 책상에서 돌릴 때 후보 |

라이선스: **Gemma 4**는 소개 글에서 **Apache 2.0**이라고 안내한다. 이전 세대는 **Gemma 이용약관**인 적이 있다. **받은 파일의 라이선스 파일**이 최종이다.

금지·제한(안전 정책, 일부 사용)은 카드의 **사용 제한**을 본다. 가중치가 열렸다고 모든 용도가 허용은 아니다.

---

## 6. RAG·위키와

젬마는 **생성 모델**이다. 회사 PDF를 알게 하려면 가중치 안에 넣는 게 아니라 [[RAG]] 로 검색해 붙이거나, 자료를 긴 컨텍스트에 넣는다. 4대의 컨텍스트 안내는 **128K / 256K** 로 큰 편이라, 짧은 매뉴얼은 창에 넣고 긴 규정 묶음은 RAG가 낫다.

사람이 검수하는 마크다운 위키는 [[LLM Wiki]]·[[Obsidian 사용법]] 축이다. 젬마가 위키를 **대신 운영**하지는 않는다.

---

## 7. 고를 때

- [ ] 제미니 **챗**이 필요한지, **가중치**가 필요한지 구분했는가  
- [ ] 기기에 맞는 태그(E4B vs 26B vs 31B)인가  
- [ ] MoE `26B`를 밀집 26B로 착각하지 않았는가  
- [ ] 라이선스 파일이 **4 / 3** 중 어느 쪽인가  
- [ ] 민감 데이터면 로컬만, 클라우드 태그 제외  

한국어·코딩 체감은 벤치보다 **내 문서 몇 개**로 보는 편이 빠르다.

## 면책

> **면책**  
> 크기·벤치·라이선스·모달리티는 **카드·스토어가 개정**되면 바뀐다. 특정 태그 설치·상업 이용을 보장하지 않는다.  
> 로컬 모델도 환각이 있다. 의료·법률·금융 결정에 쓰지 않는다.  
> 리더보드 순위는 시점·채팅 프롬프트에 따라 갈린다.
