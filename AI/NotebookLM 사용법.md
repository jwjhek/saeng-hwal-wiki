# NotebookLM 사용법

> **분류:** AI · [[생활위키 목차]]

Google의 **소스 기반(source-grounded) AI 노트북**.  
내가 올린 PDF·문서·웹·유튜브 등만 근거로 요약·질문·오디오(팟캐스트형)를 만든다. 일반 챗봇보다 **환각이 적고, 인용으로 원문을 추적**하기 쉬운 편이다.

- 웹: [https://notebooklm.google.com](https://notebooklm.google.com)  
- 도움말: [NotebookLM Help](https://support.google.com/notebooklm)  
- Google 계정 필요. 설치 없이 브라우저(및 모바일 앱)로 사용.

> **이름 안내**  
> 2026년 들어 제품이 **Gemini Notebook**으로도 불리기 시작했다. 기존 NotebookLM과 같은 계열·노트북이 이어지는 경우가 많다. UI에 새 이름이 보여도 아래 개념(소스 → 채팅 → Studio)은 같다. 이 문서에서는 익숙한 이름 **NotebookLM**을 쓴다.

확인일: 2026-08-06 (기능·한도는 자주 바뀜)

---

## 1. 한 줄로 이해하기

| | NotebookLM | ChatGPT / Gemini 일반 채팅 |
|--|------------|---------------------------|
| 지식의 범위 | **내가 넣은 소스** 중심 | 학습된 일반 지식 + (켜면) 웹 |
| 답변 스타일 | 인용·출처 강조 | 폭넓은 추론·창작 |
| 강점 | 자료 소화, 학습, 조사 정리 | 만능 질문, 코딩, 아이디어 |
| 대표 기능 | Audio Overview(음성 개요), 스터디 가이드 등 | 플러그인·이미지·에이전트 등 |

**내 문서만 읽히는 AI 독서실**에 가깝다.  
세상 일반 상식을 물어보는 용도보다, **이 PDF/이 강의/이 위키 묶음을 이해하고 싶을 때** 쓴다.

관련: [[현존 AI 비교]]

## 2. 핵심 개념

### 노트북 (Notebook)

주제 하나당 노트북 하나.  
예: `생활위키 도구`, `프로젝트 A 요구사항`, `논문 세미나`.

노트북 안에는:

1. **Sources (소스)** — 근거 자료 목록  
2. **Chat** — 소스에 대해 질문  
3. **Studio** — 오디오·가이드·퀴즈 등 **산출물** 생성

### 소스 (Source)

AI가 참고하도록 넣는 자료. 같은 노트북의 소스끼리 연결·비교해 달라고 할 수 있다.  
소스가 빈약하면 답도 빈약하다. **좋은 원문 > 그럴듯한 프롬프트**.

### 그라운딩 (Grounding)

답변을 업로드한 내용에 붙잡아 두는 방식.  
그래도 AI 요약·오디오는 **틀리거나 과장할 수 있으니**, 중요한 문장은 인용을 눌러 원문을 확인한다.

---

## 3. 시작하기

1. [notebooklm.google.com](https://notebooklm.google.com) 접속 → Google 로그인  
2. **새 노트북** 만들기  
3. 소스 추가 (아래 4절)  
4. 채팅에 질문하거나 Studio에서 Audio Overview 등 생성  
5. 설정에서 **출력 언어(Output language)** 를 한국어로 두면 채팅·오디오가 한국어로 나오기 쉽다

모바일: 공식 앱이 있으면 이동 중 청취·간단 작업에 유용. 세부 설정은 웹이 더 풍부한 경우가 많다.

---

## 4. 소스 넣기

지원 형태는 시점에 따라 늘지만, 실무에서 자주 쓰는 것:

| 종류 | 예 |
|------|----|
| 파일 | PDF, 텍스트, 오디오 등 |
| Google | Docs, Slides (Drive에서 가져오기) |
| 웹 | URL 붙여넣기 |
| YouTube | 공개 영상 URL (자막·내용 기반 요약에 활용) |
| 붙여넣기 | 메모·회의록 텍스트 직접 입력 |

### 잘 넣는 습관

1. **주제별로 노트북을 나눈다** — 서로 무관한 PDF를 한곳에 넣으면 답이 섞인다  
2. **중복·잡음 소스를 줄인다** — 같은 글 초안 5개보다 최종본 1개 + 참고 2개  
3. **스캔 PDF**는 OCR 품질이 나쁘면 인식이 약하다. 가능하면 텍스트 PDF  
4. 웹 URL은 로그인·페이월 뒤 내용은 못 가져올 수 있다  
5. 한도(노트북당 소스 수, 파일 크기, 일일 생성 횟수)는 **무료/Pro**에 따라 다름 → UI·Help에서 확인

일부 화면에는 관련 자료를 찾아 주는 **리서치/소스 추천**이 있다. 넣을지 말지는 항상 사용자가 고른다.

---

## 5. 채팅으로 질문하기

소스를 넣은 뒤 가운데(또는 채팅) 패널에서 자연어로 묻는다.

### 잘 되는 질문 예

- `이 자료의 핵심 주장을 5줄로 요약해 줘`  
- `A 문서와 B 문서에서 서로 모순되는 부분이 있으면 짚어 줘`  
- `초보자가 먼저 읽어야 할 순서로 목차를 짜 줘`  
- `‘OO’ 개념이 나오는 모든 위치를 인용과 함께 보여 줘`  
- `시험 대비 예상 질문 10개와 모범 답안 요지를 만들어 줘`

### 덜 맞는 질문

- 소스에 없는 최신 뉴스·일반 상식만 묻는 것 → [[현존 AI 비교]]의 일반 챗봇·Perplexity  
- “법적으로 문제없냐”처럼 책임 있는 판단 → 전문가 + 원문 확인

답변의 **인용 번호/인용 문장**을 눌러 원소스 위치로 돌아가는 습관을 들이면, NotebookLM을 쓰는 이유가 산다.

---

## 6. Studio 산출물

Studio(스튜디오) 패널에서 소스 묶음을 **다른 형태**로 만든다.  
대표가 **Audio Overview(오디오/음성 개요)**.

### 6.1 Audio Overview (팟캐스트형)

소스 내용을 AI 진행자가 대화·요약 형태로 읽어 준다. 이동 중 학습·초안 브리핑에 강하다.

**기본 흐름**

1. 소스 1개 이상 준비  
2. Studio → **Audio Overview**  
3. (가능하면) Customize  
4. 생성 → 완료 후 재생 / 다운로드  
5. 생성 중에도 다른 작업·다른 화면이 가능한 경우가 많다

**포맷 예** (이름·지원은 UI 기준)

| 포맷 | 느낌 |
|------|------|
| Deep Dive | 두 호스트가 깊게 풀어 설명 (기본에 가까움) |
| The Brief | 짧은 핵심만 (수 분 이내) |
| The Critique | 자료에 대한 건설적 비평 톤 |
| The Debate | 서로 다른 관점으로 토론 |

추가로:

- **출력 언어** — 한국어 등 다수 언어 지원 (80+ 언어대까지 확대된 적 있음)  
- **길이** — Shorter / Default / Longer 등 (일부 옵션은 영어만인 경우 있음)  
- **포커스 프롬프트** — “보안 부분만”, “초보자 기준으로”처럼 강조점 지정  
- **Interactive / Join** — 듣다가 끼어들어 질문 (**현재 영어만**인 경우가 많음. Deep Dive·새로 생성한 오디오에서만 되는 제한도 있음)  
- **다운로드** — 저장해 오프라인 청취·전달  
- **공유** — 오디오 링크 / 노트북 전체 공유 / 파일 전달 (계정 종류·권한에 따라 공개 공유 제한)

주의:

- 오디오도 AI라 **과장·누락·말실수**가 난다  
- 큰 노트북은 생성에 수 분 걸릴 수 있다  
- “객관적 진실”이 아니라 **올린 소스의 반영**이다

### 6.2 그 밖의 Studio 산출물

버전에 따라 스터디 가이드, 브리핑 문서, FAQ, 퀴즈, 타임라인, 마인드맵, 슬라이드·인포그래픽·비디오 요약 등이 붙는다.  
공통점은 **소스를 다른 매체로 재가공**한다는 것. 없으면 UI에 아직 없는 기능이다.

## 7. 실전 활용

### 7.1 긴 PDF·매뉴얼 읽기

매뉴얼 PDF → 노트북 →  
`설치 절차만 단계로`, `에러 코드 표 정리`, Audio Brief로 출퇴근 청취.

### 7.2 강의·유튜브 복습

공개 강의 URL → 요약·퀴즈 → Deep Dive 오디오로 복습.

### 7.3 여러 자료를 한 주제로

논문 3편 + 회의록 + 사내 위키보내기 →  
`공통점/차이점`, `아직 결정 안 된 액션 아이템`.

### 7.4 이 생활위키와 함께

1. [[생활위키 목차]] 등 md를 PDF/텍스트로내거나 내용 붙여넣기  
2. NotebookLM에서 “도구별 역할 한 줄 요약”, “초보자 학습 순서”  
3. 좋은 문장만 골라 [[Obsidian 사용법\|Obsidian]] 노트에 반영  
4. 코드·파일 수정은 [[Cursor 사용법\|Cursor]]

NotebookLM은 **로컬 vault를 대체하지 않는다**. 이해·브리핑용이고, 장기 보관·링크는 Obsidian이 맞다.

### 7.5 팀 공유

노트북 공유·Pro 팀 기능은 플랜·시점에 따라 다르다.  
민감 자료는 공유 범위·회사 정책(구글 계정 종류)을 먼저 확인한다.

## 8. 장단점

### 장점

- 소스에 묶여 **근거 있는 요약·Q&A**  
- 인용으로 원문 검증이 쉬움  
- Audio Overview로 **읽기 부담을 듣기**로 전환  
- 주제별 노트북으로 자료 정리  
- 일반 챗봇 대비 “내 자료만”에 특화  
- Google 계정만 있으면 시작이 가벼움

### 단점

- 소스 밖 지식·최신 웹 탐색은 본업이 아님  
- 코딩 IDE·에이전트 작업은 Cursor/Claude 쪽이 맞음  
- 소스 수·용량·일일 생성 **한도**  
- 스캔·이미지 위주 PDF, 페이월 URL은 약함  
- 오디오·요약의 오류 가능성  
- 구글 클라우드에 자료를 올리는 것 — **보안·규정** 이슈  
- 제품명·UI(NotebookLM ↔ Gemini Notebook) 변경으로 메뉴 위치가 바뀔 수 있음

## 9. 다른 AI·도구와 역할 나누기

| 하고 싶은 일 | 추천 |
|--------------|------|
| 내가 가진 PDF/노트를 깊게 소화 | **NotebookLM** |
| 출처 링크가 있는 웹 조사 | Perplexity ([[현존 AI 비교]]) |
| 만능 질문·이미지·일상 | ChatGPT / Gemini 채팅 |
| 코드·로컬 파일 수정 | [[Cursor 사용법\|Cursor]] |
| 장기 개인 위키 | [[Obsidian 사용법\|Obsidian]] |
| 팀 DB·칸반 | [[Notion 사용법\|Notion]] |
| 구글 Docs 안에서 초안 | Gemini / Workspace |

한 줄:

> **조사(웹)** → Perplexity · **내 문서 학습** → NotebookLM · **작성·코딩** → Cursor/Claude · **저장** → Obsidian/Notion

## 10. 프라이버시·보안 (꼭)

- Google 측 정책상, NotebookLM에 올린 개인 소스가 **모델 학습에 쓰이지 않는다**고 안내되는 경우가 많다. 그래도 **약관·Help의 최신 문구**를 확인한다.  
- 회사 기밀·개인정보·수험·의료 기록은 올리기 전 규정 확인.  
- 공유 링크가 켜져 있으면 권한이 있는 사람이 소스·채팅에 접근할 수 있다.  
- “안 올린 내용은 모른다” ≠ “올린 내용이 외부에 절대 안 나간다”. 계정 보안(2단계 인증)도 기본.

---

## 11. 요금·한도 (감)

- **무료**: 개인 학습·소규모에 충분한 경우가 많음. 노트북당 소스 수·일일 오디오 생성 등에 한도.  
- **Pro / 상위 플랜**(Google AI 유료 번들과 묶이는 경우 있음): 한도 상향, 팀 기능 등.  

정확한 숫자·가격은 계정·지역·시점에 따라 다르니 앱 안의 플랜·[Help Center](https://support.google.com/notebooklm)를 본다.

---

## 12. 추천 워크플로 체크리스트

1. 주제 정하기 → 노트북 생성  
2. 출력 언어 = 한국어  
3. 핵심 소스만 업로드 (품질 > 개수)  
4. 채팅으로 요약·비교·용어 정리  
5. 인용 눌러 원문 확인  
6. Audio Overview로 이동 중 복습  
7. 쓸 문장만 Obsidian/업무 문서에 반영  
8. 민감 노트북은 공유 끄기·정리·삭제
