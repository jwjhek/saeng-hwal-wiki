# 파라미터 수

> **분류:** AI · [[생활위키 목차]]

로컬 모델·모델 카드에 **`7B`**, **`26B`**, **`70B`** 처럼 붙는 숫자는 대개 **파라미터(parameter) 개수**다.  
`B`는 **billion**(10억 단위)이다. `26B`는 파라미터가 약 **260억 개**라는 뜻이다.

확인일: 2026-08-27  
모델명·용량·VRAM은 **카드·런타임**(예: [[Ollama]])이 우선이다.

관련: [[현존 AI 비교]] · [[Ollama]] · [[DGX Spark]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 신경망에 들어 있는 **학습된 숫자(가중치)** 의 대략 개수 |
| 표기 | `26B` = 26 × 10억 = **260억** 개 |
| 쓰는 곳 | 오픈 웨이트 이름, Hugging Face·Ollama 카드, 하드웨어 안내 |
| 무엇이 아님 | IQ, 벤치마크 점수, 파일 용량(GB), 컨텍스트 길이 |

```text
이름 예:  Qwen2.5-7B-Instruct
              │    │
              │    └─ Instruct = 대화·지시용으로 다듬음
              └─ 7B = 약 70억 개 파라미터
```

클라우드 챗(ChatGPT 등)은 이 숫자를 **안 밝히는** 경우가 많다. 로컬·오픈 웨이트를 고를 때 더 자주 본다.

---

## 2. 숫자 읽는 법

영어 접미는 **SI가 아니라 관례**다. AI에서는 거의 항상 **1 B = 10^9 = 10억**.

| 표기 | 배수 | 한글 | 예 |
|------|------|------|-----|
| **M** | million, 10^6 | 100만 | `440M` ≈ 4.4억 개. 아주 작은 모델 |
| **B** | billion, 10^9 | **10억** | `7B` = 70억, `26B` = 260억, `70B` = 700억 |
| **T** | trillion, 10^12 | **1조** | 초거대 모델 안내에서 가끔 |

`26b`처럼 소문자도 같은 뜻으로 쓴다. 모델 이름과 상관없는 **용량 `26GB`** 와 헷갈리지 말 것.

한국 뉴스의 「260억 파라미터」와 카드의 `26B`는 **같은 규모**다. 「26억」으로 읽으면 한 자리 줄어든다.

---

## 3. 파라미터가 하는 일

LLM은 단어(토큰)를 받아 다음 토큰을 예측한다. 그 계산에 쓰는 **곱하고 더하는 계수**가 파라미터다. 학습이 이 숫자의 값을 맞춘다.

개수가 많으면 패턴을 더 세밀히 담을 **여지**가 커진다. 다만 실제 품질은 **데이터·학습 방법·구조·양자화**가 같이 가른다. **큰 숫자 = 무조건 똑똑함**이 아니다.

| 같이 보면 되는 것 | 파라미터와 다름 |
|-------------------|-----------------|
| **컨텍스트 윈도우** | 한 번에 넣을 수 있는 길이. `128K` 토큰 등과 [[현존 AI 비교]] |
| **활성 파라미터** | MoE(전문가 혼합)는 **전체 B**와 **한 토큰에 켜지는 B**가 다를 수 있음 |
| **양자화** (`Q4`, `Q8`) | 같은 7B라도 파일·VRAM이 크게 줄어듦 |

MoE 이름은 `8x7B`처럼 **전문가 개수 × 크기**로 적기도 한다. 카드의 **total / active**를 본다. 예: [[젬마]] 4의 `26B A4B`.

---

## 4. 고를 때 (로컬)

대략의 **체급**만 잡는다. VRAM·RAM·속도는 양자화·구현마다 다르다.

| 흔한 구간 | 자주 쓰는 자리 |
|-----------|----------------|
| **1B~3B** | 폰·아주 약한 PC. 짧은 초안 |
| **7B~9B** | 노트북·엔트리 GPU. [[Ollama]]로 일상 실험이 많은 구간 |
| **14B~32B** | 중급 GPU. 한국어·코딩 체감이 나아지는 경우가 많음 |
| **70B 전후** | 고VRAM·[[DGX Spark]]급. 느리면 못 씀 |
| **100B+** | 워크스테이션·클라우드·멀티 GPU 안내 |

같은 `26B`라도 **밀집(dense)** 와 **MoE**, **양자화 비트**가 다르면 체감이 갈린다. 받기 전에 카드의 **크기(GB)** 와 기기 메모리를 맞춘다.

클라우드 API 모델은 내부 B를 공개하지 않는 경우가 많아, **제품명·티어**로 고른다 → [[OpenAI Platform]] · [[현존 AI 비교]].

## 5. 한 줄

| 항목 | 메모 |
|------|------|
| `26B` | 약 **260억** 개 파라미터 |
| `B` | billion = 10억 단위 |
| 의미 | 모델 **체급**의 힌트. 지능 점수가 아님 |
| 용량 | B와 GB는 별개. 양자화가 가름 |
| 로컬 | 숫자보다 **내 VRAM에 들어가는지** |
