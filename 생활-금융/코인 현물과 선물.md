# 코인 현물과 선물

> **분류:** 생활·금융 · [[생활위키 목차]]

암호화폐 **현물(Spot)** 과 **선물(특히 무기한 선물, Perpetual)** 의 개념을 정리한다.  
거래소별 화면·조작은 [[업비트]], [[Bybit]] 문서를 본다.

> **강한 면책**  
> - 교육용 일반 정보이며 **투자·매매 권유가 아니다**.  
> - 선물·레버리지는 **원금 전액(그 이상 구조도 있는 상품)** 손실 위험이 있다.  
> - 거주국 **법률·세금·거래소 이용 가능 여부**를 스스로 확인한다.  
> - 이 글의 수치는 예시이며, 실전은 약관·화면이 우선이다.

확인일: 2026-08-07

---

## 1. 한눈에

| | 현물 (Spot) | 선물 / 퍼프 (Futures / Perp) |
|--|-------------|------------------------------|
| 무엇 | 코인을 **실제로 사고팜** | **가격 방향**에 베팅하는 계약 |
| 보유 | 거래소·지갑에 BTC 등 | 포지션(롱/숏) + 증거금 |
| 방향 | 주로 상승에 유리(보유) | **롱(상승)** / **숏(하락)** 둘 다 |
| 레버리지 | 보통 없음(마진 현물 제외) | 있음 → 이익·손실 증폭 |
| 만기 | 없음 | **무기한(Perp)** 또는 만기 선물 |
| 국내 예 | [[업비트]] 등 KRW 마켓 | 해외 파생 거래소 비중이 큼 ([[Bybit]] 등) |

코인판에서 “선물”이라고 하면 대개 **USDT-M 무기한 계약**을 말한다.  
전통 금융의 만기 선물과 비슷하지만, Perp는 **펀딩비**로 현물가에 붙도록 설계된다.

---

## 2. 현물 (Spot)

### 2.1 무엇인가

원화(KRW)·스테이블(USDT) 등으로 **코인을 매수·매도**해, 잔고에 코인(또는 현금)이 남는다.  
오른 만큼 팔면 이익, 내린 뒤 팔면 손실. **청산 레버리지가 없는** 기본 형태다.

### 2.2 주문

| 주문 | 의미 |
|------|------|
| 시장가 | 당장 체결, 호가 불리 가능 |
| 지정가 | 원하는 가격에 대기 |
| 예약·조건부 | 거래소마다 이름 다름 (지정가+트리거 등) |

수수료·스프레드를 빼야 “차트상 이익”과 통장 이익이 맞는다.

### 2.3 장단 (감각)

| 상대적으로 | 내용 |
|------------|------|
| 장점 | 구조 단순, 레버 청산 없음, 장기 보유·실사용(이체)에 맞음 |
| 단점 | 하락장에 숏으로 헤지하기 어렵고(현물만), 급락 시 심리적 물타기 |

### 2.4 보관

- **거래소 잔고**: 편하지만 거래소 리스크(해킹·출금 정지·파산)  
- **개인지갑**: 통제권↑, 시드 분실·피싱 책임↑  
- 거래에 쓸 만큼만 거래소에 두는 습관이 흔히 권장된다 (투자 권유 아님).

### 2.5 국내에서

원화 입출금·실명 확인이 붙은 거래소가 많다. → [[업비트]]  
세금·특정금융정보법·이체 한도는 **본인 상황·국세청·거래소 공지**를 본다.

## 3. 선물 · 무기한(Perpetual)

### 3.1 롱 / 숏

| | 의미 | 이익 나는 때 |
|--|------|----------------|
| **Long (매수)** | 가격 상승에 베팅 | 진입가보다 올라 종료 |
| **Short (매도)** | 가격 하락에 베팅 | 진입가보다 내려 종료 |

현물을 빌려 파는 것과 비슷한 효과를 **계약**으로 낸다.

### 3.2 레버리지와 증거금

- **레버리지 10x**: 대략 포지션 가치의 1/10만 증거금으로 잡힘 (단순화).  
- 가격이 **불리한 쪽으로 조금만** 움직여도 손실률이 커지고, **청산(강제 종료)** 에 닿을 수 있다.  
- “100배 = 100배 수익”만 보고 들어가면, **반대 방향 1%대 움직임에도** 치명적일 수 있다.

### 3.3 마크 가격 / 청산

| 용어 | 감각 |
|------|------|
| **Last / 시장가** | 체결된 최근 거래가 |
| **Mark Price (마크가)** | 청산·미실현 손익 계산에 쓰는 공정가에 가까운 가격 |
| **청산 (Liquidation)** | 유지증거금 밑으로 떨어지면 거래소가 포지션 강제 종료 |
| **파산가** | 증거금이 이론상 0에 가까운 가격대 (청산은 그 전에 진행되는 구조) |

**청산은 Last가 아니라 Mark 기준인 경우가 많다.**

### 3.4 크로스 vs 격리

| | Isolated (격리) | Cross (교차) |
|--|-----------------|--------------|
| 증거금 | **그 포지션에만** 묶음 | 계정의 **가용 담보를 공유** |
| 청산 시 | 넣은 마진 위주로 손실 한정에 가깝다 | **여러 포지션·잔고**가 영향 |
| 초보 감각 | **격리 + 낮은 레버리지** | 잔고 전체가 물릴 수 있음 |

거래소마다 기본 모드·이름이 다르다. → [[Bybit]]

### 3.5 펀딩비 (Funding)

- 롱·숏 한쪽이 주기적으로 다른 쪽에 수수료를 지급 (흔히 수 시간 간격).  
- 마크가 현물 지수보다 높으면 롱이 숏에게 내는 식의 **균형 장치**.  
- 가격이 안 움직여도 **펀딩으로 잔고가 줄/늘** 수 있다.

### 3.6 주문 종류 (파생 공통)

| 주문 | 의미 |
|------|------|
| Market | 즉시 체결, 슬리피지 가능 |
| Limit | 지정가에 대기 |
| Stop / Trigger | 조건 가격에 도달하면 시장/지정 주문 |
| Take Profit / Stop Loss (TP/SL) | 익절·손절 예약 |
| Reduce-Only | 포지션 **줄이는 방향만** |
| Post-Only | 메이커만 (조건에 따라) |

### 3.7 PnL

- **미실현 손익**: 아직 안 닫은 포지션 평가 (보통 Mark 기준)  
- **실현 손익**: 닫아서 확정 ± 수수료 ± 펀딩  

### 3.8 만기 선물

일부 거래소는 **분기 만기** 등 전통형 선물을 둔다.  
만기·정산·롤오버를 모르면 Perp와 섞어 쓰지 않는다.

## 4. 현물 vs 선물 — 언제 무엇을

| 목적 | 상대적으로 |
|------|------------|
| 장기 보유·실사용 | 현물 (+ 필요 시 개인지갑) |
| 단기 방향·헤지(숙련 전제) | 선물 |
| “빨리 크게” | 대개 **고배율 선물 = 고속 청산** |

선물은 **도구**이지 ATM이 아니다.  
헤지(현물 보유 + 숏)는 의도가 명확할 때만.

## 5. 공통 리스크·비용

| 패턴 | 왜 위험한가 |
|------|-------------|
| 고배율 + Cross | 한 심볼이 계좌를 끌어내림 |
| 손절 없음 | 청산가까지 방치 |
| 물타기만 반복 | 증거금·청산가 악화 |
| 펀딩 무시 장기 홀드 | 천천히 잔고 증발 |
| 가짜 사이트·시그널 방 | 해킹·사기 |
| 생활비·대출로 진입 | 회복 어려운 손실 |
| 거래소에 전 재산 | 거래소 리스크 |

비용: 거래 수수료, 입출금 네트워크 수수료, (선물) 펀딩·청산 비용, 스프레드·슬리피지.

**감당 가능한 돈만**, **미리 최대 손실**.  
연승 후 배팅만 키우는 패턴은 계좌를 끝내기 쉽다.

## 7. 실전 전 체크리스트 (개념)

- [ ] 현물과 선물의 차이를 말한다  
- [ ] (선물) 마크가·청산·펀딩·격리/교차를 안다  
- [ ] 거주국 이용·과세 이슈를 확인한다  
- [ ] 공식 도메인·2FA  
- [ ] 손실 감수 못 할 돈을 넣지 않는다  

---

## 8. 정리

1. **현물** = 코인을 사서 보유·매도.  
2. **선물(퍼프)** = 레버리지 달린 가격 계약 (롱·숏·청산·펀딩).  
3. 청산·마진을 모르면 선물 버튼을 누르지 않는다.  
4. 거래소별 실무는 [[업비트]]·[[Bybit]].
