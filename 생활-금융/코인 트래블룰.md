# 코인 트래블룰

> **분류:** 생활·금융 · [[생활위키 목차]]

**트래블룰(Travel Rule)** 은 가상자산 사업자(거래소 등) 사이에서 일정 규모 이상의 이체가 있을 때, **송금인·수취인 정보를 주고받도록** 하는 자금세탁 방지(AML) 규칙이다.  
은행 송금의 “보내는 사람·받는 사람 기록”과 비슷한 취지로 이해하면 된다.  
실무에서는 [[업비트]] 등 **국내 거래소 코인 입출금**에서 체감이 크다. 해외([[Bybit]] 등)·개인지갑은 거래소 정책마다 다르다.

> **강한 면책**  
> - 교육용이며 **투자·이체·우회 방법 권유가 아니다.**  
> - 법령·고시·거래소 약관·한도·연동 목록은 **자주 바뀐다.** 앱·공지·금융정보분석원(FIU)·고객센터가 우선.  
> - 이 글이 법률·세무·컴플라이언스 자문이 아니다.  
> - 트래블룰을 피하려는 분할 송금·타인 명의·미신고 거래소 이체는 **거절·계정 제한·법적 리스크**로 이어질 수 있다.

확인일: 2026-08-07

관련: [[업비트]] · [[Bybit]] · [[코인 현물과 선물]] · [[재정거래]]

---

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 목적 | 자금세탁·테러자금·불법 자금 이동을 어렵게 함 |
| 누가 | **가상자산사업자(VASP)** — 거래소 등이 정보 교환·확인 |
| 무엇을 | 이체와 함께 **이름·지갑/계정 식별** 등 (구체 항목은 법·사업자마다) |
| 사용자 체감 | “주소만 넣으면 출금”이 아니라 **수취 거래소·본인 지갑 등록·동의**가 붙음 |
| 기준 금액 | 국내에서는 흔히 **원화 환산 100만 원** 전후가 의무 기준으로 이야기됨. **거래소가 더 빡세게** 운영하기도 함 |
| 관련 법 감각 | 특정금융정보법(특금법) 등 AML 체계와 연결해 설명되는 경우가 많음 |

```text
보내는 거래소(VASP)  ──정보──→  받는 거래소(VASP)
        │                              │
   출금 신청·KYC                  입금 매칭·KYC
```

개인지갑·미연동 사업자는 **등록·화이트리스트·거절** 같은 별도 절차가 붙는다.

---

## 2. 왜 생겼나

| 배경 | 감각 |
|------|------|
| FATF | 국제자금세탁방지기구가 가상자산에도 은행식 “여행 규칙”을 권고 |
| 국내 | 특금법·신고 사업자 중심으로 이행. 시점·세부 요건은 개정·감독에 따라 변동 |
| 사용자 | 익명 주소만으로 거래소↔거래소 대량이체가 어려워짐 |

“코인 = 완전 익명”은 거래소 구간에서는 **맞지 않는** 경우가 많다.  
온체인 주소와 **실명 KYC**가 사업자 쪽에서 연결된다.

---

## 3. 사용자에게 보이는 것

거래소·시점마다 화면이 다르지만, 흔히 나오는 흐름이다.

| 상황 | 감각 |
|------|------|
| 거래소 → 거래소 | 출금 시 **받는 거래소·수취인**을 고르거나 검색. 연동(CODE, VerifyVASP 등 **솔루션**)이 안 되면 출금 불가인 경우 많음 |
| 본인 확인 | 보내는 계정 명의와 받는 쪽 명의가 **같아야** 하는 정책이 흔함 (타인 지갑·대리 출금 거절) |
| 개인지갑 | 메타마스크 등 주소를 **미리 등록·본인 확인**한 뒤에만 출금 허용하는 집이 많음 |
| 동의 | 수취 거래소에 개인정보가 넘어가므로 **제3자 제공·국외 이전 동의**가 붙는 경우 (정책·시점에 따라) |
| 입금 | 출처 불명·트래블룰 미이행 입금은 **지연·반환·추가 확인**될 수 있음 |
| 소액 | 법 기준 미만이어도 거래소가 **동일 절차·모니터링**을 요구할 수 있음 → 공지 확인 |

[[업비트]] 코인 입출금 조작 감각은 [[업비트]] §5.  
해외 거래소 쪽은 [[Bybit]] 입출금 + **상대(국내) 거래소 공지**를 같이 본다.

## 4. 국내 실무에서 자주 막히는 것

| 막힘 | 왜 |
|------|-----|
| 미신고·미연동 해외소 | 트래블룰 정보를 주고받을 상대가 없거나 정책상 차단 |
| 타인 명의 주소 | 동일인 원칙 |
| 미등록 개인지갑 | 사전 등록·인증 없음 |
| 네트워크·메모 오류 | 트래블룰과 별개로 **자산 손실** 위험 ([[코인 현물과 선물]]) |
| 분할 소액 반복 | 기준 미만으로 쪼개 보내기 → 이상거래로 볼 수 있음 |
| 점검·연동 장애 | 솔루션·상대 거래소 점검 시 입출금 대기 |

[[재정거래]]처럼 거래소 간 이체가 핵심인 전략은 **수수료뿐 아니라 트래블룰·지연**이 손익을 갈라먹는다.

---

## 5. 개인지갑 · 해외 거래소

| 경로 | 감각 |
|------|------|
| 국내 VASP → 등록 개인지갑 | 등록·본인확인 후 가능한 경우가 많음. 시드·피싱 책임은 본인 |
| 국내 VASP → 해외 VASP | 연동·동일 명의·동의·한도. **되는 상대 목록은 공지** |
| 해외 → 국내 | 입금 정책·트래블룰·반환 절차. 보내기 전 **국내 쪽 입금 가능 여부** 확인 |
| 지갑 ↔ 지갑 | 온체인만이면 거래소 트래블룰이 직접 안 붙을 수 있으나, **다시 거래소 입금** 때 출처 질문이 생길 수 있음 |

거주국·제재·거래소 이용 가능 여부는 스스로 확인한다. 이 위키는 우회를 안내하지 않는다.

---

## 6. 금액 기준 (감각)

| 말 | 감각 |
|----|------|
| “100만 원” | 국내 논의·이행에서 **원화 환산 100만 원 이상**이 자주 기준로 언급됨 |
| 환산 시점 | 어느 시세·어느 통화로 보는지는 **사업자 기준** |
| 거래소 강화 | 100만 원 **미만**에도 연동·등록 지갑만 허용하는 등 **더 엄격한 운영**이 나올 수 있음 |
| 하루·누적 | 단순 1건이 아니라 패턴 모니터링이 붙는 집이 있음 |

숫자를 외우기보다 **출금 직전 앱 안내·고객센터**를 본다.

---

## 7. 실전 체크 (이체 전)

- [ ] 코인·**네트워크**·메모/태그가 입금 화면과 일치하는가  
- [ ] 받는 곳이 **연동·입금 허용** 목록에 있는가 (공지)  
- [ ] 명의가 **본인**인가 (타인 주소 아님)  
- [ ] 개인지갑이면 **사전 등록**을 마쳤는가  
- [ ] 개인정보 제공·국외 이전 **동의**가 필요한가  
- [ ] **소액 테스트** 후 본금액  
- [ ] 이체 지연 중 가격·[[재정거래]] 노출을 감수할 수 있는가  
- [ ] 피싱(가짜 고객센터·지갑 연결)이 아닌가  

실패·반환은 수수료·시간·시세 손실이 날 수 있다.

---

## 8. 정리

트래블룰은 가상자산 이체에 **실명 정보가 따라가게** 하는 AML 규칙이다.  
사용자에게는 [[업비트]] 등에서 **출금 상대 제한·지갑 등록·동의·지연**으로 보인다.  
정책은 바뀌므로 이 글보다 **거래소 공지**가 우선이고, 우회·분할 송금은 위험하다.
