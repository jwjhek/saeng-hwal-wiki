# 업비트 (Upbit)

> **분류:** 생활·금융 · [[생활위키 목차]]

[업비트](https://upbit.com)는 국내에서 널리 쓰이는 암호화폐 **거래소**로, **원화(KRW) 현물** 거래가 중심이다.  
현물·선물 **개념**은 [[코인 현물과 선물]]을 본다. 해외 파생 예시는 [[Bybit]].  
코인 입출금 시 정보 교환·상대 제한은 [[코인 트래블룰]].

> **강한 면책**  
> - 교육용이며 **가입·투자 권유가 아니다**.  
> - 서비스·수수료·상장·출금 정책은 **자주 바뀐다**. 앱·[고객센터](https://support.upbit.com)·공지가 우선.  
> - 세금·신고는 국세청·세무사 기준. 이 글이 세무 조언이 아니다.  
> - 피싱 사이트·가짜 앱 주의 → **공식 도메인·스토어만**.

확인일: 2026-08-07

---

## 1. 위치

| | 업비트 |
|--|--------|
| 강점 감각 | KRW 마켓, 실명·규제 환경에 맞춘 국내 UX |
| 주력 | **현물** (코인 매수·매도) |
| 선물(무기한) | 국내 개인이 업비트에서 해외식 Perp를 쓰는 구조와는 다름 → 개념은 [[코인 현물과 선물]], 해외 거래소는 [[Bybit]] 등 |

“코인 산다”의 국내 기본 경로 중 하나로 이해하면 된다.

---

## 2. 가입 · 인증

1. 공식 앱/웹에서 계정  
2. **본인 인증·KYC** (신분증 등 — 안내에 따름)  
3. **은행 계좌 연결**(실명 확인 입출금)  
4. 보안: 비밀번호, **2FA(OTP)**, 출금 시 추가 인증  

미인증·일부 인증만으로는 입출금·거래 한도가 크게 막히는 경우가 많다.

모바일 OTP·보안: [[갤럭시 폰과 워치 사용법]]

---

## 3. 원화 입금 · 출금

### 입금

1. 안내된 **전용 입금 계좌**(또는 앱의 입금 절차)로 이체  
2. **본인 명의** 계좌만 — 타인 명의 입금은 문제가 된다  
3. 입금 반영 후 KRW 잔고 확인  

### 출금

1. 연결된 실명 계좌로 출금 신청  
2. 보안 인증·한도·지연(이상거래 점검 등) 가능  
3. 소액으로 한 번 테스트해 보는 습관  

은행·거래소 점검 시간에는 입출금이 밀릴 수 있다.

---

## 4. 현물 거래 흐름

1. **KRW 마켓**에서 코인 선택 (예: BTC, ETH — 상장 목록은 변동)  
2. 호가·체결 내역·차트 확인  
3. **매수/매도** — 지정가 또는 시장가(앱 표기)  
4. 주문·체결·잔고(코인·KRW) 확인  
5. 필요 시 다른 코인으로 교환(마켓에 따라 KRW 또는 BTC 마켓 등)

팁:

- 시장가는 급변 시 **불리한 체결** 가능  
- 수수료·스프레드를 반영해 수익률을 본다  
- “모든 코인 영구 상장”이 아님 — **거래지원 종료(상장폐지)** 공지 확인  

---

## 5. 코인 입출금 (개인지갑·타 거래소)

1. 입금: 코인·**네트워크** 선택 → 입금 주소·메모  
2. **네트워크 불일치 = 자산 손실** 위험  
3. 출금: 주소·수량·수수료·[[코인 트래블룰]](수취 거래소·지갑 정보·동의) 안내에 따름  
4. 소액 테스트 후 본거래  

해외 거래소([[Bybit]] 등)로 보낼 때는 상대 입금 네트워크·메모를 한 번 더 확인한다.  
연동·동일 명의·미등록 지갑 거절 등은 [[코인 트래블룰]].  
법·한도·신고 이슈는 본인이 확인한다.

---

## 6. 보안 체크

| 항목 | 내용 |
|------|------|
| 공식 앱 | 스토어 게시자·도메인 확인 |
| 2FA | SMS만보다 OTP 권장 감각 |
| 출금 비밀번호·화이트리스트 | 지원 시 사용 |
| 피싱 | “업비트 보안팀” 사칭 문자·텔레그램 |
| PC | 공용 PC 로그인 금지, [[크롬]] 확장 최소화 |

거래소에 장기·대량 방치는 **거래소 리스크**. 필요 시 개인지갑(시드 관리 책임).

---

## 7. 수수료·이벤트

- 거래 수수료는 레벨·이벤트·마켓에 따라 다름 → 앱의 안내  
- 입출금 수수료·최소 수량  
- 수수료 할인 이벤트는 **기간·조건**을 읽는다  

---

## 8. 세금·기록 (감각만)

국내에서 암호화폐 소득·기타소득 등 **과세 제도가 적용**되는 구간이 있다.  
연도·기준금액·신고 방법은 바뀐다 → **국세청 안내·전문가**.  
앱의 거래내역·입출금 내역을보내기해 두면 신고 때 도움이 된다.  
이 문서는 세율을 단정하지 않는다.

---

## 9. 업비트 vs Bybit (역할)

| | 업비트 | Bybit |
|--|--------|--------|
| 중심 | 국내 KRW **현물** | 글로벌 **현물+파생** |
| 입금 | 원화 은행 연동 | 코인 네트워크 입금 비중 |
| 선물 Perp | 이 문서 범위 밖(국내 규제·상품 구조 다름) | UTA 무기한 등 |
| 개념 문서 | [[코인 현물과 선물]] | 동일 |

둘 다 쓸 때도 **계정·자산을 섞어 관리 소홀**하면 실수·피싱에 취약하다.
