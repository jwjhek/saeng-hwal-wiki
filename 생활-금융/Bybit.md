# Bybit

> **분류:** 생활·금융 · [[생활위키 목차]]

[Bybit](https://www.bybit.com)은 암호화폐 **현물·파생(무기한·만기)·일부 옵션** 등을 제공하는 해외 거래소 중 하나다.  
현물·선물 **개념**은 [[코인 현물과 선물]]을 먼저 본다.

> **강한 면책**  
> - 교육용이며 **가입·투자 권유가 아니다**.  
> - 거주국에서 **이용 가능·제재·세금** 여부를 스스로 확인한다.  
> - UI·상품·UTA 규정은 자주 바뀐다 → [헬프센터](https://www.bybit.com/en/help-center)와 앱 표시가 우선.  
> - 피싱 도메인·가짜 앱이 많다 → **공식 사이트·스토어만**.

확인일: 2026-08-07

---

## 1. 위치

| | Bybit |
|--|--------|
| 성격 | 글로벌 파생·현물 비중이 큰 거래소 |
| 비슷한 곳 | Binance, OKX, Bitget 등 (메뉴만 다름) |
| 국내 원화 현물 | [[업비트]] 등과 역할이 다름 |

거래소 파산·해킹·출금 정지 리스크가 있다. **거래에 필요한 만큼만** 입금하는 습관이 흔히 언급된다 (권유 아님).

## 2. 가입 · 보안

1. 공식 사이트/앱에서 계정 생성  
2. **KYC**(필요 시) — 한도·기능에 영향  
3. **2FA**(OTP 등)  
4. 출금 주소 화이트리스트·안티피싱 코드  
5. 이메일·SMS·시드 피싱 주의  

모바일: [[갤럭시 폰과 워치 사용법]]의 보안 감각과 같이 OTP 앱을 분리해 두는 사람이 많다.

---

## 3. 입금 · 이체 · 출금

### 입금

1. **Assets / 자산** → Deposit  
2. 코인·**네트워크** 선택 (ERC20 / TRC20 / BTC 등 — **불일치 시 영구 손실**)  
3. 주소·메모(태그) 확인 후 **소액 테스트**  
4. 파생 거래 전 **UTA(통합 계정)로 Transfer**가 필요할 수 있음  

### 출금

1. 포지션·주문 정리  
2. 필요 시 파생 → 펀딩/현물로 Transfer  
3. Withdraw — 네트워크·주소·2FA  
4. 소액 테스트 후 본거래

## 4. Unified Trading Account (UTA)

Bybit **UTA**는 현물·파생 담보를 한계정에서 다루는 통합 구조다.  
마진 모드:

| 모드 | 감각 |
|------|------|
| **Isolated** | 포지션별 증거금 격리 — 연습·소액에 자주 권장되는 쪽 |
| **Cross** | 담보 공유 — 기본인 경우가 많음, 계좌 전반 위험 |
| Portfolio 등 | 고급. 모르면 쓰지 않음 |

초보 감각: **Isolated + 낮은 레버리지**.  
상세: [Margin modes (UTA)](https://www.bybit.com/en/help-center/article/Differences-Between-the-Margin-Modes-Under-the-Unified-Trading-Account/)

청산은 보통 **Mark Price** 기준.  
[Liquidation (UTA)](https://www.bybit.com/en/help-center/article/UTA-Trading-Rules)

## 5. 선물(무기한) 사용 흐름

메뉴 이름은 앱/웹·언어에 따라 다름.

1. **Derivatives / 선물** → **USDT Perpetual** 등  
2. 심볼: `BTCUSDT`, `ETHUSDT` …  
3. 주문 전:  
   - 마진 모드 = Isolated (연습)  
   - 레버리지 낮게  
   - One-way / Hedge (헷지는 복잡)  
   - TP/SL 준비  
4. Limit 또는 Market 진입  
5. **Positions**에서 진입가·마크가·청산가·미실현 PnL  
6. Stop Loss는 청산가보다 **유리한 쪽**에  
7. Close / Reduce-only로 종료  

데모·테스트넷이 있으면 실돈 전에 프로세스만 반복 (제공 여부는 시점별).

포지션 가치 ≈ 가격 × 수량.  
필요 증거금 ≈ 포지션 가치 / 레버리지 (대략, 유지증거금·위험 한도 별도).

개념 복습: [[코인 현물과 선물]]

## 6. 현물

Assets에서 잔고 확인 → Spot 마켓에서 매수·매도.  
파생과 지갑이 나뉘어 있으면 Transfer로 옮긴다.  
장기 보유만이면 현물만으로도 충분하고, 굳이 선물을 켤 필요는 없다.
