# Sound Assistant

> **분류:** 모바일·결제 · [[생활위키 목차]]

**Sound Assistant**(사운드 어시스턴트)는 삼성 **갤럭시**용 **오디오·볼륨** 설정 앱이다. 
기본 **15단계** 볼륨을 **최대 150단계**까지 촘촘하게 바꾸는 **음량 간격 변경**이 가장 많이 쓰이는 기능이다.

**Galaxy Store** 전용. **삼성 갤럭시**에서만 동작한다.

확인일: 2026-08-11

관련: [[갤럭시 폰 사용법]] · [[갤럭시 워치 사용법]] · [[유튜브]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 볼륨 **단계 수**·**미디어/벨소리 우선**·**앱별 음량** 등을 세밀히 조절 |
| 설치 | **Galaxy Store** — `Sound Assistant` 검색 |
| Good Lock | **Good Lock** 안의 **모듈**로도 설치 가능 (같은 앱) |
| 대상 | **갤럭시** + **One UI** (버전마다 메뉴·기능 차이) |
| 비용 | **무료** (삼성 공식) |

```text
Galaxy Store → Sound Assistant 설치
 ↓
음량 간격 변경 (예: 1 = 가장 촘촘)
 ↓
볼륨 키 / 슬라이더로 미세 조절
```

이어폰·블루투스 스피커에서 **한 칸이 너무 크거나 작을 때** 특히 체감이 크다.

---

## 2. 설치

### 2.1 Galaxy Store에서 직접

1. **Galaxy Store** 실행  
2. **Sound Assistant** (또는 **사운드 어시스턴트**) 검색  
3. **설치** → 앱 아이콘 또는 **Good Lock** 목록에서 실행  

패키지: `com.samsung.android.soundassistant` (Galaxy Store 상세 페이지)

### 2.2 Good Lock 경로

[[갤럭시 폰 사용법]] §3.2와 같다.

1. Galaxy Store에서 **Good Lock** 설치  
2. Good Lock → **Sound Assistant** 모듈 **다운로드**  
3. 모듈 실행 = Sound Assistant 설정 화면  

Good Lock 없이 **단독 앱**만 깔아도 된다.

### 2.3 안 깔릴 때

| 상황 | 참고 |
|------|------|
| **비갤럭시** | **미지원** |
| 구형·해외 펌웨어 | Galaxy Store에 **없을** 수 있음 — One UI·지역 확인 |
| Play 스토어 | **공식 배포 아님** — Galaxy Store 우선 |

---

## 3. 음량 간격 변경 (핵심)

기본 볼륨은 **약 15단계**. Sound Assistant로 **간격**을 줄이면 **최대 150단계**까지 나눌 수 있다.

| 설정 | 체감 |
|------|------|
| **음량 간격 변경** 슬라이더 **왼쪽(작은 숫자, 예: 1)** | **가장 촘촘** — 한 번에 거의 안 움직임 |
| **오른쪽(큰 숫자)** | **거친** 조절 — 기본에 가깝게 |
| **중간(예: 2~3)** | 150단계와 15단계 **절충** (개인 취향) |

**설정 위치 (대략):** Sound Assistant → **음량 간격 변경** · **Change step volume**

적용 후 **볼륨 키**를 눌러 슬라이더 **눈금이 촘촘해졌는지** 확인한다.  
**스피커·유선 이어폰·블루투스** 모두에 적용되는 경우가 많다.

### 추천 감각 (참고)

| 쓰는 상황 | 간격 |
|-----------|------|
| 밤에 이어폰으로 **유튜브·음악** | **1~2** (촘촘) |
| 통화·벨소리만 | 기본 또는 **조금 거칠게** |
| 게임 (빠르게 올리기) | **5 이상** |

## 4. 자주 쓰는 옵션

메뉴 이름은 **One UI·앱 버전**마다 다를 수 있다.

| 기능 | 설명 |
|------|------|
| **미디어 볼륨 제어** | 볼륨 키가 **벨소리가 아니라 미디어**만 올리게 (영상·음악용) |
| **앱별 음량** | 볼륨 패널에서 **앱마다** 슬라이더 (게임 vs 음악) |
| **Flux Volume UI** | One UI 5+ **플로팅** 볼륨 UI (위치·스타일) |
| **볼륨 패널 위치** | 좌·우·플로팅 버튼 등 |
| **이어폰 연결 시 벨소리** | 벨·알람을 **이어폰으로만** 들을지, 스피커로 할지 |
| **좌우 밸런스** · **모노** | 청각·이어폰 편차 보정 |
| **멀티 사운드** | (지원 시) **두 앱** 동시 재생 — 예: 내비 + 음악 |
| **블루투스 메트로놈** | BT 이어폰 **영상 음성 지연** 보정 (±ms) |
| **콘서트홀 효과** | 공간감 EQ 프리셋 |
| **볼륨 키 길게 누르기** | 이전/다음 곡 등 (역방향 옵션 있음) |

[[유튜브]]·넷플릭스 시 **미디어 볼륨 제어** + **촘촘한 간격** 조합이 흔하다.

---

## 5. 볼륨 키·패널 사용 팁

| 팁 | |
|----|--|
| 볼륨 키 누른 뒤 **슬라이더 아래 점 3개** | **앱별 음량**·도구 모음 (버전별) |
| **플로팅** 볼륨 | 화면 가장자리 **버튼**으로 패널 호출 |
| **루틴**과 병행 | `이어폰 연결 → 미디어 볼륨 30%` 등 — [[갤럭시 루틴]] · [[갤럭시 폰 사용법]] §3.1 |
| **방해 금지** | 벨소리는 끄고 **미디어**만 조절하는 패턴과 맞음 |

워치에서 음량은 **워치·폰 각각** — [[갤럭시 워치 사용법]] 참고.

## 6. Good Lock·Theme Park

| 조합 | 용도 |
|------|------|
| **Sound Assistant** + **Theme Park** | 볼륨 패널 **색·테마** 커스텀 (Good Lock 모듈) |
| **Sound Assistant** 단독 | **간격·미디어·앱별**만 써도 충분한 경우 많음 |

테마만 바꾸고 싶을 때 Theme Park을 **추가** 설치한다.

## 7. 흔한 오해

| 오해 | 현실 |
|------|------|
| Good Lock 필수 | **Sound Assistant 단독** 설치 가능 |
| 시스템 설정에 있음 | **별도 앱** — Galaxy Store |
| 모든 안드로이드 | **삼성 갤럭시** 전용 |
| 간격 1이 항상 최고 | 너무 촘촘하면 **원하는 음량 맞추기**가 오히려 빡빡할 수 있음 — **2~3**도 시험 |
| 픽셀·타사폰 | **미지원** (유사 기능은 제조사별로 다름) |

## 8. 실전 체크리스트

- [ ] Galaxy Store에서 **Sound Assistant** 설치

- [ ] **미디어 볼륨 제어** 켜기 (영상·음악 위주면)  
- [ ] BT 이어폰 **영상 싱크** 안 맞으면 **메트로놈** 조정  
- [ ] One UI 업데이트 후 **메뉴 이름** 바뀌었는지 확인  

---

## 9. 정리

1. Sound Assistant는 갤럭시 **볼륨 단계·미디어·앱별 음량**을 세밀히 만드는 **공식 앱**이다.  
2. **음량 간격 변경**으로 15단계 → **최대 150단계** 미세 조절이 가능하다.  
3. **Galaxy Store**에서 설치 — Good Lock **모듈** 경로도 같다.  
4. 영상·음악·이어폰 사용자는 **미디어 볼륨 제어**와 함께 쓰는 경우가 많다.
