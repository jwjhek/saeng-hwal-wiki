# 네이버 페이

> **분류:** 모바일·결제 · [[생활위키 목차]]

**네이버 페이**(Npay)는 네이버 계정에 묶인 **간편결제**다. 
카드·계좌·**Npay 머니**·**Npay 포인트**로 **네이버 쇼핑·예약**과 제휴 온라인몰, 일부 **오프라인** 가맹에서 결제한다. 
**모바일 교통카드**(NFC·머니 충전)로 버스·지하철을 태그할 수 있고, **[[케이패스]]** 등록·**교통 이용 포인트** 프로모와 겹치는 경우가 있다. 
갤럭시에서는 **현장결제** 메뉴의 **삼성페이 탭**으로 [[삼성페이]] **MST** 단말에도 결제할 수 있다 — QR 가맹보다 **범위가 넓은** 오프라인 경로다. 
**네이버플러스 멤버십**과 겹치면 **쇼핑 적립·배송** 혜택이 커지는 경우가 많다.

비교: [[삼성페이]] · [[카카오페이]] · [[제로페이]] · [[케이패스]] · [[신용카드 소득공제]]

확인일: 2026-08-13

## 1. 개요

| 항목 | 내용 |
|------|------|
| 계정 | **네이버 ID** (로그인·본인인증) |
| 앱 | **네이버** 앱 · **Npay** 앱(10대 전용 등 별도) · PC 웹 |
| 결제 수단 | 등록 **카드** · **계좌** · **Npay 머니** · **Npay 포인트** |
| 강점 | 네이버 **쇼핑·예약·여행**과 **포인트·멤버십** 연동 · **모바일 교통카드** · 갤럭시 **삼성페이(MST) 현장결제** |
| 약점(상대적) | QR만 쓰면 **Npay 가맹** 위주 — **삼성페이 탭**·MST는 별도 (§4.2.2) |

```text
네이버 로그인 · 결제수단 등록
 ↓
온라인: Npay 버튼 / 네이버 쇼핑 결제
오프라인: QR·바코드 · (갤럭시) 현장결제 **삼성페이 탭** MST · (가맹) 비접촉
대중교통: 모바일 교통카드 NFC 태깅 (§4.3)
 ↓
포인트 적립 · 멤버십 실적 반영(조건별)
```

## 2. 결제 수단 정리

| 수단 | 설명 |
|------|------|
| **등록 카드** | 신용·체크 — 카드사별 **즉시할인·청구할인** 이벤트가 따로 붙을 수 있음 |
| **계좌** | 계좌 이체 결제 |
| **Npay 머니** | **선불 충전** 잔액 — 계좌·카드에서 충전 |
| **Npay 포인트** | 적립·이벤트로 쌓인 **포인트** — 결제 시 차감 |
| **Npay 머니카드** | 머니와 연동된 **체크카드** 형태 상품 (연회비·혜택은 상품별) |

**포인트로 결제한 금액**은 보통 **추가 적립 대상에서 제외**된다 — 멤버십·이벤트 안내 확인.

## 3. 시작하기

1. 네이버 **본인인증**·비밀번호·2단계 인증 정리  
2. 네이버 앱 또는 [Npay](https://pay.naver.com) — **결제수단 등록** (카드·계좌)  
3. **결제 비밀번호**·생체(지원 기기) 설정  
4. (선택) **Npay 머니** 충전 · **머니카드** 신청  
5. (선택) **네이버플러스 멤버십** 가입 — §5  

카드 추가는 **카드사 앱**에서 「네이버페이 등록」 경로도 있다.

## 4. 어디서 쓰나

### 4.1 온라인

| 채널 | 설명 |
|------|------|
| **네이버 쇼핑·스마트스토어** | 가격비교·스토어 결제 |
| **네이버 예약·주문** | 음식·미용·숙박 등 |
| **네이버 여행** | 항공·숙소 등 |
| **외부 쇼핑몰** | 결제창에 **Npay** 표시된 곳 — 적립·혜택은 **몰마다** 다름 |

상품 페이지의 **Npay+** · **최대 적립** 문구는 **멤버십·이벤트** 조건을 읽어야 실제와 맞는다.

### 4.2 오프라인

오프라인은 크게 **QR 현장결제**와 **삼성페이(MST) 현장결제** 두 갈래다. 
갤럭시 사용자는 **§4.2.2**가 QR 가맹보다 **쓸 곳이 많을** 때가 많다.

#### 4.2.1 QR·바코드

| 방식 | 설명 |
|------|------|
| **QR·바코드** | 가맹점에서 네이버·Npay 앱 **현장결제** 스캔 |
| **제휴 매장** | 편의점·일부 프랜차이즈 — **멤버십패스** 등 별도 혜택 |
| **네이버 주문** | [[네이버 지도]]·플레이스 연계 **매장 결제** |

QR은 **Npay 현장결제 가맹** 표시가 있는 곳 위주다.

#### 4.2.2 현장결제 — [[삼성페이]](MST) 연동

**Npay 앱 → 현장결제 → 삼성페이 탭**에서, 네이버페이에 등록한 **카드·머니·포인트**로 **MST** 단말에 결제하는 방식이다. 
[[삼성페이]] 앱을 따로 열지 않아도, **네이버페이 쪽 결제 수단**이 **카드 긁는 구역(MST)** 으로 나간다.

| 항목 | 설명 |
|------|------|
| **대상 기기** | **삼성페이를 지원하는 갤럭시** 안드로이드 — **아이폰·갤럭시 워치 현장결제**는 이 경로 **불가**(공식 안내) |
| **연령** | **만 14세 이상** (현장결제 공통) |
| **결제 수단** | 등록 **신용·체크카드** · **Npay 머니** · **Npay 포인트** |
| **가맹 범위** | **카드 MST가 되는 매장** — 편의점·식당 등 **QR 가맹이 아니어도** 되는 경우 많음 |
| **필수 앱** | **Npay** · **Samsung Wallet(삼성페이)** 최신 버전 — 일부 기기는 **모드 및 루틴** 앱 업데이트 필요 |

```text
Npay 앱 > 현장결제 > [삼성페이] 탭
 ↓
결제할 카드(또는 머니·포인트) 선택 · 본인 인증
 ↓
단말기 **카드 긁는 곳·IC 슬롯**에 폰 뒷면 대기 (MST)
 ↓
승인 · (조건) 포인트 뽑기·이벤트
```

**[[삼성페이]] 앱에서 직접 긁는 것과 차이**

| | Npay **삼성페이 탭** | [[삼성페이]] 앱 직접 |
|--|---------------------|---------------------|
| **단말·동작** | MST — **동일 계열** | MST·NFC |
| **결제 원천** | **네이버페이 등록** 카드·머니·포인트 | 월렛에 넣은 카드·교통 등 |
| **Npay 포인트** | **적립·포인트 뽑기** 등 Npay 혜택 경로 | 네이버페이 **미경유** |
| **멤버십·제휴** | QR 현장결제의 **제휴 멤버십 자동 적립**·일부 **멤버십패스**는 **안 붙을 수 있음** — 결제 화면 확인 |
| **카드 실적** | 등록 **카드** 결제 시 카드사 **실적·청구할인**에 보통 포함 |

**태깅 위치 (자주 헷갈림)**

- 편의점·자판기처럼 **NFC 패드와 MST 리더가 같이** 있는 단말: **NFC 패드가 아니라** **카드 긁는 곳·IC 넣는 곳**에 대야 한다 — [고객센터](https://help.pay.naver.com/faq/content.help?faqId=13758)  
- 삼성페이 탭에서 카드를 고르면 **NFC가 잠시 꺼지는** 동작이 정상일 수 있음 — 최신 **Samsung Wallet·모드 및 루틴** 확인  

**온라인 주문형 가맹**에서도 결제창 **일반결제**에 **삼성페이**가 뜨는 경우가 있다 — 매장·앱 버전별.

전 매장·전 카드가 되는 것은 아니다. 거절 시 **가맹점명·카드사**를 고객센터에 알리면 확인 가능하다고 안내한다.

### 4.3 모바일 교통카드 · K-패스 · 적립

**네이버페이 모바일 교통카드**는 **Npay 머니** 잔액으로 버스·지하철 등 **대중교통 단말기**에 **NFC 태깅**하는 서비스다. 
앱을 켜지 않고 태그하는 **선불 교통카드**에 가깝고, [[삼성페이]]의 **티머니 등 교통카드**와 **충전·실적 구조**가 다르다.

| 항목 | 설명 |
|------|------|
| **결제 원천** | **Npay 머니** — 미리 충전(계좌·카드) |
| **태깅** | **NFC** 지원 스마트폰 — 기기·OS별 지원 범위는 앱 안내 |
| **충전** | 충전·환불 **수수료 없음**(조건은 공식 안내) · **자동충전** 설정 가능 |
| **한도** | 1회·1일 충전 상한 등 — 앱 표기 |
| **이용 내역** | 네이버페이 앱에서 **교통 이용·잔액** 확인 |

```text
Npay 머니 충전 · 모바일 교통카드 발급/활성화
 ↓
버스·지하철 단말기 NFC 태깅
 ↓
(선택) K-패스에 「모바일 교통카드 번호」 등록 → 익월 환급
(선택) 교통 이용 포인트 프로모 → 조건 충족 시 Npay 포인트
```

#### 4.3.1 [[케이패스]] 연동

[K-패스](https://www.korea-pass.kr)에 **네이버페이 모바일 교통카드 번호**를 등록하면, 조건을 채운 달 **교통비 환급**을 받을 수 있다. 
자세한 **횟수·비율·지역**은 [[케이패스]] — 여기서는 **연동 방법**만 정리한다.

| 단계 | 내용 |
|------|------|
| 1 | 네이버페이 앱에서 **모바일 교통카드** 발급·번호 확인 |
| 2 | **K-패스** 공식 앱·사이트 가입 (미가입 시) |
| 3 | **모바일 교통카드 번호**를 K-패스에 **등록** — 플라스틱 K-패스 카드와 **번호가 다름** |
| 4 | 해당 카드로 **월 15회 이상** 등 조건 충족 시 **익월 환급** (충전금·비율은 공단 안내) |

**주의**

- 기존 **다른 K-패스 카드**를 쓰다가 네이버페이 교통카드를 새로 등록하면, **기존 등록이 해지**되는 식으로 바뀔 수 있음 — 공지 확인  
- 환급은 보통 **다음 달 20일 전후** **교통카드 충전금** 형태로 들어온다(시점·방식은 개정 가능)  
- K-패스 **환급**과 네이버 **포인트 적립**은 **별개** — 둘 다 조건을 따로 채움  

#### 4.3.2 교통 이용 **포인트 적립** (프로모)

네이버는 교통카드 **출시·K-패스 연동** 등을 기념해 **Npay 포인트** 프로모를 낸 바 있다. 예시(시점·종료 여부는 **공식 공지** 확인):

| 유형 | 예시 (과거·진행 중 프로모) |
|------|---------------------------|
| **K-패스 신규 등록** | 모바일 교통카드를 K-패스에 **처음 등록** 시 **일회성 포인트** |
| **전월 교통 이용액** | 전월 태깅 **금액 구간**별 **월 Npay 포인트** (예: 5만·10만·15만 원 이상) |
| **이용마다 적립** | 출시 당시 「탈 때마다 적립」 **예정** 안내 — **실제 진행 여부**는 혜택 탭 확인 |

**쇼핑 적립**(§5·§6)과 **교통 포인트**는 **이벤트명·중복 규칙**이 다르다. 
네이버 앱 **혜택** · [쇼핑&페이 고객센터](https://help.pay.naver.com) · [[최저가와 쿠폰]] §3.3에서 **확인일**을 갱신하는 편이 좋다.

#### 4.3.3 [[삼성페이]] 교통과 비교

| | 네이버페이 모바일 교통카드 | [[삼성페이]] 교통 |
|--|-------------------------|-------------------|
| 잔액 | **Npay 머니** 충전 | **티머니** 등 교통카드 충전 |
| K-패스 | **교통카드 번호** 등록 경로 | **K-패스 전용·후불 카드** 등 — [[케이패스]] |
| 적립 | 네이버 **포인트 프로모** | 카드사·삼성 **별도 이벤트** |
| 연말정산 | 머니·교통 **집계 방식**은 홈택스·간소화 확인 — [[신용카드 소득공제]] **대중교통 40%** 층과 **K-패스 환급**은 **제도가 다름** |

## 5. 네이버플러스 멤버십

유료 **구독** 서비스. 월·연 요금은 [멤버십 안내](https://nid.naver.com/membership) 기준(변동).

| 혜택 축 | 설명 (개요) |
|---------|-------------|
| **추가 적립** | **Npay+** 상품을 **네이버페이**로 결제 시 — 월 **유효 구매액** 구간별 **추가 포인트** (기본 적립 + 멤버십) |
| **적립 구간(예시)** | 공식 안내 기준 **월 20만 원까지** 높은 추가율, **20만~300만 원** 구간은 낮은 추가율 등 — **숫자는 시점마다 확인** |
| **N배송** | 조건 충족 시 **무료배송·교환·반납** (제외 상품·카테고리 있음) |
| **멤버십패스** | 오프라인 **제휴** 할인·쿠폰 |
| **디지털 콘텐츠** | **매월 하나** 선택 — §5.2 (넷플릭스·Xbox PC Game Pass·웹툰 쿠키 등) |
| **MYBOX** | 클라우드 용량 **추가** (멤버십 안내 기준) |

### 5.2 디지털 콘텐츠 — 넷플릭스 · Xbox · 웹툰 (택 1)

멤버십 요금(월·연) 안에 **디지털 이용권을 매월 하나** 고르는 혜택이 있다. 
**옵션 목록·쿠키 개수**는 시기마다 바뀌므로 [멤버십 MY](https://nid.naver.com/membership) · **콘텐츠+** 탭이 최종이다.

| 선택지 (예) | 포함 내용 (개요) |
|-------------|------------------|
| **넷플릭스** | **광고형 스탠다드** 이용권 — 멤버십료에 **포함**(추가 0원). Full HD·동시 2기기 등 **광고형 스탠다드**와 동급 |
| **Xbox PC Game Pass** | PC **게임 구독** — 엑스박스·PC 인기 타이틀 **시간·횟수 제한 없이**(공식 안내). **EA Play** 포함 |
| **네이버 웹툰·시리즈** | **쿠키** 묶음 (개수는 멤버십 화면 표기) |

```text
멤버십 가입 · MY > 콘텐츠+ / 디지털 혜택
 ↓
이번 달 혜택 1개 선택 (넷플릭스 / PC Game Pass / 쿠키 등)
 ↓
해당 서비스 계정 연결 · 이용
 ↓
(다음 달) 필요 시 다른 옵션으로 변경 — 규칙은 멤버십 안내
```

#### 넷플릭스 연동

| 항목 | 설명 |
|------|------|
| **신청** | 멤버십 **MY** → 디지털 혜택에서 **넷플릭스** 선택 → **계정 연결** |
| **기본 요금제** | **광고형 스탠다드** — 연결 단계에서 이 요금제를 선택 |
| **업그레이드** | **스탠다드·프리미엄**은 넷플릭스 쪽에서 **추가 요금** 업그레이드 가능 (멤버십 연결 후) |
| **이미 구독 중** | 넷플릭스 **기존 결제**를 멤버십으로 **통합** — 남은 기간은 **넷플릭스 크레딧**으로 전환되는 경우 많음 |
| **연령** | 넷플릭스 **만 19세 이상** |
| **주의** | 넷플릭스 사이트에서만 업그레이드 신청해도, 멤버십 경로는 **광고형 스탠다드** 기준으로 잡힐 수 있음 — [고객센터](https://help.naver.com/service/23168/contents/23881) |

멤버십 **해지** 시 넷플릭스는 **별도 과금**으로 돌아갈 수 있음 — 해지 전 넷플릭스·멤버십 **양쪽** 안내 확인.

#### 직접 구독 vs 네이버플러스 멤버십

**같은 화면 품질**을 기준으로 보면, 멤버십 경로는 **광고형 스탠다드**에 해당한다. 
넷플릭스 **단독 가입**에서도 이 요금제를 고를 수 있고, **스탠다드·프리미엄**(광고 없음·4K 등)은 **별도 요금**이다.

**요금(참고, 변동 가능 — 2026년 초반 기준)**

| 경로 | 월 비용(대략) | 넷플릭스에 해당하는 요금제 |
|------|----------------|---------------------------|
| **넷플릭스 직접** | **광고형 스탠다드 약 7,000원** | 광고형 스탠다드만 (원하면 스탠다드·프리미엄 선택) |
| **네이버플러스 멤버십** | **약 4,900원**(연간권이면 **월 약 3,900원** 상당) | 디지털 혜택에서 **넷플릭스 선택** 시 광고형 스탠다드 **포함** |
| **멤버십 + 업그레이드** | 멤버십료 + **넷플릭스 추가 요금** | 연결 후 넷플릭스에서 스탠다드·프리미엄 **차액** 결제 |

넷플릭스가 **광고형 스탠다드를 7,000원으로 인상**한 뒤에도, **멤버십 구독료(4,900원)** 는 별도로 유지되는 경우가 많아 **광고형만** 본다면 멤버십이 **월 2,000원 전후** 싼 편이다(연간권이면 차이 더 큼). 
단, 멤버십은 **넷플릭스만** 파는 게 아니라 **쇼핑 적립·배송·멤버십패스** 등이 **같이 붙은 번들**이다.

**요금제·시청 (광고형 스탠다드 기준)**

| 항목 | 직접 구독 | 멤버십 경로 |
|------|-----------|-------------|
| **화질·동시 시청** | Full HD · **2대** (넷플릭스 표기) | **동일** (광고형 스탠다드) |
| **광고** | **있음** | **있음** |
| **모바일 게임** | 포함(광고형 스탠다드) | 포함 |
| **결제** | 넷플릭스에 **카드·페이** 등록 | **네이버 멤버십료** — 넷플릭스 **직접 청구 없음**(연동 시) |
| **가입·변경** | 넷플릭스 사이트·앱 | 멤버십 **MY**에서 넷플릭스 선택 후 **계정 연결** |
| **업그레이드** | 스탠다드·프리미엄 **자유 선택** | 기본은 광고형 → 넷플릭스에서 **추가 요금** 업그레이드 |

**멤버십만의 제약**

| 항목 | 직접 구독 | 멤버십 |
|------|-----------|--------|
| **디지털 혜택** | 넷플릭스 **만** 가입 | **넷플릭스 / Xbox / 쿠키 중 월 1개** — Game Pass 쓰는 달엔 넷플릭스 **불가** |
| **패밀리** | 넷플릭스 **프로필·동시 시청** 규칙 따름 | 디지털 혜택은 **가족 중 1명**만 |
| **해지** | 넷플릭스만 해지 | **멤버십 해지** 시 넷플릭스 **유료 전환**·결제수단 필요 |
| **기존 구독** | 요금제 **그대로** 유지 가능 | 연동 시 **광고형 스탠다드로 통합** — 남은 기간 **크레딧** 전환 |

**언제 어떤 쪽이 나은지 (대략)**

| 상황 | 추천 방향 |
|------|-----------|
| **광고 있어도 되고**, 네이버 쇼핑·적립도 쓴다 | **멤버십** — 넷플릭스만 봐도 **요금·부가 혜택**이 유리한 경우 많음 |
| **광고형만** 보면 되고 **넷플릭스만** 쓴다 | **멤버십**(넷플릭스 선택) vs **직접 7,000원** — 멤버십이 **저렴**하지만 **매월 디지털 택1·자동결제** 부담 확인 |
| **처음부터 광고 없음**(스탠다드·프리미엄) | **직접 구독**이 단순 — 멤버십은 **광고형 기본** + 업그레이드 **차액** 계산 필요 |
| **Xbox·웹툰**을 번갈아 쓴다 | **멤버십** — 넷플릭스 **매달 고정**이 아니면 직접 넷플릭스 + 다른 구독이 나을 수 있음 |
| **계정·결제를 넷플릭스에만** 두고 싶다 | **직접 구독** — 멤버십 **해지·연동** 이슈를 피함 |

```text
광고형 + 최저가  →  멤버십(넷플릭스 택1) vs 직접 7,000원 비교
광고 없음·4K     →  직접 스탠다드/프리미엄 vs 멤버십+업그레이드 총액 비교
쇼핑도 한다      →  멤버십 적립·N배송까지 넣어 본전 계산
```

숫자는 **넷플릭스·멤버십 공지**가 최종이다. 업그레이드 **차액**은 연동 후 넷플릭스 **계정 > 멤버십** 화면에서 확인한다.

#### Xbox PC Game Pass 연동

| 항목 | 설명 |
|------|------|
| **신청** | 디지털 혜택에서 **Xbox PC Game Pass** 선택 → **마이크로소프트 계정** 연결 |
| **요금** | 멤버십료 **외 추가 없음**(공식 보도 기준) — 단독 PC Game Pass 월정액보다 **저렴한 체감**이 목적 |
| **포함** | PC용 게임 카탈로그 **무제한**(약관·지역·일부 타이틀 제외) · **EA Play** |
| **이미 구독 중** | 기존 **Game Pass** 계정 연결 시 **정책에 따라 전환·해지** 필요 — 연결 화면·MS 안내 따름 |
| **콘솔** | **Xbox 콘솔 본체**용 **Xbox Game Pass Ultimate**와는 **상품이 다름** — PC Game Pass 혜택만 해당 |

게임은 **PC·윈도우** 환경 — [[윈도우 사용법]] · 사양 확인.

#### 패밀리·변경 규칙

| 항목 | 설명 |
|------|------|
| **월 1개** | 디지털 콘텐츠는 **한 달에 하나**만 활성 — 넷플릭스 쓰는 달엔 Game Pass **동시** 불가 |
| **패밀리** | 디지털 콘텐츠 혜택은 **대표·멤버 중 1명**만 (무료 쿠키·MYBOX 등은 항목별 상이) |
| **옵션 변경** | 월마다 **다른 혜택**으로 바꿀 수 있는 경우 많음 — 변경 시 **기존 서비스 연결 해제** 주의 |

쇼핑 **적립·N배송**과 디지털 **택1**은 **별도 축** — 쇼핑만 쓰면 디지털을 안 골라도 되고, OTT만 쓰려면 **멤버십료 vs 넷플릭스 단독가**를 비교한다.

### 5.3 멤버십 가입 전에 볼 것

- 이번 달 **네이버 쇼핑·예약**에서 Npay로 쓸 **금액**이 있는지  
- **넷플릭스·Game Pass**를 이미 **단독 구독** 중이면 **연동·크레딧·해지** 규칙 확인 (§5.2)  
- **월 요금** 대비 **추가 적립 + 배송비 절약 + 디지털 택1**이 되는지  
- **인터파크** 등 **결제만 연동**된 타사몰은 **멤버십 추가 적립이 없는** 경우가 많음  
- **e쿠폰·환금성·도서정가제** 등 **적립 제외** 카테고리  

「한 달에 ○만 원 넘게 쓰면 본전」 같은 말은 **본인 구매 패턴**으로 계산한다.

## 9. 보안

1. 네이버 **비밀번호·2단계 인증**  
2. **결제 비밀번호**를 생일·연속 숫자로 두지 않기

4. 분실 시 네이버 **로그아웃·비밀번호 변경** + 등록 **카드 정지**(카드사)

## 10. 실전 팁

- 쇼핑 전 **멤버십 여부** · **Npay+** · **쿠폰** · **카드 할인**을 **한 번에** 비교  
- [[최저가 비교 사이트]]로 가격 → **네이버페이 적립 후** 실질가 계산  
- 멤버십은 **쓸 때만** 가입·해지 (자동결제일 확인)  
- 오프라인: **QR 가맹**인지 확인 — 갤럭시면 **현장결제 > 삼성페이 탭**으로 MST 매장도 검토 (§4.2.2)  
- 출퇴근은 **모바일 교통카드 + K-패스 등록** 여부·**교통 포인트 프로모**를 앱에서 확인 (§4.3)
