# 카카오톡

> **분류:** 모바일·결제 · [[생활위키 목차]]

**카카오톡**(KakaoTalk, **카톡**)은 국내에서 널리 쓰는 **모바일 메신저**다. 
1:1·그룹 채팅, 오픈채팅, 선물하기, **톡캘린더**, 채널(구독) 등을 한 앱에서 쓴다.

공식: [https://www.kakaocorp.com](https://www.kakaocorp.com) · 고객센터: [https://cs.kakao.com](https://cs.kakao.com)  
앱: Play Store · App Store **카카오톡** (공식)

확인일: 2026-08-11

관련: [[갤럭시 폰 사용법]] · [[텔레그램]] · [[삼성페이]] · [[생일 혜택]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 가입 | 휴대폰 번호 · **카카오계정** |
| 동기화 | 폰·태블릿·PC(카카오톡 PC) · 일부 기능은 기기별 차이 |
| 대화 | 친구, **채팅방**, **오픈채팅**, **채널** |
| 결제·생활 | 선물하기, **카카오페이** 연동, 미니앱 등 |
| [[텔레그램]]과 | 국내 일상·지인은 카톡, 해외·봇·채널은 텔레그램을 **같이** 쓰는 경우 많음 |

```text
번호 인증 → 카카오계정
 ↓
친구 · 그룹 · 오픈채팅 · 채널
 ↓
알림·프라이버시·생일 설정 (§6)
```

메뉴 이름은 **앱 버전**마다 바뀐다. 아래 경로는 **2026년 기준**이며, 안 보이면 설정 **검색**·[카카오 고객센터](https://cs.kakao.com)를 본다.

## 6. 생일 알려주기 **비활성화**

카카오톡은 **카카오계정·프로필**의 생일을 바탕으로 친구에게 **「오늘 생일」** 을 알리거나, 친구 목록에 **생일인 친구** 영역을 띄운다.  
**내 생일을 남에게 알리지 않기**와 **남의 생일 표시 줄이기**는 설정이 **다르다.**

### 6.1 내 생일 — **생일 알림** 끄기 (친구에게 알리지 않기)

친구 목록·프로필에 **내 생일 알림**이 뜨지 않게 한다.  
카카오 **공식 안내** 경로:

```text
카카오톡 → 더보기(…) → 설정(⚙️)
 → 내 프로필 오른쪽 「관리」
 → 생일 알림 OFF
```

**다른 진입 (같은 메뉴)**

| 경로 | |
|------|--|
| **친구** 탭 → 맨 위 **내 프로필** → 우측 **⚙️** → **생일 알림** OFF |
| **더보기** → **설정** → **프로필 관리** → **생일 알림** OFF |

| 단계 | 확인 |
|------|------|
| 스위치 | **회색(OFF)** |
| 효과 | 친구 쪽 **생일 알림·케이크 표시**에 내가 안 나가도록 (공식 설명 기준) |
| 멀티 프로필 | 프로필마다 **각각** 확인 |

**생일 날짜 자체**는 **카카오계정 내정보**에 있을 수 있다. 알림만 끄는 것과 **날짜 삭제·수정**은 별도다.

```text
더보기 → 설정 → 카카오계정 → 내정보 관리
```

### 6.2 친구 생일 — 목록·알림 줄이기

**「친구 생일이 내 화면에 안 보이게」** 는 앱 업데이트로 **메뉴가 바뀌거나 없어진** 경우가 있다. 버전에 따라 아래만 가능할 수 있다.

| 방법 | 플랫폼 | 설명 |
|------|--------|------|
| **생일인 친구 보기** OFF | **PC 카카오톡** (남아 있는 경우) | `설정` → `친구` → **생일인 친구 보기** 체크 해제 |
| **목록 접기** | **모바일** | 친구 탭 상단 **생일인 친구** 영역 **접기**(∨) — 숨김 토글이 없으면 **우회** |
| **톡캘린더 알림** | 모바일·PC | `톡캘린더` → 설정에서 **생일·기념일 알림** 끄기 |
| **채팅방 알림** | — | 생일 축하 **톡**은 해당 방만 뮤트 (근본 해결은 아님) |

모바일 `설정` → `친구`에 **「생일인 친구 보기」** 가 **보이면** OFF. **없으면** 위 표의 접기·PC·캘린더로 대응한다.

### 6.3 설정 후 점검

| 항목 | 이유 |
|------|------|
| 앱 **업데이트** 후 | 토글이 **다시 켜진** 사례 |
| **기기 변경·재설치** | 프로필 설정 초기화 가능 |
| **멀티 프로필** | 메인·서브 **각각** 생일 알림 확인 |
| 친구가 여전히 안다 | 상대가 **연락처·다른 앱**에 생일을 가지고 있을 수 있음 — 카톡만으로 **완전 비공개**가 아닐 수 있음 |

공식 FAQ: [내 생일 소식을 친구에게 알리고 싶지 않아요](https://cs.kakao.com/helps_html/1073209560)
