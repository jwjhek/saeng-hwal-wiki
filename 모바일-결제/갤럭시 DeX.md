# 갤럭시 DeX

> **분류:** 모바일·결제 · [[생활위키 목차]]

**Samsung DeX**(삼성 덱스)는 **갤럭시 스마트폰·태블릿**을 모니터·TV에 연결해 **PC처럼** 쓰는 **데스크톱 모드**다. 
창 크기 조절·작업 표시줄·마우스·키보드로 **멀티태스킹**한다.

**지원 기기·One UI 버전**에 따라 **유선·무선·PC 연결** 방식이 다르다. 이 글은 **2026년 기준** 개요다.

확인일: 2026-08-11

관련: [[갤럭시 폰 사용법]] · [[윈도우 사용법]] · [[VS Code 사용법]]

참고: [삼성 DeX](https://www.samsung.com/sec/apps/samsung-dex/) · [고객센터 — DeX 사용법](https://www.samsungsvc.co.kr/solution/970963)

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 폰 UI를 **큰 화면 + 데스크톱 레이아웃**으로 전환 |
| 목적 | 문서·브라우저·메일·프레젠테이션·멀티 앱 |
| 무엇 아님 | **윈도우 PC 대체**·전용 OS 설치는 아님 — **안드로이드 앱**이 큰 화면에서 돌아감 |
| 기기 | **일부 갤럭시**·**갤럭시 탭** (모델별) |

```text
[갤럭시] USB-C HDMI 또는 무선(Miracast)
 ↓
[모니터·TV] DeX 데스크톱
 ↓
[입력] 블루투스·USB 마우스·키보드
```

[[갤럭시 폰 사용법]] §3.3 한 줄 요약의 **상세본**이다.

---

## 2. 쓰는 이유

| 상황 | DeX |
|------|-----|
| **노트북 없이** 호텔·회의실 TV 작업 | 브라우저·오피스·메일 |
| **프레젠테이션** | 슬라이드·자료 **큰 화면** |
| **멀티 앱** | 채팅 + 문서 + 영상 나란히 |
| **개발·문서** (가벼운) | [[VS Code 사용법]] 모바일·터미널 앱 등 |

**무거운 게임·4K 편집·전문 IDE**는 **PC**가 낫다. DeX는 **이동 중 생산성**에 가깝다.

---

## 3. 지원 여부 확인

| 확인 | |
|------|--|
| **설정** | `설정` → **Samsung DeX** · **기기 간 연결** → DeX |
| **퀵 패널** | 상단 내려 **DeX** 타일 있는지 |
| **공식** | [지원 모델 안내](https://www.samsung.com/sec/apps/samsung-dex/) (연도별 갱신) |

**갤럭시 M** 등 **저가형**·구형은 **미지원**인 경우가 많다. **플래그십·S·Note·일부 A·탭 S** 위주.

---

## 4. 연결 방식

### 4.1 유선 (안정적)

| 방법 | 설명 |
|------|------|
| **USB-C → HDMI** | 단일 케이블 또는 **멀티 허브**(HDMI + 충전 + USB) |
| **DeX Pad / Station** | (구형 액세서리) HDMI·USB 허브 일체 — **신규 구매는 케이블·허브**가 흔함 |
| **자동 시작** | DeX 설정 → **HDMI 연결 시 자동 시작** (권장) |

연결 후 폰에 **「Samsung DeX」** vs **화면 미러링** 선택 — **DeX**를 고른다.

**장점:** 끊김·지연 **적음**. **단점:** 케이블·HDMI 입력 필요.

### 4.2 무선 (편함)

| 방법 | 설명 |
|------|------|
| **퀵 패널** | **DeX** → **TV·모니터에서 DeX 사용** → 기기 선택 |
| **설정** | `기기 간 연결` → **Samsung DeX** → **무선으로 연결** |
| **TV** | **미라캐스트**·**스마트 뷰** 수신 지원 필요 (삼성 TV·일부 모니터) |

**5GHz Wi-Fi**·**근거리** 권장. **2.4GHz**·옛 TV는 **끊김** 많을 수 있다.  
**Chromecast만** 있는 TV는 **DeX 무선이 안 될** 수 있음 — **유선** 또는 **스마트뷰 호환** 확인.

### 4.3 PC 연결 (주의 — One UI 7+)

| 시기 | 내용 |
|------|------|
| **과거** | PC에 **Samsung DeX** 앱 + USB → **PC 화면**에 DeX |
| **One UI 7 이후** | **PC용 DeX 프로그램 지원 종료** 안내가 많음 |
| **대안** | **Windows 휴대폰과 연결**(Phone Link) · **유선 HDMI로 모니터** |

PC에서 폰 화면을 쓰려면 [[윈도우 사용법]]의 **링크 to Windows / 휴대폰과 연결**을 본다. **DeX와 UI·기능이 다르다.**

---

## 5. 시작하기

### 5.1 유선 (요약)

1. **USB-C–HDMI**(또는 허브)로 모니터·TV 연결  
2. TV **HDMI 입력** 선택  
3. 폰 알림에서 **Samsung DeX** 실행  
4. (선택) **블루투스** 마우스·키보드 페어링  

### 5.2 무선 (요약)

1. TV·모니터 **무선 디스플레이** 대기  
2. 폰 **퀵 패널** → **DeX**  
3. **TV나 모니터에서 DeX 사용** → 목록에서 선택  
4. TV에서 **연결 승인**  

### 5.3 입력 장치

| 입력 | 연결 |
|------|------|
| **블루투스** | 마우스·키보드·북커버 키보드 |
| **USB** | 허브에 **유선** 키보드·마우스 |
| **폰 화면** | **터치패드** 모드 — DeX 안에서 폰을 **트랙패드**로 |

삼성 **북커버 키보드**는 탭·일부 폰 케이스와 짝 — **별도 판매**.

---

## 6. DeX 화면에서 하는 일

| 기능 | 설명 |
|------|------|
| **작업 표시줄** | 하단 — 앱 전환·최소화·설정 |
| **멀티 윈도우** | 앱 **크기 조절**·나란히 배치 |
| **앱 서랍** | 설치된 앱 실행 |
| **알림** | 폰 알림을 DeX에서 처리 |
| **클립보드** | (버전별) 폰 ↔ DeX **복사·붙여넣기** |

일부 앱은 **전화면 전용**·**세로 고정** — DeX에서 **창 모드 미지원**.

### DeX vs 화면 미러링

| | **Samsung DeX** | **화면 미러링** |
|--|-----------------|-----------------|
| UI | **데스크톱** 레이아웃 | 폰 화면 **그대로 확대** |
| 멀티 앱 | **창** 여러 개 | 보통 **한 화면** |
| 용도 | **작업** | 동영상·사진 보기 |

---

## 7. 설정·모드

DeX 설정(경로는 버전별):

| 옵션 | 설명 |
|------|------|
| **HDMI 연결 시 자동 시작** | 케이블 꽂으면 DeX |
| **해상도** | 모니터에 맞게 (FHD 등) |
| **폰 화면** | DeX 중 폰은 **터치패드**·**끄기** 등 |
| **확장·듀얼** (신규) | **Android 16+**·일부 기기 — **멀티 데스크톱·확장 모드** (공식 안내 따름) |

[[갤럭시 루틴]]으로 `집 Wi-Fi` + `HDMI 허브 연결` 시 **방해 금지** 등을 묶을 수 있다.

---

## 8. 잘 되는 앱·안 되는 앱

| 잘 됨 | 제한 |
|------|------|
| **삼성 인터넷**·Chrome | 일부 **금융·보안** 앱은 DeX **차단** |
| **오피스**·메일·노트 | **넷플릭스** 등 **DRM** — **TV 앱** 직접 쓰는 편이 나음 |
| **원격·SSH**·가벼운 코딩 | [[Termux]] 등 — 키보드 필수 |
| | **보안 폴더** 앱은 DeX에서 **안 열리는** 경우 많음 |

**인터넷뱅킹**·OTP 앱은 **보안 정책**으로 DeX·미러링 **금지**가 흔하다.

---

## 9. 태블릿·액세서리

| 기기 | |
|------|--|
| **갤럭시 탭 S** | DeX **기본 지원** — 키보드 커버와 궁합 |
| **폰** | HDMI **유선** 또는 **무선** TV |

**멀티 허브**: HDMI + **PD 충전** + USB-A 포트 — 장시간 작업에 유리.

---

## 10. 문제 해결

| 증상 | 시도 |
|------|------|
| DeX 메뉴 없음 | **지원 모델**·**소프트웨어 업데이트** |
| HDMI인데 미러링만 | 알림에서 **Samsung DeX** 선택 |
| 무선 안 잡힘 | TV **미라캐스트** · **5GHz** · 거리 |
| 끊김·버벅임 | **유선 HDMI**로 전환 |
| 마우스 안 됨 | BT·USB **재페어링** · 허브 **전원** |
| PC DeX 안 됨 | **One UI 7+** — **Phone Link**로 전환 검토 |
| 앱 안 열림 | **DeX 미지원** 앱 — 폰에서만 실행 |

---

## 11. 흔한 오해

| 오해 | 현실 |
|------|------|
| 모든 갤럭시 | **모델 제한** |
| 윈도우 설치 | **안드로이드 DeX UI** — Windows 아님 |
| 무선 = 유선과 같음 | **지연·끊김** 가능 — 작업은 **유선** |
| PC DeX 항상 가능 | **One UI 7+** 에서 **PC 앱 종료** 방향 |
| DeX = 미러링 | **별도 데스크톱** 모드 |

---

## 12. 실전 체크리스트

- [ ] 내 폰이 **DeX 지원**인지 확인  
- [ ] **USB-C–HDMI** 또는 **5GHz 무선 TV** 준비  
- [ ] **마우스·키보드** (BT 또는 USB)  
- [ ] DeX 설정 **HDMI 자동 시작**  
- [ ] PC 작업은 **Phone Link** vs **모니터 DeX** 구분  

---

## 13. 정리

1. **갤럭시 DeX**는 모니터·TV에서 **데스크톱형**으로 쓰는 모드다.  
2. **유선 HDMI**가 가장 안정적, **무선**은 TV·Wi-Fi 환경에 민감하다.  
3. **One UI 7+** 부터 **PC용 DeX**는 막히는 방향 — **휴대폰과 연결** 등 **대안**을 본다.  
4. 금융·DRM 앱은 **제한**될 수 있다.  
5. 가벼운 **사무·발표·멀티 앱**에 맞고, **본격 PC 대체**는 아니다.
