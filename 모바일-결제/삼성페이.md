# 삼성페이

> **분류:** 모바일·결제 · [[생활위키 목차]]

삼성페이(Samsung Pay)는 갤럭시 폰·워치에서 **카드·교통·멤버십** 등을 담아 매장·온라인에서 결제하는 삼성 모바일 결제다. 
최근 One UI에서는 **Samsung Wallet(삼성 월렛)** 앱 안에 페이·탑승권·**모바일 신분증**·**전자증명서**가 묶여 있는 경우가 많다. 메뉴에 “페이”와 “월렛”이 같이 보여도 **결제 흐름은 같은 계열**로 보면 된다.

기기·설정: [[갤럭시 폰 사용법]] · [[갤럭시 워치 사용법]]

확인일: 2026-08-21  
카드사·가맹점·신분증·전자증명서 종류·One UI 버전에 따라 지원 범위가 다르다.

---

## 1. 무엇이 되나

| 기능 | 내용 |
|------|------|
| 오프라인 결제 | 카드 단말기에서 삼성페이로 결제 |
| 온라인·앱 | 지원 가맹점에서 삼성페이/월렛 결제 |
| 교통카드 | 티머니 등 (지원 지역·카드) |
| 멤버십·포인트 | 바코드·QR 등록 (매장 정책에 따름) |
| 워치 결제 | 갤럭시 워치에서 카드 결제 (폰과 연동·단독 조건은 모델별) |
| **모바일 신분증** | 주민등록증·운전면허증·국가보훈등록증 등 — **월렛에서 발급·제시** (§5) |
| **전자증명서** | 정부24 등본·초본 등 — **월렛에서 신청·보관·제출** (§6). 신분증과 **다름** |
| 기타 | 탑승권·쿠폰·학생증 등 — 월렛 쪽. 종류마다 법적 효력이 다름 |

핵심 체감: **실물 카드 없이** 지문/얼굴/PIN으로 빠르게 계산.

---

## 2. 왜 한국에서 잘 되나 — MST와 NFC

| 방식 | 설명 |
|------|------|
| **NFC** | 비접촉(컨택리스) 단말에 갖다 댐. 해외·최신 단말 공통 |
| **MST** (Magnetic Secure Transmission) | 예전 마그네틱 긁는 단말에도 신호를 보내 **호환 범위를 넓힘** |

한국 매장에 구형 단말기가 많아, 삼성페이가 “거의 어디서나” 된다는 인식이 생긴 배경이다. 
다만 **모든 단말·모든 국가**가 MST를 쓰는 것은 아니고, 신형 단말은 NFC 비중이 크다. 
안 되면 단말 위치(NFC 마크)·다른 카드·직원 안내에 따른다.

```text
지문/PIN 인증 → 페이 실행 → 단말에 가까이 / 신호 송출 → 승인
```

---

## 3. 시작하기

1. **Samsung 계정** 로그인 ([[갤럭시 폰 사용법]] 계정 항목)
2. **Samsung Wallet** 또는 **Samsung Pay** 앱 실행 (기기에 따라 이름) 
3. 잠금화면·생체 인식 설정 (결제 PIN) 
4. **카드 추가** — 카메라로 찍거나 수동 입력 → 카드사 본인인증 
5. 기본 결제 카드 지정 

은행·카드 앱에서 “삼성페이에 추가”로 넣기도 한다. 
체크·신용·일부 계좌 기반 상품 지원 여부는 **카드사 공지**를 본다.

워치:

1. 폰 월렛/페이에서 워치로 카드 전달(또는 웨어러블 앱 경로) 
2. 워치에서 PIN·생체(지원 시) 
3. 측면 버튼 두 번 등 **바로가기**로 결제 화면 ([[갤럭시 워치 사용법]] 제스처)

---

## 4. 매장에서 쓰는 법

1. 측면 버튼 두 번 / 홈 아래 스와이프 / 월렛 앱 — **본인 설정한 실행 방법** 
2. 지문·얼굴·PIN으로 잠금 해제 
3. 쓸 카드 선택 (좌우 스와이프) 
4. 단말의 **NFC 영역**에 폰 뒷면(또는 워치 화면)을 가까이 
5. 승인음·영수증 확인 

팁:

- 케이스·메탈 카드홀더가 NFC를 가리면 인식이 나쁘다 
- 한 번에 안 되면 각도·위치를 조금 바꿔 재시도 
- **비행기 모드**여도 일부 결제는 될 수 있으나, 교통·온라인은 네트워크가 필요할 수 있음 
- 배터리 절약·초절전 시 페이 제한이 있을 수 있음

## 5. 모바일 신분증 (발급)

결제와 **별개**다. 삼성월렛이 행정안전부 등과 연동해, **정부가 발행한 모바일 신분증**을 갤럭시에 담는다. 삼성 안내·고객지원 기준으로 **실물과 같은 법적 효력**이라고 한다. 현장 직원이 모르면 거절할 수는 있다 → 모바일 신분증 고객센터 **1688-0990**.

공식 안내: [삼성월렛 모바일 신분증](https://www.samsung.com/sec/apps/samsung-wallet/serviceguide-mID/)  
정부 발급 안내: [mobileid.go.kr](https://www.mobileid.go.kr/) (주민등록증)

### 5.1 무엇이 들어가나

| 종류              | 발급 전제 (확인일 안내)                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------ |
| **모바일 주민등록증**   | **IC칩 실물** 주민등록증을 폰 뒷면에 태그. 1인 **본인 명의 폰 1대**                                                    |
| **모바일 운전면허증**   | **IC 운전면허증**(사진 아래 모바일 신분증 로고). 시험장·경찰서·[안전운전 통합민원](https://www.safedriving.or.kr)에서 IC로 바꿀 수 있음 |
| **모바일 국가보훈등록증** | IC·신청 경로는 보훈청·정부24 안내                                                                            |
| 대학 학생증 등        | 월렛 **전체 → 모바일 신분증** 목록. **국가 신분증과 효력이 같지 않을 수** 있음                                               |

옛 플라스틱만 있으면 월렛에 **바로 안 들어간다.** 주민등록증은 주민센터에서 **IC 교체**(수수료는 그날 안내)하거나, IC 없이 **창구 QR**로 정부 앱 발급을 받는 경로가 있다. 월렛 태그는 **IC 실물** 안내가 기본이다.

PASS 앱의 “면허 확인”과 **같지 않다.** PASS는 통신사 본인확인 쪽이고, 여기는 **IC 국가 신분증**이다.

### 5.2 월렛에 넣는 순서

기기: 삼성 고객지원 기준 **One UI 6.1 이상** 갤럭시. 설정 → 휴대전화 정보 → 소프트웨어 정보에서 확인.

1. Samsung Wallet **최신** 업데이트, NFC 켜기  
2. **전체** 탭 → **모바일 신분증** (또는 `+`)  
3. 넣을 종류 선택  
4. 안내에 따라 **신분증 비밀번호·얼굴·지문**  
5. **IC 실물**을 폰 **뒷면 NFC**에 댐 (케이스·메탈 홀더는 잠깐 빼기)  
6. 끝나면 **빠른 실행**에 카드가 생김  

유효기간: 월렛에 **넣은 날부터 3년**(삼성 고객지원). 실물 면허 **유효가 먼저 끝나면** 모바일도 끝난다. 번호·통신사·기기를 바꾸면 **다시 등록**하고 옛 데이터는 지워진다는 안내.

### 5.3 쓰는 법

| 상황 | 요지 |
|------|------|
| **직접 보여 주기** | 빠른 실행 → 모바일 신분증 → 생체·PIN. 화면을 직원이 봄 |
| **QR 제출** | 창구·편의점이 띄운 QR을 스캔하거나, 내 QR을 보여 줌. **30초·사용 후 폐기**, **캡처 안 됨** |
| **성인만 확인** | 편의점 주류 등은 **성인 여부만** 넘어가고 주소·주민번호 전체가 안 간다는 안내 |
| **은행 앱** | 신원확인에서 모바일 운전면허증 → **삼성월렛** → 지문 |

병원·투표·주민센터·금융 창구 안내가 있다. **거부되면** 법령·효력 논쟁보다 **1688-0990**과 그 기관 내규를 본다.

정부 **「모바일 신분증」앱**과 삼성월렛은 **같은 국가 신분증을 담는 통**이 다를 수 있다. 둘 다 쓰면 기기·1대 제한이 겹치는지 **앱 화면**을 본다.

분실: 잠금·생체 없으면 쓰기 어렵다는 안내. 그래도 [SmartThings Find](https://smartthingsfind.samsung.com)·[privacy.samsung.com](https://privacy.samsung.com)에서 잠금·월렛 데이터 삭제.

## 6. 전자증명서 (발급)

**신분증(§5)과 다른 기능**이다. 내가 누구인지를 담는 게 아니라, 정부24 **전자문서지갑**으로 **민원 서류**(등본 등)를 받아 보관·제출한다. 삼성 안내로는 정부24에서 받은 전자증명서와 **같은 효력**이다.

고객지원: [삼성월렛 전자 증명서](https://www.samsungsvc.co.kr/solution/1599017)  
정부24: [https://www.gov.kr](https://www.gov.kr) · 전자문서지갑 안내: [dpaper.kr](https://www.dpaper.kr)

### 6.1 전제

1. **[정부24](https://www.gov.kr) 회원**  
2. 월렛(옛 삼성페이) 안 **삼성 패스 전자서명 인증서** — 발급 때 본인확인용. 이후 지문·PIN  
3. 월렛 **전자증명서** 메뉴 (전체 탭·검색. 이름은 앱 버전에 따라 「전자 증명서」)

정부 전자문서지갑은 **수백 종**을 다루고, 월렛이 **바로 신청**해 주는 종류는 **그보다 적다.** 확인일 무렵 삼성 안내 예: 주민등록표 **등본·초본**, 건강보험료 납부확인서, 자격득실·자격확인서, 예방접종증명서, 국민연금 가입증명, 운전경력증명서, 초중등 졸업(예정)증명서, 소득금액증명, 사업자등록증. **지금 목록은 앱 화면.**

네이버·카카오·은행 앱도 같은 지갑 계열을 쓰는 경우가 있다. **종류·메뉴는 앱마다 다름.**

### 6.2 받는 순서

1. 월렛 → **전자증명서**  
2. 서류 선택 → 열람·발급에 필요한 **정보 입력**(주소 변동 포함 여부 등 화면)  
3. **지문 또는 PIN**(전자서명)  
4. 발급 완료 → 목록에서 열람  

유효기간은 **종이 민원과 같은 진위 확인 기간**이라는 안내. 예: 주민등록등본은 **90일**. 지나면 **삭제**되니 다시 받는다.

### 6.3 쓰·보내지·출력

| 일 | 요지 |
|----|------|
| **열람** | 월렛에서 연다. 캡처로 쓰는 안내는 **없음**(고객지원: 캡처 사용 불가) |
| **기관 제출** | 중앙부처·지자체·행정정보 공동이용 기관 등에 **전자 제출**. 수취 **기관명 검색** |
| **보내기** | 상대 **전자문서지갑**이 있으면 지갑으로. 없으면 **1회 열람 링크 + 열람 번호** |
| **종이** | 월렛에는 **인쇄 메뉴가 없다.** PC에서 정부24 → 수령 **온라인 발급(본인 출력)** |
| **예** | 운전경력증명서로 **국내선** 본인확인 안내가 있었음. 항공사·공항 **그날 정책** |

신분증 QR(§5.3)과 **같은 화면이 아니다.** 등본이 필요하다고 면허증 QR을 보여 주면 안 된다.

## 7. 교통·멤버십

| 종류 | 메모 |
|------|------|
| 교통 | 월렛/페이에서 교통카드 발급·충전. 잔액·후불은 상품마다 다름 |
| 버스·지하철 | 교통카드 모드로 태그 (일반 신용 결제 화면과 구분되는 경우 많음) |
| 멤버십 | 마트·카페 포인트 카드 바코드 등록 → 결제 전후 제시 |

교통은 **지역·지원 카드**를 앱에서 확인하고, 충전 한도·환불 규정은 교통사업자 정책을 본다. 
정부 **대중교통비 환급**은 별도 제도 → [[케이패스]].

## 8. 보안

1. **화면 잠금 + 생체**를 켠 채로 사용 
2. 결제 PIN을 단순 생일로 두지 않기 
3. 폰 분실 시 **Find My Mobile**로 잠금·위치·원격 조작 ([[갤럭시 폰 사용법]])
4. 월렛/페이에서 **카드 일시정지·삭제**, 카드사 앱·콜센터로 정지 
5. 루팅·비공식 개조 폰은 결제 앱이 막히거나 위험 
6. 공개 장소에서 PIN 입력 시 가리기 
7. 스미싱·가짜 “삼성페이 고객센터” 링크 주의 

실물 카드를 등록했다고 해서 카드 번호가 가맹점에 그대로 찍히는 방식과는 다르고, 토큰화 등 **카드사·삼성 보안 구조**를 쓴다. 그래도 기기 잠금은 필수다.

## 9. 안 될 때 점검

| 증상 | 확인할 것 |
|------|-----------|
| 앱이 안 열림 | 업데이트, Samsung 계정, 잠금화면 설정 |
| 카드 추가 실패 | 카드사 삼성페이 지원 여부, 본인인증, 해외카드 제한 |
| 단말에서만 거절 | NFC 위치, MST 미지원 단말, 한도·부정사용 의심 차단 |
| 워치만 안 됨 | 폰-워치 연동, 카드 워치 전송, 워치 잠금·거리 |
| 교통만 안 됨 | 교통카드 잔액·모드, 다른 카드와 겹침 |
| 신분증이 목록에 없음 | One UI 6.1+, 월렛 업데이트, 한국 계정·국내 모델 |
| IC 태그가 안 됨 | NFC 위치(보통 뒷면 위쪽), IC 로고 있는 실물인지, 메탈 케이스 |
| 창구에서 거절 | 법적 효력 안내·**1688-0990**. 그 자리 내규는 기관 |
| 전자증명서가 안 뜸 | 정부24 가입, **삼성 패스 전자서명**, 월렛 업데이트 |
| 증명서 기한 지남 | 등본 등은 **약 90일**. 삭제되면 다시 발급 |
| 종이가 필요 | 월렛은 인쇄 없음 → PC **정부24 본인 출력** |

카드사·삼성 고객센터는 **승인 거절 코드**가 있으면 말하기 쉽다.

## 10. 다른 페이와 비교 

| | 삼성페이 | 다른 예시 |
|--|----------|-----------|
| 강점 | 국내 오프라인 호환(전통과 MST 유산), 갤럭시·워치 연동 | Apple Pay·Google Wallet 등은 NFC·생태계 중심 |
| 전제 | 갤럭시(및 지원 기기) | 타사 폰은 삼성페이 불가(일반적) |
| 온라인 | 가맹점 지원 필요 | 각 페이·간편결제마다 다름 |

[[제로페이]]는 **카드·NFC가 아니라 QR·계좌 직불**이라 삼성페이와 **겹치지 않는다**. 은행·페이 앱 안 **별도 메뉴**로 쓰는 경우가 많다.

**[[네이버 페이]]**는 Npay 앱 **현장결제 > 삼성페이 탭**으로 **같은 MST 단말**에 네이버페이 등록 카드·머니를 쓸 수 있다 — 삼성페이 앱과 **단말은 같고**, **결제 원천·Npay 혜택**이 다르다 → [[네이버 페이]] §4.2.2.

“어느 페이가 이득인가”는 **할인 이벤트·카드 혜택**이 더 클 때가 많다. 페이는 수단일 뿐이다.

## 면책

> **면책**
> - **특정 앱·IC 교체·민원 대행 권유가 아니다.**
> - 법적 효력·제출 가능 여부는 **법령·행정안전부·정부24·삼성·그 창구 내규**가 우선이다. 이 글은 법률 자문이 아니다.
> - 지원 기종·수수료·유효기간·증명서 **종류 수**는 **앱·주민센터·시험장·정부24** 안내가 바뀐다.
