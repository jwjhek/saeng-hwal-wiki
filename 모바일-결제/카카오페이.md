# 카카오페이

> **분류:** 모바일·결제 · [[생활위키 목차]]

**카카오페이**는 카카오 계정에 묶인 **간편결제**다. 
[[카카오톡]] **더보기·송금**과 **카카오페이 앱**에서 쓰며, **QR·바코드** 오프라인 결제, **송금**, **청구서 납부**, **모바일 교통카드** 등을 한다. 
네이버처럼 **유료 OTT 번들 멤버십**은 없고, **포인트·이벤트·교통 추가 적립** 쪽이 강하다.

비교: [[네이버 페이]] · [[삼성페이]] · [[제로페이]] · [[케이패스]]

확인일: 2026-08-13

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 계정 | **카카오 계정** ([[카카오톡]]과 동일) |
| 앱 | **카카오페이** 앱 · **카카오톡** 내 카카오페이 홈 |
| 결제 수단 | **카카오페이머니** · **포인트** · 등록 **카드** · **계좌** |
| 강점 | **톡 연동**·송금, 편의점·카페 등 **오프라인 QR**, **교통카드** |
| 약점(상대적) | 네이버 쇼핑 **적립·멤버십** 축은 [[네이버 페이]]가 유리한 경우 많음 |

```text
카카오 계정 · 본인인증 · 결제 비밀번호
 ↓
머니 충전 / 카드·계좌 등록
 ↓
톡 송금 · QR 결제 · 온라인몰 · 교통 NFC 태깅
 ↓
포인트·이벤트·(조건) K-패스 환급
```

---

## 2. 결제 수단

| 수단 | 설명 |
|------|------|
| **카카오페이머니** | 선불 **충전** 잔액 — 계좌에서 충전 |
| **포인트** | 결제·이벤트 **적립** — 유효기간·전환 규칙은 앱 안내 |
| **등록 카드** | 신용·체크 — 카드사 **할인·청구할인**과 **중복** 여부 확인 |
| **계좌** | 계좌 출금 결제 |
| **머니카드** | 실물·모바일 **체크(선불)** 카드 — 교통·멤버십 바코드 등 (상품별) |

---

## 3. 시작하기

1. [[카카오톡]] 로그인 또는 **카카오페이** 앱 설치  
2. **본인인증** · **결제 비밀번호**(6자리) 설정  
3. **계좌 연결** · **머니** 충전(필요 시)  
4. (선택) **카드** 등록 · **머니카드** 발급  
5. (선택) **모바일 교통카드** 발급 — §5  

송금은 톡 **채팅방·친구**에서 바로 보낼 수 있다.

---

## 4. 어디서 쓰나

### 4.1 오프라인

| 방식 | 설명 |
|------|------|
| **QR·바코드** | 가맹점 카운터 **카카오페이** 스캔 |
| **머니카드** | 카드 **터미널**·교통 단말기 |
| **제휴** | CU·카페 등 **멤버십·스탬프** 연동 (가맹별) |

### 4.2 온라인·생활

| 채널 | 설명 |
|------|------|
| **카카오톡** | **송금**·선물하기·일부 **미니앱** 결제 |
| **배달·쇼핑** | [[배달 앱]]·제휴몰에서 **카카오페이** 결제 옵션 |
| **청구서** | 공과금·통신비 등 **납부** — 소액 **포인트** 프로모 있을 수 있음 |

가맹 여부는 결제 화면 **카카오페이 아이콘**으로 확인한다.

---

## 5. 모바일 교통카드 · [[케이패스]]

**NFC 모바일 교통카드**(안드로이드 등 — **기기·OS**는 앱 안내)로 버스·지하철을 **머니 충전** 후 태깅한다. 
[[네이버 페이]] 모바일 교통카드와 비슷한 **선불·NFC** 구조다.

| 항목 | 설명 |
|------|------|
| **충전** | **카카오페이머니** — 충전 **수수료 없음**(공식 안내 기준) · **자동충전** |
| **K-패스** | 교통카드 **번호**를 [K-패스](https://www.korea-pass.kr)에 **등록** — [[케이패스]] 조건·환급 |
| **추가 혜택** | 카카오페이 **교통 프로모**(예: 이용액 대비 **추가 적립·쿠폰**) — **시기별** 이벤트 |
| **모두의 카드** | 2026년 전후 **K-패스 개편**(모두의 카드)과 **자동 유리 적용** — [[케이패스]] §4 |

환급·추가 적립 **숫자·지급일**은 공단·카카오페이 **공지**가 최종이다.

---

## 6. 혜택·포인트

| 종류 | 설명 |
|------|------|
| **기본 적립** | 결제액 **일부** 포인트 (가맹·수단별) |
| **제휴 가맹** | 편의점·카페 등 **추가 할인·적립** |
| **머니카드 리워드** | **MZ 라이프팩** 등 — 영화·카페 등 **업종별** (상품·시기별) |
| **이벤트** | 월별 **캐시백·쿠폰** — 앱 **혜택** 탭 |
| **페이아이(Pay-i)** | AI **결제 수단 추천**·통신사 멤버십 분석 등 (기능 추가·변경됨) |

[[네이버 페이]] **네이버플러스 멤버십**(쇼핑·넷플릭스 택1)과 달리, 카카오페이는 **월 구독 번들**보다 **결제마다 쌓이는 포인트·이벤트**에 가깝다. 
표로 모으려면 [[최저가와 쿠폰]] §3.3.

## 7. [[네이버 페이]] · [[삼성페이]]와 비교

| | 카카오페이 | [[네이버 페이]] | [[삼성페이]] |
|--|------------|----------------|--------------|
| **계정** | 카카오 | 네이버 | Samsung |
| **진입** | **카카오톡**·페이 앱 | 네이버·Npay 앱 | 갤럭시 **월렛/페이** |
| **쇼핑** | 카카오·제휴몰 | **네이버 쇼핑·Npay+** | 카드사·가맹 |
| **구독 번들** | 없음(OTT 택1 등) | **멤버십**·넷플릭스 등 §5.2 | 없음 |
| **교통** | **모바일 교통카드**·K-패스 | 모바일 교통카드·K-패스 | **티머니** 등 |
| **오프라인** | **QR** 넓음 | QR·일부 NFC | **NFC·MST** 넓음 |
| **송금** | **톡 송금** 강점 | 네이버 송금(제한적) | 송금 약함 |

**삼성페이**는 **단말 결제**, **카카오페이**는 **톡·QR·송금**, **네이버 페이**는 **쇼핑·멤버십**에 치우친다 — **하나만** 쓰기보다 **용도별 병행**이 흔하다.

---

## 8. 연말정산

등록 **카드**로 결제하면 [[신용카드 소득공제]] **카드 사용** 집계에 들어갈 수 있다. 
**머니·계좌만** 쓴 분은 **현금성**에 가깝게 잡힐 수 있음 — 홈택스 **간소화** 확인.

---

## 9. 보안

1. **결제 비밀번호**·휴대폰 **잠금**  
2. 톡 **피싱·가짜 송금 요청** — 링크·계좌 확인  
3. 분실 시 **카카오 계정** 보호 · 등록 **카드 정지**  
4. **QR 결제** 시 금액·가맹명 확인 후 승인
