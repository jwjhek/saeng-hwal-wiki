# 텔레그램 봇

> **분류:** 모바일·결제 · [[생활위키 목차]]

**텔레그램 봇**은 채팅창에서 `/start`·버튼·메시지에 반응하는 **자동화된 텔레그램 계정**이다.  
알림·조회·간단한 업무·채널 관리 보조 등에 쓰이며, 앱 본체 사용법은 [[텔레그램]]을 본다.

공식 봇 API 소개: [https://core.telegram.org/bots](https://core.telegram.org/bots)

> **면책**  
> 학습·운영 **감각**이다. API·한도·정책은 공식 문서가 우선.  
> 스팸·무단 수집·사칭·악성 봇 제작은 다루지 않으며 금지에 가깝다.  
> **봇 토큰 = 비밀번호**다. Git([[Git 사용법]])·스크린샷·공개 채널에 올리지 말 것.  
> 이 글이 특정 호스팅·라이브러리 구독을 권하지 않는다.

확인일: 2026-08-07

관련: [[텔레그램]] · [[GitHub]] · [[Git 사용법]] · [[Python 학습과 패키지]]

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 사용자 | 봇을 검색·링크로 열어 **Start** |
| 운영자 | [[#3. 봇 만들기 (BotFather)]] 로 발급 → 서버/스크립트가 API로 응답 |
| 토큰 | `123456:ABC...` 형태. **유출 시 즉시 재발급** |
| 한계 | 봇이 먼저 아무 사용자에게나 스팸하듯 보내기는 제한됨. 사용자가 시작·차단 해제가 전제인 경우가 많음 |

```text
사용자 ──메시지──→ 텔레그램 서버 ──→ 내 봇 프로그램
         ←──응답──              ←──
```

## 2. 사용자로 봇 쓰기

| 단계 | 감각 |
|------|------|
| 찾기 | 검색, `t.me/봇이름`, 채널/그룹에 초대된 봇 |
| 시작 | **시작** 버튼 또는 `/start` |
| 메뉴 | 입력창 **/** 또는 봇이 띄운 버튼(Inline·Reply 키보드) |
| 중지 | 채팅 화면 메뉴 → 중지/차단. 필요 시 권한·연결 앱 해제 |
| 그룹에서 | 관리자가 봇을 추가·권한(메시지 삭제·초대 등)을 줌. **최소 권한** |

| 조심 | 왜 |
|------|-----|
| 시드·비밀번호·OTP를 봇에 입력 | 사칭·탈취 |
| “에어드랍·입금 주소” 봇 | 사기 |
| 과도한 권한 요구 | 그룹 장악·스팸 |
| 출처 불명 단축 링크 | 피싱 |

[[텔레그램]] 보안·세션 점검과 같이 본다.

## 3. 봇 만들기 (BotFather)

공식 생성 봇: **@BotFather** (검색 시 사칭 계정 주의 — 보통 파란 인증 마크)

1. [[텔레그램]]에서 BotFather를 연다  
2. `/start`  
3. `/newbot`  
4. 표시 이름(사람 눈에 보이는 이름) 입력  
5. **username** 입력 — 끝이 `bot`으로 끝나야 하는 규칙이 있음 (예: `my_wiki_bot`)  
6. 발급된 **HTTP API token**을 안전한 곳에만 저장  

| BotFather에서 자주 쓰는 것 | 감각 |
|------------------------------|------|
| `/mybots` | 내 봇 목록·토큰·설정 |
| `/setdescription` · `/setabouttext` | 소개 문구 |
| `/setuserpic` | 프로필 사진 |
| `/setcommands` | `/` 메뉴에 보일 명령 목록 |
| `/revoke` | 토큰 재발급 (유출 시) |
| `/deletebot` | 봇 삭제 |

토큰을 재발급하면 **이전 토큰은 무효**다. 서버 설정도 같이 바꾼다.

## 4. 토큰 · 프라이버시

| 규칙 | 왜 |
|------|-----|
| 환경 변수·시크릿에만 보관 | 코드·[[GitHub]] Public에 올리면 즉시 악용 |
| 로그에 token 출력 금지 | |
| 유출 의심 → BotFather `/revoke` | |
| 개인 대화 내용을 함부로 저장·재공유하지 않기 | 법·약관·신뢰 |

CI에 넣을 때는 [[GitHub]] Actions Secrets / [[GitLab]] CI Variables 등 **비밀 저장소**만.

## 5. 동작 방식 감각 (운영)

봇 프로그램이 텔레그램 서버에서 업데이트를 받는 대표 방식:

| 방식 | 감각 |
|------|------|
| Long polling | 내 서버가 주기적으로 “새 메시지 있냐” 요청. 개발·소규모에 흔함 |
| Webhook | 텔레그램이 **HTTPS URL**로 푸시. 운영에 흔함. 공개·인증서 필요 |

라이브러리 예(언어는 자유): Python이면 [[Python 학습과 패키지]] 생태계의 봇 프레임워크들이 많음.  
공식은 HTTP API를 직접 호출해도 된다.

최소 흐름:

1. 사용자가 `/start`  
2. 내 코드가 인사·버튼 응답  
3. 이후 메시지·콜백 쿼리 처리  

명령 예: `/help`, `/status` — BotFather `/setcommands`와 맞추면 UX가 좋아진다.

## 6. 그룹 · 채널에 봇 넣기

| 장소 | 감각 |
|------|------|
| 그룹 | 멤버 추가 → 봇 선택. **관리자 권한**은 필요한 것만 (메시지 읽기·삭제 등) |
| 채널 | 채널은 방송형이라 봇 역할이 다름. 관리자 봇·댓글 그룹 연동 등 |
| Privacy mode | 봇이 그룹에서 **명령·멘션·답장** 위주로만 보게 하는 설정이 BotFather에 있음. 스팸·부하·프라이버시와 관련 |

관리자 봇에게 “전부 허용”은 사고 시 피해가 크다.

## 7. 흔한 용도 (예시)

| 용도 | 감각 |
|------|------|
| 알림 | 서버 장애·빌드 결과·폼 접수 → 나에게 DM |
| 조회 | 짧은 FAQ, 상태 확인 |
| 채널 보조 | 포스팅 예약·관리 (권한·정책 준수) |
| 커뮤니티 | 인증·환영 메시지 (남용·스팸 금지) |

“무조건 돈 버는 트레이딩 봇”·무단 광고 봇은 사기·차단 대상인 경우가 많다.

## 8. 로컬에서 살짝 시험 (개념)

토큰을 환경 변수로만 두고, 공식 API로 “내게 보내기”를 시험하는 집이 있다.

```text
1. BotFather로 봇·토큰
2. 텔레그램에서 내 봇에 /start (대화가 열려야 함)
3. getUpdates 또는 라이브러리로 메시지 수신
4. sendMessage로 응답
```

구체 URL·파라미터는 [Bots FAQ / API](https://core.telegram.org/bots/api)를 본다.  
이 위키는 악성·우회·대량 스팸 코드를 싣지 않는다.

## 9. 실전 체크

**사용자**

- [ ] Start 전에 봇 이름·설명·출처  
- [ ] 비밀번호·시드·OTP 입력 안 함  
- [ ] 불필요하면 차단  

**운영자**

- [ ] BotFather 공식 계정인지  
- [ ] 토큰이 Git·채팅·이슈에 없는가  
- [ ] `/setcommands`·설명·프로필  
- [ ] 그룹 권한 최소화 · Privacy mode 이해  
- [ ] 유출 시 `/revoke`  
- [ ] 앱 사용 전반은 [[텔레그램]]  

---

## 10. 정리

텔레그램 봇은 **BotFather로 만들고, 토큰으로 API에 연결하는 자동 채팅 상대**다.  
사용자는 Start·명령을, 운영자는 토큰 보안·최소 권한·공식 API를 중심에 둔다.  
메신저 자체는 [[텔레그램]].
