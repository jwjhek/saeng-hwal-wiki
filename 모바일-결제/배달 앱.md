# 배달 앱

> **분류:** 모바일·결제 · [[생활위키 목차]]

음식·마트·편의점 등을 **앱으로 주문**하는 쪽을 정리한다.  
직접 배달하는 일(라이더)은 [[배달하기]], 플랫폼 세부는 [[배민]] · [[쿠팡이츠]].

확인일: 2026-08-07

관련: [[배민]] · [[쿠팡이츠]] · [[배달하기]] · [[최저가와 쿠폰]]

---

## 1. 한눈에

| 앱·서비스 | 감각 |
|-----------|------|
| [[배민]] | 배달의민족. 가게 수·브랜드 인지도가 큼. 배민1·알뜰·포장 등 **상품 형태**가 나뉨 |
| [[쿠팡이츠]] | 쿠팡 생태계. **한 집 배달**·쿠팡 멤버십 연계 할인이 자주 거론 |
| 요기요·기타 | 지역·프로모션에 따라 선택지. 이 위키는 배민·이츠를 자세히 둠 |

주문 흐름은 대체로 같다.

```text
앱 설치·로그인 → 주소 설정 → 가게·메뉴 선택
    → 쿠폰·배달비·예상 시간 확인 → 결제 → 실시간 추적 → 수령
```

---

## 2. 주문할 때 보는 것

| 항목 | 왜 |
|------|-----|
| **배달비** | 거리·가게·프로모션·날씨·피크에 따라 변동 |
| **최소 주문** | 미달이면 주문 불가 또는 배달비↑ |
| **예상 시간** | 가게 조리 + 배차. 지연될 수 있음 |
| **쿠폰·멤버십** | 배민클럽·와우 등 — 월 구독이 이득인지는 **이용 횟수**로 계산 |
| **포장·방문** | 배달비 절약. 앱에 포장 탭이 있는 경우 많음 |
| **리뷰** | 참고만. 사진·최근 리뷰·별점 조작 가능성 |
| **요청 사항** | 수저·벨·공동현관 비밀번호(보안 주의)·알레르기 |

공동현관 비밀번호를 리뷰·채팅에 **공개로 남기지 않는다.**

결제: 앱 카드·간편결제·[[삼성페이]]/페이 계열(지원 시)·쿠팡캐시 등.  
영수증·카드 내역은 분쟁 시 필요하다.

---

## 3. [[배민]] vs [[쿠팡이츠]] (이용자)

| | 배민 | 쿠팡이츠 |
|--|------|----------|
| 인상 | 가게·카테고리 폭, 브랜드 익숙함 | 빠른 한 집 배달·쿠팡 할인 연계 이미지 |
| 배달 형태 | 가게 배달 / 배민1(플랫폼 배달) / 알뜰 등 **옵션이 다양** | 한 집 배달이 기본 감각으로 자주 설명됨 |
| 할인 | 가게 쿠폰·배민 쿠폰·클럽 | 이츠 쿠폰·와우 등 쿠팡 멤버십 |
| 같이 보면 | 포장·배민스토어·B마트 등 확장 | 쿠팡 앱·로켓과 **계정·멤버십**이 겹침 |

“어느 쪽이 항상 싸다”는 없다. **같은 메뉴를 두 앱에서 배달비·쿠폰까지** 비교하는 습관이 실질적이다.

상세: [[배민]] · [[쿠팡이츠]]

---

## 4. 문제·분쟁 감각

| 상황 | 시도 |
|------|------|
| 늦은 배달 | 앱 주문 상세·채팅/고객센터. 가게·라이더·배차 중 어디인지 확인 |
| 누락·오메뉴 | 사진 촬영 후 앱 신고·고객센터. 포장 개봉 전 영상이 유리한 경우 |
| 위생·이상 | 섭취 중단, 증빙, 플랫폼·필요 시 신고 |
| 결제만 되고 취소 | 주문 상태·환불 규정·카드사 문의 |
| 리뷰 강요 | 의무 아님. 정책 위반이면 신고 |

라이더와 직접 갈등은 피하고 **앱 공식 채널**을 쓴다.

---

## 5. 배달을 “하는” 쪽

오토바이·자전거·자동차로 플랫폼 배달을 하려면 [[배달하기]]를 본다.  
배민·이츠 각각 라이더 앱·정산·보험 안내는 그 글과 [[배민]] · [[쿠팡이츠]] 라이더 절에 있다.

---

## 6. 실전 체크 (주문)

- [ ] 주소·공동현관·연락처  
- [ ] 배달비+쿠폰+최소주문 합산  
- [ ] 알레르기·수저·비대면 여부  
- [ ] 결제 수단·영수증  
- [ ] 필요하면 배민·이츠 **가격 교차 확인**  

---

## 면책

> **면책**  
> 수수료·할인·운영 정책은 **앱·시점에 따라 자주 바뀐다**. 화면·약관이 우선.  
> 알레르기·위생·분쟁은 가게·플랫폼 고객센터·필요 시 소비자 상담.  
> 이 글은 특정 앱 가입·이용을 권유하지 않는다.
