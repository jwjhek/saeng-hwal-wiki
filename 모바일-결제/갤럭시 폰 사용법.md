# 갤럭시 폰 사용법

> **분류:** 모바일·결제 · [[생활위키 목차]]

삼성 갤럭시 스마트폰(**One UI**) 설정·팁 정리.
OS 개념·Play·계정은 [[안드로이드]]. 워치·웨어러블은 [[갤럭시 워치 사용법]].

메뉴 이름은 **모델·One UI 버전**에 따라 다를 수 있다. 설정 검색창에 한글 키워드를 치면 찾기 쉽다.

확인일: 2026-08-11

---

## 1. 처음 해두면 좋은 설정

| 항목 | 어디 / 무엇을 |
|------|----------------|
| Samsung 계정 | 설정 → 계정. Find My Mobile, 백업, Galaxy Store |
| Google 계정 | Play 스토어·백업 |
| 지문 / 얼굴 | 설정 → 보안 및 개인정보 보호 → 생체 인식 |
| 알림 | 설정 → 알림. 중요한 앱만 허용 |
| 배터리 | 설정 → 배터리. 사용 패턴 확인 |
| 소프트웨어 업데이트 | 설정 → 소프트웨어 업데이트. 보안 패치 |
| 스팸 전화 알림 | 전화 앱 → 설정 → **발신번호 및 스팸 확인** (§7) |

설정 앱 **검색창**에 `스팸`, `발신번호`, `보이스피싱`처럼 치면 메뉴를 헤매지 않아도 된다.

워치 연동 시 폰에 **갤럭시 웨어러블** 앱이 필요하다 → [[갤럭시 워치 사용법]].

## 2. 제스처·버튼

모델마다 네비게이션이 **제스처** 또는 **소프트 버튼 3개**다.

| 동작 | 흔한 방법 |
|------|-----------|
| 홈 | 하단에서 위로 스와이프 (제스처) / 홈 버튼 |
| 최근 앱 | 홈 제스처 후 멈추기 / 최근 앱 버튼 |
| 뒤로 | 좌·우 가장자리에서 안쪽으로 |
| 전원 / 측면 | 측면 버튼 짧게 = 화면 끄기, 길게 = 전원 메뉴 또는 빅스비/Gemini (설정 가능) |
| 빠른 설정 | 상태바를 두 손가락으로 내리기 또는 두 번 내리기 |
| 스크린샷 | 측면+볼륨 아래 (또는 손 측면 밀기 — 모션에서 켜기) |
| 화면 녹화 | 빠른 설정 패널에 **화면 녹화** 타일 추가 |

측면 버튼을 길게 눌렀을 때 **전원 메뉴**가 뜨게 바꾸는 것을 추천하는 사람이 많다. 
`설정 → 고급 기능 → 측면 버튼` (경로 유사).

## 3. One UI 핵심 기능

### 3.1 모드 및 루틴

`설정 → 모드 및 루틴` — 상세는 **[[갤럭시 루틴]]**.

- **모드**: 수면, 운전, 직장, 운동 등 — 방해 금지·화면·연결을 묶음 
- **루틴**: IF-THEN 자동화 
 예: `집 Wi-Fi 연결 → 와이파이 통화 켜기`, `특정 시간 → 다크 모드`, `이어폰 연결 → 미디어 볼륨`

조금만 만들어도 체감이 크다. 너무 많이 만들면 충돌하니 5~10개 안으로.

### 3.2 Good Lock / Good Guardians (선택)

Galaxy Store에서 **Good Lock** 모듈로 UI를 깊게 커스텀할 수 있다.

| 모듈 예 | 용도 |
|---------|------|
| **Sound Assistant** | **볼륨 미세 조절**·미디어 우선·앱별 음량 → [[Sound Assistant 사용법]] |
| LockStar | 잠금화면 |
| Home Up | 홈 화면·폴더 |
| Keys Cafe | 키보드 |
| NavStar | 내비 바 |
| MultiStar | 멀티윈도우 |
| Nice Catch | 클립보드·알림 히스토리 등 |

필수는 아니다. 기본 One UI만으로도 충분하면 설치하지 않아도 된다.

### 3.3 멀티윈도우·DeX

- 최근 앱 → 앱 아이콘 → **멀티 윈도우 / 팝업** 
- **Samsung DeX**: 지원 폰을 모니터·TV에 연결해 PC형 UI — 상세 **[[갤럭시 DeX]]**

### 3.4 Secure Folder (보안 폴더)

민감한 사진·앱·파일을 지문 뒤에 분리. 
`설정 → 보안` 쪽에서 Secure Folder 생성.

### 3.5 무선 배터리 공유 / 급속 충전

폰으로 버즈·**구형 갤럭시 워치**(워치6 이하 등)를 응급 충전(모델·지원 여부 확인). 
**갤럭시 워치7·Ultra 이후**는 폰에 올려도 **「충전기와 호환되지 않음」** 경고가 뜨고 **충전되지 않음** — [[갤럭시 워치 사용법]] §4.1. 
보호 케이스·정품 아닌 충전기는 무선 충전이 약하거나 발열날 수 있다.

## 4. 배터리·발열 팁

1. **항상 최대 성능**보다 적응형 배터리·자동 최적화 
2. 백그라운드 unrestricted 앱을 줄인다 (`설정 → 앱 → 배터리`) 
3. 5G가 불필요하면 **LTE 우선** 또는 지능형 전환 
4. AOD는 편하지만 배터리를 먹는다 — 예약 시간만 켜기 
5. 게임·카메라 직후 충전이면 **열 식힌 뒤** 
6. 80~90% 충전 제한(배터리 보호) 옵션이 있으면 야간 충전에 유리 
7. 저장공간 부족도 버벅임의 원인 — 클라우드·휴지통 정리 

---

## 5. 알림·집중

- 앱마다 알림 채널(중요/조용)을 나눈다 
- **방해 금지 / 수면 모드**로 밤 알림 차단 
- 카카오톡 등은 채팅방별 알림 OFF — 생일은 [[카카오톡]] §6
- 엣지 조명은 취향 — 밤에 거슬리면 끄기 

워치로 넘길 알림은 [[갤럭시 워치 사용법]]에서 앱별로 고른다.

## 7. 스팸·피싱 전화 알림

모르는 번호·스팸·보이스피싱 의심 전화를 **수신 화면에서 미리 알려 주는** 기능이다. 
삼성 **전화** 앱에 들어 있으며, 해외에서는 **Samsung Smart Call**(Hiya 연동) 이름으로도 안내된다.

**전제:** 대부분 **One UI 7 이상**·최신 **삼성 전화** 앱. 모델·통신사·소프트웨어에 따라 **메뉴가 없거나** 이름이 다를 수 있다.

### 7.1 발신번호 및 스팸 확인 (기본)

연락처에 없는 번호로 전화가 올 때 **발신 정보·스팸 여부**를 표시한다.

**켜는 방법 (가장 흔함)**

1. **전화** 앱 실행  
2. 우측 상단 **⋮** (더보기) → **설정**  
3. **통화 설정** (또는 **발신번호 및 스팸**)  
4. **발신번호 및 스팸 확인** → **켜기**  
5. **이용 약관·개인정보** 동의 (Hiya 등 제휴 안내가 뜰 수 있음)

**다른 진입**

| 방법 | 설명 |
|------|------|
| **알림** | 홈에서 내려 **「발신번호 및 스팸 확인」** 알림 탭 |
| **최근 통화** | 통화 기록에 **기능 켜기** 안내가 있으면 **시작** |
| **설정 검색** | `설정` 앱에서 `스팸` · `발신번호` 검색 |

**켜면 어떻게 보이나**

| 표시 예 | 의미 (참고) |
|---------|-------------|
| 업체명·프로필 | 등록된 **사업자·기관** 발신 (연락처 없어도) |
| **스팸** · **사기 의심** | DB·신고 기반 **의심** 표시 |
| 수신 화면 **강조 색** | 위험도에 따라 배경·문구로 **거절 권유** |

100% 정확하지 않다. **정상 전화**가 스팸으로 뜨거나, 반대로 **스팸이 통과**할 수 있다.

### 7.2 스팸·피싱 **자동 차단** (One UI 8 등)

알림만이 아니라 **의심 전화를 받지 않게** 막는 옵션이 **새 소프트웨어**에 추가되는 경우가 있다.

1. **전화** 앱 → **설정** → **발신번호 및 스팸 확인** (같은 메뉴 안)  
2. **스팸 및 피싱 의심 전화 차단** (또는 유사 이름) → **켜기**

중요한 **병원·택배·은행** 번호까지 막히면 **끄거나** 예외를 둔다. 차단 목록은 전화 앱 **스팸 및 차단 번호**에서 관리한다.

### 7.3 보이스피싱 의심 전화 알림 (일부 최신 기기)

AI·패턴으로 **보이스피싱 가능성**을 따로 알리는 메뉴가 **별도**로 있는 모델이 있다 (예: One UI 8, 신형 플래그십 순차 적용).

1. **전화** 앱 → **설정**  
2. **보이스피싱 의심 전화 알림** → **켜기**

공식 뉴스·고객 안내 기준 **점진 확대** 중이다. 메뉴가 없으면 **소프트웨어 업데이트** 후 다시 본다.

### 7.4 차단·신고

| 동작 | 방법 |
|------|------|
| **수신 후 차단** | 통화 기록·수신 화면에서 **차단** |
| **스팸 신고** | 삼성 전화 **신고** → 제휴 DB 반영에 쓰인다고 안내 |
| **수동 차단 목록** | 전화 앱 **스팸 및 차단 번호** |

### 7.5 문자(스팸)는 별도

**전화**와 **메시지** 설정이 **같지 않다.**

| 기능 | 대략 위치 |
|------|-----------|
| **악성 메시지 차단** | **메시지** 앱 → 설정 → 스팸·악성 메시지 (KISA 연동 등, One UI 6.1+) |
| **인텔리전스로 차단** | 메시지 앱 → **스팸 및 차단 번호 관리** 등 (One UI 7+) |

스미싱 링크는 [[삼성페이]]·금융 앱 안내와 같이 **문자만 믿지 않는다.**

### 7.6 메뉴가 없을 때

| 상황 | 참고 |
|------|------|
| One UI 6 이하 | **발신번호 및 스팸 확인** 미지원일 수 있음 → **업데이트** 또는 통신사·서드파티 앱 |
| 통신사 앱 | 예전 **후후**(KT) 등 **별도 앱** 쓰던 경우 — 삼성 전화 기능과 **중복** 가능 |
| Google 전화 기본 | 기본 전화 앱이 **Google 전화**면 삼성 메뉴가 다름 → **삼성 전화**를 기본으로 바꾸거나 해당 앱 스팸 설정 |
| 해외 펌웨어 | 메뉴·제휴사가 **국내와 다름** |

One UI 버전: `설정 → 휴대전화 정보 → 소프트웨어 정보 → One UI 버전`.

### 7.7 주의

- **의심** 표시일 뿐, 법적 판단이 아니다.  
- **검찰·금융·택배** 사칭은 **전화만** 보지 말고 공식 앱·번호로 **역확인**.  
- 기능 사용 시 **발신 번호·통화 메타**가 제휴사(Hiya 등)로 전달될 수 있다 — 약관 확인.  
- 부모님·가족 폰도 **같이 켜 두는** 것을 권장하는 안내가 많다.
