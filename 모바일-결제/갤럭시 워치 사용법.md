# 갤럭시 워치 사용법

> **분류:** 모바일·결제 · [[생활위키 목차]]

갤럭시 워치(**Wear OS + One UI Watch**) 설정·알림·배터리·헬스 팁 정리. 
폰 본체 One UI는 [[갤럭시 폰 사용법]].

메뉴 이름은 **모델·One UI Watch 버전**에 따라 다를 수 있다.

확인일: 2026-08-11

---

## 0. 연동 그림

```text
갤럭시 폰 ([[갤럭시 폰 사용법]])
 │ Bluetooth / Wi-Fi
 ▼
갤럭시 웨어러블 앱 ── 워치 설정·앱·시계 화면·알림
 │
갤럭시 워치
 │
삼성 헬스 ── 운동·수면·심박·체성분 등 (폰에 기록 모음)
```

- **갤럭시 웨어러블** = 폰에서 워치를 관리 (필수) 
- 갤럭시 폰이 궁합이 가장 좋다. 일부 기능은 비갤럭시에서 제한될 수 있다.

---

## 1. 초기 설정

1. 폰에 **갤럭시 웨어러블**(Galaxy Wearable) 설치 
2. 워치 전원 → 폰 블루투스 → 앱 안내에 따라 페어링 
3. Samsung 계정·알림·전화·위치 등 권한 
4. 소프트웨어 업데이트 (앱 + 워치) 
5. 시계 화면·타일·알림 앱 정리 

LTE 모델은 별도 개통 시 폰 없이 통화·데이터 가능. 배터리·요금 부담이 있으니 필요시만.

## 2. 화면·조작

| 동작 | 설명 |
|------|------|
| 홈(시계) | 홈 버튼 / 제스처 |
| 앱 목록 | 위로 스와이프 등 (UI 버전별) |
| 알림 | 아래로 스와이프 |
| 빠른 설정 | 아래로 두 번 또는 상태 영역 |
| 타일 | 좌우 스와이프 — 날씨·운동·심박 등 |
| 회전 베젤 | 클래식·일부 모델. 목록 스크롤 |
| 퀵 버튼 | Ultra 등 — 운동 시작 등에 할당 |

**Now Bar** 등은 모델·업데이트에 따라 다르다.

---

## 3. 알림

폰 **갤럭시 웨어러블 → 알림**에서 앱별로 끈다.

- 둘 것: 전화, 문자, 캘린더, 은행 승인, 메신저 **중요 방만** 
- 끌 것: 쇼핑·뉴스·게임·광고성, 단톡 폭탄 

팁: 알림 시 화면 켜기, 폰 사용 중 워치 알림 숨기기, 무음/진동만. 
카카오톡 답장이 안 되면 워치용 앱·권한을 확인.

---

## 4. 배터리

1. **Always On Display** 끄기 또는 필요할 때만 
2. **손목 올려 켜기** — 밤에만 끄거나 수면 모드로 자동 OFF 
3. 밝기·자동 꺼짐 15~30초 
4. 불필요 알림 삭제 (§3) 
5. 단독 LTE 데이터 ON 시간 최소화 
6. 긴 운동 전 절전 / 불필요 GPS OFF 
7. 장거리: **절전 모드** 
8. 업데이트, 정품 충전, 고온·한겨울 방치 피하기 

수면 측정 ON + AOD·올려켜기 OFF 조합이 무난하다.

---

## 5. 건강·운동·수면 (개요)

삼성 헬스(폰) + 워치 센서. **참고용**.

| 기능 | 팁 |
|------|-----|
| 운동 자동 감지 | 오탐 많으면 민감도↓ |
| GPS 운동 | 야외에서 GPS 잡을 때까지 잠깐 대기 |
| 수면 | Overnight 착용. 충전은 아침 |
| 심박·산소·스트레스 | 스트랩 너무 느슨하지 않게 |

혈관 스트레스·항산화 지수 등도 **참고용**이다. 
**체성분(체지방·골격근 등)** 은 §6.

## 6. 체성분 측정 — 체지방량·체질량지수(BMI)

갤럭시 워치4 이후 많은 모델에 **BIA(생체전기저항분석)** 센서가 있어, 손목에서 **체성분**을 잰다. 
메뉴·지원 여부는 모델·국가·펌웨어에 따라 다르다.

### 6.1 이름 정리 (헷갈리기 쉬운 것)

| 용어 | 의미 (이 글에서의 뜻) |
|------|-------------------------|
| **체성분** | 삼성 헬스/워치 메뉴 이름. 지방·근육·수분 등을 **묶어서** 봄 |
| **체지방량 / 체지방률** | 지방이 얼마나 있는지 (측정·추정 결과의 핵심 중 하나) |
| **골격근량·체수분** | 같이 나오는 항목 |
| **체질량지수 (BMI)** | 키·몸무게로 계산하는 지수. 워치가 **체중을 직접 재지는 않음** → 입력한 체중·키로 계산 |
| **체질량**이라는 말 | 일상에서 BMI·체중과 섞어 쓰는 경우가 많음. 워치 화면은 보통 **체성분 / 체지방률 / BMI** 쪽 표기 |

정리: 워치가 손가락으로 재는 쪽은 **체성분(그중 체지방 등)** 이고, **BMI(체질량지수)** 는 프로필 키·체중 기반 계산에 가깝다.

### 6.2 측정 전 준비

- 폰 **삼성 헬스** 프로필: **키·성별·생년월일(계정)** 정확히 
- 체중은 **저울로 잰 값**을 입력 (워치가 체중계가 아님) 
- 스트랩을 적당히 밀착, 손목 뼈에 너무 뜨지 않게 
- 가능하면 **매일 비슷한 조건** (예: 아침, 화장실 후, 공복에 가깝게) 
- 임산부·이식 의료기기·안내상 금지 대상은 **측정하지 않음** (제품 안내)

의료용 인바디·DEXA와 **숫자가 다를 수 있다**. 추세(같은 워치·같은 방법)를 보는 용도가 안전하다.

### 6.3 워치에서 측정하는 법

모델·UI에 따라 문구가 조금 다를 수 있다.

1. 워치 앱 목록 → **삼성 헬스** 
2. **체성분** → **측정** 
3. 안내되면 **성별·키·체중** 확인/입력 (체중은 최근 저울 값) 
4. 화면 안내에 따라, 워치를 **착용한 팔의 반대 손** 손가락을 올린다 
 - 흔히 **중지·약지**를 각각 **홈 버튼**과 **뒤로 가기 버튼**(옆면 두 버튼)에 접촉 
 - 손가락끼리 서로 닿지 않게, 버튼 **이외** 케이스에는 대지 않기 
5. 손바닥이 위·팔은 몸에 붙이지 않고, **약 15초** 움직이지 않기 
6. 결과: **체지방률** 등이 크게 나오고, 스크롤하면 골격근량·체지방량·체수분·BMI·기초대사량 등 

같은 손가락·비슷한 각도로 재는 편이 비교에 유리하다. 
손가락이 너무 건조하면 신호가 끊길 수 있어, 안내대로 살짝 촉촉하게 한 뒤 재시도하는 경우가 있다. 
워치 **뒷면 센서**는 이물질·수분을 닦는다.

### 6.4 폰에서 결과 보기

측정은 **워치에서 시작**하는 흐름이 일반적이다. 
끝나면 폰 **삼성 헬스 → 체성분**(또는 신체 관련 메뉴)에서 기록·그래프를 본다. 
프로필(키·체중)이 틀리면 결과가 크게 흔들린다 → 헬스 앱에서 수정.

### 6.5 결과가 들쭉날쭉할 때

| 원인 후보 | 대응 |
|-----------|------|
| 체중 미입력·오래된 체중 | 저울 후 다시 입력 |
| 키·성별·나이 오류 | 헬스·삼성 계정 프로필 |
| 손가락 접촉·각도·힘 | 같은 손가락, 안내 자세 |
| 운동 직후·목욕·과음·부종 | 조건 맞춰 다시 |
| 스트랩 느슨 | 밀착 |

숫자 하나에 일희일비하지 말고, **같은 조건의 추세**를 본다.

## 8. 폰 + 워치 연동

| 상황 | 활용 |
| ------ | ------------------------- |
| 폰 찾기 | 워치에서 벨 / 반대 |
| 사진 | 워치로 폰 카메라 셔터 |
| 결제 | [[삼성페이]] / Samsung Wallet |
| 잠금 | 워치 착용 중 폰 잠금 해제(설정 시) |
| 통화 | 워치 스피커·버즈 |
| 배터리 응급 | 폰 **무선 배터리 공유** |

### 8.1 카카오맵 · 대중교통 실시간 (Wear OS)

**카카오맵**을 갤럭시 워치에 설치·연동하면, 폰을 꺼내지 않고 **버스·지하철 도착 정보**와 **승하차 알림**을 손목에서 볼 수 있다. 
출근·환승 때 가방을 든 채 폰 위젯을 여는 대신 워치로 확인하는 용도다.

| 항목 | 내용 |
|------|------|
| 플랫폼 | **Wear OS** (갤럭시 워치 4 이후, Wear OS 3.0+ 등 — [공식 안내](https://kakaomap.tistory.com/367) 기준) |
| 앱 | 폰 **카카오맵** + 워치용 **카카오맵** (워치 **Play 스토어**에서 설치) |
| 버전 | 폰 카카오맵 **5.8.0+**, 워치 앱 **1.0.0+** (이후 버전은 스토어 표기 따름) |
| 연결 | 폰·워치 **블루투스** (길 안내·승하차 연동 시 폰과 동기화) |

```text
[폰] 카카오맵 설치 · 위치 권한
 ↓
[워치] Play 스토어 → 카카오맵 설치 · 위치 동의
 ↓
[폰] 카카오맵 → 워치 설정 → 즐겨찾는 버스·지하철 등록
 ↓
[워치] 도착 정보 · (경로 안내 시) 승하차 진동
```

#### 설치·권한

1. 폰에 **카카오맵** 최신 버전 설치  
2. 워치에서 **Google Play 스토어** → **카카오맵** 검색 → 설치  
   - **갤럭시 웨어러블** → 앱 → 워치에 앱 보내기 경로도 있음  
3. 워치에서 카카오맵 **첫 실행** → **위치** 권한 (보통 **앱 사용 중** 허용)  
4. 폰·워치 **소프트웨어 업데이트** 후 메뉴가 안 보이면 버전 확인

#### 워치에서 할 수 있는 것

| 기능 | 설명 |
|------|------|
| **즐겨찾기 도착** | 폰에서 등록한 **버스·지하철** 실시간 **도착 정보** |
| **내 주변** | 별도 등록 없이 **GPS** 기준 가까운 **정류장·역** (마지막 화면 스와이프 등에서 **거리순** 옵션) |
| **승하차 알림** | 폰에서 **대중교통 길찾기** 후 **승하차 알람** 실행 → 워치 **진동**으로 승·하차 지점 안내 |
| **길 안내 연동** | 안내 중 워치에서 **구간·주행** 확인, 일시정지·종료 등 **간단 조작** |
| **자전거 내비** | (지원 시) 폰 거치 없이 워치 **진동** 길 안내 |

**실시간 위치**는 대중교통 **도착·경로 안내** 맥락이다. 타 버스·지하철 **차량 GPS**가 지도에 항상 뜨는 것과는 **항목·지역**마다 다를 수 있다. 화면에 나오는 **도착 분·역·환승**을 보면 된다.

#### 폰에서 워치 연동 설정

1. 폰 **카카오맵** 실행  
2. **설정** → **워치**(또는 웨어러블·Galaxy Watch) 관련 메뉴  
3. **자주 쓰는 버스 번호**, **지하철 역**, **정류장** 등 등록 → 워치 **홈·목록**에 표시  

메뉴 이름은 앱 버전마다 다르다. 없으면 설정 **검색**에 `워치` 입력.

#### 승하차 알림 쓰는 흐름

1. 폰 카카오맵에서 **출발·도착** 입력 → **대중교통** 경로 선택  
2. **승하차 알람**(또는 유사 이름) **시작**  
3. 워치에 **연동** 안내가 뜨면 허용 — 착용 중 **진동**으로 승차·하차·환승 구간 확인  
4. 이동 중 위치가 바뀌면 워치 **경로·안내**가 갱신되는 경우가 많음 (지하철·버스 안에서 **역·정류장 지나침** 방지)

폰을 가방에 넣어도 되지만, **블루투스 끊김**·**배터리 절전**이면 연동이 끊길 수 있다 → §9 연결 문제 참고.

#### 워치에서 여는 법

| 방법 | |
|------|--|
| 앱 목록 | **카카오맵** 아이콘 |
| **타일** | 웨어러블 앱에서 카카오맵 **타일** 추가 (자주 쓸 때) |
| 위치 갱신 | 화면 **아래로 당겨** 새로고침(↻) — GPS·도착 정보 다시 조회 |

#### 주의·한계

| 주제 | 내용 |
|------|------|
| **지원 기기** | 구형 워치·비 Wear OS는 **미지원** |
| **위치·배터리** | GPS·백그라운드 안내는 **배터리** 소모 ↑ ([[갤럭시 워치 사용법]] §4) |
| **LTE 워치** | 폰 없이도 되는 경우가 있으나 **데이터·연결** 상태 따름 |
| **도착 정보** | 교통·API 지연으로 **실제와 1~2분 차** 날 수 있음 |
| **다른 앱** | **카카오버스** 워치·**네이버 지도** 등은 별도 — 이 절은 **카카오맵 Wear OS** 기준 |
| **환급** | 교통비 **K-패스** 등은 결제·가입 제도 → [[케이패스]] (맵과 별개) |

대중교통을 매일 쓰면 **즐겨찾기 + 승하차 알림 + 타일** 조합이 편한 경우가 많다.

연결이 끊기면: 웨어러블·Samsung Accessory Service 배터리 제한 없음, 블루투스 유지, 금속 케이스 간섭 확인. 
폰 쪽 세부: [[갤럭시 폰 사용법]].

## 9. 모델·문제 대처

| 계열 | 특징 |
|------|------|
| Watch FE / 보급 | 가성비 |
| Watch 일반 | 일상·슬림 |
| Classic | 회전 베젤 |
| Ultra | 야외·퀵버튼·배터리 |

혈압·ECG·체성분 등은 **국가 인허가·모델**에 따라 없을 수 있다.
