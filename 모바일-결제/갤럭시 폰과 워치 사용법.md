# 갤럭시 폰·워치 사용법

> **분류:** 모바일·결제 · [[생활위키 목차]]

삼성 갤럭시 스마트폰(One UI)과 갤럭시 워치(Wear OS + One UI Watch)를 같이 쓸 때 자주 쓰는 설정·팁 정리.  
메뉴 이름은 **모델·One UI 버전**에 따라 조금 다를 수 있다. 설정 검색창에 한글 키워드를 치면 찾기 쉽다.

확인일: 2026-08-06

---

## 0. 같이 쓰는 그림

```text
갤럭시 폰 (One UI)
    │  Bluetooth / Wi-Fi
    ▼
갤럭시 웨어러블 앱 ── 워치 설정·앱·시계 화면·알림
    │
갤럭시 워치 (One UI Watch)
    │
삼성 헬스 ── 운동·수면·심박 등 (폰에 기록 모음)
```

- **폰** = 본체·알림 허브·앱 설치  
- **워치** = 손목에서 알림·운동·결제·원격 조작  
- **갤럭시 웨어러블** = 폰에서 워치를 관리하는 앱 (필수)

건강 수치는 **의료 진단용이 아니다**. 이상 증상이 있으면 병원을 본다.

# Part A — 갤럭시 폰

## 1. 처음 해두면 좋은 설정

| 항목 | 어디 / 무엇을 |
|------|----------------|
| Samsung 계정 | 설정 → 계정. Find My Mobile, 백업, Galaxy Store |
| Google 계정 | Play 스토어·백업 |
| 지문 / 얼굴 | 설정 → 보안 및 개인정보 보호 → 생체 인식 |
| 알림 | 설정 → 알림. 중요한 앱만 허용 |
| 배터리 | 설정 → 배터리. 사용 패턴 확인 |
| 소프트웨어 업데이트 | 설정 → 소프트웨어 업데이트. 보안 패치 |

설정 앱 **검색창**에 `AOD`, `측면`, `루틴`처럼 치면 메뉴를 헤매지 않아도 된다.

---

## 2. 제스처·버튼 (매일 쓰는 조작)

모델마다 네비게이션이 **제스처** 또는 **소프트 버튼 3개**다.

| 동작 | 흔한 방법 |
|------|-----------|
| 홈 | 하단에서 위로 스와이프 (제스처) / 홈 버튼 |
| 최근 앱 | 홈 제스처 후 멈추기 / 최근 앱 버튼 |
| 뒤로 | 좌·우 가장자리에서 안쪽으로 |
| 전원 / 측면 | 측면 버튼 짧게 = 화면 끄기, 길게 = 전원 메뉴 또는 빅스비/Gemini (설정 가능) |
| 빠른 설정 | 상태바를 두 손가락으로 내리기 또는 두 번 내리기 |
| 스크린샷 | 측면+볼륨 아래 (또는 손 측면 밀기 — 모션에서 켜기) |
| 화면 녹화 | 빠른 설정 패널에 **화면 녹화** 타일 추가 |

측면 버튼을 길게 눌렀을 때 **전원 메뉴**가 뜨게 바꾸는 것을 추천하는 사람이 많다.  
`설정 → 고급 기능 → 측면 버튼` (경로 유사).

---

## 3. One UI 핵심 기능

### 3.1 모드 및 루틴

`설정 → 모드 및 루틴`

- **모드**: 수면, 운전, 직장, 운동 등 — 방해 금지·화면·연결을 묶음  
- **루틴**: IF-THEN 자동화  
  예: `집 Wi-Fi 연결 → 와이파이 통화 켜기`, `특정 시간 → 다크 모드`, `이어폰 연결 → 미디어 볼륨`

조금만 만들어도 체감이 크다. 너무 많이 만들면 충돌하니 5~10개 안으로.

### 3.2 Good Lock / Good Guardians (선택)

Galaxy Store에서 **Good Lock** 모듈로 UI를 깊게 커스텀할 수 있다.

| 모듈 예 | 용도 |
|---------|------|
| LockStar | 잠금화면 |
| Home Up | 홈 화면·폴더 |
| Keys Cafe | 키보드 |
| NavStar | 내비 바 |
| MultiStar | 멀티윈도우 |
| Nice Catch | 클립보드·알림 히스토리 등 |

필수는 아니다. 기본 One UI만으로도 충분하면 설치하지 않아도 된다.

### 3.3 멀티윈도우·DeX

- 최근 앱 → 앱 아이콘 → **멀티 윈도우 / 팝업**  
- **Samsung DeX**: 지원 폰을 모니터·TV에 연결해 PC형 UI (케이블/무선은 모델별)

폴드·태블릿과 같이 쓰면 창 분할이 특히 유용하다.

### 3.4 Secure Folder (보안 폴더)

민감한 사진·앱·파일을 지문 뒤에 분리.  
`설정 → 보안` 쪽에서 Secure Folder 생성.

### 3.5 무선 배터리 공유 / 급속 충전

폰으로 버즈·워치를 응급 충전(모델·지원 여부 확인).  
보호 케이스·정품 아닌 충전기는 무선 충전이 약하거나 발열날 수 있다.

---

## 4. 배터리·발열 팁 (폰)

1. **항상 최대 성능**보다 적응형 배터리·자동 최적화  
2. 백그라운드  unrestricted 앱을 줄인다 (`설정 → 앱 → 배터리`)  
3. 5G가 불필요하면 **LTE 우선** 또는 지능형 전환  
4. AOD(Always On Display)는 편하지만 배터리를 먹는다 — 예약 시간만 켜기  
5. 게임·카메라 직후 충전이면 **열 식힌 뒤**  
6. 80~90% 충전 제한(배터리 보호) 옵션이 있으면 야간 충전에 유리  
7. 저장공간 부족도 버벅임의 원인 — 클라우드·휴지통 정리

---

## 5. 알림·집중

- 앱마다 알림 채널(중요/조용)을 나눈다  
- **방해 금지 / 수면 모드**로 밤 알림 차단  
- 카카오톡 등은 채팅방별 알림 OFF가 정신 건강에 도움  
- 엣지 조명(테두리 빛)은 취향 — 밤에 거슬리면 끄기

# Part B — 갤럭시 워치

## 7. 초기 설정

1. 폰에 **갤럭시 웨어러블**(Galaxy Wearable) 설치  
2. 워치 전원 → 폰 블루투스 켜기 → 앱 안내에 따라 페어링  
3. Samsung 계정·웨어러블 권한(알림, 전화, 위치 등) 허용  
4. 소프트웨어 업데이트 (폰 앱 + 워치 설정)  
5. 시계 화면·타일·알림 앱을 취향에 맞게

갤럭시 폰이 가장 궁합이 좋다. 일부 기능(수면 코칭 세부, 전화 연동 등)은 **비갤럭시 폰**에서 제한될 수 있다.

LTE 모델은 별도 개통 시 폰 없이 통화·데이터 가능. 배터리·요금 부담이 있으니 필요시만.

---

## 8. 워치 화면·조작

| 동작 | 설명 |
|------|------|
| 홈(시계) | 홈 버튼 / 제스처 |
| 앱 목록 | 위로 스와이프 등 (UI 버전별) |
| 알림 | 아래로 스와이프 |
| 빠른 설정 | 아래로 두 번 또는 상태 영역 |
| 타일(위젯 줄) | 좌우 스와이프 — 날씨·운동·심박 등 |
| 회전 베젤 | 클래식·일부 모델. 목록 스크롤에 편함 |
| 퀵 버튼 | Ultra 등 — 운동 시작 등에 할당 |

**Now Bar / 멀티 정보 타일**(One UI 8 Watch 계열): 진행 중 운동·타이머 등을 시계 화면에서 빠르게 이어서 본다. 모델·업데이트 여부 확인.

---

## 9. 알림 — 워치 배터리·멘탈의 핵심

폰 **갤럭시 웨어러블 → 알림**에서 앱별로 끈다.

추천 원칙:

- 워치에 둘 것: 전화, 문자, 캘린더, 은행 승인, 메신저 **중요 방만**  
- 끌 것: 쇼핑·뉴스·게임·광고성, 카톡 단톡 폭탄  

옵션 팁:

- 알림 시 **화면 켜기** ON/OFF — 켤수록 편하고 배터리↓  
- 폰 사용 중 워치 알림 숨기기 — 중복 방지  
- 무음/진동만 — 회의·도서관

카카오톡은 웨어러블용 앱·알림 설정이 버전에 따라 다르다. 답장이 안 되면 Play/Galaxy Store의 워치용 카카오톡·권한을 확인.

---

## 10. 배터리 팁 (워치)

효과 큰 순서로:

1. **Always On Display 끄기** 또는 필요한 때만  
2. **손목 올려 켜기** — 편하지만 소모 큼. 밤에만 끄거나 수면 모드로 자동 OFF  
3. 화면 밝기·**자동 꺼짐 15~30초**  
4. **불필요 알림 삭제** (9절)  
5. Wi-Fi는 폰 근처면 자동으로 충분. 단독 LTE는 데이터 ON 시간 최소화  
6. 긴 운동 전 **운동 중 절전** / GPS 필요 없으면 끄기  
7. 야간·장거리: **절전 모드** (기능 제한됨 — 전화·알림 위주)  
8. 소프트웨어·앱 업데이트 (비정상 배터리 드레이어 수정)  
9. 정품·지지 충전기. 고온·한겨울 방치는 수명↓  

수면 측정을 켠 채 자면 배터리 곡선이 가파르다. **수면은 켜고 AOD·올려켜기는 끄는** 조합이 무난하다.

---

## 11. 건강·운동·수면

삼성 헬스(폰) + 워치 센서.

| 기능 | 팁 |
|------|-----|
| 운동 자동 감지 | 걷기·달리기 감도 조절. 오탐 많으면 민감도↓ |
| GPS 운동 | 출발 전 야외에서 GPS 잡을 때까지 잠깐 대기 |
| 수면 | Overnight 착용. 충전은 아침. 코골이 등은 **폰 마이크·권한** 필요할 수 있음 |
| 심박·산소·스트레스 | 스트랩을 너무 느슨하지 않게. 문신·추위는 측정 오차 |
| 러닝 코치 등 | One UI Watch 업데이트·모델에 따라 제공. 동기 부여용 |

혈관 스트레스·항산화 지수 등 신규 지표도 **참고용**이다. 공포 마케팅에 흔들리지 말 것.

운동 중 음악: 워치에 오프라인 음원 / 폰 제어 / 버즈 직접 연결(모델별).

---

## 12. 제스처·버튼 커스텀

`설정 → 버튼 및 제스처` (워치 또는 웨어러블 앱)

- 홈 버튼 **길게 누르기**: Bixby → **Google Gemini** 등으로 변경 가능(지원 시)  
- 두 번 누르기: 최근 앱 / 결제([[삼성페이]]·Samsung Wallet) 등  
- 제스처: 주먹 쥐기·핀치로 알림 닫기·전화 받기 등 (모델·버전별)

개발자 옵션(소프트웨어 버전 연속 탭)으로 애니메이션 배율을 낮추면 UI가 빨라 보일 수 있다. 필수 아님.

---

## 13. 폰 + 워치 연동 팁

| 상황 | 활용 |
|------|------|
| 폰 찾기 | 워치에서 폰 벨 울리기 / 그 반대 |
| 사진 | 워치로 폰 카메라 셔터 |
| 결제 | [[삼성페이]] / Samsung Wallet (교통·카드 — 지원 카드만) |
| 잠금 | 워치 착용 중 폰 잠금 해제(설정 시) |
| 통화 | 워치 스피커·버즈 연동 |
| 알림 읽기 | 회의 중 폰은 두고 워치만 진동 |
| 배터리 응급 | 폰 **무선 배터리 공유**로 워치 잠깐 충전 |

연결이 자주 끊기면: 폰 배터리 최적화에서 **갤럭시 웨어러블·Samsung Accessory Service**를 제한 없음으로, 블루투스를 끄지 않기, 두꺼운 금속 케이스 간섭 확인.

## 15. 문제 빠른 대처

| 증상 | 시도 |
|------|------|
| 워치 연결 안 됨 | 블루투스 토글 → 웨어러블 앱에서 재연결 → 양쪽 재부팅 |
| 알림만 안 옴 | 폰 알림 권한, 웨어러블 앱별 알림, 절전 제외 |
| 배터리 급감 | AOD·올려켜기·LTE·최근 설치 앱 의심. 안전 모드·초기화는 최후 |
| 수면 기록 이상 | 착용 위치·밤중 충전 여부·헬스 권한 |
| 터치 이상 | 보호필름·수분. 방수 후 스피커에 물 빼기 기능 |
| 충전 안 됨 | 접점 이물질, 정품 케이블, 무선 정렬 |

초기화 전에 **웨어러블 앱에서 백업**을 확인한다.

## 16. 추천 세팅 체크리스트

### 폰

- [ ] 측면 버튼 = 전원 메뉴 (취향)  
- [ ] 수면 모드·방해 금지 일정  
- [ ] 루틴 2~3개 (집/잠/이어폰)  
- [ ] 알림 다이어트  
- [ ] 배터리 보호·업데이트  

### 워치

- [ ] 웨어러블 앱에서 알림 앱 최소화  
- [ ] AOD / 손목 올려 켜기 취향·배터리 타협  
- [ ] 타일에 날씨·운동·타이머  
- [ ] 수면 측정 ON + 야간 화면 자극 최소화  
- [ ] 홈 버튼 길게 = 쓸 비서(Gemini 등)  
- [ ] 최신 One UI Watch / 보안 패치
