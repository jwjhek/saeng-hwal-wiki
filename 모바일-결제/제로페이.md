# 제로페이

> **분류:** 모바일·결제 · [[생활위키 목차]]

**제로페이**(Zero Pay)는 소상공인·전통시장 등을 위한 **QR·바코드 기반 계좌 결제** 서비스다. 
별도 **제로페이 전용 앱** 없이, 쓰던 **은행 앱·간편결제 앱** 안에서 결제한다.

공식: [https://www.zeropay.or.kr](https://www.zeropay.or.kr)

확인일: 2026-08-11

관련: [[삼성페이]] · [[배달 앱]] · [[세액공제 기초]] · [[갤럭시 폰 사용법]]

---

## 1. 개요

| 항목       | 설명                                                                        |
| -------- | ------------------------------------------------------------------------- |
| 무엇       | 가맹점 **QR**을 찍거나, 내 **QR·바코드**를 매장이 스캔해 **계좌에서 출금**                        |
| 목적       | 소상공인 **카드 수수료 부담** 완화, **현금 없는** 직거래 결제                                   |
| 앱        | **제로페이 단독 앱 필수 아님** — 연동된 은행·페이 앱 목록은 [공식 사이트](https://www.zeropay.or.kr) |
| [[삼성페이]] | 삼성페이는 **카드·NFC** 중심. 제로페이는 **QR·계좌 직불** 중심 — **겹치지 않음**                   |

```text
[소비자] 은행·페이 앱에 계좌 등록
 ↓
[매장] 제로페이 가맹 QR 또는 바코드 리더기
 ↓
[결제] 계좌 → 가맹점 계좌 이체 (카드 VAN 경유 구조와 다름)
```

---

## 2. 언제 쓰나

| 상황 | 제로페이 |
|------|----------|
| 동네 **식당·카페·미용실** | 카드 단말기 없어도 QR만 있으면 가능한 곳 많음 |
| **전통시장·상점가** | 스티커·QR 부착 가맹점 |
| **현금 없이** 계좌 결제 | 카드 없이도 (계좌·앱만 있으면) |
| **소득공제** | 조건 맞으면 **소득공제** 대상으로 거론되는 경우 있음 (§7) |

**대형마트·일부 프랜차이즈·온라인**은 제로페이가 **없거나 제한**적이다. 매장 **스티커**·앱 **가맹점 찾기**로 확인한다.

---

## 3. 결제 방식 (두 가지)

공식 안내 기준으로 **소비자·가맹점** 역할이 나뉜다.

### 3.1 가맹점 QR을 내가 찍기 (가장 흔함)

| 단계 | 동작 |
|------|------|
| 1 | 연동 앱 실행 → **제로페이**·**QR결제** 메뉴 |
| 2 | **직불**(계좌) 또는 **상품권** 선택 |
| 3 | 매장 **QR코드** 촬영 |
| 4 | **금액 입력** → 비밀번호·생체 인증 → 결제 |
| 5 | 가맹점 앱에 **실시간 입금 알림** (가맹점 측) |

매장에 붙은 QR은 보통 **고정형**(같은 QR)이다.

### 3.2 내 QR·바코드를 매장이 찍기

| 단계 | 동작 |
|------|------|
| 1 | 앱에서 **결제용 QR·바코드** 표시 |
| 2 | 직원이 **리더기**로 스캔 |
| 3 | 금액 확인 후 승인 |

**바코드 리더기**가 있는 가맹점만 가능하다.

처음 쓸 때 **「내가 찍나?」「가게가 찍나?」** 헷갈리기 쉽다. 계산대 **안내·스티커**를 보면 된다.

---

## 4. 어떤 앱에서 쓰나

**제로페이 전용 앱을 새로 깔 필요는 없다.** 이미 쓰는 앱이 연동돼 있으면 그 안에서 한다.

| 종류 | 예 (일부, 변경됨) |
|------|-------------------|
| **은행 앱** | 국민·신한·우리·하나·농협·카카오뱅크·토스 등 |
| **간편결제** | [[카카오페이]] · [[네이버 페이]] · 페이코 등 (연동 여부는 앱·시기별) |

정확한 목록: [제로페이 공식 — 결제 가능 앱](https://www.zeropay.or.kr)

### 시작하기 (공통 흐름)

1. **본인 명의** 은행 계좌 준비  
2. 쓰는 **은행·페이 앱** 업데이트  
3. 앱 안 **제로페이**·**QR결제**·**계좌이체 결제** 메뉴  
4. **결제 계좌** 등록 · **결제 비밀번호**·생체 설정  
5. 제로페이 **가맹점**에서 §3대로 결제

[[삼성페이]]에 카드를 넣어 두어도, 제로페이는 **같은 앱의 다른 메뉴**이거나 **은행 앱**에서 하는 경우가 많다.

---

## 5. 직불 vs 모바일 상품권

| 구분 | 직불 | 모바일 상품권 |
|------|------|----------------|
| 돈 나가는 곳 | **연결된 은행 계좌** | 미리 산 **지역·전통시장 상품권** 등 |
| 쓰임 | 일반 가맹 결제 | **상품권 가맹**·행사 |
| QR | 가맹 QR 스캔 | 상품권 메뉴에서 스캔 |

**[[온누리 상품권]]** 이 대표적이다. 디지털은 **전용 앱 충전 + 등록 카드 결제** 또는 앱·제로페이 QR 경로로 쓴다.  
지자체·행사 **상품권**은 별도 충전·유효기간이 있다. **직불**과 메뉴가 갈라진다.

## 6. 가맹점 찾기

| 방법 | |
|------|--|
| **제로페이 홈페이지** | 가맹점 찾기 |
| **결제 앱** | 주변 가맹점·지도 검색 (앱마다 다름) |
| **매장** | 입구·계산대 **제로페이 가능** 스티커 |
| **지도** | [[지도 앱]]([[네이버 지도]]·[[카카오맵]] 등)에서 「제로페이」 검색 (표시 여부는 매장마다) |

가맹이어도 그날 **QR 분실·네트워크** 문제로 안 될 수 있다. **현금·카드** 대안을 두는 편이 안전하다.

---

## 7. 소득공제·혜택 (참고)

제로페이·온누리 연동 결제는 **신용카드 등 사용금액 소득공제** 안에 들어가며, 가맹 분류에 따라 **공제율**이 달라진다. → [[신용카드 소득공제]]

| 주의 | |
|------|--|
| **비율·한도·대상 가맹** | **매년·귀속 연도**마다 바뀜 |
| **본인 명의 계좌** | 타인 계좌·현금성 충전이면 안 될 수 있음 |
| **세액공제 아님** | 대부분 **소득공제** 쪽 논의 — [[세액공제 기초]]와 구분 |
| **확인** | **국세청**·**홈택스**·제로페이·카드사 **당해 연도** 안내 |
| **상세** | [[신용카드 소득공제]] — 공제율 표·한도·온누리·전통시장 40% 분류 |

연말정산 전에 **「제로페이 소득공제」** 를 검색해 **그해 규정**을 본다. 이 글은 **세무 자문이 아니다.**

## 8. 다른 결제와 비교

| | 제로페이 | [[삼성페이]] | 신용카드 |
|--|----------|--------------|----------|
| 수단 | **계좌**·상품권 | **카드**·교통 등 | 카드 |
| 결제 | **QR** 위주 | **NFC**·단말 | 카드 긁기·NFC |
| 앱 | 은행·페이 **내장** | 삼성 월렛 | 카드사·페이 |
| 가맹 | 제로페이 **가입** 매장 | 카드 가맹 일반 | 넓음 |
| 수수료(가맹) | **낮은 편** (정책 목적) | 카드 수수료 체계 | 카드 수수료 |

**서울페이**·**지역화폐**([[경기지역화폐]] 등)는 **별도** 지자체·상품권 체계다. 이름만 비슷하고 **앱·가맹**이 다를 수 있다.

[[배달 앱]] 주문은 보통 **앱 결제·카드**이고, 제로페이 QR은 **오프라인 매장** 쪽에 가깝다.
