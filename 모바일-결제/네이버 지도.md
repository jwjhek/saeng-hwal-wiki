# 네이버 지도

> **분류:** 모바일·결제 · [[생활위키 목차]]

**네이버 지도**는 네이버의 지도·길찾기·장소 검색 앱이다. 
국내 **가게·병원·관광지** 정보와 리뷰·예약 링크가 풍부한 편이라, 「어디 있지?」보다 **「어떤 곳이지?」** 를 고를 때 자주 쓴다.

비교: [[지도 앱]] · [[카카오맵]] · [[구글 지도]]

확인일: 2026-08-13

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 플랫폼 | Android · iOS · 웹(map.naver.com) |
| 계정 | 네이버 ID (저장·리뷰 동기화) |
| 강점 | **플레이스**·블로그·예약·부동산 등 네이버 생태계 연동 |
| 약점(상대적) | 해외·오프라인은 [[구글 지도]]가 유리한 경우 많음 |

---

## 2. 자주 쓰는 기능

### 2.1 장소 검색

- 카테고리(음식점·카페·병원·주유소 등)·키워드 검색  
- **영업시간·휴무·전화·주차·메뉴** — 방문 전 **최근 리뷰 날짜**도 같이 본다  
- **음식점 평점** — [[카카오맵]]이 더 낫다는 **이용자 평**도 있어, 맛집 후보는 두 앱 **평점을 같이** 보는 편이 안전  
- 네이버 예약·스마트플레이스 링크가 붙은 가게는 앱에서 바로 예약 가능한 경우 있음  

부동산·매물 지도는 [[호갱노노]] 등 **전용 앱**과 데이터·UI가 다르다.

### 2.2 길찾기

| 모드 | 설명 |
|------|------|
| **자동차** | 실시간 교통·유료도로·회피 옵션 |
| **대중교통** | 버스·지하철 환승 — [[카카오맵]]과 **도착·경로**가 다를 수 있음 |
| **도보·자전거** | 단거리·공원길 |

운전 내비만 쓸 때는 [[티맵]]·[[카카오맵]]과 **교통 정보**를 비교해 보는 사용자도 있다.

### 2.3 저장·공유

- **집·회사**·즐겨찾기·나만의 지도(목록)  
- 카카오톡·문자로 **위치 링크** 공유  
- [[배달 앱]] 주소 입력 시 핀을 여기서 잡고 **동·층**을 배달 앱에 다시 적는 패턴이 흔하다  

---

## 3. 네이버만의 연동

| 연동 | 쓰임 |
|------|------|
| **네이버 검색·플레이스** | 웹에서 본 가게를 앱 지도로 이어짐 |
| **블로그·클립** | 맛집 후기·영상 링크 |
| **네이버 예약** | 미용실·병원 등 (가게별 상이) |
| **부동산·지도** | 매물 핀 — 투자·계약은 공식 등기·계약서가 우선 |

---

## 4. 설정·권한

1. **위치** — 검색·길찾기: 「앱 사용 중」이면 충분한 경우 많음. 백그라운드 내비는 「항상」 요구될 수 있음  
2. **알림** — 길 안내·버스 도착 (원치 않으면 끄기)  
3. **로그인** — 저장 장소·리뷰·예약 이력 동기화  

---

## 5. 다른 앱과 같이 쓸 때

| 상황 | 팁 |
|------|-----|
| 대중교통 출퇴근 | [[카카오맵]]과 **도착 시간** 교차 확인 |
| 해외 | [[구글 지도]] + 오프라인 영역 (국내 일상은 반출 규제로 구글 지도만으로는 부족할 수 있음) |
| 운전만 | [[티맵]] 병행 설치 검토 |
| 가맹점·결제 | [[제로페이]]·[[온누리 상품권]] 앱 지도와 키워드 검색 병행 |

## 면책

> **면책**
> 영업시간·가격·리뷰는 **사용자 제출·업주 입력**이라 오래되거나 틀릴 수 있다. 방문·주문 전 **전화 확인**을 권한다.
> 내비·도보 안내는 참고용이며, 실제 도로 상황·안전은 운전자·보행자가 확인한다.
