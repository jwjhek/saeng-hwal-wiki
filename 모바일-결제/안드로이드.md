# 안드로이드

> **분류:** 모바일·결제 · [[생활위키 목차]]

**안드로이드**(Android)는 구글이 주도하는 **스마트폰·태블릿용 OS**다. 커널은 [[리눅스]]이지만, 앱·화면·권한은 PC 리눅스 배포판과 **다른 세계**다.

한국에서 “안드로이드 폰”은 대개 **삼성 갤럭시 + One UI**를 가리킨다. One UI는 안드로이드 **위 제조사 피부**이지, 안드로이드 그 자체가 아니다. 픽셀·모토로라·중저가 브랜드는 **설정 메뉴 이름부터** 다르다.

이 글은 **개념·계정·보안·다른 글과의 자리**만 정리한다. 갤럭시 버튼·루틴은 [[갤럭시 폰 사용법]]을 본다.

확인일: 2026-08-14  
버전 번호(Android 15·16 등)와 제조사 업데이트는 **기기마다** 다르다. `설정 → 휴대전화 정보 → 소프트웨어 정보`가 우선.

관련: [[갤럭시 폰 사용법]] · [[Termux 사용법]] · [[리눅스]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 모바일 OS. 앱은 **APK**(또는 스토어 번들)로 설치 |
| **누가 만드나** | **AOSP**(오픈 소스 뼈대) + 구글 **Play 서비스** + **제조사 UI** |
| **앱 장터** | **Google Play**. 갤럭시는 **Galaxy Store**가 겹침 |
| **계정** | **Google** 계정이 Play·백업·Gmail의 중심. 갤럭시는 **Samsung 계정**이 따로 |
| **PC와** | 커널만 리눅스. `apt`·데스크톱 앱이 그대로 도는 것이 **아님** → [[Termux 사용법]] |

```text
[커널] Linux
   +
[시스템] AOSP (권한·앱 샌드박스)
   +
[구글] Play 스토어 · Play 서비스 (대부분 시중 폰)
   +
[제조사] One UI · 다른 스킨 · 통신사 앱
   =
손에 쥔 “안드로이드 폰”
```

「안드로이드 = 갤럭시」「안드로이드 = 리눅스 PC」둘 다 **틀린 축약**이다.

## 3. 구글 안드로이드 vs 제조사 UI

| | **AOSP / 픽셀에 가까움** | **갤럭시 One UI** |
|--|------------------------|-------------------|
| 설정 이름 | 구글 기본에 가까움 | 삼성 번역·배치 |
| 자동화 | 구글 루틴 등 (기기별) | [[갤럭시 루틴]] |
| 데스크톱 | 없음이 흔함 | [[갤럭시 DeX]] |
| 스토어 | Play | Play + Galaxy Store |
| 업데이트 | 구글 기기 쪽이 **빠른 편** | 모델·통신사 **지원 연한**이 갈림 |

같은 Android 버전이어도 **보안 패치 날짜**가 다르다. 중고·알뜰폰은 **패치가 멈춘** 기기가 있다. 설정에서 **보안 업데이트** 날짜를 본다.

Play 서비스가 없는 폰(일부 해외·특수 기기)은 은행·지도 앱이 **안 깔리거나** 기능이 빠질 수 있다.

## 4. iPhone과 대략 비교

구매 권유가 아니다.

| | 안드로이드 (시중) | iOS (아이폰) |
|--|-------------------|--------------|
| 기기 | 삼성·구글·기타 **여러 회사** | 애플만 |
| 기본 장터 | Play | App Store |
| 파일·기본 앱 | 상대적으로 **열림**. 제조사마다 다름 | 닫힌 편, 생태계가 같음 |
| 국내 페이 | [[삼성페이]] MST 등 **기기 의존** | 애플페이 범위가 다름 |
| 워치 | Wear OS 등 | Apple Watch |
| 차 연결 | **Android Auto** | CarPlay — [[티맵]] 등 |

앱은 **스토어가 둘**이라 같은 서비스도 아이콘·권한이 조금 다를 수 있다.

## 5. 계정·백업·권한

| 할 일 | 설명 |
|------|------|
| **Google 계정** | Play, Gmail, 연락처·사진 동기(설정에 따름), Find My Device |
| **제조사 계정** | 갤럭시면 Samsung — 찾기, Galaxy Store, [[갤럭시 워치 사용법]] |
| **백업** | Google 백업 + (갤럭시) Smart Switch·삼성 클라우드. **둘 다 꺼져 있으면** 기기를 잃었을 때 복구가 어렵다 |
| **권한** | 위치·카메라·알림은 **앱마다**. 「항상 허용」은 지도·루틴만 |
| **잠금** | PIN·지문·얼굴. 화면 잠금이 없으면 분실 시 **전부 열림** |

권한을 **한 번에 다 허용**하는 앱은 의심한다. 은행·페이 사칭 앱은 [[Bitwarden 사용법]]·스토어 개발자 이름으로 가린다.

---

## 6. 앱을 어디서 받나

| 경로 | 메모 |
|------|------|
| **Play 스토어** | 기본. 리뷰·개발자명·권한을 본다 |
| **Galaxy Store** | 삼성 앱·Good Lock. Play에 없는 모듈이 있음 |
| **F-Droid** | 오픈소스. Termux는 여기·공식 APK가 안전하다는 안내가 많음 — [[Termux 사용법]] |
| **알 수 없는 출처 APK** | 악성코드·가짜 은행 앱 위험 **큼**. 이 글에서 **우회 설치를 안내하지 않음** |

Play에도 가짜가 있다. **공식 웹의 스토어 링크**, 개발자 이름, 다운로드 수를 같이 본다.

## 8. 개발·터미널 (방향만)

| 목적 | 글 |
|------|-----|
| 폰에서 명령·Git | [[Termux 사용법]] · [[리눅스 기본 명령어]] |
| 앱을 **만드는** 쪽 | 공식은 **Kotlin** 비중. JVM 기초는 [[Java 언어 학습]], PC JDK는 [[JDK]]. Studio는 **내장 JDK** |
| PC에서 폰 디버그 | Android Studio. 이 허브는 **사용 OS** 글이지 앱 강의가 아님 |

루팅·커스텀 롬·부트로더 해제는 **보증·보안 업데이트·뱅킹**이 깨지기 쉽다. **절차는 적지 않는다.**

---

## 9. 보안 습관

| 습관 | 이유 |
|------|------|
| **보안 패치**를 미루지 않기 | 제조사가 끊으면 기기를 바꾸는 시점이 됨 |
| 화면 잠금 + 잠금 전 알림 숨김 | 잠금 화면에 인증번호가 뜨면 탈취 |
| USB **파일 전송**은 필요할 때만 | 공공 충전기 |
| 스팸·피싱 | 갤럭시는 [[갤럭시 폰 사용법]] §7. 전화·문자는 **공식 앱 설정** |
| 중고 구매 | 계정 로그아웃·공장 초기화 여부, **잠긴 계정**(FRP) |

## 10. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 리눅스 커널 위의 **모바일 OS** + 구글·제조사 층 |

## 면책

> **면책**
> - **기종 구매·통신사 가입 권유가 아니다.**
> - 메뉴·버전·보안 패치·스토어 정책은 **제조사·구글·통신사**가 바꾼다. 기기 **설정 화면**이 우선.
> - 알 수 없는 APK·루팅·계정 우회는 **악성코드·보증 거절** 위험이 있다. 이 글은 그 절차를 안내하지 않는다.
> - 은행·페이 장애는 **앱·OS 조합**마다 다르다.
