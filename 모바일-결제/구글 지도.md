# 구글 지도

> **분류:** 모바일·결제 · [[생활위키 목차]]

**구글 지도**(Google Maps)는 Google의 지도·내비·장소 검색 서비스다. 
**해외 여행**·다국어·**오프라인 지도**·Street View에서 강점이 있고, 국내에서는 **지도(공간정보) 반출 규제** 때문에 서비스가 **제한적**인 편이라 [[네이버 지도]]·[[카카오맵]]과 **병행**하는 경우가 많다.

비교: [[지도 앱]] · [[네이버 지도]] · [[카카오맵]]

확인일: 2026-08-13

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 플랫폼 | Android · iOS · 웹 |
| 계정 | Google 계정 (저장·리뷰 동기화) |
| 강점 | 해외 POI·대중교통(도시별)·오프라인·위성·Street View |
| 약점(상대적) | 국내는 **지도 반출 규제**로 상세 데이터·기능이 제한 — 세부 주소·가게·내비는 국내 앱이 나은 경우 많음 |

---

## 2. 해외·여행

| 기능 | 쓰임 |
|------|------|
| **오프라인 지도** | Wi-Fi에서 영역 다운로드 → 데이터 없이 지도·길찾기(기능 제한) |
| **대중교통** | 도시마다 지원 수준 다름 — 현지 앱과 병행 권장 |
| **다국어** | 로마자·현지어 주소 검색 |
| **Street View** | 거리 실경 — 숙소·관광지 사전 확인 |

```text
여행 전: 숙소·역 주변 오프라인 영역 저장
 ↓
현지: 도보·대중교통·택시 경로
 ↓
귀국 후: 불필요한 오프라인 영역 삭제(용량)
```

## 3. 국내에서 쓸 때 — 지도 반출과 제한

한국은 **공간정보(지도 데이터)를 해외로 반출**하는 것에 대해 규제가 있다. 
Google 같은 **해외 지도 사업자**는 국내 상세 지도·측량 데이터를 해외 서버로 옮기기 어렵고, 그만큼 **국내 서비스 품질·기능이 제한**되는 구조다. 
(애플 지도 등 다른 해외 지도도 비슷한 맥락에서 국내 앱 대비 약한 편으로 알려진 경우가 많다.)

| 국내에서 체감되는 제한(예) | 설명 |
|---------------------------|------|
| **상세 주소·POI** | 동네 가게·영업시간 — [[네이버 지도]]·[[카카오맵]]이 풍부한 경우 많음 |
| **대중교통** | 실시간 도착·환승 — 국내 앱과 **정확도·노선** 차이 |
| **운전 내비** | 국내 교통·유료도로 — [[티맵]]·국내 앱과 비교 |
| **Street View** | 국내 커버리지가 해외보다 **좁거나 없는** 구역이 있음 |

**일상·출퇴근·맛집**은 국내 앱을 기본으로 두고, 구글 지도는 **해외 일정·다국어 검색** 보조로 쓰는 패턴이 흔하다.

## 4. 자주 쓰는 기능

| 기능 | 설명 |
|------|------|
| **저장된 장소** | 별·목록·여행 계획 |
| **공유 위치** | 실시간 위치 공유(기간 제한 설정 가능) |
| **리뷰·사진** | 가게 평점 — 참고만, 최근성 확인 |
| **타임라인** | Google 계정에 **이동 기록** 저장(설정에서 끄기·삭제 가능) — 프라이버시 주의 |

---

## 5. 설정·프라이버시

1. Google 계정 → **위치 기록**·타임라인 켜기/끄기  
2. 앱 **위치 권한** — 「사용 중」 vs 「항상」(내비 시)  
3. **오프라인 지도** 용량 관리 — 설정 → 오프라인 지도  
4. 가족·아이 기기는 **공유 범위**를 제한

## 6. 개발·API (참고)

웹·앱에 지도를 넣을 때 **Google Maps Platform** API를 쓴다. 
무료 할당·과금은 Google Cloud 콘솔 기준이며, 일상 이용 앱과는 별개다. 
개발 입문: [[Python 학습과 패키지]] 등과 별도로 공식 문서를 본다.
