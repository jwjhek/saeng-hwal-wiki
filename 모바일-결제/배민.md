# 배민

> **분류:** 모바일·결제 · [[생활위키 목차]]

**배달의민족(배민)** 앱·서비스 이용(주문)과 라이더 쪽 감각을 정리한다.  
비교: [[배달 앱]] · [[쿠팡이츠]] · 일하기: [[배달하기]]

확인일: 2026-08-07  
운영사: 우아한형제들(기업 구조·브랜드명은 시점마다 확인).

---

## 1. 한눈에

| 항목 | 내용 |
|------|------|
| 무엇을 | 음식 배달·포장, (지원 지역) 마트·스토어 등 |
| 누구용 | **주문 고객** 앱 / **가게** / **라이더(배달 파트너)** 앱이 분리 |
| 특징 감각 | 가게 수가 많고, **배달 유형(가게배달·배민1·알뜰 등)** 을 고르는 맛이 있음 |

아이콘·브랜드 캐릭터(광고요정 등)로 인지도가 높다.

---

## 2. 주문 고객

### 2.1 시작

1. 앱 설치 → 전화·SNS 등 로그인  
2. **배달 주소** 설정 (현위치·즐겨찾기)  
3. 카테고리·검색·랭킹·쿠폰함  
4. 메뉴·옵션·요청 → 결제  

지도 핀이 건물과 다르면 라이더가 헤맨다. **상세 주소·공동현관**을 정확히.

### 2.2 배달 유형 (이름·구성은 바뀔 수 있음)

| 유형 감각 | 설명 |
|-----------|------|
| 가게 배달 | 가게 소속·제휴 라이더가 오는 전통적 형태에 가까움 |
| **배민1** | 플랫폼이 배달을 중개하는 형태. 한 집만 가는 상품으로 자주 설명됨 |
| **알뜰배달** 등 | 묶음·할인과 맞바꾼 **시간·경로** 트레이드오프가 있는 상품 |
| 포장 | 직접 방문. 배달비 없음(대기·이동은 본인) |

같은 가게라도 **상품 탭마다 배달비·예상 시간이 다름**. 주문 전 탭을 확인한다.

### 2.3 쿠폰·멤버십·포인트

- 가게 쿠폰, 배민 쿠폰함, 첫 주문·기간 프로모션  
- **배민클럽** 등 구독형: 배달비 할인·쿠폰이 묶임 → **한 달에 몇 번 시는지** 계산  
- 포인트·배민페이 등은 결제란에서 잔액·유효기간 확인  

쿠팡 와우와 동시에 쓰는 집은 “이번 주문은 어느 앱이 싼지”만 보면 된다 → [[쿠팡이츠]].

### 2.4 배민 생태계 (주문 앱 안·연관)

| 이름 감각 | 용도 |
|-----------|------|
| 음식 배달 | 핵심 |
| 포장 | 방문 포장 |
| B마트·배민스토어 등 | 식료품·생활용품 (지역·서비스명 변동) |
| 배민오더 등 | 매장 내 태블릿 주문 — 배달과 별개 축 |

지역에 없으면 메뉴에 안 보인다.

### 2.5 고객센터·분쟁

주문 내역 → 문의·채팅·전화(앱 안내).  
누락은 **사진**, 결제는 **주문번호·결제 시각**.  
리뷰는 선택. 악의적 비방은 분쟁·이용 제한 이슈가 될 수 있다.

## 3. 라이더·배달 파트너 (요약)

상세 공통: [[배달하기]].

| 항목 | 배민 쪽 감각 |
|------|----------------|
| 앱 | **배민커넥트** 등 파트너용 앱(명칭 확인) |
| 등록 | 신분증·면허(오토)·계좌·교육·지역 |
| 배차 | 배민1·알뜰 등 **상품별 물량·단가**가 다름 |
| 정산 | 건당·인센티브·주정산 등 — 앱 내 내역이 기준 |
| 보험 | 유상운송·플랫폼 보험 안내를 **약관·공지**로 확인 |

피크(점심·저녁·비·콜)에 물량이 몰린다.  
단가만 보고 과속하지 말 것 → [[배달하기]] 안전.

| 상황 | 감각 |
|------|------|
