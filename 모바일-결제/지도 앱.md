# 지도 앱

> **분류:** 모바일·결제 · [[생활위키 목차]]

스마트폰 **지도·길찾기·장소 검색** 앱을 정리한다. 
국내에서는 [[네이버 지도]]·[[카카오맵]]·[[티맵]]이 자주 쓰이고, 해외·다국어·오프라인은 [[구글 지도]]가 유리한 경우가 많다.

확인일: 2026-08-13

관련: [[네이버 지도]] · [[카카오맵]] · [[구글 지도]] · [[티맵]] · [[갤럭시 워치 사용법]] · [[케이패스]]

---

## 1. 개요

| 앱 | 한 줄 |
|----|--------|
| [[네이버 지도]] | 국내 **장소·리뷰·예약** 정보가 풍부. 네이버 검색·플레이스와 연동 |
| [[카카오맵]] | **대중교통**·실시간 도착·승하차 알림. 음식점 **평점**은 네이버보다 낫다는 **이용자 평**도 있음 |
| [[티맵]] | **자동차 내비**·교통 정보에 특화. **인앱 HUD는 2024년 종료** — CarPlay 등으로 대체 |
| [[구글 지도]] | **해외**·Street View·오프라인. 국내는 **지도 반출 규제**로 서비스 **제한적** — 일상은 국내 앱 병행 |
| 애플 지도 | iPhone·iPad 기본. 국내는 **지도 반출** 등으로 해외 지도와 같이 **제한적** — 위 앱과 병행하는 경우 많음 |

```text
목적 정하기 (운전 / 대중교통 / 맛집·가게 / 해외)
 ↓
앱 1~2개 설치 · 위치 권한 (필요 시 「앱 사용 중」)
 ↓
집·회사 등록 · 즐겨찾기
 ↓
길찾기 모드 선택 (자동차·대중교통·도보·자전거)
```

## 2. 용도별로 고르기

| 상황                | 먼저 볼 앱                         | 이유                                                                                            |
| ----------------- | ------------------------------ | --------------------------------------------------------------------------------------------- |
| **버스·지하철** 출퇴근    | [[카카오맵]]                       | 실시간 도착·환승·승하차 알림. 워치 연동은 [[갤럭시 워치 사용법]] §8.1                                                  |
| **운전**·고속도로       | [[티맵]] · [[카카오맵]] · [[네이버 지도]] | 교통·사고·유료 구간 안내. 차량에 **미러링**할 때는 앱·차종 확인                                                       |
| **맛집·병원·가게** 찾기   | [[네이버 지도]] · [[카카오맵]]          | 영업시간·전화·예약은 네이버가 풍부한 편. **음식점 평점**은 카카오맵이 네이버보다 정확하다는 **평**도 있다 — **같은 가게를 두 앱에서** 비교하는 편이 안전 |
| **만원 이하 한 끼**       | [[거지맵]]                          | 제보 가격 지도. 길·영업은 위 앱과 **병행**. 숫자는 매장에서 재확인 |
| **배달·픽업 주소**      | 위 앱 + [[배달 앱]]                 | **핀 위치·층·동**이 틀리면 배달이 헤맨다                                                                     |
| **해외 여행**         | [[구글 지도]]                      | 오프라인 영역 저장·대중교통(도시별)·다국어                                                                      |
| **제로페이·지역화폐 가맹점** | 지도 앱 검색 + 각 결제 앱               | 「제로페이」「온누리」 등 키워드 — [[제로페이]] · [[온누리 상품권]]                                                    |

“한 앱이 항상 낫다”기보다 **목적마다 기본 앱을 정해 두고**, 장소 정보는 **교차 확인**하는 편이 실용적이다.

## 3. 요약 비교

|             | 네이버 지도         | 카카오맵                       | 티맵                    | 구글 지도               |
| ----------- | -------------- | -------------------------- | --------------------- | ------------------- |
| **강점**      | 플레이스·리뷰·부동산·예약 | 대중교통·승하차, 음식 **평점**(이용자 평) | 자동차 내비                | 해외·오프라인·Street View |
| **약점(상대적)** | 해외·오프라인        | 장소 메타는 네이버와 격차 있을 수 있음     | 도보·대중교통은 보조           | 국내 **지도 반출** 규제로 기능·POI 제한     |
| **계정**      | 네이버 ID         | 카카오 계정                     | 티맵 ID (선택)            | Google 계정           |
| **유료**      | 대부분 무료         | 대부분 무료                     | 내비·주차 등 부가 유료 있을 수 있음 | 무료 (API·기업용 별도)     |

세부: 각 앱 글 참고.

## 5. 위치 권한·배터리

| 권한 | 쓰임 |
|------|------|
| **앱 사용 중** | 검색·길찾기 때만 GPS — 일반 이용에 충분한 경우 많음 |
| **항상 허용** | 백그라운드 내비·지오펜스 루틴([[갤럭시 루틴]]) — 배터리 소모↑ |
| **정확 위치** | 층·골목 안내에 유리. 끄면 대략 위치만 |

설정 → 앱 → 위치에서 **항상**을 쓰지 않아도 되면 **사용 중**으로 두는 편이 배터리에 유리하다. 
[[갤럭시 폰 사용법]] 배터리·백그라운드 제한과 함께 본다.

## 6. 실전 팁

- **주소 vs 핀**: 아파트는 **동·호**·배달 메모까지. 지도 핀만 믿지 말 것 ([[배달의 민족]]).
- **두 앱 교차**: 영업 종료·임시 휴무는 **전화** 또는 가게 SNS가 최종.
- **대중교통 환급**: [[케이패스]]는 **교통카드 결제** 사업이지 지도 앱이 아니다. 경로 확인은 지도, 환급은 K-패스 등록.
- **운전 중 조작**: 터치 최소화·음성 안내·대시보드 **미러링** 우선. 법규·안전이 우선.

## 면책

> **면책**
> 경로·도착 시간·영업 정보는 **실시간 데이터**에 의존하며 틀릴 수 있다. 운전·도보 시 **교통법규·안전**을 스스로 확인한다.
> 유료 주차·택시·대리 요금은 앱·시점마다 다르다. 이 글은 특정 앱 가입·이용을 권유하지 않는다.
