# 롯데잇츠

> **분류:** 모바일·결제 · [[생활위키 목차]]

**롯데잇츠**(LOTTE EATZ)는 롯데GRS가 운영하는 **자사 외식 브랜드 통합 주문 앱**이다. 
[[배달의 민족]]·[[쿠팡이츠]]처럼 동네 가게를 모아 둔 **중개 플랫폼이 아니다**. 롯데리아·엔제리너스 등 **롯데 계열 메뉴만** 주문한다.

비교: [[배달 앱]] · [[생일 혜택]] · [[최저가와 쿠폰]]

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 무엇을 | 롯데GRS 브랜드 **배달·픽업·매장 주문** |
| 운영 | 롯데GRS(롯데리아·엔제리너스 등 외식 사업) |
| 앱·웹 | **롯데잇츠** 앱, [lotteeatz.com](https://www.lotteeatz.com/) 모바일 웹 |
| [[배달 앱]]과 차이 | 가게 탐색용 **오픈 마켓이 아님**. 메뉴·혜택이 **자사 브랜드**에 묶임 |

### 1.1 주문 가능 브랜드 (예시)

지역·매장에 따라 다르다. 앱·웹 **브랜드 선택** 화면이 기준이다.

| 브랜드 | 비고 |
|--------|------|
| **롯데리아** | 버거·사이드. [[생일 혜택]] 멤버십·쿠폰과 연동 |
| **엔제리너스** | 커피·베이커리 |
| **크리스피 크림 도넛** | 도넛·음료 |
| **플레:이팅** | 플레이팅·도시락 등 |
| 기타 | 마루가메 우동·스탠브루·쇼콜라 등 **지역별** 노출 |

같은 메뉴도 **배민·쿠팡이츠**에 올라와 있을 수 있다. 쿠폰·적립은 **어느 앱으로 결제했는지**에 따라 갈린다.

## 2. 주문 방식

### 2.1 공통 흐름

```text
앱 설치·회원 가입 → 브랜드 선택 → 주소·매장 확인
 → 메뉴·옵션 → 쿠폰·마일·결제 → 추적·수령
```

주소 핀·연락처는 [[배달 앱]]과 같이 **정확히** 넣는다.

### 2.2 배달

- 지정 주소로 **브랜드 메뉴** 배달 
- 배달비·최소 주문·가능 시간은 **브랜드·매장·지역**마다 다름 
- 프로모션(마일 적립 등)은 **앱 주문**에만 붙는 경우가 많음 

롯데리아만 시키려면 배민 대신 **롯데잇츠**를 쓰는 이유가 쿠폰·등급·마일 **적립**인 경우가 많다.

### 2.3 매장 픽업

- 주문 후 매장에서 **대기 줄 없이** 수령 
- 픽업 시간·매장 혼잡도는 앱 안내 확인 

### 2.4 드라이빙 픽업

- 차에 탄 채 **지정 픽업 위치**에서 수령 
- 매장·브랜드마다 지원 여부가 다름 

### 2.5 테이블 오더

- 일부 매장에서 **테이블 QR·앱**으로 매장 내 주문 
- 배달·픽업과 **주문 채널**만 다르고, 적립·결제는 같은 계정으로 묶이는 경우가 많음

## 3. 혜택·결제

### 3.1 마일·칩

| 이름 | 설명 |
|------|------|
| **EATZ마일**(잇츠마일) | 결제 금액 등에 따라 적립. 브랜드 **쿠폰 교환** 등에 씀 |
| **잇츠 CHIP** / **브랜드 CHIP** | 스탬프형 적립. 브랜드·이벤트에 따라 이름·규칙이 다름 |

적립·소멸·교환 조건은 **앱 멤버십 안내**가 우선이다.

### 3.2 등급·쿠폰

- 브랜드별 **누적 구매**로 Regular·Gold·VIP 등 **등급** (기준·이름은 개편될 수 있음) 
- 등급별 **할인·무료 쿠폰** — [[생일 혜택]]의 롯데리아 생일 쿠폰은 **골드 이상** 등 조건이 붙는 경우가 많음 
- **구독 쿠폰**: 할인 쿠폰을 정기 구매하는 상품(약관·환불 확인) 

### 3.3 결제 수단

| 항목 | 설명 |
|------|------|
| **EATZ페이** | 앱 내 간편 결제 |
| **EATZ카드** | 충전·선물·통합 관리 |
| **원바코드** | 오프라인 매장에서 결제·적립 연동 |
| **L.Point** | 롯데 포인트 연동 구간 있음 — 결제 화면 문구 확인 |
| 카드·간편결제 | 앱에 노출되는 수단 사용 |

예전에는 **매장 전용**이던 금액권·외부 쿠폰을 **배달 주문**에도 쓸 수 있게 확대된 적이 있다. 쿠폰마다 **사용 채널(매장·배달·픽업)** 이 다르다.

## 4. [[배달의 민족]]·[[쿠팡이츠]]와 고를 때

| 상황 | 설명 |
|------|------|
| 롯데리아·엔제리너스만 | 롯데잇츠 — **등급·마일·생일 쿠폰** 확인 |
| 여러 가게 비교·탐색 | 배민·이츠 — [[배달 앱]] |
| 같은 롯데리아 메뉴 | **총액(음식+배달비−쿠폰)** 과 **적립**을 같이 비교 |
| 멤버십 유지 | 한 달에 몇 번 쓰는지로 **등급·구독 쿠폰** 이득 계산 → [[최저가와 쿠폰]] |

롯데GRS 쪽 공개 설명에서는 배민·이츠와 **직접 경쟁**보다 **자사 고객·가맹 매출** 강화에 가깝다고 밝힌 보도가 있다. 이용자 입장에서는 **할인이 큰 쪽**만 고르면 된다.
