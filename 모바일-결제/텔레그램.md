# 텔레그램

> **분류:** 모바일·결제 · [[생활위키 목차]]

**텔레그램(Telegram)** 은 클라우드 기반 **메신저**다.  
개인 채팅·그룹·채널·봇([[텔레그램 봇]])을 한 앱에서 쓰고, 폰·데스크톱·웹이 같은 계정으로 동기화된다.

공식: [https://telegram.org](https://telegram.org)  
앱: 스토어의 **공식 Telegram** / 데스크톱은 공식 사이트

확인일: 2026-08-07

관련: [[텔레그램 봇]] · [[갤럭시 폰 사용법]] · [[크롬]]

---

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 가입 | 휴대폰 번호 (국가번호) |
| 동기화 | 여러 기기 동시 로그인 → 대화가 클라우드에 쌓이는 구조 |
| 대화 종류 | 1:1, 그룹, **채널**(방송형), 봇 |
| 강점 감각 | 대용량 파일, 채널·봇 생태계, 멀티 디바이스 |
| 주의 | “완전 익명·절대 안전”은 과장. 설정·상대·봇에 따라 다름 |

```text
전화번호 인증
    ↓
개인 채팅 · 그룹 · 채널 · 봇
    ↓
폰 / 데스크톱 / 웹 (같은 계정)
```

국내에서는 카카오톡과 **역할이 겹치되**, 해외·개발·채널·봇 용도로 같이 쓰는 집이 많다.

---

## 2. 설치 · 가입 · 기기

| 단계 | 감각 |
|------|------|
| 설치 | Play/App Store **공식** Telegram. 사칭 앱 주의 |
| 가입 | 번호 → SMS/통화 코드. 사용자 이름(@id)은 설정에서 |
| 프로필 | 이름·사진·자기소개. @username이 있으면 번호 몰라도 검색·추가 가능 |
| 데스크톱 | Windows/macOS/Linux 공식 클라이언트. QR 또는 코드로 연동 |
| 웹 | 브라우저 버전. [[크롬]] 등에서 사용 가능하나 **공식 도메인**만 |

갤럭시: [[갤럭시 폰 사용법]] — 알림·배터리 최적화에 앱이 죽지 않게 조절.

---

## 3. 채팅 · 그룹 · 채널

| 종류 | 감각 |
|------|------|
| 1:1 | 일반 클라우드 채팅. 여러 기기에서 이어서 봄 |
| 비밀 채팅(Secret chat) | 기기 간 **종단 암호화** 쪽이 강조됨. 클라우드 동기·일반 채팅과 **다름**. 데스크톱 등 제약이 있을 수 있음 |
| 그룹 | 여러 명 대화. 권한·느린 모드·토픽(포럼형) 등은 설정·플랜에 따라 |
| 채널 | **공지·구독**형. 댓글은 연결 그룹으로 두는 경우가 많음 |
| 폴더 | 개인/업무/채널을 폴더로 나누기 |

파일·사진·음성·영상 메시지, 링크 미리보기, 저장한 메시지(Saved Messages)를 자주 쓴다.

---

## 4. 알림 · 프라이버시 · 보안

| 설정 쪽 | 보면 좋은 것 |
|---------|----------------|
| 알림 및 소리 | 채팅/그룹/채널별 뮤트, 예외 |
| 프라이버시 | 전화번호·마지막 접속·프로필 사진·통화 **누구에게 보일지** |
| 2단계 인증 | 비밀번호(클라우드 비밀번호) — 번호 탈취 대비로 **켜 두는 편을 권장하는 안내가 많음** |
| 활성 세션 | 모르는 기기 로그인 끊기 |
| 차단·신고 | 스팸·사칭 |

| 주의 | 왜 |
|------|-----|
| 모르는 링크·apk·지갑 연결 | 피싱·악성코드 |
| “고객센터·거래소 직원” DM | 사칭. 공식은 보통 먼저 DM으로 시드를 묻지 않음 |
| 초대 링크 무분별 클릭 | 스팸 그룹·유해 채널 |
| Public @username | 검색·언급에 노출 |

텔레그램도 **계정·세션·봇 토큰**이 새면 피해가 크다. 백업·내보내기는 공식 기능을 본다.

---

## 5. 검색 · 저장 · 유용한 습관

| 습관 | 감각 |
|------|------|
| 전역 검색 | 사람·채널·메시지(설정·인덱싱에 따라) |
| Saved Messages | 나에게 보내는 메모·임시 보관 |
| 고정(Pin) | 중요 채팅을 목록 위 |
| 보관함(Archive) | 목록만 정리, 알림은 유지 가능 |
| 번역 | 앱·클라이언트에 번역 기능이 있는 버전 |

채널은 **구독만으로도** 피드가 쌓이므로, 폴더·뮤트로 알림을 가른다.

---

## 6. 봇은 뭔가

대화 상대처럼 보이는 **자동 계정**이다.  
만들기·토큰·명령은 [[텔레그램 봇]].

| 사용자로서 | 감각 |
|------------|------|
| 시작 | 봇 검색 또는 링크 → **Start** / `/start` |
| 명령 | `/` 메뉴 또는 버튼 |
| 주의 | 권한·개인정보를 과도히 요구하는 봇, 투자·도박 유도 |

## 9. 정리

텔레그램은 **멀티 기기 메신저 + 채널·봇**이 특징이다.  
편하게 쓰되 사칭·스팸을 경계하고, 자동화는 [[텔레그램 봇]]을 본다.
