# 쿠팡이츠

> **분류:** 모바일·결제 · [[생활위키 목차]]

**쿠팡이츠** 음식 배달 서비스 이용(주문)과 라이더 쪽 내용을 정리한다. 
비교: [[배달 앱]] · [[배달의 민족]] · 일하기: [[배달하기]]

확인일: 2026-08-07

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 무엇을 | 음식 배달(지역·가게 제휴 범위 내) |
| 인상 | **한 집 배달**(한 주문만 들고 가는 모델)로 많이 알려짐 |
| 쿠팡과의 관계 | 쿠팡 계정·**와우 멤버십** 할인·쿠폰이 묶여 보이는 경우가 많음 |
| 앱 | 쿠팡이츠 전용 앱 및/또는 쿠팡 앱 내 진입 — **시점·개편에 따라 다름** |

로켓배송(물류)과 **음식 라이더 배달은 다른 축**이다. 혼동하지 말 것.

---

## 2. 주문 고객

### 2.1 시작

1. 쿠팡이츠(또는 쿠팡 내 이츠) 로그인 — 쿠팡 계정과 통합인 경우 많음 
2. 주소·휴대폰 인증 
3. 가게·메뉴·옵션 → 배달비·할인·예상 시간 → 결제 

주소 단위·건물명이 쿠팡 로켓과 달라도, **음식 배달용 핀**을 다시 확인한다.

### 2.2 한 집 배달

마케팅·설명에서 강조되는 점:

- 라이더가 **다른 집 주문을 섞지 않고** 우리 집만 가는 형태 
- 묶음 배송 대비 **식는 시간·경로**에서 유리하다는 주장 

대신 배달비·최소주문·프로모션 구조가 배달의 민족(배민) 알뜰형과 **다를 수** 있다. 
항상 더 빠른·더 싼 것은 아니므로 **같은 메뉴를 배달의 민족과 비교**.

### 2.3 쿠폰·와우·결제

| 항목 | 설명 |
|------|------|
| 이츠 쿠폰 | 앱 쿠폰함·가게 할인 |
| **와우** | 멤버십 가입 시 배달비·할인 혜택이 붙는 구간이 있음 → **월 회비 vs 주문 횟수** |
| 쿠팡캐시·카드 | 결제 수단. 영수증·취소는 주문 상세 |
| 로켓와우와 관계 | 혜택이 통합·분리되는 시기가 있었음 → **결제 직전 문구** 확인 |

와우만 믿고 안 시켜도 되는 달에는 **구독 유지 비용**만 나갈 수 있다.

### 2.4 추적·요청·비대면

- 조리중·배차·배달중 상태 
- 라이더 연락·요청 사항(수저·문 앞) 
- 공동현관 비밀번호는 **보안 주의** (리뷰에 남기지 않기) 

분쟁: 주문 내 고객센터, 사진·주문번호. 
쿠팡 고객센터와 이츠 경로가 나뉘어 보일 수 있으니 주문 상세의 버튼을 따른다.

## 3. 라이더·배달 파트너 (요약)

상세 공통: [[배달하기]].

| 항목 | 쿠팡이츠 쪽 |
|------|------------------|
| 앱 | **쿠팡이츠 배달 파트너**용 앱(명칭·스토어 검색은 공식 안내) |
| 등록 | 서류·면허·지역·교육·계정 |
| 배차 | 한 집 배달 모델이라 **동선·단가 구조**가 묶음형과 다름 |
| 정산 | 건당·프로모션·우대 시간대 — 앱 정산 내역 |
| 피크 | 점심·저녁·날씨·이벤트 |

배민커넥트(배달의 민족 파트너 앱)와 **동시에** 켜 두면 콜이 겹칠 수 있다. 수락 전 도착 가능 여부를 본다.

## 5. 로켓·이츠 혼동 방지

| | 쿠팡 로켓 등 | 쿠팡이츠 |
|--|--------------|----------|
| 무엇 | 물류·택배·로켓설치 등 | **음식** 배달 |
| 배달 주체 | 쿠팡 물류·택배 체계 | 음식 라이더·파트너 |
| 앱 위치 | 쿠팡 쇼핑 | 이츠·쿠팡 내 음식 |

환불·문의 창구도 다르다.
