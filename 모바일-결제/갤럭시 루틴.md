# 갤럭시 루틴

> **분류:** 모바일·결제 · [[생활위키 목차]]

**갤럭시 루틴**은 삼성 **One UI**의 **모드 및 루틴**(Modes and Routines) 기능이다. 
**조건(IF)** 이 맞으면 **동작(THEN)** 을 자동 실행한다. 예전 이름은 **빅스비 루틴**(Bixby Routines)이다.

**갤럭시·One UI** 전용. 메뉴 이름은 **Android·One UI 버전**마다 다를 수 있다.

확인일: 2026-08-11

관련: [[갤럭시 폰 사용법]] · [[Sound Assistant 사용법]] · [[갤럭시 워치 사용법]] · [[카카오톡]]

참고: [삼성 고객센터 — 루틴 사용법](https://www.samsungsvc.co.kr/solution/41085)

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **상황·시간·장소**에 맞게 소리·화면·연결·앱을 **자동**으로 바꿈 |
| 구성 | **모드**(상황 프리셋) + **루틴**(사용자 IF-THEN) |
| 진입 | `설정` → **모드 및 루틴** · 앱 서랍 **모드 및 루틴** 앱 |
| OS | **One UI 5+** 에서 설정에 통합. 구형은 **빅스비 루틴** 앱 |

```text
[조건] 시간 / Wi-Fi / 위치 / 앱 / 블루투스 …
 ↓
[루틴 실행] 방해 금지 · 다크 모드 · 볼륨 · 앱 실행 …
 ↓
[종료] 반대 조건 · 시간 종료 · 수동 끄기
```

[[갤럭시 폰 사용법]] §3.1 요약본이고, 이 글은 **설정·예시·주의**를 붙인다.

---

## 2. 모드 vs 루틴

| | **모드** | **루틴** |
|--|----------|----------|
| 성격 | **수면·운전·업무** 등 **묶음** 프로필 | **내가 짠** 자동화 |
| 켜기 | **시간·수동**·루틴에서 모드 실행 | **조건** 충족 시 자동 |
| 동시 | 보통 **모드 하나** 중심 | **여러 루틴** 가능 (충돌 주의) |
| 예 | 취침 시간에 **수면 모드** | `집 Wi-Fi` → **와이파이 통화 ON** |

**모드**로 큰 틀을 잡고, **루틴**으로 세부(이어폰 볼륨·특정 앱)를 보완하는 식이 많다.

---

## 3. 어디서 여나

| 경로 | |
|------|--|
| **설정** | `설정` → **모드 및 루틴** |
| **앱** | 설정 → 모드 및 루틴 → **앱 화면에 표시** (버전별) |
| **퀵 패널** | 상단 내려 **모드** 타일 |
| **검색** | 설정 앱에서 `루틴` · `모드` 검색 |

**루틴** 탭 → **+** → 조건·동작 추가 → 이름·아이콘 저장.

---

## 4. 모드 (Modes)

삼성이 미리 만든 **상황 프로필**이다.

| 모드 예 | 흔한 설정 |
|---------|-----------|
| **수면** | 방해 금지·어두운 화면·그레이스케일·절전 |
| **운전** | 운전 중 메시지 자동 응답·방해 금지 (모델별) |
| **업무** | 알림 제한·벨소리 |
| **운동** | 음악·방해 금지 완화 등 |
| **영화관·휴식** | 무음·화면 최소 |

### 수면 모드 예

1. **모드** 탭 → **수면** → **시작**  
2. **취침·기상** 시간  
3. **방해 금지**·**다크 모드**·**편안하게 화면 보기** 등 선택  
4. 시간대에 **자동** 켜짐 — **Now bar**·잠금 화면에 표시되는 경우 많음  

[[불면증]] 대처는 **의료** 영역이지만, **밤 알림 차단** 용도로 수면 모드·루틴을 쓰는 사람은 많다.

---

## 5. 루틴 만들기

### 5.1 흐름

| 단계 | 내용 |
|------|------|
| 1 | **모드 및 루틴** → **루틴** → **+** |
| 2 | **조건 추가** — 언제 켤지 (하나 이상) |
| 3 | **동작 추가** — 무엇을 할지 |
| 4 | (선택) **종료 조건** — 언제 끌지 |
| 5 | 이름·아이콘 → **저장** |

조건은 **AND**(모두 만족)로 묶이는 경우가 많다. **OR**·복합은 UI에서 **조건 그룹**으로 설정 (버전별).

### 5.2 추천 루틴

삼성 **추천**(출근·퇴근·잠들기 전 등)을 가져와 **편집**만 해도 된다.

**맞춤형 서비스**(루틴 → **⋮** → 설정): 사용 패턴으로 **기상·취침·운전** 조건을 **제안** — 켜면 위치·사용 기록이 쓰일 수 있어 **개인정보·배터리**를 본다.

---

## 6. 조건 (If) 예시

| 조건 | 쓰임 |
|------|------|
| **시간** | 평일 09:00, 23:00 이후 |
| **위치** | 집·회사 **들어옴/나감** (GPS·지오펜스) |
| **Wi-Fi** | `우리집` SSID **연결/해제** |
| **블루투스** | **버즈·차량·워치** 연결 |
| **충전** | 충전 시작·종료 |
| **앱** | **[[지도 앱]]**·유튜브 실행 |
| **전화** | 통화 중 |
| **잠금 해제** | 화면 켤 때 |
| **모드** | **수면 모드** 켜짐 |
| **바로가기** | 홈 화면 **루틴 위젯** 탭 |

위치·Wi-Fi 루틴은 **배터리 최적화**에서 **모드 및 루틴** 제외를 검토한다 ([[갤럭시 폰 사용법]] §4).

---

## 7. 동작 (Then) 예시

| 동작 | 쓰임 |
|------|------|
| **방해 금지** | 알림·전화 제한 |
| **사운드 모드** | 무음·진동·벨소리 |
| **미디어 볼륨** | 이어폰 연결 시 30% 등 — [[Sound Assistant 사용법]]와 병행 |
| **다크 모드** | 밤·영화관 |
| **Wi-Fi / 모바일 데이터** | 집에서 Wi-Fi ON |
| **와이파이 통화** | 집 Wi-Fi에서 통화 품질 |
| **블루투스** | 차량 연결 시 BT ON |
| **앱 실행·종료** | 출근 시 **[[카카오맵]]** 등 |
| **절전·성능** | 게임 전 성능 모드 |
| **Always On Display** | 끄기/켜기 |
| **모드 실행** | 조건 맞으면 **수면 모드** 시작 |
| **알림** | 루틴 시작 알림 (디버그용) |

고급: **터치 매크로**·**SmartThings** 기기 제어 (지원 기기·버전 한정).

## 8. 자주 쓰는 루틴 예

| 이름 (예) | 조건 | 동작 |
|-----------|------|------|
| **집 Wi-Fi** | 집 Wi-Fi 연결 | 와이파이 통화 ON · [[삼성페이]] NFC는 그대로 |
| **회사** | 회사 Wi-Fi | 벨소리 · 업무 모드 |
| **잠자리** | 23:00~07:00 또는 수면 모드 | 방해 금지 · 다크 모드 |
| **이어폰** | BT 이어폰 연결 | 미디어 볼륨 20~40% |
| **운전** | 차량 BT | 운전 모드 · 무선 Android Auto (지원 시) |
| **유튜브** | [[유튜브]] 실행 | 회전 고정 · [[Sound Assistant 사용법]] 미디어 볼륨 |
| **충전 밤** | 22시 이후 + 충전 중 | AOD 끄기 · 알림 최소 |

**5~10개** 안에서 시작한다. [[갤럭시 폰 사용법]]과 같다.

---

## 9. 실행 중인지 확인

갑자기 앱이 열리거나 소리가 바뀌면 **루틴** 때문일 수 있다.

| 방법 | |
|------|--|
| **루틴** 목록 | **실행 중** 표시 |
| **퀵 패널** | 활성 **모드** 아이콘 |
| **Now bar** | 수면 등 **모드** 진행 표시 (One UI 버전별) |
| **알림** | 루틴 시작 알림을 켜 두면 추적 쉬움 |

해당 루틴을 **끄기**·조건·동작 **수정**한다.

## 10. 워치·Good Lock

| 연동 | |
|------|--|
| [[갤럭시 워치 사용법]] | 폰 **모드·방해 금지**가 워치 알림에도 영향 |
| **Good Lock** | **Routine+** 등 모듈로 UI·조건 확장 (선택) |

워치만 따로 쓰는 **방해 금지**와 **폰 루틴**이 겹치지 않게 본다.

## 11. 주의·팁

| 주제 | 내용 |
|------|------|
| **충돌** | 비슷한 조건 루틴이 **여러 개**면 마지막 실행·우선순위가 헷갈림 |
| **위치** | GPS 오차로 **집 밖인데 집**으로 인식 — Wi-Fi 조건 **병행** |
| **배터리** | 위치·항상 감지 루틴은 소모 ↑ |
| **개인정보** | 맞춤형 서비스·위치 **약관** 확인 |
| **카카오톡** | 방해 금지 시 **중요 알림**만 허용 — [[카카오톡]] 채널별 설정 |
| **삭제** | 안 쓰는 루틴은 **끄기** — 디버깅이 쉬워짐 |

## 12. 흔한 오해

| 오해 | 현실 |
|------|------|
| 빅스비만 쓴다 | **모드 및 루틴**으로 통합됐고, **빅스비 음성**과는 별개 |
| 모드 = 루틴 | **모드**는 프로필, **루틴**은 자동화 규칙 |
| 안드로이드 공통 | **삼성 One UI** 기능 |
| Tasker와 동일 | 루틴이 **쉬운 편** — Tasker만큼 **깊지 않음** |

## 13. 실전 체크리스트

- [ ] `설정` → **모드 및 루틴** 위치 확인  
- [ ] **수면** 또는 **밤 방해 금지** 모드 1개  
- [ ] **집/회사 Wi-Fi** 또는 **이어폰** 루틴 1~2개  
- [ ] 이상 동작 시 **실행 중 루틴** 확인  
- [ ] 10개 넘게 쌓지 않기  

---

## 14. 정리

1. **갤럭시 루틴** = **모드 및 루틴** — 조건 맞으면 동작 자동 실행.  
2. **모드**는 수면·운전 등 **묶음**, **루틴**은 **IF-THEN** 세밀 설정.  
3. **Wi-Fi·시간·블루투스** 조합이 가장 안정적이다.  
4. [[Sound Assistant 사용법]]·[[삼성페이]]·[[카카오톡]]과 **겹치는 설정**을 한번씩 점검한다.
