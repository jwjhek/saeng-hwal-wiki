# 유튜브

> **분류:** 미디어 · [[생활위키 목차]]

유튜브(YouTube)는 동영상 **시청·검색·구독**과, 채널을 키우는 **업로드·스튜디오**가 한곳에 있는 플랫폼이다.  
웹(youtube.com)·앱(Android/iOS)·스마트 TV·갤럭시에서 같은 계정으로 이어진다.

공식: [https://www.youtube.com](https://www.youtube.com)  
스튜디오: [https://studio.youtube.com](https://studio.youtube.com)

확인일: 2026-08-06  
메뉴·정책·수익화 기준은 자주 바뀐다. 수익·광고는 **공식 헬프**를 기준으로 한다.

---

## 1. 계정과 화면

| 구분 | 내용 |
|------|------|
| Google 계정 | 로그인·시청 기록·구독·댓글·업로드의 열쇠 |
| 채널 | 업로드·커뮤니티의 “얼굴”. 계정 하나에 채널(브랜드 포함) 구조 |
| 홈 | 추천 피드 |
| 구독 | 구독한 채널의 최근 영상 |
| Shorts | 세로 짧은 영상 |
| 보관함 | 시청 기록, 재생목록, 나중에 볼 동영상 |

갤럭시 앱: [[갤럭시 폰과 워치 사용법]]  
PC 브라우저 단축키는 아래 §6.

비로그인으로도 볼 수 있지만, 추천·동기화·업로드는 로그인이 필요하다.

## 2. 시청 팁

### 기본

| 동작 | 방법 (앱·웹 공통 감각) |
|------|------------------------|
| 재생/일시정지 | 탭 또는 스페이스(웹) |
| 건너뛰기 | 좌우 더블탭(앱) / `J` `L` 또는 ← → (웹) |
| 배속 | 설정(톱니) → 재생 속도 |
| 자막 | 설정 → 자막. `C`(웹) |
| 화질 | 설정 → 화질 (데이터·Wi-Fi에 맞게) |
| 미니플레이어 | 웹에서 스크롤 내려도 작은 창으로 재생 |
| 나중에 보기 | ⋯ → 나중에 볼 동영상에 저장 |
| 재생목록에 저장 | ⋯ → 재생목록에 저장 |

### 추천·시간 아끼기

- 관심 없으면 **관심 없음** / 채널 추천 숨기기  
- 홈이 산만하면 **구독** 탭 위주로  
- **재생목록**으로 강의·음악·다큐를 묶기  
- 어린이·집중이 필요하면 **시청 시간 제한**(디지털 웰빙 / YouTube 설정)  

### YouTube Premium (유료)

광고 제거, 백그라운드 재생, 다운로드(오프라인) 등이 핵심이다.  
무료로도 대부분 시청 가능. 필요·가성비는 개인 판단.

## 3. 검색·발견

1. 검색창에 키워드 — 필터: 업로드 날짜, 길이, 시청 수, 자막 등  
2. 채널 탭에서 채널만 찾기  
3. 영상 끝 **관련 영상** / 카드 / 최종 화면(엔스크린)  
4. Shorts 피드 — 짧은 발견용. 긴 영상과 섞어 쓰기  

가짜 썸네일·낚시 제목은 댓글·채널 신뢰·출처를 한번 더 본다.  
뉴스·의학·투자는 영상만으로 결정하지 않는 편이 안전하다. (관련 감각: [[보험 기초]], [[코인 현물과 선물]] 등은 별도 문서)

## 4. 구독·알림·커뮤니티

| 행동 | 의미 |
|------|------|
| 구독 | 구독 피드·채널에 표시 |
| 종(알림) | 전체 / 맞춤 / 없음 — 알림 폭주 조절 |
| 멤버십 | 채널 유료 멤버 (배지·이모지·전용 영상 등, 채널마다 다름) |
| 커뮤니티 글 | 텍스트·투표·이미지 공지 (스튜디오에서 작성) |

알림이 안 오면: 앱 알림 권한, 배터리 최적화 제외, 종 설정, 방해 금지 모드를 확인한다 ([[갤럭시 폰과 워치 사용법]]).

## 5. 재생목록·보관

| 종류 | 용도 |
|------|------|
| 나중에 볼 동영상 | 임시 대기열 |
| 좋아요 표시한 동영상 | 하트 누른 목록 |
| 비공개 재생목록 | 나만의 커리큘럼·음악 |
| 공개·일부공개 | 공유 링크용 |

학습용으로 “강의 순서” 재생목록을 만들어 두면 [[NotebookLM 사용법]]에 넣기 전에 소재를 고르기 쉽다.

## 6. PC 단축키 (웹)

| 키 | 동작 |
|----|------|
| `Space` / `K` | 재생·일시정지 |
| `J` / `L` | 10초 뒤·앞 |
| `←` / `→` | 5초 뒤·앞 |
| `↑` / `↓` | 볼륨 |
| `F` | 전체 화면 |
| `M` | 음소거 |
| `C` | 자막 |
| `Shift` + `,` / `.` | 배속 느리게·빠르게 |
| `0`~`9` | 영상 위치 % |
| `/` | 검색창 |

브라우저 전체화면·PIP는 OS·브라우저 기능을 같이 쓴다 ([[윈도우 사용법]]).

## 7. 만드는 쪽 — YouTube Studio

주소를 올리는 사람 기준 최소 흐름:

```text
촬영·편집 → 업로드 → 제목·설명·태그·썸네일
        → 공개 설정(공개/일부공개/비공개)
        → 분석(조회·유지율) 보고 다음 영상
```

**기획·촬영·편집·내보내기**까지 자세한 실무는 [[유튜브 영상 제작]].

### 업로드 체크

- [ ] **제목** — 검색될 말 + 내용과 일치  
- [ ] **설명** — 요약, 챕터(타임스탬프), 링크  
- [ ] **썸네일** — 모바일에서도 읽히는 글자  
- [ ] **재생목록** 편성  
- [ ] **아동용 여부** 등 규정 질문 정확히  
- [ ] 음악·클립 **저작권** (유료 음원·TV 장면 주의)  
- [ ] 자막·챕터 (접근성·유지율에 도움)  

### Studio에서 자주 보는 것

| 메뉴 | 용도 |
|------|------|
| 대시보드 | 최근 성과 요약 |
| 콘텐츠 | 영상·Shorts·라이브 목록 |
| 분석 | 시청 유지율, 트래픽 소스, 시청자 |
| 수익 창출 | 조건 충족 시 광고·후원 등 (정책 확인) |
| 맞춤설정 | 채널 아트, 소개, 링크 |

Shorts는 세로·짧은 호흡. 롱폼과 **목표가 다름** (발견 vs 깊이).  
라이브는 채팅 관리·저작권 음원·안정적 업로드(비트레이트)를 미리 본다.

## 8. 수익화·정책 (감각만)

수익화(예: 구독자·시청 시간 조건, Shorts 조건 등)는 **시점에 따라 숫자가 바뀐다**.  
Studio·[YouTube 고객센터](https://support.google.com/youtube)의 현재 요건을 본다.

주의:

- 반복·도배·오해 유발 썸네일 → 추천 제한·제재 가능  
- 스팸 댓글·스캠 링크  
- 의료·금융·위험한 챌린지는 가이드라인·현지 법  
- 타 채널 영상 무단 재업로드  

이 문서는 **수익 보장·투자 권유가 아니다**.

## 9. 개인정보·안전

1. 시청 기록 끄기/일시정지 — 설정 → 시청 기록  
2. 검색 기록 삭제  
3. 댓글·닉네임에 전화번호·주소 금지  
4. 어린이는 **YouTube Kids**·감독 계정 검토  
5. 수상한 “구독하면 돈” DM·외부 링크 경계  
6. 2단계 인증은 Google 계정에서 유지
