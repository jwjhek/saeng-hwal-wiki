# 유튜브 영상 제작

> **분류:** 미디어 · [[생활위키 목차]]

유튜브에 **올리는 쪽** — 기획부터 촬영·편집·업로드까지 최소 흐름을 정리한다. 
시청·구독·Studio 메뉴 전반은 [[유튜브]].

스튜디오: [https://studio.youtube.com](https://studio.youtube.com)

확인일: 2026-08-07

관련: [[유튜브]] · [[위키 쇼츠 자동 제작]] · [[그림판 사용법]] · [[윈도우 사용법]] · [[갤럭시 폰 사용법]] · [[현존 AI 비교]]

---

## 1. 개요 — 전체 파이프라인

```text
주제·시청자 정하기
 ↓
구성(훅 → 본문 → 끝)·대본/키워드
 ↓
촬영 (또는 화면 녹화)
 ↓
편집·자막·소리
 ↓
내보내기 (해상도·용량)
 ↓
[[유튜브]] Studio 업로드
 ↓
제목·설명·썸네일·공개 설정
 ↓
분석 보고 다음 영상
```

처음이면 **완벽 장비보다 “끝까지 한 편 올리기”**가 우선이다.

| 형태 | 설명 |
|------|------|
| Shorts | 세로, 짧음, 발견·훅 중요 |
| 롱폼 | 가로(흔히 16:9), 검색·구독·유지율 |
| 라이브 | 송출·채팅. 별도 준비 |
| 화면 해설 | 게임·코딩·강의 — 마이크+화면 녹화 |

이 생활위키 성격이면 **도구 사용법·리뷰·튜토리얼**이 롱폼·Shorts 둘 다 만들기 쉽다. 
**이미 있는 위키 글 → Shorts 반자동** 은 [[위키 쇼츠 자동 제작]].

---

## 2. 기획 (찍기 전에)

| 질문 | 예 |
|------|-----|
| 누구용? | 초보 / 이미 아는 사람 |
| 한 줄 약속 | “3분 안에 ○○ 하는 법” |
| 검색될 말 | 제목·설명에 넣을 키워드 2~3개 |
| 길이 | Shorts ~60초대 vs 롱폼 8~15분 등 — **지루한 부분 자르기**가 더 중요 |
| 시리즈? | 같은 인트로·썸네일 틀이면 채널이 통일됨 |

대략 구성:

1. **훅** (0~15초) — 무엇을 得られる지 
2. **본문** — 단계·데모 
3. **마무리** — 요약, 다음 영상·재생목록 

대본은 一字一句가 아니어도 된다. **불릿 메모**만 있어도 말이 덜 샌다. 
초안은 [[현존 AI 비교]]·[[Cursor 사용법]]으로 짜고, 사실·정책은 직접 검증.

## 3. 촬영 · 녹화

### 폰만으로 (입문)

| 항목 | 설명 |
|------|------|
| 기기 | [[갤럭시 폰 사용법]] 카메라. 렌즈 닦기 |
| 고정 | 삼각대·책상 거치. 손떨림↓ |
| 빛 | 얼굴 향해 창·조명. 역광 피하기 |
| 소리 | 가능하면 핀마이크·이어폰 마이크. 조용한 방 |
| 구도 | 눈높이, 머리 위 여백. Shorts는 **세로** |
| 테이크 | 한 호흡씩 짧게 여러 번 → 편집에서 잇기 |

### 화면 녹화 (튜토리얼·코딩)

| 도구 | 용도 |
|-----------|------|
| Windows 게임 바 / Xbox Game Bar | 간단 화면 녹화 ([[윈도우 사용법]]) |
| OBS Studio | 화면+웹캠+장면 전환 (무료, 학습 곡선 있음) |
| 편집 앱 내 녹화 | CapCut 등 |

해상도는 최종 업로드에 맞게 **1080p**면 입문으로 충분하다. 
마우스를 크게, 클릭 전에 잠깐 멈추면 시청자가 따라오기 쉽다.

### 체크

- [ ] 배터리·저장 공간 
- [ ] 알림 무음 / 방해금지 
- [ ] 테스트 10초 찍고 **소리·초점** 확인 
- [ ] 민감 정보(비밀번호·주소·토큰) 화면에 안 나오게

## 4. 편집

| 할 일 | 설명 |
|------|------|
| 자르기 | 침묵·말 더듬·실패한 테이크 제거 |
| 순서 | 훅을 앞으로, 중복 설명 삭제 |
| 자막 | 자동 자막 보정. 모바일은 소리 없이 보는 사람 많음 |
| 확대·줌 | 화면 녹화에서 중요 UI만 확대 |
| BGM | **유튜브 오디오 라이브러리**·사용 허락된 음원. 인기곡 무단 금지 |
| 인트로 | 길면 이탈. 3~5초 안이 안전한 편 |
| 엔드스크린 | 구독·다음 영상·재생목록 (스튜디오에서도 가능) |

### 편집 도구 (고르기만)

| 도구 | 설명 |
|------|------|
| 폰 CapCut·기본 갤러리 편집 | Shorts·입문 |
| DaVinci Resolve | PC 무료·고기능 (배움 필요) |
| Premiere 등 | 유료·팀 표준인 경우 |
| 썸네일 | [[그림판 사용법]]·Canva 등 — 큰 글씨, 얼굴/결과물 클로즈업 |

“어떤 앱이 정답”보다 **익숙한 것 하나로 완성**이 낫다.

### 내보내기

| 항목 | 흔한 출발 |
|------|-----------|
| 해상도 | 1080p (1920×1080 또는 Shorts 1080×1920) |
| 프레임 | 30fps 또는 촬영과 동일 |
| 코덱 | H.264 + AAC 조합이 호환에 무난한 편 |
| 비트레이트 | 너무 낮으면 뭉개짐. 편집 앱 기본 ‘유튜브 1080p’ 프리셋 활용 |

파일명에 날짜·주제만 적어도 Studio에서 찾기 쉽다.

## 5. 업로드 (YouTube Studio)

1. [studio.youtube.com](https://studio.youtube.com) → **만들기** → 동영상 업로드 (또는 앱) 
2. 파일 선택 · 처리(프로세싱) 기다림 
3. 세부정보 입력 후 공개 설정 

| 필드 | 설명 |
|------|------|
| 제목 | 검색어 + 약속. 낚시만 하면 유지율·신뢰↓ |
| 설명 | 첫 줄이 중요. 타임스탬프(챕터), 관련 링크 |
| 썸네일 | 1280×720 권장. 모바일에서 글자가 읽히는지 |
| 재생목록 | 시리즈면 바로 편성 |
| 태그 | 보조. 제목·설명이 더 중요하다는 견해가 많음 |
| 아동용 | 규정에 맞게 **정확히** |
| 공개 | 공개 / 일부 공개(링크만) / 비공개 / **예약** |

Shorts: 세로·길이 조건은 **시점별 정책**을 스튜디오·헬프에서 확인. 
자세한 Studio 메뉴는 [[유튜브]] §7.

### 업로드 전 체크

- [ ] 저작권 음원·클립 
- [ ] 비밀번호·개인정보 노출 없음 
- [ ] 자막·챕터 
- [ ] 썸네일·제목이 내용과 일치 
- [ ] (선택) 일부 공개로 본인·친구만 먼저 시청

## 6. 올린 뒤

| 보기 | 왜 |
|------|-----|
| 시청 유지율 | 어디서 이탈하는지 → 다음 편집 |
| 트래픽 소스 | 검색·탐색·Shorts·외부 |
| 댓글 | 고정 댓글에 챕터·자료 링크 |
| 커뮤니티·카드 | 시리즈 안내 |

알고리즘 “꿀팁”보다 **클릭(썸네일·제목) × 끝까지 보기(내용)** 가 기본 틀이다. 
수익화 조건·정책은 [[유튜브]] §8 · 공식 헬프.

## 7. 최소 장비 단계

| 단계 | 구성 예 |
|------|---------|
| 0 | 폰 + 창가 빛 + 무료 편집 + Studio |
| 1 | 저가 핀마이크 + 삼각대 + 간단한 조명 |
| 2 | 마이크(USB)·OBS·PC 편집 |
| 3 | 카메라·오디오 인터페이스 등 — **채널이 버틸 때** |

돈을 먼저 쓰지 말고 **3편** 올려 본 뒤 병목을 산다 (소리? 구도? 편집 속도?).

## 9. 실전 체크 (첫 업로드)

- [ ] 한 줄 주제·훅을 적었다 
- [ ] 테스트 촬영으로 소리·화면을 봤다 
- [ ] 침묵·실패 테이크를 잘랐다 
- [ ] 자막·BGM 저작권을 봤다 
- [ ] Studio에 제목·설명·썸네일·공개 범위를 넣었다 
- [ ] 분석은 며칠 뒤 유지율만 이라도 본다 
- [ ] 시청·채널 설정은 [[유튜브]]

## 10. 정리

유튜브 영상 제작은 **기획 → 촬영/녹화 → 편집 → Studio 업로드 → 분석**이다. 
입문은 폰·화면 녹화·무료 편집으로 한 편을 끝내고, 장비는 나중에 올린다. 
플랫폼 조작·수익·정책은 [[유튜브]]와 공식 헬프를 본다.
