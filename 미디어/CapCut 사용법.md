# CapCut 사용법

> **분류:** 미디어 · [[생활위키 목차]]

**CapCut(캡컷)** 은 ByteDance 계열로 알려진 **동영상 편집 앱·PC 프로그램**이다. 
숏폼(Shorts·릴스·틱톡형) 제작에 많이 쓰이고, 생활위키 → 쇼츠 입문 조합에서는 **TTS·자막·세로 내보내기** 담당으로 둔다 → [[위키 쇼츠 자동 제작]].

공식: 스토어·PC는 검색 시 **CapCut** 표기. 지역·버전마다 메뉴 이름이 조금 다를 수 있다.

확인일: 2026-08-07

관련: [[위키 쇼츠 자동 제작]] · [[유튜브 영상 제작]] · [[유튜브]] · [[갤럭시 폰 사용법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 스마트폰·PC용 **영상 편집기** |
| 잘하는 것 | 자르기, 자막, 효과, **텍스트 읽어주기(TTS)**, 템플릿, 9:16 숏폼 |
| 누가 쓰나 | Shorts·릴스 입문자, “대본만 있으면 영상으로” 싶은 사람 |
| 이 위키에서 | [[위키 쇼츠 자동 제작]]의 **렌더 툴** (대본은 AI, 업로드는 Studio) |

Premiere·DaVinci처럼 “영화 장편”용이라기보다, **짧은 세로 영상**에 최적화된 쪽에 가깝다.

---

## 2. 왜 쇼츠 입문에 거론되나

| 이유 | 설명 |
|------|------|
| 한곳에 모음 | 음성(TTS) + 자막 + 비율(9:16) +보내기 |
| 학습 곡선 | 타임라인 UI가 비교적 직관적 |
| 폰·PC | [[갤럭시 폰 사용법]] 앱으로도, PC로도 가능 |
| 위키 워크플로 | 글을 읽어 주게 두고 자막만 맞추면 **촬영 없이** 1편 가능 |

“캡컷 = 유튜브 대체”가 아니다. **편집기**이고, 올리는 곳은 [[유튜브]] Studio다.

---

## 3. 위키 쇼츠에서 쓰는 기능만

| 기능 | 하는 일 |
|------|---------|
| 비율 9:16 | Shorts용 세로 |
| 텍스트 / 텍스트 음성(TTS) | 대본을 읽혀 줌 (메뉴명: TTS·텍스트 읽어주기 등으로 검색) |
| 자막·자동 캡션 | 화면에 글자 |
| 자르기·배속 | 침묵·길이 조절 |
| 내보내기 | mp4 저장 → Studio 업로드 |

그 외 화려한 템플릿·주식 영상은 **선택**. 처음엔 단색 배경 + 큰 글씨면 충분하다.

## 4. 설치 · 주의

| 항목 | 설명 |
|------|------|
| 설치 | Play Store / App Store / PC 설치 파일 — **공식**만 |
| 계정 | 일부 기능·동기화에 로그인 필요할 수 있음 |
| 무료·유료 | 효과·내보내기·워터마크 조건은 **버전·시점에 따라 다름** →보내기 전 미리보기 |
| 개인정보 | 클라우드 업로드·권한은 설정에서 확인 |
| 저작권 | 앱 음원·효과가 Shorts·수익화에 되는지는 **라이선스·YouTube** 기준 |

사칭 앱·크랙은 쓰지 않는다.

## 7. 정리

CapCut은 **숏폼용 영상 편집 앱**이다. 
생활위키 쇼츠에서는 AI 대본을 **읽어 주고 세로 mp4로 만드는 도구**로 쓰고, 공개는 YouTube Studio에서 한다.
