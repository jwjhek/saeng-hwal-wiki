# 무료 전자책 정보

> **분류:** 미디어 · [[생활위키 목차]]

합법적으로 **공짜·거의 공짜**로 책을 읽는 경로를 정리한다. 
이 위키 사용·정리 중: **위키독스**, **화성시 도서관**, **경기도(사이버)도서관**, **서울도서관**(및 서울 교육청 전자도서관). 
건물·특화관(만화 등) 방문은 [[무료 도서관]].

확인일: 2026-08-07

---

## 1. 종류

| 유형 | 예 | 특징 |
|------|-----|------|
| **공공 도서관** | 화성시립, **경기도**, **서울**, 타 지자체 | 세금으로 산 책·전자책. **회원** 필요 |
| **기술·위키형 공개책** | 위키독스 | 저자가 웹에 공개. IT·입문 강 |
| **공공·기관 공개 자료** | 국가·대학·연구 리포지터리 | 보고서·교재 PDF |
| **퍼블릭 도메인·오픈 라이선스** | Project Gutenberg, 위키책 등 | 저작권 만료·자유 라이선스 |
| **출판사·저자 샘플** | 미리보기, 일부 챕터 공개 | 맛보기 |
| **구독 번들** | (유료) 밀리·리디 등 | 이 글의 “무료” 밖. 도서관 전자책이 대안 |

가성비: **도서관 정회원(거주지·직장 가능한 곳) + 위키독스**면 IT·교양 상당 부분을 돈 안 내고 커버하는 집이 많다. 
경기도민이면 **시군 도서관 + 경기도사이버도서관**을 같이 쓰는 경우가 많고, 서울은 **서울도서관·교육청 도서관** 경로를 본다.

## 2. 위키독스

사이트: [https://wikidocs.net](https://wikidocs.net)

### 무엇인가

개인·저자가 **온라인 책**을 쓰고 공개하는 한국 플랫폼. 
프로그래밍·데이터·AI 입문서가 특히 많다. (예: 점프 투 파이썬 계열, NLP·딥러닝 입문 등)

### 쓰는 법

1. 베스트 / 추천책 / 공개책 / 검색 
2. 브라우저에서 챕터 단위로 읽기 (로그인 없이도 공개 범위는 열람 가능한 경우 많음) 
3. 일부 책은 **대부분 무료 + 심화만 유료 e-book** 
4. 전자책 메뉴의 유료분은 구매 전 목차·무료 비율 확인 

### 팁

- 출퇴근·틈새 학습용으로 북마크·브라우저 읽기 목록 ([[크롬 사용법]])
- 코드는 따라 치며 [[VS Code 사용법]]·[[Python 학습과 패키지]]와 병행 
- 내용을 [[NotebookLM 사용법]]에 넣어 요약할 때는 **저작권·이용약관** (개인 학습 vs 재배포) 지킨다 
- “전부 공짜”가 아닌 책이 있으니 유료 뱃지를 본다 

### 한계

- 출판 교재·소설·수험서 전 분야를 대체하진 않음 
- 품질·업데이트는 책마다 편차 
- 인용·상업 이용은 각 책 라이선스·안내에 따름

## 3. 화성시 도서관

화성특례시 **시립도서관** 네트워크(공공·작은도서관 다수). 
실물 대출 + **디지털자료**(전자책·오디오북·잡지·논문 등).

누리집: [https://www.hscitylib.or.kr](https://www.hscitylib.or.kr)

### 회원

- 누리집에서 가입 후 **정회원·온라인 회원증** 등 안내에 따라 인증 (경기도민·재직·학생 등 대상 범위는 공지 확인) 
- 전자책·구독형 서비스는 보통 **정회원** 기준 

공식 입구는 검색어 «화성시립도서관» 또는 시 도서관 포털. 
(주소·앱은 개편될 수 있음 → 시 홈·도서관 공지)

### 전자·디지털 

| 구분 | 내용 |
|------|------|
| **소장형 전자책** | 도서관이 산 권수·동시 대출 제한 → 인기는 **예약·대기** |
| **구독형 전자책** | 앱(예: **부커스** 등, 명칭·계약은 시기별) — 동시 제한이 느슨하고 **즉시 대출**에 가까운 체험 |
| **오디오북·전자잡지·학술** | 디지털자료 메뉴에 함께 있는 경우 많음 |
| **대출 권수** | 월 한도·이벤트(예: 방학철 구독형 권수 확대)는 공지 |

이용: 도서관 누리집 **디지털자료** 또는 안내된 앱에 **도서관 계정으로 로그인**.

### 실물

- 가까운 분관·본관에서 대출·반납·예약 
- 상호대차·타관 반납 가능 여부는 안내 확인 
- 행사·북큐레이션·열람실 

### 팁 (화성 이용자)

1. 인기 신간은 **구독형**으로 먼저, 소장형은 예약 
2. 앱·누리집 공지의 **권수·기간·반납**을 달력에 맞춤 
3. 타 지역 도서관 회원과 중복 가능 여부는 각 관 규정 
4. 전자책 DRM은 캡처·영구 소장이 안 되는 경우가 많음 — **기간 대출** 개념 
5. 논문·잡지가 필요하면 디지털자료·학술 DB 메뉴를 따로 본다 

### 한계

- 회원 자격(거주·재직 등)에서 벗어나면 이용 제한 
- 모든 베스트셀러·기술서가 전자로 있는 건 아님 
- 위키독스처럼 최신 프레임워크 튜토리얼은 도서관보다 **위키독스·공식 문서**가 빠를 때가 많음 
- 경기도민이면 §4 **경기도사이버도서관** 구독형과 **권수·대기**를 나눠 쓰는 편이 유리할 수 있음

## 4. 경기도 도서관 (사이버도서관·전자책)

경기도는 시군 도서관과 별도로, 도 단위 **경기도사이버도서관(경기도서관 전자책)** 전자책·오디오북 창구가 있다. 
화성 등 시군 회원과 **계정·자격이 다를 수** 있으니, 둘 다 해당되면 **각각 가입·인증**을 확인한다.

누리집: [https://www.library.kr](https://www.library.kr) 
전자책 안내: [https://ebook.library.kr](https://ebook.library.kr) (경로·도메인은 개편될 수 있음)

### 4.1 누구나

- 보통 **경기도민 본인 인증**을 마친 사이버도서관 회원 
- 상세 자격·인증 방법은 누리집·공지 (전입·학생·재직 등은 시점마다 확인)

### 4.2 전자책 종류 

| 구분 | 내용 |
|------|------|
| **소장형** | 도서관이 산 권수·동시 대출 제한 → 인기작은 **대기·예약** |
| **구독형** | 대기 없이 바로 읽는 체험에 가깝다. **월 대출 권수 한도**(예: 전자책·오디오 합산 안내는 연도·예산에 따라 변동 — 2025년 보도·안내에 월 6권대 예시가 있었음) |
| **국외 전자책** | 영문 등 별도 메뉴·권수 |
| **뷰어·앱** | PC 웹, **부커스** 등 모바일 앱에 기관명 «경기도사이버도서관» 선택 후 도서관 계정 로그인 |

권수·기간·운영 기간(예산)은 **매년·수시 공지**가 우선이다. “올해 몇 권”은 이 위키 숫자보다 **누리집 이용안내**를 본다.

### 4.3 쓰는 법 (요약)

1. library.kr(또는 안내된 주소)에서 **회원 가입·본인 인증** 
2. 전자책/구독형·소장형 메뉴에서 검색 → 대출·바로읽기 
3. 모바일: 스토어에서 뷰어 앱(부커스 등) → 기관 **경기도사이버도서관** → 동일 계정 
4. PC: 누리집 로그인 후 내서재·뷰어 

### 4.4 시군(예: 화성)과 같이 쓸 때

| | 시군 도서관 (예: §3 화성) | 경기도사이버도서관 |
|--|---------------------------|---------------------|
| 실물 대출 | 분관·본관 | 전자·온라인 중심 |
| 전자 | 시가 계약한 디지털자료 | 도 단위 전자책·구독형 |
| 계정 | 시 도서관 회원 | 도 사이버도서관 회원 |

둘 다 되면 **인기 신간은 구독형(도)·시 구독형**을 먼저, 없으면 소장형 예약을 나눠 건다.

### 4.5 한계

- 경기도민 인증 밖이면 이용 어려움 
- 구독형 종수·월 한도는 예산·정책에 따라 줄거나 바뀔 수 있음 
- 시군 상호대차·실물과 전자 규정이 다름

## 5. 서울 도서관 (서울도서관·교육청)

서울은 창구가 **둘 이상**으로 나뉘어 보이는 경우가 많다. 
자격(거주·직장·학교)에 맞는 쪽을 고른다.

### 5.1 서울도서관 (시립·Library of Seoul)

서울시 **서울도서관** 정회원이 쓰는 전자책·오디오북 창구.

- 도서관 포털: [https://lib.seoul.go.kr](https://lib.seoul.go.kr) 
- 전자책 누리집: [https://elib.seoul.go.kr](https://elib.seoul.go.kr) 
- 국외(영문) 전자책: OverDrive 등 별도 주소가 안내되는 경우 (예: seoullib.overdrive.com 계열 — 공지 확인)

**회원:** 서울시 거주·서울 소재 직장/학교 등 **정회원** 요건은 누리집 가입 안내. 
전자책 이용 전 **서울도서관(또는 안내된) 정회원**이 되어 있어야 하는 흐름이 일반적이다.

**이용:**

1. 정회원 등록(방문·비대면 인증 등 — 자격별 서류는 공지) 
2. elib 등 전자책 사이트/앱에 **회원 연동 로그인**(PC·모바일·공식 앱 중 최초 1회 연동이 필요하다는 안내가 있음) 
3. 국내 **소장형·구독형**, 오디오북, 국외 전자책 메뉴에서 대출 
4. 내서재에서 읽기·듣기 

대출 권수·기간·예약(예: 통합 몇 권·며칠)은 **이용안내 페이지**가 우선. 숫자가 자주 바뀐다.

### 5.2 서울특별시교육청 전자도서관

서울시교육청 소속 **도서관·평생학습관** 대출회원(정회원)용 전자도서관이 따로 있다.

- 주소: [https://e-lib.sen.go.kr](https://e-lib.sen.go.kr) 
- 가입: 통합도서관 준회원 → **정회원(대출회원)** 등록(방문 또는 서울시민 비대면 인증 등) 
- 타 시·도 거주 + 서울 직장/학교만 해당하면 **방문 등록**이 필요한 경우가 있음 

서울도서관(시)과 **회원·앱·책이 완전히 같지는 않을 수** 있다. 
자격이 되면 둘 다 열어 두고, 없는 책은 다른 쪽에서 찾는 식.

### 5.3 서울 이용 팁

1. 먼저 **내가 정회원이 될 수 있는 관**이 시립인지 교육청인지 확인 
2. 전자는 **구독형(대기 적음) → 소장형(예약)** 순으로 시도하는 집이 많음 
3. 국외 전자책은 OverDrive 등 **별도 로그인·앱**일 수 있음 
4. 경기도·타 지역 도서관 회원과 병행 가능 여부는 각 관 약관 
5. [[크롬 사용법]]·모바일 앱 로그인 연동 안 되면 고객센터·공지의 “최초 1회 연동”을 본다

### 5.4 한계

- 비거주·비재직은 가입 자체가 막히는 경우가 많음 
- 교육청관·시립관 전자 목록이 다름 
- 인기작은 대기 — 구독형 한도·예산을 공지에서 확인

## 7. 역할 나누기 

```text
최신 코딩·입문 튜토리얼 ──→ 위키독스 · 공식 문서
소설·교양·베스트·오디오 ──→ 거주지 도서관 전자(구독형·소장형)
 경기 → §4 사이버도서관 + 시군(§3)
 서울 → §5 서울도서관 · 교육청
논문·리포트 근거 ──→ 도서관 학술 · NotebookLM으로 정리
영문 고전 ──→ Gutenberg · (회원 시) 국외 전자책
```

위키독스에서 본 내용을 도서관 종이책·전자책으로 **심화 대출**하는 식의 조합도 좋다.

- [ ] 정회원·온라인 회원증 
- [ ] 디지털자료 / 부커스(또는 현행 앱) 로그인 
- [ ] 구독형·소장형 차이 이해 
- [ ] 가까운 분관·반납 일정 

### 경기도사이버도서관

- [ ] 본인 인증·회원 가입 
- [ ] 구독형·소장형·국외 메뉴 확인 
- [ ] 월 대출 한도·공지 (예산·연도) 
- [ ] 모바일 앱 기관명 «경기도사이버도서관» 

### 서울 (시립·교육청)

- [ ] 정회원 자격(거주·직장·학교) 확인 
- [ ] 서울도서관 elib 및/또는 교육청 e-lib 로그인 연동 
- [ ] 구독형·소장형·국외(OverDrive 등) 
- [ ] 대출 권수·기간 이용안내 확인 

### 공통

- [ ] 읽은 책·메모를 Obsidian에 한 줄 ([[Obsidian 사용법]]) 
- [ ] 필요 시 NotebookLM에 **본인이 합법적으로 보유·대출한** 자료만
