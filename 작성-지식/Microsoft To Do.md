# Microsoft To Do

> **분류:** 작성·지식 › 노트·지식 · [[생활위키 목차]]

**Microsoft To Do**(마이크로소프트 투 두)는 **할 일·체크리스트**를 모아 두는 Microsoft **클라우드** 앱이다. 
**Microsoft 계정**(개인·회사·학교)으로 로그인하면 PC·웹·휴대폰에서 **동기화**되고, **Outlook**·**Planner** 작업과 **겹치는 구간**이 있다.

웹: [to-do.office.com](https://to-do.office.com) · 앱: Windows / macOS / iOS / Android  
도움말: [Microsoft To Do 지원](https://support.microsoft.com/todo)

확인일: 2026-08-11

관련: [[메모 앱]] · [[Notion 사용법]] · [[윈도우 사용법]] · [[Microsoft Copilot과 무료 Office]] · [[웹 드라이브 비교]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **목록 + 작업** 단위의 할 일 관리 |
| 요금 | **Microsoft 계정** 기준 **무료** (유료 티어 없음) |
| 데이터 | **Exchange Online** 쪽에 저장 — Outlook **작업**과 연동 |
| 전신 | 예전 **Wunderlist** 계열을 Microsoft가 흡수·대체한 흐름 |
| 잘 맞음 | **오늘 할 일**, 메일 **플래그 → 작업**, 가족·팀 **공유 체크리스트** |
| 덜 맞음 | 간트·의존 관계·대형 **프로젝트 보드** → **Planner**·[[Notion 사용법]] DB |

```text
떠오른 할 일 → 목록에 추가 (또는 Outlook 플래그)
 ↓
My Day(나의 하루)에 오늘 것만 골라 넣기
 ↓
완료 체크 → 미완료는 내일 제안에 다시 뜰 수 있음
```

**장문 메모·위키**는 [[Obsidian 사용법]]·[[메모 앱]]이 맡고, To Do는 **실행 단위**에 가깝다.

## 2. 화면 구조

### 2.1 스마트 목록 (기본)

| 목록 | 설명 |
|------|------|
| **My Day**(나의 하루) | **오늘 집중**할 작업만 모아 둠. 매일 비우고 다시 채움 |
| **Important**(중요) | 별표(중요) 표시한 작업 |
| **Planned**(계획됨) | **기한**이 있는 작업 |
| **Assigned to me**(나에게 할당됨) | **Planner** 등에서 나에게 배정된 작업(환경·권한에 따라) |
| **Flagged email**(플래그 지정된 전자 메일) | Outlook에서 **플래그**한 메일이 작업으로 표시 (설정에서 켜기) |
| **Tasks**(작업) | 기한 없이 넣은 작업의 **기본 보관** |

### 2.2 사용자 목록

**+ 새 목록**으로 **장보기·프로젝트·여행** 등 **주제별** 목록을 만든다. 
목록마다 **색·이모지**를 바꿀 수 있다.

### 2.3 작업(태스크) 안

| 요소 | 설명 |
|------|------|
| **제목** | 한 줄 할 일 |
| **메모** | 부가 설명 |
| **기한·미리 알림** | 날짜·시간 — **Planned**·알림에 연결 |
| **반복** | 매일·매주 등 (옵션) |
| **단계**(Steps) | 작업 안 **하위 체크** 목록 |
| **첨부** | 파일·사진 (용량·저장소는 계정·정책 따름) |
| **중요** | Important 목록으로 보냄 |

## 3. My Day와 제안

**My Day**는 “오늘 끝낼 것”만 보는 **집중 뷰**다.

1. 앱을 열면 빈 **My Day**가 보임 → 오늘 할 작업 입력  
2. 하루 이상 쓰면 **제안**(전구 아이콘)에 **어제 미완료·자주 쓰는 작업**이 뜰 수 있음  
3. My Day에 넣은 작업은 **Tasks** 등 원래 목록에도 **남음**  
4. 오늘 못 끝낸 것은 **다음 날 제안**에 다시 나올 수 있음  

Outlook **새 Outlook**에서는 우측 **My Day** 패널로 **일정 + 할 일**을 같이 볼 수 있다 → §4.

---

## 4. Outlook 연동

**같은 Microsoft 계정**으로 To Do와 Outlook에 로그인하면 작업이 **자동 동기화**된다.

| 기능 | 설명 |
|------|------|
| **작업 동기화** | To Do에서 만든 작업이 Outlook **작업**에, 그 반대도 표시 |
| **플래그 메일** | 메일에 **플래그** → To Do **Flagged email** 목록에 작업 생성 (설정에서 목록 표시) |
| **메일 → 작업** | 새 Outlook에서 메일을 **할 일 창으로 끌어** 작업 만들기 |
| **My Day 패널** | 메일·일정 화면에서 **나의 하루** 열기 — 오늘 일정·할 일 한곳 |

플래그 작업에서 **Outlook에서 열기**로 원본 메일로 돌아갈 수 있다.

회사 **Exchange** 정책에 따라 **동기화·플래그**가 막혀 있을 수 있다 — IT 안내 확인.

## 5. Planner·Teams와

| | Microsoft To Do | Microsoft Planner |
|--|-----------------|-------------------|
| 형태 | **체크리스트**·가벼운 목록 | **버킷·보드**·팀 프로젝트 |
| 공유 | 목록 **초대 링크** | 팀·플랜 단위 |
| 적합 | 개인·가족·짧은 협업 | 일정·담당·진행률이 중요한 **프로젝트** |

Planner에서 **나에게 할당**된 작업은 To Do **Assigned to me**에 모이는 경우가 많다. 
Teams 채널의 **Tasks by Planner and To Do** 탭으로 팀 할 일을 다루기도 한다.

**칸반·의존 관계·리포트**가 필요하면 Planner를, **오늘 할 일 몇 개**면 To Do가 가볍다.

## 6. 목록 공유

1. 공유할 **목록** 열기  
2. 우측 상단 **공유** 아이콘  
3. **초대 링크 만들기** → 복사해 메신저·메일로 전달  
4. 링크 받은 사람이 **같은 종류의 계정**으로 참여  

| 시나리오 | 가능 여부 |
|----------|-----------|
| **개인 계정 ↔ 개인 계정** | 일반적으로 가능 |
| **같은 회사·학교 계정** | 조직 내 공유 |
| **개인 ↔ 회사 계정** | **제한**되는 경우 많음 — 링크만으로 안 될 수 있음 |

**공유 중지**·**현재 멤버만** 제한은 공유 메뉴 **액세스 관리**에서 한다. 
가족 장보기·여행 준비처럼 **짧은 협업**에 쓰기 좋다.

## 7. [[메모 앱]]·다른 도구와 역할 나누기

| 넣을 것 | 추천 | 이유 |
|---------|------|------|
| 오늘·내일 **할 일** | **To Do** | 기한·알림·My Day |
| 3초 **메모** | Google Keep 등 | [[메모 앱]] |
| 팀 **프로젝트 DB** | **Notion** | 칸반·관계·권한 |
| **장기 지식·위키** | **Obsidian** | `[[링크]]`·로컬 md |
| 회의록·문서 | Notion / OneNote | 본문은 노트, **액션만** To Do로 |

```text
Notion 회의록 @할 일  →  To Do 목록에 작업 (또는 수동 복사)
Obsidian daily note   →  실행 항목만 To Do로 옮김 (선택)
Outlook 플래그 메일   →  To Do Flagged email (자동)
```

**이중 기록**을 줄이려면 **할 일의 최종본은 To Do**(또는 팀이면 Planner) 한곳으로 정한다.

## 8. 설치·동기화

| 플랫폼 | 경로 |
|--------|------|
| Windows | Microsoft Store **Microsoft To Do** |
| 웹 | [to-do.office.com](https://to-do.office.com) |
| macOS / iOS / Android | 스토어에서 동일 이름 검색 |

- 모든 기기에서 **같은 계정** 로그인  
- 변경은 **수 초 내** 동기화되는 편 (공식 안내 기준)  
- [[윈도우 사용법]] — Microsoft 계정·Store와 같은 축  

오프라인에서 적어 두었다가 **온라인 복귀 시** 반영된다. 충돌이 나면 **최근 수정**이 이기는 경우가 많다 — 중요 작업은 한 기기에서만 편집하는 편이 안전하다.

## 9. 실전 팁

| 팁 | 설명 |
|----|------|
| **My Day 습관** | 아침에 오늘 3~5개만 My Day에 넣기 |
| **플래그 메일** | “나중에 처리” 메일은 Outlook **플래그** → To Do에서 정리 |
| **목록 쪼개기** | 일·집·쇼핑·프로젝트 **목록 분리** — Tasks 한곳에만 쌓지 않기 |
| **단계** | “여권·짐싸기·예약”처럼 **큰 할 일**은 Steps로 쪼개기 |
| **월 초 공유** | 가족 목록은 **링크 재확인** — 멤버 나가기·중지 설정 |

---

## 10. 실전 체크

- [ ] **개인·회사 계정**을 섞어 쓰지 않았는가 (동기화·공유 꼬임)  
- [ ] Outlook **플래그 메일** 목록을 켰는가 (쓸 때만)  
- [ ] My Day에 **너무 많이** 넣지 않았는가  
- [ ] 팀 프로젝트는 **Planner**가 맞는지, To Do만으로 버티지 않는가  
- [ ] 장문 자료는 [[Obsidian 사용법]]·[[Notion 사용법]]에 두고 **액션만** To Do에 있는가
