# 번역 앱

> **분류:** 작성·지식 › 노트·지식 · [[생활위키 목차]]

**번역 앱**은 글·말·화면을 **다른 언어로 바꿔** 읽거나 대화할 때 쓴다. 
같은 “번역”이라도 **짧은 문장**, **카메라·메뉴판**, **실시간 대화**, **회의 전사+번역**처럼 쓰임이 다르다.

이 글은 **Google 번역(Google Translate)** 과 **Soniox** 를 중심으로 비교하고, **무엇을 언제 쓸지** 정하는 데 쓴다.

Google 번역: [https://translate.google.com](https://translate.google.com)  
Soniox: [https://soniox.com](https://soniox.com) · 앱(iOS·Android)

확인일: 2026-08-11

---

## 1. 개요

| 축 | 설명 |
|----|------|
| **텍스트** | 붙여 넣기·타이핑·웹페이지·문서 |
| **이미지** | 카메라·스크린샷으로 표지판·메뉴 인식 |
| **음성** | 말하기·듣기·대화 모드 |
| **실시간** | 말하는 동안 **연속** 자막·통역 (지연 적을수록 대화에 유리) |
| **전사** | 말을 **글**로 남기고, 화자·요약까지 (회의·강의) |

```text
짧은 문장·여행·메뉴 → Google 번역 (텍스트·카메라·대화)
 ↓
긴 회의·강의·다국어 실시간 통역 → Soniox (전사 + 스트리밍 번역)
 ↓
PC 영상 자막만 → [[라이브 캡션]] (Windows) · 브라우저·앱 내장 번역
```

한 앱이 **모든 상황**에 최적인 경우는 드물다. **목적**에 맞게 고른다.

---

## 2. 요약 비교

| | Google 번역 | Soniox |
|--|-------------|--------|
| **정체** | Google **범용 번역** (웹·앱) | **음성 AI** 기반 전사·통역 앱 |
| **플랫폼** | 웹, iOS, Android, [[크롬 사용법]] 연동 | iOS·Android 앱 (개발용 **API** 별도) |
| **강점** | **100개 이상** 언어, 카메라·오프라인 팩, 무료, 접근성 | **실시간** 전사·번역, 화자 구분, 요약·질문, 60+ 언어 |
| **약점** | 긴 회의 **기록·요약**은 약함. 통역은 문장 단위 느낌일 수 있음 | 텍스트만 빠르게 붙여 넣기·카메라 번역은 Google 쪽이 편함 |
| **비용** | **무료** (광고·데이터 정책은 Google 약관) | **무료 시작** + 유료(무제한·고급 기능) |
| **오프라인** | 언어 팩 **다운로드** 후 일부 기능 | 실시간 품질은 **온라인** 전제가 많음 |
| **쓰임** | 여행, 쇼핑, 짧은 대화, 웹·문서 | 회의, 강의, 인터뷰, **다국어 실시간** 대화 |

**참고:** 네이버 **Papago**, **DeepL**, Apple **번역** 등도 있다. 한·영 문장 품질만 보면 Papago·DeepL을 같이 쓰는 사람도 많다. 이 글은 요청한 **Google 번역·Soniox** 위주다.

## 3. Google 번역 (Google Translate)

Google이 제공하는 **무료** 번역 서비스. 웹·모바일 앱·일부 Google 앱·[[크롬 사용법]]에서 쓴다.

### 주요 모드

| 모드 | 하는 일 |
|------|---------|
| **텍스트** | 입력·붙여 넣기 → 번역. **저장**해 두기 가능 |
| **음성** | 말하면 인식 후 번역·읽어 주기 |
| **대화** | 두 사람이 폰을 오가며 **번갈아** 말하는 형식 |
| **카메라** | 표지판·메뉴·라벨을 **실시간 오버레이** 또는 사진 촬영 후 번역 |
| **필기** | 키보드에 없는 문자를 손가락·스타일러스로 쓰기 |
| **문서** | 파일 업로드 후 **서식 유지** 번역 (지원 형식·용량은 앱 안내) |
| **웹사이트** | URL 넣어 **페이지 전체** 번역 (웹·앱) |
| **전사(Transcribe)** | 주변 음성을 **같은 언어 또는 번역**으로 긴 자막처럼 표시 (기기·언어에 따라 다름) |

### 오프라인

앱에서 **언어 팩**을 받으면 인터넷 없이도 **일부** 텍스트·카메라 번역이 된다. 여행·데이터가 약한 곳에서 유용하다. 팩은 용량이 있으니 필요한 언어만 받는다.

### 다른 앱과 연동

| 연동 | 방법 |
|------|------|
| [[크롬 사용법]] | 페이지 우클릭·주소창 **번역** (외국어 사이트) |
| Android | 텍스트 **복사** 후 번역 팝업 (「앱에서 번역」) |
| [[갤럭시 폰 사용법]] | Google 앱·키보드·렌즈와 함께 쓰는 경우 많음 |

### 잘 맞는 상황

- 공항·식당 **메뉴·안내판** (카메라)
- 쇼핑몰·블로그 **짧은 문장**
- 해외 사이트 **빠른 훑기**
- **오프라인**이 필요한 짧은 여행

### 한계

- **의료·법률·계약** 문구는 오역 위험이 크다. 전문 번역·원문 확인이 필요하다.
- 긴 **회의 녹음**의 화자 구분·요약·검색은 Soniox 같은 **전사 앱**이 낫다.
- 대화 모드는 **턴제**에 가깝고, 빠르게 오가는 토론은 실시간 통역 앱이 나을 수 있다.

## 4. Soniox

Soniox는 **음성 인식(STT)** 과 **실시간 번역**에 특화된 서비스다. **소비자용 앱**과 개발자용 **API**가 따로 있다. 여기서는 **앱** 기준으로 정리한다.

### 하는 일

| 기능 | 설명 |
|------|------|
| **실시간 전사** | 말하는 대로 **글**로 표시. 여러 화자 **구분**(diarization) |
| **실시간 번역** | **단어·구 단위**로 스트리밍 번역 (문장 끝을 기다리지 않는 방식을 강조) |
| **자동 언어 감지** | 말하는 언어를 바꿔도 **중간에 설정**을 안 바꿔도 되는 경우가 많음 |
| **요약·하이라이트** | 회의·강의 후 **요약**, 할 일, 인용 추출 |
| **맞춤 질문** | 전사본에 대해 **질문·분석** (액션 아이템 뽑기 등) |
| **맥락 힌트** | 인명·전문 용어를 **미리 넣어** 인식률 보완 |
| **보내기** | 전사·요약 **공유·보내기** |

공식 기준 **60개 이상** 언어. **일방·양방** 통역 모드로 상대와 화면을 보며 대화하는 용도를 내세운다.

### Google 번역과 다른 점

| | Google 번역 | Soniox |
|--|-------------|--------|
| 초점 | **범용** 번역 (글·사진·짧은 음성) | **말** → 글 + **연속 통역** |
| 지연 | 대화·전사 모드는 상황마다 다름 | **스트리밍** 통역을 제품 핵심으로 내세움 |
| 회의 후 | 저장·요약은 제한적 | **요약·검색·태그** 중심 워크플로 |
| 카메라 | **강함** | 앱 목적이 **음성** 쪽 |

### 잘 맞는 상황

- **다국어 회의**·화상 통화 옆에서 실시간 자막
- **강의·세미나** 듣고 전사+번역+요약
- **인터뷰**·팟캐스트 녹음 정리
- 해외 체류 중 **상대와 말이 통하지 않을 때** 폰을 통역 보조로

### 비용·계정

앱은 **무료로 시작**하고, 사용량·고급 기능에 **유료 플랜**이 있다. 가격·한도는 앱·웹 **요금 안내**를 본다 (변경될 수 있음).

### 개인정보

Soniox는 **기기에 오디오를 두고** 처리한다는 식의 **프라이버시** 설명을 한다. 그래도 **계정·클라우드 동기화·공유 링크**를 쓰면 데이터가 서버로 가는 구간이 생길 수 있다. 회사·의료·법률 대화는 **서비스 약관·개인정보 처리방침**을 읽고, 필요하면 **녹음 동의**를 받는다.

### API (참고)

개발자는 Soniox **API**로 앱·서비스에 실시간 전사·번역을 붙일 수 있다. 일반 사용자는 **앱만** 써도 된다.

## 5. 역할 나누기

| 상황 | 추천 |
|------|------|
| 메뉴판·간판 사진 | **Google 번역** 카메라 |
| 이메일·웹 한 단락 | **Google 번역** 텍스트 · Papago·DeepL로 교차 확인 |
| 비행기·지하철 **오프라인** | Google **언어 팩** |
| 1시간 회의 **전사+요약** | **Soniox** |
| 빠르게 오가는 **양방향** 대화 | **Soniox** 통역 모드 (품질은 환경·언어쌍마다 다름) |
| PC에서 영상만 자막 | [[라이브 캡션]] (번역은 기기·버전에 따라) |
| 메신저 안 문장 | [[텔레그램]] 등 **앱 내 번역** + 필요 시 Google |

```text
[여행·일상] Google 번역 앱 + 오프라인 팩
[업무·학습] Soniox로 녹음·전사 → 요약 확인
[중요 문서] 기계 번역 1차 → 사람·전문가 검수
```

## 6. 품질·주의

| 주제 | 내용 |
|------|------|
| **오역** | 속담·뉘앙스·전문 용어는 틀리기 쉽다. **중요한 결정**은 원문·전문 번역을 본다. |
| **의료·법률** | 진단·계약·약관은 **앱 번역만** 믿지 않는다. |
| **녹음 법** | 회의·통화 **녹음·전사**는 국가·기관 규정·상대 **동의**가 필요할 수 있다. |
| **배터리·발열** | 실시간 전사·통역은 **마이크·네트워크**를 오래 쓴다. |
| **소음** | 카페·거리에서는 **이어폰 마이크**·조용한 자리가 낫다. |
| **AI 요약** | Soniox 요약도 **할루시네이션**이 있을 수 있다. 사실 확인은 **전사 원문**으로. |

## 7. 정리

| 항목 | Google 번역 | Soniox |
|------|-------------|--------|
| 한 줄 | **무료 범용** 번역기 | **실시간 음성** 전사·통역·요약 |
| 꼭 쓸 때 | 글·카메라·오프라인·웹 | 회의·강의·다국어 **대화** |
| 같이 쓰기 | 짧은 문장은 Google, 긴 말은 Soniox | 요약은 Soniox, 표지판은 Google |

---

## 면책

> **면책**  
> 지원 언어·기능·요금·오프라인 범위는 **앱·웹 버전**마다 다르다. 공식 안내를 본다.  
> 번역·전사·요약 결과는 **참고용**이며, 의료·법률·금융 결정에 그대로 쓰지 않는다.  
> 녹음·개인정보는 **현지 법**과 서비스 약관을 따른다.
