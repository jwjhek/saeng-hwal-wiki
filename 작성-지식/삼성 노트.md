# 삼성 노트

> **분류:** 작성·지식 › 노트·지식 · [[생활위키 목차]]

**삼성 노트**(Samsung Notes)는 갤럭시 폰·탭·북에 기본으로 들어가는 **손글씨·텍스트 메모** 앱이다.  
키보드 메모도 되지만, 강점은 **S펜으로 PDF 위에 쓰거나**, 화면이 꺼진 채로 바로 적는 쪽에 가깝다.

공식: [https://www.samsung.com/sec/apps/samsung-notes/](https://www.samsung.com/sec/apps/samsung-notes/)  
Windows: Microsoft Store **Samsung Notes** (갤럭시 북에 최적화 안내)

확인일: 2026-08-27  
메뉴·Galaxy AI·S펜은 **모델·One UI**마다 다르다. 앱 안 설정·[삼성 고객지원](https://www.samsung.com/sec/support/)이 우선이다.

관련: [[갤럭시 폰 사용법]] · [[메모 앱]] · [[Obsidian 사용법]]

---

## 1. 개요

| 항목     | 설명                                                                           |
| ------ | ---------------------------------------------------------------------------- |
| 무엇     | 삼성 계정으로 묶는 **필기 노트북**. 사진·음성·PDF를 한 노트에 담음                                   |
| 잘 맞음   | 강의·회의 PDF 주석, 손글씨 아이디어, 탭+S펜 필기                                              |
| 덜 맞음   | `[[위키링크]]` 지식 베이스, 팀 DB, Git으로 글 관리                                          |
| 데이터    | 기기 + **삼성 클라우드** 동기화 (같은 삼성 계정)                                              |
| 형식별    | 노트 파일은 **sdocx** 계열. 위키 `.md`와 다름                                            |
| 무엇이 아님 | [[Obsidian 사용법]] vault, [[Notion 사용법]] 워크스페이스, [[Microsoft To Do 사용법]] 할 일 앱 |

```text
떠오름 → S펜 꺼진 화면 메모 / 새 노트
 ↓
강의 PDF·회의 녹음은 같은 노트에
 ↓
손글씨 → (필요하면) 텍스트 변환 → 공유·PDF
 ↓
장기 위키로 남길 글만 [[Obsidian 사용법]]으로 옮김
```

S펜이 없는 갤럭시는 **손가락·키보드**로 쓴다. 필기 체감은 펜 있는 기기가 낫다.

다른 메모 앱과의 자리는 [[메모 앱]].

---

## 2. 기기·계정

| 기기 | 메모 |
|------|------|
| **갤럭시 폰** | 기본 앱. Ultra·S펜 지원 모델에서 꺼진 화면 메모가 특히 편함 → [[갤럭시 폰 사용법]] |
| **갤럭시 탭** | 필기·PDF 주석의 본진. 화면이 넓음 |
| **폴드** | 별도 **S펜 폴드 에디션**이 필요한 기기가 있음. 호환은 삼성 표 |
| **Windows** | Store 앱. **갤럭시 북**에 맞춰져 있고, 다른 PC는 설치·실행이 막히거나 불안정할 수 있음 |
| **DeX** | 모니터에 연결해 노트 정리 → [[갤럭시 DeX]] |

동기화 전제:

1. 쓸 기기에 **같은 삼성 계정**  
2. 삼성 노트 설정에서 **삼성 클라우드 동기화** 켜기  
3. Wi-Fi·최신 앱. PDF·녹음이 많으면 시간이 걸림  

계정이 다르면 노트가 안 보인다. 회사 갤럭시와 개인 계정을 섞을 때는 **어느 계정에 쌓이는지**를 먼저 정한다.

---

## 3. 화면에서 자주 쓰는 것

앱을 열면 노트 목록. **+** 로 새 노트. 모델마다 아이콘 위치가 조금 다르다.

| 기능 | 활용 |
|------|------|
| **펜·형광펜·지우개** | 손글씨·밑줄. 두께·색은 펜 메뉴 |
| **텍스트 상자** | 키보드 입력. 손글씨와 섞어 쓰기 |
| **PDF 넣기** | 자료를 노트로 가져와 **위에 필기**. 원문 글자를 워드처럼 고치는 기능은 아님 |
| **음성 녹음** | 회의·강의. 쓰면서 녹음하면 **그 시점**으로 되감기 쉬운 안내가 있음 |
| **사진·첨부** | 칠판·영수증·화이트보드 |
| **태그·폴더** | 과목·프로젝트로 나누기. 검색과 같이 씀 |
| **잠금** | 민감 노트만. 폰 잠금과 별도인 경우가 많음 |
| **공유·내보내기** | PDF·이미지·텍스트. 상대가 삼성 노트가 없으면 PDF가 무난함 |

손글씨를 고른 뒤 **텍스트로 변환**하면 메일·메신저에 붙이기 쉽다. 언어·글씨에 따라 오인식이 있다.

지원 기기에는 **Galaxy AI**(요약·교정·번역 등)가 노트에 붙는 경우가 있다. 있으면 초안용으로 보고, 숫자·고유명은 다시 읽는다.

## 4. S펜 활용

펜이 있는 기기에서 체감이 갈린다. 에어 커맨드·버튼 동작은 **설정 → S펜**(또는 유용한 기능)에서 본다.

### 4.1 꺼진 화면 메모

화면이 꺼진 채 **S펜을 뽑으면** 바로 쓰는 기능. 잠금 해제 전에 아이디어를 남긴다.  
쓴 뒤 **삼성 노트에 저장**하거나, Always On Display에 **고정**하는 안내가 있다.  
긴 글로 쓰지 말고 **캡처용**으로 두고, 나중에 폴더로 옮긴다.

### 4.2 영상 위 메모

강의·영상을 보다가 S펜 버튼 + 화면 두 번 탭 등으로 **작은 메모창**을 띄우는 안내가 있다. 크기·투명도를 줄여 화면을 가리지 않게 한다.

### 4.3 PDF 필기

1. 노트에서 PDF 불러오기 (또는 파일을 삼성 노트로 열기)  
2. 형광펜·펜으로 밑줄·동그라미  
3. 저장 후 같은 계정 탭·PC에서 이어서  

시험·회의 자료는 **원본 PDF를 따로** 두고, 필기본은 노트에 두는 편이 안전하다.

### 4.4 손글씨 → 텍스트

필기를 선택 → 변환. 공유·검색용. **위키 본문**으로 쓸 만큼 깨끗하면 [[Obsidian 사용법]]에 붙여 넣고 다듬는다.

## 5. 상황별 활용

| 상황 | 하는 일 |
|------|---------|
| **회의** | 새 노트 + 녹음. 안건은 텍스트, 그림은 펜. 끝나면 PDF로 메일 |
| **강의·자격** | 슬라이드 PDF를 넣고 필기. 탭이 있으면 폰은 녹음·사진 |
| **장보기·할 일** | 짧은 목록은 [[메모 앱]]의 Keep이 더 빠른 경우가 많음. 손글씨 습관이면 여기 체크리스트 |
| **아이디어** | 꺼진 화면 메모 → 밤에 폴더로 분류 |
| **서명·양식** | PDF 위에 서명. 민감 서류는 공유 범위를 줄임 |
| **DeX·북** | 키보드로 장문, 펜으로 그림. 동기화만 켜 두면 됨 |

위키·반복되는 절차 글은 삼성 노트에 쌓지 말고, 정리된 문장만 Obsidian으로 옮긴다. 노트는 **잉크·PDF**, 위키는 **검색·링크**.

---

## 6. 정리·백업

| 할 일 | 이유 |
|--------|------|
| 폴더를 **적게** (과목·일·집 정도) | 태그와 검색이 더 잘 먹음 |
| 제목에 **날짜·주제** | 목록에서 찾기 |
| 중요 노트 **PDF 내보내기** | sdocx만 있으면 삼성 앱 밖에서는 불편함 |
| 삼성 클라우드 + (선택) 내보내기 복사 | 계정 분실·기기 초기화 대비 |
| 민감 정보는 **잠금** 또는 보안 폴더 | 폰을 넘길 때 |

Windows에 앱이 안 되면 **탭·폰에서 PDF로 보낸 뒤** PC에서 보는 우회가 안전하다. Store 제한을 **레지스트리로 푸는 방법**은 이 글에서 다루지 않는다.

## 7. 다른 앱과

| | 삼성 노트 | Keep | Obsidian |
|--|-----------|------|----------|
| 손글씨·PDF 주석 | **강함** | 약함 | 플러그인·별도 앱 |
| 빠른 한 줄 | 보통 | **강함** | PC 중심 |
| 위키 링크·공개 사이트 | 없음 | 없음 | **본체** ([[Quartz 사용법]]) |
| 동기화 | 삼성 계정 | Google | 폴더·유료 Sync 등 |

갤럭시만 쓰면 캡처는 삼성 노트, 지식은 Obsidian으로 나누는 집이 많다.
