# VS Code 사용법

> **분류:** 작성·지식 › 에디터·IDE · [[생활위키 목차]]

Windows 기준으로 정리. Cursor도 같은 뼈대를 쓰므로, 편집·검색·터미널 부분은 [[Cursor 사용법]]에서도 그대로 통한다.

---

## 1. VS Code가 하는 일

Visual Studio Code는 **폴더를 하나의 프로젝트(워크스페이스)로 열고**, 그 안에서 파일을 편집·검색·실행하는 에디터다.

- 메모장처럼 “파일 하나”만 여는 용도가 아니다.
- 탐색기·검색·Git·터미널·확장이 한 창에 붙어 있다.
- 단축키와 명령 팔레트로 거의 모든 기능을 키보드만으로 쓸 수 있다.

설치: [https://code.visualstudio.com](https://code.visualstudio.com)

---

## 2. 처음 설정해 두면 좋은 것

### 2.1 폴더로 열기

1. `파일 → 폴더 열기…`
2. 작업할 프로젝트 폴더 선택 (예: `생활위키`)
3. 왼쪽 탐색기에 그 폴더 트리가 보이면 정상

다음에 다시 열 때는 **최근 항목**이나 시작 화면에서 같은 폴더를 고르면 된다. 창을 여러 개 쓰려면 `Ctrl + Shift + N`.

### 2.2 필수 습관: 명령 팔레트

`Ctrl + Shift + P` (또는 `F1`)

여기에 원하는 동작을 **한글로든 영문으로든** 치면 된다.

예:

- `테마` → 색 테마 바꾸기
- `형식` / `Format Document` → 코드 정렬
- `다시 로드` → 창 새로고침
- `설정 동기화` → 계정으로 설정 백업

단축키를 외울 필요 없다. 팔레트에 뜨는 오른쪽 단축키만 보고 익히면 된다.

### 2.3 설정

| 목적 | 여는 법 |
|------|---------|
| UI 설정 | `Ctrl + ,` |
| 단축키 편집 | `Ctrl + K` 누른 뒤 `Ctrl + S` |
| 설정 JSON | 팔레트 → `Preferences: Open User Settings (JSON)` |

자주 건드리는 항목 예:

- **자동 저장** (`files.autoSave`) — `afterDelay` 추천
- **탭 크기** (`editor.tabSize`)
- **워드랩** (`editor.wordWrap`) — 긴 글/마크다운에 `on`
- **미니맵** (`editor.minimap.enabled`) — 거슬리면 끄기
- **글꼴** (`editor.fontFamily`, `editor.fontSize`)

프로젝트마다 다른 설정이 필요하면 폴더 안에 `.vscode/settings.json`을 둔다. 팀/저장소 전용 설정이다.

### 2.4 설정 동기화 (Settings Sync)

여러 PC를 쓰면 계정으로 로그인 후 Settings Sync를 켠다. 테마·단축키·확장 목록을 맞춰 둔다.

## 3. 화면 구조

```
┌────────┬──────────────────────────┬────────────┐
│ 사이드 │ 에디터 │ 보조 패널 │
│ 바 │ (탭으로 여러 파일) │ (가끔 사용) │
├────────┴──────────────────────────┴────────────┤
│ 패널 (터미널 / 문제 / 출력) │
└────────────────────────────────────────────────┘
```

| 영역 | 하는 일 | 단축키 |
|------|---------|--------|
| 사이드바 | 파일, 검색, Git, 확장 | `Ctrl + B` 토글 |
| 에디터 | 실제 편집 | — |
| 패널 | 터미널, 문제, 디버그 콘솔 | `Ctrl + J` 토글 |
| 상태바 | 줄/인코딩/Git 브랜치 등 | 클릭으로 관련 설정 |

사이드바 아이콘:

| 아이콘 | 단축키 | 용도 |
|--------|--------|------|
| 탐색기 | `Ctrl + Shift + E` | 파일 트리 |
| 검색 | `Ctrl + Shift + F` | 폴더 전체 텍스트 검색 |
| 소스 제어 | `Ctrl + Shift + G` | Git 변경·커밋 |
| 실행 및 디버그 | `Ctrl + Shift + D` | 디버거 |
| 확장 | `Ctrl + Shift + X` | 확장 설치 |

## 4. 파일 열고 이동하기

| 동작 | 단축키 | 설명 |
|------|--------|------|
| 파일 빠른 열기 | `Ctrl + P` | 파일명 일부만 쳐도 됨 |
| 줄로 이동 | `Ctrl + G` | 줄 번호 입력 |
| 심볼로 이동 (현재 파일) | `Ctrl + Shift + O` | 함수/제목 목록 |
| 워크스페이스 심볼 | `Ctrl + T` | 프로젝트 전역 심볼 |
| 정의로 이동 | `F12` | 코드에서 |
| 참조 찾기 | `Shift + F12` | 코드에서 |
| 뒤로 / 앞으로 | `Alt + ←` / `Alt + →` | 커서 위치 히스토리 |
| 최근 닫은 탭 다시 열기 | `Ctrl + Shift + T` | 실수로 닫았을 때 |

`Ctrl + P` 팁:

- `@` 붙이면 현재 파일 심볼
- `:` 붙이면 줄 번호 (`:120`)
- `?` 붙이면 도움말

## 5. 편집 단축키 (매일 쓰는 것)

### 줄 단위

| 동작 | 단축키 |
|------|--------|
| 줄 잘라내기 (선택 없을 때) | `Ctrl + X` |
| 줄 복사 (선택 없을 때) | `Ctrl + C` |
| 줄 삭제 | `Ctrl + Shift + K` |
| 줄 위/아래 이동 | `Alt + ↑` / `Alt + ↓` |
| 줄 복제 | `Shift + Alt + ↑` / `↓` |
| 아래에 빈 줄 | `Ctrl + Enter` |
| 위에 빈 줄 | `Ctrl + Shift + Enter` |

### 선택·다중 커서

| 동작 | 단축키 |
|------|--------|
| 다음 동일 단어 추가 선택 | `Ctrl + D` |
| 모두 선택 | `Ctrl + Shift + L` |
| 열(박스) 선택 | `Shift + Alt` 누른 채 드래그 |
| 커서 추가 | `Alt + 클릭` |
| 선택 영역 위/아래로 커서 | `Ctrl + Alt + ↑` / `↓` |

같은 변수명·같은 문구를 여러 군데 고칠 때 `Ctrl + D`를 반복하는 습관이 특히 중요하다.

### 주석·서식

| 동작 | 단축키 |
|------|--------|
| 줄 주석 토글 | `Ctrl + /` |
| 블록 주석 | `Shift + Alt + A` |
| 문서 서식 | `Shift + Alt + F` |
| 선택 영역 들여쓰기 | `Ctrl + ]` / `Ctrl + [` |
| 접기 / 펼치기 | `Ctrl + Shift + [` / `]` |

### 찾기·바꾸기

| 동작 | 단축키 |
|------|--------|
| 현재 파일 찾기 | `Ctrl + F` |
| 바꾸기 | `Ctrl + H` |
| **폴더 전체 검색** | `Ctrl + Shift + F` |
| 폴더 전체 바꾸기 | 검색 패널의 바꾸기 칸 |

전체 검색에서:

- `Aa` — 대소문자 구분
- `ab` — 단어 단위
- `.*` — 정규식
- 포함할 파일: `*.md`, 제외: `**/node_modules`

## 6. 에디터 레이아웃

| 동작 | 단축키 |
|------|--------|
| 좌우 분할 | `Ctrl + \` |
| 그룹 1/2/3 포커스 | `Ctrl + 1` / `2` / `3` |
| 탭 닫기 | `Ctrl + W` |
| 모든 에디터 닫기 | `Ctrl + K` 후 `Ctrl + W` |
| 다음/이전 탭 | `Ctrl + Tab` / `Ctrl + Shift + Tab` |
| 사이드바 숨기기 | `Ctrl + B` |
| Zen Mode (집중) | `Ctrl + K` 후 `Z` |

### 파일 비교 (diff)

두 파일(또는 같은 파일의 다른 버전)을 **좌우 diff**로 본다. 폴더 통째 비교는 [[WinMerge 사용법]].

#### 팔레트 — Compare Active File With (추천 습관)

지금 열어 둔 파일을 기준으로 다른 파일과 비교할 때:

1. 비교의 **한쪽**이 될 파일을 연다 (활성 탭) 
2. `Ctrl + Shift + P` 로 명령 팔레트 
3. `Compare Active File With` 입력 · 실행 
 (한글 UI면 **활성 파일 비교** / **활성 파일을 다음과 비교** 등으로 검색) 
4. 목록에서 **다른 쪽 파일**을 고른다 

워크스페이스 안 파일뿐 아니라, 안내에 따라 **최근 파일·디스크의 다른 경로**도 고를 수 있다.

비슷한 명령:

| 명령 (영문 검색어) | 설명 |
|--------------------|------|
| `Compare Active File With...` | 활성 탭 vs 고른 파일 |
| `Compare Active File With Saved` | 저장 안 한 수정 vs 디스크에 저장된 내용 |
| `File: Compare Active File With Clipboard` | 활성 파일 vs 클립보드 (버전에 따라 존재) |

명령 이름·번역은 VS Code 버전에 따라 조금 다를 수 있으니, 팔레트에 `Compare` / `비교`만 쳐도 후보가 뜬다.

#### 탐색기에서 두 파일 지정

1. 탐색기에서 파일 A 우클릭 → **Select for Compare** (비교할 항목 선택) 
2. 파일 B 우클릭 → **Compare with Selected** (선택 항목과 비교) 

탭을 미리 열어 두지 않아도 된다.

#### Git 변경분

소스 제어(`Ctrl + Shift + G`)에서 파일 클릭 → **워킹트리 vs 마지막 커밋** diff. 
개념은 [[Git 사용법]], UI 흐름은 아래 [[#8. Git (소스 제어)]].

## 7. 통합 터미널

`Ctrl + `` ` `` (백틱)으로 아래 패널 터미널을 연다.

- 새 터미널: `Ctrl + Shift + `` ` ``
- 여러 터미널 탭을 두고 npm, git, 서버를 동시에 돌릴 수 있다.
- 기본 셸은 PowerShell / cmd / Git Bash 중 고를 수 있다. 
 팔레트 → `Terminal: Select Default Profile`

작업 폴더는 보통 **연 워크스페이스 루트**다. `cd`로 옮겨 다닐 필요를 줄인다.

## 8. Git (소스 제어)

사이드바 소스 제어(`Ctrl + Shift + G`) 또는 터미널에서 git 명령을 쓴다. 
개념·브랜치·원격·충돌은 [[Git 사용법]], 호스팅은 [[GitHub]]·[[GitLab]].

기본 UI 흐름:

1. 변경된 파일 확인
2. `+`로 스테이징
3. 메시지 입력 후 커밋
4. 상태바 브랜치 이름 클릭으로 브랜치 전환

터미널에서 자주 쓰는 것:

```powershell
git status
git diff
git add .
git commit -m "메시지"
git log --oneline -10
```

VS Code는 diff를 시각적으로 보여 주므로, 커밋 전에 UI로 한 번 훑는 편이 안전하다.

## 9. 확장 (Extensions)

`Ctrl` + `Shift` + `X`

추천 목록·언어별 세트는 **[[VS Code 추천 확장]]** 에 따로 정리했다.

### 고르는 기준

- 공식/많이 쓰이는 것 우선 (다운로드 수, 최근 업데이트)
- “만능 확장 팩”을 잔뜩 깔지 않기 — 느려짐의 주범
- 언어 하나당 공식 확장 하나면 충분한 경우가 많다

### 용도별 출발점 (요약)

| 목적 | 예 |
|------|----|
| 언어 지원 | Python, Extension Pack for Java, ESLint |
| 포맷 | Prettier (팀이 쓰면) |
| 마크다운 | Markdown All in One, markdownlint |
| Git | GitLens, Git Graph |
| 컨테이너 | Docker, YAML, WSL/SSH Remote |

확장 문제 의 시: 해당 확장 비활성화 → 창 다시 로드 → 원인 확인.

## 10. 문제 패널·언어 기능

| 동작 | 단축키 |
|------|--------|
| 문제(에러/경고) 패널 | `Ctrl + Shift + M` |
| 다음/이전 문제 | `F8` / `Shift + F8` |

## 11. 마크다운·문서 작업

이 위키처럼 `.md`를 많이 쓰면:

1. 워드랩 켜기 (`Alt + Z` 토글)
2. 미리보기: 팔레트 → `Markdown: Open Preview` 또는 `Ctrl + Shift + V`
3. 옆 미리보기: `Ctrl + K` 후 `V`
4. 개요(제목 목록): `Ctrl + Shift + O`

이미지 붙여넣기는 확장에 따라 동작이 다르다. Obsidian vault를 VS Code로 열어도 편집은 되지만, 위키링크 `[[...]]` 미리보기는 Obsidian이 더 편하다.

## 12. 추천 워크플로

1. **항상 폴더로 연다** — 검색·Git·터미널이 같은 기준점을 갖는다.
2. **파일은 `Ctrl + P`, 기능은 `Ctrl + Shift + P`** — 마우스로 메뉴를 헤매지 않는다.
3. **고치기 전에 전체 검색** — `Ctrl + Shift + F`로 영향 범위를 본다.
4. **다중 커서로 반복 수정** — 같은 문자열은 `Ctrl + D`.
5. **커밋 전 diff 확인** — 소스 제어에서 한 파일씩 훑는다. 임의 두 파일은 팔레트 `Compare Active File With`.
6. **확장 최소화** — 느리면 확장부터 의심한다.

---

## 13. 단축키가 안 먹을 때

1. `Ctrl + K`, `Ctrl + S`로 단축키 검색 → 충돌 여부 확인
2. 다른 프로그램(한컴, 게임 오버레이, 원격 툴)이 키를 가로채는지 확인
3. 키보드 레이아웃(한/영) — 영문 상태에서 다시 시도
4. 확장 키바인딩 충돌 — 최근 설치한 확장 끄고 재확인
