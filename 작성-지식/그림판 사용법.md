# 그림판 사용법

> **분류:** 작성·지식 › 비교·이미지 · [[생활위키 목차]]

Windows에 기본 포함된 **간단한 그림·이미지 편집** 앱이다. 
자르기·리사이즈·캡처 편집·투명 PNG·(Windows 11) 레이어·AI 기능까지, “포토샵 없이 빠르게” 할 때 쓴다.

실행: 시작 메뉴에서 `그림판` / `Paint` 검색 
또는 `Win` + `R` → `mspaint`

확인일: 2026-08-06 
버전·AI 기능은 Windows·Microsoft 계정·지역에 따라 없을 수 있다.

---

## 1. 언제 쓰나

| 잘 맞음 | 다른 도구 |
|---------|-----------|
| 스크린샷 자르기·화살표·메모 | 정교한 합성 → Photoshop / GIMP / Photopea |
| 아이콘·도형·간단 밈 | 벡터 로고 → Illustrator / Inkscape |
| 투명 배경 PNG 만들기 | 대량 일괄 → [[Python 학습과 패키지\|Python]]+Pillow |
| 빠른 마킹 | 주석 전용 → Snipping Tool / ShareX |

스크린샷은 `Win` + `Shift` + `S` 후 그림판에 `Ctrl` + `V`가 기본 루틴이다.

---

## 2. 화면 구성 

```text
┌ 파일 | 홈 | (보기) | (AI/Copilot 등) ─────────────┐
│ 도구(연필·채우기·텍스트·도형·선택…) 색·굵기 │
├──────────────┬──────────────────┬────────────────┤
│ (레이어 패널) │ 캔버스 │ │
└──────────────┴──────────────────┴────────────────┘
```

- **홈**: 그리기·선택·이미지(자르기/크기)·색 
- **보기**: 확대·눈금·눈금자 (버전에 따라) 
- **레이어**: Windows 11 최신 Paint — 오른쪽/전용 패널 
- 상태바: 좌표·선택 크기·확대 비율 

구형 Windows 10 Paint는 리본이 비슷하지만 **레이어·투명·AI가 없을** 수 있다. Microsoft Store에서 Paint를 최신으로 두거나 Windows 11로 올리면 기능이 늘어난다.

---

## 3. 기본 도구

| 도구 | 용도 | 팁 |
|------|------|-----|
| 연필 / 브러시 | 자유 곡선 | 굵기·색 먼저 고르기 |
| 채우기(통) | 닫힌 영역 색 채우기 | 틈이 있으면 새어 나감 |
| 텍스트 (A) | 글자 넣기 | 글꼴·크기 선택 후 클릭·드래그 |
| 도형 | 선·사각형·원·화살표 | 그리기 전 윤곽/채우기 색 |
| 지우개 | 지우기 | 배경색으로 칠해지는 구버전 동작 vs 투명 지원 신버전 |
| 돋보기 / 배율 | 확대 | `Ctrl` + 휠이 편한 경우 많음 |
| 색 선택(스포이트) | 화면 색 추출 | 로고 색 맞출 때 |
| 선택 | 사각/자유 선택 후 이동·복사·자르기 | `Ctrl` + `C` / `V` |

### 색

- 색 1 = 왼쪽 클릭, 색 2 = 오른쪽 클릭으로 쓰는 전통이 있음 (도구에 따라). 
- **색 편집**에서 RGB/헥스에 가까운 값을 맞출 수 있다 (UI 버전별).

## 4. 이미지 편집 필수

### 4.1 열기·붙여넣기

- `Ctrl` + `O` 열기 
- 클립보드 이미지 `Ctrl` + `V` 
- 캔버스가 작으면 **크기 조정** 또는 붙여넣은 뒤 드래그로 맞춤 

### 4.2 자르기 (Crop)

1. **선택** 도구로 영역 지정 
2. **자르기** (홈 → 이미지 → 자르기) 
또는 선택 후 우클릭 메뉴 

스크린샷에서 불필요 영역을 잘라낼 때 가장 많이 쓴다.

### 4.3 크기 조정·기울이기

- `Ctrl` + `W` 또는 홈 → **크기 조정** 
- **비율 유지** 체크 여부 확인 (로고 찌그러짐 방지) 
- 픽셀 / 퍼센트 단위 

### 4.4 회전·뒤집기

홈 → 회전: 왼쪽/오른쪽 90°, 수평·수직 반전. 
스마트폰 사진 방향 고칠 때.

### 4.5 선택 영역만 다루기

- `Ctrl` + `X` / `C` / `V` 
- 선택 후 `Delete` — 배경/투명에 따라 결과가 다름 
- **투명 선택**(구버전 “투명한 선택 영역”) — 단색 배경을 빼고 옮길 때

## 5. 파일 형식

| 형식 | 언제 |
|------|------|
| **PNG** | 기본 추천. 무손실, **투명** 유지 |
| JPEG / JPG | 사진·용량 작을 때. 투명 없음, 뭉개짐 |
| GIF | 단순 그림·구형 호환 (색 수 제한) |
| BMP | 무압축·용량 큼 |
| **.paint** (프로젝트) | Windows 11 — **레이어 보존** 재편집용 |

작업 중에는 `.paint`로 저장하고, 올릴 때만 PNG로보내는 식이 레이어를 안 잃는다. 
구형 Paint는 PNG에 투명 저장이 약했으나, 최신 Windows 11 Paint는 **투명 PNG**를 지원한다 (체크보드 = 투명).

---

## 6. Windows 11 그림판 — 레이어

레이어 = 위·아래 **겹친 투명 필름**. 글자·화살표·배경을 나눠 수정한다.

1. 레이어 패널에서 **+** 또는 `Ctrl` + `Shift` + `N` 
2. 위 레이어에 텍스트·도형 
3. 드래그로 순서 변경 
4. 눈 아이콘으로 표시 on/off 
5. 합치기 `Ctrl` + `Shift` + `M` (버전에 따라) 
6. 삭제 `Ctrl` + `Shift` + `Delete` 

팁:

- 배경 사진은 맨 아래, 주석은 위 
- 한쪽만 지워도 아래 레이어는 안전 
- 최종 공유 전 PNG로보내면 레이어는 합쳐진 한 장으로 저장되는 경우가 많음 → 재편집용은 `.paint`

## 7. 투명·배경 제거

### 투명 PNG

1. 캔버스/레이어에서 지울 부분을 지우개로 (투명 지원 시 체크보드) 
2. **PNG로 저장** 
3. 다른 문서·PPT·웹에 올릴 때 흰 사각이 없어야 성공 

### AI 배경 제거 (제공 시)

홈/도구의 **배경 제거** 등 — 피사체만 남기고 배경을 투명 처리. 
품질은 피사체·대비에 따라 다르고, 세부는 레이어·지우개로 손본다.

---

## 8. AI 기능 (있는 경우)

Microsoft 계정·크레딧·Copilot+/지역에 따라 **Image Creator / Cocreator** 등이 보인다.

| 기능 | 설명 |
|------|------|
| Image Creator | 텍스트 프롬프트 → 이미지 생성 (클라우드, 크레딧) |
| Cocreator | 낙서+프롬프트 → 다듬어진 이미지 (로컬/하이브리드일 수 있음) |
| 배경 제거 | 한 번에 피사체 분리 |

프롬프트는 구체적일수록 낫다: 주제·스타일·구도·색. 
생성물은 저작권·사용 조건을 Microsoft 정책을 확인. 
안 보이면 Windows Update·Paint 업데이트·계정 로그인을 점검.

| 동작 | 단축키 |
|------|--------|
| 새로 만들기 | `Ctrl` + `N` |
| 열기 / 저장 | `Ctrl` + `O` / `S` |
| 다른 이름 저장 | `Ctrl` + `Shift` + `S` |
| 실행 취소 / 다시 | `Ctrl` + `Z` / `Y` |
| 복사·잘라·붙여 | `Ctrl` + `C` / `X` / `V` |
| 모두 선택 | `Ctrl` + `A` |
| 인쇄 | `Ctrl` + `P` |
| 크기 조정 | `Ctrl` + `W` |
| 확대·축소 | `Ctrl` + 휠 (지원 시) |
| 100% | `Ctrl` + `0` |
| 새 레이어 | `Ctrl` + `Shift` + `N` |
| 레이어 병합 | `Ctrl` + `Shift` + `M` |

단축키는 Paint 빌드마다 다를 수 있다. 메뉴에 표시된 키를 우선한다.

## 10. 실전 레시피

### 10.1 스크린샷에 화살표·설명

1. `Win` + `Shift` + `S` → 영역 캡처 
2. 그림판 `Ctrl` + `V` 
3. 도형에서 화살표·사각형 
4. 텍스트로 한 줄 메모 
5. PNG 저장 → 메신저·문서 첨부 

### 10.2 증명사진·아이콘용으로 정사각 리사이즈

1. 열기 → 선택·자르기로 주제만 
2. 크기 조정에서 가로=세로 픽셀 지정 (비율 유지 off일 수 있음 — 왜곡 주의) 
3. PNG 저장 

### 10.3 로고 배경 없애기

1. PNG로 열기 
2. 배경 제거(AI) 또는 채우기/지우개로 배경 정리 
3. 레이어로 확인 후 PNG 저장 
4. 흰 배경 PPT에 올려 투명 여부 확인 

### 10.4 여러 캡처를 한 장에

1. 캔버스 크기를 넉넉히 (`Ctrl` + `W`로 캔버스 확대 — UI에 “캔버스”/이미지 크기 구분 주의) 
2. 각 캡처를 붙여넣고 이동 
3. (가능하면) 캡처마다 레이어 

이미지 크기와 **캔버스 크기**를 헷갈리면 잘리거나 여백이 생긴다. 
“전체 그림 키우기” vs “해상도만 키우기”를 대화상자에서 구분한다.

|------|------|

| AI 생성물 무단 상업 이용 | 약관 위반 가능 |
