# 메모 앱

> **분류:** 작성·지식 › 노트·지식 · [[생활위키 목차]]

**메모 앱**은 생각·할 일·자료를 **적어 두고 나중에 찾는** 도구다. 
같은 “메모”라도 **빠른 캡처**, **팀 공유·DB**, **로컬 위키**, **마크다운 글쓰기**처럼 목적이 다르다.

이 글은 **에버노트(Evernote)**, **구글 킵(Google Keep)**, **노션(Notion)**, **옵시디언(Obsidian)**, **타이포라(Typora)** 를 한곳에서 비교하고, **무엇을 어디에 둘지** 정하는 데 쓴다.  
노션·옵시디언 상세는 [[Notion 사용법]] · [[Obsidian 사용법]].

확인일: 2026-08-11

관련: [[Obsidian 사용법]] · [[Notion 사용법]] · [[Microsoft To Do 사용법]] · [[Quartz 사용법]] · [[Cursor 사용법]] · [[웹 드라이브 비교]]

---

## 1. 개요

| 축 | 설명 |
|----|------|
| **캡처** | 생각이 날 때 **3초 안**에 적기 (Keep, 킵 단축) |
| **정리** | 노트북·태그·폴더·DB로 **나중에 찾기** (Evernote, Notion) |
| **연결** | 글끼리 **링크·그래프** (Obsidian) |
| **글쓰기** | 마크다운으로 **읽기 좋은 문서** (Typora, Obsidian) |
| **협업** | 팀 **권한·댓글·DB** (Notion) |
| **소유** | 데이터가 **내 PC 폴더**인지 **회사 서버**인지 |

```text
떠오름 → (Keep / Evernote 빠른 메모)
 ↓
정리·공유 → (Notion DB / Evernote 노트북)
 ↓
장기 지식·위키 → (Obsidian vault + [[위키링크]])
 ↓
공개 사이트 → ([[Quartz 사용법]] 등)
```

한 앱이 **전부**를 잘하는 경우는 드물다. **역할을 나누는** 편이 덜 망가진다.

## 2. 요약 비교

| | Evernote | Google Keep | Notion | Obsidian | Typora |
|--|----------|-------------|--------|----------|--------|
| **정체** | 클라우드 **메모·클리핑** | **빠른 스티키** 메모 | **페이지+DB** 워크스페이스 | **로컬 위키** vault | **마크다운 에디터** |
| **데이터** | Evernote 서버 | Google 계정 | Notion 서버 | **로컬 `.md`** | **로컬 `.md`** |
| **강점** | 웹 **클리퍼**, 검색 | 속도·알림·라벨 | 팀 DB·칸반·템플릿 | `[[링크]]`·그래프·플러그인 | WYSIWYM·집중 글쓰기 |
| **약점** | 유료·구조 무거움 | 장문·위키에 약함 | 오프라인·로컬 소유 | 협업·DB는 Notion보다 약함 | vault·DB 없음 |
| **이 vault** | 참고·이전 자료 | 임시 메모 | 팀·DB 병행 가능 | **본체** | 초안·단일 글 편집 |

## 3. Evernote (에버노트)

공식: [https://evernote.com](https://evernote.com)

| 항목   | 설명                                                                                 |     |
| ---- | ---------------------------------------------------------------------------------- | --- |
| 무엇   | 오래된 **클라우드 메모** 서비스. 노트북·태그·첨부·**웹 클리퍼**                                           |     |
| 잘 맞음 | 웹·PDF **저장**, 여러 기기 **동기화**, “찾아보관”                                                |     |
| 형식   | 과거 독점 형식 비중이 컸으나, **보내기·이전** 도구가 있다                                                |     |
| 요금   | 무료는 **기기 수·업로드** 등 제한. 플랜은 공식 페이지 확인                                               |     |
| 이전   | [[Notion 사용법]]에서 **Evernote 가져오기** 지원. Obsidian으로는 enex 등 **변환** 후 vault에 넣는 경우 많음 |     |

**언제 쓸지:** 아직 Evernote에 자료가 많거나, **브라우저 클리핑**이 습관일 때.  
**새로 시작**한다면 Keep(가벼움)·Notion(팀)·Obsidian(위키)과 **목적**을 비교해 고른다.

## 4. Google Keep (구글 킵)

공식: [https://keep.google.com](https://keep.google.com) · 앱: Android 기본에 가깝게 쓰이는 경우 많음

| 항목 | 설명 |
|------|------|
| 무엇 | **색 스티키**·체크리스트·라벨·**알림·위치** |
| 잘 맞음 | **초 단위** 메모, 장보기·할 일·전화 번호 한 줄 |
| 약점 | 긴 글·버전 관리·위키 링크·폴더 구조 |
| 연동 | Google 계정. Gmail·Calendar와 **같은 생태계** |
|보내기 | Google Takeout 등으로 백업 가능 — **장기 위키 본체**로는 보통 안 씀 |

**언제 쓸지:** 폰에서 **즉시** 적고, 나중에 Notion·Obsidian으로 **옮길** 짧은 것.  
생활위키 본문은 Keep에 두지 않고, `private/` 또는 Obsidian vault로 **정리**하는 편이 낫다 ([[공개 규칙]]).

## 5. Notion (노션)

상세: [[Notion 사용법]]

| 항목 | 설명 |
|------|------|
| 무엇 | **블록** 페이지 + **데이터베이스**(표·칸반·캘린더) |
| 잘 맞음 | 팀 **회의록·프로젝트·CRM**, 공유 위키, 대시보드 |
| 데이터 | **Notion 서버**. 오프라인·로컬 파일 소유는 Obsidian보다 약함 |
| AI | 플랜에 따라 Notion AI — [[현존 AI 비교]] |
| 이 vault와 | **로컬 md 위키**는 Obsidian. Notion은 **공유·DB** 쪽 |

**언제 쓸지:** 가족·팀과 **같은 표**로 일할 때. 개인 장기 지식은 [[Obsidian 사용법]]과 **병행**.

## 6. Obsidian (옵시디언)

상세: [[Obsidian 사용법]]

| 항목 | 설명 |
|------|------|
| 무엇 | PC **폴더(vault)** 안의 `.md`를 `[[위키링크]]`로 연결 |
| 잘 맞음 | 개인 **지식 위키**, MOC·태그·그래프, **툴 독립** (Git·[[Quartz 사용법]]) |
| 동기화 | Obsidian Sync(유료), iCloud·OneDrive·Syncthing 등 **폴더 동기화** — [[웹 드라이브 비교]] |
| 편집 보조 | [[Cursor 사용법]]·[[VS Code 사용법]]으로 같은 폴더 열기 가능 |
| 이 생활위키 | vault 루트 = `생활위키/` · 공개는 [[Quartz 사용법]] + `publish: true` |

**언제 쓸지:** 글을 **파일로 소유**하고 링크로 키울 때. **메모 앱 중 이 vault의 중심.**

---

## 7. Typora (타이포라)

공식: [https://typora.io](https://typora.io)

| 항목        | 설명                                                      |
| --------- | ------------------------------------------------------- |
| 무엇        | **마크다운 WYSIWYM** 에디터 — 입력하면 바로 서식이 보임                   |
| 잘 맞음      | **한 편의 글**·보고서·README를 md로 **예쁘게** 쓰기                   |
| Obsidian과 | Obsidian = **vault·링크·그래프**. Typora = **단일 파일 글쓰기**에 강함 |
| 동기화       | 앱 자체 동기화 없음 — **폴더**를 OneDrive 등으로 ([[웹 드라이브 비교]])      |
| 보내기       | PDF·HTML·Word 등 — 배포용 초안                                |

**언제 쓸지:** 위키 **한 글**을 집중해서 다듬을 때. 완성본을 Obsidian vault에 **저장**해 `[[링크]]`로 묶는다.  
전체 지식 구조는 Typora가 아니라 **Obsidian**이 맡는다.

```text
Typora로 초안·교정 → vault에 .md 저장 → Obsidian에서 링크·목차
```

## 8. 역할 나누기 (예시)

| 넣을 것      | 추천                                    | 이유        |
| --------- | ------------------------------------- | --------- |
| 장보기·1분 메모 | **Keep**                              | 속도        |
| 웹 기사 저장   | **Evernote** 클리퍼 또는 Obsidian 클리퍼 플러그인 | 습관에 따름    |
| 팀 할 일·회의  | **Notion**                            | DB·권한     |
| 개인·Outlook 할 일 | **Microsoft To Do**               | My Day·플래그 메일 |
| 개인 위키·학습  | **Obsidian**                          | 로컬 md·링크  |
| 긴 글 집필    | **Typora** 또는 Cursor                  | 서식·AI 초안  |
| 이 사이트 공개  | Obsidian + **[[Quartz 사용법]]**             | 정적 사이트    |
| 민감 정보     | `private/` · `publish: false`         | [[공개 규칙]] |

**이중 기록**은 피한다. “최종본은 Obsidian”처럼 **한곳을 정**하고 나머지는 **임시·공유**로 둔다.

## 10. 이 생활위키와의 관계

```text
Keep / Evernote  →  임시·클리핑 (선택)
Notion           →  팀·DB (선택)
Obsidian vault   →  생활위키 .md 본체
Cursor           →  초안·일괄 수정 ([[Cursor 사용법]])
Typora           →  단일 글 다듬기 (선택)
Quartz           →  publish: true 만 웹 공개
```

[[생활위키 목차]]는 Obsidian에서 **MOC**처럼 쓰는 입구다. 메모 앱을 바꿔도 **폴더 안 md**만 지키면 이식이 쉽다.

---

## 11. 실전 체크

- [ ] **임시**와 **본문** 앱을 구분했는가  
- [ ] 민감 메모는 `private/` 또는 비공개 플랜인가 ([[공개 규칙]])  
- [ ] Obsidian vault를 **백업**(Git·클라우드)하고 있는가  
- [ ] Notion만에 중요 자료를 **한곳에만** 두지 않았는가  
- [ ] Typora·Obsidian **같은 파일**을 동시에 열 때 충돌을 아는가  
- [ ] 팀 문서는 Notion, 개인 위키는 Obsidian처럼 **역할**이 겹치지 않는가

## 12. 정리

|----|--------|
| Evernote | 클라우드 메모·**웹 클리핑**·검색 |

## 면책

> **면책**  
> - 요금·기기 제한·기능은 **공식 사이트**가 우선. 이 글은 가입·유료 권유가 아니다.  
> - 클라우드 메모는 **계정·서비스 종료·동기화 오류** 위험이 있다. 중요 자료는 **백업**한다.  
> - 건강·금융·법률 메모는 공개 위키에 올리지 않는다.
