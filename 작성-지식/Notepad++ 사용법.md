# Notepad++ 사용법

> **분류:** 작성·지식 › 에디터·IDE · [[생활위키 목차]]

Windows용 **가벼운 텍스트 에디터**. 메모장보다 훨씬 강하고, VS Code보다는 단순하다.  
로그·설정 파일·인코딩 변환·정규식 일괄 치환·매크로에 특히 잘 맞는다.

설치: [https://notepad-plus-plus.org](https://notepad-plus-plus.org)  
매뉴얼: [https://npp-user-manual.org](https://npp-user-manual.org)

아래는 Windows 기본 단축키 기준. `설정 → 단축키 매퍼`에서 바꿀 수 있다.

---

## 1. 언제 쓰나

| 잘 맞음 | 다른 도구가 나을 때 |
|---------|---------------------|
| 설정 파일·로그·CSV를 빨리 열고 고치기 | 큰 코드 프로젝트 → [[VS Code 사용법\|VS Code]] / [[Cursor 사용법\|Cursor]] |
| 인코딩(UTF-8 / CP949) 확인·변환 | 위키링크·노트 그래프 → [[Obsidian 사용법\|Obsidian]] |
| 정규식으로 여러 파일 일괄 치환 | 폴더 트리 통째 비교 → [[WinMerge 사용법\|WinMerge]] |
| 탭 여러 개 + 매크로로 반복 작업 | AI로 코드 수정 → Cursor |
| 설치 거의 없이 “그냥 텍스트” | 팀 DB·공유 문서 → [[Notion 사용법\|Notion]] |

한 줄: **빠른 텍스트 수술 도구**. IDE 대체는 아니다.

---

## 2. 설치·한글·휴대용

1. 공식 사이트에서 Installer 또는 **portable**(ZIP) 받기
2. 설치 시 언어에 Korean이 있으면 선택. 없으면 `설정 → 환경설정 → 일반 → 현지화`
3. 탐색기에서 “Notepad++로 편집” 통합은 설치 옵션으로 켤 수 있다

portable은 USB에 넣고 설정까지 같이 다니기 좋다.

## 3. 화면 구성

```text
┌──────────┬────────────────────────────┐
│ 폴더     │  탭1 | 탭2 | 탭3 …         │
│ 워크스   ├────────────────────────────┤
│ 페이스   │         편집 영역            │
│ (선택)   │                            │
└──────────┴────────────────────────────┘
              상태바: 줄·인코딩·언어 …
```

| 영역 | 하는 일 |
|------|---------|
| 탭 | 연 파일들. 더블클릭으로 닫기 옵션 가능 |
| 편집 영역 | 본문. 줄 번호, 북마크 여백 |
| 상태바 | 줄/칸, 문서 길이, 인코딩, 줄바꿈(Windows/Unix), 언어 |
| 폴더 패널 | `보기 → 폴더 as 워크스페이스` 등으로 디렉터리 트리 |

다크 톤: `설정 → 스타일 구성 관리자`에서 테마 선택 (예: Dark mode 계열).

| 열기 | `Ctrl + O` |

| 모두 저장 | `Ctrl + Shift + S` |
| 닫기 | `Ctrl + W` |
| 모두 닫기 | `Ctrl + Shift + W` |
| 최근 파일 | `파일 → 최근 사용` |
| 새로고침(디스크에서 다시) | 파일이 외부에서 바뀌면 안내 후 다시 로드 |

### 편집

| 동작 | 단축키 |
|------|--------|
| 실행 취소 / 다시 | `Ctrl + Z` / `Ctrl + Y` |
| 줄 복제 | `Ctrl + D` |
| 줄 삭제 | `Ctrl + L` (버전에 따라 `Ctrl + Shift + L`) |
| 줄 위/아래 이동 | `Ctrl + Shift + ↑/↓` |
| 주석 토글 (언어에 따라) | `Ctrl + Q` |
| 들여쓰기 / 내어쓰기 | `Tab` / `Shift + Tab` |
| 모두 선택 | `Ctrl + A` |
| 대문자 / 소문자 | `Ctrl + Shift + U` / `Ctrl + U` |

### 이동·북마크

| 동작 | 단축키 |
|------|--------|
| 줄로 이동 | `Ctrl + G` |
| 짝 괄호로 | `Ctrl + B` |
| 북마크 토글 | `Ctrl + F2` |
| 다음/이전 북마크 | `F2` / `Shift + F2` |
| 시작/끝으로 | `Ctrl + Home` / `Ctrl + End` |

여백(줄 번호 왼쪽)을 클릭해도 북마크가 토글된다. 로그에서 “나중에 볼 줄”을 찍어 두기 좋다.

## 5. 찾기·바꾸기 (가장 중요한 기능)

| 동작 | 단축키 |
|------|--------|
| 찾기 | `Ctrl + F` |
| 바꾸기 | `Ctrl + H` |
| 파일에서 찾기 | `Ctrl + Shift + F` |
| 표시(Mark) | `Ctrl + M` |
| 다음 / 이전 | `F3` / `Shift + F3` |
| 선택 단어로 다음 | `Ctrl + F3` |
| 증분 검색 | `Ctrl + Alt + I` |

### 찾기 옵션

대화상자에서:

- **일치하는 단어만** — `test`가 `testing`에 안 걸리게
- **대/소문자 구분**
- **둘러싸기** — 끝까지 가면 처음부터
- **검색 모드**
  - 일반
  - 확장 (`\n` `\t` `\r` 등)
  - **정규식**

### 바꾸기 팁

1. 한 건씩: 찾기 다음 → 바꾸기
2. 문서 전체: **모두 바꾸기**
3. 실수 방지: 먼저 `모두 찾기` / `개수`로 몇 건인지 확인
4. 확장 모드에서 줄바꿈 넣기: `\r\n` (Windows), `\n` (Unix)

### 파일에서 찾기 / 바꾸기

`Ctrl + Shift + F`

- 찾을 폴더 지정
- 필터: `*.log;*.txt;*.cfg`
- 하위 폴더 포함
- 결과 창에서 더블클릭 → 해당 파일·줄로 이동
- **파일에서 바꾸기**는 되돌리기 어려우니 백업 후 실행

### 표시(Mark)

검색어가 나오는 줄을 색/북마크로 남겨 둔다.  
로그에서 에러만 칠해 두고 스크롤할 때 유용. 지우기는 Mark 대화상자의 Clear.

## 6. 정규식 맛보기

검색 모드를 **정규식**으로.

| 패턴 | 의미 |
|------|------|
| `.` | 아무 문자 하나 |
| `.*` | 아무 문자열 |
| `\d` | 숫자 |
| `\w` | 단어 문자 |
| `^` | 줄 시작 |
| `$` | 줄 끝 |
| `(...)` | 그룹 (바꾸기에서 `\1` `\2`) |

예:

- 빈 줄 찾기: `^\s*$`
- `foo=숫자`를 `foo:숫자`로: `foo=(\d+)` → `foo:\1`
- 줄 끝에 `;` 붙이기: `$` → `;` (신중히, 이미 있는 줄 제외 조건 필요)

정규식이 복잡하면 한 파일에서 테스트한 뒤 파일에서 찾기로 확장한다.

공식 검색 문서: [Searching](https://npp-user-manual.org/docs/searching/)

## 7. 인코딩·줄바꿈 (한글 깨짐 해결)

상태바 오른쪽에서 인코딩·줄바꿈 확인.

| 메뉴 | 언제 |
|------|------|
| `인코딩 → UTF-8` 등으로 **변환** | 저장 형식을 바꿀 때 |
| `인코딩 → 문자 집합 → …`로 **해석만** | 깨져 보일 때 “이 인코딩으로 다시 읽어보기” |

실전:

1. 한국어 구형 파일이 깨지면 **ANSI / EUC-KR / Windows-1252** 등을 번갈아 해석해 본다  
   (메뉴 이름은 버전에 따라 `한국어`·코드 페이지로 표시)
2. 맞게 보이면 **UTF-8로 변환** 후 저장해 앞으로 깨짐을 줄인다
3. UTF-8 BOM 유무도 옵션에 있다. 일부 구형 도구는 BOM을 싫어한다

줄바꿈:

- Windows: `CRLF` (`\r\n`)
- Unix/macOS: `LF` (`\n`)
- `편집 → 줄 끝 형식 변환`

스크립트·Git 저장소와 맞출 때 중요하다.

## 8. 문법 강조·언어

`언어` 메뉴에서 HTML, Python, JSON, XML, SQL 등 선택.  
확장자를 알면 자동 감지하는 경우가 많다.

JSON/XML이 한 줄로 뭉쳐 있으면:

- 플러그인(예: JSON Viewer) 또는
- 외부 포매터 / VS Code로 정렬  

Notepad++ 기본만으로도 색 구분은 되지만, 프로젝트 단위 IntelliSense는 기대하지 않는 편이 좋다.

탭 vs 스페이스: `설정 → 환경설정 → 언어` / 탭 설정에서 탭 크기·스페이스로 바꾸기.

## 9. 다중 커서·열 모드

| 기능 | 방법 |
|------|------|
| 열(칼럼) 선택 | `Alt` + 마우스 드래그 |
| 사각형 편집 | 열 모드로 같은 위치에 문자 삽입 |

고정 폭 로그·정렬된 텍스트에서 열 삭제가 특히 편하다.

## 10. 매크로 — 반복 작업 녹화

1. `매크로 → 녹음 시작` (툴바 빨간 버튼 / `Ctrl + Shift + R`인 빌드도 있음)
2. 평소처럼 편집·찾기·바꾸기 수행
3. `녹음 중지`
4. `매크로 실행` 또는 **매크로를 여러 번 실행** (문서 끝까지)
5. 필요하면 **현재 녹음된 매크로 저장** + 단축키 부여

주의:

- 커서 위치 기준으로 상대 동작한다. 시작 위치를 맞출 것
- 복잡한 분기·조건은 매크로보다 스크립트 플러그인(PythonScript 등)
- 저장 위치는 설정 파일(`shortcuts.xml` 등). 수동 편집은 백업 후

매뉴얼: [Macros](https://npp-user-manual.org/docs/macros/)

## 11. 플러그인

`플러그인 → 플러그인 관리…` (Plugin Admin)

체크 → 설치 → Notepad++ 재시작.

인기·실용 예 (필요만):

| 플러그인 | 용도 |
|----------|------|
| Compare | 두 파일 diff (간단 비교). 본격 폴더는 WinMerge |
| NppFTP | 원격 파일 편집 |
| Markdown 관련 | 미리보기 |
| JSON Viewer | JSON 트리·포맷 |
| DSpellCheck | 맞춤법 |
| PythonScript | 스크립트로 자동화 |

플러그인을 잔뜩 깔면 시작이 느려지고 업그레이드 때 충돌이 난다. **쓰는 것만**.

## 12. 세션·작업 이어서

하루 종일 탭을 많이 열어 두면:

- `파일 → 세션 저장` / `세션 불러오기`
- 또는 종료 시 다음 실행에 파일 다시 열기 옵션 (`환경설정 → 백업`)

워크스페이스처럼 “이 프로젝트 탭 묶음”을 세션 파일로 보관할 수 있다.

## 14. 실전 시나리오

### 14.1 로그에서 에러만 보기

1. 로그 파일 열기
2. `Ctrl + M` → `ERROR` 표시
3. `F2`로 북마크 점프  
   또는 `Ctrl + F`로 순회

### 14.2 CSV에서 특정 컬럼 값 일괄 수정

1. 백업 복사
2. `Ctrl + H` 정규식 또는 확장 모드
3. 소수 건만 바꾼 뒤 확인 → 모두 바꾸기
4. 엑셀에서 다시 열어 검증

### 14.3 한글 깨진 설정 파일

1. 인코딩 메뉴에서 해석만 바꿔 가며 복구
2. 정상 표시되면 UTF-8로 변환 저장
3. 그 파일을 읽는 프로그램이 UTF-8을 지원하는지 확인

### 14.4 같은 편집을 100줄에

1. 한 줄에서 절차 확정
2. 매크로 녹음
3. “문서 끝까지 실행”

### 14.5 두 설정 파일 비교

- 간단: Compare 플러그인
- 폴더·대량: [[WinMerge 사용법]]

## 15. VS Code / Cursor와 역할

| | Notepad++ | VS Code / Cursor |
|--|-----------|------------------|
| 시작 속도 | 매우 빠름 | 상대적으로 무거움 |
| 프로젝트·Git·터미널 | 약함 | 강함 |
| 정규식 치환·인코딩 | 매우 편함 | 가능하지만 UI가 다름 |
| 확장 생태계 | 플러그인 | 확장 + AI(Cursor) |
| 용도 | 단일/소수 파일 수술 | 개발 워크스페이스 |

메모장 대용·긴급 수정·로그 열람은 Notepad++.  
개발은 VS Code/Cursor를 쓰고, “이 파일만 인코딩 고치고 끝”이면 Notepad++로 충분한 경우가 많다.
