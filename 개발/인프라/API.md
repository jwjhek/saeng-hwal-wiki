# API

> **분류:** 개발 › 인프라 · [[생활위키 목차]]

**API**(Application Programming Interface)는 프로그램이 **약속된 방식으로 서로 일을 시키는 면**이다. 화면 버튼이 아니라 **함수·URL·메시지 형식**으로 기능을 연다.

일상에서 「API」라고 하면 대개 **HTTP로 JSON을 주고받는 원격 API**를 가리킨다. [[JDK]]의 `List.add` 같은 **라이브러리 API**, 폰의 카메라 권한 같은 **OS API**도 같은 말이다. 층만 다르다.

확인일: 2026-08-14  
엔드포인트·인증 방식·요금은 **그 서비스 공식 문서**가 우선이다.

관련: [[Spring과 Spring Boot 학습]] · [[Django Flask FastAPI 학습]] · [[OpenAI Platform]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 「무엇을 어떤 형식으로 주면, 무엇을 돌려준다」는 **계약** |
| **누가 쓰나** | 앱·서버·봇·스크립트. 사람이 채팅창을 누르는 것과 **별 과금·별 키**인 경우가 많음 |
| **흔한 형태** | `HTTPS` + `JSON` + 경로(`/v1/orders`) |
| **무엇이 아님** | 데이터베이스 그 자체, 웹사이트 HTML 전체, 비밀번호를 우회하는 뒷문 |

```text
[호출하는 쪽] 앱 · 서버 · curl · 봇
      ↓  요청 (방법, 주소, 헤더, 본문)
[API]
      ↓  응답 (상태 코드, JSON…)
[결과] 데이터 · 에러 · 빈 본문
```

비유: 식당 **메뉴판 + 주문 규칙**. 주방에 들어가 재료를 집는 것(DB 직접 접속)과 다르다.

## 3. 가까운 말

| 말 | 한 줄 |
|----|--------|
| **라이브러리 API** | 같은 프로세스 안 함수. `list.add`, OS 카메라 |
| **원격(웹) API** | 네트워크 너머. 이 글의 중심 |
| **SDK** | 그 API를 감싼 **언어별 라이브러리**. 결국 안에서 HTTP를 보냄 |
| **MCP** | LLM 앱이 외부 도구를 쓰는 **JSON-RPC 규격** → [[MCP]]. 사람용 REST와 다름 |
| **엔드포인트** | 한 기능의 주소. `https://api.example.com/v1/items` |
| **웹훅** | **상대가 우리 URL로** 나중에 POST. GitHub·결제 알림 |
| **GraphQL** | 클라이언트가 **필요한 필드**를 질의문에 씀. REST와 병행 |
| **gRPC** | 내부 서비스끼리. 이진·성능. 브라우저 공개 API로는 덜 흔함 |
| **SOAP** | XML·기업 레거시 연동. 신규 학습은 REST부터 |

「OpenAI API」「카카오 REST API」「JDK API 문서」는 **층이 다른 같은 단어**다. 헤더에 HTTP가 없으면 라이브러리 쪽을 의심한다.

## 4. REST와 HTTP 한 바퀴

현장 공개 API 대부분은 **REST 스타일**(자원 URL + HTTP 방법)에 가깝다. 교과서 REST와 100% 같지는 않아도, 아래 약속이면 읽기 충분하다.

| 방법 | 의도 (흔히) |
|------|-------------|
| **GET** | 조회. 서버 상태를 바꾸지 않는다고 가정 |
| **POST** | 만들기·처리 요청 |
| **PUT** | 전체 교체에 가깝게 수정 |
| **PATCH** | 일부 수정 |
| **DELETE** | 삭제 |

| 상태 | 의미 |
|------|------|
| **200** | 성공, 본문 있음 |
| **201** | 생성됨 |
| **204** | 성공, 본문 없음 |
| **400** | 요청이 잘못됨 |
| **401** | 인증 없음·키 잘못 |
| **403** | 인증은 됐으나 **권한 없음** |
| **404** | 없음 |
| **409** | 충돌 (이미 있음 등) |
| **429** | 너무 자주 침 (**레이트 리밋**) |
| **5xx** | 서버 쪽 오류 |

본문은 **JSON**이 기본이다. XML은 공공·레거시에 남는다.

```text
GET /v1/orders/42 HTTP/1.1
Host: api.example.com
Authorization: Bearer (키는 환경 변수)
Accept: application/json
```

버전을 경로에 넣는 예: `/v1/`, `/v2/`. 앱을 안 바꾸고 서버만 깨면 **호출하는 쪽이 전부 멈춘다**.

## 5. 인증 (방향만)

| 방식 | 메모 |
|------|------|
| **API 키** | 헤더·쿼리. 발급 화면에서 **한 번만** 보이는 경우가 많음 |
| **Bearer 토큰** | `Authorization: Bearer …`. JWT인 경우도 있음 |
| **OAuth 2** | 「구글로 로그인」처럼 **위임**. 앱이 비번을 직접 안 받음 |
| **없음** | 공개 조회만. 쓰기·개인 데이터는 거의 항상 막힘 |

습관:

- 키는 **서버·환경 변수**. 프론트·Git·스크린샷·채팅에 넣지 않는다  
- 유출이면 **즉시 폐기·재발급**. 텔레그램 봇 토큰도 같다 → [[텔레그램 봇]]  
- 거래소는 **출금 권한 없는 키** → [[Freqtrade 사용법]]  
- 최소 권한. 「전부 허용」 키는 사고가 크다  

키를 **훔치거나 우회하는 절차는 적지 않는다.** 보관은 [[Bitwarden 사용법]], 저장소에서 빼는 규칙은 [[Git 사용법]].

## 7. 호출할 때 자주 막히는 점

| 증상 | 먼저 볼 것 |
|------|------------|
| 401·403 | 키·프로젝트·결제 한도. ChatGPT 구독 ≠ Platform 키 |
| 429 | 대기·백오프. 한도를 문서에서 확인 |
| 타임아웃 | `timeout`을 켠다. 무한 대기는 위험 |
| CORS 에러 | **브라우저**가 다른 출처 API를 직접 칠 때. 공개 키를 프론트에 두는 설계부터 의심 |
| 로컬은 되고 서버는 안 됨 | 환경 변수 미설정, HTTP vs HTTPS, IP 허용 목록 |
| 스키마가 어제와 다름 | **버전·필드 폐기**. OpenAPI·변경 로그 |

요금: 챗 구독과 **토큰·호출 과금**이 따로인 서비스가 많다 → [[현존 AI 비교]] · [[OpenAI Platform]].

## 면책

> **면책**
> - **특정 서비스 가입·유료 API 권유가 아니다.**
> - 경로·헤더·모델명·요금·약관은 **제공자가 수시로** 바꾼다. 공식 문서가 우선이다.
> - 키 유출·과도한 권한·출금 가능 키는 **계정·자산 피해**로 이어질 수 있다.
> - 이 글은 개념이다. 타인 시스템 **무단 호출·우회**를 안내하지 않는다.
