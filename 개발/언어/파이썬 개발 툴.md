# 파이썬 개발 툴

> **분류:** 개발 › 언어 · [[생활위키 목차]]

파이썬을 돌리려면 **언어 문법**과 **도구 묶음**이 같이 필요하다. 문법은 [[Python 학습과 패키지]]다. 이 글은 **인터프리터·가상환경·에디터·노트북**이 이 위키에서 어디에 있는지만 지도로 정리한다.

Java는 [[JDK]] 하나에 컴파일·실행이 모인다. 파이썬은 **인터프리터 + venv + 에디터**가 흩어져 있어서, IDE만 바꾸고 환경을 안 맞추면 `No module named`가 난다.

확인일: 2026-08-14  
설치 파일·메뉴 이름은 **python.org · JetBrains · VS Code**가 우선이다.

관련: [[Python 학습과 패키지]] · [[PyCharm 사용법]] · [[Jupyter 노트북]]

---

## 1. 개요

| 층 | 하는 일 | 글 |
|----|---------|-----|
| **인터프리터** | `python` 실행 파일. 버전(3.10+) | 아래 §3. 세부 패키지는 [[Python 학습과 패키지]] |
| **가상환경** | 프로젝트마다 패키지 격리 (venv·conda·uv) | [[Python 학습과 패키지]] §8 |
| **에디터·IDE** | 편집·디버그·Git | [[PyCharm 사용법]] · [[VS Code 사용법]] · [[Cursor 사용법]] |
| **노트북** | 셀 실험 `.ipynb` | [[Jupyter 노트북]] |
| **웹·API** | Django / Flask / FastAPI | [[Django Flask FastAPI 학습]] · [[API]] |
| **품질** | Git, 테스트, 컨테이너 | [[Git 사용법]] · [[Docker 사용법]] |

```text
[인터프리터] python.org / conda / uv
      ↓
[가상환경] .venv 또는 conda env
      ↓
[에디터] PyCharm · VS Code · Cursor
      ↓
[실험] Jupyter   [앱] FastAPI·Django   [봇] 스크립트
```

**무엇이 아님:** 문법 교재, 특정 유료 IDE 광고, Google [[NotebookLM 사용법]](AI 노트).

## 3. 인터프리터

| 항목 | 메모 |
|------|------|
| **받기** | [python.org](https://www.python.org/downloads/) . Windows는 **Add python.exe to PATH** |
| **확인** | `python --version` / `py -3 --version` |
| **권장** | 이 위키 예시는 **3.10+**. 2.x는 제외 |
| **주의** | 스토어 앱·여러 설치본이 겹치면 PATH가 꼬임. `where python` |

데이터 강의가 Anaconda면 인터프리터가 **conda env**다. python.org venv와 **섞지 말 것** → [[Python 학습과 패키지]] §8.1.

IDE가 보는 경로와 터미널 `python`이 다르면, 패키지를 어디에 깔아도 한쪽은 실패한다 → [[PyCharm 사용법]] §4.

---

## 4. 가상환경 · 패키지

한 줄: **프로젝트 폴더마다 환경 하나.** `base`나 시스템 Python에 전부 깔지 않는다.

| 도구 | 언제 | 상세 |
|------|------|------|
| **venv + pip** | 기본. 웹·스크립트 | [[Python 학습과 패키지]] §8.2 |
| **uv** | 빠른 설치. PyCharm 마법사가 권하는 경우 | 같은 글 §8.3 |
| **conda** | 과학·바이너리 의존 | §8.1 |
| **Poetry 등** | 라이브러리를 배포할 때 | §8.3 |

`requirements.txt` 또는 `environment.yml`을 Git에 넣고, 키는 넣지 않는다 → [[Git 사용법]] · [[Bitwarden 사용법]].

---

## 5. 에디터 · IDE 고르기

구매 권유가 아니다. **회사 표준이 있으면 그걸 따른다.**

| 도구 | 잘 맞는 때 | 무게 |
|------|------------|------|
| [[PyCharm 사용법]] | 큰 Python 저장소, 리팩터·디버그, Django | 무거움. 핵심 무료 + Pro |
| [[VS Code 사용법]] | 다언어, 위키, 가벼운 스크립트 | 가벼움. Python·Pylance·Jupyter 확장 → [[VS Code 추천 확장]] |
| [[Cursor 사용법]] | 같은 뼈대 + **에이전트**. 생활위키 작성 | AI 구독은 python과 별개 |
| [[Eclipse 사용법]] | Java·eGov. 파이썬 주력이 아님 | — |

고르는 법:

- 파이썬만 깊게 → PyCharm이 메뉴가 짧다  
- 위키 + 파이썬 + AI → Cursor / VS Code  
- 노트북만 → Lab 또는 IDE의 `.ipynb` → [[Jupyter 노트북]]

세 에디터가 **같은 `.venv`** 를 가리키게 맞추면 충돌이 줄어든다.

## 6. 노트북과 스크립트

| | `.ipynb` ([[Jupyter 노트북]]) | `.py` |
|--|-------------------------------|-------|
| 맞음 | 탐색, 그래프, 수업 | 앱, 봇, 테스트, CI |
| 커널 | 변수 기억. 실행 순서가 함정 | 위에서 아래로 한 번 |
| Git | 출력 때문에 diff가 큼 | 리뷰가 수월 |

실험이 굳으면 노트북에서 **모듈로 옮긴다.** Colab은 커널·패키지가 집 PC와 다를 수 있다.

이름만 노트북인 **NotebookLM**은 코드 실행이 없다 → [[NotebookLM 사용법]].

## 7. 실행 · 테스트 · 주변

| 도구 | 자리 |
|------|------|
| 터미널 | `python app.py`. IDE 실행 구성과 **같은 인터프리터** |
| **pytest** | 테스트. 패키지 표는 [[Python 학습과 패키지]] |
| 포맷·린트 | Ruff·Black 등. VS Code 확장 또는 PyCharm 설정 |
| [[Git 사용법]] | `.venv/` 는 보통 무시. 소스는 커밋 |
| [[Docker 사용법]] | 배포·Freqtrade 공식 경로 |
| [[Playwright]] | 브라우저 E2E. pytest 플러그인 |
| [[OpenAI Platform]] | SDK 호출. 키는 환경 변수 |

디버그는 `print`보다 중단점. PyCharm·VS Code 모두 된다.

## 8. 상황별 세트 (예)

| 상황 | 한 세트 |

| 데이터 수업 | conda 또는 venv + [[Jupyter 노트북]] (+ pandas) |
