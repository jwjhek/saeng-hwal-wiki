# Jupyter 노트북

> **분류:** 개발 › 언어 · [[생활위키 목차]]

**Jupyter 노트북**은 브라우저(또는 IDE)에서 **셀 단위로 코드·설명·그래프**를 섞어 실행하는 문서다. 파일 확장자는 **`.ipynb`**. 문법은 [[Python 학습과 패키지]], 도구 지도는 [[파이썬 개발 툴]], 편집기는 [[PyCharm 사용법]]·[[VS Code 사용법]]을 본다.

공식: [https://jupyter.org](https://jupyter.org)  
설치 안내: [https://jupyter.org/install](https://jupyter.org/install)

확인일: 2026-08-14  
인터페이스 이름(Notebook 7 · JupyterLab)은 버전에 따라 조금 다르다.

**Google [[NotebookLM 사용법]]과 다른 제품이다.** NotebookLM은 PDF를 근거로 묻는 AI 노트다. `.ipynb`를 실행하지 않는다.

관련: [[파이썬 개발 툴]] · [[Python 학습과 패키지]] · [[PyCharm 사용법]] · [[NotebookLM 사용법]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 셀(코드·마크다운) + **커널**(실행 엔진, 대개 Python) |
| **결과** | 표·그래프·출력이 **문서 안에** 남음. 실험·수업·탐색에 맞음 |
| **무엇이 아님** | 웹 서비스 본체([[Django Flask FastAPI 학습]]), AI 자료 노트북([[NotebookLM 사용법]]), 메모장 |
| **조상** | **IPython** 대화형 쉘. 매직 명령(`%`, `%%`)이 여기서 옴 |

```text
.ipynb 파일
  → 노트북 UI (Lab / VS Code / PyCharm / Colab)
  → 커널 (선택한 인터프리터)
  → 셀을 위에서 아래로 — 또는 아무 순서나
```

비유: **실험 노트**. `.py` 스크립트는 레시피 한 장, 노트북은 중간 계산이 적힌 공책이다.

## 3. Notebook · Lab · Colab · IDE

| 환경 | 메모 |
|------|------|
| **JupyterLab** | 지금 로컬의 **기본에 가까운 UI**. 파일 트리·여러 탭. `jupyter lab` |
| **Jupyter Notebook** | 고전 한 파일 화면. 최근 7.x는 Lab 부품을 씀 |
| **Google Colab** | 브라우저·구글 계정. GPU 등 **호스팅**. 런타임이 끊기면 파일이 날아갈 수 있음 |
| [[PyCharm 사용법]] | 프로젝트 인터프리터와 맞춤. 로컬 노트북은 핵심에 포함 |
| VS Code / Cursor | 확장 **Jupyter**. 커널 = 선택한 Python |

같은 `.ipynb`를 옮겨 열 수 있다. **커널(패키지)이 없으면** import가 실패한다. Colab에 있는 패키지가 집 PC venv에 없을 수 있다.

---

## 4. 셀 · 커널 · 실행 순서

| 종류 | 하는 일 |
|------|---------|
| **코드 셀** | Python 실행. 출력이 셀 아래에 붙음 |
| **마크다운 셀** | 제목·설명. 코드가 아님 |
| **커널** | 변수를 **기억**하는 프로세스. 끄면 변수가 사라짐 |

자주 쓰는 조작(로컬 Lab 기준, 키는 설정마다 다름):

| 동작 | 흔히 |
|------|------|
| 셀 실행 | `Shift + Enter` (실행 후 다음 셀) |
| 커널 재시작 | Kernel → Restart. **변수·import가 리셋** |
| 전부 위에서 다시 | Restart & Run All |

**함정:** 셀을 건너뛰거나 아래에서 위로 실행하면, 화면에 그래프가 있어도 **다시 열면 재현이 안 된다.**  
제출·공유 전에 **Restart & Run All**이 통과하는지 본다.

`In [3]` 번호는 **실행한 횟수**이지 파일 순서가 아니다. 번호가 뒤죽박죽이면 순서가 꼬인 신호다.

매직 예: `%pip install …` 는 **그 커널 환경**에 깐다. 터미널 venv와 다르면 또 어긋난다 → [[Python 학습과 패키지]] 가상환경.

## 5. 설치 (로컬)

프로젝트 환경을 켠 뒤:

```text
pip install jupyterlab
jupyter lab
```

conda면 `conda install jupyterlab` (또는 Anaconda 묶음에 이미 있는 경우).  
브라우저가 열리고 터미널에 **주소·토큰**이 보인다. 그 터미널을 닫으면 서버가 끊긴다.

확인: 커널 목록에서 **지금 쓰는 venv/conda** 인지. 시스템 Python으로 열면 패키지가 없다.

회사 PC는 포트·방화벽·오프라인 설치 정책을 본다.

## 6. 어디에 쓰고, 어디에 안 쓰나

| 맞음 | 비추천에 가까움 |
|------|------------------|
| 데이터 훑기, 그래프, 수업, 논문 실험 | **운영 API·장시간 봇** ([[Django Flask FastAPI 학습]]) |
| pandas 한두 장 탐색 | 큰 앱 구조·테스트·CI의 **유일한** 소스 |
| Colab으로 GPU 잠깐 | 비밀 키·개인정보를 **클라우드 셀**에 붙이기 |

익숙해지면 **노트북에서 확인 → `.py` 모듈로 옮기기**가 실무 흐름이다. 노트북만 Git에 쌓이면 리뷰가 힘들다.

키·토큰은 환경 변수. 출력 셀에 키가 찍히면 커밋 전에 지운다 → [[API]] · [[Bitwarden 사용법]] · [[Git 사용법]].

## 7. Git과 용량

`.ipynb`는 JSON이다. **실행 결과(그림·표)** 가 파일 안에 들어가 커밋이 커지고 diff가 읽기 어렵다.

습관:

- 실험 중 결과는 로컬에 두고, 공유본은 **출력 지우기** 또는 nbdime 등 **노트북 diff 도구** (팀 합의)
- 큰 데이터 파일은 노트북 옆에 두고 Git에 올리지 않기
- 재현은 `requirements.txt` / `environment.yml` + Restart & Run All

---

## 8. 보안

노트북은 **그 커널 권한으로 코드를 실행**한다. 모르는 사람이 준 `.ipynb`를 열기만 해도, 환경에 따라 코드가 돌아갈 수 있다.

- 출처 불명 노트북은 **가상환경·가상머신**에서만, 또는 코드를 읽고 실행하지 않는다  
- Colab도 계정·드라이브 권한이 걸린다  
- 이 글은 악성 노트북 **제작 방법을 안내하지 않는다**

## 면책

> **면책**
> - **특정 클라우드·유료 GPU 권유가 아니다.**
> - Lab/Notebook 버전, Colab 한도, IDE 지원은 **각 공식 문서**가 우선이다.
> - 노트북 코드는 본인 환경에서 실행된다. 출처 불명 파일·셀에 붙은 키는 **계정·데이터 피해**로 이어질 수 있다.
