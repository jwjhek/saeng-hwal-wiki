# MBTI

> **분류:** 생활·문화 · [[생활위키 목차]]

**MBTI(Myers-Briggs Type Indicator)** 는 선호 경향을 네 축으로 나눠 **16유형**으로 부르는 **성격 유형 프레임**이다.  
국내에서는 검사·밈·팀 빌딩·소개팅 화제로 흔하고, [[사주팔자]]와 같이 “나를 설명하는 말”로 쓰이기도 한다.

> **면책**  
> - **과학적 확정 진단·채용·연애·진로 처방이 아니다.**  
> - 검사 결과는 그날의 기분·문항 해석·유료/무료 사이트마다 달라질 수 있다.  
> - 임상 성격장애·정신질환 진단과 **다르다** ([[우울장애]], [[강박장애]] 등과 혼동하지 말 것).  
> - 유형으로 사람을 깎아내리거나, 채용·차별의 근거로 쓰지 않는다.  
> - “재미·자기 관찰·대화 소재” 수준이 안전하다.

확인일: 2026-08-07

관련: [[사주팔자]]

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 출처 | 융의 심리유형 논의를 바탕으로 Myers·Briggs가 검사·유형 체계로 정리한 흐름으로 알려짐 |
| 결과 | 네 글자 조합 → 16유형 (예: INFP, ESTJ) |
| 말하는 것 | **선호(preference)** — “항상 그렇게만 행동한다”가 아님 |
| 한계 | 재검사 시 유형이 바뀌는 경우, 학계에서 타당성 논쟁, 바넘 효과(누구에게나 맞는 말) |
| 비슷한 관심 | [[사주팔자]] — 출생 시각 기반의 **다른** 전통 프레임 |

```text
에너지 방향   E ↔ I
정보 수집     S ↔ N
결정 방식     T ↔ F
생활 양식     J ↔ P
        ↓
   16유형 라벨
```

---

## 2. 네 축

| 축 | 한쪽 | 다른쪽 | 감각(과장 없이) |
|----|------|--------|-----------------|
| E / I | 외향(Extraversion) | 내향(Introversion) | 에너지를 **바깥 활동·사람**에서 채우는지, **혼자·안쪽**에서 채우는지 |
| S / N | 감각(Sensing) | 직관(iNtuition) | **구체·현재·경험**을 중시하는지, **패턴·가능성·의미**를 중시하는지 |
| T / F | 사고(Thinking) | 감정(Feeling) | 결정할 때 **논리·기준**을 앞세우는지, **사람·가치·조화**를 앞세우는지 |
| J / P | 판단(Judging) | 인식(Perceiving) | **계획·마감·정리** 쪽이 편한지, **열어 두고 적응** 쪽이 편한지 |

글자만 보고 “I면 사람 싫어함”, “T면 냉혈”처럼 **캐릭터화하면** 틀리기 쉽다.  
같은 유형 안에도 편차가 크다.

## 4. 검사는 어떻게 쓰나

| 단계 | 감각 |
|------|------|
| 문항 | “평소에 더 가까운 쪽”을 고른다. 이상적 나·회사 나를 섞으면 결과가 흔들림 |
| 공식·비공식 | 유료 공식 검사와 무료 웹·앱은 **문항·채점·해석이 다름** |
| 재검사 | 몇 달·스트레스·환경이 바뀌면 글자가 바뀔 수 있음 → **고정 신분증이 아님** |
| 읽기 | 설명이 맞으면 기록. 안 맞으면 억지로 유형에 끼워 넣지 말 것 |

팀·학교에서 쓸 때: **대화 촉진**용. “저 유형이라 승진 불가”는 남용이다.

---

## 5. 인지기능 이야기 (짧게)

일부 커뮤니티는 유형 뒤에 **주기능·보조기능**(예: Ni, Te, Fi…)을 붙인다.  
깊이 파고들면 모형이 갈라지고 논쟁이 많다.  
일상 위키 수준에서는 **네 글자 + ‘선호’** 만으로도 충분하고, 기능 스택은 **선택 심화**다.

## 6. 잘 쓰는 법 · 조심할 점

| 비교적                     | 조심               |
| ----------------------- | ---------------- |
| “요즘 나는 계획보다 즉흥이 편하다” 관찰 | “P라서 평생 미룸”      |
| 갈등 시 상대 축을 짐작해 보기       | 유형으로 낙인·조롱       |
| 직무·공부 환경 취향 힌트          | 적성·자격·노력을 유형이 대체 |
| 재미·소개 말                 | 연애·결혼·투자 결정의 전부  |
| 스트레스 시 평소와 다르게 나옴       | 검사 한 장 = 진짜 나    |

바넘 효과: 두루뭉술한 칭찬·단점이 **누구에게나** 맞아 보이기 쉽다.  
“맞는 말만 모아 둔 해석”인지 한 번 의심한다.

## 7. [[사주팔자]]와 비교

| | MBTI | 사주팔자 |
|--|------|----------|
| 입력 | 자기 보고 문항 | 생년월일(·시) |
| 언어 | 심리·선호 유형 | 천간·지지·오행 등 전통 체계 |
| 변화 | 재검사·성장으로 달라질 수 있음 | 기둥은 고정, **해석**은 사람·유파마다 |
| 공통 | 정체성 이야기·대화 소재로 쓰임 | 동일 |
| 공통 주의 | 결정·차별·사기의 근거로 쓰지 말 것 | 동일 |

둘을 맞춰 보는 건 **취미**다. 서로 모순돼도 “틀린 우주”가 아니다.

## 8. 실전 체크

- [ ] 결과를 **선호 메모**로 두는가 (신분증 아님)  
- [ ] 무료 사이트 별명·운세형 문구에 과몰입하지 않는가  
- [ ] 타인·채용·연애를 유형만으로 판단하지 않는가  
- [ ] 마음이 힘들면 유형이 아니라 [[우울장애]] 등 **도움 경로**를 보는가  
- [ ] 다른 프레임이 궁금하면 [[사주팔자]]  

---

## 9. 정리

MBTI는 **네 축·16유형으로 선호를 이야기하는 도구**다.  
잘 쓰면 자기 관찰과 대화에 도움이 되고, 못 쓰면 낙인·과몰입·사이비 상담으로 간다.  
재미로 두되, 인생 결정은 **현실 정보·상담·시간**에 맡긴다.
