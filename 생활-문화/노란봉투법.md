# 노란봉투법

> **분류:** 생활·문화 · [[생활위키 목차]]

**노란봉투법**은 **정식 법률 이름이 아니다.**  
「**노동조합 및 노동관계조정법**(노조법)」 **제2조·제3조** 등을 개정한 법안 묶음을, **노란봉투 캠페인** 등과 연관 지어 부르는 **별칭**이다.

이 글은 **제도 개요·용어·논쟁 포인트**만 정리한다. **법률·노무 자문이 아니다.**  
최신 조문·시행일은 [국가법령정보센터](https://www.law.go.kr) 등 **공식 자료**를 본다.

확인일: 2026-08-13

관련: [[민식이법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **정식 법률** | 「노동조합 및 노동관계조정법」 등 **일부개정법률** |
| **별칭 유래** | 2014년경 **쌍용자동차** 노사 분쟁 뒤 **손해배상 판결**·**노란봉투 모금**(시민 성금) 사례에서 유래했다는 설명이 흔함 |
| **핵심 쟁점** | 노동쟁의·파업 등으로 생긴 **손해배상**을 **누가·얼마나** 져야 하는가, **사용자(회사) 범위**는 어디까지인가 |
| **입법** | 2025년 국회 본회의 통과·공포 — **시행 2026년 3월 10일** (보도·법령 정보 기준) |
| **적용 시점** | 개정 규정은 **시행 이후** 청구·소송 등에 **어떻게** 적용되는지 **사건마다** 다름 — 전문가 확인 |

```text
노사 분쟁·파업 → 손해 발생
 ↓
기존: 조합원 연대 손배 청구·압류 등 논쟁
 ↓
노조법 제2·3조 개정 (통칭 노란봉투법)
 ↓
손배 청구·책임 분담·감면·신원보증 등 규칙 조정
```

## 2. 개정의 큰 줄기 (중립 요약)

언론·로펌·노무 자료가 공통으로 짚는 **주제**만 나열한다.

### 2.1 제2조 — 사용자·노동쟁의 범위

| 주제              | 개정 방향 (개요)                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------- |
| **사용자**         | 근로계약 당사자가 아니어도 **근로조건을 실질적으로 지배·결정**하는 자를 **사용자**에 포함한다는 취지의 문언 **확장** — **원청·하청** 등 논쟁과 연결 |
| **쟁의행위(파업) 범위** | **근로조건**뿐 아니라 **근로조건에 영향을 미치는 경영상 결정** 등과 관련된 쟁의도 논의 대상이 될 수 있다는 **확대 해석** 논쟁               |

**찬성 측**은 **실질 사용자**·**교섭 대상**을 넓혀 **노동권**을 보강한다고 본다.  
**우려 측**은 **사용자 범위·파업 요건**이 **불명확**해 **경영 결정**까지 쟁점이 되면 **기업 활동**이 **위축**된다고 본다.

### 2.2 제3조 — 손해배상 (핵심)

| 조항 취지 (개요) | 설명 |
|------------------|------|
| **정당한 노조 활동** | 법이 정한 **단체교섭·쟁의행위** 등 **정당한** 활동으로 생긴 손해에 대한 배상 청구 **제한** (종전 실무와 **큰 틀 유사**하다는 해석도 있음) |
| **개별 책임 비율** | 불법 쟁의 등으로 배상 책임이 인정될 때, **조합원 전원 연대**가 아니라 **개인별 역할·참여·기여도**에 따라 **책임 비율** 산정 **의무화** |
| **감면 청구** | 배상 의무자(노조·근로자)가 법원에 **배상액 감면** 청구 가능 — **경제 상태·생계** 등 고려 |
| **신원보증인** | 쟁의행위 손해배상에서 **신원보증인 책임** **배제** (보도·해석 자료 공통) |
| **청구권 남용 금지** | 노조 **존속·활동 방해** 또는 **조합원 활동 견제** **목적**의 손배 청구 **금지** |
| **대응 손해 면제** | 사용자 **불법행위**에 맞서 **부득이** 사용자에게 손해를 가한 경우 **면책** 논지 (요건은 **사건별**) |

## 3. 찬반 논점 (요지만)

| 쪽 | 대표적 주장 |
|----|-------------|
| **개정 찬성·필요** | **과도한 손배·압류**로 노동자 **생계·노조 활동**이 위축됨 → **개별 책임·감면**으로 **인권·단결권** 보호 |
| **개정 우려·반대** | **불법 파업**에 대한 **기업 구제** 약화, **사용자·파업 범위** 확대로 **투자·고용** 불안, **국제 경쟁력** 저하 우려 |
| **중립적 정리** | **노사 모두**에게 **소송·입증** 방식이 바뀜 — 회사는 **개별 귀책 입증**, 노조·근로자는 **감면·분담** 주장 가능 |

이 글은 **입법 정당성**을 판단하지 않는다.

## 4. 흔한 오해

| 오해 | 정리 |
|------|------|
| **「파업하면 회사가 손배 못 받는다」** | **정당한** 쟁의·활동에 대한 **면책** 논리와, **불법** 쟁의에 대한 **배상** 논리가 **구분**됨 — **위법성·정당성**은 **사건마다** 다툼 |
| **「조합원은 무조건 무죄」** | **개별 책임 비율**·**감면**은 **면제가 아니라** 산정·감경 **절차**에 가깝다는 설명이 많음 |
| **「시행 전 사건도 전부 적용」** | **시행일 이전** 분쟁·청구는 **종전 법리·판례**가 남을 수 있음 — **전문가 확인** |
| **「노란봉투 = 모금법」** | 별칭은 **캠페인에서 유래**했을 뿐, 법 내용은 **노조법 개정** |

## 5. 누가 관심 가져야 하나

| 대상 | 이유 |
|------|------|
| **근로자·노조 가입자** | 파업·쟁의 **참여** 시 **손배 소송·압류** 리스크·**신원보증** 조항 변화 |
| **기업·인사·노무** | **손배 청구** 전략·**입증** 부담·**사용자** 범위 |
| **하청·원청** | **사용자** 확대 해석과 **교섭·책임** 논쟁 |
| **일반 시민** | 뉴스 **헤드라인**만으로 **법 전체**를 이해하기 어려움 — **조문 단위** 확인 필요 |

## 6. 확인 방법

1. [국가법령정보센터](https://www.law.go.kr) — **노동조합 및 노동관계조정법** 제2조·제3조 **개정 연혁**  
2. [고용노동부](https://www.moel.go.kr) · **국회 입법 예고·보도자료**  
3. 개별 소송 — **노무사·변호사** 상담 (이 위키 **대체 불가**)

## 면책

> **면책**
> - **법률·노무 자문·소송 전략이 아니다.**
> - 노사 분쟁은 **사실관계·판례**에 따라 결과가 크게 달라진다.
> - 조문·시행·적용 범위는 **개정·해석**될 수 있다.
