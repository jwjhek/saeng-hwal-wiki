# 사주팔자

> **분류:** 생활·문화 · [[생활위키 목차]]

**사주팔자**는 태어난 **년·월·일·시**를 네 기둥으로 두고, 천간·지지·오행 관계로 사람을 읽는 **동아시아 명리 전통**이다.  
한국에서는 작명·궁합·신년 운세·예능·대화 소재로 흔하고, [[MBTI]]처럼 “나를 설명하는 말”로 소비되기도 한다.

확인일: 2026-08-07

관련: [[MBTI]]

---

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 이름 | 사주(네 기둥) + 팔자(간지 여덟 글자)로 부르는 경우가 많음 |
| 입력 | 양력/음력·윤달·**출생 시각**(모르면 시주 추정·생략 논의) |
| 뼈대 | 십천간 · 십이지 · 오행 · (나중에) 십성·신살·대운 등 |
| 중심 | 많은 해석이 **일간(일주의 천간)** 을 “나”로 둠 |
| 한계 | 출생 시각 오차, 역법·써머타임·병원 기록, 해석자 주관 |
| 비슷한 관심 | [[MBTI]] — 문항 기반 **다른** 프레임 |

```text
년주 · 월주 · 일주 · 시주
 (각 기둥 = 천간 + 지지)
        ↓
오행·합·충 등으로 관계 읽기
        ↓
성격·경향·시기(대운) 이야기 — 유파마다 다름
```

---

## 2. 사주가 뭔 말인가

| 말 | 감각 |
|----|------|
| 기둥(주) | 년·월·일·시 각각을 하나의 기둥으로 봄 |
| 천간 | 열 가지 하늘 글자. 오행·음양이 붙음 |
| 지지 | 열두 지지(쥐~돼지에 대응하는 전통 동물 이미지로 알려져 있음) |
| 팔자 | 네 기둥 × (천간+지지) → 글자 여덟 |
| 일간 | 일주 천간. “나의 기질” 이야기의 출발점으로 쓰는 집이 많음 |
| 월주 | 계절·성장 배경 이야기에 자주 등장 |
| 대운·세운 | 나이대·해마다 흐른다는 **시기** 이야기 (유파·계산 방식 상이) |

예능·앱의 “올해 재물운”은 **오락·요약**인 경우가 많다. 원국(사주 전체) 없이 별자리만 보는 서양 점성과도 **체계가 다르다.**

---

## 3. 오행 · 천간 · 지지 (입문)

### 3.1 오행

| 오행 | 자주 붙는 이미지 | 기억 |
|------|------------------|------|
| 목 | 성장·뻗음 | 이미지는 암기용. 해석은 관계로 |
| 화 | 확산·열 | |
| 토 | 매개·안정 | |
| 금 | 수렴·규칙 | |
| 수 | 저장·흐름 | |

상생·상극(서로 돕거나 극함) 이야기로 **균형·과다·부족**을 말하곤 한다.  
“물 사주라 물을 많이 마셔라” 수준의 처방은 **생활 건강과 무관**할 때가 많다.

### 3.2 천간 · 지지

| | 개수 | 감각 |
|--|------|------|
| 천간 | 10 | 갑을병정무기경신임계 — 이름만 알아도 입문 |
| 지지 | 12 | 자축인묘진사오미신유술해 |

음양·오행이 간지에 매핑된다. 표 전체를 외울 필요는 없고, **앱·만세력이 계산**해 주는 집이 많다.  
중요한 건 계산기 결과보다 **누가 어떤 규칙으로 읽느냐**다.

### 3.3 합 · 충 등 (이름만)

| 말 | 감각 |
|----|------|
| 합 | 글자끼리 합쳐진다는 관계 이야기 |
| 충 | 부딪힌다는 관계 이야기 |
| 형·해·파 등 | 유파마다 비중·해석이 다름 |

초보가 처음부터 신살 이름만 모아 “불운 확정”으로 읽으면 공포에 빠지기 쉽다.

## 4. 사람들은 어디에 쓰나

| 쓰임 | 감각 | 주의 |
|------|------|------|
| 자기 이해·대화 | “나는 이런 기질” 이야기 | [[MBTI]]와 같은 과몰입 |
| 작명·개명 | 발음·오행 맞춤 문화 | 법적·행정 절차는 별개 |
| 궁합 | 연애·결혼 화제 | 관계의 전부로 두지 말 것 |
| 신년·이사·취업 택일 | 문화·심리 위안 | 계약·법은 문서·전문가 |
| 유튜브·앱 운세 | 재미·클릭 | 개인 원국 없이 범용 문구 |

## 5. 볼 때 현실 체크

| 체크 | 왜 |
|------|-----|
| 출생 **시각** | 시주가 갈리면 해석이 많이 달라질 수 있음. 모르면 “시 모름”으로 두는 게 정직 |
| 양력·음력·윤달 | 만세력 입력 실수 |
| 시간대·기록 | 옛 기록·추정 출생은 오차 |
| 여러 해석 | 같은 사주에 정반대 조언이 나올 수 있음 |
| 돈 | 상담비·부적·수강 강요 → 냉각기 |
| 결정 | 이직·투자·수술은 **정보·전문가·본인 판단** |

공포형(“당장 끊어야 산다”)·확정형(“너는 평생 ○○”)은 거리 둔다.

## 6. 실전 체크

- [ ] 재미·문화·자기 서사 수준으로 두는가  
- [ ] 출생 시각·역법 입력을 대충 넣지 않았는가  
- [ ] 고액·공포 마케팅에 급히 결제하지 않는가  
- [ ] 연애·채용·돈을 **사주만**으로 정하지 않는가  
- [ ] 불안이 크면 운세보다 생활·의료 도움을 보는가  
- [ ] 유형 이야기도 궁금하면 [[MBTI]]  

---

## 7. 정리

사주팔자는 **출생 네 기둥·간지·오행으로 경향을 이야기하는 전통 프레임**이다.  
한국 일상·미디어에 깊게 들어와 있지만, **미래 확정·치료·투자 지침이 아니다.**  
[[MBTI]]와 같이 “나를 말하는 언어”로 쓰되, 결정은 현실에 둔다.

---

## 면책

> **면책**  
> - **과학적 예측·의학·투자·법률 자문이 아니다.**  
> - 유파·앱·역술인마다 해석이 달라 **정답이 하나라고 보기 어렵다.**  
> - 고액 신점·공포 마케팅·“액막이 결제” 강요는 거리 둔다.  
> - 채용·결혼·차별의 근거로 쓰지 않는다.  
> - 불안·우울이 크면 운세보다 **정신건강·생활 상담** ([[우울장애]] 등).
