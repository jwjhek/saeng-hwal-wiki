# 기아 PV5

> **분류:** 자동차 · [[생활위키 목차]]

**기아 PV5**는 기아가 2025년부터 판매하는 **전기 PBV**(Purpose Built Vehicle, 목적 기반 모빌리티)다. 
승합·화물·택시·장애인 이동(WAV)·소형 트럭(오픈베드) 등 **용도별 바디**를 같은 플랫폼에 얹은 **상용·다목적 전기차** 라인업이다.

이 글은 **개념·라인업·제원 요약·살 때 볼 것**을 정리한다.

확인일: 2026-08-11

공식: [기아 PV5](https://www.kia.com/kr/vehicles/pv5-passenger) · 제원·가격은 **당월 카탈로그·대리점** 기준

관련: [[자동차 보험]] · [[운전자 보험]] · [[배달하기]] · [[전기자전거]] · [[케이패스]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **전기(PHEV 아님)** PBV. PV 시리즈 중 **준중형** (PV1·PV7 등은 별도 계획) |
| 플랫폼 | **E-GMP.S** (PBV·상용 전용 전기 플랫폼) |
| 구동 | **전륜** 단일 모터(FF) |
| 배터리 | **51.5kWh**(스탠다드) · **71.2kWh**(롱레인지) NCM 등 (트림·지역별 상이) |
| 생산 | 국내 **화성 EVO Plant East** 등 |
| 슬로건 | Play your Vision — **목적에 맞게** 바디·실내를 고르는 차 |

일반 승용 EV(EV6·EV3)와 달리 **적재·승차 배치·도어 구조**가 업무용에 맞춰진다. 
가족용 MPV만이 아니라 **택시·배송·현장·복지 이동**까지 한 모델군으로 묶인다.

---

## 2. 라인업 (바디 타입)

```text
공통 플랫폼 (E-GMP.S)
 ├─ 패신저 — 승용·가족·택시
 ├─ 카고 — 컴팩트 / 롱, 트윈 스윙 도어
 ├─ WAV — 휠체어 접근 승합
 ├─ 오픈베드 — 2인 소형 픽업형
 └─ 도너모델 등 — 특수 목적 (병원·기관용)
```

| 타입 | 특징 | 흔한 용도 |
|------|------|-----------|
| **패신저** | 해치형 테일게이트, 5~7인승 배치 선택 | 가족, **택시**, 캠핑·레저 개조 |
| **카고** | 적재함, 2~3도어, **최대 적재량** 중시 | **배송·물류**, 현장 자재 |
| **WAV** | 승하차·고정 설비 | **휠체어** 이동 지원 |
| **오픈베드** | 오픈 적재함, 전장 더 김 | 소형 화물·현장 |
| **도너모델** | 2인승 특수 | 의료 이송 등 **기관 주문** |

패신저 좌석 배치 예:

| 이름 | 배치 | 인원 |
|------|------|------|
| **2-3-0** | 2열 3인 | 5인 |
| **2-2-3** | 1열 2인 + 2·3열 | 7인 |

트림은 **베이직**·**플러스**(패신저) 등. 휠·내장·색상은 트림별 제한이 있다.

---

## 3. 제원 (대표·롱레인지 기준)

공인·카탈로그 값은 **트림·타이어·도어 수**마다 다르다. 아래는 **패턴 이해용**이다.

| 항목 | 패신저·카고(컴팩트) 대략 | 오픈베드 등 |
|------|-------------------------|-------------|
| 전장 | 약 **4,495~4,695mm** | 롱바디 **약 5,040mm** |
| 전폭 | **1,895mm** | 동일 |
| 전고 | **1,905mm** 전후 | 약 **1,950mm** |
| 축거 | **2,995mm** | 동일 |
| 배터리 | 51.5 / **71.2 kWh** | 동일 계열 |
| 출력 | 스탠다드 약 **89kW** / 롱레인지 **120kW** | 트림별 |
| 토크 | **250Nm** 전후 | |
| 구동 | 전륜 FF | |
| 타이어 | **16인치** 기본(효율·비용 중시) | |
| 1회 충전 거리 (복합, 공인) | 스탠다드 **약 265~280km** / 롱레인지 **약 355~377km** | 카탈로그 표 참고 |

- 충전구: **전면 중앙**  
- 급속: 조건에 따라 **약 30분**(10→80% 등, 출력·온도·충전기에 따름)  
- 인포테인먼트: **Pleos Connect** 등 PBV 전용 계열  

유럽 일부 카고는 **LFP 43.3kWh** 등 **지역별 배터리**가 다를 수 있다.

## 4. PBV가 일반 전기차와 다른 점

| | 일반 전기 승용 | PV5 (PBV) |
|--|----------------|-----------|
| 목적 | 개인·가족 이동 | **업무·적재·특수** + 승용 |
| 바디 | 고정 차종 | **카고·패신저·WAV** 등 모듈 |
| 실내 | 편의·디자인 | **평바닥·개방 적재·승하차** |
| 휠 | 17~20인치 흔함 | **16인치** 효율 위주 |
| 구매 | 개인·리스 | **법인·택시·플릿** 비중 큼 |
| 개조 | 제한적 | **액세서리·바디 키트** 전제 설계 언급 |

CES 2024 콘셉트에서 **PV1·PV5·PV7** 로드맵이 공개됐고, 양산 1세대 코드명은 **SW1**(2025~).

## 5. 어디에 쓰이나

| 용도 | 왜 PV5가 거론되나 |
|------|-------------------|
| **택시·대리** | 전기 택시 보조금·운행비. 패신저 **베이직(택시)** 트림 |
| **배송·물류** | 카고 **적재량·도어**. [[배달하기]]에서 **자동차** 허용 시 후보 (플랫폼·계약 별도) |
| **가족 MPV** | 7인승·넓은 실내. 다만 **상용차 느낌**·16인치 휠 |
| **복지·WAV** | 휠체어 승하차 설비 |
| **캠핑·밴라이프** | 평바닥·개조 커뮤니티 (출고 상태와 개조는 별개) |
| **현장·소형 화물** | 오픈베드 |

전기 **오토바이·[[전기자전거]]** 와 비교하면 적재·날씨·거리는 유리하고, **취득·보험·주차·충전** 부담은 크다.

## 6. 가격·보조금 (방향만)

가격은 **매월·트림·옵션·세제**에 따라 바뀐다. 공식 **가격표 PDF**를 본다.

| 타입 | 공식 안내 예 (세제 혜택 후·최저가 방향, 시점별 변동) |
|------|------------------------------------------------------|
| 카고 컴팩트 스탠다드 | **약 4,100만 원대~** |
| 패신저 2-3-0 베이직 | **약 4,590만 원대~** |
| 패신저 2-2-3 베이직 | **약 4,660만 원대~** |

| 체크 | |
|------|--|
| **전기차 보조금** | 지자체·차종·연도별 상한·소진 여부 |
| **택시·상용** | 별도 지원·요건 |
| **개소세·취득세** | 전기차 감면 시점 |
| **리스·렌트** | 사업자 **비용 처리** vs 개인 소유 |

구매·할부·리스 **권유가 아니다.** 견적은 대리점·제조사 채널.

## 7. 충전·운행

| 항목 | 메모 |
|------|------|
| 충전 | **완속(가정·업무)** + **급속(50~350kW급)**. 집·차고 **설치 가능 여부** 먼저 |
| 효율 | 공기저항·**16인치**·상용 차체로 승용 대비 **km/kWh**는 카탈로그 표 기준 |
| 겨울 | 전기차 공통 **주행거리 감소** |
| V2L | 트림·마켓별 **외부 급전** 지원 여부는 제원·옵션 확인 |
| 통행료 | [[케이패스]] 등 **하이패스** 등록·전기차 할인 정책은 시점별 확인 |

택시·배송은 **일일 주행·급속 의존도**가 높다. **충전 인프라 계획** 없이 구매하지 않는다.

| 항목 | 설명 |
|------|------|
| **자동차보험** | [[자동차 보험]] — 대인·대물·**자차**, 운전자 범위·연령 |

사고·적재 과적은 **보험 면책·약관** 이슈가 될 수 있다.

## 10. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 기아 **전기 PBV** — 패신저·카고·WAV·오픈베드 등 |
| 플랫폼 | E-GMP.S, 전륜, 51.5 / 71.2kWh급 |
| 강점 | **목적별 바디**, 상용·택시·물류·WAV |
| 약점 | 승용 SUV 대비 **개인 편의·이미지** 트레이드오프, 16인치·상용 느낌 |
| 비용 | **전기차 보조금·보험·충전**까지 묶어서 계산 |

## 면책

> **강한 면책**  
> - **차량 구매·리스·할부·투자 권유가 아니다.**  
> - 가격·제원·보조금·세제·옵션은 **시점·지역·트림**마다 다르다. **기아 공식 카탈로그·대리점**이 우선이다.  
> - 배송·택시·영업용은 **법규·플랫폼·보험** 요건을 별도로 확인한다.  
> - 이 글은 2025~2026년 초반 양산 정보를 바탕으로 한 **일반 정리**이며, 리콜·SW 업데이트는 공지를 따른다.
