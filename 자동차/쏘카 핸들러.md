# 쏘카 핸들러

> **분류:** 자동차 · [[생활위키 목차]]

**쏘카 핸들러**는 쏘카가 운영하는 **카셰어링 탁송·차량 관리** 플랫폼이다. 
[[탁송]] 글의 **공통 개념**(대리운전과 구분, 안전·세금 등)은 상위 글을 보고, 여기서는 **쏘카·핸들러 앱**만 다룬다.

확인일: 2026-08-13

---

## 1. 개요

```text
핸들러 앱 가입 · 면허 인증 · 교육
 ↓
미션(핸들) 목록 확인 → 수락
 ↓
스마트키로 차량 개방 → 이동·작업
 ↓
앱에서 완료·인증(미션 유형별)
 ↓
정산(주기·금액은 앱·약관 기준)
```

| 항목 | 내용 |
|------|------|
| 상위 | [[탁송]] — 차량 이동 일반 |
| 운영 | (주)쏘카 |
| 앱 | **핸들러** 전용 앱 (스토어에서 「핸들러」 검색) |
| 차량 | 쏘카 소유·관리 차 — **실물 키 없이** 앱 **스마트키** |
| 특징 | **승객 없음**. 앱에 뜬 **핸들**(미션) 단위 |

---

## 2. 미션 종류

| 유형 | 설명 |
|------|------|
| **차량 이동(탁송)** | 주차된 차 → **쏘카존·지정 주차장** |
| **주유** | 연료 부족 차 → **주유소** |
| **전기차 충전** | EV → **충전소** |
| **세차·점검** | 세차장 등 **외관·상태** 작업 |
| **현장 대응** | 반납·주차·운영 보조 (미션별 상이) |

**탁송 미션**은 목적지까지 **쏘카 차를 운전**하는 형태다. 
**제한 시간**·**반납 위치**·주차 규칙은 앱 안내를 따른다.

---

## 3. 가입·자격

| 조건 | 설명 |
|------|------|
| **나이** | 만 **24세 이상** (공식·보도 기준) |
| **면허** | 유효 운전면허 — 취득 **1년 이상** 등 (앱 표기) |
| **교육** | 온라인 교육 · **심사** (영업일 며칠) |

쏘카 **대여 고객**(만 21세 등)과 **핸들러** 자격은 **별도**다.

---

## 4. 탁송 미션 수행 (쏘카)

1. **핸들 목록** — 시작·종료 시각, 보상, 출발·도착 확인  
2. **핸들 잡기** — 수락 가능 시각(예: 시작 10분 전~)  
3. 현장 → **스마트키** 개방  
4. **인수** — 외관·연료·위치. 이상 시 **핸들 지원**  
5. [[지도 앱]]·[[티맵]]으로 **목적지** 운전·주차  
6. 앱 **완료** — 사진·인증 필요한 미션은 빠뜨리지 않기  
7. **주차비·통행료** — 영수증 보관 → 실비 청구 (미션·약관별)

### 4.1 취소·페널티

| 상황 | 주의 |
|------|------|
| **수락 후 취소** | **위약금**(예: 1만 원대) |
| **시간 초과** | 할증·미션 삭제 — 차량 이상·교통은 **지원 센터** 먼저 |
| **미인증 완료** | 정산 누락 가능 |

규정은 **앱 공지**가 최종이다.

---

## 5. 보상·정산

| 항목 | 설명 |
|------|------|
| **미션당** | 수천 원~수만 원 이상 (거리·작업·앱 표기) |
| **정산** | 흔히 **월~일** 합산 → **다음 주 수요일** 입금 |
| **쿠폰** | 일부 **쏘카 쿠폰** 보상 미션 — 수락 전 확인 |

시간당 체감·세금은 [[탁송]] §7 참고.

---

## 6. 쏘카 대여와 구분

| | 쏘카 **고객** | **핸들러** |
|--|---------------|------------|
| 앱 | 쏘카 앱 | **핸들러** 앱 |
| 목적 | 차 **대여** 이용 | 차 **이동·관리** 후 보상 |
| 요금 | 대여료 | 미션 **보상** |

---

## 7. 쏘카 핸들러만의 팁

- **집·퇴근 동선** 탁송 미션만 — [[탁송]] §9  
- **주차 영수증** 즉시 촬영  
- **EV 충전·세차** 포함 미션은 **종료 시각** 여유 있게  
- [[배달하기]]와 **시간 겹치는** 수락 피하기  

사고·보험·운전 안전: [[탁송]] §8.
