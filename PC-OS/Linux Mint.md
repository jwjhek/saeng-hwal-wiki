# Linux Mint

> **분류:** PC·OS · [[생활위키 목차]]

**Linux Mint**는 초보·윈도우 이주민에게 자주 추천되는 **데스크톱 리눅스**다. 
우분투(또는 에디션에 따라 Debian) 기반에, 민트만의 메뉴·업데이트·소프트웨어 도구를 얹은 형태가 많다.

비교 전체: [[저사양 PC용 무료 OS]] · 웹 단말 대안: [[ChromeOS Flex]]

확인일: 2026-08-07

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 무엇 | 무료 리눅스 배포판, **윈도우와 비슷한 바탕화면**으로 유명 |
| 에디션 | **Cinnamon**(기본 느낌), **MATE**, **Xfce**(가벼움) 등 |
| 저사양 | 보통 **Xfce**를 먼저 검토. Cinnamon은 예쁜 대신 더 무거울 수 있음 |
| 기반 | 많은 사용자가 쓰는 계열은 **[[Ubuntu]] 기반** Mint → 앱·질문 자료가 많음 |

“민트 리눅스” = 이 배포판을 말한다.

---

## 2. 왜 저사양·구형 PC에서 나오나

- 윈도우 11 요구 사양·지원 종료로 **대안 OS** 수요 
- 시작 메뉴·작업 표시줄이 익숙 
- Timeshift 등 **스냅샷·복구** 도구가 초보에게 심리적 안전장치 
- [[ChromeOS Flex]]보다 **로컬 앱·파일·프린터**에 유리한 편 

램 4GB·SSD면 Xfce로 웹·문서가 무난한 경우가 많다. 
램 2GB대·아주 낡은 PC는 [[Ubuntu]]의 Lubuntu 등 더 가벼운 플레이버나 초경량을 [[저사양 PC용 무료 OS]]에서 본다.

---

## 3. 에디션 고르기

| 에디션 | 설명 |
|--------|------|
| **Cinnamon** | 민트 “대표” UI. 편하지만 저사양에선 부담될 수 있음 |
| **MATE** | 전통적 데스크톱, 중간 무게 |
| **Xfce** | **저사양 추천 후보**로 가장 자주 언급 |

같은 Mint라도 에디션 USB를 **따로** 받아 Live 체험하는 것이 좋다.

---

## 4. [[ChromeOS Flex]]·[[Ubuntu]]와 연결

| | Linux Mint | [[ChromeOS Flex]] | [[Ubuntu]] (GNOME) |
|--|------------|-------------------|---------------------|
| UI | 윈도우에 가까움 | 크롬북·런처 | 개요·제스처형, 이질감 있을 수 있음 |
| 용도 | 범용 데스크톱 | 웹 중심 | 범용(저사양엔 무거울 수 있음) |
| 패키지 | 우분투 저장소와 가까운 길 | 웹·제한적 리눅스 앱 | 동일 계열 저장소 |
| 고를 때 | 로컬 PC를 유지 | 브라우저 머신 | 자료·서버·WSL. 저사양은 Lubuntu/Xubuntu·Mint Xfce |

Mint를 쓰면 **우분투 생태계**를 간접적으로 쓰는 경우가 많다.  
본판·LTS·플레이버·서버는 [[Ubuntu]], 윈도우형 UX는 이 글(Mint)을 본다.

---

## 5. 설치·첫 설정

1. 공식 사이트에서 에디션 ISO · USB 작성 (Ventoy, Rufus, balenaEtcher 등) 
2. Live로 와이파이·한글 입력·소리·터치패드 확인 
3. 설치 — 디스크 구성은 신중(윈도우와 듀얼부팅은 백업·여유 공간) 
4. 업데이트, 언어팩, 타임존 
5. 소프트웨어 관리자에서 필요 앱 (브라우저, 오피스, [[크롬]] 등) 

드라이버(특히 일부 NVIDIA·와이파이)는 추가 설정이 필요할 수 있다. 
은행·보안 프로그램은 **리눅스 미지원**인 경우가 있으니 웹·다른 PC 계획을 둔다.

---

## 6. 장점 / 한계

| 장점 | 한계 |
|------|------|
| 익숙한 UI, 커뮤니티·한글 자료 상대적으로 많음 | 모든 윈도우 프로그램을 Wine으로 해결하진 않음 |
| 무료·광고 OS 아님 | 초기 드라이버·앱 탐색 학습 |
| Xfce로 구형 노트북 연장 | 게임·전문 CAD 등은 케이스별 |
| Flex보다 오프라인·로컬 작업 | “완전 자동 관리”는 Flex 쪽이 단순한 편 |

---

## 7. 실전 체크

- [ ] Xfce / Cinnamon 중 Live로 체감 비교 
- [ ] 백업·USB 체험 완료 
- [ ] 필수 윈도우 앱 목록 → 대체·와인·유지 여부 
- [ ] 웹만이면 [[ChromeOS Flex]]도 후보에 올렸는가 
- [ ] SSD 여부 

---

## 8. 정리

Linux Mint는 **윈도우 대신 쓰기 쉬운 무료 리눅스**로, 저사양에는 **Xfce**가 자주 맞다. 
웹만 필요하면 [[ChromeOS Flex]], 전체 고름은 [[저사양 PC용 무료 OS]]를 본다.
