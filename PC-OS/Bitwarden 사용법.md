# Bitwarden 사용법

> **분류:** PC·OS · [[생활위키 목차]]

**Bitwarden**은 비밀번호·로그인·메모를 **암호화해 저장**하고, 브라우저·PC·폰에서 꺼내 쓰는 **비밀번호 관리자**다.  
클라이언트·서버 코드가 **오픈소스**로 공개되어 있어, 브라우저에만 암호를 맡기는 방식의 대안으로 자주 거론된다.

이 글은 **개념·쓰는 법·주의**다. 특정 플랜·보안 감사를 **보장하지 않는다.**

공식: [https://bitwarden.com](https://bitwarden.com)  
도움말: [https://bitwarden.com/help](https://bitwarden.com/help)

확인일: 2026-08-13

관련: [[크롬 사용법]] · [[윈도우 사용법]] · [[갤럭시 폰 사용법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **하는 일** | 사이트마다 **다른 암호**를 저장·생성·자동 입력 |
| **금고** | 항목이 모인 **볼트**(vault). 서버에는 **암호문**이 올라가는 모델 |
| **열쇠** | **마스터 암호** (+ 기기 잠금·생체). 이게 새면 금고가 열린다 |
| **동기화** | 공식 클라우드, 또는 **직접 서버** (후자는 운영 부담) |
| **플랜** | 개인 **무료** 핵심 + 유료(가족·조직·부가). **구성은 공식 가격표** |

```text
마스터 암호 (머리·암호 관리에만)
 ↓
볼트 잠금 해제
 ↓
항목: 로그인 · 카드 · 신원 · 보안 메모 · (지원 시) 패스키
 ↓
브라우저 확장 · 앱이 해당 사이트에 채움
```

브라우저 저장([[크롬 사용법]] §7)과 **같이 쓰면** 어느 쪽이 최신인지 헷갈린다. **한쪽으로 모으는** 편이 안전하다.

---

## 2. 브라우저 저장과 비교

| | Bitwarden | 브라우저(Chrome 등) |
|--|-----------|---------------------|
| **기기** | PC·폰·다른 브라우저 | 그 브라우저·그 계정 |
| **생성기** | 길이·기호 옵션이 김 | 기본 생성은 있음 |
| **2단계 코드(TOTP)** | 항목에 넣어 **같이** 쓰는 집이 많음 | 보통 별도 앱 |
| **피싱** | 주소(URI)가 맞을 때만 채우게 설정 가능 | 저장 사이트와 비슷해도 속는 경우 |
| **이전** | 내보내기·가져오기 | Google 계정에 묶임 |

어느 쪽이든 **마스터(또는 Google 계정)가 뚫리면** 저장된 로그인이 위험하다. **2단계 인증**을 계정에 켠다.

---

## 3. 설치·계정

1. **공식 사이트·공식 스토어**만 (가짜 확장·앱이 있음)  
2. 계정 만들기 → **마스터 암호** 설정  
3. **힌트**는 남이 추측 못 하게. 힌트만으로 암호가 복구되지는 않음  
4. 클라이언트: **브라우저 확장** + **데스크톱** 또는 **모바일** (필요한 것만)

| 클라이언트 | 쓰임 |
|------------|------|
| **확장** (Chrome·Firefox·Edge 등) | 웹 자동 입력. 일상 핵심 |
| **데스크톱** | Windows·macOS·Linux |
| **모바일** | 앱 로그인·자동 입력 (OS 접근성·자동완성 권한) |
| **CLI** (`bw`) | 스크립트·고급. 초보에게 필수 아님 |
| **웹 볼트** | 브라우저로 금고 화면. 주소가 **공식 도메인**인지 확인 |

회사 PC는 반입 정책·스토어 제한을 본다.

---

## 4. 마스터 암호·잠금

| 규칙 | 이유 |
|------|------|
| **길고 유일** | 다른 사이트와 **재사용 금지** |
| **관리자에 안 넣음** | 닭이 달걀을 품는 꼴. 종이나 **오프라인** 백업 위치를 정함 |
| **잊으면 곤란** | 개인 계정은 **마스터를 모르면 볼트를 못 여는** 설계에 가깝다. 비상 접근·조직 복구는 **플랜·설정**에 따름 |
| **잠금 시간** | 자리 비우면 볼트가 잠기게. 공용 PC는 더 짧게 |
| **PIN·생체** | 편의. **마스터를 기기에 남기는 설정**은 도움말을 읽고 선택 |

피싱: Bitwarden **로그인 화면을 사칭**한 사이트·확장. 주소·게시자를 **매번** 본다.

---

## 5. 항목 쓰기

로그인 항목의 흔한 칸:

| 칸 | 내용 |
|----|------|
| **이름** | 내가 찾는 이름 (은행, GitHub) |
| **사용자 이름** | 이메일 또는 아이디 |
| **암호** | 생성기로 만듦. **사이트마다 다르게** |
| **URI** | `https://example.com` — 자동 완성 **매칭** |
| **TOTP** | 2단계 **시간 코드**. 사이트 2FA와 별개로, **복구 코드는 다른 곳에도** |
| **메모** | 보안 질문 힌트 등. **주민번호·카드 전체**는 최소화 |

```text
새 가입
 ↓
생성기로 암호 만들기 (길이 충분, 사이트 규칙 준수)
 ↓
저장 → 그 사이트 암호는 머릿속에 안 둠
 ↓
기존 약한 암호는 하나씩 교체 (유출 알림 있으면 그 사이트부터)
```

**카드·신원** 항목은 자동 완성에 쓰이지만, 유출 시 피해가 크다. 꼭 넣을지 정한다.

**보내기(Send)** 는 일회 링크처럼 비밀을 잠깐 공유하는 기능이다. 만료·암호를 걸고, 채팅에 **평문 암호를 같이** 보내지 않는다. ([[반디집 사용법]] 암호 zip과 같은 습관)

---

## 6. 자동 입력

1. 확장 잠금 해제  
2. 사이트에서 확장 아이콘 → 항목 선택, 또는 페이지 아이콘  
3. URI가 **다른 도메인**이면 안 채우게 매칭을 조정 (피싱 완화)

앱(모바일)은 OS **자동 완성 서비스**로 Bitwarden을 지정한다. [[갤럭시 폰 사용법]]에서 키보드·자동완성 경로가 버전에 따라 다르다.

브라우저 **자체 저장을 끄면** 중복 제안이 줄어든다.

---

## 7. 2단계 인증 (계정·사이트)

두 층을 섞지 않는다.

| 층 | 역할 |
|----|------|
| **Bitwarden 계정 2단계** | 볼트 로그인에 OTP·보안 키 등. **켜 두는 안내가 많음** |
| **각 사이트 2단계** | 그 서비스 보호. 코드를 볼트 TOTP에 넣으면 **한곳에 몰림** — 편리 vs 볼트 유출 시 같이 위험 |

백업: 사이트 **복구 코드**는 볼트와 **다른 장소**(오프라인)에도 두는 집이 있다.  
[[업비트]]·[[GitHub]]처럼 자산·코드가 걸린 계정은 2단계를 **필수로** 본다.

---

## 8. 가져오기·내보내기·백업

| 작업 | 주의 |
|------|------|
| **가져오기** | Chrome·다른 관리자 CSV. **끝난 뒤 CSV는 삭제** (디스크·휴지통) |
| **내보내기** | 암호화된 내보내기 옵션이 있으면 그쪽. 평문 JSON/CSV는 **금고 통째 유출**과 같음 |
| **백업** | 내보내기 파일을 클라우드 루트에 평문으로 두지 않기. [[웹 드라이브 비교]]는 저장 위치일 뿐 암호화가 아님 |

기기를 바꾸면: 공식 앱 설치 → 같은 계정 → 동기화. **마스터 암호**가 있으면 된다.

---

## 9. 직접 호스팅

공식은 **Bitwarden 서버**를 직접 돌리는 안내가 있다 (Docker 등) → [[Docker 사용법]].  
커뮤니티 **Vaultwarden** 등 호환 서버를 쓰는 사람도 있으나 **비공식**이고, 공식 지원·감사 범위가 다르다.

직접 호스팅은 **백업·업데이트·HTTPS·노출 포트**를 내가 진다. 초보·한 대 PC만이면 **공식 클라우드**가 단순한 경우가 많다.

---

## 10. 보안 습관

- 확장·앱은 **공식 스토어·공식 도메인**만  
- 마스터 암호를 **메일·메신저·위키**에 안 남김 (`private/`에도 암호 본문은 비권장)  
- 공용 PC에서 웹 볼트 썼으면 **로그아웃**  
- 유출 알림(Have I Been Pwned 연동 등, 메뉴는 버전에 따름)이 있으면 **해당 항목부터 교체**  
- [[Git 사용법]] — `.env`·키는 볼트 **보안 메모** 또는 시크릿 저장소. Git에 커밋 금지  
- [[텔레그램 봇]] — 시드·OTP를 봇에 입력하지 않음  

---

## 11. 흔한 오해

| 오해 | 현실 |
|------|------|
| 오픈소스라 **무조건 안전** | 코드가 열려 **검토 가능**. 설치본·피싱·마스터 암호는 별개 |
| 클라우드라 **업체가 내 암호를 읽음** | **설계상** 평문을 서버가 못 읽게 하는 모델. 구현·설정·피싱은 별개 |
| 하나 쓰면 **2단계 필요 없음** | 볼트 계정·중요 사이트는 **2단계가 여전히** 중요 |
| 브라우저 저장과 **둘 다 최신** | 한쪽이 옛 암호면 로그인 실패·혼란 |

---

## 12. 실전 체크

- [ ] 공식 앱·확장만 설치  
- [ ] 마스터 암호가 **유일하고 길며**, 힌트·백업 위치를 정했는가  
- [ ] Bitwarden 계정 **2단계**  
- [ ] 브라우저 저장과 **역할이 겹치지** 않는가  
- [ ] 중요 사이트 암호를 **생성기로 교체** 시작  
- [ ] CSV 내보내기 파일을 디스크에 남기지 않았는가  

---

## 13. 정리

Bitwarden은 **마스터 암호로 여는 암호화 금고**다.  
사이트마다 다른 암호 + 공식 클라이언트 + 2단계가 기본이고, 마스터를 잊거나 피싱에 속으면 도구가 강해질수록 피해가 커진다.
