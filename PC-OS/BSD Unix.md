# BSD Unix

> **분류:** PC·OS · [[생활위키 목차]]

**BSD**(Berkeley Software Distribution)는 1970~80년대 **버클리 대학**에서 AT&T **Unix**를 바탕으로 발전한 **유닉스 계열 운영체제**·코드 계보다. 
오늘날 **FreeBSD**, **OpenBSD**, **NetBSD** 같은 배포판과, **macOS·iOS**의 코어(**Darwin**)가 이 혈통과 연결된다.

리눅스와 함께 “유닉스처럼 쓰는 OS”로 묶이지만, **커널·라이선스·개발 문화**는 다르다. 
일반 PC 대안으로는 [[Linux Mint]]가 훨씬 흔하고, BSD는 **서버·네트워크·애플 생태계·특수 장비** 쪽에서 자주 만난다.

확인일: 2026-08-11

참고: [FreeBSD — BSD에 대한 설명](https://docs.freebsd.org/ko/articles/explaining-bsd/) · [Apple Open Source — Darwin](https://opensource.apple.com/)

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 버클리에서 나온 **Unix 계열** OS·소스 코드 계보. 지금은 여러 **독립 배포판**으로 이어짐 |
| Unix와 | AT&T Unix 소스를 연구·개선하다 **4.4BSD** 등으로 정리. 1990년대 법적 분쟁 후 **자유 배포판**이 갈림 |
| 리눅스와 | 둘 다 **Unix-like**(POSIX·쉘·도구가 비슷). **커널은 별개** — 리눅스는 Linus 커널, BSD는 BSD 커널 계열 |
| 라이선스 | **BSD 라이선스** 계열이 많아 **상업 제품에 코드 재사용**이 쉬운 편 (macOS 등) |
| 데스크톱 | 가능하지만 **점유율·하드웨어·게임·은행 앱** 등에서 리눅스·윈도우보다 니치 |
| 실무에서 | **서버·NAS·방화벽·임베디드**, **macOS 터미널·네트워크 스택**, 일부 **콘솔·가전** |

“BSD = 옛날 Unix”만은 아니다. **지금도 배포판이 살아 있고**, 특히 **애플 OS 코어**에 BSD 코드가 남아 있다.

## 2. 역사 (짧게)

```text
AT&T Unix
 ↓ (버클리 CSRG 연구·개선)
BSD 4.x — TCP/IP·소켓 등 현대 네트워킹의 뿌리
 ↓
1990년대 AT&T vs BSD 저작권 분쟁
 ↓
4.4BSD-Lite (자유 배포) / 상업용 Encumbered 분리
 ↓
386BSD → FreeBSD · NetBSD (1993 전후)
              ↓              ↓
         DragonFly BSD   OpenBSD (1996)
```

| 시기 | 사건 |
|------|------|
| 1970~80년대 | 버클리 **CSRG**가 Unix에 기능 추가. **BSD** 테이프 배포 |
| 1980년대 후반 | BSD에 **TCP/IP** 스택 등이 실질적 표준 역할 |
| 1992~1994 | USL( AT&T 계열)과 **저작권 소송** → 코드 정리·재배포 |
| 1993~ | **386BSD**에서 **FreeBSD**·**NetBSD** 분기 |
| 1996 | **OpenBSD** (NetBSD에서 분기, 보안 강조) |
| 2003 | **DragonFly BSD** (FreeBSD에서 분기) |
| 2000년대~ | **Darwin**(BSD+Mach) 기반 **macOS** 본격화. FreeBSD 등은 서버·임베디드에 지속 사용 |

CSRG(Computer Systems Research Group)는 1995년경 해산했지만, **오픈 소스 BSD 배포판**이 계보를 이어 받았다.

## 3. 주요 BSD 배포판

| 배포판 | 초점 | 흔한 이미지 |
|--------|------|-------------|
| **FreeBSD** | 범용 서버·데스크톱, 성능·생태계 | 웹·DB 서버, **TrueNAS**, 일부 게임·콘솔 OS |
| **OpenBSD** | 보안·코드 검토·보수적 기본값 | **OpenSSH**·**PF** 등이 여기서 나옴. 방화벽·라우터 |
| **NetBSD** | **이식성** — 다양한 CPU·보드 | 오래된 장비·임베디드·연구 |
| **DragonFly BSD** | SMP·스토리지·커널 구조 실험 | 서버·고급 사용자 니치 |

```text
4.4BSD-Lite 계열 (개념)
 ├─ FreeBSD ──→ DragonFly BSD
 ├─ NetBSD ──→ OpenBSD
 └─ (상용·파생) macOS Darwin, BSD/OS(역사) 등
```

배포판마다 **패키지 도구·릴리스 주기·하드웨어 지원**이 다르다. “BSD 하나만 깔면 된다”가 아니라 **목적에 맞는 배포판**을 고른다.

## 4. 리눅스와 비교

| | BSD 계열 | 리눅스 ([[Linux Mint]] 등) |
|--|----------|------------------------------|
| 커널 | FreeBSD·OpenBSD 등 **자체 커널** | **Linux 커널** + GNU/배포판 도구 |
| 라이선스 | BSD·ISC 등 **허용적**이 많음 | GPL 등 **카피레프트** 성격이 강한 구성도 많음 |
| 소프트웨어 | **Ports**·`pkg` 등 (배포판별) | `apt`·`dnf`·Flatpak 등 — **배포판·저장소**가 다양 |
| 데스크톱 | 가능하나 **자료·드라이버·앱**이 상대적으로 적음 | **일반 PC 대체** 자료가 훨씬 많음 |
| 서버 | **FreeBSD**·**OpenBSD** 전통 강함 | **[[Ubuntu]] Server**·RHEL·Debian 등 점유 큼 |
| macOS | **Darwin = BSD 사용자 공간 + Mach/XNU** | 직접 관계 없음 (맥에서 리눅스는 VM·듀얼부팅) |
| 컨테이너 | FreeBSD **jail**, 나중에 **bhyve** 등 | **Docker**·containerd·K8s 생태계가 압도적 ([[Docker 사용법]]) |

**명령어·쉘**(`ls`, `grep`, `ssh`, `man`)은 비슷해서 맥·리눅스 경험이 BSD 서버에도 일부 통한다.  
반대로 **시스템 설정 파일 위치·서비스 관리·패키지 설치**는 배포판마다 다시 익혀야 한다.

## 5. 오늘 어디에 쓰이나

### 5.1 애플 — macOS·iOS·iPadOS 등

- **Darwin**: 오픈 소스 코어. **XNU** 커널 = **Mach** + **BSD 계층**  
- 터미널의 많은 **유닉스 도구**·네트워크 코드가 BSD 계보  
- GUI(**Aqua**)·앱 스토어 등은 **폐쇄 소스** — “macOS = 완전 오픈 BSD”는 **아님**  
- 맥을 쓰면 **이미 BSD 계열 코드**를 간접적으로 쓰는 셈. `man`, `pf`(버전에 따라), 파일 시스템 관례 등이 Unix/BSD 쪽에 가깝다.

### 5.2 서버·인프라

| 용도 | 예 |
|------|-----|
| 웹·앱 서버 | FreeBSD 호스팅, 일부 CDN·스트리밍 백엔드 |
| 저장소 | **TrueNAS** (FreeBSD 기반) |
| 방화벽·라우터 | **pfSense**·**OPNsense**(FreeBSD), OpenBSD 자체 |
| 보안 | OpenSSH는 OpenBSD에서 시작해 **전 세계 표준** |

### 5.3 임베디드·게임·기기

- **PlayStation** 등 일부 콘솔 OS에 FreeBSD 계열 사용 사례  
- **NetBSD**는 “이상한 CPU에도 포팅” 예제로 자주 인용  
- 가전·네트워크 장비에 BSD 코드가 **부분 포함**되는 경우도 있음 (제품마다 다름)

## 6. 일반 사용자 입장

| 질문 | 방향 |
|------|------|
| 구형 PC에 깔까? | 보통은 [[저사양 PC용 무료 OS]] → [[Linux Mint]]·[[ChromeOS Flex]]를 먼저 본다. BSD 데스크톱은 **학습 곡선**이 있다 |
| 맥 사용자 | 이미 **BSD 혈통 OS**를 쓰는 중. 터미널·개발 도구가 Unix/BSD 관례 |
| 윈도우만 쓸 때 | 일상 PC용으로 BSD를 **굳이** 찾을 이유는 적음. 서버·NAS·네트워크 장비를 직접 다룰 때 등장 |

FreeBSD 등도 **데스크톱 환경**(KDE, GNOME 등)을 올릴 수 있지만, **와이파이·노트북 전원·프린터·한글**은 리눅스만큼 “검색하면 답이 쏟아지는” 수준은 아닐 수 있다.

## 7. 개발자·인프라 입장

| 주제 | BSD 쪽에서 자주 나오는 말 |
|------|---------------------------|
| **jail** | FreeBSD의 경량 격리 (리눅스 컨테이너와 비슷한 목적, 구현 다름) |
| **ZFS** | FreeBSD·TrueNAS에서 강조되는 파일시스템·스냅샷 (리눅스에도 포팅 있음) |
| **Ports** | 소스에서 빌드하는 패키지 트리 (`/usr/ports`) |
| **OpenSSH** | 원격 접속 사실상 표준. OpenBSD 프로젝트 기원 |
| **PF** | 패킷 필터·NAT (OpenBSD, macOS 등) |
| **맥 개발** | Xcode·CLI가 Darwin/BSD 관례 — `brew`는 macOS용, FreeBSD는 `pkg` |

[[Docker 사용법]]·[[쿠버네티스]]는 **리눅스 컨테이너**가 중심이다. FreeBSD 서버에 Docker를 쓰는 구성도 있지만, **BSD 네이티브**로 가면 jail·bhyve·네이티브 패키지를 보는 경우가 많다.

[[Git 사용법]]·[[GitHub]]는 OS와 무관하지만, CI·서버 OS 선택 시 **Ubuntu vs FreeBSD** 같은 논의가 나올 수 있다.

## 8. BSD 라이선스 (왜 상업에 많이 쓰이나)

| | BSD·ISC 류 | GPL (리눅스 커널 등) |
|--|------------|------------------------|
| 재배포 | **저작권 표시** 등 조건만 지키면 **독점 소프트에 합쳐 넣기**가 상대적으로 쉬움 | 소스 공개·파생물 조건이 **더 강함** |
| 결과 | **macOS**, 장비 펌웨어, 상용 제품에 BSD 코드 **포함** 사례 많음 | 리눅스는 배포판마다 GPL 구성 요소 관리 필요 |

“오픈 소스 = 전부 같은 규칙”이 **아니다.** BSD 계열은 **허용적 라이선스** 때문에 기업이 가져다 쓰기 편한 면이 있다.

## 9. 고를 때 (BSD vs 리눅스)

```text
집 PC·저사양·한글 데스크톱
 → [[Linux Mint]] · [[저사양 PC용 무료 OS]]

맥·아이폰 개발·일상
 → 이미 Darwin(BSD 계열). Linux VM은 필요 시

서버·NAS·방화벽 직접 운영
 → FreeBSD · TrueNAS · OPNsense / OpenBSD 후보

보안·최소 공격면·라우터
 → OpenBSD

이식·오래된 보드·실험
 → NetBSD

컨테이너·K8s 표준 스택
 → 리눅스 + [[Docker 사용법]] · [[쿠버네티스]]
```

## 10. 실전 체크

- [ ] “BSD”가 **배포판 이름**인지(**FreeBSD** 등) **라이선스·계보**인지 구분했는가  
- [ ] **macOS = BSD**라고만 단순화하지 않았는가 (Mach·폐쇄 GUI 포함)  
- [ ] 데스크톱 대안은 [[Linux Mint]]와 비교했는가  
- [ ] 서버·NAS·방화벽 제품이 **어떤 BSD** 기반인지 확인했는가  
- [ ] Docker·K8s 전제면 **리눅스** 호환성을 우선 봤는가

## 11. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | 버클리 유래 **Unix 계열** OS·코드. Free/Open/Net/DragonFly 등으로 이어짐 |
| 리눅스 | 둘 다 Unix-like, **커널·라이선스·생태계**는 다름 |
| 일상 | **macOS·iOS**가 가장 흔한 BSD 혈통 접점 |
| 인프라 | FreeBSD·OpenBSD는 **서버·보안·네트워크**에 강한 전통 |
| PC 대체 | 일반인은 [[Linux Mint]] 쪽이 현실적. BSD는 **목적 있을 때** |
