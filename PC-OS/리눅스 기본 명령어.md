# 리눅스 기본 명령어

> **분류:** PC·OS · [[생활위키 목차]]

**리눅스·macOS·WSL** 터미널에서 매일 쓰는 **쉘 명령**을 정리한다. 
예시는 **bash** 기준이며, [[Ubuntu]]·[[Linux Mint]]·WSL·SSH 서버에서 그대로 통하는 경우가 많다.

상위 개념: [[리눅스]] · Android 터미널: [[Termux]] · 윈도우: [[윈도우 사용법]]

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **쉘** | 사용자 입력을 받아 프로그램을 실행. **bash**가 기본인 배포판이 많음 |
| **프롬프트** | `user@host:~$` — 여기에 명령 입력 후 **Enter** |
| **경로** | `/` 가 루트. 폴더 구분은 **`/`** (윈도우 `\` 와 다름) |
| **대소문자** | 명령·파일명 **구분** (`File.txt` ≠ `file.txt`) |
| **관리자** | 많은 설치·시스템 변경은 **`sudo`** 필요 |

```text
명령 [옵션] [인자]
예: ls -la /home
```

옵션은 보통 **`-`** 한 글자(`-l`) 또는 **`--`** 긴 이름(`--help`).

---

## 2. 위치·목록·이동

| 명령 | 설명 | 예 |
|------|------|-----|
| `pwd` | **현재 폴더** 경로 출력 | `pwd` |
| `ls` | **목록** | `ls` · `ls -l` · `ls -la` |
| `cd` | **이동** | `cd Documents` · `cd ..` · `cd ~` |

| 기호 | 의미 |
|------|------|
| `~` | 내 홈 (`/home/사용자`) |
| `..` | 한 단계 **위** 폴더 |
| `.` | **현재** 폴더 |
| `/` | **루트** (최상위) |

```bash
cd ~              # 홈으로
cd /var/log       # 절대 경로
cd -              # 직전에 있던 폴더로
```

`ls -l` 은 권한·소유자·크기·날짜를 보여 준다. `ls -a` 는 **숨김 파일**(이름이 `.` 로 시작) 포함.

---

## 3. 파일·폴더 만들기·지우기

| 명령 | 설명 |
|------|------|
| `mkdir 이름` | 폴더 생성 |
| `mkdir -p a/b/c` | 중간 폴더까지 **한 번에** |
| `touch 파일` | 빈 파일 만들기 또는 **수정 시각** 갱신 |
| `rm 파일` | 파일 삭제 |
| `rm -r 폴더` | 폴더 **안까지** 삭제 |
| `rmdir 빈폴더` | **비어 있는** 폴더만 삭제 |

```bash
mkdir projects
touch notes.txt
rm notes.txt
rm -r old_backup    # 복구 어려움 — 신중히
```

**`rm -rf`** 는 확인 없이 지운다. 경로를 **두 번 확인**한다 → §12.

---

## 4. 복사·이동·이름 바꾸기

| 명령 | 설명 |
|------|------|
| `cp 원본 대상` | 복사 |
| `cp -r 폴더 대상` | 폴더 **통째로** 복사 |
| `mv 원본 대상` | 이동 또는 **이름 변경** |

```bash
cp report.txt report_backup.txt
cp -r photos ~/backup/
mv draft.md final.md
```

`mv` 로 같은 폴더 안에서 이름만 바꿀 수 있다.

## 5. 파일 내용 보기

| 명령 | 설명 |
|------|------|
| `cat 파일` | **전체** 출력 (짧은 파일) |
| `less 파일` | **페이지** 단위 (q 로 종료) |
| `head -n 20 파일` | **앞** 20줄 |
| `tail -n 20 파일` | **뒤** 20줄 |
| `tail -f 로그` | **실시간**으로 이어서 보기 (로그 모니터) |

```bash
cat /etc/os-release    # 배포판 정보
less long.log
tail -f /var/log/syslog
```

## 6. 검색

### 6.1 `grep` — 내용 검색

```bash
grep "error" app.log
grep -r "TODO" ~/projects    # 하위 폴더 재귀
grep -i "fail" log.txt       # 대소문자 무시 (-i)
```

### 6.2 `find` — 파일 이름·조건

```bash
find . -name "*.md"
find /var/log -type f -mtime -7   # 7일 이내 수정 파일
```

`.` 은 **현재 폴더**부터다.

---

## 7. 권한 (간단)

`ls -l` 첫 열 예: `-rw-r--r--` · `drwxr-xr-x`

| 기호 | 의미 |
|------|------|
| `r` | 읽기 |
| `w` | 쓰기 |
| `x` | 실행 (폴더는 **들어가기**) |
| `d` | 디렉터리(폴더) |

```bash
chmod +x script.sh    # 실행 허용
chmod 644 file.txt    # 숫자 모드 (고급)
```

시스템 파일은 **`sudo` 없이** 건드리지 않는다.

---

## 8. 파이프·리다이렉트

| 기호 | 설명 |
|------|------|
| `|` | 앞 명령 **출력**을 뒤 명령 **입력**으로 |
| `>` | stdout을 **파일로 덮어쓰기** |
| `>>` | stdout을 **파일 끝에 추가** |
| `2>` | **에러**만 파일로 |

```bash
ls -l | grep ".md"
echo "hello" > out.txt
echo "more" >> out.txt
cat missing.txt 2> err.log
```

---

## 9. `sudo` — 관리자 권한

패키지 설치·시스템 설정은 **root** 권한이 필요하다.

```bash
sudo apt update
sudo systemctl restart nginx
```

- 비밀번호 입력 시 **화면에 안 보이는 것**이 정상  
- 모르는 스크립트를 **`curl | bash`** 로 실행하지 않는다  

---

## 10. 패키지 설치 (Ubuntu·Mint·WSL)

**Debian/Ubuntu** 계열은 **`apt`** 를 쓴다.

```bash
sudo apt update              # 목록 갱신
sudo apt upgrade             # 설치된 패키지 업그레이드
sudo apt install git         # 설치
sudo apt remove 패키지명      # 제거
apt search 키워드             # 검색 (sudo 없이 가능한 경우 많음)
```

[[Git 사용법]]·[[Docker 사용법]] 설치 전에도 `apt` 를 쓰는 경우가 많다.

Fedora는 `dnf`, Arch는 `pacman` — 배포판마다 다름 ([[리눅스]] §4).

## 11. 네트워크·원격

| 명령 | 설명 |
|------|------|
| `ping host` | 연결 확인 (Ctrl+C 로 중지) |
| `curl URL` | HTTP 등 **다운로드·응답** 보기 |
| `wget URL` | 파일 **저장** |
| `ssh user@host` | **원격** 쉘 접속 |
| `scp 파일 user@host:경로` | **복사** (SSH 기반) |

```bash
ping -c 4 example.com
curl -I https://example.com
ssh ubuntu@203.0.113.10
scp report.txt user@server:~/backup/
```

서버 첫 접속 시 **호스트 키** 확인 메시지가 나온다.

## 12. 프로세스

| 명령 | 설명 |
|------|------|
| `ps aux` | 실행 중 프로세스 목록 |
| `top` / `htop` | **실시간** (htop 은 별도 설치) |
| `kill PID` | 프로세스 종료 요청 |
| `kill -9 PID` | **강제** 종료 (최후 수단) |

```bash
ps aux | grep nginx
kill 12345
```

## 13. 도움말

| 방법 | 예 |
|------|-----|
| `--help` | `ls --help` |
| `man` | `man ls` (q 로 종료) |
| `info` | 일부 명령 (`info coreutils`) |

```bash
man grep
whatis ls
```

## 14. 편집기

| 도구 | 설명 |
|------|------|
| **nano** | 초보에게 쉬움. 하단에 단축키 안내 |
| **vim** / **vi** | 서버에 **기본**으로 있는 경우 많음. 학습 곡선 있음 |

```bash
nano notes.txt    # Ctrl+O 저장, Ctrl+X 종료
```

긴 개발은 [[VS Code 사용법]]·WSL·SSH 원격으로 **GUI 에디터**를 쓰기도 한다.

## 15. 습관·단축

| 습관 | 설명 |
|------|------|
| **Tab** | 명령·경로 **자동 완성** |
| **↑ / ↓** | 이전 명령 **히스토리** |
| **Ctrl+C** | 실행 중 명령 **중단** |
| **Ctrl+L** | 화면 **지우기** (`clear` 와 비슷) |
| **경로에 공백** | `"My Docs"` 처럼 **따옴표** |

현재 폴더를 모를 때는 **`pwd`** 를 먼저 친다.

---

## 16. 위험·실수

| 명령·습관 | 위험 |
|-----------|------|
| `rm -rf /` · `rm -rf /*` | 시스템 **전체 삭제** |
| `sudo rm -rf` + 잘못된 경로 | 복구 **거의 불가** |
| `chmod -R 777 /` | 보안 **무너짐** |
| `dd` 로 디스크에 쓰기 | **데이터 전부** 덮어씀 |
| 출처 불명 `curl \| bash` | **악성 스크립트** |

복사·삭제 전에 **`pwd`** 와 **`ls`** 로 위치를 확인한다. 
중요 데이터는 **백업** ([[Git 사용법]]·클라우드 등).

## 17. 환경별 차이

| 환경 | 참고 |
|------|------|
| **[[Ubuntu]] / Mint** | 위 예시 그대로 |
| **WSL** | 윈도우 파일은 `/mnt/c/Users/...` |
| **[[Termux]]** | `pkg install`, 경로·권한이 Android 제약 |
| **macOS** | `apt` 대신 **Homebrew**(`brew`). 나머지 명령 대부분 동일 |
| **Docker** | `docker exec -it 컨테이너 sh` 안에서 동일 명령 ([[Docker 사용법]]) |

---

## 18. 실전 체크

- [ ] `pwd` · `ls` · `cd` 로 **폴더**를 다룰 수 있는가  
- [ ] `cp` · `mv` · `rm` 차이와 **`rm -r`** 위험을 아는가  
- [ ] `grep` · `|` 로 **로그·파일**을 거를 수 있는가  
- [ ] `sudo apt update && sudo apt install` 흐름을 아는가  
- [ ] `man` · `--help` 로 **모르는 명령**을 찾을 수 있는가

## 면책

> **면책**  
> 명령·옵션·기본 쉘은 **배포판·버전**마다 다를 수 있다. `man`·공식 문서가 우선.  
> 터미널은 **되돌리기 어려운** 작업이 많다. 중요 시스템·서버에서는 **백업·스냅샷** 후 실습한다.
