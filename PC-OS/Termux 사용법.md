# Termux 사용법

> **분류:** PC·OS · [[생활위키 목차]]

**Termux**는 [[안드로이드]] 안에서 **리눅스 쉘·패키지**를 쓰게 해 주는 **터미널 에뮬레이터 + 사용자 공간(userland)** 앱이다. 
PC 없이도 **SSH·Git·Python·스크립트**를 폰에서 돌리거나, 서버에 원격 접속할 때 쓴다.

**가상머신으로 [[Ubuntu]] 전체를 깔는 것**과는 다르다. Android 위에 **리눅스 도구 모음**에 가깝다.

공식: [https://termux.dev](https://termux.dev) · 소스: [GitHub termux/termux-app](https://github.com/termux/termux-app)

확인일: 2026-08-11

관련: [[안드로이드]] · [[갤럭시 폰 사용법]] · [[Git 사용법]] · [[리눅스 기본 명령어]] · [[Python 학습과 패키지]] · [[Ubuntu]] · [[리눅스]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 플랫폼 | **Android** (일부는 태블릿·크롬북 Android 앱 호환) |
| 무엇 | Bash 등 **쉘** + `pkg`로 **패키지 설치** (ssh, git, python 등) |
| 무엇 아님 | **루팅**·**듀얼부팅**·**Docker 호스트** 대체는 아님 |
| 기반 | Android **Bionic** libc 위 사용자 공간 — 일반 PC 리눅스와 **바이너리가 다름** |
| 비용 | 앱 **무료·오픈 소스** (확장 앱 일부 별도) |

```text
Android OS
 ↓
Termux 앱 (터미널 + 환경)
 ↓
$ pkg install git python openssh
 ↓
로컬 스크립트 / ssh user@server
```

[[갤럭시 폰 사용법]]의 폰 설정(배터리 최적화 해제 등)과 **겹치는** 부분이 있다.

---

## 2. 쓰는 이유

| 상황 | Termux |
|------|--------|
| **외출 중 SSH** | 노트북 없이 **서버·라즈베리파이** 점검 |
| **Git** | 저장소 clone·commit·push (가벼운 작업) | 
| **Python·쉘 스크립트** | 자동화·학습. [[파이썬 개발 툴]] · [[Python 학습과 패키지]] |
| **curl·wget** | API 호출·파일 받기 |
| **로컬 도구** | ffmpeg·imagemagick 등 (패키지 제공 시) |
| **학습** | 리눅스 명령·[[Git 사용법]] 입문 |

**무거운 IDE·[[Docker 사용법]]·대형 빌드**는 PC·[[Ubuntu]] Server·WSL이 낫다.

## 3. 설치 (중요)

| 경로 | 권장 |
|------|------|
| **F-Droid** | 공식이 안내하는 **권장** 경로 — [termux.dev](https://termux.dev) |
| **GitHub Releases** | `termux-app` APK 직접 설치 |
| **Google Play 스토어** | **2020년 이후 구버전** — 저장소·패키지 **호환 안 됨**. **새로 깔지 말 것** |

Play 스토어에 남은 항목은 **오래된 빌드**일 수 있다. 이미 깔려 있으면 **삭제 후 F-Droid**로 재설치하는 안내가 공식 FAQ에 있다.

### 첫 실행

```bash
pkg update && pkg upgrade
```

패키지 목록을 **최신**으로 맞춘 뒤 도구를 설치한다.

---

## 4. 기본 사용법

### 4.1 패키지 (`pkg`)

Debian의 `apt`와 비슷한 **Termux 전용** 패키지 관리자다.

| 명령 | 설명 |
|------|------|
| `pkg update` | 패키지 목록 갱신 |
| `pkg upgrade` | 설치된 패키지 업그레이드 |
| `pkg install git` | 패키지 설치 |
| `pkg search python` | 검색 |
| `pkg show openssh` | 정보 |

예:

```bash
pkg install git openssh python
```

### 4.2 홈·파일

| 경로 | 설명 |
|------|------|
| `~` | Termux **전용** 홈 (`/data/data/com.termux/files/home`) |
| `~/storage/` | **저장소 연동** 후 Android 폴더 (DCIM, Download 등) |
| `termux-setup-storage` | 최초 1회 — 갤러리·다운로드 접근 권한 |

Android **Scoped Storage** 때문에 PC 리눅스처럼 `/` 전체를 맘대로 쓰지 **못한다**.

### 4.3 SSH

**나가기(클라이언트)**

```bash
pkg install openssh
ssh user@example.com
```

**들어오기(서버)** — 같은 Wi-Fi에서 폰을 SSH 서버로 쓰는 고급 설정도 가능하나, **보안·배터리**를 고려해야 한다. 공식 위키·문서를 따른다.

[[Git 사용법]]의 원격 저장소 작업과 **같은 ssh 키**를 `~/.ssh`에 둘 수 있다.

## 5. 확장 앱 (선택)

| 앱 | 역할 |
|----|------|
| **Termux:API** | 배터리·위치·클립보드 등 **Android API** 호출 (`termux-api` 패키지와 짝) |
| **Termux:Boot** | 부팅 시 **스크립트** 실행 |
| **Termux:Widget** | 홈 화면 **바로가기**로 명령 실행 |
| **Termux:Styling** | 터미널 **색·폰트** |

본체 **Termux**만으로도 대부분의 CLI는 된다.

---

## 6. proot·배포판 (고급)

**proot** + **termux-chroot** 등으로 **[[Ubuntu]]·Debian** 루트 파일시스템을 **폴더 안에** 풀어 쓰는 방법이 있다 (`pkg install proot-distro` 등).

| | Termux 기본 | proot 배포판 |
|--|-------------|--------------|
| 성격 | 가벼운 **Termux 패키지** | 배포판 **rootfs** 안에서 `apt` |
| 용도 | ssh·git·python | **apt**로 PC에 가까운 환경 |
| 부담 | 상대적 가벼움 | **용량·속도** 부담 큼 |

**완전한 VM·듀얼부팅**은 아니다. 일부 네이티브 바이너리·커널 기능은 **안 되거나** 우회가 필요하다.

---

## 7. PC 리눅스·WSL과 비교

| | Termux | [[Ubuntu]] PC / WSL |
|--|--------|---------------------|
| OS | **Android** 위 | PC **리눅스 커널** 또는 WSL2 |
| 패키지 | `pkg` (Termux 빌드) | `apt` (배포판) |
| Docker | **공식적으로 비권장**·제약 많음 | WSL2·리눅스에서 **일반적** |
| GUI 앱 | **X11/VNC** 등 우회 필요 | 데스크톱 기본 |
| 휴대 | **폰 하나** | 노트북 필요 |

폰은 **이동 중 터미널**; 본격 개발·빌드는 **PC**가 맞는 경우가 많다.

---

## 8. Android·갤럭시에서 주의

| 주제 | 내용 |
|------|------|
| **배터리 최적화** | 시스템이 Termux를 **죽이면** SSH·스크립트 중단 — 설정에서 **최적화 제외** ([[갤럭시 폰 사용법]]) |
| **백그라운드** | Android **도즈**·앱 대기 — 장시간 서버 역할은 부적합할 수 있음 |
| **화면 꺼짐** | `termux-wake-lock` 등 (wake-lock 패키지) — 배터리 소모 |
| **업데이트** | Android·Termux **둘 다** 최신 유지 |
| **루팅** | 없어도 Termux **동작**. 루팅은 **보안 위험** 별도 |

---

## 9. 보안

| 주칙               |                                      |                                       |
| ---------------- | ------------------------------------ | ------------------------------------- |
| **출처**           | F-Droid·공식 GitHub만 — **난독화된 APK** 금지 |                                       |
| **스크립트**         | `curl                                | bash` **한 줄 설치**는 신뢰할 수 있는 **공식 문서**만 |
| **SSH 키**        | 폰 분실 시 **키 유출** — 잠금·암호화·서버에서 키 폐기   |                                       |
| **공용 Wi-Fi**     | SSH·비밀번호 **평문** 주의 — VPN·키 인증        |                                       |
| **Play 스토어 구버전** | 알려진 **호환·보안** 문제 — 재설치 권장            |                                       |

Termux 자체가 해킹 도구가 아니지만, **악용 사례** 때문에 Play 정책 논란이 있었다. **합법·본인 장비** 범위에서만 쓴다.

---

## 10. 흔한 오해

| 오해 | 현실 |
|------|------|
| Termux = 리눅스 폰 | **Android** + 리눅스 **도구**. 커널은 Android |
| Play에서 받으면 됨 | **구버전** — **F-Droid** 권장 |
| PC 우분투랑 패키지 같음 | `pkg` ≠ `apt` (proot 안에서는 apt) |
| 폰에서 Docker 돌리면 됨 | **실무에선 PC·서버** 권장 |
| 루팅 필수 | **비루팅**으로 대부분 CLI 가능 |

---

## 11. 실전 체크리스트

- [ ] **F-Droid** 또는 공식 APK로 설치했는가  
- [ ] `pkg update && pkg upgrade` 했는가  
- [ ] 저장소 쓸 때 `termux-setup-storage` 했는가  
- [ ] 배터리 **최적화 제외** (장시간 작업 시)  
- [ ] 무거운 빌드는 **PC·원격 서버**로 넘겼는가  

---

## 12. 정리

1. Termux는 Android에서 **쉘·패키지·SSH·Git** 등을 쓰는 **터미널 환경**이다.  
2. 설치는 **F-Droid·공식 릴리스** — Play 스토어 **구버전 주의**.  
3. `pkg`로 도구를 깔고, 파일은 `~/storage` 연동을 본다.  
4. **[[Ubuntu]] 전체·Docker** 대체는 아니다 — **이동 중 터미널**에 가깝다.  
5. 보안·배터리·백그라운드 제한을 **Android 앱**으로 이해한다.

---

## 면책

> **면책**  
> Android·Termux·패키지 버전은 **업데이트**마다 바뀐다. 설치·SSH·루팅은 **본인 책임**이며, 회사·학교 **보안 정책**을 따른다.  
> 이 글은 **도구 설명**이며 불법 침입·라이선스 위반 용도를 권하지 않는다.
