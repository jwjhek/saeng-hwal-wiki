# 라이브 캡션

> **분류:** PC·OS · [[생활위키 목차]]

**라이브 캡션**(Live Captions)은 **Windows 11**에 들어 있는 **실시간 자막** 기능이다. 
PC에서 나는 **시스템 오디오**(유튜브·회의·게임·음악 등)를 기기 안에서 인식해, 화면 위에 **글자로 보여 준다.**

청각이 약하거나, 스피커 없이·소음 속에서 듣기 어려울 때 쓰는 **접근성** 도구이지만, **외국어 강의·회의 메모**에도 자주 쓴다.

확인일: 2026-08-11

참고: [Microsoft — 라이브 캡션으로 오디오 이해하기](https://support.microsoft.com/ko-kr/windows/use-live-captions-to-better-understand-audio)

관련: [[윈도우 사용법]] · [[유튜브]] · [[갤럭시 폰 사용법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | Windows가 **재생 중인 소리**를 실시간으로 **텍스트 캡션**으로 표시 |
| 범위 | 특정 앱 하나가 아니라 **PC 오디오 전체** (브라우저·Zoom·게임 등) |
| 버전 | **Windows 11 22H2 이상** (공식 안내 기준). Windows 10에는 **없음** |
| 언어 | **한국어** 포함 다수 언어. 최초 **언어 파일 다운로드** 필요 |
| 오프라인 | 언어 파일 받은 뒤에는 **인터넷 없이**도 동작하는 경우가 많음 |
| 단축키 | **`Win` + `Ctrl` + `L`** — 켜기/끄기 토글 |

별도 앱·유료 구독 없이 **설정만**으로 켤 수 있다. [[CapCut]]·[[유튜브]] 앱 자막과 **역할이 다르다** (아래 §8).

---

## 2. 켜는 방법

### 2.1 단축키 (가장 빠름)

| 동작 | 키 |
|------|-----|
| 라이브 캡션 켜기/끄기 | **`Win` + `Ctrl` + `L`** |

처음 켤 때 **음성 처리·언어 파일** 동의·다운로드 창이 나올 수 있다.

### 2.2 설정

1. **`Win` + `I`** → **접근성** → **캡션**  
2. **라이브 캡션** 토글 **켬**  

또는:

- 작업 표시줄 **빠른 설정**(네트워크·볼륨 등) → **접근성** → 라이브 캡션  
- 시작 메뉴 → **모든 앱** → **접근성** → **라이브 캡션**

### 2.3 첫 실행

```text
라이브 캡션 켬
 ↓
음성 데이터 기기 처리 동의 (안내에 따름)
 ↓
캡션 언어 선택 (예: 한국어)
 ↓
언어 파일 다운로드 (수백 MB·수 분)
 ↓
상단/하단 캡션 바에 실시간 글자 표시
```

한국어는 Microsoft 공식 **지원 언어 목록**에 포함된다. 목록·용량은 **Windows 업데이트**마다 바뀔 수 있다.

---

## 3. 캡션 창·스타일

캡션 바 **톱니바퀴(설정)** 에서 조정하는 항목이 많다.

| 설정 | 설명 |
|------|------|
| **위치** | 화면 **위** / **아래** / **오버레이**(겹침) |
| **캡션 스타일** | 글자 크기·글꼴·색·배경 (`설정` → `접근성` → `캡션`에서도 편집) |
| **언어 변경** | Change language → 다른 언어 팩 **다운로드** |
| **마이크 포함** | **대면 대화**도 캡션 (Preferences → include microphone audio) |
| **비속어 필터** | Filter profanity (버전에 따라) |

캡션 **텍스트를 복사**하는 기능은 **없다**. 기록·번역본 저장용이 아니라 **실시간 읽기**용이다.

---

## 4. 어디에 쓰나

| 상황 | 예 |
|------|-----|
| 청각 보조 | 영상·강의·회의를 **글로 따라 읽기** |
| 스피커 없음 | 이어폰·음소거 환경에서 **조용히** 내용 확인 |
| 발음·억양 | **한국어·외국어** 강의에서 놓친 말 보완 |
| 잡음 | 카페·사무실에서 소리가 작을 때 |
| 게임·라이브 | 대사·알림을 텍스트로 (인식률은 게임마다 다름) |

[[유튜브]]·브라우저·Teams 등 **앱마다 자막 버튼**이 있어도, 라이브 캡션은 **OS 전체**에 걸린다. 앱에 자막이 없을 때 특히 유용하다.

---

## 5. Copilot+ PC — 번역 (선택)

**Copilot+ PC** + **Windows 11 24H2 이상**에서는 라이브 캡션에 **실시간 번역**이 붙는 경우가 있다 (공식 안내 기준).

| | 일반 PC | Copilot+ (해당 버전) |
|--|---------|----------------------|
| 기본 | 들리는 말을 **같은 언어**로 캡션 | 일부 언어 → **영어·중국어 등**으로 번역 캡션 |
| 용도 | 자막 | **외국어 회의·영상** 대략 이해 |

기기·버전이 아니면 **번역 없이 캡션만** 된다고 보면 된다.

---

## 6. 한계·주의

| 한계 | 설명 |
|------|------|
| **정확도** | 전문 용어·빠른 말·BGM·여러 사람이 겹치면 **오인식** |
| **지연** | 실시간이지만 **몇 초 늦게** 나오기도 함 |
| **저장 불가** | 캡션 **복사·보내기** 없음. 필요하면 별도 메모 |
| **법·의료** | **공식 기록·증거**로 쓰기엔 부적합 |
| **CPU** | 기기 안 음성 인식 — **배터리·발열** 체감 가능 |
| **버전** | Windows 10·구형 11 빌드에서는 **없거나 다름** |

회의록·강의 필기는 [[NotebookLM 사용법]]·앱 자막·전사 서비스와 **역할을 나눈다.**

## 7. [[유튜브]]·앱 자막과 비교

| | 라이브 캡션 (Windows) | 앱·사이트 자막 |
|--|----------------------|----------------|
| 대상 | **PC 전체 소리** | 그 **앱/영상**만 |
| 켜기 | `Win`+`Ctrl`+`L` | [[유튜브]] `C` 등 |
| 품질 | OS 음성 인식 | 업로더 자막·플랫폼 STT |
| 저장 | 안 됨 | 일부 앱은 자막 파일·스크립트 |
| 편집 | [[CapCut]] 등과 **무관** | 쇼츠 제작용 TTS·자막은 편집 앱 |

**둘 다 켜면** 화면에 자막이 **겹쳐** 보일 수 있다. 하나만 쓰는 편이 낫다.

---

## 8. [[갤럭시 폰 사용법]]

안드로이드·갤럭시에도 **라이브 캡션**(Live Caption)류 기능이 있다. **폰 미디어**용이고, **Windows PC 오디오**와는 별개다.

| | Windows 라이브 캡션 | 갤럭시 (기기·버전별) |
|--|---------------------|----------------------|
| 대상 | PC 스피커·헤드셋 소리 | 폰 재생·일부 통화 |
| 연동 | 없음 | 각각 설정 |

PC에서 듣는 강의는 **Windows** 쪽을, 폰만 쓸 때는 **폰 접근성** 설정을 본다.

---

## 9. 안 될 때

| 증상 | 확인 |
|------|------|
| 메뉴에 없음 | **Windows 11 22H2+**? 업데이트 (`설정` → `Windows Update`) |
| 언어 파일 실패 | 디스크 공간·인터넷. `설정` → `시간 및 언어` → **언어** |
| 캡션 안 나옴 | PC **볼륨**·앱 음소거. **올바른 출력 장치**(이어폰/스피커) |
| 한글이 깨짐 | 캡션 **언어**가 한국어인지. 언어 팩 재다운로드 |
| 바로 꺼짐 | Windows **최신 누적 업데이트**. 표시 언어 관련 버그는 패치 이력 확인 |
| 마이크만 필요 | Preferences에서 **마이크 포함** 켰는지 |

그래도 안 되면 Microsoft 지원 문서·피드백 허브를 본다.

---

## 10. 실전 체크

- [ ] **`Win` + `Ctrl` + `L`** 익혔는가  
- [ ] 한국어(또는 필요한 언어) **언어 파일** 받았는가  
- [ ] 캡션 **위치·글자 크기**가 읽기 편한가  
- [ ] 회의·강의에 **마이크 포함**이 필요한지 정했는가  
- [ ] 앱 자막과 **중복** 켜지 않는가  
- [ ] **정확한 기록**이 필요하면 다른 도구도 쓸 계획인가

## 11. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | Windows 11 **전체 오디오** 실시간 자막 |
| 켜기 | **`Win` + `Ctrl` + `L`** 또는 접근성 → 캡션 |
| 언어 | **한국어** 지원, 최초 언어 팩 다운로드 |
| 강점 | 앱 공통·무료·오프라인(팩 설치 후) |
| 한계 | 오인식·복사 불가·공식 속기 대체 아님 |

## 면책

> **면책**  
> 기능·언어·단축키는 **Windows 버전**마다 다르다. Microsoft 공식 도움말을 본다.  
> 캡션은 **참고용**이며 법률·의료·계약의 **정확한 기록**을 대체하지 않는다.  
> 음성 처리 동의·개인정보는 Microsoft 개인정보 처리방침을 따른다.
