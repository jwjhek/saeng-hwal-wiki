# 윈도우 사용법

> **분류:** PC·OS · [[생활위키 목차]]

Windows는 PC의 **운영체제**다. 파일·앱·네트워크·보안의 바탕이 되므로, 단축키와 설정만 익혀도 일상·업무 속도가 많이 달라진다.

이 글은 **Windows 10 / 11** 공통 위주. 메뉴 이름은 버전에 따라 `설정` 위치가 조금 다를 수 있다.

확인일: 2026-08-06

---

## 1. 기본 조작

| 동작 | 방법 |
|------|------|
| 시작 메뉴 | `Win` 또는 작업 표시줄 시작 버튼 |
| 검색 | `Win` + `S` 또는 시작 메뉴 검색창 |
| 실행 창 | `Win` + `R` (`mspaint`, `cmd`, `control` 등) |
| 작업 보기 / 가상 데스크톱 | `Win` + `Tab` / `Win` + `Ctrl` + `D` |
| 창 닫기 | `Alt` + `F4` |
| 작업 관리자 | `Ctrl` + `Shift` + `Esc` |
| 잠금 | `Win` + `L` |
| 클립보드 기록 | `Win` + `V` (켜 두기) |
| 이모지·기호 | `Win` + `.` |
| 설정 | `Win` + `I` |
| 라이브 캡션 | `Win` + `Ctrl` + `L` (Windows 11) → [[라이브 캡션]] |
| 파일 탐색기 | `Win` + `E` |
| 바탕 화면 보기 | `Win` + `D` |

전원: 시작 → 전원 → 절전 / 종료 / 다시 시작. 
강제 종료가 필요하면 작업 관리자에서 프로세스 종료.

## 2. 필수 단축키

### 창·화면

| 단축키 | 동작 |
|--------|------|
| `Win` + `←` / `→` | 창 좌우 스냅 |
| `Win` + `↑` / `↓` | 최대화 / 최소화·복원 |
| `Alt` + `Tab` | 앱 전환 |
| `Win` + `숫자` | 작업 표시줄 n번째 앱 |
| `Win` + `Shift` + `S` | 영역 스크린샷 (캡처 도구) |
| `PrtSc` | 전체 화면 클립보드 (환경에 따라) |
| `Win` + `PrtSc` | 전체 화면을 그림 폴더에 저장 |
| `Win` + `Ctrl` + `←` / `→` | 가상 데스크톱 이동 |
| `Win` + `A` | 빠른 설정 (Wi-Fi, 블루투스…) |
| `Win` + `N` | 알림 센터 (버전에 따라) |

### 파일 탐색기

| 단축키 | 동작 |
|--------|------|
| `Ctrl` + `C` / `X` / `V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl` + `Z` | 실행 취소 |
| `F2` | 이름 바꾸기 |
| `Delete` / `Shift` + `Delete` | 휴지통 / 영구 삭제 |
| `Ctrl` + `Shift` + `N` | 새 폴더 |
| `Alt` + `↑` | 상위 폴더 |
| `F5` | 새로 고침 |
| `Ctrl` + `F` | 검색 |

스크린샷 편집은 [[그림판 사용법]]으로 이어가면 된다.

## 3. 파일·폴더

### 주요 위치

| 경로 | 용도 |
|------|------|
| 바탕 화면 | 바로가기·임시 |
| 문서 / 다운로드 / 사진 | 기본 사용자 폴더 |
| `C:\Users\사용자명\` | 프로필 루트 |
| `C:\Program Files\` | 설치된 64비트 앱 |
| 휴지통 | 삭제 대기 |

팁:

- **다운로드**는 주기적으로 비우기 
- 중요한 자료는 OneDrive·외장·Git 등 **이중 보관** 
- 경로가 너무 길면 일부 도구에서 오류 → 짧은 경로·라이브러리 활용 

### 숨김·확장자

탐색기 → 보기 → **파일 이름 확장자** 표시 권장 (매크로 `.docm` 구분). 
숨김 항목은 필요할 때만.

### 압축

Windows 11은 zip을 탐색기에서 바로. 
7-Zip 등은 암호·다양한 형식에 유리.

## 4. 설정에서 자주 건드리는 것

`Win` + `I`

| 항목 | 내용 |
|------|------|
| 시스템 → 디스플레이 | 해상도, 배율(125%/150%), 야간 모드 |
| 시스템 → 소리 | 출력 장치, 볼륨 |
| 시스템 → 전원 | 절전, 화면 끄기 시간 |
| 시스템 → 정보 | 장치 이름, Windows 버전 |
| 블루투스 및 장치 | 키보드, 버즈, 갤럭시 워치 등 |
| 네트워크 | Wi-Fi, VPN, 데이터 사용량 |
| 개인 정보 | 앱 권한 (카메라·마이크·위치) |
| 계정 | Microsoft 계정, PIN, Windows Hello |
| Windows Update | 보안 패치 — 미루되 **너무 오래 끄지 말 것** |
| 앱 | 설치됨 목록, 기본 앱(브라우저·PDF) |

Windows 11: 시작 메뉴 핀, 작업 표시줄 정렬, 스냅 레이아웃(`Win` + `Z`).

## 5. 계정·보안

1. **PIN / Windows Hello** — 로그인 편의 
2. Microsoft 계정 — Store·OneDrive·설정 동기화 
3. **로컬 계정**만 쓰는 선택도 가능 (버전·정책에 따라) 
4. BitLocker(지원 PC) — 디스크 암호화 
5. Windows 보안 → 바이러스 위협 방지 **실시간 보호** 유지 
6. 관리자 권한 UAC 프롬프트 — 모르는 설치는 아니오 

피싱·가짜 크랙 설치 금지. 
공용 PC는 Microsoft 계정 로그아웃·OneDrive 주의.

관련: [[갤럭시 워치 사용법]] (퀵셰어·링크 to Windows)

## 6. 앱 설치·제거

| 경로 | 용도 |
|------|------|
| Microsoft Store | 검증된 앱, 그림판 업데이트 등 |
| 공식 사이트 설치 파일 | Chrome, IDE, 유틸 |
| `설정` → `앱` → `설치된 앱` | 제거 |
| `앱` → `선택적 기능` | OpenSSH, 언어팩 등 |

기본 앱 변경: `설정` → `앱` → `기본 앱` → 브라우저, 메일, PDF.

개발 도구: [[VS Code 사용법]], [[Eclipse 사용법]], [[Cursor 사용법]], [[Notepad++ 사용법]], [[Docker 사용법]]

## 7. 클립보드·캡처·생산성

- **클립보드 검색 기록** `Win` + `V` — 여러 개 복사본 보관 (설정에서 켜기) 
- **캡처 도구** `Win` + `Shift` + `S` — 영역/창/전체 
- **이모지** `Win` + `.` 
- **클립보드에 캡처 후** 그림판·메신저·Obsidian에 붙여넣기 

원격:

- 빠른 지원(Nearby sharing) 
- Phone Link / 링크 to Windows — 안드로이드(갤럭시) 알림·사진 
- 원격 데스크톱 — Pro 이상·네트워크 설정 필요

## 8. 터미널·개발자

| 도구 | 열기 |
|------|------|
| 명령 프롬프트 | `cmd` |
| PowerShell | `powershell` / 터미널 앱 |
| Windows 터미널 | Store 또는 `wt` |
| WSL | `wsl` (설치 시) |

관리자 권한: 시작에서 우클릭 → 관리자로 실행. 
경로 복사: 탐색기 주소창 `Ctrl` + `L` 후 복사, 또는 Shift+우클릭 → “경로로 복사”.

패키지 대략:

```powershell
winget search notepad
winget install --id Microsoft.VisualStudioCode
```

## 9. 업데이트·백업·복구

1. **Windows Update** 정기 적용 (활성 시간 설정으로 재부팅 방해 완화) 
2. 중요 폴더 **OneDrive 백업** 또는 외장 HDD 
3. **시스템 복원 지점** — 드라이버 설치 전 만들기 
4. 설정 → 시스템 → 복구 — 이 PC 초기화 (최후) 
5. `Win` + `X` → 터미널/디스크 관리 등 고급 메뉴 

디스크가 가득 차면: 설정 → 시스템 → 저장소 → 임시 파일 정리, 휴지통·다운로드.

---

## 10. 성능이 느릴 때

1. 작업 관리자 → CPU/메모리/디스크 점유 앱 확인 
2. 시작 앱 끄기 (`설정` → `앱` → `시작 프로그램`) 
3. 저장 공간 확보 
4. 악성 코드·멀웨어 검사 
5. 그래픽/칩셋 드라이버 공식 업데이트 
6. 브라우저 탭·확장 과다 여부 

SSD인데 디스크 100%면 백그라운드 인덱싱·Windows Update·고장 징후를 의심.

## 11. Windows 10 vs 11 (체감)

| | 11에서 두드러짐 |
|--|-----------------|
| 시작 메뉴 | 중앙·위젯 |
| 스냅 | 레이아웃 `Win` + `Z` |
| 앱 | 그림판 레이어·AI 등 신기능 |
| 요구 사양 | TPM 등 — 구형 PC는 10 유지 가능 |

지원 종료 일정은 Microsoft 공지를 따른다. 보안 업데이트가 끊기면 교체·업그레이드를 검토.
