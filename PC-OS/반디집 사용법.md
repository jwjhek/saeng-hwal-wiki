# 반디집 사용법

> **분류:** PC·OS · [[생활위키 목차]]

**반디집**(Bandizip)은 Windows용 **압축·해제** 프로그램이다. 
ZIP·7Z로 묶고, RAR·EGG·ALZ 등 **다양한 형식을 풀며**, 탐색기 **우클릭 메뉴**와 **암호 zip**까지 한곳에서 처리한다.

제작: 반디소프트(Bandisoft)  
공식: [https://kr.bandisoft.com/bandizip](https://kr.bandisoft.com/bandizip)

확인일: 2026-08-11

관련: [[윈도우 사용법]] · [[Everything 사용법]] · [[Q-Dir 사용법]] · [[WinMerge 사용법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 파일·폴더를 **한 덩어리**로 줄이거나(압축), 받은 압축을 **원래대로** 푸는 도구 |
| 비용 | **무료** Standard + **유료** Professional·Enterprise (고급 기능) |
| OS | Windows 10·11 등 (32·64비트, ARM64 지원 버전 있음) |
| [[윈도우 사용법]]과 | 탐색기는 **zip 기본**만. 반디집은 **rar·분할·암호·미리보기** 확장 |

```text
[받은 파일] .zip .rar .7z .egg …
 ↓
[반디집] 우클릭 → 압축 풀기 · 일부만 추출
 ↓
[정리] [[Q-Dir 사용법]] 등으로 폴더 이동 · [[WinMerge 사용법]]으로 내용 비교
```

---

## 2. 언제 쓰나

| 상황 | 반디집으로 하는 일 |
|------|-------------------|
| 이메일·메신저 **첨부** | 폴더를 **zip**으로 묶기 |
| **용량 제한** | 분할 압축 (여러 개로 나눔) |
| **비밀번호** zip | AES-256 등으로 암호 걸기 |
| 해외·구형 **한글 깨짐** | 코드페이지 **자동·수동** 변환 |
| **RAR** 받음 | Windows만으로 안 풀릴 때 **해제** |
| 압축 **안 풀고** 확인 | 내부 목록·미리보기·파일만 꺼내기 |
| 백업·배포 | `project.zip` 만들어 [[Git 사용법]]·클라우드와 병행 |

## 3. 지원 형식 (요약)

공식 안내 기준. **버전**마다 목록이 조금 다를 수 있다.

### 압축 (만들기)

| 형식 | 비고 |
|------|------|
| **ZIP** | 가장 흔함. 호환성 좋음 |
| **7Z** | 압축률·용량에 유리한 경우 많음. LZMA2·AES 등 |
| **ZIPX, TAR, TGZ, GZ, XZ, LZH, ISO, EXE(SFX)** 등 | 용도별 |

**RAR로 새로 압축**하는 것은 WinRAR 라이선스 영역이라, 반디집은 주로 **RAR 해제**에 초점을 둔다.

### 해제 (풀기)

ZIP, **RAR·RAR5**, 7Z, **EGG, ALZ**, CAB, ISO, TAR, TBZ, WIM, ZSTD 등 **40종 이상** (공식 표 기준).

| 자주 받는 것 | |
|--------------|--|
| `.zip` | 일반 |
| `.rar` / `.part1.rar` | 분할 RAR |
| `.7z` | 고압축 |
| `.egg` `.alz` | 국내에서 쓰이던 형식 |
| `.exe` (SFX) | 실행형 압축 — **출처 불명이면 실행 주의** |

## 4. 주요 기능

| 기능 | 설명 |
|------|------|
| **탐색기 연동** | 파일·폴더 **우클릭** → 압축·풀기·암호 |
| **드래그 앤 드롭** | 압축 창에 끌어 넣기, 압축 안에서 **일부만** 끌어 내기 |
| **빠른 압축** | 멀티코어·고속 아카이빙(이미 압축된 파일은 건너뛰기 등) |
| **분할 압축** | `z01`, `part2` 형태로 **나눠 저장** |
| **대용량** | 4GB 넘는 파일 zip 등 (NTFS·형식에 따름) |
| **암호** | 압축 시 비밀번호, **AES-256** (zip·7z 등) |
| **압축 안에서 편집** | 풀지 않고 **추가·삭제·이름 변경** (zip 등) |
| **미리보기** | 탐색기에서 압축 **내용 목록** 보기 |
| **무결성 검사** | 압축 파일 **손상** 테스트 |
| **유니코드** | UTF-8 파일명. 옛 **한글 깨짐** 시 코드페이지 지정 |

### 무료 vs 유료 (개념만)

| Standard (무료) | Professional 등 (유료) |
|-----------------|-------------------------|
| 일반적인 압축·해제·암호 | 광고 제거, 배치·자동화, 기업 배포 등 **추가** |
| 개인·가벼운 사용에 충분한 경우 많음 | 정책·기능은 **공식 비교표** 참고 |

가격·기능 차이는 **수시로** 바뀐다. 설치 전 [공식 사이트](https://kr.bandisoft.com/bandizip)에서 확인한다.

## 5. 기본 사용

### 압축 만들기

1. 폴더 또는 파일 **우클릭** → **압축** (또는 반디집 실행 후 추가)  
2. 형식 **ZIP** 또는 **7Z**, 저장 위치·이름 지정  
3. (선택) **암호**·분할 크기 설정  
4. 확인 → `.zip` / `.7z` 생성

여러 파일을 한 zip으로: 파일 선택 → 우클릭 **선택 항목 압축**.

### 압축 풀기

1. `.zip` 등 **우클릭** → **압축 풀기** (또는 **여기에 압축 풀기**)  
2. 암호 zip이면 **비밀번호** 입력  
3. **분할 압축**은 `.z01`·`.part1.rar` 등 **첫 파일** 또는 전체가 같은 폴더에 있어야 함

### 압축 안에서만 꺼내기

1. 압축 파일을 **더블클릭**해 반디집 창 열기  
2. 필요한 파일만 **드래그**해 바탕화면·폴더로  
3. 전체가 필요 없으면 **용량·시간** 절약

### 자주 쓰는 설정

| 설정 | 이유 |
|------|------|
| **연결 프로그램** | zip·rar 더블클릭 시 반디집으로 열기 |
| **풀기 경로** | `다운로드\압축이름\`처럼 **하위 폴더** 자동 생성 |
| **덮어쓰기** | 같은 이름 있을 때 **묻기**로 두기 |
| **업데이트** | 보안 패치 **최신** 유지 (§7) |

## 6. 다른 도구와 비교

| | Windows 탐색기 | 반디집 | 7-Zip |
|--|----------------|--------|-------|
| zip 압축·해제 | **기본** | ○ | ○ |
| rar **해제** | △ (버전·설정) | **○** | ○ |
| 우클릭·UI | 단순 | **한국어 친숙** | 기능 위주 |
| 암호·분할 | 제한적 | **○** | ○ |
| 무료 | 내장 | Standard 무료 | 무료 |

[[Q-Dir 사용법]]은 zip을 **폴더처럼** 열 수 있지만, **rar·암호·분할**은 반디집·7-Zip 쪽이 낫다.
[[WinMerge 사용법]]은 압축을 **푼 뒤** 폴더·파일 **내용**을 비교한다.

## 7. 보안·주의

| 주제 | 내용 |
|------|------|
| **출처 불명 압축** | 메일·채팅 **첨부**·`.exe` SFX는 **멀웨어** 위험. 함부로 실행하지 않음 |
| **최신 버전** | 압축 포맷 **취약점** 패치가 자주 나옴. 반디집 **업데이트** 유지 |
| **MoTW** | 인터넷에서 받은 파일 표시(웹 표시) 관련 수정이 changelog에 반복됨 — **신뢰할 수 있는 경로**만 풀기 |
| **암호** | zip 비밀번호는 **공유 채널**에 같이 보내지 않기 |
| **이중 확장자** | `invoice.pdf.exe` 속임수 주의 ([[윈도우 사용법]] 확장자 표시) |
| **백업** | 중요 파일만 압축해 두고 **원본 삭제**는 신중히 |
