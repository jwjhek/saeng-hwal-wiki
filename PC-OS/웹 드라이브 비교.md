# 웹 드라이브(클라우드 스토리지) 비교

> **분류:** PC·OS · [[생활위키 목차]]

파일·사진을 **인터넷 너머 저장·동기화·공유**하는 서비스를 흔히 웹하드·클라우드·드라이브라고 부른다.  
종류·무료 용량·요금·생태계가 달라 **“TB당 원”만으로 고르면** 낭비가 난다.

> **면책**  
> 요금·용량·약관은 **국가·프로모션·시점에 따라 바뀐다**. 숫자표는 **감각용**이며 가입 전 각사 공식 요금표를 확인한다.  
> 특정 상품 가입 권유가 아니다.

확인일: 2026-08-06  

이 위키 작성자 기준: **OneDrive 유료(Microsoft 365 계열로 쓰는 경우가 많음)** → §6에 “이미 유료면” 정리.

관련: [[윈도우 사용법]], [[Microsoft Copilot과 무료 Office]], [[갤럭시 폰과 워치 사용법]]

---

## 1. 종류를 나누는 축

| 축 | 예 |
|----|-----|
| **소비자 동기화 드라이브** | OneDrive, Google Drive, iCloud Drive, Dropbox |
| **포토·메일과 용량 공유** | Google One(포토·Gmail), iCloud(백업·사진) |
| **협업·업무 특화** | Dropbox Business, Box, Google Workspace, OneDrive for Business |
| **개인 서버·NAS** | Synology·TrueNAS + 외부 접속 (클라우드 구독과 성격이 다름) |
| **프라이버시·암호화 강조** | Proton Drive, Sync.com, pCloud Crypto 등 |
| **국내 포털** | 네이버 MYBOX, 카카오·기타 (정책·용량 변동 큼) |
| **기기 제조사** | 삼성 클라우드 등 — 기기 백업 비중이 크고 용량 정책이 자주 바뀜 |

일상에서 말하는 “웹드라이브 가성비”는 대개 **소비자 동기화 + 사진** 비교다.

---

## 2. 큰 손 비교 (개인 감각)

무료 용량·유료 진입은 **대략**이다. 한국 원화·부가세는 결제 페이지가 정확하다.

| 서비스 | 무료(대략) | 유료 감각 | 잘 맞는 사람 |
|--------|------------|-----------|--------------|
| **OneDrive** | ~5GB | 100GB 단독 / **M365에 1TB(±) + Office** | Windows·Office·Teams |
| **Google Drive** (Google One) | ~15GB (메일·포토와 **공유**) | 100GB·200GB·2TB… | Android·Gmail·포토·Docs |
| **iCloud+** | ~5GB | 50GB부터 소액 티어가 매력적인 편 | iPhone·Mac 백업·사진 |
| **Dropbox** | ~2GB | 바로 **TB급**으로 뛰는 요금이 많음 | 크로스플랫폼 동기화·외부 공유 UX |
| **Box** | 개인 무료 있음 | 기업·규정 중심 | 회사 지정 시 |
| **MEGA / pCloud 등** | 프로모·플랜별 | 종신(lifetime) 마케팅도 | 가격·암호화 실험 (약관·신뢰 검토) |

### 가성비를 읽는 법

1. **이미 쓰는 구독에 묶였는가**  
   - Office가 필요 → M365 = OneDrive TB가 “덤”처럼 보임 → **용량만 사는 것보다 싸게 느껴짐**  
   - Google 포토·메일 용량 압박 → Google One이 한 방에 해결  
   - iPhone 백업 경고 → iCloud 소용량 티어가 체감 최고인 경우 많음  
2. **순수 TB당 원**만 보면 Dropbox·일부 프리미엄이 비싸 보인다.  
3. **가족 공유** (M365 Family, Google One 가족, iCloud 가족)면 인당 단가↓.  
4. 무료 15GB Google는 **포토 원본·메일 첨부에 금방 잠식**된다.

## 3. 서비스별 한 줄 성격

### OneDrive (Microsoft)

- Windows 탐색기에 **폴더처럼** 붙음, Office 자동 저장·버전 기록과 궁합.  
- [[Microsoft Copilot과 무료 Office]] 웹 문서도 여기로 가는 경우가 많음.  
- **M365 Personal/Family** 쓰면 용량+데스크톱 Office가 한 세트.  
- 약점: 무료 단독은 작고, Apple만 쓰는 집에서는 존재감↓.

### Google Drive / Google One

- 무료 상대적 여유, Docs/Sheets 협업, Android 백업·포토.  
- 약점: 용량이 Drive+Gmail+Photos **한 통**. Windows에선 OneDrive만큼 OS 일체감은 약할 수 있음.

### iCloud Drive

- 기기 백업·사진·메시지 등 Apple 생태계.  
- 약점: Windows 클라이언트가 “메인 작업 드라이브”로는 답답한 경우. PC 중심이면 보조로 두는 편.

### Dropbox

- 동기화·공유 링크·선택 동기화 등 **드라이브 UX**로 오래 강세.  
- 약점: 개인 가성비(TB·원화)는 M365·Google One에 밀리기 쉬움. 팀·클라이언트가 Dropbox면 유지 이유.

### 그 외 (짧게)

| | 메모 |
|--|------|
| **네이버 MYBOX** | 국내 계정·이벤트 용량. 장기 메인으로 쓰기 전 약관·종료 리스크를 본다 |
| **Proton/Sync 등** | 암호화·관할 강조. 속도·앱 완성도·복구를 직접 시험 |
| **NAS** | 월정액↓·초기비용·전기·보안·백업 책임↑. “가성비”가 시간 비용까지 포함 |

## 4. 용도별 추천 감각 (구매 아님)

| 상황 | 기운 쪽 |
|------|---------|
| Windows + Word/Excel 헤비 | **OneDrive + M365** (이미 유료면 §6) |
| 갤럭시 + 구글 포토·메일 | **Google One** |
| iPhone 용량 경고만 | **iCloud+** 소·중용량 |
| 외주·클라이언트와 링크 공유가 일상 | Dropbox 또는 상대가 쓰는 것 |
| 사진 원본 수십 GB | Google One / iCloud / Amazon Photos 등 **포토 특화**도 비교 |
| 기밀·제로지식 | 암호화 특화 + **로컬 백업** (클라우드 단일 신뢰 금지) |
| 백업 3-2-1 | 클라우드 1곳 + 외장/NAS (드라이브 ≠ 완벽한 백업) |

갤럭시만으로 모든 걸 삼성 클라우드에 맡기기보다, **구글·OneDrive 중 메인**을 정하는 집이 많다. → [[갤럭시 폰과 워치 사용법]]

## 5. 가성비 함정

| 함정 | 설명 |
|------|------|
| 드라이브 2~3개 유료 중복 | 같은 사진이 삼중 과금 |
| “평생 이용권” | 회사 존속·약관 변경 리스크 |
| 무료만 여러 개 | 어디 있는지 모름 = 실종 |
| 동기화 폴더에 노드_modules·ISO | 대역·충돌·과금 |
| 공유 링크 권한 방치 | 유출 |
| 클라우드만 믿고 PC 삭제 | 실수·랜섬·계정 잠김 시 끝 |

**선택적 동기화**(필요한 폴더만 PC에) + 대용량은 온라인 전용으로 두는 습관이 비용을 지킨다.

## 6. 이미 OneDrive 유료라면

전제: Microsoft 365 등으로 **유의미한 OneDrive 용량(예: 1TB급)을 이미 내는 중**.

### 유지가 보통 이득인 이유

1. **Office 데스크톱·웹**과 용량이 한 결제에 묶여 있으면, Drive만 따로 사는 Google/Dropbox보다 **총지출이 낮거나 비슷**한 경우가 많음.  
2. Windows·탐색기·[[크롬]]/Edge·전화(Android용 OneDrive)까지 한 계정.  
3. Copilot·웹 Office 초안 파일도 OneDrive로 모으기 쉬움 ([[Microsoft Copilot과 무료 Office]]).  
4. 버전 기록·휴지통으로 “덮어쓴 문서” 복구 습관이 생기면 이직·실수 비용↓.

### 그래도 다른 클라우드를 쓰는 경우

| 이유 | 팁 |
|------|-----|
| 가족이 전부만 / 구글 포토 | iCloud·Google은 **그 생태계 최소 티어**만 (중복 백업 목적 명확히) |
| 회사·학교가 다른 드라이브 강제 | 업무 계정과 **개인 OneDrive 분리** |
| 협업 상대가 Dropbox만 | 프로젝트 폴더만 Dropbox, 원본 아카이브는 OneDrive |
| 용량 부족 | M365 Family·추가 스토리지·사진 압축·외장 아카이브 순으로 계산 |

### “옮길까?” 체크

- [ ] 월(연) 결제액 vs Google One 동일 용량 + **별도 Office 필요 여부**  
- [ ] 갤럭시 사진 기본 백업이 어디로 가는지  
- [ ] 중요 vault·문서가 이미 OneDrive 경로인지 ([[Obsidian 사용법]], 생활위키)  
- [ ] 이중 유료가 되면 한쪽 해지 일정  

**결론 감각:** Office를 쓰고 OneDrive 유료가 안정적으로 돌아가면, 가성비 때문에 **메인를 억지로 갈아타기보다** 보조만 최소로 두는 편이 손해가 적다.

---

## 7. 보안·백업 최소

1. 로그인 **2단계 인증**  
2. 공유 링크는 기간·암호·편집 권한  
3. 중요 자료는 클라우드 + **오프라인 복사** (3-2-1)  
4. 랜섬웨어 대비: OneDrive/Google의 버전·휴지통 기간 알아 두기  
5. 공용 PC에서 “이 장치 기억” 남발 금지
