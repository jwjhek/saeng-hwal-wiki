# Q-Dir 사용법

> **분류:** PC·OS · [[생활위키 목차]]

**Q-Dir**(Quad Explorer)는 Windows용 **다중 창 파일 관리자**다. 화면을 여러개로 나눠 폴더를 동시에 보고, **드래그 앤 드롭**으로 복사·이동한다. 
기본 **파일 탐색기**를 대체하거나, 탐색기 창을 여러 개 띄우는 대신 **한 창**에서 처리할 때 쓴다.

제작: SoftwareOK (Nenad Hrg)  
공식: [https://www.softwareok.com/?seite=Freeware/Q-Dir](https://www.softwareok.com/?seite=Freeware/Q-Dir)

확인일: 2026-08-11

관련: [[윈도우 사용법]] · [[Everything 사용법]] · [[반디집 사용법]] · [[WinMerge 사용법]] · [[웹 드라이브 비교]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **4분할** + **탭** 파일 탐색기 (Windows 탐색기 확장 느낌) |
| 비용 | **무료** (Freeware) |
| 설치 | **설치형** 또는 **포터블**(USB·폴더에서 실행) |
| 기반 | Windows **탐색기**와 비슷한 조작·보기 (익숙한 사용자 전제) |
| [[윈도우 사용법]]과 | 탐색기 단축키·드래그 습관을 **유지**하면서 칸만 늘림 |

```text
[한 칸 탐색기] Win+E 여러 번 → 창 전환
 ↓
[Q-Dir] 2~4칸 + 탭 → 한 화면에서 복사·대조
 ↓
[내용 비교] [[WinMerge 사용법]] — 줄·폴더 diff
```

Q-Dir은 **폴더를 빨리 옮기는** 도구이고, WinMerge는 **파일 내용이 같은지** 보는 도구다. 역할이 다르다.

---

## 2. 언제 쓰나

| 상황 | Q-Dir로 하는 일 |
|------|-----------------|
| USB·외장 HDD ↔ PC | 한 칸은 USB, 한 칸은 `문서` — **끌어다 놓기** |
| [[웹 드라이브 비교\|OneDrive]] 로컬 폴더 정리 | 동기화 폴더와 백업 폴더 **나란히** |
| 사진·동영상 대량 이동 | 출처·목적지 **동시 표시** |
| 프로젝트·vault 복사 | `src` / `dst` 두 칸 고정 |
| 구형 PC | 가벼운 **포터블**로 탐색기 대체 |
| 여러 경로 자주 방문 | **즐겨찾기**·폴더 조합 저장 |

탐색기 창을 3~4개 띄우는 습관이 있으면 Q-Dir이 **클릭 수**를 줄이는 경우가 많다.

---

## 3. 화면 구성

### 4분할(Quad) 레이아웃

| 요소 | 설명 |
|------|------|
| **창 1~4** | 각각 독립 **폴더 경로**. 2칸·3칸만 쓰는 레이아웃도 가능 |
| **탭** | 창마다 **여러 폴더**를 탭으로 (브라우저처럼) |
| **트리** | 왼쪽 **폴더 트리** 표시·숨김 전환 |
| **주소 표시줄** | 경로 입력·클릭 이동 (클래식·모던 스타일 선택) |
| **보기** | 자세히·목록·타일 등 탐색기와 유사 |

창 배치(2×2, 1+3 등)는 메뉴에서 바꾼다. 모니터가 넓을수록 4칸이 체감이 크다.

### 주요 기능

| 기능 | 쓰임 |
|------|------|
| **드래그 앤 드롭** | 칸 사이 **복사·이동** (Ctrl 누르면 복사 등 탐색기와 동일) |
| **즐겨찾기** | 자주 쓰는 **폴더 조합** 저장 (최대 수십 개 조합) |
| **색 필터** | 확장자·유형별 **글자색** — exe·zip 등 구분 |
| **폴더 크기** | 목록에 **용량·비율** 표시 (정리·백업 전) |
| **미리 보기** | 텍스트·이미지 등 **간단 미리보기** |
| **ZIP** | 압축 파일을 **폴더처럼** 열기 (기본 zip) |
| **FTP** | 원격 폴더 연결 (일반 사용자는 드묾) |
| **인쇄** | 현재 보기 목록 **인쇄** (감사·목록용) |

## 4. 설치·실행

### 설치형

1. 공식 사이트에서 **Q-Dir Installer** 받기  
2. 설치 후 실행 — 탐색기 **대체 프로그램**으로 등록하는 옵션은 취향 (필수 아님)

### 포터블

1. **포터블 zip** 또는 설치 파일 이름을 `Q-Dir.exe`로 바꿔 실행하는 방식(공식 안내)  
2. USB·`D:\Tools\` 등에 두고 **설치 없이** 실행  
3. PC마다 **같은 습관**으로 파일 관리 (회사·집)

32비트·64비트 빌드가 있다. Windows 11·10에서 **64비트**를 쓰는 경우가 많다.

### 첫 설정 팁

| 항목 | 권장 |
|------|------|
| 레이아웃 | 처음엔 **2칸**(좌우)만 켜고 익숙해지기 |
| 언어 | 메뉴에서 **한국어** 선택 (버전에 따라) |
| 즐겨찾기 | `다운로드`·`문서`·백업 드라이브 **한 세트** 저장 |
| 자동 업데이트 알림 | 거슬리면 설정에서 **끄기** (공식 FAQ에 방법) |

## 5. 기본 사용 흐름

### 폴더 두 개 복사

1. Q-Dir 실행  
2. **왼쪽 칸** — 출처 폴더 열기  
3. **오른쪽 칸** — 목적지 폴더 열기  
4. 파일·폴더를 **끌어다 놓기** (복사 vs 이동은 Ctrl·Shift 탐색기와 같음)  
5. 덮어쓰기 대화상자는 **한 번에** 확인

### 즐겨찾기(폴더 조합)

1. 네 칸에 자주 쓰는 경로를 각각 연다  
2. **즐겨찾기에 저장** — 이름 붙이기  
3. 다음부터 한 번에 **같은 배치** 복원

백업·사진 정리·개발 배포처럼 **고정 패턴**이 있을 때 유리하다.

### 탭

한 칸 안에서 `프로젝트A` · `프로젝트B` 탭을 열어 두고, 다른 칸은 `백업` 고정 — **탐색기 창 난립**을 줄인다.

## 6. 단축키·탐색기와 공통

[[윈도우 사용법]] 탐색기 단축키 대부분이 통한다.

| 단축키 | 동작 |
|--------|------|
| `Ctrl` + `C` / `X` / `V` | 복사 / 잘라내기 / 붙여넣기 |
| `F2` | 이름 바꾸기 |
| `Delete` | 삭제 |
| `F5` | 새로 고침 |
| `Alt` + `↑` | 상위 폴더 |

Q-Dir만의 **창·탭·칸 이동** 단축키는 `도움말`·설정에서 확인한다 (버전마다 다름).

## 7. 다른 도구와 비교

| | Windows 탐색기 | Q-Dir | [[WinMerge 사용법\|WinMerge]] |
|--|----------------|-------|------------------------------|
| 목적 | 일상 파일 열기 | **다중 경로** 동시 작업 | **내용·폴더 diff** |
| 창 | 보통 1경로 | **최대 4경로** + 탭 | 비교 시 2경로 |
| 포터블 | 내장 | **가능** | 설치형 일반적 |
| 클라우드 UI | OneDrive 통합 | **없음** (로컬 폴더는 동일) | 해당 없음 |
| zip·FTP | zip 기본 | zip·FTP 지원 | 해당 없음 |

**Total Commander** 등 유료·듀얼 패널 탐색기와 비슷한 니즈지만, Q-Dir은 **무료·4칸·가벼움** 쪽이다.

## 8. 주의·한계

| 주제 | 내용 |
|------|------|
| **UI** | 정보 밀도가 높아 **낯설 수** 있음. 2칸부터 |
| **클라우드** | OneDrive **상태 아이콘·공유** UI는 탐색기가 나을 때 있음 |
| **기본 앱** | Windows **기본 탐색기 완전 대체**는 설정·습관 문제. 병행도 흔함 |
| **대량 삭제** | 실수 방지 — 경로 **두 칸 다시 확인** |
| **보안** | 포터블 exe는 **공식 사이트**에서만 받기 |
| **버전** | SoftwareOK 제품은 **자주 업데이트**. 포터블도 가끔 교체 |

## 9. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | Windows용 **4칸 파일 관리자** (Quad Explorer) |
| 강점 | **한 화면**에서 복사·정리·즐겨찾기, **포터블** |
| 약점 | UI가 빽빽함, 클라우드 전용 기능은 약함 |
| 짝 | 이동·정리 **Q-Dir**, 내용 비교 **WinMerge**, 일상 **탐색기** |

## 면책

> **면책**  
> Q-Dir은 **서드파티** 무료 프로그램이다. 기능·메뉴·다운로드 경로는 **버전마다** 다르다. 공식 SoftwareOK 페이지를 본다.  
> 파일 삭제·덮어쓰기는 **되돌리기 어렵다.** 중요 데이터는 백업 후 작업한다.
