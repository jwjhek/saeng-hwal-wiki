# Everything 사용법

> **분류:** PC·OS · [[생활위키 목차]]

**Everything**은 Windows용 **파일 이름 검색** 도구다. 전체 디스크를 **인덱스**해 두고, 이름·경로를 타이핑하면 **거의 즉시** 결과가 나온다. 
Windows 기본 검색보다 **파일명·경로 찾기**에 특화되어 있다.

제작: voidtools  
공식: [https://www.voidtools.com](https://www.voidtools.com)

확인일: 2026-08-11

관련: [[윈도우 사용법]] · [[Q-Dir 사용법]] · [[반디집 사용법]]

---

## 1. 개요

| 항목          | 설명                                                 |
| ----------- | -------------------------------------------------- |
| 무엇          | **파일·폴더 이름** 검색 엔진 (본문 검색 엔진 아님)                   |
| 비용          | **무료** (개인·기업 사용 공식 허용)                            |
| 속도          | NTFS **MFT** 읽기로 인덱스 구축 — 수십만 파일도 **수 초~수 분**      |
| 실시간         | NTFS **USN 저널**로 변경 반영 (앱이 꺼져 있어도 저널 유지)           |
| [[윈도우 사용법]] | `Win`+`S`·탐색기 검색은 **다른 엔진**. Everything은 **이름** 위주 |

```text
[기억] 파일명 일부만 앎
 ↓
[Everything] 검색창에 입력 → 즉시 목록
 ↓
[열기] 더블클릭 · 우클릭 → 탐색기 · [[Q-Dir 사용법]]로 이동
```

**파일 내용**(문서 안 글자)을 찾을 때는 Windows 검색·에디터·`content:`(느림) 등 **다른 수단**이 낫다.

---

## 2. Windows 검색과 차이

| | Everything | Windows 검색 (Win+S 등) |
|--|------------|-------------------------|
| 인덱스 대상 | 주로 **이름·경로** (+ 선택 시 크기·날짜) | **내용·앱·설정** 등 넓음 |
| 속도 (이름) | **매우 빠름** | 설정·드라이브에 따라 느림 |
| NTFS | **MFT** 직접 활용 | Windows Search 인덱서 |
| 설치 | **별도 프로그램** | OS 내장 |
| USB FAT | **폴더 인덱스**로 추가 가능 | 제한적 |

둘을 **같이** 써도 된다. “그 설정 어디 있지?”는 Windows, “`report_2024_final_v3.docx` 어디 있지?”는 Everything.

---

## 3. 언제 쓰나

| 상황 | Everything |
|------|------------|
| 파일명 **일부**만 기억 | `budget`, `quartz.config` |
| 확장자로 걸러내기 | `*.md`, `*.pdf` |
| 특정 **폴더 아래**만 | `path:Documents` 등 |
| 오래된 백업 찾기 | 날짜·크기 조건 |
| 개발·위키 vault | `publish: true` 있는 md **파일명** 검색 |
| [[반디집 사용법]]으로 받은 zip **이름** 찾기 | 압축 풀기 전 위치 확인 |

## 4. 설치·인덱스

### 설치

1. [voidtools](https://www.voidtools.com)에서 **설치형** 또는 **포터블** 받기  
2. 첫 실행 시 **NTFS 볼륨** 인덱스 구축 (진행 표시)  
3. (권장) **Everything 서비스** 설치 또는 **관리자** 실행 — NTFS 전체 인덱스에 필요할 수 있음

UAC(관리자 권한) 없이 쓰려면 공식 FAQ의 **서비스 설치** 안내를 본다.

### 무엇이 인덱스되나

| 대상 | 기본 |
|------|------|
| 로컬 **NTFS** 고정 디스크 | **자동** |
| **ReFS** | 자동 (버전에 따름) |
| **FAT·exFAT** USB | **폴더 인덱스**로 수동 추가 |
| **네트워크 드라이브** | 폴더 인덱스 |
| **제외** | 옵션에서 경로·종류 제외 가능 |

NTFS 볼륨을 **폴더 인덱스에 또 넣으면** 결과가 **중복**될 수 있다 (공식 FAQ).

### 안 잡힐 때

| 증상 | 확인 |
|------|------|
| 드라이브 전체가 없음 | `도구` → `옵션` → `인덱스` → **NTFS** 탭에서 해당 볼륨 **포함** |
| 외장·USB | **폴더 인덱스**에 경로 추가 |
| 결과가 옛날 | **강제 다시 인덱스** (옵션) |
| Windows 검색만 리빌드함 | **효과 없음** — Everything 인덱스는 **별도** |

## 5. 기본 사용법

### 검색창

1. Everything 실행 (작업 표시줄·**단축키**로 띄우기 설정 가능)  
2. 검색창에 **파일명 일부** 입력  
3. 목록이 **즉시** 줄어듦  
4. 항목 **더블클릭** — 열기 / **Enter** — 기본 동작  
5. **우클릭** — 경로 복사, 탐색기에서 폴더 열기, 속성

처음에는 **필터 없이 전체 목록**이 보이다가, 글자를 치면 좁혀진다 (“Everything”이라는 이름의 유래).

### 자주 쓰는 패턴

| 입력 예 | 의미 |
|---------|------|
| `readme` | 이름에 readme 포함 |
| `*.md` | 확장자 md |
| `*.png \| *.jpg` | png 또는 jpg (`\|` = 또는) |
| `!*.tmp` | tmp **제외** (`!`) |
| `"exact name.txt"` | 공백·정확 구문 |
| `quartz config` | 공백 = **AND** (둘 다 포함) |

### 경로·속성 (고급)

| 연산 | 예 | 설명 |
|------|-----|------|
| `path:` | `path:생활위키` | 경로에 문자열 포함 |
| `parent:` | `parent:templates` | 직속 부모 폴더 |
| `size:` | `size:>10mb` | 크기 (인덱스된 경우 빠름) |
| `dm:` | `dm:lastmonth` | 수정일 (버전·로케일에 따름) |
| `content:` | `content:면책` | **본문** 검색 — **느림**, 기본 미인덱스 |

정확한 연산자 목록은 공식 **검색 문법**·도움말(chm)을 본다.

## 6. 편의 기능

| 기능 | 쓰임 |
|------|------|
| **북마크** | 자주 쓰는 검색·폴더 저장 |
| **필터 메뉴** | 오디오·비디오·문서 등 **종류** 버튼 |
| **정렬** | 이름·경로·크기·날짜 (크기·날짜는 인덱스 옵션) |
| **HTTP·ETP** | 같은 LAN에서 브라우저로 검색 (고급·보안 주의) |
| **다국어 UI** | 한국어 포함 |

시작 프로그램 등록·**전역 단축키**(예: `Ctrl`+`Shift`+`E`)를 켜 두면 탐색기를 뒤지는 시간이 줄어든다.

## 7. 다른 도구와 함께

| 도구 | 역할 |
|------|------|
| **Everything** | 파일 **어디 있나** (이름) |
| [[Q-Dir 사용법]] | 찾은 폴더에서 **복사·정리** |
| [[반디집 사용법]] | 찾은 **압축** 풀기 |
| [[WinMerge 사용법]] | 찾은 두 파일 **내용 비교** |
| [[VS Code 사용법]] | `Ctrl`+`P`는 **연 workspace** 안만 |

Git 저장소 안 파일은 VS Code/Cursor 검색과, PC 전체는 Everything과 **역할을 나눈다**.

---

## 8. 주의·한계

| 주제 | 내용 |
|------|------|
| **내용 검색** | 기본은 **파일명**. 본문은 `content:` 또는 다른 도구 |
| **권한** | NTFS 인덱스에 **관리자·서비스** 필요할 수 있음 |
| **네트워크** | NAS는 **실시간**이 느리거나 폴더 인덱스만 |
| **보안** | HTTP 서버·원격 검색은 **방화벽·신뢰 네트워크**만 |
| **개인정보** | 인덱스는 **이름·경로** 노출. 공용 PC 주의 |
| **Windows Search** | 인덱스 **공유 안 함** — 각각 관리 |

## 9. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | Windows **초고속 파일명** 검색 (voidtools) |
| 강점 | NTFS **즉시** 인덱스·실시간 갱신·가벼움 |
| 약점 | **본문** 검색은 비주력 |
| 습관 | 단축키로 띄우고 `*.확장자`·`path:` 조합 |
