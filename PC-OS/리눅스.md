# 리눅스

> **분류:** PC·OS · [[생활위키 목차]]

**리눅스**(Linux)는 **커널** 이름이다. 일상에서는 **리눅스 배포판**(Ubuntu·Mint 등) — 커널 + GNU 도구 + 바탕화면 + 앱 묶음 — 을 통틀어 **「리눅스」** 라고 부르는 경우가 많다.

무료·오픈 소스이며, **서버·클라우드·개발·구형 PC·[[안드로이드]](커널)** 에 넓게 쓰인다. 
윈도우만 쓰다가도 **WSL**·**SSH**·**Docker**·**[[Termux 사용법]]** 로 터미널 명령을 만난다.

확인일: 2026-08-11

관련: [[리눅스 기본 명령어]] · [[Ubuntu]] · [[Linux Mint]] · [[저사양 PC용 무료 OS]] · [[윈도우 사용법]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **커널** | 하드웨어·프로세스·메모리를 다루는 OS 핵심. **Linux** |
| **배포판** | 커널 + 패키지 + (선택) 바탕화면. **Ubuntu**, **Mint**, Fedora 등 |
| **쉘** | 명령을 받는 인터페이스. **bash**가 흔함 → [[리눅스 기본 명령어]] |
| **Unix-like** | `ls`, `grep`, `ssh` 등 **유닉스 계열** 명령·철학을 공유. macOS·BSD와도 겹침 |

```text
[커널] Linux
   +
[도구] GNU coreutils, bash, apt/dnf …
   +
[UI] GNOME · KDE · Xfce … (데스크톱만)
   =
배포판 (예: Ubuntu Desktop, Ubuntu Server)
```

**[[BSD Unix]]** 는 **다른 커널**이지만 쉘·명령이 비슷해 **같이 배우는** 경우가 많다.

---

## 2. 어디서 만나나

| 환경 | 설명 |
|------|------|
| **PC 데스크톱** | [[Linux Mint]] · [[Ubuntu]] · [[저사양 PC용 무료 OS]] |
| **서버·클라우드** | VPS·AWS·Azure **Ubuntu Server** 등 — **SSH**로 접속 |
| **윈도우 안** | **WSL2** + Ubuntu — [[윈도우 사용법]] |
| **[[안드로이드]]** | 커널은 Linux. 앱·화면은 PC 배포판과 다름. 폰 터미널은 **[[Termux 사용법]]** |
| **컨테이너** | [[Docker 사용법]] 이미지 대부분이 **리눅스** 기반 |
| **맥** | 커널은 Darwin. 터미널 명령은 **Unix-like**로 [[리눅스 기본 명령어]]와 겹침 |

윈도우를 유지해도 **개발·서버 학습**에서는 리눅스 명령을 자주 본다.

## 3. 윈도우·macOS와 비교 (대략)

| | Windows | macOS | 리눅스 (데스크톱) |
|--|---------|-------|-------------------|
| 라이선스 | 상용 (대부분 PC에 포함) | Apple 하드웨어 중심 | **무료** 배포판 다수 |
| 앱 | `.exe` · Microsoft Store | `.app` · App Store | **저장소·Flatpak** 등 |
| 터미널 | PowerShell · cmd · WSL | Terminal · zsh/bash | **기본 터미널**이 핵심 도구 |
| 게임·은행 | 강함 | 중간 | **제한** 있는 경우 많음 — 웹·듀얼부팅 |
| 서버 점유 | 있음 | 적음 | **매우 큼** |

「PC를 리눅스로 **완전 교체**」와 「WSL로 **명령만**」은 목적이 다르다.

---

## 4. 배포판 고르기 (입문)

| 목적 | 먼저 볼 글 |
|------|------------|
| 구형 PC·윈도우 대체 | [[저사양 PC용 무료 OS]] → [[Linux Mint]] · [[Ubuntu]] 플레이버 |
| 웹·크롬만 | [[ChromeOS Flex]] |
| 공식 우분투·서버·WSL | [[Ubuntu]] |
| Android 터미널 | [[안드로이드]] · [[Termux 사용법]] |
| Unix 계열 이해 | [[BSD Unix]] |

배포판마다 **패키지 관리자**가 다르다.

| 계열 | 예 | 설치 명령 예 |
|------|-----|-------------|
| Debian·Ubuntu | [[Ubuntu]], [[Linux Mint]] | `sudo apt install …` |
| Fedora·RHEL | Fedora, Rocky | `sudo dnf install …` |
| Arch | Arch, Manjaro | `sudo pacman -S …` |

아래 명령 글은 **Ubuntu·Mint·WSL** 문맥이 많아 **`apt`** 를 [[리눅스 기본 명령어]]에서 같이 다룬다.

---

## 5. 터미널에서 시작하기

1. **터미널** 앱 실행 (Ubuntu: `Ctrl+Alt+T` 등)  
2. 프롬프트에 **명령 + Enter**  
3. 막히면 `명령 --help` 또는 `man 명령`  

```bash
pwd          # 지금 폴더
ls           # 목록
cd Documents # 이동
```

전체 표·습관·주의는 **[[리눅스 기본 명령어]]** 에 모았다.

## 7. 실전 체크

- [ ] **배포판·에디션**(Desktop vs Server)을 목적에 맞게 골랐는가  
- [ ] PC 교체 전 **Live USB**·와이파이·한글·필수 앱을 시험했는가 ([[Ubuntu]]·[[Linux Mint]])  
- [ ] 윈도우 유지 시 **WSL**·[[리눅스 기본 명령어]]로 연습할 계획이 있는가  
- [ ] `sudo`·`rm -rf` 같은 **위험 명령**을 알고 있는가  
- [ ] 은행·보안·게임 **미지원** 가능성을 확인했는가

## 면책

> **면책**  
> 배포판·지원 기간·하드웨어 호환은 **버전·기기**마다 다르다. 공식 사이트·릴리스 노트가 우선.  
> 터미널 명령은 **데이터 삭제·시스템 손상**을 일으킬 수 있다. 백업·복구 계획을 둔다.  
> 이 글은 OS 교체·서버 운영을 권유하지 않는다.
