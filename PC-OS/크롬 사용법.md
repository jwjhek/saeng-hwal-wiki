# 크롬 사용법

> **분류:** PC·OS · [[생활위키 목차]]

Google Chrome은 Chromium 기반 **웹 브라우저**다. 검색·웹앱·개발자 도구·동기화가 한곳에 있어 PC 일상의 기본 창구인 경우가 많다. 
Windows에서는 보통 [[윈도우 사용법]] 위에 올린다. Edge·Brave 등도 같은 계열이면 단축키·설정이 비슷하다.

공식: [https://www.google.com/chrome/](https://www.google.com/chrome/) 
다운로드는 **공식 사이트**만 사용한다.

확인일: 2026-08-13 
메뉴 이름은 Chrome 버전·언어에 따라 조금 다를 수 있다.

---

## 1. 설치·기본 앱

1. 공식에서 설치 → Google 계정으로 로그인(선택) 
2. Windows: `설정` → `앱` → `기본 앱` → Chrome을 기본 브라우저로 ([[윈도우 사용법]]) 
3. 주소창에 `chrome://version` — 버전·경로 확인 

모바일 Chrome은 [[갤럭시 워치 사용법]] 폰에서 Play 스토어로. PC와 **같은 Google 계정**이면 탭·북마크 동기화가 된다.

## 4. 프로필·동기화 (여러 계정)

**프로필**은 북마크·쿠키·확장·저장된 로그인을 **칸막이**로 나눈다.  
창 오른쪽 위 **프로필 아이콘**(이름·사진)이 지금 칸이다.

| 개념 | 설명 |
|------|------|
| **프로필** | 사람·용도별 **별도 Chrome**. 창이 따로 열림 |
| **Google 계정** | 프로필마다 **다른 계정**을 넣을 수 있음 (개인 / 회사 / 유튜브 전용 등) |
| **동기화** | 그 프로필에 로그인한 계정의 북마크·암호 등이 **그 칸만** 기기 간 맞춤 |
| **게스트** | 흔적 적게. 닫으면 그 세션이 사라지는 쪽에 가까움 |
| **시크릿** | `Ctrl` + `Shift` + `N` — **임시 창**. 프로필을 새로 만드는 것과 다름 |

회사 메일·개인 쇼핑·[[Bitwarden 사용법]]을 **한 프로필에 몰면** 쿠키·확장이 섞인다. **용도당 프로필 하나**가 기본이다.

```text
프로필 A (개인 Google)     프로필 B (회사 Google)
북마크·확장·로그인 분리     북마크·확장·로그인 분리
        ↘ 창이 둘
```

### 4.1 프로필 추가

메뉴 이름은 버전·한국어 UI에 따라 `다른 프로필 추가` / `추가`로 보일 수 있다.

1. 오른쪽 위 **프로필 아이콘** 클릭  
2. **다른 프로필 추가**(또는 `+ 추가`)  
3. **계정 없이 계속** 또는 **Google 계정으로 로그인**  
4. **이름·색·아바타**를 정해 구분 (예: `개인`, `회사`, `유튜브`)  
5. 새 **창**이 열린다 — 그게 새 프로필이다  

설정에서 하려면: 주소창 `chrome://settings` → **나와 Google**(또는 사람·프로필) → 프로필 추가.  
정확한 경로: `chrome://settings/manageProfile` · 목록은 `chrome://profile-picker/` (버전마다 다름).

로그인하지 않아도 프로필은 만들 수 있다. **동기화**만 안 될 뿐이다.

### 4.2 전환

| 방법 | 동작 |
|------|------|
| 프로필 아이콘 → 다른 이름 | **그 프로필 창**으로 (없으면 새 창) |
| 작업 표시줄 Chrome 아이콘 | 여러 창이 떠 있으면 각각이 **다른 프로필**일 수 있음. 제목 표시줄·아이콘 색으로 구분 |
| 시작 시 | 마지막에 쓰던 프로필, 또는 **프로필 선택 화면** (설정에 따름) |

한 창 안에서 탭만 바꿔 **계정이 바뀌지는 않는다.** 계정 칸막이는 **창(프로필)** 단위다.

### 4.3 이름·색·바로 가기

1. 프로필 아이콘 → **프로필 맞춤설정**(톱니·연필)  
2. 이름·테마 색·캐릭터  
3. **바탕 화면 바로 가기 만들기**가 있으면, 아이콘을 눌러 **그 프로필만** 바로 연다  

Windows에서 바로 가기가 안 보이면: 프로필 선택 화면에서 해당 칸 메뉴를 보거나, Chrome 도움말의 `--profile-directory` 안내를 본다. 경로는 `chrome://version`의 **프로필 경로**로 확인.

작업 표시줄에 **프로필마다** 고정하려면, 그 프로필 창을 연 뒤 아이콘 우클릭 **작업 표시줄에 고정** (창이 해당 프로필인지 확인).

### 4.4 Google 계정 여러 개

| 하고 싶은 일 | 하는 법 |
|--------------|---------|
| 메일·드라이브가 **다른 계정** | 프로필을 나누고 **각각 로그인** |
| 같은 프로필에서 계정만 추가 | Gmail 등에서 계정 전환은 됨. **쿠키·유튜브 추천은 섞이기 쉬움** |
| 동기화 항목 줄이기 | 설정 → 나와 Google → **동기화** — 암호·결제만 끄기 등 |

**회사 Google Workspace**와 **개인 Gmail**은 프로필을 나누는 편이 안전하다. 확장·화면 캡처·광고 로그인이 안 넘어간다.

암호는 프로필마다 브라우저 저장이 갈린다. 공통 금고는 [[Bitwarden 사용법]] — **확장도 프로필마다 설치**해야 한다.

### 4.5 게스트 · 시크릿 · 프로필

| | 프로필 | 게스트 | 시크릿 |
|--|--------|--------|--------|
| **북마크·확장** | 그 칸에 유지 | 거의 안 남김 | 기존 프로필 확장 일부만, 기록은 창 닫으면 약함 |
| **용도** | 일상·업무 분리 | 잠깐 빌려 주기 | 검색만 남기고 싶지 않을 때 |
| **로그인 유지** | 됨 | 닫으면 끝 | 창 닫으면 그 세션 쿠키는 안 남는 편 |

시크릿은 **새 프로필이 아니다.** 다운로드 폴더에 받은 파일은 남는다.

아이용 **감독 대상 계정**(Family Link 등)은 Google 가족 설정과 묶인다. 메뉴·가능 여부는 공식 안내.

### 4.6 삭제·정리

1. 프로필 아이콘 → 관리 / 설정 → 해당 프로필 **삭제**  
2. 또는 `chrome://settings` 프로필 목록에서 제거  

삭제하면 그 칸의 **로컬 북마크·쿠키·확장 데이터**가 사라질 수 있다. Google 동기화를 켜 두었으면 **클라우드 쪽 계정 데이터는 남을** 수 있다. 회사 PC 반납 전에는 프로필 삭제 + 계정 로그아웃.

프로필이 많아지면 메모리가 는다. 안 쓰는 칸은 창을 닫거나 삭제.

### 4.7 동기화 위치 (참고)

설정 → 나와 Google → 동기화 및 Google 서비스.  
암호·결제 수단은 항목을 **선택적으로** 끈다.

팁: 회사 PC와 개인을 **프로필로 나누면** 확장·쿠키가 섞이지 않는다.

## 5. 북마크·다운로드·검색

### 북마크

- 폴더로 주제별 정리 
- 북마크 바에는 **매일 쓰는 것만** 
- 백업: 북마크 관리자 → ⋮ → 북마크 내보내기(HTML) 

### 다운로드

- 기본 폴더: 보통 `다운로드` ([[윈도우 사용법]] 파일·폴더) 
- 설정 → 다운로드에서 위치·다운로드 전 저장 위치 묻기 
- `chrome://downloads` 또는 `Ctrl` + `J` 

### 검색엔진

설정 → 검색엔진 → 주소창에 사용된 검색엔진. 
사이트별 검색: 검색엔진 관리에서 키워드 지정(예: `wiki` → 위키 검색).

## 6. 확장 프로그램

`chrome://extensions` 또는 Chrome 웹 스토어.

| 할 일 | 메모 |
|------|------|
| 설치 | 스토어에서 추가 → 권한 확인 |
| 핀 | 툴바에 고정 |
| 끄기/제거 | 확장 페이지에서 |
| 사고 대응 | 수상한 확장은 즉시 제거 + 암호 변경 |

원칙:

1. **최소 설치** — 탭·CPU·개인정보 비용 
2. 권한(모든 사이트 데이터 읽기)이 과하면 재고 
3. 스토어 평점·게시자·최근 업데이트 확인 
4. 애드블록·비밀번호 관리자·번역 정도가 실사용 상위권 

개발·위키: 불필요하면 끄고, [[Cursor 사용법]]·에디터와 역할을 나눈다.

## 7. 비밀번호·자동완성·안전

1. Google 비밀번호 관리자 또는 외부 관리자([[Bitwarden 사용법]]) 
2. 설정 → 자동 완성 — 주소·결제 저장 여부 
3. **유출 알림**이 있으면 해당 사이트 암호 변경 
4. HTTPS·자물쇠 아이콘 — 민감 정보는 HTTP에 치지 않기 
5. 가짜 주소(호모그래프)·급한 “계정 정지” 메일 경계 
6. 확장·테마는 공식 스토어 위주 

사이트 데이터 삭제: `Ctrl` + `Shift` + `Delete` → 기간·쿠키·캐시 선택. 
한 사이트만: 주소창 자물쇠/튜닝 아이콘 → 사이트 설정 → 데이터 삭제.

## 8. 성능·탭 관리

| 증상 | 시도 |
|------|------|
| 느림·팬 소음 | 탭·확장 줄이기, 작업 관리자(`Shift` + `Esc`) |
| 메모리 | 안 쓰는 프로필·탭 그룹으로 접기 |
| 깨진 페이지 | 강력 새로고침, 캐시·쿠키 삭제, 하드웨어 가속 on/off |
| 영상 끊김 | 하드웨어 가속, GPU 드라이버 ([[윈도우 사용법]] 성능) |

탭 그룹: 탭 우클릭 → 탭을 새 그룹에 추가. 색·이름으로 업무/쇼핑 분리. 
검색으로 탭 찾기: `Ctrl` + `Shift` + `A` (지원 버전).

Chrome 작업 관리자: `Shift` + `Esc` — 어떤 탭·확장이 무거운지 종료.
