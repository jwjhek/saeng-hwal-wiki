# 저사양 PC용 무료 OS

> **분류:** PC·OS · [[생활위키 목차]]

윈도우가 버겁거나 지원이 끝난 PC를 **무료 OS**로 살려 쓰는 선택지를 비교한다.  
요즘 자주 거론되는 축은 **[[ChromeOS Flex]]**, **[[Linux Mint]]**, 그리고 Mint와 뿌리가 가까운 **우분투 계열 경량판**(Lubuntu 등)이다.

확인일: 2026-08-07

상세: [[ChromeOS Flex]] · [[Linux Mint]] · (바탕) [[윈도우 사용법]]

---

## 1. 문서 구성 (3개)

| 문서 | 역할 |
|------|------|
| **이 글** | 저사양·무료 OS **비교·고르는 흐름** |
| [[ChromeOS Flex]] | 구글 클라우드·브라우저 중심 Flex |
| [[Linux Mint]] | 윈도우 느낌의 리눅스, 저사양엔 Xfce |

우분투 본판(GNOME)은 저사양에선 무거울 때가 많아, **Mint / Lubuntu·Xubuntu** 쪽으로 연결해 둔다.  
별도 “우분투만” 문서는 두지 않고, 필요하면 이 글 §4와 [[Linux Mint]]를 본다.

---

## 2. 한눈에 비교

| | [[ChromeOS Flex]] | [[Linux Mint]] | 우분투 경량판 (Lubuntu 등) |
|--|-------------------|----------------|---------------------------|
| 성격 | 크롬북에 가까운 **웹·클라우드 OS** | 데스크톱 리눅스, **윈도우 이주민**에 친절 | 우분투 저장소 + **가벼운 바탕화면** |
| 강점 | 관리 단순, 자동 업데이트, 빠릿한 웹 | 앱·한글·프린터 등 **로컬 PC**에 가깝음 | 램이 더 빠듯할 때 Mint보다 가벼울 수 있음 |
| 약점 | 윈도우 전용 프로그램·일부 장치 | 학습·드라이버·앱 호환 이슈 가능 | 커뮤니티·UI가 Mint보다 덜 “완성품” 느낌일 수 있음 |
| 저사양 감각 | 공식 최소 **RAM 4GB** 급, **인증 기기** 확인 | **Xfce** 에디션 권장 감각, RAM 4GB면 여유 | RAM **2GB대** 논의도 많음(브라우저는 여전히 무거움) |
| 이런 사람 | 메일·문서·유튜브·웹앱 위주 | 오피스·파일·일부 리눅스 앱을 PC에 두고 싶음 | Mint도 버거울 때, 우분투 계열을 유지하고 싶을 때 |

공통: **SSD + 백업 + Live USB로 먼저 시험**이 HDD·무백업 설치보다 체감·안전에 유리하다.

---

## 3. 언제 무엇을

```text
주로 브라우저·구글/웹 오피스만 씀
        → [[ChromeOS Flex]] (인증 PC면 더 안심)
윈도우처럼 시작 메뉴·로컬 파일·다양한 앱
        → [[Linux Mint]] (저사양이면 Xfce)
Mint Cinnamon도 무겁다 / 램이 더 적다
        → Mint Xfce 또는 Lubuntu·Xubuntu (이 글 §4)
윈도우 전용 프로그램이 필수
        → 무료 OS만으로 해결 어려움 → [[윈도우 사용법]] 유지·원격·새 PC
극저사양(램 1GB대 등)
        → antiX·Puppy 등 초경량 (이 글은 맛보기만, 공식 위키 확인)
```

---

## 4. 우분투 계열은 어디에 두나

| 이름 | 감각 |
|------|------|
| Ubuntu (GNOME) | 자료·드라이버 정보는 많음. **저사양 첫 선택으론 무거울 수 있음** |
| Xubuntu | Xfce + 우분투 |
| Lubuntu | LXQt 등, **더 가볍게** 가는 공식 플레이버로 자주 언급 |
| [[Linux Mint]] | 우분투(또는 Debian) 기반 + **민트만의 UI·도구**(업데이트·소프트웨어 관리) |

Mint를 고르면 “우분투 앱 생태계”에 가까운 길을 가면서, 초보 UI는 Mint 쪽이 낫다는 평가가 많다.  
그래서 이 묶음에서는 **Mint 문서를 우분투 쪽 대표 상세글**로 둔다.

---

## 5. 설치 전 공통 체크

- [ ] 중요 파일 **백업** (외장·클라우드)  
- [ ] USB로 **체험(Live)** 부팅 — 와이파이·화면·소리·터치패드  
- [ ] BIOS/UEFI에서 USB 부팅·Secure Boot 이슈 확인  
- [ ] [[ChromeOS Flex]]면 **인증 모델 목록**  
- [ ] 가능하면 **HDD→SSD** (OS 교체보다 체감 큰 경우 많음)  
- [ ] 회사·학교 계정·프린터·은행 앱 호환  

---

## 6. 정리

저사양·무료로 PC를 살리려면 **웹 중심이면 Flex**, **윈도우 같은 데스크톱이면 Mint(Xfce)**, **더 가볍게 우분투 계열이면 Lubuntu 등**을 보면 된다.  
세부 설치·특징은 [[ChromeOS Flex]] · [[Linux Mint]]로 이어진다.
