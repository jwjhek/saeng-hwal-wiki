# ChromeOS Flex

> **분류:** PC·OS · [[생활위키 목차]]

구글이 기존 PC·맥에 설치할 수 있게 만든 **ChromeOS Flex**(무료)다.  
크롬북처럼 **브라우저·웹앱·클라우드** 중심이며, 저사양·구형 PC “웹 기기화”에 자주 거론된다.

비교 전체: [[저사양 PC용 무료 OS]] · 대안 데스크톱: [[Linux Mint]]

> **면책**  
> 설치 시 디스크를 지울 수 있다. **백업 필수**.  
> 인증되지 않은 PC는 기능·안정성이 보장되지 않는다.  
> 요구 사양·인증 목록·지원 종료일은 **구글 공식 도움말**이 우선.

확인일: 2026-08-07

---

## 1. 한눈에

| 항목 | 내용 |
|------|------|
| 무엇 | PC에 올리는 **크롬OS 계열** (Android 앱·Play 스토어는 일반 크롬북과 다름) |
| 맞는 용도 | 메일, [[크롬]], 문서(웹), 화상회의, 유튜브 |
| 안 맞는 용도 | 윈도우 전용 설치형 프로그램, 고사양 로컬 작업 |
| 저사양 | 공식 감각: **64비트 CPU, RAM 4GB+, 저장 16GB+**, USB 부팅 |

“윈도우 대체”가 아니라 **웹 단말로 바꾸는 선택**에 가깝다.

---

## 2. [[Linux Mint]]·우분투와 비교

| | ChromeOS Flex | [[Linux Mint]] 등 |
|--|---------------|-------------------|
| 앱 | 웹·PWA·일부 리눅스 앱(환경에 따라) | 데스크톱 앱·저장소 패키지 |
| 관리 | 구글 계정·자동 업데이트 감각 | 사용자가 업데이트·드라이버·저장소 |
| 익숙함 | 크롬·크롬북 사용자 | 윈도우 시작 메뉴형 UI (Mint) |
| 오프라인 | 제한적일 수 있음 | 로컬 앱·파일에 유리 |
| 기기 | **인증 목록** 중요 | 대체로 폭넓게 시도 가능(드라이버는 케이스별) |

웹만 쓰면 Flex, **로컬 오피스·다양한 프로그램**이면 Mint 쪽이 자연스럽다.  
고르는 흐름은 [[저사양 PC용 무료 OS]].

---

## 3. 인증 기기

구글은 모델별로 **Certified / 이슈 / 지원 종료** 등을 공개한다.  
목록에 있으면 안정성·지원 기간을 가늠하기 쉽고, 없으면 부팅은 돼도 **와이파이·절전·그래픽**이 불완전할 수 있다.

설치 전: 공식 **ChromeOS Flex certified models**에서 제조사·모델명을 검색한다.

---

## 4. 설치 감각 (요약)

1. 데이터 백업  
2. 다른 PC에서 Flex 설치 매체를 만듦 (구글 안내·Chromebook Recovery Utility 등)  
3. USB로 부팅해 **체험**  
4. 문제 없으면 내장 디스크에 설치 (기존 OS 삭제될 수 있음)  
5. 구글 계정 로그인, [[크롬]] 동기화·확장  

회사·교육용 기기는 관리 콘솔·정책이 있을 수 있다.

---

## 5. 장점 / 한계

| 장점 | 한계 |
|------|------|
| 인터페이스 단순, 부팅·웹이 가벼운 편 | 윈도우 .exe 그대로 불가 |
| 자동 업데이트·샌드박스 감각 | Play 스토어·안드로이드 앱은 크롬북과 동일하지 않음 |
| 구형 PC를 “브라우저 머신”으로 재활용 | 인증 밖·드라이버 이슈 |
| | 로컬 전문 소프트는 [[Linux Mint]]·윈도우가 나을 수 있음 |

은행·정부 사이트는 **브라우저·보안 프로그램** 호환을 미리 확인한다.

---

## 6. 실전 체크

- [ ] 인증 모델인가, 지원 종료일은?  
- [ ] RAM 4GB·SSD 여부  
- [ ] Live/USB 체험에서 무선·화면·입력  
- [ ] 필수 작업이 웹으로 가능한가  
- [ ] 백업 완료  

---

## 7. 정리

ChromeOS Flex는 **무료로 PC를 크롬OS처럼** 쓰는 길이다.  
저사양·웹 중심이면 후보이고, 로컬 데스크톱이 필요하면 [[Linux Mint]]와 [[저사양 PC용 무료 OS]] 비교를 본다.
