# Ubuntu

> **분류:** PC·OS · [[생활위키 목차]]

**Ubuntu**(우분투)는 **Canonical**이 배포하는 **데비안(Debian) 계열 리눅스**다. 
데스크톱·노트북용 **Ubuntu Desktop**, 서버·클라우드용 **Ubuntu Server**로 나뉘며, 
질문 자료·튜토리얼·[[Docker 사용법]] 기본 이미지 등에서 **가장 자주 보이는 리눅스 이름** 중 하나다.

초보 PC 이주에는 UI가 익숙한 [[Linux Mint]]가 더 자주 추천되기도 하지만, 
**우분투 본판·공식 플레이버·서버**를 직접 쓰는 경우도 많다.

비교 전체: [[저사양 PC용 무료 OS]] · [[리눅스]] · 윈도우형 UI: [[Linux Mint]] · 웹 단말: [[ChromeOS Flex]]

공식: [https://ubuntu.com](https://ubuntu.com)

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **무료·오픈 소스** 리눅스 배포판. 데스크톱·서버·클라우드·WSL 등 폭넓게 쓰임 |
| 기반 | **Debian** 패키지·도구를 계승. `apt`·`.deb` 생태계 |
| 배포 | **Canonical**이 정기 릴리스·LTS·보안 업데이트 관리 |
| 데스크톱 UI | 기본은 **GNOME**. 공식 **플레이버**는 KDE·Xfce·LXQt 등 다른 바탕화면 |
| 서버 | **Ubuntu Server** — SSH·클라우드 VM·[[Docker 사용법]]·[[쿠버네티스]] 문맥에서 흔함 |
| Mint와 | [[Linux Mint]]는 **우분투(또는 Debian) 기반** 파생 배포판. 앱·저장소가 가까움 |

“리눅스 = 우분투”로 부르는 경우가 있을 정도로 **검색·문서·클라우드**에서 노출이 크다.

---

## 2. 데스크톱 vs 서버

```text
Ubuntu Desktop (GNOME 등)
 → 노트북·PC 일상 사용, 개발자 워크스테이션

Ubuntu Server (GUI 없음이 기본)
 → VPS·AWS·Azure·온프레 VM, 웹·DB·컨테이너 호스트

Windows + WSL
 → 윈도우 안에서 우분투 커널·사용자 공간 실행 ([[윈도우 사용법]]과 병행)
```

| | Desktop | Server |
|--|---------|--------|
| 목적 | 브라우저·오피스·개발 IDE | 원격 서비스·배치·인프라 |
| UI | 그래픽 바탕화면 기본 | **터미널·SSH** 중심 |
| 설치 이미지 | ISO + Live 체험 | 최소 패키지, 클라우드 이미지 많음 |
| 이 위키 | [[저사양 PC용 무료 OS]]·[[Linux Mint]]와 비교 | [[Docker 사용법]]·[[Git 사용법]]·CI와 연결 |

서버용을 PC에 억지로 데스크톱처럼 쓰기보다, **용도에 맞는 에디션**을 고른다.

## 3. LTS와 일반 릴리스

| 종류                          | 설명                                                            |
| --------------------------- | ------------------------------------------------------------- |
| **LTS** (Long Term Support) | **2년마다** 주요 버전. **5년** 표준 지원(확장 옵션 있음). **PC·서버 첫 선택**에 자주 권장 |
| **중간 릴리스**                  | 6개월 주기. 최신 하드웨어·데스크톱 기능 빠름. 지원 기간 **짧음** (약 9개월)              |

버전 번호 예: **24.04 LTS**, **22.04 LTS** (연도.월 형식).  
안정·장기 사용이면 **LTS ISO**를 받는 편이 낫다. 중간 버전은 “최신 칩·실험”에 가깝다.

## 4. 공식 플레이버 (바탕화면)

Ubuntu **본판**은 GNOME이다. **같은 우분투 저장소**에 다른 UI만 바꾼 **공식 플레이버**가 있다.

| 플레이버 | 바탕화면 | 메모 |
|----------|----------|------|
| **Ubuntu** | GNOME | 기본. 자료 많음. **저사양에선 무거울 수 있음** |
| **Kubuntu** | KDE Plasma | 설정·꾸미기 풍부. GNOME과 체감 무게 비슷한 편일 수 있음 |
| **Xubuntu** | Xfce | **저사양** 후보. [[Linux Mint]] Xfce와 비슷한 축 |
| **Lubuntu** | LXQt | **더 가볍게** 가는 공식 플레이버로 자주 언급 |
| **Ubuntu MATE** | MATE | 전통적 메뉴·패널 |
| **Ubuntu Budgie** | Budgie | 단순·모던 UI |

```text
저사양·구형 PC
 → Lubuntu · Xubuntu · [[Linux Mint]] Xfce
GNOME 그대로 + 자료 최대
 → Ubuntu Desktop LTS
윈도우 느낌 + 민트 도구
 → [[Linux Mint]] (우분투 기반)
```

플레이버마다 **별도 ISO**를 받아 Live로 체험하는 것이 좋다.

## 5. [[Linux Mint]]와 비교

| | Ubuntu (본판·플레이버) | [[Linux Mint]] |
|--|------------------------|----------------|
| 정체성 | **공식 우분투** 계열 | 우분투(또는 Debian) **파생**, 민트만의 UI·도구 |
| 데스크톱 | GNOME 또는 플레이버 선택 | **Cinnamon** 등, 윈도우에 가까운 UX로 유명 |
| 업데이트 | Canonical·`unattended-upgrades` 등 | 민트 **업데이트 관리자** 정책 (보수적 옵션 있음) |
| 초보 | 자료는 많으나 GNOME 이질감 | **시작 메뉴·작업 표시줄** 익숙함 |
| 패키지 | 우분투 저장소·Snap | 우분투와 **가까운** `.deb` 길. Snap 정책은 민트 버전마다 다름 |

Mint를 쓰면 **우분투 앱·드라이버 정보**를 같이 검색해도 되는 경우가 많다.  
반대로 “민트만의 메뉴·Timeshift”는 우분투 본판과 **다르다.**

## 6. 패키지·소프트웨어

| 방식 | 설명 |
|------|------|
| **apt** | 터미널·“소프트웨어” 앱으로 `.deb` 패키지 설치. Debian 계열 표준 |
| **Snap** | Canonical이 밀던 **컨테이너형** 패키지. 자동 업데이트·격리. **용량·속도·저장소 중복** 불만도 있음 |
| **Flatpak** | 일부 앱을 스토어 없이 설치. 배포판마다 기본 지원 다름 |
| **PPA** | 개인·팀 저장소. 최신 앱용. **신뢰할 출처만** |

일상: **소프트웨어** 앱·`apt`로 충분한 경우가 많다.  
개발: [[Python 학습과 패키지]]·Node 등은 `apt`·`pip`·`venv`·공식 설치 스크립트를 문서별로 본다.

## 7. 설치·첫 설정 (데스크톱)

1. [ubuntu.com/download](https://ubuntu.com/download)에서 **LTS Desktop** 또는 플레이버 ISO 
2. USB 작성 (Rufus, Ventoy, balenaEtcher 등) 
3. **Live** 부팅 — 와이파이·한글·소리·터치패드·해상도 확인 
4. 설치 — 디스크 **백업** 후 파티션(듀얼부팅은 여유 공간·부트로더 주의) 
5. 업데이트 (`sudo apt update && sudo apt upgrade`) 
6. 언어·입력기, 브라우저·오피스·[[크롬 사용법]] 등

| 주의 | |
|------|--|
| **Secure Boot** | 일부 NVIDIA·와이파이에서 추가 단계. Live에서 먼저 확인 |
| **듀얼부팅** | 윈도우 **빠른 시작** 끄기, 백업, BitLocker 여부 확인 |
| **한글** | 설치 시 언어 선택 또는 설치 후 `ibus`·한글 입력기 설정 |
| **은행·보안** | 국내 일부 프로그램은 **리눅스 미지원** — 웹·다른 PC 계획 |

상세 비교·저사양 흐름: [[저사양 PC용 무료 OS]].

## 8. 서버·개발·클라우드

우분투는 **서버·교육·클라우드**에서 기본 OS처럼 쓰인다.

| 맥락 | 설명 |
|------|------|
| VPS | DigitalOcean·Linode·AWS EC2 등 **Ubuntu Server** 이미지 기본 제공 |
| 컨테이너 | `ubuntu:22.04` 등 **Docker Hub** 공식 베이스 이미지 ([[Docker 사용법]]) |
| CI | GitHub Actions 등에서 `runs-on: ubuntu-latest` 흔함 ([[GitHub]]) |
| WSL | 윈도우 10/11에서 **WSL2 + Ubuntu** — 리눅스 쉘·도구 without 듀얼부팅 |

로컬 PC를 우분투로 바꾸지 않아도, **개발·서버 학습**에서는 우분투 명령·경로를 자주 본다.

## 9. 장점 / 한계

| 장점 | 한계 |
|------|------|
| 문서·커뮤니티·한글 자료 **압도적** | GNOME 본판은 **저사양에 부담** — 플레이버·Mint 검토 |
| LTS로 **장기 안정** | Snap 정책·일부 앱 설치 방식에 **불만**도 있음 |
| 서버·클라우드·Docker와 **호환** | 윈도우 전용 프로그램은 Wine·VM·유지 필요 |
| 하드웨어 지원 넓은 편 | 드라이버(특히 GPU)는 **케이스별** 수동 설정 |
| 무료·광고 OS 아님 | [[ChromeOS Flex]]보다 **직접 관리** 부담 |

## 10. 고를 때

```text
검색·튜토리얼이 우분투 기준
 → Ubuntu LTS 또는 해당 플레이버

윈도우 이주·시작 메뉴 익숙
 → [[Linux Mint]] (우분투 기반)

램·CPU 빠듯
 → Lubuntu · Xubuntu · Mint Xfce ([[저사양 PC용 무료 OS]])

웹·구글만
 → [[ChromeOS Flex]]

서버·Docker·클라우드 학습
 → Ubuntu Server (GUI 없이 SSH)

윈도우 유지 + 리눅스 명령만
 → WSL2 Ubuntu
```

## 11. 실전 체크

- [ ] **LTS** ISO인지, 플레이버(GNOME vs Xfce/LXQt)를 골랐는가 
- [ ] Live USB로 **와이파이·한글·소리** 확인했는가 
- [ ] **백업**·듀얼부팅 리스크를 이해했는가 
- [ ] 저사양이면 본판 GNOME 대신 **Lubuntu/Xubuntu** 또는 [[Linux Mint]] Xfce를 봤는가 
- [ ] 필수 윈도우 앱·은행 프로그램 **호환**을 확인했는가 
- [ ] 서버 목적이면 Desktop ISO가 아닌 **Server**·클라우드 이미지인지

## 12. 정리

| 항목 | 한 줄 |
|------|--------|
| 정의 | Canonical의 **데비안 계열** 리눅스. Desktop·Server·WSL |
| 데스크톱 | 기본 GNOME. 저사양은 **Lubuntu·Xubuntu** 또는 [[Linux Mint]] |
| 서버 | 클라우드·Docker·CI에서 **사실상 표준**에 가까운 선택지 |
| Mint | 우분투 **파생**. 앱 생태계는 가깝고 UI·도구는 다름 |
| 설치 | LTS + Live 체험 + 백업. [[저사양 PC용 무료 OS]]와 함께 고름 |
