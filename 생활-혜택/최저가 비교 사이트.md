# 최저가 비교 사이트

> **분류:** 생활·혜택 · [[생활위키 목차]]

**최저가 비교 사이트**는 여러 쇼핑몰·입점사의 **같은 상품 가격**을 한 화면에 모아 보여 주는 서비스다. 
국내에서는 **다나와**, **에누리**, **네이버 쇼핑** 등이 자주 쓰인다.

이 글은 **어디가 무엇에 강한지·어떻게 보면 덜 속는지**를 정리한다. 실시간 가격 DB는 아니며, **결제 직전**에는 항상 해당 몰에서 다시 확인한다.  
허브: [[최저가와 쿠폰]] · 기간 세일: [[기간 할인과 시즌 세일]]

확인일: 2026-08-11

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 하는 일 | 동일·유사 상품의 **판매가·배송비·판매처**를 나란히 표시 |
| 장점 | 몰마다 들어가지 않고 **후보를 빠르게** 거름 |
| 한계 | **쿠폰·카드·멤버십**이 반영 안 된 경우 많음. **품절·가짜 최저**도 있음 |
| 수익 모델 | 대개 **제휴 링크·광고·입점** — “최저”가 항상 진짜 최종가는 아님 |

```text
비교 사이트에서 후보 2~3곳 고르기
 ↓
각 몰에서 쿠폰·배송·옵션·판매자 확인
 ↓
카드·페이([[삼성페이]] 등) 적용 후 금액 비교
 ↓
결제
```

주간 쿠폰·행사 표는 [[최저가와 쿠폰]], 시즌만 따로는 [[기간 할인과 시즌 세일]].

## 2. 주요 서비스 비교

| 서비스 | URL (공식) | 강한 분야 | 특징 |
|--------|------------|-----------|------|
| **다나와** | [danawa.com](https://www.danawa.com) | **PC 부품·조립 PC·디지털·가전** | 가격 **추이 그래프**, 사용자 리뷰·커뮤니티, 입점몰 **등재** 문화 |
| **에누리** | [enuri.com](https://www.enuri.com) | **가전·디지털·생활** | 다나와와 비슷한 **가격비교** 축. 앱·이벤트·적립 연동 |
| **네이버 쇼핑** | [shopping.naver.com](https://shopping.naver.com) | **전 카테고리·스마트스토어** | 검색·필터 중심. **네이버페이·멤버십**과 겹치는 혜택 많음 |
| **11번가·G마켓·옥션** 등 | 각 공식몰 | 해당 몰 **자체 최저**·딜 | “비교 사이트”라기보다 **오픈마켓** — 네이버·다나와에도 링크됨 |

해외 직구·대행은 **관세·배송·A/S**가 달라서, 국내 비교표만으로 결론 내리기 어렵다.

### 다나와 · 에누리 (PC·가전 축)

| | 다나와 | 에누리 |
|--|--------|--------|
| 이미지 | DIY·**부품 호환**·견적 문화 | 가전·생활·모바일도 넓음 |
| 가격 추이 | **과거 최저**·그래프로 “지금 살 만한지” 참고 | 유사 기능·이벤트 탭 |
| 리뷰 | **구매자·전문 리뷰**가 구매 전에 자주 참고됨 | 리뷰·가이드 콘텐츠 |
| 주의 | **등재몰**이라도 판매자·옵션은 각각 확인 | 동일 |

PC를 조립·업그레이드할 때는 다나와에서 **부품 호환·스펙**을 보고, 가격은 에누리·네이버와 **교차 확인**하는 패턴이 흔하다.

### 네이버 쇼핑

- **스마트스토어·브랜드관·대형몰** 링크가 한데 모임.  
- **최저가 정렬**은 편하지만, **네이버 전용 쿠폰·적립**은 비교 목록에 안 잡힐 수 있음.  
- 의류·잡화·중소 브랜드는 다나와보다 **네이버 쪽 후보가 많은** 경우가 많다.

## 3. 카테고리별 어디를 볼지

| 살 것 | 먼저 볼 곳 | 메모 |
|--------|------------|------|
| CPU·GPU·RAM·SSD·모니터 | **다나와** (+ 에누리) | 리퍼·중고·병행수입 옵션 구분 |
| 노트북·태블릿·스마트폰 | 다나와 · 에누리 · 네이버 | 통신사 **할부·요금제 결합**은 별도 계산 |
| 냉장고·세탁기·에어컨 | 다나와 · 에누리 | **설치비·배송·에너지등급** |
| 식품·생활·패션 | **네이버 쇼핑** · 쿠팡 앱 | g·개당 단가 — [[다이어트 추천 음식]] 장보기와 겹칠 때 |
| 배달·음식 | 비교 사이트보다 **[[배달 앱]]** | 플랫폼 쿠폰이 가격을 좌우 |

**쿠팡 로켓**·멤버십 전용가는 비교 사이트에 **늦게·부분만** 나오는 경우가 있다. 쿠팡은 앱에서 **직접** 보는 편이 낫다.

## 4. 비교 사이트에서 보는 법

| 화면 항목 | 확인 |
|-----------|------|
| **판매가** | 할인 전·후. “와우·회원가” 전제인지 |
| **배송비** | 무료 조건·도서산간·설치비 |
| **판매처** | 공식몰 vs 입점몰 vs **해외·병행** |
| **옵션** | 용량·색·번들. **다른 SKU**끼리 비교하지 않기 |
| **가격 추이** (다나와 등) | 역대 최저·급등락. **시즌·신제품** 타이밍 |
| **재고** | 품절인데 목록에 남아 있을 수 있음 |

```text
비교 사이트 최저가 10만 원
 ≠ 카드 5% + 쿠폰 1만 원 + 무료배송 적용 후 8만 5천 원
```

[[최저가와 쿠폰]] §4와 같이 **적용 후·단위당 가격**으로 마무리한다.

## 5. 함정·주의

| 함정 | 설명 |
|------|------|
| **옛 가격** | 몰이 가격을 안 바꿔 **허위 최저**처럼 보임 |
| **제휴 순위** | 광고·제휴 몰이 위에 노출될 수 있음 |
| **리퍼·중고·박스훼손** | 신품과 **같은 줄**에 있으면 착각 |
| **가짜 비교 사이트** | 유명 사이트 **이름만 흉내** — **공식 URL**만 |
| **피싱·가짜 쿠폰** | “최저가 모음” 사이트에 개인정보·결제 유도 — [[최저가와 쿠폰]] 면책 참고 |
| **청구할인 미반영** | [[삼성페이]]·카드사 할인은 **결제 단계**에서만 |
| **반품·A/S** | 최저 몰이 **보증·반품**이 불리할 수 있음 — 1~2천 원 차이만 보지 않기 |

“비교 사이트 최저”를 믿고 **결제 버튼만** 누르지 않는다.

## 6. [[최저가와 쿠폰]]과 같이 쓰기

| 역할 | 글 |
|------|-----|
| **어디서 검색할지** | 이 글 (다나와·에누리·네이버 등) |
| **이번 주 쿠폰·행사 숫자** | [[최저가와 쿠폰]] 표 (주간 점검) |
| **기간 한정 세일** | [[기간 할인과 시즌 세일]] |
| **생일 무료** | [[생일 혜택]] |

```text
월~일: 큰 구매 → 비교 사이트로 후보
매주: [[최저가와 쿠폰]] 확인일·쿠폰 표 갱신
대형 세일 주: [[기간 할인과 시즌 세일]] 행 추가
```

Cursor `/loop`로 “최저가와 쿠폰 표 점검”을 걸어 두면, **비교 사이트는 사람이**, **쿠폰 표는 주기적으로** 맞추기 쉽다.

## 7. 실전 체크

- [ ] **공식 URL** (다나와·에누리·네이버 쇼핑)인지  
- [ ] PC·가전이면 **다나와 + 한 곳 더** 교차 확인  
- [ ] 옵션·판매자·신품/리퍼 구분  
- [ ] 배송비·설치비 포함 **총액**  
- [ ] 몰에서 쿠폰·멤버십·카드 **적용 후** 재확인  
- [ ] [[최저가와 쿠폰]] **확인일**이 너무 옛날이 아닌지  
- [ ] 의심 링크·가짜 쿠폰 사이트는 **닫기**

## 8. 정리

| 항목 | 한 줄 |
|------|--------|
| 다나와 | **PC·디지털·가전** 비교·가격 추이·리뷰에 강함 |
| 에누리 | 다나와와 **비슷한 축**, 교차 확인용 |
| 네이버 쇼핑 | **전 카테고리·스마트스토어**, 생활·패션 후보 많음 |
| 원칙 | 비교 사이트는 **후보 선정**, 최종가는 **각 몰·쿠폰·카드**에서 |

## 면책

> **면책**  
> - **가입·구매·특정 사이트·카드 권유가 아니다.**  
> - 가격·입점·UI는 **언제든 바뀐다.** 이 글은 실시간 최저가를 보장하지 않는다.  
> - 제휴·광고·스폰서 노출이 있을 수 있다 — **결제 전 본인 확인**이 우선.  
> - 피싱·가짜 비교·가짜 쿠폰 사이트 주의. **공식 도메인**만.  
> - 직구·중고·리퍼는 **관세·보증·반품**이 다르다.
