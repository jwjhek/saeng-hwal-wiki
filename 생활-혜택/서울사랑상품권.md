# 서울사랑상품권

> **분류:** 생활·혜택 · [[생활위키 목차]]

**서울사랑상품권**은 서울시·자치구가 발행하는 **지역사랑상품권**이다. 살 때 **선할인**(회차마다 %)이 붙는 경우가 많고, **서울페이플러스(서울Pay+)** 앱에서 사고 가맹점에서 쓴다.

공식 안내: [서울시 경제 — 자주 묻는 질문](https://news.seoul.go.kr/economy/archives/515980) · 앱 **서울페이플러스** · 고객센터 **1600-6120**  
확인일: 2026-08-21

관련: [[경기지역화폐]] · [[온누리 상품권]] · [[제로페이]] · [[세액공제 기초]] · [[신용카드 소득공제]] · [[손목닥터9988]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 미리 산 **모바일 상품권**으로 서울 **가맹점** 결제 |
| **앱** | **서울페이플러스**(서울Pay+). 상품권 구매·QR·바코드·일부 터치결제 |
| **상시 매대 아님** | **발행 회차**가 있다. 날짜·시각·구별로 열리고 **선착순·예산** |
| **혜택** | 구매 시 **할인**. 구·회차에 따라 **페이백**. 사용분 **소득공제**(조건별) |
| **무엇이 아님** | [[경기지역화폐]], [[온누리 상품권]], 은행 [[제로페이]] 잔액 그 자체 |

```text
서울페이플러스 설치 · 본인 인증 가입
 ↓
구매용 계좌(또는 카드) 미리 등록
 ↓
발행 시각에 앱 「상품권 구매」 → 권종 선택 → 1만 원 단위 결제
 ↓
가맹점에서 앱 QR·바코드(되는 점은 터치)
```

할인율·월 한도·페이백은 **그 회차 공고·앱 화면**이 우선이다. 이 글이 이번 달 매대를 대신하지 않는다.

---

## 2. 권종

이름이 같아도 **쓰는 범위**가 다르다. 사기 전에 앱 목록의 권 이름을 본다.

| 권 | 쓰는 곳 (자주 나오는 안내) |
|----|----------------------------|
| **자치구** 서울사랑상품권 (예: ○○사랑상품권) | **그 구** 안 가맹점 |
| **광역**(오프라인) | 서울 **여러 구** 가맹점 |
| **온라인** 광역 | **서울배달플러스(땡겨요)** · **e서울사랑샵** 등 지정 온라인. 동네 매장과 **다를 수** 있음 |
| **배달 전용** 등 | 회차마다 이름·한도가 따로 공고됨 |

자치구 권은 할인·페이백이 더 붙는 회차가 있고, 생활이 **한 구**에 몰리면 맞다. 출퇴근이 구를 넘으면 **광역**을 보는 사람이 많다.

가맹에서 빠지는 쪽(본사 FAQ 취지): **대기업·중견 직영**, **대규모·준대규모 점포**, 유흥·부동산·금융 등, 일부 **연매출 큰 학원·귀금속**. 편의점·프랜차이즈도 **가맹만**. 앱 **가맹점 찾기**·계산대 안내가 최종이다.

---

## 3. 구매 방법

지류 창구가 아니라 **앱 선착순**이 기본이다. 발행 당일 서버가 몰리면 로그인이 느릴 수 있어, **계좌·카드는 전날까지** 넣는다.

### 3.1 준비 (발행 전에)

| 단계 | 내용 |
|------|------|
| 1 | 스토어에서 **서울페이플러스** 설치 (구 앱과 이름이 비슷해도 **지금 쓰는 앱**인지 확인) |
| 2 | **본인 명의** 휴대폰으로 가입·인증. 만 **14세 이상** 안내가 있음 |
| 3 | **구매 계좌**: 본인 명의 **개인** 계좌. 법인·타인 계좌는 안 된다는 안내 |
| 4 | **카드로 살 계획**이면 전체 메뉴 → 마이페이지 → **카드 관리**에서 본인 개인 카드 등록. 되는 카드사는 **앱이 우선**(예전에 하나·삼성·국민·현대가 적힌 적 있음) |
| 5 | 결제 비밀번호·생체 설정. 푸시 알림을 켜 두면 발행 공지를 보기 쉽다 |

계좌를 넣으면 보유 한도가 **더 크게** 열리는 안내가 있다(확인일 FAQ: 계좌 등록 시 보유 **최대 150만 원**대). **카드만** 넣으면 한도가 **작게** 막히는 안내가 있다.

### 3.2 사는 날

| 단계 | 내용 |
|------|------|
| 1 | 서울시 누리집·앱 공지의 **날짜·시각·구**를 본다. 광역은 **출생연도 짝·홀 2부제**가 걸린 회차가 있음 |
| 2 | 정각에 앱 하단 **상품권 구매**(또는 같은 이름의 메뉴) |
| 3 | 목록에 뜬 **자치구·광역·온라인** 중 쓸 곳을 고른다. 시각 전에는 목록이 비어 있을 수 있음 |
| 4 | 금액은 공통으로 **1만 원 이상, 1만 원 단위** |
| 5 | 할인 적용가를 보고 계좌 또는 등록 카드로 결제. 성공하면 **바로 잔액**에 들어옴 |

**예산이 떨어지면** 그 회차는 끝이다. 다음 발행을 기다린다.

### 3.3 한도 · 결제 수단 (방향만)

숫자는 권종·회차마다 바뀐다. 확인일 전후 공고에 자주 나온 뼈대:

| 항목 | 자주 나온 안내 |
|------|----------------|
| **월 구매** | 자치구·광역 오프라인 **50만 원**대. 온라인 광역은 **더 낮게**(예: 30만 원) 적힌 적 있음 |
| **보유** | 오프라인 권 **150만 원**대, 온라인은 **100만 원**대가 적힌 적 있음 |
| **신용카드로 구매** | **선물·환불 불가** 안내가 반복됨. 월 한도가 따로 적힌 회차도 있음 |
| **체크·계좌** | 선물·환불이 되는 편. 잔액 **일정 비율 이상 사용** 뒤에 환불되는 규정이 있음 |

네이버페이 등으로 **그 회차만** 살 수 있게 연 적도 있다. 없으면 앱의 계좌·카드만 보면 된다.

## 4. 쓰기

| 방법 | 설명 |
|------|------|
| **매장 QR을 내가 스캔** | 고정 QR 또는 사장님 앱 QR |
| **내 QR·바코드를 보여 줌** | 계산대가 스캔 |
| **합산** | 자치구 권 + 광역 권을 한 번에 (앱이 열면) |
| **복합** | 상품권 부족분을 **미리 등록한 카드**로. 「부족한 금액은 카드로」 체크. 카드로 나간 금액은 **카드 월 한도**에 잡힌다는 안내가 있음 |
| **취소** | 결제 취소 시 권이 **바로 복원**된다고 본사가 안내한 적 있음 |

같은 권을 여러 장 사면 **구매일·수령일이 빠른 것부터** 쓰인다는 안내가 있다.

유효기간은 **그 권의 앱 만료일**이 최종이다. FAQ는 조례상 **발행일부터 5년**(구매일이 기산이 아님)이라고 하고, 개별 판매 안내에는 **구매일부터 5년**이라고 적힌 회차도 있다. 온라인 권은 **1년**으로 안내된 적이 있다. 정책수당으로 받은 권은 **수당별 기한**.

[[배달 앱]] 일반 결제(배민·이츠)와는 **별개**인 경우가 많다. 배달은 **지정 앱·배달 전용 권**인지 본다.

## 5. 선물 · 환불

| 주제 | 본사 FAQ·발행 안내 취지 |
|------|-------------------------|
| **선물** | 성명·휴대폰. 비회원도 보내지만 **앱 가입 후** 수령. **30일** 안 받거나 거절이면 취소. 받은 뒤 보낸 쪽 취소 불가 |
| **신용카드로 산 권** | 선물 **불가** |
| **정책수당** | 선물 **불가**. [[손목닥터9988]] 전환분도 이 축으로 안내되는 경우가 있음 |
| **전액 미사용 취소** | 마이페이지 **상품권 환불 신청**. 당일 산 것은 당일 즉시, 아니면 **영업일 1~3일** |
| **일부 사용 환불** | 같은 메뉴. 계좌로 산 경우 **일정 % 이상 사용** 조건이 공고에 붙는 경우가 많음 |
| **휴대폰 분실** | **1600-6120**에 알려 계정 정지 |

## 6. 소득공제 (참고)

가맹에서 쓴 서울사랑상품권은 **지역사랑상품권 사용분 소득공제**로 거론되는 경우가 많다. 흔히 말하는 **30%**(전통시장 가맹이면 **40%**로 분류되는 이야기)는 **귀속 연도·총급여·다른 카드 공제**와 묶여 실제 절세액이 달라진다.

| 주의 | |
|------|--|
| **세액공제 아님** | [[세액공제 기초]] |
| **본인 명의** | 타인 계좌·카드로 산 분은 빠질 수 있음 |
| **앱·홈택스** | 소득공제 동의·집계 경로는 **그해 국세청·앱** |
| **한도** | [[신용카드 소득공제]]와 **같은 풀**에서 합산 규칙이 있음 |

이 글은 **세무 자문이 아니다.** 연말정산 전 「지역사랑상품권 소득공제」로 그해 안내를 본다.

|      | 서울사랑상품권                          | [[경기지역화폐]]     | [[온누리 상품권]]        |
| ---- | -------------------------------- | -------------- | ------------------ |
| 지역   | **서울** 시·구                       | **경기도** 시·군    | **전국** 전통시장·소상공인 축 |
| 사는 법 | 앱 **발행 회차**에 구매                  | 앱 **충전**(인센티브) | 은행 창구·디지털 앱 충전     |
| 결제   | 서울페이플러스 QR 등                     | 카드·QR          | 등록 카드·QR           |
| QR   | 기존 **제로페이 QR**을 그대로 쓰는 가맹 안내가 있음 | 별도             | [[제로페이]]와 겹치기도     |

**삼성페이로 일반 카드만** 긁으면 상품권 잔액이 **안 나간다.** 서울 권을 쓰려면 **서울페이플러스** 경로를 따른다.

## 8. 자주 막히는 점

| 상황             | 볼 것                                          |
| -------------- | -------------------------------------------- |
| 앱에 살 권이 없음     | 아직 발행 시각 전, 또는 **매진**. 상시 판매가 아님             |
| 할인가로 안 떨어짐     | 그 회차 할인·페이백 **예산 소진**                        |
| 강남에서 산 권을 마포에서 | **자치구 권**이면 그 구만. **광역**인지 확인                |
| 대형마트·백화점       | 가맹 제한이 기본                                    |
| 카드로 사고 환불      | 신용 구매는 **환불·선물 불가** 안내                       |
| (구)서울페이 잔액     | 신 앱 가입 후 **이관** 메뉴. 예전 은행 앱 단독 경로는 막힌 회차가 있음 |

피싱: 공식 스토어 앱·서울시 누리집 외 **「상품권 환급」 링크**는 쓰지 않는다.
