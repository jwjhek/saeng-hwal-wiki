# 기간 할인과 시즌 세일

> **분류:** 생활·혜택 · [[생활위키 목차]]

**특정 기간만** 열리는 할인·쿠폰·무료배송·멤버십 특가를 적는 글이다. 
생일 전용은 [[생일 혜택]], 상시·주간 표는 [[최저가와 쿠폰]].

확인일: 2026-08-07 
**점검:** 주 1회([[최저가와 쿠폰]]과 같이) + 대형 세일 주간에 추가.

관련: [[최저가와 쿠폰]] · [[생일 혜택]] · [[배달 앱]] · [[배달의 민족]] · [[쿠팡이츠]]

---

## 1. 개요

| 유형 | 예 | 볼 것 |
|------|-----|------|
| 시즌 세일 | 연말, 브랜드 위크, 페스티벌 | 기간·회원·카드 |
| 타임특가 | 자정~몇 시간, 선착순 | 재고·서버 지연 |
| 첫구매·복귀 | 신규·휴면 | 계정·기기 제한 |
| 배달 프로모 | 주말·날씨·카테고리 | [[배달의 민족]]·[[쿠팡이츠]] 쿠폰함 |
| 카드·페이 | [[삼성페이]]·카드사 청구할인 | 가맹·할부·한도 |

```text
기간 확인 → 조건(회원·카드) → 적용 후 가격 비교 → 종료일 캘린더
```

## 3. 적는 규칙

| 규칙 | 왜 |
|------|-----|
| 종료일 필수 | 기한 지난 글은 해롭다 |
| 확인일 갱신 | 주간 점검과 맞춤 |
| “~까지”만 있고 시각 없으면 앱에서 재확인 | 자정 기준·타임존 |
| 선착순·한정수량 명시 | 기대 관리 |
| [[생일 혜택]]과 섞지 않기 | 대상이 다름 |

---

## 4. 최저가 (기간 세일 때)

| 체크 | 설명 |
|------|------|
| 평소가·쿠폰 적용가 | “할인율”만 보지 않기 |
| 배송비·멤버십 | 유료 멤버 전제인지 |
| 반품·교환 | 행사 상품 제한 |
| 재고 | 품절 후 유사품 유도 |

상세 비교는 [[최저가와 쿠폰]] §4 · 비교 사이트는 [[최저가 비교 사이트]].

---

## 6. 정리

기간 할인·시즌 세일은 **달력과 종료일**이 생명이다. 
이 글에 행을 쌓고, 상시 쿠폰은 [[최저가와 쿠폰]], 생일은 [[생일 혜택]]으로 나눈다.

## 면책

> **면책** 
> - **구매·가입 권유가 아니다.** 
> - 시작·종료 시각, 조기 소진, 회원 등급, 카드 전용 조건이 있다. 
> - 종료된 행을 남겨 두지 말 것(또는 **종료** 표시). 
> - 공식 몰·공식 앱만. 출처 불명 “역대급 쿠폰” 링크 금지.
