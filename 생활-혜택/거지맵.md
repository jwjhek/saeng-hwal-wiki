# 거지맵

> **분류:** 생활·혜택 · [[생활위키 목차]]

**거지맵**은 **만원 이하** 한 끼가 중심인 **가성비 식당**을 지도에 모아 보여주는 참여형 서비스다. 이용자가 가격·메뉴를 **제보·수정**한다. 길찾기 본업은 [[지도 앱]]([[네이버 지도]]·[[카카오맵]]), 한식 정액은 [[한식뷔페]], 직장 창구는 [[구내식당]]을 본다.

이름 속 「거지」는 빈곤 비하라기보다, 고물가에 **한 끼를 아끼는 쪽**을 농담으로 부른 말에 가깝다. 이 글이 사람을 낮추거나 특정 가게를 홍보하지 않는다.

웹: [https://거지맵.com](https://거지맵.com)  
앱: iOS·Android 스토어에서 **거지맵** 검색 (지도는 웹만으로도 됨)

확인일: 2026-08-14  
식당 가격·폐업은 **당일 매장**이 맞다. 지도 숫자는 제보 시점이다. 도메인·스토어 앱은 **서비스가 바꿀 수 있음**.

관련: [[한식뷔페]] · [[구내식당]] · [[지도 앱]] · [[최저가와 쿠폰]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 저렴한 식당을 **지도 위 점**으로 보는 웹·앱. 2026년 봄 전후로 입소문이 남 |
| **웹** | [https://거지맵.com](https://거지맵.com) — 브라우저만. 설치 없이 지도 |
| **앱** | 스토어 **거지맵**. 지도 + (스토어 설명) 출석·만보기·티끌 등 |
| **기준** | 보도·안내상 **1만 원 이하** 메뉴가 중심. 필터 상한은 서비스가 바꿀 수 있음 |
| **데이터** | **이용자 제보**. 네이버·카카오 **공식 플레이스가 아님** |
| **같이 있는 것** | 커뮤니티(보도에 **거지방**), 핫딜, (앱) 출석·만보기 등 **리워드** |
| **무엇이 아님** | 미슐랭, 배달 중개([[배달 앱]]), 영양 상담, 수입 보장 앱테크 |

```text
위치 허용 · 가격 필터
 ↓
주변 점 찍힌 식당
 ↓
메뉴·제보 가격 확인
 ↓
길찾기는 [[지도 앱]] · 방문 전 영업·가격은 매장
```

호갱노노가 **아파트 실거래**면, 거지맵은 **한 끼 가격 제보** 쪽에 가깝다. 둘 다 **공개·제보 데이터 ≠ 계약·계산서**.

## 2. 웹 · 앱

지도·제보는 **웹만으로** 된다. 앱은 필수가 아니다.

| 경로 | 설명 |
|------|------|
| **웹** | [https://거지맵.com](https://거지맵.com). PC·폰 브라우저. 영문 별칭 주소는 보도가 갈린다. **이 한글 도메인**을 우선 |
| **스토어 앱** | Apple App Store · Google Play에 **거지맵**이 있다. 확인일 기준 스토어 설명에 가성비 지도·거지방·핫딜·출석·만보기·**티끌** 리워드 |
| **홈 화면에 추가** | 웹을 연 뒤 브라우저 **공유·메뉴 → 홈 화면에 추가**. 스토어 앱과 **다른 아이콘**일 수 있음 |

앱을 고를 때:

- 이름만 비슷한 **다른 앱·가짜 사이트**가 있을 수 있다. 웹은 **거지맵.com**, 앱은 스토어 **개발자 표시·권한**을 본다.
- 위치 권한은 **주변 점**을 찍을 때 쓴다. 거부하면 검색한 동네로 볼 수 있는지 화면을 본다.
- 티끌·응모권·쿠폰은 스토어 안내상 **앱 안 보상**이다. 현금 환급·수익으로 단정하지 말 것.

가입·설치 권유가 아니다.

## 3. 쓰는 흐름

1. 웹 또는 앱에서 **현재 위치**(또는 검색한 동네)  
2. **가격 필터**로 후보를 줄임  
3. 점을 눌러 메뉴·제보 가격·후기를 봄  
4. 네이버·카카오에서 **영업시간·전화·휴무**를 한 번 더 봄 → [[지도 앱]]  
5. 가격이 올랐거나 문을 닫았으면 **제보·수정**(기능이 열려 있으면)

대학가·직장 밀집 지역에 점이 많고, 외곽은 **비어 보일** 수 있다. 없는 동네 = 싼 식당이 없다는 뜻이 아니다.

외부인 출입이 되는 **구내식당**이 찍히는 경우도 있다. 출입·식권은 [[구내식당]].

## 5. 한계 · 매너

| 한계 | 왜 |
|------|-----|
| **가격이 어제와 다름** | 물가·메뉴 개편. 제보가 안 따라옴 |
| **폐업·임시 휴무** | 점이 남아 있음 |
| **줄·품절** | 입소문 나면 작은 집은 재료가 동남 |
| **맛은 보장 없음** | 기준이 **가격** |
| **리워드·광고** | 앱테크 포인트는 **현금이 아닐** 수 있음. 약관 |

매너:

- 사장님·다른 손님을 **몰래 촬영·저격**하지 않기  
- 「지도에 나왔으니 이 값이 의무」가 아님. 올린 뒤 값이 바뀌면 **그날 메뉴판**  
- 남은 반찬·위생은 [[한식뷔페]]처럼 **눈으로 보고** 고른다  

싼 집만 고르다 나트륨·튀김만 쌓이면 [[다이어트]] 평균이 무너진다. 집밥은 [[요리]].

## 면책

> **면책**
> - **특정 식당·앱 가입·리워드 수익 권유가 아니다.**
> - 가격·영업·폐업·필터 기준·웹 주소는 **서비스·매장이 수시로** 바꾼다. 방문 직전 화면이 우선이다.
> - 제보는 틀릴 수 있다. 알레르기·식중독·영양은 **의료·매장**에 묻는다.
> - 앱 포인트·추첨은 약관·이벤트 종료에 따른다. 현금 환급으로 단정하지 말 것.
