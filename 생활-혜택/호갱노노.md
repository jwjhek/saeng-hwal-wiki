# 호갱노노

> **분류:** 생활·혜택 · [[생활위키 목차]]

**호갱노노**는 **아파트 실거래가·시세·단지 정보**를 모아 보는 국내 **부동산 정보** 앱·웹이다. 
이름은 **「호갱(바가지) 당하지 말자」** 에서 온 말로, **국토교통부 실거래가** 등을 바탕으로 **가격 감**을 잡는 데 쓰는 경우가 많다.

운영: **직방** 계열 (프롭테크). **중개 계약·법률 자문 앱이 아니다.**

공식: [https://hogangnono.com](https://hogangnono.com)  
앱: iOS·Android 스토어에서 **호갱노노** 검색

확인일: 2026-08-11

관련: [[최저가와 쿠폰]] · [[최저가 비교 사이트]] · [[나만의닥터]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **아파트** 중심 — 실거래·시세·학군·분양·리뷰·검색 |
| 대상 | **매매·전세·월세** 알아보는 **실수요자**·시세 참고하는 사람 |
| 데이터 | **국토교통부 실거래가** 공개 데이터 + 자체 **시세·리뷰** |
| 요금 | **핵심 조회**는 **무료**(광고 수익). 유료·부가 서비스는 앱 안내 |
| 웹 | **hogangnono.com** — 앱과 계정·관심 단지 연동 |

```text
[탐색] 실거래가 · 시세 · 학군 · 3D 단지
 ↓
[비교] 필터 · 랭킹 · 관심 단지 알림
 ↓
[행동] 분양 청약 정보 / (선택) 집내놓기·AI중개사·중개 문의
```

[[나만의닥터]]가 **의료비 최저가**라면, 호갱노노는 **아파트 시세·단지 정보** 쪽에 가깝다.

## 2. 주요 기능

### 2.1 실거래가·시세

| 기능 | 설명 |
|------|------|
| **실거래가** | 단지·평형별 **최근 거래** (공개 데이터 기반) |
| **시세·호가** | 앱이 제시하는 **적정 시세**·매물 호가 (모델·시점에 따라 다름) |
| **차트** | 기간별 **가격 흐름** |

**실거래가 = 실제 체결가**이고, 앱 **시세는 추정**이다. 계약 전 **등기·중개** 확인이 필요하다.

### 2.2 단지·입지

| 기능 | 설명 |
|------|------|
| **단지 상세** | 세대수·준공·평형·주차·용적률 등 |
| **3D 단지 투어** | 단지·동·**일조** 등 시각 정보 (지원 단지 한정) |
| **학군** | 초·중·고·학원가·통학 거리 등 |
| **교통·상권** | 지하철·버스·편의시설 |

### 2.3 검색·랭킹

| 기능 | 설명 |
|------|------|
| **검색 필터** | 매매/전세/월세, 가격, 평형, 입주년차, **갭**·전세가율·월세수익률 등 |
| **랭킹** | 인기 단지·지역, 청약·재건축 이슈 반영 |

### 2.4 분양·청약

| 기능 | 설명 |
|------|------|
| **분양 일정** | 민간·**LH** 등 분양·청약 **일정·경쟁률** (공고 연동) |
| **관심 분양** | 알림·일정 추적 |

청약 **자격·가점**은 **본인**이 공고·주택청약 앱으로 확인한다.

### 2.5 관심·알림

| 기능 | 설명 |
|------|------|
| **관심 단지** | 시세·매물 변동 **푸시** |
| **관심 매물** | 가격 변경 알림 |

### 2.6 이야기·리뷰

| 기능 | 설명 |
|------|------|
| **입주민 후기** | 층간소음·주차·분위기 등 **생활** 정보 |
| **칼럼** | 부동산 연구소 등 **전문가 글** (참고용) |

리뷰는 **주관적**이다. 한두 건만 보고 결정하지 않는다.

### 2.7 재건축·경매

| 기능 | 설명 |
|------|------|
| **재건축** | 지역·단계별 **현황** |
| **경매** | 관련 정보·이야기 (법적 절차는 **별도** 확인) |

## 3. AI중개사 (대화형 추천)

2025년 전후 **직방·호갱노노**가 **「AI중개사」** 를 낸 바 있다.

| 항목 | 설명 |
|------|------|
| 방식 | **자연어**로 조건 입력 → AI가 단지 **추천** |
| 반영 데이터 | 실거래·리뷰·학군·교통 등 (앱 안내 기준) |
| 한계 | **추천 목록**일 뿐 — 현장·등기·대출·세금은 **직접** 확인 |

지도만 돌리기 어려울 때 **첫 후보**를 좁히는 용도로 쓰는 경우가 많다.

---

## 4. 집내놓기 (매도·임대)

**집을 내놓을 때** 호갱노노·**직방**에 매물을 올리는 **집내놓기** 연동이 있다 (시기·지역·수수료는 **앱·약관**).

| 참고 | |
|------|--|
| 노출 | 호갱노노·직방 + 인근 중개사에 정보 전달 (안내대로) |
| 중개 | **공인중개사** 계약·수수료는 **별도** |
| 의뢰 | 앱에서 **의뢰**해도 **최종 계약**은 서류·현장 확인 |

---

## 5. 다른 서비스와

| | 호갱노노 | 참고 |
|--|----------|------|
| **직방** | 같은 계열 — 매물·중개 쪽 강함 | 앱이 **분리**돼 있음 |
| **네이버 부동산** 등 | 포털 **매물·지도** | 데이터·UI가 다름 |
| **국토교통부 실거래가** | **원천** 공개 사이트 | 호갱노노는 **가공·시각화** |
| [[나만의닥터]] | **의료비** 비교 | 분야만 다름 |
| [[최저가 비교 사이트]] | **쇼핑** 가격 | 부동산은 **단지·시세** 단위 |

「어느 앱이 정확하다」보다 **여러 출처**를 맞춰 보는 편이 안전하다.

## 6. 요금

| 구분 | 일반적 안내 |
|------|-------------|
| **실거래·시세·단지·학군·3D** 등 | **무료** 이용 가능한 경우가 많음 |
| **광고** | 앱 내 **배너·프로모션** |
| **유료·부가** | 메뉴별 — **앱·웹 최신 안내** |

숫자·플랜명은 **자주 바뀐다.** 가입·결제 전 **공식 요금 안내**를 본다.

---

## 7. 쓸 때 체크

| 주제 | 내용 |
|------|------|
| **시세 vs 실거래** | 앱 시세는 **참고**. 실제는 **협상·상태·층·향**에 따라 다름 |
| **매물 호가** | **내놓은 가격** — 거래가 아닐 수 있음 |
| **투자** | 글·랭킹은 **투자 권유가 아님** — [[금융]]·세금·대출은 전문 상담 |
| **개인정보** | 관심 단지·문의 시 **약관** 확인 |
| **피싱** | 「호갱노노 환불」 등 **가짜 링크** 주의 — **공식 앱·도메인**만 |

---

## 8. 흔한 오해

| 오해 | 현실 |
|------|------|
| 호갱 = 통신 요금 | **부동산(아파트)** 앱 — 통신과 **무관** |
| 앱 시세 = 반드시 그 가격 | **추정·모델** — 실거래와 **차이** 날 수 있음 |
| 앱만으로 계약 | **중개·등기·대출·세금**은 **오프라인·전문가** 영역 |
| 리뷰 = 팩트 | **경험담** — 시기·동·층마다 다름 |
| AI중개사 = 공인중개사 대체 | **정보 추천** — 법적 중개 **대체 아님** |

## 9. 실전 체크리스트

- [ ] 관심 **단지** 실거래 **최근 6~12개월** 흐름 확인  
- [ ] **전세가율·갭** 등은 본인 **자금**에 맞는지  
- [ ] 분양은 **청약 공고**·자격 **직접** 확인  
- [ ] 계약 전 **등기부등본**·현장·중개사 **대면**  
- [ ] 투자 목적이면 **대출·세금** 별도 상담  

---

## 10. 정리

1. 호갱노노는 **아파트 실거래가·시세·단지·학군·분양** 정보 앱이다.  
2. **국토부 실거래** 기반으로 **호갱(고가 매수)** 을 피하려는 **참고 도구**로 쓰인다.  
3. **AI중개사**·**3D 단지**·**리뷰**가 보조한다.  
4. **무료 조회**가 중심이나, **매물·중개**는 약관·수수료를 본다.  
5. 최종 결정은 **공식 데이터·현장·계약**이 우선이다.

---

## 면책

> **면책**  
> 실거래·시세·매물·분양 정보는 **지연·오류**가 있을 수 있다. **부동산 투자·세무·법률 자문이 아니며**, 앱 표시가 **거래 가격을 보장하지 않는다.**  
> 계약·대출·청약은 **공인중개사·관할 기관·공식 공고**를 따른다.
