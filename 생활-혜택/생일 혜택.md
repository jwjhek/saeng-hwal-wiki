# 생일 혜택

> **분류:** 생활·혜택 · [[생활위키 목차]]

카페·배달·쇼핑몰·통신 등에서 **생일(또는 생일 주간)** 에 주는 무료·쿠폰·할인을 점검용으로 정리한다. 
허브: [[최저가와 쿠폰]] · 기간 한정 세일은 [[기간 할인과 시즌 세일]].

확인일: 2026-08-07 
**점검:** 생일 **한 달 전**에 이 표 + 자주 쓰는 앱을 한 바퀴. 평소에는 분기 1회.

관련: [[최저가와 쿠폰]] · [[기간 할인과 시즌 세일]] · [[배달 앱]] · [[배달의 민족]] · [[쿠팡이츠]] · [[삼성페이]] · [[카카오톡]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 흔한 형태 | 음료 1잔 무료, 버거·사이드 무료 교환권, 할인 쿠폰 |
| 기간 | 생일 당일 / 전후 N일 / **생일 당월** — 브랜드마다 다름 |
| 필수 | 앱 가입, 생일 **사전 등록**, 푸시·쿠폰함 확인 |
| 함정 | 등급 미달, 특정 메뉴·사이즈만, 일부 매장·배달 제외, 중복 불가 |

```text
자주 쓰는 브랜드 앱에 생일 등록
 ↓
생일 1~4주 전 쿠폰함·이벤트 탭 확인
 ↓
유효기간 안에 사용
```

---

## 2. 자주 쓰는 곳

사용자가 챙기는 네 곳부터 정리한다. **결제·교환 직전 앱 쿠폰 상세**가 최종이다.

### 2.1 요약 표

| 브랜드 | 혜택 | 기간 | 핵심 조건 | 확인일 |
|--------|------------|------------|-----------|--------|
| **스타벅스** | 제조 음료 **Tall 1잔** 무료(사이즈업·옵션은 추가금) | 생일 기준 **전후 약 14일**(대략 29일 구간으로 안내되는 경우 많음). 생일 **14일 전** 전후 자동 발급 이야기도 흔함 | **리워드 그린 이상**, 앱·사이렌오더·매장. 병음료 등 일부 제외 | 2026-08-07 |
| **롯데리아** | **리아불고기(불고기) 버거 단품** 무료 쿠폰으로 안내되는 경우 많음 | **생일 당일 오전** 발급 안내가 흔함. 유효는 쿠폰 표기 | [[롯데잇츠]] 멤버십 **골드 이상**(최근 6개월 구매 기준 등). 생일 뒤 승급분은 미지급일 수 있음 | 2026-08-07 |
| **버거킹** | **불고기와퍼주니어** 무료 교환권으로 안내되는 경우 많음 | **생일 당월** 발급(당월 1일 등)·**당월 말**까지 유효 안내가 흔함 | 앱 가입 + **MY킹 생일 등록**. 연 1회·미사용 시 재발급 안 됨 | 2026-08-07 |
| **KFC** | 등급별 상이. **일반**은 에그타르트 무료 등으로 안내되는 경우. 실버↑는 징거버거·타워·더블다운 등 | **생일 당월** 구간으로 안내되는 경우 많음 | **KFC 앱** 멤버십 등급. 메뉴·유효는 쿠폰함 | 2026-08-07 |

커뮤니티 Q&A에서 더 넓게 언급되는 곳은 [[#3. 추가로 자주 언급되는 곳]]을 본다. 
참고 글(비공식): [아하 — 이번 달 생일 혜택](https://www.a-ha.io/questions/414fcd272296ea77ac8392bed55e2043)

### 2.2 스타벅스

| | 설명 |
|--|------|
| 앱 | 스타벅스 코리아 앱 · 리워드 |
| 받기 | 생일이 맞게 등록된 **그린 이상**이면 쿠폰함에 Birthday(생일) 쿠폰 |
| 쓰기 | 매장 제시 또는 **사이렌오더** → 쿠폰 적용. Tall 제조 음료 1잔 |
| 팁 | 금액 제한 없이 Tall이면 **단가 높은 제조 음료**를 고르는 집이 많음. Grande/Venti는 **차액**. Extra 1회 무료 이야기 있음 |
| 주의 | 병음료·일부 제외. 유효기간 지나면 소멸. 정책은 **별·등급 안내**가 우선 |

### 2.3 롯데리아

| | 설명 |
|--|------|
| 앱 | [[롯데잇츠]] — 롯데리아 멤버십·쿠폰 |
| 받기 | **골드 이상**이면 생일 쿠폰(불고기/리아불고기 **단품** 무료) 자동 발급 안내가 흔함 |
| 쓰기 | 쿠폰함 → 매장·키오스크·앱 주문(채널은 쿠폰 상세) |
| 주의 | Regular(구매 실적 미달)는 **생일 쿠폰 없음**인 경우가 많음. **생일 당일 이후**에야 골드가 되면 미지급일 수 있음 → 생일 **전에** 등급·생일 등록 확인 |

등급 기준(바뀔 수 있음): 최근 6개월 누적 구매로 Gold / VIP / VVIP 등. 앱의 **멤버십 안내**를 본다.

### 2.4 버거킹

| | 설명 |
|--|------|
| 앱 | 버거킹 앱 |
| 받기 | **MY킹 → 정보변경**에 생일 입력. 생일 **해당 월**에 쿠폰(불고기와퍼주니어 무료 등) |
| 쓰기 | 앱 쿠폰함. 매장·킹오더·딜리버리 등 **쿠폰별 채널** 확인 |
| 주의 | 연 1회. 기간 내 미사용 시 **재발급·이월 없음**. 생일 수정이 막힌 시기가 있다는 이용기 → 가입 시 정확히 |

멤버십 등급(Welcome/Junior 등)과 별도로 **생일 쿠폰은 생일 등록 회원**에게 간다는 안내가 흔하다. 등급 전용 쿠폰과 혼동하지 말 것.

### 2.5 KFC

| | 설명 |
|--|------|
| 앱 | KFC 앱 |
| 받기 | 멤버십 **등급별** 생일 축하 쿠폰(일반·Silver·Gold·VIP 등) |
| 혜택 | 일반: 에그타르트 무료 / Silver: 징거버거 / Gold: 징거타워 / VIP: 징거 더블다운 통다리 등 — **앱 등급·쿠폰명이 우선** |
| 주의 | 등급·메뉴는 자주 바뀜. “타워버거 무료”처럼 **한 종류로만** 말하는 글도 있으나, 실제는 **등급·쿠폰함**이 우선 |

### 3.4 생일 달 “어디부터” 루틴 (아하형)

1. 카페: 스타벅스(그린) · 투썸·배스킨(등급) 
2. 버거: 버거킹 · 롯데리아(골드) · KFC 
3. 영화: 메가박스·CGV·롯데시네마 앱 쿠폰함 
4. 쇼핑: 무신사·올리브영 등 **자주 쓰는 앱만** 

한 번에 다 가입할 필요 없다. **이미 쓰는 앱**부터.

---
## 4. 정리

스타벅스·롯데리아·버거킹·KFC는 **앱 + 생일 등록**(+ 일부는 **등급**)이 핵심이다. 
투썸·배스킨·영화관·무신사 등은 커뮤니티에서 자주 언급되지만 **앱으로 재확인**한다. 
혜택 내용은 바뀌므로, 이 글은 **어디를 열어볼지**를 고정한다.

## 면책

> **면책** 
> - **가입·구매 권유가 아니다.** 브랜드·연도마다 조건이 바뀐다. 
> - 앱 회원·멤버십·사전 등록·본인 인증이 필요한 경우가 많다. 
> - “무조건 공짜”가 아니다. **공식 앱·매장 안내**가 우선. 
> - 아래 표는 공개 안내·이용기 기준으로 정리한 **설명**이다. 메뉴명·등급·기간은 바뀌니 **쿠폰함·약관**으로 재확인. 
> - 생년월일 오등록·대리 수령 남용은 제재·계정 위험.
