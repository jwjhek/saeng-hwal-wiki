# 생일 혜택

> **분류:** 생활·혜택 · [[생활위키 목차]]

카페·배달·쇼핑몰·통신 등에서 **생일(또는 생일 주간)** 에 주는 무료·쿠폰·할인을 점검용으로 정리한다.  
허브: [[최저가와 쿠폰]] · 기간 한정 세일은 [[기간 할인과 시즌 세일]].

> **면책**  
> - **가입·구매 권유가 아니다.** 브랜드·연도마다 조건이 바뀐다.  
> - 앱 회원·멤버십·사전 등록·본인 인증이 필요한 경우가 많다.  
> - “무조건 공짜”가 아니다. **공식 앱·매장 안내**가 우선.  
> - 생년월일 오등록·대리 수령 남용은 제재·계정 위험.

확인일: 2026-08-07  
**점검:** 생일 **한 달 전**에 이 표 + 자주 쓰는 앱을 한 바퀴. 평소에는 분기 1회.

관련: [[최저가와 쿠폰]] · [[기간 할인과 시즌 세일]] · [[배달 앱]] · [[배민]] · [[쿠팡이츠]] · [[삼성페이]]

## 1. 한눈에

| 항목 | 감각 |
|------|------|
| 흔한 형태 | 음료 1잔 무료, 할인 쿠폰, 포인트·스탬프, 배송비·배달비 쿠폰 |
| 기간 | 생일 당일만 / 생일 주 / 생일 달 전체 — **브랜드마다 다름** |
| 필수 | 앱 가입, 생일 **사전 등록**, 푸시·쿠폰함 확인 |
| 함정 | 특정 사이즈만, 다른 쿠폰과 중복 불가, 매장 제외 |

```text
자주 쓰는 브랜드 앱에 생일 등록
        ↓
생일 1~4주 전 쿠폰함·이벤트 탭 확인
        ↓
유효기간 안에 사용 (일부는 예약 필요)
```

## 2. 받기 전 체크

- [ ] 앱·멤버십에 **생일(양력/음력)** 이 맞게 들어가 있나  
- [ ] “생일 쿠폰 자동 발급”인지, **이벤트 페이지에서 받기**인지  
- [ ] 사용처(매장만/배달만/온라인만)  
- [ ] 타 쿠폰·카드 할인과 **중복** 되는지  
- [ ] 가족·지인 명의 도용 금지

## 4. 생일 달 루틴 (추천)

| 시기 | 할 일 |
|------|------|
| D-30 | 이 글 표 + 자주 쓰는 앱 쿠폰함 |
| D-7 | 미수령 쿠폰 “받기” 버튼, 유효기간 메모 |
| 당일~주간 | 매장/배달에서 사용. 재고·대기 확인 |

---

## 7. 정리

생일 혜택은 **미리 등록하고, 생일 전에 쿠폰함을 여는** 생활 체크리스트다.  
구체 숫자는 브랜드가 바꾸므로 이 글은 **표 + 루틴**을 유지하는 쪽에 의미가 있다.
