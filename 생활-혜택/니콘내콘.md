# 니콘내콘

> **분류:** 생활·혜택 · [[생활위키 목차]]

**니콘내콘**은 안 쓰는 **기프티콘·모바일 쿠폰**을 플랫폼이 **검수·매입**한 뒤, 정가보다 낮게 다시 파는 앱이다. 이름은 **네 콘·내 콘**에서 온 말에 가깝다. 당근처럼 **개인끼리 바코드를 주고받는 장터는 아니다.**

운영: **더블엔씨**(DoubleNC)  
웹: [https://ncnc.app/](https://ncnc.app/)  
앱: 스토어에서 **니콘내콘** 검색  
고객센터: 앱 1:1 · 스토어·사이트 전화번호(02-6080-0016 등이 적힌 적 있음)

확인일: 2026-08-14  
매입가·할인가·출금일·취소 조건·카드 앱 검색 노출은 **앱 화면·약관**이 우선이다.

관련: [[최저가와 쿠폰]] · [[카카오톡]] · [[생일 혜택]] · [[메가커피]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 기프티콘 **할인 구매** + 안 쓰는 콘 **매각** |
| **거래 형태** | 판매자 → 플랫폼 검수·매입 → 구매자 (**C2B2C**). 개인 직거래가 아님 |
| **흔한 품목** | 카페·편의점·치킨·영화·상품권 등. 입점 브랜드는 앱이 바꿈 |
| **카드 앱** | **하나카드**(하나페이) 앱 검색창에 `니콘내콘` → 제휴로 구매 |
| **무엇이 아님** | [[카카오톡]] 선물하기(발행처), [[온누리 상품권]], 수입 보장 앱테크, 사기 예방을 대신하는 보험 |

```text
안 쓰는 콘 등록 → 검수·매입가 안내 → (수락하면) 니콘머니·출금
                                              ↓
쓰고 싶은 콘을 할인가로 구매 → 바코드·번호로 매장·앱에서 사용
```

[[카카오톡]] 선물하기·브랜드 앱에서 받은 콘을 **현금처럼 바꾸거나**, 같은 콘을 **정가보다 싸게** 사는 축이다. 가입·매매 권유가 아니다.

비슷한 기프티콘 앱(기프티스타·팔라고 등)이 있다. 할인율·품절·약관은 **그때 앱**.

---

## 2. 하나카드 앱에서

스토어 **니콘내콘 앱**과 별도로, **하나카드 앱**(화면에 **하나페이**로 보이는 경우 있음) **검색**에 `니콘내콘`을 치면 제휴 화면으로 들어가 **구매**할 수 있다. 은행 앱 **하나원큐**와는 다른 축이다.

```text
하나카드(하나페이) 앱 → 검색 → 니콘내콘
 ↓
처음이면 가입·약관 동의 (하나카드 개인정보 제3자 제공 등이 필수인 안내가 있었음)
 ↓
기프티콘 고르기 · 결제
```

| 항목 | 메모 |
|------|------|
| **하는 일** | 카드 앱 안에서 니콘내콘 **할인 쿠폰 구매**. 메뉴 이름·검색 노출은 **앱이 바꿈** |
| **동의** | 하나카드 쪽에 「니콘내콘 가입에 동의해 주세요」 창이 뜬다. 마케팅 수신은 **선택**인 안내가 있었음 |
| **결제** | 하나카드·하나페이. 니콘내콘 쪽 결제창에 하나페이가 뜨는 경우도 있음 |
| **이벤트** | 즉시할인·선착순 상품은 **기간·대상 카드**가 있다. 법인·선불·하나BC 제외 안내가 있었음. **지금 혜택·이벤트 탭** |
| **판매** | 안 쓰는 콘을 **매각·출금**하는 기능은 카드 앱 제휴에 **없을 수** 있다. 팔려면 스토어 **니콘내콘** 앱 |

가입·카드 발급 권유가 아니다. 검색에 안 나오면 스토어 앱·웹 [https://ncnc.app/](https://ncnc.app/) 을 본다.

## 3. 사는 쪽

| 항목 | 메모 |
|------|------|
| **값** | 권면(표시 금액)보다 **낮은 판매가**가 흔함. 남은 유효기간이 짧을수록 더 싼 경우가 많음 |
| **고를 때** | **유효기간·사용처·옵션**(핫/아이스, 사이즈)을 결제 전에 본다 |
| **받은 뒤** | 바코드·번호를 **캡처해 공유하지 않기**. 보면 취소가 막히는 안내가 흔함 |
| **취소** | 기간·열람 여부에 따라 **불가**인 건이 있다. 마이페이지·약관 |
| **사고** | 이미 쓰인 콘·발행 취소 등은 스토어 안내상 **1:1 문의**. “100% 환불”은 **만료·단순 변심과 다름** |

카페 콘은 [[메가커피]]·스타벅스처럼 **공식 앱 스탬프·사이렌오더**와 안 맞을 수 있다. 키오스크·직원 스캔만 되는 집이 있다. 매장에서 거절하면 **발행처 고객센터 + 니콘내콘 1:1**.

[[생일 혜택]] 무료 음료 쿠폰과 **다른 축**이다. 생일 쿠폰을 여기 팔 수 있는지도 **앱·브랜드 약관**.

## 4. 파는 쪽

| 항목 | 메모 |
|------|------|
| **등록** | 브랜드·상품을 고르고 콘 이미지를 올림. AI·심사 안내가 있음 |
| **거절** | 재고가 많거나, 기간이 너무 짧거나, 품목이 안 맞으면 **매입 안 함** |
| **수락** | 매입가가 뜨면 **기한 안에 수락**하라는 안내가 있었음. 지금 화면 |
| **대금** | **니콘머니**로 들어온 뒤 출금. 스토어 안내 예: 확정 후 **+2 영업일**부터 신청, 다음 영업일 낮 입금, 출금 수수료 0원 — **바뀌면 앱** |
| **적립** | 카드 결제 시 니콘머니를 준다는 웹 안내가 있음. 월 한도는 **이벤트** |

팔면 대개 **권면보다 적은 돈**이다. 못 쓸 콘을 버리는 대신 일부만 회수하는 쪽에 가깝다.

## 5. 당근 · 카톡 선물과 비교

구매 권유가 아니다.

| | 니콘내콘 | 당근·중고나라 등 | [[카카오톡]] 선물하기 |
|--|----------|-------------------|------------------------|
| 상대 | 플랫폼이 매입·재판매 | **개인 직거래** | 발행처·브랜드 |
| 사기 | 바코드 직거래보다 **구조가 단순** | 사용 완료 콘·잠수 | 정가·공식에 가까움 |
| 값 | 할인·매입 마진 | 흥정 | 할인 행사가 따로 있음 |
| 기간 | **남은 유효**를 옵션으로 고름 | 제각각 | 발행 당시 기간 |

문자·오픈채팅으로 “콘 싸게 팝니다”는 **니콘내콘이 아니다.** 이름만 비슷한 앱·가짜 사이트도 있을 수 있다. 웹은 **ncnc.app**, 앱은 스토어 개발자 **더블엔씨**(DoubleNC).

## 6. 쓸 때 주의

| 함정 | 왜 |
|------|-----|
| **기간이 짧다** | 리셀 콘은 옵션에 적힌 날까지만. 만료 후 연장·환불이 **안 되는** 안내가 흔함 |
| **바코드를 먼저 봄** | 구매 취소가 막히는 조건으로 자주 나옴 |
| **매장·앱이 안 받음** | 품목 교환, 배달·오더 앱, 일부 키오스크 |
| **발행 취소** | 원래 산 사람이 취소를 건 콘. 1:1 — 며칠 걸릴 수 있음 |
| **스크린샷 유출** | 누가 먼저 쓰면 끝 |
| **피싱** | 고객센터를 사칭해 번호·사진을 요구 |
| **카드 앱 제휴** | 검색이 빠지거나, 동의 창만 있고 결제가 스토어 앱으로 넘어갈 수 있음 |

스토어 개인정보 안내(수집 항목·암호화 여부)는 **설치 전 화면**. 이 글이 보안 인증을 하지 않는다.

## 면책

> **면책**
> - **가입·구매·판매·출금·카드 발급 권유가 아니다.** 기프티스타 등 다른 앱과 우열을 정하지 않는다.
> - 가격·할인율·매입 거절·출금일·취소·환불·**카드 앱 검색·제휴 노출**은 **앱·약관·발행처**가 바꾼다.
> - 스토어의 「사고 시 환불」과 **유효기간 만료·단순 변심**은 다르다.
> - 판매 대금·적립의 세금·계정 제재는 **개인·세무·약관**. 이 글이 절세 방법이 아니다.
> - 바코드 직거래·피싱은 이 서비스 밖이다. 피해는 **수사·소비자 상담**.
