# 메가커피

> **분류:** 생활·혜택 · [[생활위키 목차]]

**메가커피**는 일상에서 부르는 이름이고, 매장 간판·앱은 **메가MGC커피**(MEGA MGC COFFEE)다. **양이 큰 저가 커피** 프랜차이즈로, 대학가·학원가·직장가에 점이 많다. 스타벅스 같은 프리미엄 카페와 자리가 다르다.

공식: [https://www.mega-mgccoffee.com/](https://www.mega-mgccoffee.com/)  
앱: 스토어에서 **메가MGC커피** 검색 (메가오더·퀵오더 등)  
고객센터: 앱·사이트 안내 (1588-8298 등이 적힌 적 있음)

확인일: 2026-08-14  
가격·스탬프·사이즈·이벤트는 **매장 메뉴판·앱**이 우선이다.

관련: [[생일 혜택]] · [[최저가와 쿠폰]] · [[배달 앱]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 국내 **저가·대용량** 커피 체인. 가맹점이 많음 |
| **부르는 말** | 메가커피 / 메가 / MGC. 공식 표기는 **메가MGC커피** |
| **포인트** | 아메리카노 단가가 싼 편으로 알려짐. **메가 사이즈**·메가리카노(아주 큰 아이스) |
| **앱** | 픽업 주문, 스탬프·쿠폰(메가월렛), 선물하기, 함께오더 |
| **무엇이 아님** | 스벅 리워드 등급제, [[배달 앱]] 중개 플랫폼, 가맹 투자 권유 |

```text
매장 키오스크 · 또는 앱 주문(메가오더 되는 점)
 ↓
번호·바코드로 스탬프 (되는 결제만)
 ↓
픽업 · 매장 수령
```

컴포즈·빽다방·더벤티 등과 **같은 저가 축**에서 비교하는 사람이 많다. 맛·원두·점은 집마다 다르다. 길 안내는 [[지도 앱]].

## 2. 메뉴 · 사이즈 (방향만)

| 축 | 메모 |
|----|------|
| **아메리카노** | 대표 메뉴. 핫/아이스 가격이 다른 안내가 흔함 |
| **메가 사이즈** | 아이스 컵이 **큰 편**. 카페인·수분 섭취가 같이 늘어남 |
| **메가리카노** | 아메리카노를 **더 크게** 낸 메뉴 이름. 샷·용량은 **그날 메뉴** |
| **시즌·협업** | 프리퀀시·아티스트·디저트 콜라보가 자주 바뀜 |
| **디저트·병음료·MD** | 스탬프가 **안 찍히는** 경우가 많음 |

당 음료·샷 추가는 열량·카페인이 붙는다. [[역류성 위염]]·[[불면증]]·[[ADHD]]가 있으면 **오후 늦은 대형 아이스**를 의심한다. 이 글이 금지를 처방하지 않는다.

가격은 이 글에 고정하지 않는다. 점포·행사·사이즈가 갈린다.

## 3. 앱 · 주문

앱 이름은 **메가MGC커피**. 스토어 설명 기준 기능(매장마다 꺼져 있을 수 있음):

| 기능 | 하는 일 |
|------|---------|
| **퀵오더** | 저장한 MY메뉴를 짧게 재주문 |
| **메가오더** | 메뉴 고르고 픽업 |
| **픽업 예약** | 시간 맞춰 받기 (가능 구간은 앱) |
| **함께오더** | 링크를 나눠 **한 번에 결제**. 비회원 참여 안내가 있음 |
| **메가월렛** | 쿠폰·상품권·스탬프 |
| **선물하기** | 모바일 교환 |

**메가오더를 안 쓰는 매장**이 있다. 앱에서 점포 필터·매장 안내를 본다.  
배달은 배민 등에도 올라온다. **스탬프·앱 쿠폰은 매장·자사 앱만**인 주문이 많다 → [[배달 앱]].

키오스크는 결제 전 **휴대폰 번호** 또는 앱 바코드.

## 4. 스탬프 · 쿠폰

멤버십 안내의 **큰 골격**(세부·만료는 앱 약관):

| 항목 | 흔히 나오는 말 |
|------|----------------|
| 적립 | **제조 음료 1잔 → 스탬프 1** |
| 보상 | **10개**면 아메리카노 무료 또는 **금액 할인** 쿠폰으로 바뀐다는 안내 |
| 만료 | 스탬프·쿠폰에 **기간**이 있음 |
| 안 찍히는 예 | 병음료, 디저트만, 일부 할인·상품권·배달 — **그때 화면** |
| 사용 매장 | 전 점 가능으로 바뀐 적 있음. 예전엔 적립 점 제한이 있었다는 이야기 |

할인·쿠폰을 쓰면 **스탬프가 안 쌓이는** 조합이 있다. 본전을 계산할 때 같이 본다. 기프티콘을 할인 앱에서 사는 집이 있음 → [[니콘내콘]]. 공식 앱·스탬프와 **다를 수 있음**.

통신사 **우주패스** 등 구독 할인이 붙은 시기가 있다. 일·월 한도, 스탬프 제외 여부는 **통신사·메가 안내**. 구독 권유가 아니다.

이벤트(프리퀀시·콘서트 응모 등)는 **시즌마다** 사라진다. 2026년 메가콘서트형 프리퀀시가 보도된 적 있음. **지금 앱 배너**.

생일 음료는 스벅처럼 고정 공식이 아닐 수 있다 → [[생일 혜택]] 표는 앱을 본다.

## 5. 다른 카페와 비교

구매 권유가 아니다.

| | 메가커피 | 스타벅스 등 | 다른 저가 체인 |
|--|----------|-------------|----------------|
| 값 | 싼 편으로 알려짐 | 비쌈. 리워드·공간 | 빽다방·컴포즈·더벤티 등과 겹침 |
| 양 | **큰 사이즈**가 강점 | 톨·그란데 등 | 집마다 |
| 앱 | 픽업·스탬프 | 사이렌오더·별 | 제각각 |
| 점포 | 가맹 밀도 높음. **길 건너 경쟁점**이 있는 골목도 많음 | 상대적으로 적음 | 같은 상권에 붙는 경우 많음 |

[[제로페이]]·[[경기지역화폐]]는 **가맹 점포만**. 키오스크에 없으면 카드·페이.

가맹 개설은 이 글 밖이다. 예비 점주는 **공정위 정보공개서·본사 공지**.
