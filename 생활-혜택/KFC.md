# KFC

> **분류:** 생활·혜택 · [[생활위키 목차]]

**KFC**는 Kentucky Fried Chicken이다. 한국 매장·앱은 **주식회사 케이에프씨코리아**가 운영한다. 프라이드 치킨·버거 체인으로, 밤 시간 **1+1** 행사가 자주 거론된다.

공식: [https://www.kfckorea.com/](https://www.kfckorea.com/)  
앱: 스토어에서 **KFC Korea** (징거벨오더·딜리버리)  
고객: 본사 안내 **1661-8380**(월~금 09:00~12:00, 13:00~17:00, 공휴일 제외). 주문·콜센터는 앱·행사 안내에 **1599-8484**가 적힌 적이 있음

확인일: 2026-08-21  
시간·매장·1+1 대상·쿠폰은 **앱·키오스크·프로모션 탭**이 우선이다.

관련: [[생일 혜택]] · [[최저가와 쿠폰]] · [[배달 앱]] · [[기간 할인과 시즌 세일]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| **무엇** | 치킨·버거 프랜차이즈. 한국은 케이에프씨코리아 |
| **앱** | 픽업 **징거벨오더**, 배달 **딜리버리**, 쿠폰함, 커넬 멤버십 |
| **상시로 많이 보는 행사** | **치킨나이트** 1+1 (매일 밤 9시~10시, 결제 완료 기준) |
| **일부 매장** | 같은 1+1을 **밤 8시~10시**로 연다. 흔히 **얼리치킨 나이트**라고 부름 |
| **매월 11일** | **치킨올데이**(올데이 치킨나이트) — 하루 종일 1+1으로 안내된 적이 많음 |
| **무엇이 아님** | [[배달 앱]] 중개 플랫폼, 가맹 투자 권유 |

```text
KFC 앱에서 매장 선택
 ↓
1+1 표기 치킨 단품(1조각)만 담기
 ↓
행사 시간 안에 결제 완료
 ↓
징거벨오더 픽업 · 또는 매장·딜리버리(되는 채널만)
```

가격은 이 글에 고정하지 않는다. 매장가와 딜리버리가가 다른 안내가 흔하다. [[배달의 민족]]·[[쿠팡이츠]] 같은 **외부 배달 앱**에는 이 1+1이 안 열리는 경우가 많다.

## 2. 앱 · 주문

앱 이름은 **KFC Korea**. 스토어·본사 소개 기준:

| 기능 | 하는 일 |
|------|---------|
| **징거벨오더** | 미리 주문·결제하고 매장에서 픽업(또는 매장 식사) |
| **딜리버리** | 공식 앱 배달. 최소 주문·배달비·판매가가 매장과 다를 수 있음 |
| **커넬** | 결제 금액에 따라 적립. 등급·쿠폰 |
| **쿠폰함** | 생일·가입·등급 쿠폰. 1+1과 **중복 불가**가 기본 |
| **선불카드** | 충전·결제. 적립 안내는 FAQ |

**특수 매장**(에버랜드, 야구장, 인천공항 T1, 코엑스몰, 인스파이어 등)은 행사·쿠폰이 빠지는 안내가 반복된다. 방문 전 앱 매장 정보를 본다.

## 3. 치킨나이트 (매일)

본사 상시 배너: **매일 밤 9시~밤 10시까지 치킨 1+1**. 확인일 기준 안내(영수증·결제 시각).

| 항목 | 본사 안내 (확인일) |
|------|---------------------|
| **시간** | **21:00~22:00** 사이 **결제 완료** |
| **대상** | 메뉴에 **1+1 표기**가 있는 치킨 단품. 같은 종류로만 하나 더 |
| **안 됨** | 일반 1·3·5·8조각, 팩, 할인·교환 쿠폰, 텐더·너겟 등 스낵, 일부 신제품 |
| **채널** | 매장 방문, KFC 앱, 웹, 전화 |
| **매장** | 밤 9시 이후 영업하는 점. 특수 매장 제외 안내가 있음 |
| **중복** | 제휴·다른 쿠폰·단체 추가 할인 **불가**로 안내 |

10시가 지난 결제, 1+1이 아닌 일반 치킨 메뉴는 대상이 아니다. 앱은 시간 안에 **1+1 표기 상품을 담아 결제**했는지가 핵심이다.

## 4. 얼리치킨 나이트 (일부 매장)

공식 제목은 **「치킨나이트 1+1 우리 매장은 한 시간 더 일찍!」** 이다. 일상에서는 **얼리치킨 나이트**라고 부른다. **전 점이 아니다.**

확인일 기준 본사 안내:

| 항목 | 설명 |
|------|------|
| **시간** | 매일 **20:00~22:00** (기본 치킨나이트보다 1시간 먼저 시작, 끝은 22:00) |
| **채널** | 매장, KFC 앱 **징거벨오더** |
| **딜리버리** | 이 일찍 시작 안내는 **21:00~22:00**만 연다고 적혀 있음 |
| **대상** | 1+1 표기 **치킨 1조각**. 3·5·8조각·교환·할인 쿠폰은 미적용 |
| **품목 예** | 핫크리스피치킨, 오리지널치킨, 핫크리스피통다리, 갓양념치킨, 갓양념통다리, 트러플치르르통다리, 오리지널통다리 — **점마다 미판매**가 있을 수 있음 |

확인일 기준 본사에 적힌 매장 이름(순서는 사이트와 같음):

광화문 · 광안리 · 구로디지털2 · 마두역 · 밀양 · 산본역 · 성남태평 · 속초DI · 시흥능곡 · 시흥배곧 · 시흥신천 · 시흥은계 · 안산중앙 · 철산역 · 하남시청

**이 목록은 바뀐다.** 결제 직전 앱에서 해당 점·1+1 표기를 다시 본다.

## 5. 11일 · 치킨올데이

**치킨올데이**(보도에서는 **올데이 치킨나이트**)는 치킨나이트와 같은 종류의 **1+1을 하루 종일** 연다고 안내된 행사다. 날짜는 예전에 매월 **1일**이었다가 **11일**로 바뀐 보도가 있다. 본사 다른 행사 유의사항에도 **치킨나이트, 치킨올데이**가 같이 적힌다.

| 항목 | 점검 메모 |
|------|-----------|
| **날짜** | 매월 **11일**로 안내된 경우가 많음. **그날 앱·프로모션**이 최종 |
| **시간** | 영업시간(또는 앱이 적어 둔 구간) 종일. 밤 9시까지 기다릴 필요는 없다는 취지 |
| **혜택** | 지정 치킨 단품 1+1. 메뉴 구성은 달마다 다를 수 있음 |
| **채널** | 매장·공식 앱(징거벨·딜리버리)·웹. 외부 배달 앱은 빼는 안내가 흔함 |
| **혼잡** | 11일은 주문이 몰린다는 이야기가 많음. 재고·조기 종료는 점마다 |

확인일(2026-08-21) 기준 **진행 중 프로모션 목록에는 치킨올데이 단독 배너가 없었다.** 8월 11일은 이미 지났고, 다음 달은 앱에서 **9월 11일** 전후를 보면 된다. 상시처럼 매일 뜨는 배너가 아닐 수 있다.

가입 환영 딜리버리 쿠폰 등 **일부 쿠폰은 치킨나이트·치킨올데이에 적용 제외**로 적혀 있다.

## 6. 멤버십 · 생일

적립 단위는 **커넬**. 본사 멤버십 페이지(확인일): 결제 **5천 원당 1커넬**, 적립일부터 **약 6개월(180일)** 뒤 소멸. 등급은 커넬 수·6개월 유지 조건으로 다시 매긴다.

| 등급 | 승급(확인일 안내) | 생일 축하 쿠폰(본사 표기) |
|------|-------------------|---------------------------|
| **일반** | 가입 즉시 | 에그타르트 교환권 |
| **SILVER** | 10커넬 | 징거 교환권 |
| **GOLD** | 40커넬 | 징거타워세트 교환권 |
| **VIP** | 70커넬 | 치즈징거통다리박스 교환권 |

생일 쿠폰은 **매장 방문 전용**, 유효 **발급일부터 30일**로 안내된다. 상세는 [[생일 혜택]] · 앱 쿠폰함.

신규 가입 웰컴(확인일): 징거 단품 할인(매장), 딜리버리 할인, 버터 비스켓 무료(징거벨, 단독 주문 불가) 등이 **첫 가입 1회**. 탈퇴 후 재가입은 안 준다는 안내가 있다. 금액·제외 매장은 쿠폰함이 우선이다.

## 7. 자주 막히는 점

| 상황 | 볼 것 |
|------|--------|
| 9시 전에 담아 두고 결제만 9시에 | 시간 안에 **1+1 표기 상품**으로 결제했는지. 미리 담은 일반가가 그대로일 수 있음 |
| 배민·이츠에서 1+1이 없음 | 공식 앱·매장·웹·전화인지 |
| 얼리 시간에 배달 | 일찍 여는 점은 **징거벨·매장**. 딜리버리는 21시 안내 |
| 세트·사이드만 주문 | 1+1은 **표기된 치킨 1조각** |
| 특수 매장 | 공항·야구장·테마파크·일부 몰은 제외가 반복됨 |
| 11일에 배너가 없음 | 월 1회라 목록에서 빠질 수 있음. 당일 앱을 연다 |

기름·나트륨·열량은 개인·의료다. [[다이어트]]가 목적이면 이 글의 1+1과 별개로 본다.
