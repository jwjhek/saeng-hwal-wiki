# 최저가와 쿠폰

> **분류:** 생활·혜택 · [[생활위키 목차]]

배달·쇼핑·구독에서 자주 나오는 **할인·쿠폰·최저가 이벤트**를 한곳에 모아 둔다. 
숫자는 빨리 바뀌므로 **확인일**을 보고, 결제 직전 **앱·사이트 화면**이 우선이다.

확인일: 2026-08-07 
**다음 점검 목표:** 매주 1회 (일요일 등 고정일을 정해 두면 유지가 쉽다)

관련: [[배달 앱]] · [[배달의 민족]] · [[쿠팡이츠]] · [[삼성페이]] · [[케이패스]] · [[생일 혜택]] · [[기간 할인과 시즌 세일]]

---

## 1. 왜 이 분류인가

| 장점 | 주의 |
|------|------|
| 배달·장보기 전에 “지금 뭐가 있지?” 한곳 | 방치하면 **만료 정보**만 남아 신뢰↓ |
| 쇼츠·알림용 소재로도 쓰기 쉬움 ([[위키 쇼츠 자동 제작]]) | 매주·격주 **확인일** 갱신이 필수에 가깝다 |
| [[배달의 민족]]·[[쿠팡이츠]] 등과 링크 | 앱마다 계정·멤버십 조건이 다름 |

운영: **허브(이 글)** 에 표로 모으고, 양이 많아지면 배달/쇼핑 글을 쪼갠다. 
**생일** → [[생일 혜택]] · **기간·시즌만** → [[기간 할인과 시즌 세일]].

## 2. 업데이트 규칙 (정기)

| 주기 | 할 일 |
|------|------|
| 매주 | 아래 표의 **유효·확인일** 점검. 만료·종료는 삭제 또는 “종료” 표기 |
| 행사 시 | 대형 세일(연말·브랜드데이 등)만 짧게 추가 |
| 매월 | 쓰이지 않는 행 정리. 출처 링크 유효성 |
| 올리지 말 것 | 출처 불명, 타인 계정 공유 코드, 스크린샷만 있는 조건 |

글 상단 **확인일**을 고치면 “언제 봤는지”가 남는다. 
Cursor에서 주기적으로 보게 하려면 `/loop` 등으로 “최저가와 쿠폰 표 점검”을 걸어 둘 수 있다. (자동이 앱 API를 대신하진 않음)

## 4. 최저가 비교

**어디서 검색할지**(다나와·에누리·네이버 쇼핑 등)는 [[최저가 비교 사이트]]. 아래는 **결제 직전** 체크.

| 할 일 | 설명 |
|------|------|
| 같은 상품 | 배송비·멤버십·쿠폰 **적용 후** 비교 |
| 단위 | g·개당 단가 |
| 시간 | 깜짝 세일·자정 마감 |
| 함정 | 카드 청구할인 미적용, 유료 멤버십 전제 |

이 위키가 **실시간 가격 DB**는 아니다. “어디서 보면 좋은지·무엇을 의심할지” 체크리스트에 가깝다.

## 8. 정리

최저가·쿠폰 페이지는 **유지보수가 전제**인 생활 허브다. 
비어 있는 표 + **매주 확인일**만 지켜도 쓸모가 생기고, 방치하면 독이 된다. 
배달 실무는 [[배달 앱]]·[[배달의 민족]]·[[쿠팡이츠]]와 같이 본다.

## 면책

> **면책** 
> - **가입·구매·특정 카드/앱 권유가 아니다.** 
> - 쿠폰·행사는 지역·계정·재고·기간·중복 불가 조건이 있다. 
> - “무조건 최저”를 보장하지 않는다. 비교·조건은 본인 확인. 
> - 피싱·가짜 쿠폰 사이트 주의. **공식 앱·공식 몰**만. 
> - 제휴·광고를 붙일 경우 그 글에 **명시**한다. (이 허브 기본은 정보 정리)
