# 경기지역화폐

> **분류:** 생활·혜택 · [[생활위키 목차]]

**경기지역화폐**는 경기도 **31개 시·군**이 발행하는 **지역사랑상품권**이다. 
계좌에서 **충전**해 동네 **가맹점**에서 쓰고, 시·군 정책에 따라 **인센티브(충전 보너스)** 와 **소득공제** 혜택이 붙는 경우가 많다.

공식: [gmoney.or.kr](https://gmoney.or.kr) · 앱 **「경기지역화폐」** · 고객센터 **1899-7997**  
확인일: 2026-08-11

관련: [[온누리 상품권]] · [[세액공제 기초]] · [[제로페이]] · [[삼성페이]] · [[최저가와 쿠폰]]

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **선불형 지역화폐** — 충전 잔액으로 가맹점 결제 |
| 법적 성격 | **지역사랑상품권** (지자체 발행) |
| 대상 | **경기도** 시·군별 발행 — 가입 시 **주 활동 지역(시·군)** 선택 |
| 목적 | 지역 소상공인·상권 활성화, 카드 수수료 부담 완화 |
| [[온누리 상품권]]과 차이 | 온누리는 **전국 전통시장** 축, 경기지역화폐는 **경기도 시·군** 축 |

```text
[가입] 앱·홈페이지 — 주 활동 시·군 선택, 카드·모바일 신청
 ↓
[충전] 본인 명의 계좌 연동 → 월 한도 내 충전 + 인센티브(시·군·예산)
 ↓
[결제] 카드·앱 QR·[[삼성페이]] 등 — 가맹점에서만
 ↓
[연말] 앱에서 소득공제 신청(조건) → 홈택스·연말정산 반영
```

**서울페이**·**부산페이** 등 다른 지역 화폐와 **앱·가맹·인센티브**가 다르다. 이름만 비슷한 **해외 송금 서비스**와 혼동하지 말 것.

## 2. 종류

| 구분 | 설명 |
|------|------|
| **카드형** | 실물 카드 우편 배송(수 일). 매장에서 카드 결제 |
| **모바일형** | 앱 잔액·QR 결제. 일부 시·군(예: 성남·시흥)은 모바일만 운영 |
| **지류** | 참여 **농협** 등 창구 — 앱·카드보다 절차가 다름 |

처음 쓰는 사람은 **앱 설치 → 카드 신청 → 계좌 연결 → 충전** 흐름이 일반적이다.

## 3. 시작하기

| 단계 | 내용 |
|------|------|
| 1 | 스토어에서 **「경기지역화폐」** 앱 설치 |
| 2 | 본인 인증·회원 가입 |
| 3 | **주 활동 지역**(거주·자주 쓰는 시·군) 선택 — 인센티브·한도가 **여기 기준** |
| 4 | 카드형이면 **배송 신청**·등록, 모바일형이면 앱 내 카드 발급 |
| 5 | **출금 계좌**(본인 명의) 연동 |
| 6 | 충전 — 인센티브·월 한도는 [인센티브 현황](https://gmoney.or.kr)·앱 공지 확인 |

오프라인: 일부 **농협** 창구에서 카드 신청·지류 구매(시·군별).  
명절·행사 시 카드 **배송 지연**이 있을 수 있다.

### 자동 충전

잔액이 일정 이하(예: 1만 원)가 되면 **자동 충전**을 켤 수 있다. 
인센티브 **예산이 월 초에 소진**되는 시·군이 많아, 자동 충전 시각·금액을 **매월 공지**와 맞춘다.

---

## 4. 충전·인센티브

| 항목 | 설명 |
|------|------|
| 충전 | 연동 계좌에서 **실시간** 출금 → 잔액 반영 |
| 최소 충전 | 보통 **1만 원**부터 (공식 안내 기준) |
| **월 충전 한도** | 시·군마다 다름 — 흔히 **30만~60만 원**대 |
| **인센티브** | 충전액의 **일정 %**를 추가 적립 — 시·군·예산에 따라 **6~12%** 등 |
| 예산 소진 | 해당 월 **인센티브 예산**이 떨어지면 **보너스 없이** 충전만 됨 |
| 유효기간 | 충전금·인센티브마다 **만료일**이 다를 수 있음 — 앱 **잔액 상세** 확인 |

인센티브는 **별도 신청 없이** 충전과 동시에 붙는 경우가 많다. 
다만 **비율·한도·종료 시점**은 시·군·도 예산으로 **수시 변경**된다. 
「월 60만 원 넣으면 67만 원 쓴다」 식 예시는 **당해 월 정책**이 맞을 때만 성립한다.

**팁:** 인센티브가 빨리 끝나는 지역은 **매월 초** 충전하는 편이 유리하다는 이용 후기가 많다.

## 5. 결제

| 방법 | 설명 |
|------|------|
| **실물 카드** | 가맹점 카드 단말기 |
| **앱 QR** | 매장 QR 스캔·결제 |
| **[[삼성페이]]** | 카드 등록 후 NFC(지원 매장·앱 버전 확인) |
| **분할 결제** | 잔액 부족 시 **일반 카드와 합산**이 안 되는 매장이 있음 — 결제 전 잔액 확인 |

**온라인 쇼핑몰**·[[배달 앱]] 결제와는 **직접 연동되지 않는** 경우가 대부분이다.

## 7. 혜택 — 인센티브 · 소득공제

### 7.1 충전 인센티브

§4 — **시·군·월 예산**이 기준. 신용카드 **캐시백**과 별개다.

### 7.2 지역사랑상품권 소득공제 (참고)

경기지역화폐로 **가맹점**에서 쓴 금액은 **지역사랑상품권 사용분 소득공제** 대상으로 **거론**되는 경우가 많다. 
흔히 말하는 **30% 공제율**은 **귀속 연도·총급여·다른 카드 공제와의 관계**에 따라 실제 절세액이 달라진다.

| 주의 | |
|------|--|
| **세액공제 아님** | [[세액공제 기초]] — 대부분 **소득공제** 축 |
| **앱 신청** | **전체 메뉴 → 소득공제 신청** 등 약관 동의가 필요한 경우 많음 — 미신청 시 **공제 누락** |
| **본인 명의** | 타인 카드·계좌면 **인정 안 될 수** 있음 |
| **한도** | 연간 **지역사랑상품권 공제 한도**·신용카드 공제와 **합산 규칙** — **당해 연도** 국세청 안내 |
| **가맹** | 등록 가맹·허용 업종에서 쓴 분만 |

연말정산 전 **「지역사랑상품권 소득공제」** + **귀속 연도**로 검색한다. 이 글은 **세무 자문이 아니다.**

## 8. [[온누리 상품권]]·[[제로페이]]·[[삼성페이]]와

| | 경기지역화폐 | [[온누리 상품권]] | [[제로페이]] |
|--|-------------|-----------------|--------------|
| 발행 | **경기도 시·군** | **전국** 전통시장·소상공인 | 은행·계좌 연동 QR |
| 충전 혜택 | 시·군 **인센티브** | 디지털 **충전 할인** 등 | 해당 없음 |
| 소득공제 | **지역사랑상품권** 사용분 | **전통시장** 사용분 등 | 조건별 논의 |
| 겹침 | 같은 가게가 **둘 다** 가맹일 수 있음 | 제로페이 QR 가맹과 겹치기도 | 상품권 메뉴와 별개 |

**삼성페이로 일반 카드만 결제**하면 지역화폐 잔액이 **안 나갈 수** 있다. 
지역화폐를 쓰려면 **등록한 지역화폐 카드**·앱 QR 경로를 따른다.

경기도가 아니면 **서울·인천·부산** 등 **해당 지역 화폐**를 본다. 경기지역화폐는 **경기도 시·군** 전용이다.

## 11. 정리

1. 경기지역화폐는 경기도 **지역사랑상품권** — **충전 후 가맹점**에서만 쓴다.  
2. **시·군별** 인센티브·월 한도·예산 소진 시점이 다르다 — **앱 공지**가 최종본.  
3. 결제는 **카드·앱 QR·삼성페이(지원 시)**. 온라인·배달 앱과는 **별개**인 경우가 많다.  
4. 조건 맞으면 **지역사랑상품권 소득공제** — 앱 **소득공제 신청**·[[세액공제 기초]]와 구분.  
5. [[온누리 상품권]]·[[제로페이]]와 **가맹이 겹칠 수** 있으니 매장마다 확인한다.
