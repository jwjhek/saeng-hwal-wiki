# 온누리 상품권

> **분류:** 생활·혜택 · [[생활위키 목차]]

**온누리 상품권**(온누리상품권)은 **전통시장·상점가·소상공인** 결제를 돕기 위해 정부가 뒷받침하는 **선불형 상품권**이다. 
지류(종이)·**디지털 앱**(모바일·카드형 통합)으로 살 수 있고, **가맹점**에서만 쓴다.

공식: [https://www.onnurigift.or.kr](https://www.onnurigift.or.kr)  
운영: 소상공인시장진흥공단 등 (정책·한도는 **연도·예산**마다 변동)

확인일: 2026-08-11

관련: [[제로페이]] · [[세액공제 기초]] · [[경기지역화폐]] · [[최저가와 쿠폰]] · [[삼성페이]]

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | **미리 산 돈**(상품권 잔액)으로 **동네 시장·소상공인**에서 결제 |
| 목적 | 지역 상권·전통시장 활성화, 소상공인 **카드 수수료** 부담 완화 |
| 쓰는 곳 | **온누리 가맹** 매장 — 대형마트·일부 프랜차이즈는 **불가**가 많음 |
| 혜택 | **충전 할인**(디지털) · **전통시장 소득공제**(조건별, §6) |

```text
[구매] 지류 창구 / 디지털 앱 충전 (할인율·한도 있음)
 ↓
[보유] 종이 권 / 앱 잔액·등록 카드
 ↓
[결제] 가맹점에서만 — 스티커·앱 가맹점 찾기로 확인
 ↓
[연말] 조건 맞으면 전통시장 사용분 소득공제 (홈택스 등)
```

---

## 2. 종류 (지류 vs 디지털)

2025년부터 **모바일형·카드형**이 **「디지털 온누리」앱**으로 통합되는 흐름이다. 
세부 UI·한도는 **공식 앱·사이트**가 최종본이다.

| 구분 | 지류(종이) | 디지털 (앱) |
|------|------------|-------------|
| 구매 | **은행 등 금융기관** 창구 | **온누리상품권** 앱, 충전 계좌 연동 |
| 할인 | **5%** 수준 (정책 시기별) | 충전 시 **10%** 할인가로 충전되는 구조가 일반적 |
| 월 구매 한도 | **낮은 편**(예: 50만 원대) | **높은 편**(예: 100~200만 원, 예산 따라 변동) |
| 보유 한도 | — | 앱 잔액 **최대 200만 원** 등 (공식 안내 기준) |
| 결제 | 권을 건네거나 바코드 | **등록 카드**로 결제 시 잔액 차감, 또는 QR·[[제로페이]] 연동 경로 |
| 카드 실적 | 해당 없음 | **카드형·등록 카드** 사용 시 카드사 실적 **인정**되는 경우 많음 (카드사별 확인) |
| 온라인 | **불가**에 가깝다 | **전통시장몰** 등 일부만 |

**처음 쓰는 사람**은 디지털 **카드 등록 + 충전** 흐름이 편한 경우가 많다. 
시장만 자주 가면 **지류**도 단순하다.

---

## 3. 디지털 앱 — 시작하기

| 단계 | 내용 |
|------|------|
| 1 | 앱스토어·플레이스토어에서 **「온누리상품권」** 설치 |
| 2 | **본인 명의** 휴대폰·계정으로 가입 |
| 3 | **충전용 본인 명의 계좌** 등록 |
| 4 | 평소 쓰는 **신용·체크카드** 등록 (가맹점 결제용) |
| 5 | **충전** — 할인된 금액으로 잔액 채움 (한도 확인) |
| 6 | 가맹점에서 **등록 카드**로 결제 → 잔액에서 우선 차감 |

### 자동 충전

잔액이 일정 이하로 떨어지면 **자동 충전**을 켤 수 있다. 
한도·출금 계좌를 **미리 확인**한다.

### 잔액 부족 시 (중요)

공식 안내: **충전 잔액보다 결제액이 크면**, 일부 환경에서는 **온누리 + 일반 카드 분할**이 안 되고 **카드 전액 결제**만 되는 경우가 있다.  
결제 전 **잔액**을 보거나, 직원에게 **온누리 가능 여부**를 묻는다.

---

## 4. 지류(종이) — 구매·사용

| 항목 | 내용 |
|------|------|
| 구매처 | 참여 **은행·농협** 등 금융기관 창구 (목록은 공식 사이트) |
| 할인 | 권면 대비 **5%** 할인 구매가 흔함 |
| 사용 | 가맹점에 **권 전달** 또는 매장 안내에 따른 결제 |
| 소득공제 | **사용 전** 소득공제 등록 절차가 필요한 경우 있음 (BC카드 등 안내 — §6) |
| 보관 | **분실 시 복구 어려움** — 디지털보다 관리 부담 |

명절·행사 때 창구 **대기**가 길 수 있다.

## 5. 어디서 쓰나 · 안 쓰나

| 쓸 수 있는 편 | 쓰기 어렵거나 불가인 편 |
|---------------|-------------------------|
| **전통시장** 노점·상점 | **대형마트**·백화점 (일반적) |
| 동네 **정육·청과·식당·미용실** (가맹) | **온라인 쇼핑몰** (일부 몰 제외) |
| **상점가** 온누리 스티커 매장 | 가맹 **미등록** 가게 |
| [[배달 앱]] | 배달 주문 결제와 **직접 연동 안 됨** |

### 가맹점 확인

| 방법 | |
|------|--|
| **온누리 앱** | 가맹점 찾기·지도 |
| **매장** | 입구·계산대 **온누리상품권 가맹** 스티커 |
| **[[제로페이]]** | QR 결제 가맹과 **겹치는 곳** 많음 — 둘 다 되는지 **매장 확인** |

## 6. 혜택 — 충전 할인 · 소득공제

### 6.1 충전 할인

디지털 충전 시 **10% 할인가**로 잔액이 채워지는 구조가 일반적이다.  
예: 10만 원 충전 → 계좌에서 **9만 원** 출금, 잔액 10만 원 (시기·정책 확인).

지류는 **5%** 할인 구매가 흔하다. **명절·정책**에 따라 **추가 할인** 행사가 붙기도 한다.

### 6.2 전통시장 소득공제 (참고)

온누리로 **전통시장·상점가 가맹**에서 쓴 금액은 **소득공제** 대상으로 **거론**되는 경우가 많다. 
흔히 말하는 **40% 공제율**·**추가 한도**는 **귀속 연도·소득 구간·총급여**에 따라 달라진다.

| 주의 | |
|------|--|
| **세액공제 아님** | [[세액공제 기초]] — 대부분 **소득공제** 쪽 |
| **가맹 분류** | 전통시장으로 **등록된** 가맹에서 쓴 분만 |
| **본인 명의** | 타인 카드·계좌면 **인정 안 될 수** 있음 |
| **지류** | 사용 전 **소득공제 등록** 필요할 수 있음 (카드사·공식 안내) |
| **디지털** | 등록 카드 결제 시 **자동 집계**되는 경우 많음 — **홈택스**로 확인 |
| **한도** | 신용카드 소득공제와 **단계·한도가 다름** — **당해 연도** 국세청 안내 |

연말정산 전 **「전통시장 소득공제」** + **귀속 연도**로 검색한다. 이 글은 **세무 자문이 아니다.**

## 7. [[제로페이]]·[[삼성페이]]와

| | 온누리 상품권 | [[제로페이]] | [[삼성페이]] |
|--|---------------|--------------|--------------|
| 정체 | **선불 상품권** 잔액 | **계좌 직불** QR 결제 | **카드** NFC 등 |
| 돈 | 미리 **충전** | 계좌에서 **즉시 출금** | **카드** 승인 |
| 겹침 | 디지털·모바일은 **제로페이 QR** 가맹과 **겹치는 경우** | 앱 안 **상품권 메뉴**와 연동 | 별개 — 카드 결제는 온누리 **아님** |

**삼성페이로 카드만 긁은 결제**는 온누리 잔액이 **안 나갈 수** 있다. 
온누리를 쓰려면 **앱에 등록한 카드**로 결제하거나, 매장 **QR·안내**를 따른다.

## 9. 누구에게 맞나

| 맞는 편 | 덜 맞는 편 |
|---------|------------|
| **전통시장·동네 가게**를 자주 감 | 대형마트·온라인만 씀 |
| 연말 **소득공제**까지 챙기고 싶음 (조건 충족 시) | 충전·앱 설정이 **번거롭다**고 느낌 |
| 디지털로 **카드 실적 + 온누리** 같이 쓰고 싶음 | 가맹이 **없는** 동네 |

---

## 10. 정리

1. 온누리 상품권은 **소상공인·전통시장용 선불 상품권**이다.  
2. **지류(5% 할인)** 와 **디지털 앱(10% 충전 할인)** 이 있다.  
3. **가맹점**에서만 쓰며, 앱·스티커로 **미리 확인**한다.  
4. 조건 맞으면 **전통시장 소득공제** — [[세액공제 기초]]와 구분, **국세청**이 최종본.  
5. [[제로페이]]·등록 카드와 **겹치는 결제**가 있으니 **잔액·가맹**을 본다.
