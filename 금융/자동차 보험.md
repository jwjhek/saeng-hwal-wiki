# 자동차 보험

> **분류:** 금융 · [[생활위키 목차]]

자동차를 **운행·보유**할 때 드는 **자동차보험(자보)** 을 담보·특약·할인·사고 처리 기준으로 정리한다. 
형사·벌금·변호사·합의 **정액** 쪽은 [[운전자 보험]]. 보험 전체 틀은 [[보험 기초]].

확인일: 2026-08-10 
약관·요율·할인·법정보장 한도는 **보험사·상품·시점·차종**마다 다르다. 증권·다이렉트 견적·설계 설명이 우선.

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 자동차 사고로 **남에게 입힌 손해·내 차·내 몸** 등을 약관 범위에서 보상 |
| 의무 | 법에서 정한 **대인배상** 등 (미가입·미갱신 운행은 처벌·사고 시 큰 부담) |
| 선택 | 대물 한도 확대, 자차, 자기신체/자동차상해, 무보험차상해, 긴급출동 등 |
| 누구 | **피보험자동차** 중심. 운전자 **범위·연령** 특약이 보험료·보장에 직결 |
| 옆자리 | [[운전자 보험]] — 배상과 다른 **형사·법률비용** 축 |

```text
의무(대인 등) + 필요한 선택 담보
 ↓
운전자 범위·연령·할인 특약 맞추기
 ↓
견적 비교(동일 조건) → 가입·증권 보관
 ↓
사고 시: 안전 → 신고·보험사 → 과실·수리·합의
```

---

## 2. 자동차보험 vs 운전자보험

| | [[자동차 보험]] | [[운전자 보험]] |
|--|-----------------|-----------------|
| 주 목적 | 피해 **배상**, 내 차·탑승자 등 | 운전자의 **형사·벌금·합의·변호사** 정액 등 |
| 대상 | 차량(피보험자동차) | 사람(운전자)인 경우 많음 |
| 성격 | 의무 + 선택 | 선택 |

배상·수리는 자보를 먼저 튼튼히. 운전자보험은 그 **공백**을 메울지 본다. 
상세 비교: [[운전자 보험]].

---

## 3. 주요 담보 (이름만 고정해도 됨)

상품 문구는 “대인배상Ⅰ·Ⅱ”처럼 표기된다. **한도·자기부담·면책**은 증권 확인.

### 3.1 대인배상 (사람)

| 구분 | 설명 |
|------|------|
| **대인배상Ⅰ** | 법정보장. 상대 **사망·부상**에 대한 최소 의무 층 |
| **대인배상Ⅱ** | 법정 한도를 넘는 손해를 위해 **한도를 키운** 선택(사실상 필수에 가깝게 보는 집이 많음) |

상대 치료비·위자료·합의 성격의 **민사 배상** 축이다. 
한도가 낮으면 큰 사고에서 **개인 재산**이 위험해질 수 있다.

### 3.2 대물배상 (남의 물건·차)

남의 차·시설 등 **물건 손해**를 보상. 
한도(예: 수억 원대)를 사고 규모·주차·고가 차량 환경을 보고 고른다. 
자기부담금이 붙는 설계가 있다.

### 3.3 자기신체사고 vs 자동차상해

나와 탑승자의 **부상·사망** 쪽.

| | 자기신체사고(자손) | 자동차상해(자상) |
|--|-------------------|------------------|
| 설명 | 과실·상대 유무에 따라 지급이 까다로울 수 있음 | 부상 등급·약관에 따라 **정액·실손 혼합**으로 더 두껍게 설계되는 경우가 많음 |
| 보험료 | 상대적 저렴한 편 | 상대적 비쌈 |

“싸게만” 가면 자손만, “나와 가족을 두껍게”면 자상 비교가 흔하다. **약관 정의**가 기준.

### 3.4 자기차량손해 (자차)

내 차 **수리·전손** 등. 
단독 사고·가해자 불명·침수 등 **조건·자기부담·부품**을 본다. 
중고·잔가·수리비 대비 보험료가 안 맞으면 빼는 선택도 있다 (대신 사고 시 자비).

### 3.5 무보험차상해 등

보험 없는 차·뺑소니 등으로 다쳤을 때 나를 보호하는 담보. 
대인·자상과 **역할이 겹치는지** 설계 시 물어본다.

### 3.6 기타 자주 붙는 것

| 특약·서비스 | 설명 |
|-------------|------|
| **긴급출금·견인** | 배터리·타이어·견인 거리 한도 |
| 다른 자동차 운전 | 남의 차·렌트 운전 시 보장 범위 (조건 엄격) |
| 물적사고 할증 완화 등 | 소액 사고 시 할증 완화 — 회사·상품마다 |
| 법률비용·형사 관련 | 일부는 자보 특약, 두꺼우면 [[운전자 보험]]과 중복 점검 |

## 4. 운전자 범위·연령

보험료와 “누가 몰아도 되나”를 가르는 핵심이다.

| 특약 | 의미 |
|-----------|------|
| 부부 한정 / 가족 한정 | 지정 범위만. 범위 밖이 몰면 **보장 거절** 위험 |
| 누구나(연령 제한) | 범위는 넓고 보험료↑. **최저 연령**을 맞춤 |
| 임직원·가족 등 | 법인·가족 차 설계 |

빌려 주기 전 **특약상 운전 가능 여부**를 본다. 
연령을 낮추면(예: 21세 이상 → 누구나) 보험료가 크게 오른다.

---

## 5. 보험료를 가르는 것

| 요인 | 메모 |
|------|------|
| 차종·배기·가액·연식 | 자차·부품비 |
| 운전자 범위·연령 | 위 §4 |
| 주행거리(마일리지) | 적게 타면 할인·정산형 |
| 블랙박스·안전장치 | 할인 특약 (장착·고지 조건) |
| 자녀·티맵 등 | 회사별 제휴 할인 |
| 사고·할증 등급 | 과거 사고·갱신 할증 |
| 가입 경력·무사고 | 다이렉트·설계 견적에 반영 |
| 납입 방법 | 일시납·분납 수수료 |

**동일 담보·한도·특약**으로 여러 곳(다이렉트·설계)을 비교한다. 
싸다고 대인Ⅱ·대물 한도만 깎으면 본말이 뒤바뀐다.

---

## 6. 가입·갱신 흐름

1. 차대번호·차종·연식·주행·운전자 정보 준비 
2. 의무 + 선택 담보·한도 초안 
3. 견적 비교 → 청약·고지(사고·장치 등 사실대로) 
4. 증권(전자)·긴급출동 번호·사고 접수 경로 저장 
5. **만기 전** 갱신 견적 — 보험료·등급·특약 변경 여부 

만기 공백에 운행하면 미가입과 비슷한 위험에 노출된다. 
차 팔면 **해지·명의 변경** 절차를 보험사에 바로 알린다.

---

## 7. 사고 났을 때 

1. **안전** — 비상등·삼각대·안전한 곳 
2. 부상자 있으면 **119**, 필요 시 **경찰** 
3. 상대 연락처·차번호·사진(현장·파손·블랙박스) 
4. **내 보험사 사고 접수** (상대 보험만 믿지 말고 내 증권도) 
5. 과실·수리·렌트·합의는 약관·담당 안내 따름 
6. 음주·무면허·도주 등은 **면책·형사**로 크게 불리 

작은 접촉이라도 나중에 통증·추가 파손이 나올 수 있어, **기록·접수**를 남기는 편이 안전한 경우가 많다. 
할증이 걱정되면 자기부담·물적사고 할증 특약·보험사 안내를 물어본다.

형사·합의 압박이 크면 [[운전자 보험]] 증권도 같이 본다.

---

## 8. 받을 때·거절 때 자주 걸리는 것

| 이슈 | 설명 |
|------|------|
| 운전자 범위 위반 | 특약에 없는 사람이 운전 |
| 고지 위반 | 블랙박스 할인만 받고 미장착 등 |
| 면책 | 음주·약물·무면허·경기·고의 등 |
| 자기부담 | 자차·대물에 본인 부담금 |
| 중고 부품·감가 | 자차 지급액이 기대와 다름 |
| 과실 비율 | 내 과실만큼 내 담보·상대 청구가 갈림 |

분쟁 시 약관 조항·사고 조사 결과를 받아 두고, 필요하면 분쟁조정 등 공적 경로를 검토한다 ([[보험 기초]] 청구).

## 9. 체크리스트

- [ ] 대인Ⅰ(의무) + **대인Ⅱ 한도**가 충분한가 
- [ ] **대물 한도**·자기부담 
- [ ] 자손 vs **자상** 중 무엇을 골랐는지 설명 가능한가 
- [ ] 자차 필요 여부(차 가액·수리비 vs 보험료) 
- [ ] 무보험차상해·긴급출동 
- [ ] 운전자 **범위·연령** = 실제 운전자 
- [ ] 마일리지·블랙박스 등 할인 조건 이행 
- [ ] 만기일·갱신 알림 
- [ ] 사고 접수 번호·증권 앱 
- [ ] 형사·벌금 공백이 크면 [[운전자 보험]] 검토 

---

## 10. 정리

1. 자보는 **배상·내 차·탑승**이 본업이고, 의무 담보 + 한도 설계가 먼저다. 
2. 운전자 범위·연령을 어기면 사고 때 보장이 무너질 수 있다. 
3. 할인은 조건(주행·장치)을 지켜야 한다. 
4. 형사·변호사·합의 정액은 [[운전자 보험]] 축과 역할을 나눈다. 
5. 비교는 **같은 한도·특약**으로, 약관·증권이 최종이다.

---

## 면책

> **면책** 
> 일반 정보이며 **가입·해지·특약 선택 권유가 아니다**. 
> 의무보험 범위·요율·할인·약관은 바뀐다. 계약 전 보험사·설계 설명서·약관을 확인한다. 
> 사고·과실·보상은 개별 사실관계에 따르며, 이 글이 법률·보험 자문이 아니다.
