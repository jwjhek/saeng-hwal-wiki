# 보험 기초

> **분류:** 금융 · [[생활위키 목차]]

일상에서 만나는 보험을 **종류·용어·고를 때 원칙** 위주로 정리한다.  
상품·약관·세법은 자주 바뀌고 개인 상황에 따라 답이 다르다.

확인일: 2026-08-06

---

## 1. 보험이 하는 일

보험은 **큰 손해가 날 확률은 낮지만, 나면 감당하기 어려운 위험**을 여럿이 나눠 지는 장치다.

```text
매달(또는 일시) 보험료 납부
        ↓
사고·질병·사망 등 약관상 사유 발생
        ↓
보험금 지급 (또는 보장)
```

| 잘 맞는 위험 | 보험보다 저축·대비가 나은 경우 |
|--------------|--------------------------------|
| 큰 병원비, 사망 시 유가족 생활비 | 자주 쓰는 소액 (안경, 감기약 수준) |
| 자동차 대인·대물 | “설마”에 모든 특약을 과다 가입 |
| 화재·배상책임 | 이미 다른 보험과 **보장 중복**만 쌓는 경우 |

**원칙**: 파산·가계 붕괴를 막을 보장을 먼저, 저축·투자는 목적에 맞는 별도 수단으로.

---

## 2. 큰 분류

### 2.1 생명보험 vs 손해보험 (감각)

| | 생명보험 | 손해보험 |
|--|----------|----------|
| 초점 | 사람(사망·생존·질병 등) | 재산·배상·실손 성격이 많음 |
| 예 | 종신·정기·연금·일부 질병정액 | 자동차·화재·실손의료비·여행 |
| 보험금 | 약정 **정액**이 많은 편 | **실제 손해** 보상이 많은 편 (상품마다 다름) |

실손·자동차는 손해보험사, 종신·연금은 생명보험사 비중이 크다.  
같은 “암보험”도 회사·상품 구조가 다를 수 있다.

### 2.2 사회보험 vs 민영보험

| 사회보험 (국가) | 민영보험 |
|-----------------|----------|
| 국민건강보험, 국민연금, 고용·산재 등 | 개인이 계약하는 보험 |
| 의무·공적 성격 | 선택 가입 |

민영을 고를 때는 **건보·실손이 이미 덮는 부분**을 알고, 그 위에 필요한 정액·특약만 얹는 식이 합리적이다.

---

## 3. 자주 보는 상품 유형

### 3.1 실손의료보험 (실손)

병원·약국에서 **실제로 쓴 의료비** 중 건보 급여·비급여 등을 약관 범위에서 보상.  
“병원비 보험”의 기본층.

- 자기부담금·연간 한도·비급여 특약 구조는 세대(구실손/신실손 등)마다 다름  
- **실제 손해를 넘기지 않음** (여러 실손으로 중복 수령 제한)  
- 갱신·보험료 인상 가능성을 전제로 둔다  

### 3.2 정액 질병·상해 (암·뇌·심장 등)

진단 시 **약정 금액**을 받는 형태가 많음.  
치료비 보조, 생활비·소득 공백 메우기 목적.

- “암 진단비”와 “치료비 실손”은 역할이 다름  
- 유사암·소액암·면책·감액 기간을 약관에서 확인  
- 겹치는 특약이 여러 증권에 있으면 보험료만 이중  

### 3.3 사망 보장 (정기·종신)

| 정기보험 | 종신보험 |
|----------|----------|
| 일정 기간만 사망 보장, 보험료 상대적 저렴 | 평생 보장, 보험료↑·저축성 성격 섞인 상품 많음 |
| “가장 소득 대체”에 유리한 경우 많음 | 상속·강제 저축 목적이면 따져볼 여지 |

유가족이 **몇 년치 생활비·대출**이 필요한지가 가입 금액의 출발점이다.

### 3.4 자동차보험

의무: **대인배상** 등 법정보장.  
선택: 대물 확대, 자차, 무보험차 상해, 긴급출동 등.

- 운전자 범위·연령 특약  
- 블랙박스·마일리지 할인  
- 사고 시 할증·갱신 보험료 영향  

형사·벌금·변호사·합의 정액 등은 자동차보험과 역할이 다른 [[운전자 보험]]을 참고.

### 3.5 기타

| 종류 | 메모 |
|------|------|
| 여행자보험 | 단기 해외·국내 여행 |
| 화재·재물 | 주택·점포 |
| 배상책임 | 일상생활·화재 배상 등 |
| 연금·저축성 | 보장보다 **수익률·수수료·중도해지**를 투자 상품처럼 비교 |
| 운전자보험 | → [[운전자 보험]] (자동차보험과 역할 다름) |

저축성·변액은 “보험” 라벨이어도 **수수료·공시이율·펀드 비용**을 꼭 본다. 순수 보장이 목표면 저축성 비중을 낮추는 선택이 많다.

## 4. 필수 용어

| 용어 | 의미 |
|------|------|
| 보험료 | 내가 내는 돈 |
| 보험금 | 사고 시 받는 돈 |
| 보험금 수익자 | 보험금을 받도록 지정된 사람 |
| 피보험자 | 보장 대상이 되는 사람(또는 차량 등) |
| 계약자 | 계약하고 보험료를 내는 주체 |
| 보장 / 담보 | 무엇을  confer 하는지 |
| 특약 | 주계약에 붙이는 추가 보장 |
| 면책 | 안 주는 경우 (고의, 일부 위험 등) |
| 감액 기간 | 초기 일정 기간 보험금 축소 |
| 고지의무 | 청약 시 건강·직업 등을 사실대로 알릴 의무 |
| 알릴 의무 위반 | 나중에 해지·보험금 거절로 이어질 수 있음 |
| 청약 철회 | 일정 기간 내 계약 취소 (기간은 법·약관) |
| 품질보증해지 등 | 약관 설명 의무 위반 시 구제 제도 (요건 확인) |
| 갱신형 | 주기마다 보험료 재산정 |
| 비갱신형 | 기간 중 보험료 구조가 다른 형태 (상품별 확인) |
| 만기 환급 / 순수보장 | 만기 때 돈 돌려주는지, 보장만 하는지 |
| 자기부담금 | 실손 등에서 본인이 먼저 부담하는 금액 |
| 대기 기간 | 가입 후 보장이 안 되는 초기 기간 |

## 5. 가입 전 체크리스트

1. **목적** — 실손? 사망 시 생활비? 암 진단비? 자동차?  
2. **이미 있는 보장** — 건보, 직장 단체, 가족 합산 실손·정액  
3. **예산** — 소득 대비 보험료 과하면 유지 실패 → 해지 손해  
4. **건강·직업 고지** — 숨기면 장래 분쟁  
5. **갱신·만기·납입 기간** — 60세 납 vs 90세 만기 등 숫자 읽기  
6. **면책·소액암·부지급 사례** — 요약서가 아니라 약관 해당 조항  
7. **설계사·비교** — 한 곳만 듣지 말고 동일 조건을 비교  
8. **증권 보관** — 전자증권·앱·수익자 지정 확인  

### 고지의무

병원 치료·약 복용·검사 이상을 **물어보면 사실대로**.  
애매하면 보험사에 문서로 확인. “가벼운 거니까” 하고 빼면 나중에 치명적일 수 있다.

---

## 6. 보험금 청구 감각

1. 사고·진단 서류 (진단서, 진료비 영수증, 입퇴원 확인 등)  
2. 보험사 앱·콜센터·설계사 경로로 접수  
3. 실손은 영수증·세부내역, 정액은 진단명·코드 중요  
4. 조사·자문이 있으면 기간이 길어질 수 있음  
5. 부지급 시 **사유·약관 조항**을 받아 두고, 필요 시 분쟁 조정 기관 검토  

서류 목록은 상품·사유마다 다르니 접수 창구 안내를 따른다.

---

## 7. 해지·유지

| 상황 | 생각 |
|------|------|
| 급전 | 약관대출·감액·일부 해지를 해지보다 먼저 검토 |
| 보장 과다 | 중복 특약부터 정리 |
| 갱신 보험료 급등 | 보장 공백 없이 대체 가능한지 비교 후 이동 |
| 저축성 중도 해지 | 해지환급금이 납입액보다 적을 수 있음 |

“이미 낸 돈이 아까워”로 불필요 계약을 유지하는 것도 비용이다.  
다만 **실손·필수 사망보장**을 공백으로 두지는 말 것.

---

## 8. 연령·상황별 우선순위 (예시)

개인차는 크다. 참고용.

| 상황 | 우선 검토 |
|------|-----------|
| 사회초년 | 실손, (운전 시) 자동차, 필요 시 소액 정기사망 |
| 부양가족 | 정기 사망·소득대체, 실손, 주요 질병 정액 |
| 자가 보유 | 화재·배상, 자동차 |
| 은퇴 근접 | 실손 유지 가능 여부, 불필요 특약 정리, 저축성 재검토 |
| 여행 | 여행자보험 단기 |

아이에게 과도한 성인병 특약만 잔뜩 넣기보다, **가족 실손·보호자 사망보장**이 우선인 경우가 많다.

## 9. 흔한 오해

| 오해 | 현실 |
|------|------|
| 보험은 많을수록 좋다 | 중복·유지비·해지 위험 |
| 실손만 있으면 끝 | 소득 공백·간병·사망은 별개 |
| 지인이 추천하면 무조건 OK | 약관·본인 고지·목적이 우선 |
| 저축성 = 은행 적금 | 사업비·해지환급 구조가 다름 |
| 거절·부담보 = 평생 끝 | 상품·기간·다른 회사·조건 가입 여지 (사례별) |
| 보험금은 신청만 하면 바로 | 심사·조사 가능 |

## 10. 정리 — 다섯 줄

1. **큰 위험부터** (실손·필수 배상·부양 책임).  
2. **건보 + 기존 증권**을 그린 다음 민영을 얹는다.  
3. **고지는 정직**하게, 약관은 **면책·갱신**을 읽는다.  
4. 저축·투자는 보험과 **목적을 섞지 말지** 먼저 정한다.  
5. 상품 권유보다 **내 예산·만기·중복**을 기준으로 고른다.
