# 실손보험

> **분류:** 금융 · [[생활위키 목차]]

**실손의료보험(실손)** 은 병원·약국에서 **실제로 쓴 의료비**를 약관 범위에서 보상하는 민영보험이다.  
흔히 “병원비 보험”의 **기본층**으로 본다. 보험 전체 틀은 [[보험 기초]], 자동차·운전은 [[자동차 보험]] · [[운전자 보험]].

확인일: 2026-08-11  
세대·자기부담·특약·청구 서류·보험료는 **약관·보험사·가입 시점**마다 다르다. 증권·약관·설계 설명이 우선.

---

## 1. 개요

| 항목 | 설명 |
|------|------|
| 무엇 | 진료비·약제비 등 **실제 지출**의 일부를 보상 (실손 = 실제 손해) |
| 기반 | **국민건강보험**이 먼저 적용된 뒤, 본인부담·비급여 등을 실손이 이어 받는 구조가 많음 |
| 성격 | 손해보험 성격. **쓴 만큼**(한도·자기부담 내). 진단만으로 큰 정액을 주는 암보험과 다름 |
| 중복 | 실손끼리 **실제 손해를 넘는 이중 수령은 제한**되는 경우가 일반적 |
| 갱신 | 대부분 **갱신형**. 나이·손해율에 따라 보험료가 오를 수 있음 |

```text
병원·약국에서 진료·처방
        ↓
국민건강보험 급여 처리
        ↓
본인부담금·비급여 등 발생
        ↓
실손 약관 범위에서 청구·보상 (자기부담·한도 적용)
```

---

## 2. 건보·정액보험과 역할

| | 국민건강보험 | [[실손보험]] | 암·뇌·심장 등 **정액** |
|--|--------------|--------------|------------------------|
| 주체 | 공적 | 민영 | 민영 |
| 지급 | 급여 수가·본인부담 구조 | 실제 의료비 일부 | 진단·수술 시 **약정 금액** |
| 목적 | 기본 의료 보장 | 본인부담·비급여 완충 | 생활비·여유자금·공백 메우기 |

실손만으로 “소득이 끊긴 기간의 생활비”까지 다 커버된다고 보기 어렵다.  
큰 진단비·사망 보장은 [[보험 기초]]의 정액·정기 쪽을 따로 본다.

---

## 3. 자주 나오는 보장 축

상품·세대마다 이름과 묶음이 다르다. **증권의 담보 목록**이 기준이다.

| 축 | 설명 |
|----|------|
| **입원** | 입원 의료비 (한도·일수·자기부담) |
| **통원** | 외래 진료비 (1회·연간 한도, 자기부담·공제) |
| **처방약** | 약국 조제약 (통원과 묶이거나 별도인 경우) |
| **비급여** | 건보 적용 안 되는 검사·치료·재료 등 — **특약·세대**에 따라 범위가 크게 갈림 |

최근 상품은 급여/비급여를 **특약으로 나누어** 고르게 하는 설계가 많다.  
“실손 하나면 비급여 전부”가 아니다.

---

## 4. 자기부담·한도

| 용어 | 설명 |
|------|------|
| **자기부담금(공제)** | 보상 전에 본인이 먼저 부담하는 금액·비율 |
| **연간 한도** | 1년 동안 받을 수 있는 상한 |
| **1회(1일) 한도** | 통원 1회당 상한 등 |

같은 “통원”이라도 세대·특약에 따라 **공제액·비율**이 다르다.  
소액 통원을 자주 청구하면 자기부담 때문에 **받는 돈이 기대보다 적을** 수 있다.

---

## 5. 세대별 특징 (1~4세대)

실손은 가입 **시기·표준약관**에 따라 1~4세대로 나눈다.  
시점은 대략 **표준화·개정 시점**이고, 회사·상품·특약에 따라 경계가 조금 다를 수 있다.  
**내가 든 증권·약관 요약**이 최종이다.

### 5.1 시기 요약

| 세대 | 대략 가입 시기 | 별칭·메모 |
|------|----------------|-----------|
| **1세대** | ~2009년 9월(표준약관 전) | 구실손. 회사마다 약관 편차 큼 |
| **2세대** | 2009년 10월 ~ 2017년 3월 | 표준화 시작, 자기부담 본격 도입 |
| **3세대** | 2017년 4월 ~ 2021년 6월 | 신실손·「착한 실손」으로 불리기도 함 |
| **4세대** | 2021년 7월 ~ (판매 중인 축) | 급여·비급여 분리, 비급여 이용에 따른 보험료 차등 |

「구실손」은 보통 1~2세대(넓게는 3세대까지)처럼 **지금 신상품과 다른 옛 계약**을 가리킬 때 쓰는 말이다.

### 5.2 세대별 핵심

#### 1세대 (~2009.9, 표준약관 전)

| 항목 | 흔히 이야기되는 특징 |
|------|----------------------|
| 약관 | 보험사별 **제각각**. 같은 “1세대”라도 증권마다 다름 |
| 보장 | 입원 등에서 **자기부담 0%(전액에 가깝게)** 인 계약이 많다는 설명이 흔함 |
| 비급여 | 포괄적으로 넓게 들어가는 경우가 많음 (상품별 확인) |
| 보험료 | 갱신 시 **부담이 큰** 편으로 자주 거론 |
| 주의 | “1세대 = 무조건 최고”가 아니라, **내 약관 문구**를 봐야 함 |

손보 협회 등 안내에서도 1세대는 표준약관 이전·회사별 차이를 강조한다.

#### 2세대 (2009.10 ~ 2017.3)

| 항목 | 흔히 이야기되는 특징 |
|------|----------------------|
| 약관 | **표준화**로 회사 간 큰 틀이 맞춰지기 시작 |
| 자기부담 | 입원·통원 등에 **자기부담률·공제**가 본격 도입 (흔히 급여·비급여 10~20%대 이야기) |
| 한방·치과 | 건보 **급여 영역 위주**로 제한되는 식으로 정리된 경우가 많음 |
| 갱신 | 1~3년 등 (상품별) |
| 의미 | “실손 = 병원비 거의 다”에서 **본인 부담이 생긴** 전환기 |

#### 3세대 (2017.4 ~ 2021.6)

| 항목 | 흔히 이야기되는 특징 |
|------|----------------------|
| 구조 | **기본형 + 특약**. 과잉진료 우려가 큰 비급여를 분리 |
| **3대 비급여 특약** | ① 도수치료·체외충격파·증식치료 ② 비급여 주사 ③ 비급여 MRI/MRA 등 — **특약·연간 한도·횟수**가 따로 붙는 설명이 흔함 |
| 자기부담 | 일반 의료비와 3대 비급여 특약의 부담률·공제가 **다를 수** 있음 (특약은 더 높은 부담 이야기가 많음) |
| 보험료 | 기본만 들면 상대적으로 낮게, 특약을 붙이면 그만큼 오름 |
| 별칭 | 「착한 실손」— 보험료·구조를 맞춘 개편으로 불린 마케팅·언론 표현 |

체외충격파 등 비급여 시술은 [[체외충격파 치료]]와 겹쳐 이야기되지만, **실손 적용 여부는 특약·약관**이다.

#### 4세대 (2021.7 ~)

| 항목 | 흔히 이야기되는 특징 |
|------|----------------------|
| 구조 | **급여**와 **비급여**를 더 분명히 나눔. 비급여는 **별도 특약**으로 선택하는 설계가 중심 |
| 자기부담 | 급여·비급여 **부담률을 다르게** (흔히 급여 쪽보다 비급여 쪽을 더 높게 — 예: 급여 20%·비급여 30%대가 자주 인용됨). 통원은 **정액 공제 vs 비율** 중 큰 쪽을 쓰는 식의 계산이 많음 |
| 보험료 | 기본(급여 중심)만이면 상대적으로 낮고, 비급여 특약·이용량에 따라 달라짐 |
| **비급여 보험료 차등** | 비급여 보험금 수령(이용)이 많으면 **할증**, 적으면 **할인**이 붙는 제도가 도입·시행된 것이 4세대의 큰 변화로 안내됨 (적용 시점·세부 구간은 공시·약관) |
| 갱신·재가입 | 갱신 1년, 재가입 주기(예: 5년) 이야기가 흔함 — **내 증권** 확인 |

지금 **새로 가입**하면 대체로 4세대 축이다. 1~3세대는 **유지 중인 옛 계약**이 많다.

### 5.3 비교 요약

| | 1세대 | 2세대 | 3세대 | 4세대 |
|--|-------|-------|-------|-------|
| 표준화 | 약함(회사별) | 시작 | 이어짐 | 현행 표준 축 |
| 자기부담 | 없거나 매우 낮다는 설명 많음 | 도입(10~20%대 언급 많음) | 유지·특약은 더 높을 수 있음 | 급여·비급여 차등(비급여↑ 언급 많음) |
| 비급여 | 포괄적일 수 있음 | 기본에 넓게 포함되는 편 | **3대 항목** 특약 분리 | **비급여 전반** 특약·이용 차등 |
| 보험료(체감) | 갱신 부담 크다는 평 많음 | 중간 | 기본만이면 상대적으로 낮음 | 기본 낮음·비급여·할증에 민감 |
| 갈아타기 | 보장↓·보험료↓ 트레이드오프 | 동일 | 동일 | 신계약은 보통 여기로 |

숫자는 **예시·흔히 인용되는 수준**이다. 실제 자기부담·한도·특약명은 증권마다 다르다.

### 5.4 내 세대 확인·전환

1. 보험 앱·증권 PDF·고객센터에 **가입일·상품명·약관 버전** 확인  
2. 설계사·비교 공시보다 **약관 조항**(입원·통원·비급여)을 본다  
3. 4세대로 **전환**을 권유받으면:  
   - 지금 보장(특히 1·2세대의 넓은 부분) vs 보험료  
   - 비급여 이용이 많은지(4세대 할증)  
   - 건강·고지·나이로 **재가입이 가능한지**  
4. “무조건 4세대가 이득/손해”는 없다. **의료 이용 패턴·예산**에 달림  

중요한 점:

1. **지금 든 증권의 세대**가 내 보장의 기준이다.  
2. 전환·중지·재가입은 보험사·금융감독·비교공시 안내를 따른다.  
3. 5세대 등 **이후 개편**이 논의·예고될 수 있으나, 기존 계약은 그때그때 공지가 우선이다.

---

## 6. 중복 가입

- 실손 **여러 개**를 들어도, 실제 의료비를 **초과해 받는 구조는 제한**되는 것이 일반적이다.  
- 가족·단체·카드 부가·여행자보험 단기 담보 등과 **겹치는지** 확인한다.  
- 정액 암보험과 실손은 **역할이 다름** → 둘 다 있을 수 있으나, 실손끼리만 잔뜩 늘리는 것은 효율이 떨어질 때가 많다.

---

## 7. 보험료·갱신

| 이슈 | 설명 |
|------|------|
| 갱신 | 주기마다 보험료 재산정. **나이가 들수록·손해율이 오르면** 부담↑인 경우가 많음 |
| 유지 | 해지 후 재가입 시 **고지·인수·나이** 때문에 조건이 나빠질 수 있음 |
| 특약 | 비급여·특정 담보를 빼면 보험료는 줄지만 **보장 공백**이 생김 |

“평생 보험료 고정”처럼 말하는 상품과 혼동하지 말 것. 실손은 **갱신·인상**을 전제로 두는 편이 안전하다.

---

## 8. 청구할 때

1. 진료비·약제비 **영수증**, (필요 시) **세부내역서**, 진단서·입퇴원 확인 등  
2. 보험사 앱·홈페이지·팩스·설계사 경로로 접수  
3. 급여/비급여·본인부담이 구분돼 있는지 확인  
4. 다른 실손·단체 청구가 있으면 **안내대로** 순서·분담 처리  
5. 부지급·삭감 시 **사유·약관 조항**을 받아 둔다  

소액은 앱 간편청구, 고액·입원은 서류가 더 붙는 경우가 많다.  
자세한 목록은 접수 창구 안내가 우선 ([[보험 기초]] 청구 절과 같음).

## 9. 면책·주의 (자주 걸리는 것)

| 이슈 | 설명 |
|------|------|
| 고지의무 | 청약 시 병력·치료를 사실대로. 위반 시 해지·부지급 위험 |
| 면책·감액 | 약관상 보상 안 하는 경우, 초기 감액 기간 |
| 미용·예방 | 성형·단순 건강검진 등은 제외되는 경우가 많음 (약관 확인) |
| 산재·자보 | 산재·자동차보험으로 처리되는 구간과 실손 관계가 약관마다 다름 |
| 해외 | 국내 실손이 **해외 의료비**를 안 덮거나 제한하는 경우 → 여행자보험 검토 |

## 10. 고를 때·유지할 때 체크

- [ ] 내 증권이 **몇 세대**(가입일·상품명)인지  
- [ ] 자기부담·통원/입원 한도·**비급여 특약**을 설명들을 수 있는지  
- [ ] 4세대면 **비급여 보험료 차등(할인·할증)** 안내를 봤는지  
- [ ] 갱신·보험료 인상 가능성을 감수하는지  
- [ ] 암·뇌·심장 **정액**과 역할을 섞어 생각하지 않는지  
- [ ] 갈아탈 때 **기존 세대 보장 vs 4세대**를 같은 표로 비교했는지  
- [ ] 청구 앱·서류 보관 방법을 아는지  

---

## 11. 정리

1. 실손은 **실제 의료비**를 건보 뒤에서 받쳐 주는 층이다.  
2. 정액 진단비·사망보장과 **목적이 다르다**.  
3. 세대·특약·자기부담이 곧 내 보장이다. 1세대일수록 넓고 비싸다는 이야기, 4세대는 비급여·할증에 민감하다는 이야기가 흔하나 **증권**이 우선이다.  
4. 중복 실손은 실손액 한도 안에서만 의미가 있는 경우가 많다.  
5. 갱신·인상을 전제로 **유지 가능 보험료**를 본다.

> **면책**  
> 일반 정보이며 **가입·해지·전환·특약 선택 권유가 아니다**.
