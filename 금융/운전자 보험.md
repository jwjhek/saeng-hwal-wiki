# 운전자 보험

> **분류:** 금융 · [[생활위키 목차]]

운전자보험은 **내가 운전하다 생긴 교통사고**에서, 자동차보험이 잘 안 덮는 **형사·행정·합의·변호사** 쪽 비용을 **정액·특약**으로 준비하는 상품이다.  
차의 대인·대물·자차는 [[보험 기초]]의 **자동차보험** 영역이고, 운전자보험은 그 **옆자리**에 가깝다.

확인일: 2026-08-06

---

## 1. 자동차보험과 뭐가 다른가

| | 자동차보험 | 운전자보험 |
|--|------------|------------|
| 주 목적 | 사고 **피해 배상·내 차 수리** 등 | 운전자 본인의 **형사·벌금·합의·방어** 등 |
| 성격 | 의무(대인 등) + 선택 특약 | 선택 가입 (손해보험 정액형 비중이 큼) |
| 대상 | **차량** 중심 (피보험자동차) | **사람(운전자)** 중심인 경우가 많음 |
| 예 | 대인·대물·자차·무보험차상해 | 교통사고처리지원금, 변호사선임, 벌금, 형사합의 관련 |

한 줄:

```text
자동차보험  → 상대·내 차·배상 (민사상 손해를 주로)
운전자보험  → 내가 처한 형사·합의·법률비용 공백을 메우려는 정액 보장
```

둘 다 있으면 “교통사고 올패스”가 아니다.  
약관 면책(음주·무면허·도주 등)은 **양쪽 모두**에서 자주 걸린다.

---

## 2. 왜 따로 보나 — 공백이 생기는 지점

교통사고로 **상대가 크게 다치거나 사망**하면:

1. 자동차보험 **대인배상**으로 치료비·합의금 성격의 손해를 처리하는 흐름  
2. 동시에 **형사 입건·기소**, **벌금**, **합의 압박**, **변호사** 비용이 생길 수 있음  

민사상 배상과 형사·행정은 축이 다르다.  
자동차보험만으로는 **변호사 비용·벌금·형사합의금**이 기대만큼 안 나오는 경우가 있어, 그 틈을 운전자보험 특약이 노린다.

다만:

- “무조건 실형·거액”이 아니라 **사고 경위·과실·상해 정도**에 따름  
- 특약마다 **중상해·사망·12주 이상** 등 **트리거 조건**이 있음  
- 이미 다른 증권·단체·신용카드 부가에 비슷한 보장이 있으면 **중복**만 살 수 있음  

---

## 3. 자주 보는 보장 (이름만 알아두기)

상품·시기에 따라 이름과 묶음이 다르다. **약관의 정의**가 기준이다.

| 보장(흔한 이름) | 감각적 역할 |
|-----------------|-------------|
| **교통사고처리지원금** | 상대 사상 등 조건 충족 시, 합의·처리에 쓰는 정액 지원 |
| **벌금** | 교통사고 관련 형사 벌금 실손/정액 (한도·면책 확인) |
| **변호사선임비용** | 형사 절차에서 변호사 비용 지원 |
| **형사합의금** / 유사 | 합의에 필요한 금액을 정액으로 |
| **자동차사고 부상치료비** 등 | 운전자·탑승 본인 부상 정액 (실손·자상과 역할 구분) |
| **면허정지·취소** 관련 | 행정처분 시 위로금 성격 (상품에 따라) |
| **방어비용** | 소송·방어 관련 비용 |

포인트:

- **실손형**(쓴 만큼, 한도 내) vs **정액형**(조건 맞으면 약정액)을 구분  
- 같은 “합의”라도 **자동차 대인으로 나가는 돈**과 **운전자보험 정액**은 별개 계약  
- **중복 가입**해도 실손형은 실제 손해 한도, 정액형은 약관대로 각각 지급될 수 있음 → 보험료 대비 필요 여부만 따질 것  

---

## 4. 가입 형태

| 형태 | 메모 |
|------|------|
| **운전자보험 단독** | 운전자 보장만 모은 상품 |
| **상해·통합 보험의 특약** | 다른 보장에 교통사고 특약 추가 |
| **자동차보험 특약** | 일부 형사·벌금 관련을 자보에 붙이기도 함 (회사마다) |
| **가족·부부형** | 배우자·자녀 운전까지 범위 확장 여부 확인 |

**피보험자 = 누구의 운전 사고인가**가 핵심이다.  
내 차만 타도, **다른 사람 차·렌트·회사차**를 자주 몰면 “차량”이 아니라 “운전자” 보장이 더 맞는 경우가 있다.  
반대로 차는 있지만 거의 안 몰면 보장이 과할 수 있다.

---

## 5. 자동차보험에서 먼저 챙길 것

운전자보험을 보기 **전에** 자보 쪽을 점검하는 편이 낫다.

1. **대인배상** 무한(또는 충분한 한도) — 큰 사고 시 기본  
2. **대물** 한도 — 외제차·다중 충돌  
3. **자기신체사고 / 자동차상해** — 나와 탑승자  
4. **무보험차상해**  
5. 운전자 **연령·범위** 특약 (부부만, 가족, Anyone 등)  
6. 긴급출동·블랙박스 할인은 부가  

자보가 부실한데 운전자보험만 두껍게 드는 것은 순서가 뒤바뀐 경우가 많다.  
자세한 큰 그림은 [[보험 기초]].

---

## 6. 가입 전 체크리스트

- [ ] **목적** — 형사·벌금·변호사인지, 본인 부상 정액인지 명확히  
- [ ] **자동차보험** 대인·대물·자상(또는 자손) 한도 확인  
- [ ] 이미 있는 **특약·단체·카드** 중복 여부  
- [ ] 지급 **조건** (사망·중상해·진단주수·공소 등)  
- [ ] **면책** — 음주·약물·무면허·도주·고의·경기·유상운송 등  
- [ ] 보장 기간·**갱신**·보험료 인상 구조  
- [ ] 누가 운전하나 — 본인만 / 가족 / 타인 차량  
- [ ] 설계서의 **월 보험료 vs 실제 필요한 한도**  

영업 멘트만 듣고 “형사합의금 ○억”만 보지 말고, **언제 얼마가 나오는지** 약관 문장을 본다.

---

## 7. 면책·주의 (자주 걸리는 것)

약관마다 다르지만 감각적으로 자주 등장:

| 유형 | 메모 |
|------|------|
| 음주·약물 | 민·형사·보험 모두에서 치명적 |
| 무면허·면허 조건 위반 | |
| 사고 후 도주 | |
| 고의·자살·싸움 | |
| 경기·흥행·시험운전 | |
| 유상 운송·영업용 | 개인용 약관과 안 맞을 수 있음 |
| 전쟁·천재 등 | 일반 면책 |

“보험 있으니까”가 아니라 **사고 예방·블랙박스·과실 줄이기**가 1순위다.

---

## 8. 보험금·사고 시 감각

1. **안전·신고·교환** — 112/보험사 사고접수 (자보)  
2. 사진·블랙박스·목격자  
3. 상대 상해 정도에 따라 **형사 절차** 진행 가능 → 필요 시 변호사  
4. 운전자보험은 **진단서·공소장·판결·영수증** 등 약관상 서류  
5. 자보 담당·운전자보험 담당이 **다를 수** 있음 → 증권 번호 따로 보관  

합의는 법률·과실 문제라 성급히 사인하지 않는 편이 낫다.  
보험금은 **약관 심사**를 거친다.

---

## 9. 누구에게 더 의미 있나 (예시)

| 상황 | 감각 |
|------|------|
| 출퇴근·운전 빈도 높음 | 검토 여지 ↑ |
| 대인 무한 등 자보만 최소 | 자보 보강이 먼저 |
| 타인 차·렌트 자주 | 운전자(사람) 보장 쪽 유리할 수 있음 |
| 거의 안 운전 | 우선순위 ↓ |
| 영업·배달 | 전용/유상 약관 확인 필수 |
| 이미 유사 특약 충분 | 추가 가입 신중 |

나이나 차급만으로 결정되지 않는다. **운전 패턴 + 자보 공백 + 중복**이 기준이다.

---

## 10. 흔한 오해

| 오해 | 보완 |
|------|------|
| 운전자보험 = 자동차보험 업그레이드 | 역할이 다름. 배상은 자보 |
| 가입하면 형사처벌이 없어진다 | 처벌 면제가 아님. 비용·합의 여력에 도움 |
| 금액이 클수록 무조건 이득 | 조건·면책·중복·보험료를 같이 봄 |
| 음주사고도 나온다 | 대체로 면책 |
| 가족 모두 자동 보장 | 피보험자·특약 범위 확인 |

---

## 11. 정리

1. **배상·내 차** → 자동차보험을 먼저 튼튼히  
2. **형사·벌금·변호사·합의 정액** 공백이 걱정되면 운전자보험(또는 자보 특약)을 비교  
3. **조건·면책·중복**을 약관으로 확인  
4. 예방·법규 준수가 어떤 보험보다 앞선다

## 면책

> **면책**  
> 일반 학습용 정리이며 **특정 상품 가입·설계 권유가 아니다**.  
> 보장명·한도·지급 조건·면책은 보험사·약관·특약마다 다르다. 계약 전 약관·상품설명서를 확인한다.
